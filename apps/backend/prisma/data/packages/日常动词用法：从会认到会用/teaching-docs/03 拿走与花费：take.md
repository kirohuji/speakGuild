# take：把东西纳入行动

`take` 常带有“拿走、选择或接受并使用”的感觉。

| 场景 | 搭配 |
| --- | --- |
| 从这里带走 | `take this bag with you` |
| 交通或路线 | `take a bus / taxi / train` |
| 时间 | `It takes ten minutes.` |
| 药物与措施 | `take medicine / action / a break` |
| 照片与记录 | `take a photo / notes` |
| 接受机会或责任 | `take a chance / responsibility` |
| 参与 | `take part in a meeting` |

和 `bring` 对比：`Take this to Leo.` 是把它从这里带走；`Bring this to me.` 是朝我所在的位置带来。

常见短语有 `take off` 脱下或起飞、`take out` 取出、`take over` 接管、`take care of` 照顾或处理。

## 开口任务

说明你去机场需要采取的六个动作，包括交通、耗时、随身物品、拍照或记录以及一次休息。
