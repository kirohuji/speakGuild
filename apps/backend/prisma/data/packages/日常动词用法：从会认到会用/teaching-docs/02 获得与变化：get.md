# get 的核心不是一个中文意思

`get` 的核心是“到达一个新位置或新状态”，因此在日常英语中可以承担很多功能。

- 收到或获得：`get a message / job / ticket`
- 到达：`get to the station`，但说 `get home / here / there`
- 变得：`get tired / cold / better / worse`
- 理解：`I get it.`
- 让某事完成：`get something done`，如 `I got my phone repaired.`

常见短语也保留了“变化或移动”的感觉：`get up` 起床、`get in/out` 进出、`get on/off` 上下公共交通、`get back` 回来、`get over` 从疾病或挫折中恢复、`get along with` 与人相处。

`get` 很口语；正式语境可以换成更明确的 `receive`、`obtain`、`become` 或 `arrive`。
