# 动词后的小词为什么重要？

小品词常带有方向或结果：`up` 常有向上、完成或增强感，`down` 有向下、减少或停止感，`on` 有接触或继续感，`off` 有分离或停止感，`out` 有向外、显现或耗尽感。但最终仍要按完整短语学习。

| 场景 | 高频短语 |
| --- | --- |
| 设备 | `turn on/off`、`plug in`、`shut down` |
| 拿取穿戴 | `pick up`、`put down`、`put on`、`take off` |
| 日程 | `set up`、`put off`、`call off`、`show up` |
| 问题 | `find out`、`work out`、`figure out`、`deal with` |
| 数量状态 | `run out of`、`cut down on`、`use up` |
| 人际 | `get along with`、`look after`、`break up`、`calm down` |

可分短语中，名词可放两处：`turn off the light / turn the light off`；代词只能放中间：`turn it off`。`look after`、`run out of` 等不可分。
