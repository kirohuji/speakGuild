# 放下、设置和保持原样

`put` 表示把物品移到一个位置，句子通常要说明“放在哪里”：`Put the cup on the table.` 只说 `Put the cup.` 通常不完整。

`set` 常表示经过选择后设置设备、时间、规则、目标或场景：`set an alarm / date / goal / limit / example`。它也可以表示摆放：`set the table` 是摆餐具。

`leave` 有两条常见路线：一是离开或把东西留下，`leave the office / leave my bag at home`；二是让某物保持状态，`leave the door open / leave me alone`。

常见短语：`put on` 穿上或开启播放、`put off` 推迟、`put away` 收好、`put up with` 忍受；`set up` 安装或创立；`leave out` 遗漏，`leave behind` 落下。
