# 已经知道、正在学习、系统钻研和教给别人

`know` 描述已经拥有知识或熟悉某人某地，通常是状态：`I know the answer / Mia / Shanghai well.`

`learn` 强调知识或技能从无到有：`learn English`、`learn to drive`、`learn about history`、`learn that the shop is closed`。`study` 强调投入时间观察或系统学习，但不保证已经学会。`teach` 是把知识传给别人。

> I studied Spanish for two years, but I never learned to speak it well.

常见结构：

- `know how to do` 知道怎么做
- `learn from mistakes` 从错误中学习
- `study for a test` 为考试学习
- `teach someone something / how to do`

注意 `learn someone` 不能表示“教某人”，应使用 `teach someone`。

## 开口任务

介绍一项技能：你原来知道什么、如何学习、系统练习了什么、谁教了你，以及现在是否已经学会。
