## 课程定位

课程训练高频动词在真实句子中的选择和搭配，不把动词当作孤立词表。第一卷解决日常动作、移动、给予、说话和感知；第二卷解决放置、发现、决定、尝试、持续、请求、关系处理和短语动词。

## 第一卷：L1 动作发动机

1. do 与 make
2. get
3. take
4. have、keep 与 hold
5. give、bring、send 与 show
6. say、tell、speak 与 talk
7. look、see、watch 与 read
8. hear、listen 与 sound
9. go、come、arrive 与 reach

最终输出覆盖一天安排、拿取物品、传递信息、问路和简短经历。学习者要能选择合适动词并说出完整简单句。

## 第二卷：L2 决定、过程与处理

1. put、set 与 leave
2. find、look for 与 discover
3. know、learn、study 与 teach
4. think、consider、decide 与 choose
5. try、manage 与 practice
6. 开始、继续与停止
7. ask、wait、pay 与 apply
8. care、depend、deal 与 belong
9. 高频短语动词综合

最终输出覆盖选择方案、说明进度、处理问题和复述过程。学习者需要说明原因，并在 3–5 轮对话中保持动词搭配正确。

## 训练标准

- 每主题 2 个核心动词对比、4 个句块、2 个句型，现有数据量合理。
- 每主题最后完成一个 30–60 秒场景输出。
- 第二卷复用第一卷动词时标为复习，不重复认领。
