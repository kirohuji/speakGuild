# 四种“说”看什么？

`say` 看话语内容；`tell` 看接收信息的人；`speak` 常用于语言、能力或较正式谈话；`talk` 强调互动交谈。

| 动词 | 常见结构 |
| --- | --- |
| `say` | `say something`、`say something to someone` |
| `tell` | `tell someone something`、`tell someone to do` |
| `speak` | `speak English`、`speak to/with someone` |
| `talk` | `talk to/with someone about something` |

所以说 `She said hello to me.`，但说 `She told me the truth.` 不能说 `said me`。固定搭配包括 `tell a story / joke / lie`、`say sorry / thank you`。

短语 `speak up` 是大声说或公开表达，`talk over` 是详细讨论，`talk someone into doing` 是说服某人做事。

## 开口任务

转述一次谈话：谁说了什么、谁告诉了谁、使用什么语言、双方谈论了什么。四个动词都要用到。
