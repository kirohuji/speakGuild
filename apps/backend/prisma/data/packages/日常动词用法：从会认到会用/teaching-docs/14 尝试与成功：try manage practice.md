# 努力做、试一种办法、最终成功和反复练习

`try to do` 表示努力完成目标；`try doing` 表示把一种方法拿来试试看。

> I tried to open the door, but it was stuck.
>
> Try using the other key.

`manage to do` 包含“有困难但最终成功”的结果，所以 `I managed to open it.` 明确表示门开了。`practice` 表示为了提高技能反复做，后接名词或 `V-ing`：`practice pronunciation / speaking`，不说 `practice to speak`。

相关动词：`attempt to do` 比 `try to do` 正式；`succeed in doing` 表示成功且介词 `in` 后接 `V-ing`；`fail to do` 表示未能完成。

## 开口任务

描述解决一个设备故障的过程：努力完成什么、试了哪些办法、是否最终成功，以及以后需要练习什么技能。
