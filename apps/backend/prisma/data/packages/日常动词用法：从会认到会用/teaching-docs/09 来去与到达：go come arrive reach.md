# 先确定移动参照点

`go` 通常表示离开说话者所在处；`come` 表示朝说话者、听者或双方约定的地点移动。电话里可以对在办公室的人说 `I'm coming to the office now.`，因为办公室是对方的参照点。

表达到达时结构不同：

- `arrive at` + 小地点：`arrive at the station`
- `arrive in` + 城市、国家：`arrive in Shanghai`
- `reach` + 地点：`reach the station`，不加 `to/at`
- `get to` + 地点：`get to the station`
- 特殊副词：`arrive/get home`，不加 `to`

常见短语：`go out` 外出、`go on` 继续或发生、`come back` 回来、`come from` 来自、`come across` 偶然遇见、`come up with` 想出。

## 开口任务

说明一位朋友从另一座城市来你家：何时出发、到达城市、抵达车站、到你家以及你去哪里接他。
