# do 与 make：过程还是结果？

两者都常译成“做”，但观察角度不同。`do` 聚焦任务、活动和过程；`make` 聚焦产生、创造或促成的结果。

| 用 `do` | 用 `make` |
| --- | --- |
| `do homework / housework / exercise` | `make breakfast / coffee / a cake` |
| `do a job / task / test` | `make a plan / decision / choice` |
| `do business / research` | `make a mistake / change / difference` |
| `do well / your best` | `make money / friends / progress` |

不是所有搭配都能靠逻辑猜出，因此要把它们当成完整句块学。`make someone do something` 还有“使某人做某事”的意思：`The joke made me laugh.`

> I did some research and made a list. Then we made a decision.

## 开口任务

说出今天要做的三项任务和希望产生的三个结果。至少使用 `do the laundry`、`make a plan` 这类完整搭配，而不是只说孤立动词。
