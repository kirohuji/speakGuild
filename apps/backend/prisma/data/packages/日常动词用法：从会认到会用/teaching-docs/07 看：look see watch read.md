# 主动看、看见、持续观看和阅读

`look` 是主动把目光投向目标，目标前通常有 `at`；`see` 是看见的结果或视觉能力；`watch` 是持续注意变化中的活动；`read` 是理解文字或符号。

> Look at the door. Can you see the sign? Read it while I watch the traffic.

常见搭配和短语：

- `look for` 寻找，`look after` 照顾，`look up` 查阅或好转，`look into` 调查。
- `see a doctor` 看医生，`see someone` 会见或交往，`see what you mean` 明白意思。
- `watch TV / a game / someone do something`。
- `read about` 读到相关内容，`read through` 从头到尾检查。

`look like` 后接名词表示看起来像；`look + adjective` 描述外观：`You look tired.`
