# 动作处在哪个阶段？

`start/begin` 表示开始，后接 `to do` 或 `V-ing` 时多数日常场景差别不大：`It started to rain / raining.`

`continue` 同样可接 `to do` 或 `V-ing`；`keep doing` 更强调持续或反复：`He kept asking the same question.`

最重要的区别是：

- `stop doing`：终止正在做的事，`I stopped working.`
- `stop to do`：停下原来的事去做另一件事，`I stopped to eat.`

`finish` 后接名词或 `V-ing`：`finish the report / writing the report`，不能说 `finish to write`。`end` 更常描述事件或时期结束：`The meeting ended at five.`

## 开口任务

讲述一天的工作节奏：何时开始、什么活动持续进行、因为什么停下来做另一件事、停止了什么坏习惯，以及最终完成了什么。
