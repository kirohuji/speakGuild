# Foundation 学习包 — 词汇总表

> 以下为所有 Foundation 学习包（基础①—⑩）的实义词汇清单。
> **设计原则**：仅登记**实义词**（名词、实义动词、形容词、副词），语法功能词（be 动词、助动词、情态动词、代词、介词、连词、冠词）通过句型教学自然覆盖，不计入词汇。
> 词汇来源：牛津 3000 A1-B1 级别高频词 + 各包 `学习包的功能介绍.md` 中的实义词。
> 每个词在其首次出现的包中登记，跨包不重复。

## 排除的语法功能词（不计入词汇）

以下词类通过句型/句块/对话教学自然覆盖，**不作为词汇登记**：

| 类别 | 示例 | 教学方式 |
|:-----|:-----|:---------|
| be 动词 | am, is, are, was, were | `I'm ___` / `It's ___` 句块 |
| 助动词 | do, does, did, don't, doesn't, didn't | `Do you ___?` 句型 |
| 情态动词 | can, could, will, would, may, might, shall, should, must | `Can I ___?` / `I'd like ___` 句块 |
| 人称代词 | I, you, he, she, it, we, they | 角色对话自然习得 |
| 物主/指示代词 | my, your, his, her, our, their, mine, yours, this, that | `My name ___` / `This is ___` 句块 |
| 介词 | in, on, at, to, for, from, with, by, about, of | 搭配句块覆盖 |
