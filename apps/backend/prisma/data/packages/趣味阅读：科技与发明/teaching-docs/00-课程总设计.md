## 主题方向

一个问题怎样产生发明、失败的原型、电话与远距离沟通、摄影留下瞬间、冰箱改变食物、疫苗背后的合作、卫星和导航、机器人怎样感知、可再生能源、无障碍科技、日常物品的小设计、未来城市的一个选择。

选题不追逐厂商宣传，也不把尚无证据的预测写成事实。内容制作时记录权威来源和核验日期。

## 明确学习内容

问题—尝试—结果结构、步骤、原因和影响；`be used to / allow / make it possible / solve / improve` 等说明表达。

## 读后输出

学习者用“问题、办法、改变”三张卡完成 1 分钟讲解，再选择一个设计说明它帮助了谁、仍有什么限制。
