## 课程定位

这套内容提供 500 个日常交流中可以快速识别和调用的表达，包括问候、回应、请求、澄清、评价、安慰和事务处理。它不是要求学习者按编号从头背到尾的线性课程，而是供场景训练和其他学习包调用的高频表达库。

## 8 个表达主题

1. 问候与寒暄
2. 感谢、道歉与祝福
3. 请求、指令与许可
4. 疑问、澄清与确认
5. 观点、同意与评价
6. 情绪与安慰
7. 日常陈述与事务
8. 惯用语与俚语

## 500 句的使用方式

- 按交际功能和场景调用，不按编号机械背诵。
- 每个表达需要标注含义、使用场景、正式程度、关系距离和必要的风险提示。
- 优先训练可以迁移到多个场景的表达；影视化、冒犯性或低频表达只作为识别内容。
- 重复表达、错误表达和不自然表达需要在进入后续数据前完成清理。
- 每个场景首轮只新学 5–8 条；其余表达用于听辨、选择和间隔复习，不能要求一次背完一卷。

## 训练路径

> 听懂表达 → 判断场景 → 模仿语气 → 替换信息 → 对话回应 → 延伸一句

表达库将为“口语万能造句”、动词、时态、情态以及句子扩展等学习包提供例句和对话素材。
