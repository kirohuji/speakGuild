# Foundation / Course / Advanced 课程内容统一设计规范

> 本规范适用于所有学习包 MD。CSV 必须严格依据 MD 生成；如 MD 与 CSV 冲突，以修订后的 MD 为唯一内容来源。

## 1. Vocabulary、Chunk、Pattern 的边界

| 类型 | 定义 | 正确示例 | 不应放入 |
|:-----|:-----|:---------|:---------|
| Vocabulary | 单词、固定多词词项或有独立词义的搭配 | `decide`、`deadline`、`look after` | 带具体主语的整句 |
| Chunk | 现实交流中可直接说出的完整或半固定表达 | `I see what you mean.`、`I'm calling to follow up on...` | 只有抽象槽位、没有交际功能的语法骨架 |
| Pattern | 能生成多个新句子的结构模板 | `The main reason is that ___.` | 不能替换、只能原样背诵的句子 |

补充规则：

```text
decide                 → Vocabulary
decide to do           → Vocabulary 中的搭配说明
I decided to leave.    → Chunk
I decided to ___ because ___. → Pattern
```

一个表达可以因教学需要在不同资产中建立关联，但不能把完整句子计作“一个单词”。词汇总量只统计词元和固定多词词项；句块、句型另行统计。

## 2. 跨包复现原则

取消“核心词必须零跨包重叠”的规则，改为“首次引入 + 累加复现”：

| 标签 | 含义 |
|:-----|:-----|
| `new_core` | 本包首次引入，必须主动掌握 |
| `review_core` | 前包已学，但本包任务仍必须主动调用 |
| `extension` | 用于扩大表达范围，不作为首次通过的硬性要求 |

高频词必须跨包、跨场景、跨时间复现。去重只用于统计首次引入数量，不得为了追求新词数量加入低频、古旧、过度正式或不适合当前 CEFR 的词。

新核心词必须同时满足：

1. 对本 Topic 的交流任务有直接价值。
2. 符合当前 CEFR 和语域。
3. 至少进入一个 Chunk。
4. 至少进入一个 Pattern 示例或替换槽。
5. 在后续至少两个 Topic 中再次主动调用。

## 3. 每个 Topic 的双输出

每个 Topic 必须同时提供：

### 口语输出

- Foundation 1—3：20—45 秒或 4—6 轮互动。
- Foundation 4—5：45—60 秒或 6—8 轮互动。
- Foundation 6—10：1—2 分钟或 8—10 轮互动。
- Course：2—5 分钟或 12—16 轮互动。
- Advanced：4—10 分钟或 16—24 轮互动。

### 微写作输出

- Foundation 1—3：20—50 词。
- Foundation 4—5：50—80 词。
- Foundation 6—10：80—150 词。
- Course：120—250 词。
- Advanced：250—500 词。

微写作必须迁移同一 Topic 的交际能力，而不是抄写口语台词。

## 4. 反馈与重做

每个 Topic 至少执行一次：

```text
首次输出
→ 按任务完成、连贯、词汇、语法、发音/拼写获得反馈
→ 只查看反馈，不查看完整标准答案
→ 第二次重说或重写
→ 在新场景做一次延迟迁移
```

句块命中数量不能单独决定通过。只有完成任务且第二次输出达到该阶段最低标准，Topic 才算掌握。

## 5. 数量口径

每个 MD 只能有一套权威数量。文件开头“数据规模”和文末“数据文件说明”必须完全一致：

```text
Scenes
Topics
Vocabulary（new_core / review_core / extension 分列）
Chunks
Patterns
Episodes
episode_chunks
Warmup Topics
Ink scripts
```

目标数量与实际内容尚未完全编写时，使用“目标”并明确标记；不得同时出现互相冲突的两套数字。
