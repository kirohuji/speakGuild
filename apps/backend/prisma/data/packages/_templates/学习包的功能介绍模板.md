### Topic 对话设计规则

```text
□ 场景必须具体，不能只写“日常对话”或“工作场景”
□ 人物必须有身份和关系，不能只写 A / B
□ 对话必须完成一个明确任务，而不是互相朗读例句
□ 每句都应符合本包已学语法和难度
□ 核心句块应自然出现在对话中
□ 每个对话 List 至少 10 句；综合 Topic 建议 12—16 句
□ 10 句应形成“开场—任务出现—信息推进—确认或修复—任务完成”的连续过程
□ 同一章节优先复用固定人物，形成连续剧情
□ 对话需要包含回应、追问、确认或纠正，不能只有单向陈述
```

## 输出训练流水线（Warmup Pipeline）

| 阶段 | 训练目的 | 词汇要求 |
|:----|:---------|:---------|
| **listen_and_choose** | 听懂句块的真实意图 | 核心句块 |
| **chunk_shadowing** | 建立语音和节奏 | 核心句块 |
| **core_substitution** | 使用全部核心词 | 核心词全部覆盖 |
| **extension_substitution** | 扩大表达范围 | 扩展词全部覆盖 |
| **contrast_or_repair** | 对比或修正常见错误 | 本 Topic 核心语法 |
| **scenario_response** | 根据对话场景作回应 | 核心词 + 扩展词 |
| **personal_output** | 输出自己的真实内容 | 开放回答 |

## 设计检查清单

```text
□ 学习包有明确核心目标和可验收的结课能力
□ 每个场景承担不同交际任务，与前后包形成递进
□ 每个 Topic 都有教学说明、学习重点和完成标准
□ 每个 Topic 都有至少一个核心动词或功能动词
□ 每个 Topic 都有一个可独立验收的主句型
□ 每个 Topic 都有至少三个独立核心句块
□ 每个 Topic 都有具体场景、具名人物和对话 List
□ 对话中的句块自然、高频，并符合本包难度
□ 每个核心词至少进入一个核心句块
□ 每个核心词至少进入一个句型示例或替换槽
□ 每个扩展词都进入 warmup_pipeline
□ Warmup 的场景回应与 Topic 对话保持一致
□ 综合 Topic 不增加新核心词或新语法
□ Topic 数量以练习深度为准，不为了数量拆分
```

### 常见设计错误

| 错误类型 | 问题 | 调整原则 |
|:---------|:-----|:---------|
| Topic 只有标题 | 用户不知道本节要学什么 | 补齐教学说明、重点和完成标准 |
| Topic 没有独立教学资产 | 只能依赖其他 Topic，无法回答“这节学什么” | 配置动词、主句型和至少三个独立句块 |
| 对话没有场景和人物 | 台词缺少真实语境 | 写明时间、地点、任务和人物关系 |
| 对话只是例句排列 | 没有真正完成沟通 | 加入回应、追问、确认或纠正 |
| 核心词只出现在词表 | 学习者认识但不会用 | 放入 chunks 和 patterns |
| 扩展词没有训练出口 | 分层设计失效 | 逐词进入 warmup |
| 场景之间重复 | 用户缺少新鲜感和进阶感 | 每个场景承担不同任务 |
