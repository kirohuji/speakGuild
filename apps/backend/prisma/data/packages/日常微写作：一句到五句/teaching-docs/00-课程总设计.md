## 单包边界

| 包内阶段 | 难度 | 场景任务 |
| --- | --- | --- |
| 前半：一句到三句 | L1 | 介绍自己、今天安排、回复邀请、说明迟到、描述地方 |
| 后半：三句到五句 | L1–L2 | 提请求、报问题、分享经历、做比较、总结本周 |

共 10 个主题，每主题包含口答、两次写作和写后口述。两阶段属于同一能力链，不再拆成两个偏薄学习包。

## 课程定位

这不是传统作文课。学习者先说出一句，再把它写清楚；然后逐步扩展到三至五句，最后重新开口。写作在这里用于减慢思考速度、看清缺失信息，并帮助下一轮口语更完整。

## 10 个日常场景与学习内容

| 场景任务 | 从一句扩展到五句时要学什么 | 写后口语任务 |
| --- | --- | --- |
| 介绍自己 | 姓名、来自哪里、工作/学习、兴趣 | 30 秒自我介绍 |
| 说今天的安排 | 时间 + 动作 + 地点 | 不看稿说出三个安排 |
| 回复邀请 | 接受/拒绝 + 原因 + 替代时间 | 给朋友口头回复 |
| 说明迟到 | 当前情况 + 原因 + 到达时间 + 道歉 | 留一段 20 秒语音 |
| 描述一个地方 | 总体印象 + 位置 + 两个细节 | 向朋友推荐这个地方 |
| 提一个请求 | 背景 + 明确请求 + 时间 + 感谢 | 当面礼貌提出请求 |
| 报告小问题 | 什么坏了 + 何时开始 + 影响 + 希望怎样处理 | 给维修人员说明情况 |
| 分享一次经历 | 何时何地 + 发生什么 + 感受 | 45 秒经历复述 |
| 做简单比较 | 两个选择 + 一个共同点 + 一个差异 + 选择 | 说出选择和理由 |
| 总结本周 | 完成的事 + 困难 + 下一步 | 1 分钟学习周报 |

## 单课流程

> 先口答 → 写关键词 → 写第一句 → 补两至四句必要信息 → 检查顺序 → 朗读修改 → 合上文本重新说

L1 每题 10–40 词，可以提供词库和开头；L2 每题 30–80 词，只提供内容功能提示。反馈优先指出“缺少哪条必要信息”和“哪两句关系不清楚”，随后才处理局部语法。

## 掌握标准

学习者能围绕一个日常目的写出 3–5 句连贯短文，并在不逐字朗读的情况下，用相同信息完成 30–60 秒口头表达。
