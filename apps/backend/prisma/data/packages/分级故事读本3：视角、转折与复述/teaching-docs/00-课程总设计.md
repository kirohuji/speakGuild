## 内容设计

每篇包含人物目标、隐含动机、一次信息转折和不同视角。题材覆盖友谊、城市谜题、家庭选择、旅行意外和小型职场冲突。

## 学习与输出

学习伏笔、视角、可靠信息和人物变化。每篇用两条证据解释转折，再完成 1–2 分钟复述；不追求文学术语考试化。
