# 11 日常动作与生活场景动词

> 所属课程：常见动词专项：300 个核心用法  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

从起床到下班，用准确动词讲一天，而不是反复使用 do、make、go。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 高频动词要和对象一起记：make breakfast、take a shower。
2. do/make/take/get 的中文都很宽，英语靠固定搭配区分。
3. 动作顺序用 first/then/after that/finally 组织。
4. 复述真实生活时优先选具体动词。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `I made breakfast at seven.` | 我七点做了早餐。 | make + 成果 |
| `I took a quick shower.` | 我快速洗了个澡。 | take a shower |
| `I caught the early bus.` | 我赶上了早班公交。 | catch + 交通工具 |
| `I picked up a package.` | 我取了一个包裹。 | pick up + 物 |
| `I spent an hour cooking.` | 我花了一小时做饭。 | spend + 时间 + doing |
| `I set an alarm for six.` | 我把闹钟设在六点。 | set + 设备 + for + 时间 |

2. 以 `I took a quick shower.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `I caught the early bus.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `I picked up a package.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：用 10 个不同实义动词讲今天，禁止连续两句使用 do、make 或 go。
