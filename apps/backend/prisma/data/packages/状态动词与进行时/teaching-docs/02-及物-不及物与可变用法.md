# 02 及物、不及物与可变用法

> 所属课程：常见动词专项：300 个核心用法  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

在机场说明航班到达、工作人员打开登机口、乘客等待等动作。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 及物动词直接带宾语；不及物动词不能硬接宾语。
2. arrive/reply/listen 等常需介词；reach/answer/hear 可直接接宾语。
3. 很多动词可及物也可不及物，如 open、change、start、stop。
4. 错误修正时优先检查“这个义项后面能否直接放名词”。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `The train arrived at nine.` | 火车九点到达。 | arrive 后不直接接地点宾语 |
| `We reached the station at nine.` | 我们九点到达车站。 | reach 直接接地点 |
| `She answered my question.` | 她回答了我的问题。 | answer 是及物动词 |
| `She replied to my email.` | 她回复了我的邮件。 | reply to + 内容 |
| `The meeting started late.` | 会议开始得很晚。 | start 不及物 |
| `They started the meeting late.` | 他们很晚才开始会议。 | start 及物 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `The train arrived at nine.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `We reached the station at nine.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `She answered my question.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `She replied to my email.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：模拟机场服务台说明三个事件，刻意交替使用及物和不及物结构。
