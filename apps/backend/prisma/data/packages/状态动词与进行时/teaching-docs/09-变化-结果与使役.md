# 09 变化、结果与使役

> 所属课程：常见动词专项：300 个核心用法  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

描述设备从正常到故障、维修人员使它恢复工作的过程。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. become/get/grow/turn 表变化，后接形容词或名词。
2. break/melt/dry/close 等可构成自发变化与使动交替。
3. make/let/have/get 表使役，但后接形式不同。
4. 结果结构关注“最后变成什么”，不是只罗列动作。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `The screen went dark.` | 屏幕黑了。 | go + 形容词表不良变化 |
| `The room became quiet.` | 房间安静下来。 | become + 形容词 |
| `The ice melted quickly.` | 冰很快融化了。 | 自发变化 |
| `The heat melted the ice.` | 高温使冰融化。 | 使动用法 |
| `I had a technician check it.` | 我让技术员检查了它。 | have + 人 + 原形 |
| `I got the printer working again.` | 我让打印机重新工作了。 | get + 宾语 + doing |

2. 以 `The room became quiet.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `The ice melted quickly.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `The heat melted the ice.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：按“原状态—发生变化—采取动作—最终结果”报告一次故障。
