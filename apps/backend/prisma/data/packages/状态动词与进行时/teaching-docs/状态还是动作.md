# 它本来如此，还是正在发生？

你走进一个房间时，可以同时说两种信息：房间本来是什么样的，以及此刻谁正在做什么。英语会用不同的形式把这两层信息分开。

## 先问自己一个问题

你是在描述一个稳定状态，还是在拍一张“现在正在发生”的照片？

- `This room is usually quiet.` 说的是房间通常的状态。
- `People are talking outside.` 说的是此刻正在发生的动作。

`usually`、`every day` 这类词常常提示你在说习惯或状态；`right now`、`at the moment` 常常提示你在看眼前的过程。

再看四组最基本的对比。左边是状态，右边是眼前动作：

| 状态 / 事实 | 正在发生的动作 |
| --- | --- |
| `I know the answer.` | `I am looking for the answer.` |
| `This soup tastes salty.` | `The chef is tasting the soup.` |
| `You look tired.` | `Why are you looking at me?` |
| `The bag weighs ten kilos.` | `I am weighing the bag.` |

## 这样把话接起来

> Mia: Is this room usually quiet?
>
> Lin: Yes, it is. But people are talking outside right now.
>
> Mia: I can hear them.

| 你要说什么 | 可以这样开口 | 换成自己的信息 |
| --- | --- | --- |
| 通常状态 | `It is usually quiet here.` | quiet → busy / warm / crowded |
| 眼前动作 | `People are talking outside.` | talking → waiting / cooking / working |

不要先背一张“不能用进行时”的动词表。先确认你想表达的是状态还是动作；形式会跟着意思走。

## 轮到你开口

1. 说一句你现在所在地方通常的状态。
2. 再说一句此刻有人正在做的事。
3. 把两句话接成一句：`It is usually ..., but ... right now.`

## 说完自己检查

- 我有没有把稳定状态和眼前动作分开？
- 我的进行时是不是在描述正在发生的过程？
