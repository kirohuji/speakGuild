# 01 先看动词，不先看“进行时”

> 所属课程：常见动词专项：300 个核心用法  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

在咖啡店描述“汤尝起来咸”和“厨师正在尝汤”，建立动词中心意识。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 动词决定句子的骨架；先判断意义和配价，再选时态。
2. 同一个词可有状态义和动作义，结构随词义改变。
3. 及物性属于某个义项，不是单词永久不变的标签。
4. 先学高频搭配和场景句，不孤立背中文释义。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `The soup tastes salty.` | 这汤尝起来很咸。 | taste 是系动词，后接形容词 |
| `The chef tasted the soup.` | 厨师尝了汤。 | taste 是及物动作动词 |
| `I think the plan will work.` | 我认为这个计划可行。 | think 表观点 |
| `I am thinking about the offer.` | 我正在考虑这个提议。 | think about 表思考过程 |
| `The door opened slowly.` | 门慢慢开了。 | open 不及物 |
| `She opened the door slowly.` | 她慢慢打开了门。 | open 及物 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `The soup tastes salty.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `The chef tasted the soup.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `I think the plan will work.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `I am thinking about the offer.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第二轮：中译英（限时 8 秒/题）

1. 这汤尝起来很咸。
2. 厨师尝了汤。
3. 我认为这个计划可行。
4. 我正在考虑这个提议。
5. 门慢慢开了。
6. 她慢慢打开了门。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：描述餐厅里一个问题：物品呈现什么状态、谁做了什么、你希望如何解决。
