# 12 工作、学习与解决问题

> 所属课程：常见动词专项：300 个核心用法  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

在站会上汇报任务、发现问题、提出方案、分配工作并确认结果。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 工作动词要连同搭配学习：meet a deadline、solve a problem。
2. plan/decide/agree/refuse 常决定后接 to do、on 或 that 从句。
3. avoid/finish/practice 后常接 doing。
4. 汇报时用动词区分事实、过程、结果和下一步。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `We completed the task on time.` | 我们按时完成了任务。 | complete + 名词 |
| `I am working on the report.` | 我正在处理报告。 | work on + 任务 |
| `We solved the main problem.` | 我们解决了主要问题。 | solve + problem |
| `She suggested changing the date.` | 她建议更改日期。 | suggest + doing |
| `They agreed to test it again.` | 他们同意再测试一次。 | agree + to do |
| `I prevented the error from spreading.` | 我阻止了错误扩散。 | prevent + 物 + from doing |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `We completed the task on time.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `I am working on the report.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `We solved the main problem.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `She suggested changing the date.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：做一次 60 秒站会汇报：完成项、阻塞项、解决办法、负责人和下一步。
