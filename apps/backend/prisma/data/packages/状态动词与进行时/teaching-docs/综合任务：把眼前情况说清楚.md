# 眼前的问题，怎样说清楚？

语法判断的价值不在于把句子分类，而在于让对方准确理解：这个东西现在是什么状态，谁正在做什么，你希望怎样解决。

今天把前几课放进一个咖啡店或酒店的真实场景。先说问题呈现出来的状态，再说眼前正在发生的事，最后提出需要。

## 这样把话接起来

> Lin: Excuse me. This soup tastes too salty.
>
> Server: I am sorry. The chef is checking it now.
>
> Lin: Thank you. I need some help with this order.
>
> Server: Of course. Could you wait for two minutes?

再比较两种你可能会听到的回应：

> The soup tastes strange today.
>
> 汤今天尝起来不对劲；重点是它呈现的味道。

> The chef is tasting the soup now.
>
> 厨师现在正在尝汤；重点是他的动作。

> Will you be needing a new spoon as well?
>
> 你还需要一把新勺子吗？这里用将来进行时，是服务场景中自然、礼貌的确认。

| 你要完成的动作 | 可以先说 | 为什么这样说 |
| --- | --- | --- |
| 描述问题状态 | `This soup tastes too salty.` | 汤呈现出来的味道。 |
| 说明正在处理 | `The chef is checking it now.` | 厨师的动作正在发生。 |
| 说出需要 | `I need some help with this.` | 你现在处于需要帮助的状态。 |
| 礼貌请求 | `Could you check it for me?` | 请对方做一个动作。 |

## 轮到你开口

1. 选择咖啡店、酒店或商店中的一个小问题。
2. 用一句状态句说明问题：`It tastes / looks / sounds ...`
3. 用一句进行时说明工作人员正在做什么，或你看到什么。
4. 用 `I need ...` 或 `Could you ...?` 说清你希望的下一步。

## 说完自己检查

- 我是否先让对方知道问题是什么？
- 我有没有把“物品呈现的状态”和“人正在做的动作”分开？
- 我的请求是否具体、礼貌且可执行？
