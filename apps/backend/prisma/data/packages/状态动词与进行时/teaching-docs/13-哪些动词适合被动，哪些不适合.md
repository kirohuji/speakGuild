# 13 哪些动词适合被动，哪些不适合

> 所属课程：常见动词专项：300 个核心用法  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

写事故报告：强调受影响的物品、已采取的措施和责任不明的信息。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 只有能带宾语的义项通常才能把宾语提升为被动主语。
2. 发生、到达、属于、拥有等不及物或关系义通常没有普通被动。
3. 双宾语动词可能形成两种被动，但自然度不同。
4. 被动不是“更高级”，只有受事更重要或施事未知时才用。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `The package was delivered this morning.` | 包裹今天早上送到了。 | 受事是信息中心 |
| `The window was broken during the storm.` | 窗户在暴风雨中破了。 | 施事未知或不重要 |
| `I was given a new key.` | 有人给了我一把新钥匙。 | 人宾语提升 |
| `A new key was given to me.` | 一把新钥匙给了我。 | 物宾语提升 |
| `The accident happened at noon.` | 事故中午发生。 | happen 无普通被动 |
| `This laptop belongs to Mia.` | 这台电脑属于米娅。 | belong to 无被动 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `The package was delivered this morning.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `The window was broken during the storm.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `I was given a new key.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `A new key was given to me.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：用主动和被动各三句报告事故，并解释为什么选择该语态。
