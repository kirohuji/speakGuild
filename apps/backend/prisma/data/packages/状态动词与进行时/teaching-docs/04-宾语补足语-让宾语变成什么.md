# 04 宾语补足语：让宾语变成什么

> 所属课程：常见动词专项：300 个核心用法  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

处理酒店投诉：客人发现房间很冷，经理让员工保持门关闭并安排换房。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 宾语补足语说明宾语的身份、状态或动作。
2. make/keep/find/consider 可接宾语 + 形容词或名词。
3. want/ask/tell/allow 常接宾语 + to do。
4. 感官动词可接宾语 + do/doing，完整过程与进行片段不同。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `The news made me nervous.` | 这个消息让我紧张。 | make + 宾语 + 形容词 |
| `Please keep the door closed.` | 请让门保持关闭。 | keep + 宾语 + 过去分词 |
| `We found the room empty.` | 我们发现房间是空的。 | find + 宾语 + 形容词 |
| `I want you to check it.` | 我想让你检查一下。 | want + 宾语 + to do |
| `I saw him cross the street.` | 我看见他过了马路。 | 看见完整过程 |
| `I saw him crossing the street.` | 我看见他正在过马路。 | 看见进行片段 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `The news made me nervous.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `Please keep the door closed.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `We found the room empty.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `I want you to check it.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：复述一次客诉处理，至少用 make、keep、find、want 中的三个结构。
