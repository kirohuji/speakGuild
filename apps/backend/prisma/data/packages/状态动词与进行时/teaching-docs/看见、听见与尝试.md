# 闻起来很香，还是正在闻？

在咖啡馆里，`The bread smells wonderful.` 不是说面包主动在“闻”什么，而是在描述它给人的气味。`The soup tastes salty.` 也是在说汤呈现出来的味道。这类感官结果通常用一般时。

如果人主动去闻、尝或看，动作正在发生，就可以用进行时。

## 先听出这一步

| 你在描述什么 | 英语怎么说 |
| --- | --- |
| 食物给人的味道 | `The soup tastes great.` |
| 厨师主动尝汤 | `The chef is tasting the soup.` |
| 花给人的气味 | `The flower smells nice.` |
| 一个人主动闻花 | `She is smelling the flowers.` |

`look` 也有两个方向：`You look tired.` 是“你看起来累”；`Why are you looking at me?` 是“你为什么正在看我”。

## `can` 和感官动词：强调“此刻感知到”

在日常英语里，尤其英式英语中，`can see / can hear / can smell / can feel` 很常用。它们不是进行时，而是把“我此刻能够感知到”的意思说得更鲜明。

> I can see Emma coming down the road.
>
> 我看见埃玛正沿着路走过来。

> Can you smell something burning?
>
> 你闻到有东西烧糊了吗？

> I can hear someone singing upstairs.
>
> 我听见楼上有人正在唱歌。

> I can feel my phone vibrating.
>
> 我能感觉到手机在震动。

这里 `coming / burning / singing / vibrating` 描述你感知到的动作；核心动词仍是 `can see / hear / smell / feel`。不要误以为看见、听见本身一定要变成 `I’m seeing` 或 `I’m hearing`。

## 这样把话接起来

> Server: How does the soup taste?
>
> Lin: It tastes too salty. The chef is tasting it now.
>
> Server: I see. We are making a new one for you.

## 轮到你开口

1. 选一种食物，说它闻起来或尝起来怎样。
2. 说一个人正在闻、尝或看的东西。
3. 对身边的人说一句 `You look ...`，再问他或她此刻在做什么。

## 说完自己检查

- 我是在说感官结果，还是人在主动做感官动作？
- `look` 后面是外观印象，还是 `look at` 的动作？
