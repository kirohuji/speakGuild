# 03 双宾语：给谁什么

> 所属课程：常见动词专项：300 个核心用法  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

在办公室转交文件、发送链接、解释流程并为同事预订房间。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. give/send/show/teach/tell 常用“人 + 物”。
2. 也可用“物 + to + 人”；buy/make/get 常用 for。
3. explain/describe/suggest 不能随意套双宾语。
4. 两个宾语较长时，用 to/for 结构通常更清楚。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `She sent me the file.` | 她把文件发给了我。 | send + 人 + 物 |
| `She sent the file to me.` | 她把文件发给了我。 | send + 物 + to + 人 |
| `Can you book me a room?` | 你能给我订个房间吗？ | book + 人 + 物 |
| `Can you book a room for me?` | 你能为我订个房间吗？ | for 表受益者 |
| `He explained the rule to us.` | 他向我们解释了规则。 | 不能说 explained us the rule |
| `I suggested a cheaper option to her.` | 我向她建议了一个更便宜的选择。 | suggest + 物 + to + 人 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `She sent me the file.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `She sent the file to me.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `Can you book me a room?` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `Can you book a room for me?` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：完成一次工作交接：给谁发什么、替谁做什么、向谁解释什么。
