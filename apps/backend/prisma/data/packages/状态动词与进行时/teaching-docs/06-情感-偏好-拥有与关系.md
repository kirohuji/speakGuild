# 06 情感、偏好、拥有与关系

> 所属课程：常见动词专项：300 个核心用法  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

向新朋友介绍喜好、需要、所属关系和目前的生活安排。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. like/love/hate/prefer/want/need 常表达相对稳定的心理状态。
2. have 表拥有通常不用进行体；表体验或进行活动时可以。
3. belong/contain/consist/depend 等描述关系。
4. 状态动词也会因语境改变为动态义，不能死背禁用表。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `I prefer tea to coffee.` | 比起咖啡，我更喜欢茶。 | prefer A to B |
| `This bag belongs to me.` | 这个包属于我。 | belong to 无被动 |
| `The box contains old photos.` | 盒子里装着旧照片。 | contain 表包含 |
| `We are having lunch.` | 我们正在吃午饭。 | have 表活动 |
| `I need more time.` | 我需要更多时间。 | need + 名词 |
| `It depends on the weather.` | 这取决于天气。 | depend on + 条件 |

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：做 60 秒自我介绍，包含偏好、拥有、需要和依赖条件四类信息。
