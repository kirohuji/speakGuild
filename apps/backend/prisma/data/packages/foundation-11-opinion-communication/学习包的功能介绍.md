# 基础⑪ · 表达观点与互动 · Opinion Communication（L1~L2）

> 本文件是基础系列（Foundation）· 第 11 包，专注观点表达本身：询问看法、说明理由、回应同意或不同意见，并完成比较与选择。

## 学习包概览

学习者不只回答事实，还要能够说明“我怎么看”、解释原因，并听懂或回应他人的看法。

```text
询问观点 → 给出观点 → 提供理由 → 回应观点 → 追问或澄清 → 得出选择
```

> 🎯 **核心目标**：掌握48个观点交流核心表达，能够询问观点、表达看法、解释理由、回应不同意见，并作出选择。

> ✅ **结课能力**：能够围绕食物、活动、学习、工作、服务和生活选择完成至少10轮观点对话；不只说 `Yes / No / I like it`，还能说明“为什么、是否同意、哪里不同、最终选择什么”。

### 适用对象

| 维度 | 说明 |
|:----|:-----|
| 难度 | L1~L2 |
| 前置要求 | 已掌握一般现在时、现在进行时和基础疑问句 |
| 学习方式 | 核心表达 → 两个完整句块 → 句型替换 → 10句对话 → Warmup输出 |
| 核心结果 | 从“回答问题”升级为“参与讨论” |

## 设计哲学

### 🗣️ 事实、感受与观点要区分

```text
It is raining.                    眼前事实
I do not like rainy days.         个人感受
I think staying inside is better. 基于事实得出的观点
```

观点可以不同，但理由必须能被别人听懂。礼貌不同意按以下顺序训练：

```text
先确认听懂 → 承认合理部分 → 表达不同看法 → 给出理由
```

例如：`I see your point, but I prefer the first plan.`

### 📐 训练硬性要求

| 教学资产 | 要求 |
|:---------|:-----|
| 核心表达 | 进入2个完整句块、1个句型和所属Topic对话 |
| 扩展词 | 进入Warmup的辨义、构句和情境回应 |
| 对话 | 连续10句，包含观点问题、明确观点、理由/例子、回应与结论 |
| 语法 | 使用《学习包的功能介绍.md》中的时态、状态动词等规则提供依据 |

## 逐话题教学说明与对话 List

| Topic | 教学重点 | 核心表达（4） | 扩展词 |
|:-----:|:---------|:---------------|:-------|
| 09 | 询问对象的看法；`think about / feel about / view on` 后要交代对象 | `What do you think about...?`<br>`How do you feel about...?`<br>`What's your view on...?`<br>`Do you think...is...?` | `topic, issue` |
| 10 | 用完整句标记自己的观点；`I think` 是状态意义 | `I think...`<br>`I feel...`<br>`In my opinion,...`<br>`The way I see it,...` | `personally, honestly` |
| 11 | 先观察正在发生的事，再作评价 | `I can see that...is...ing`<br>`It looks...to me`<br>`I think...is going well`<br>`I don't think...is working` | `currently, clearly` |
| 12 | 对比习惯与今天/此刻的临时情况，再作评价 | `I usually..., but today I'm...ing`<br>`...normally...s, but now...is...ing`<br>`This week, we're...ing`<br>`I think today's...is better` | `normally, temporarily` |
| 13 | `because` 接原因；`so / that's why` 引出结果，不在简单句中同时堆叠 | `I think...because...`<br>`The main reason is...`<br>`That's why...`<br>`So, I think...` | `reason, result` |
| 14 | 区分确定、相信、可能与仍不确定 | `I'm sure...`<br>`I believe...`<br>`Maybe...`<br>`I'm not sure whether...` | `certain, unsure` |
| 15 | `agree` 是动词，使用 `I agree`，不用 `I am agree` | `I agree with you`<br>`I think so too`<br>`That's a good point`<br>`We see it the same way` | `agree, point` |
| 16 | 先承认合理部分，再用 `but` 或条件补充 | `I see your point`<br>`I agree in part`<br>`That may be true, but...`<br>`It depends on...` | `partly, depends` |
| 17 | 礼貌反对：先回应，再说不同理由；`agree` 用 `do not` 否定 | `I don't agree with...`<br>`I don't think so`<br>`I see it another way`<br>`I'm not convinced that...` | `disagree, differently` |
| 18 | 听不清时确认关键词、复述理解并获得确认 | `What do you mean by...?`<br>`Do you mean...?`<br>`Are you saying that...?`<br>`Let me check if I understand` | `meaning, clarify` |
| 19 | 追问理由、例子和依据；`Why do you think...?` 不用 `are` | `Why do you think...?`<br>`Can you give me an example?`<br>`What makes you think...?`<br>`What is your reason for...?` | `example, evidence` |
| 20 | 比较相同点、不同点与最终选择 | `...is better than...`<br>`...is more...than...`<br>`Both are..., but...`<br>`My choice is...` | `option, difference` |


## 输出训练流水线（Warmup Pipeline）

| 阶段 | 训练目标 |
|:-----|:---------|
| `meaning_match` | 区分询问、观点、理由、同意、反对和澄清 |
| `chunk_shadowing` | 建立完整语音节奏 |
| `pattern_substitution` | 替换话题、人物、评价和理由 |
| `opinion_chain` | 组成“问题 → 观点 → 理由 → 回应”链条 |
| `extension_output` | 每个扩展词至少完成3道主动输出题 |
| `dialogue_response` | 推动对话继续，不只回答 `Yes/No` |

## 设计检查清单

```text
□ 每个Topic有4个核心表达、2个扩展词和1段连续对话
□ 每个核心表达有2个句块、1个句型，并进入所属对话
□ 每段对话都有“询问—观点—理由—回应—继续或结论”
□ 同意与反对都说明具体内容或理由
□ 澄清发生在同意或反对之前
□ 比较后说明最终选择及原因
```
