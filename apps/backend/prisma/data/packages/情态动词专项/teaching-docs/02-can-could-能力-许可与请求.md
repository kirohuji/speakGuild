# 02 can、could：能力、许可与请求

> 所属课程：情态动词专项：14 个实用主题  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

在酒店说明能力限制、询问许可并礼貌请求帮助。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. can 表现在能力或非正式许可。
2. could 可表过去一般能力，也可软化请求。
3. 一次成功完成常用 was able to/managed to 更明确。
4. Could you...? 是请求，不一定在问能力。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `I can speak English.` | 我会说英语。 | 现在能力 |
| `I could swim when I was five.` | 我五岁时会游泳。 | 过去一般能力 |
| `We were able to fix it.` | 我们成功修好了。 | 一次成功完成 |
| `Can I leave my bag here?` | 我可以把包放这里吗？ | 询问许可 |
| `Could you check my booking?` | 您能查一下我的预订吗？ | 礼貌请求 |
| `You cannot park here.` | 这里不能停车。 | 禁止或不允许 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `I can speak English.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `I could swim when I was five.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `We were able to fix it.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `Can I leave my bag here?` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：完成酒店入住：说能力、问许可、提两个请求并回应限制。
