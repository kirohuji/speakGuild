# 12 情态疑问与简短回答

> 所属课程：情态动词专项：14 个实用主题  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

在租车柜台询问能力、许可、必要性、建议与可能性。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 情态直接移到主语前，不使用 do。
2. 简短回答保留情态：Yes, you can。
3. Could I...? 的许可回答通常用 can，而不是 could。
4. Must I...? 的否定回答常用 No, you do not have to。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `Can I pay by card?` | 我能刷卡吗？ | 询问可行或许可 |
| `Could you explain this fee?` | 您能解释这项费用吗？ | 礼貌请求 |
| `Must I return it today?` | 我必须今天归还吗？ | 询问强制要求 |
| `No, you do not have to.` | 不，你不必。 | 不是 must not |
| `Should we buy insurance?` | 我们应该买保险吗？ | 征求建议 |
| `Might it be cheaper online?` | 网上会不会更便宜？ | 试探可能 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `Can I pay by card?` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `Could you explain this fee?` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `Must I return it today?` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `No, you do not have to.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：完成租车柜台完整问答，至少问 8 题并使用自然简短回答。
