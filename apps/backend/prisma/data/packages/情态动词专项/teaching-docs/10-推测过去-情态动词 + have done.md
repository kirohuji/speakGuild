# 10 推测过去：情态动词 + have done

> 所属课程：情态动词专项：14 个实用主题  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

复盘错过的会议，推断谁可能忘记、已经离开或本可以通知。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. must have done 表对过去的强推断。
2. may/might/could have done 表过去可能发生。
3. cannot/could not have done 表过去不可能。
4. could have done 也可能表示本可以却没做。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `She must have forgotten.` | 她一定是忘了。 | 过去强推断 |
| `He may have taken the wrong train.` | 他可能坐错车了。 | 过去可能 |
| `They might have left already.` | 他们也许已经走了。 | 弱推测 |
| `It cannot have happened here.` | 这不可能发生在这里。 | 过去不可能 |
| `I could have called you.` | 我本可以给你打电话。 | 有能力但未做 |
| `You should have checked the time.` | 你本该核对时间。 | 过去应做未做 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `She must have forgotten.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `He may have taken the wrong train.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `They might have left already.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `It cannot have happened here.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：复盘一次失误：给出三种推测、一个不可能判断和两条改进意见。
