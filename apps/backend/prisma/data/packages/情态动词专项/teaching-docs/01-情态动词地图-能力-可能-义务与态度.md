# 01 情态动词地图：能力、可能、义务与态度

> 所属课程：情态动词专项：14 个实用主题  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

同一件事分别表达“能、可能、必须、应该、愿意”。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 情态动词后接动词原形，没有第三人称 -s。
2. 情态不是单纯时态，它表达说话人的判断和人际态度。
3. 否定位置在情态后，不用额外 do。
4. 先确定交际意图，再选择强度。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `I can help.` | 我能帮忙。 | 能力或可行性 |
| `It may rain.` | 可能会下雨。 | 中性可能 |
| `You must leave now.` | 你现在必须离开。 | 强义务 |
| `You should rest.` | 你应该休息。 | 建议 |
| `I will call you.` | 我会给你打电话。 | 意愿或承诺 |
| `Would you wait here?` | 你愿意在这里等吗？ | 礼貌请求 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `I can help.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `It may rain.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `You must leave now.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `You should rest.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：围绕一个临时问题，用六种不同态度各说一句。
