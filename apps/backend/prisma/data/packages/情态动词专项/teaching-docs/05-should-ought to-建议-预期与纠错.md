# 05 should、ought to：建议、预期与纠错

> 所属课程：情态动词专项：14 个实用主题  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

给朋友健康、工作和旅行建议，并评价过去没做好的事。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. should/ought to 表建议或合理预期，弱于 must。
2. should have done 表过去本该做却可能没做。
3. should not have done 表过去本不该做。
4. Why should...? 可表达质疑，不只是询问信息。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `You should get some rest.` | 你应该休息一下。 | 建议 |
| `We ought to leave early.` | 我们应该早点走。 | 较正式建议 |
| `The bus should arrive soon.` | 公交应该快到了。 | 合理预期 |
| `You should have called me.` | 你本该给我打电话。 | 过去未做 |
| `I should not have said that.` | 我当时不该那样说。 | 过去后悔 |
| `Why should I apologize?` | 我为什么应该道歉？ | 质疑理由 |

3. 以 `The bus should arrive soon.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。
