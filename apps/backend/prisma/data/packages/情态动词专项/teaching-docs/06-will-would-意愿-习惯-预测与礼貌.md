# 06 will、would：意愿、习惯、预测与礼貌

> 所属课程：情态动词专项：14 个实用主题  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

安排聚会、请求协助、回忆过去习惯并处理拒绝。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. will 可表预测、承诺、即时决定和意愿。
2. would 可软化请求和偏好。
3. would 可表达过去反复习惯，但不描述过去状态。
4. 物品 will not 也可表示“怎么也不肯工作”。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `I will send it tonight.` | 我今晚会发。 | 承诺 |
| `I will help you.` | 我来帮你。 | 即时意愿 |
| `Would you open the window?` | 请您开一下窗好吗？ | 礼貌请求 |
| `I would rather stay home.` | 我宁愿待在家。 | 偏好 |
| `We would visit every summer.` | 我们过去每年夏天都会去。 | 过去习惯 |
| `The door will not open.` | 这门怎么也打不开。 | 事物拒绝工作 |

2. 以 `I will help you.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `Would you open the window?` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `I would rather stay home.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：邀请朋友参加活动，协商安排，并礼貌接受或拒绝。
