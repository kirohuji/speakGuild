# Course ② · 叙事与经历讲述（L3）

> 从“我做了什么”升级为有背景、过程、转折、感受和结果的完整故事。

## 学习包概览

| 维度 | 设计 |
|:-----|:-----|
| CEFR | B1 |
| 前置要求 | Course ①；一般过去时和完成时基础 |
| 核心目标 | 按清晰时间线讲述经历，并让听者能追问和理解重点 |
| 结课任务 | 完成一段 2—3 分钟个人故事并回答追问 |

```text
建立背景 → 事件开始 → 过程推进 → 意外转折 → 结果与反思
```

## 场景与 Topics

| 场景 | Topics | 交际成果 |
|:-----|:-------|:---------|
| 建立故事背景 | 01 时间地点；02 人物关系；03 当时状态；04 故事开场 | 快速建立语境 |
| 推进事件 | 05 先后顺序；06 同时发生；07 原因结果；08 添加关键细节 | 讲清过程 |
| 处理转折 | 09 突发事件；10 计划改变；11 误解与发现；12 高潮时刻 | 形成故事张力 |
| 描述体验 | 13 当时感受；14 他人反应；15 困难与应对；16 最终结果 | 增加人物视角 |
| 回顾反思 | 17 总结经历；18 学到什么；19 如果重来；20 回答追问 | 连接过去与现在 |

## 核心语言系统

- 叙事时态：一般过去时、过去进行时、过去完成时的高频组合。
- 顺序标记：`At first...` / `Meanwhile...` / `Eventually...`
- 转折：`Just as...` / `It turned out that...`
- 评价：`What surprised me most was...`
- 反思：`Looking back, I realize that...`

## 章节与剧集

5 章 × 2 课，依次完成背景、过程、转折、体验和反思；每章末输出一段 60—120 秒叙事，终章整合为完整故事。

## 数据目标

5 Scenes / 20 Topics / 约 80 Chunks / 约 40 Patterns / 120—150 Vocabulary / 10 Episodes / 20 Ink scripts。

## 设计边界

- 故事来自旅行、学习、第一次体验、意外和解决问题。
- 不用大量低频文学描写词制造难度。
- 同一故事至少包含一处听者追问和一处说者澄清。
