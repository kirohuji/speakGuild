# 现在会、过去会、将来能

`can` 最常用于现在的能力：`I can swim.` `could` 可以说过去的一般能力：`I could read when I was five.`

`be able to` 能进入更多时态：`I will be able to join tomorrow.`、`I haven't been able to sleep.` 它也常用于强调某次具体行动最终成功：`We were able to fix the door.`

| 时间或场景 | 常用表达 |
| --- | --- |
| 现在的一般能力 | `can` |
| 过去的一般能力 | `could` |
| 将来或完成时 | `be able to` |
| 过去某次成功完成 | `was/were able to` 或 `managed to` |

> A: Can you use this software?
>
> B: Yes. I couldn't use it last year, but I can now.

## 口语任务

说一项你现在会的技能、一项小时候会的技能，以及一件下周能够完成的事。
