# 回头看：本应、可能和一定已经发生

谈论过去时，常用结构是 `情态动词 + have + 过去分词`。这里的 `have` 不能省略，后面也不是过去式。

- `should have done`：本应该做但通常没有做，常带遗憾或批评。
- `might have done`：过去可能发生了，但不确定。
- `must have done`：根据证据高度确信过去发生了。
- `can't have done`：根据证据认为过去不可能发生。

> I should have checked the platform number.
>
> We might have taken the wrong train.
>
> The train must have left already.

不要说 `must had left`。情态动词之后始终先用原形 `have`，再接过去分词 `left`。

## 综合任务

讲述一次错过约会或交通工具的经历：说一件你本应做的事、两种可能原因和一个根据证据得出的结论。最后再说如果重来你会给自己什么建议。
