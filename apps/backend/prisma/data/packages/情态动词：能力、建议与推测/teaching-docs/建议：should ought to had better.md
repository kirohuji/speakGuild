# 建议也有不同力度

`should` 是最常见的建议；`ought to` 意思相近且稍正式；`had better` 更强，常暗示不照做会有不好的后果。

| 表达 | 常见语气 | 例子 |
| --- | --- | --- |
| `should` | 普通建议 | `You should rest.` |
| `ought to` | 建议或道义期待 | `We ought to tell her.` |
| `had better` | 带警告意味的强建议 | `You had better leave now.` |

`had better` 虽然有 `had`，通常说的是现在或将来；后面直接接动词原形：`You had better go.` 否定是 `You had better not go.`

> A: I have an early flight tomorrow.
>
> B: You should pack tonight. You had better set two alarms too.
