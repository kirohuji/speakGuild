# 必须做、不必做和绝对不能做

`must` 常突出说话者的强烈要求或正式规则；`have to` 常突出外部情况造成的义务；`need to` 说明完成目标所需的行动。

> You must show your ID.（明确要求）
>
> I have to catch the last train.（外部情况）
>
> We need to charge the battery.（现实需要）

最重要的否定对比是：

- `mustn't` = 禁止、绝对不能。
- `don't have to` / `don't need to` = 不必、没有必要。

`You mustn't pay.` 是不允许付款；`You don't have to pay.` 是可以付但没有必要。两者不能混用。

## 情境练习

想象你在介绍一间办公室：说一条必须遵守的规定、一条禁止事项，以及一件访客不必做的事。
