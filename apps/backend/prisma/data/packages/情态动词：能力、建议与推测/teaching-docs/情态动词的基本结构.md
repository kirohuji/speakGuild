# 情态动词后面为什么不加 to？

`can`、`could`、`may`、`might`、`must`、`should`、`will`、`would` 等情态动词帮助表达能力、态度和判断。它们后面直接接动词原形。

| 句型 | 结构 | 例子 |
| --- | --- | --- |
| 肯定 | 主语 + 情态动词 + 动词原形 | `She can drive.` |
| 否定 | 主语 + 情态动词 + not + 动词原形 | `She cannot drive.` |
| 疑问 | 情态动词 + 主语 + 动词原形 | `Can she drive?` |

情态动词本身不随主语改变：说 `He can swim.`，不能说 `He cans swim.`。后面的动词也不用第三人称单数：说 `She should go.`，不能说 `She should goes.`。

`have to`、`need to`、`ought to` 和 `be able to` 含有 `to`，结构也会随时态或主语变化，本包会把它们作为相关表达一并比较。

## 轮到你开口

选择 `can`、`should`、`must` 各造一个肯定句，再把其中一句改成否定句和疑问句。
