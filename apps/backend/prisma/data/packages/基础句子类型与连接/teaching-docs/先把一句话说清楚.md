# 把一句话摆顺

英语普通句最稳的顺序是：谁/什么 → 做什么/是什么 → 对谁或什么 → 时间地点。

`I sent the message this morning.` 先有 `I`，再有 `sent`，最后补 `the message` 和时间。`Emma is cooking at home.` 也是同样的路径。

不要把中文的信息顺序逐个搬过去。先完成一个核心句，再补地点、时间或原因。

1. `My friend works in a library.`
2. `We watched a film after dinner.`
3. `The meeting starts at nine.`

轮到你：用“谁 + 动作 + 对象 + 时间”说今天做过的一件事。
