## 单包边界

| 包内阶段 | 难度 | 阅读场景 |
| --- | --- | --- |
| 一屏生活信息 | L1 | 聊天、邀请、招牌、菜单、车次、天气 |
| 变化与行动要求 | L1–L2 | 课程通知、预约、快递、邮件、操作提示、方案比较 |

共 12 个主题；后半阶段不是单纯增加词数，而是要求整合变化、限制和下一步动作。

## 课程定位

这套课使用一屏内可以读完的真实短文本。学习者不是读完做题就结束，而是必须根据读到的信息说一句回应、提出一个问题或完成一次决定。

## 12 个场景与明确学习内容

| 阅读场景 | 要读懂什么 | 最终口语输出 |
| --- | --- | --- |
| 聊天消息 | 谁、什么事、希望何时回复 | 录一条合适回复 |
| 活动邀请 | 时间、地点、需要准备什么 | 接受或拒绝并说明原因 |
| 店铺招牌 | 营业时间、楼层、限制 | 告诉同伴何时去 |
| 菜单 | 品类、价格、配料、选项 | 完成点单并说明选择 |
| 车次信息 | 方向、站台、出发和到达时间 | 向工作人员确认路线 |
| 天气提示 | 时间、天气变化、建议 | 告诉朋友怎样调整计划 |
| 课程通知 | 教室、作业、截止时间、变化 | 向同学复述新安排 |
| 预约确认 | 人名、项目、时间、修改方式 | 口头确认或提出改期 |
| 快递信息 | 当前状态、地点、下一步 | 说明怎样取件或处理异常 |
| 简短邮件 | 发件人目的、请求和回复期限 | 用一句话概括并口头回应 |
| 操作提示 | 步骤顺序和警告 | 口头指导另一个人操作 |
| 两个选项 | 价格、时间、地点等差异 | 选择一个并说出依据 |

## 每课训练链

1. 先看现实任务，不先逐词翻译。
2. 在 30–90 秒内找到人物、时间、地点、动作或限制。
3. 回答 1–3 个基础理解问题并指出证据。
4. 根据材料完成一次选择、提问或口头回应。
5. 隐藏原文后，用自己的话说出两条关键信息。

## 材料与语言范围

- L1 为 15–60 词，L2 为 40–120 词。
- 每篇最多引入 3–5 个对任务必要的新词。
- 优先学习日期、时间、价格、地点、否定、变更和行动要求等高价值信息。
- 题目只检查完成任务所需的理解，不用生僻常识制造难度。

## 掌握标准

学习者能在短文本中找到完成任务所需的信息，并用一句到四句英语作出与材料一致的口头回应。只会选对答案但不能说明下一步，不算完成整个主题。
