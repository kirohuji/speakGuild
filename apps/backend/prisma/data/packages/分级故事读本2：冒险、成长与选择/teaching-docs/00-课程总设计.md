## 故事概念

三位年轻人在一次海边旅行中发现一本旧笔记，跟随其中的线索寻找一座已经关闭的灯塔。真正的主线不是宝藏，而是合作、误解、做选择和承担结果。

## 章节框架

1. 火车上的旧笔记
2. 地图上没有的路
3. 海边小店的老人
4. 一条错误的线索
5. 团队第一次争执
6. 暴雨前的决定
7. 灯塔里的照片
8. 谁写下了笔记
9. 回城之前的选择
10. 给下一位读者的留言

## 明确学习内容

人物目标、阻碍、线索、事件因果、感受变化和简单推断；复习过去时，学习 `realize / decide / wonder / instead / although / as soon as` 等叙事表达。每章最多 8 个必要新词。

## 阅读与输出

每章完成主线理解、一个有证据的推断和一次预测；每两章做 1–2 分钟口头复盘。最终输出为完整故事复述和“我会怎样选择”的角色回答。

本包使用 Markdown 分章阅读；如果以后制作完整 EPUB 版本，再迁入 `novel` 模式，不同时维护两套正文。
