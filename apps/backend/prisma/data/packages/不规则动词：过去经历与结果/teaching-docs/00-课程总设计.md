## 包定位

这是一个完整的专项包，不再按动词表机械拆册。重点不是背三列表，而是把高频不规则动词用于过去经历、完成结果和连续叙述。

## 学习目标

- 掌握约 60 个口语和日常写作中最高频的不规则动词。
- 能在“昨天做了什么、曾经有过什么经历、事情已经产生什么结果”等场景中正确输出。
- 能识别常见过去式与过去分词，并在短对话、语音复述和微写作中主动使用。

## 练习闭环

每个主题按“辨认词形 → 选择语境 → 补全句子 → 跟读替换 → 口头回答 → 复述或微写作”推进。每次只引入少量新词，但持续混入旧词，避免只会背表不会使用。
