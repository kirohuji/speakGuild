# 拥有与创造

## 用这个话题开口

用制作、维持、变化和结果组织高频核心动词。

先在情境中理解动作，再分别练习“要做 / 已发生 / 到现在的结果”。

## 怎么看三种形式

- **原形**：常见于 can、should、want to 等结构，也用于 I / we / you / they 的一般现在时。
- **过去式**：说已经结束、时间明确的动作。
- **过去分词**：常和 have / has 连用，表达经历或现在仍相关的结果。

## 逐个动词练习

### have — had — had

**原形：用在计划、能力或建议里**

> I can have breakfast.

**过去式：讲一件已经发生的事**

> Yesterday, I had breakfast.

**过去分词：和 have / has 一起说经历或结果**

> I have had breakfast.

这里的 **have** 表示“有”。

## 开口任务

介绍一件作品或任务：开始做什么、做了什么、现在完成到哪里。

先说短句，再把两个动词连成自己的小故事。
