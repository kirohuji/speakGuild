# 运动与比赛

## 用这个话题开口

用比赛中的连续动作记住运动类不规则动词。

先在情境中理解动作，再分别练习“要做 / 已发生 / 到现在的结果”。

## 怎么看三种形式

- **原形**：常见于 can、should、want to 等结构，也用于 I / we / you / they 的一般现在时。
- **过去式**：说已经结束、时间明确的动作。
- **过去分词**：常和 have / has 连用，表达经历或现在仍相关的结果。

## 逐个动词练习

### run — ran — run

**原形：用在计划、能力或建议里**

> I can run every morning.

**过去式：讲一件已经发生的事**

> Yesterday, I ran every morning.

**过去分词：和 have / has 一起说经历或结果**

> I have run every morning.

这里的 **run** 表示“跑”。

## 开口任务

像解说员一样讲一次比赛或运动：按动作顺序说三句。

先说短句，再把两个动词连成自己的小故事。
