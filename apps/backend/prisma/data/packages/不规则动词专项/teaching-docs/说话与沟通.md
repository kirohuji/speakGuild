# 说话与沟通

## 用这个话题开口

用“说什么、对谁说、怎样回应”组织沟通类不规则动词。

先在情境中理解动作，再分别练习“要做 / 已发生 / 到现在的结果”。

## 怎么看三种形式

- **原形**：常见于 can、should、want to 等结构，也用于 I / we / you / they 的一般现在时。
- **过去式**：说已经结束、时间明确的动作。
- **过去分词**：常和 have / has 连用，表达经历或现在仍相关的结果。

## 逐个动词练习

### say — said — said

**原形：用在计划、能力或建议里**

> I can say hello.

**过去式：讲一件已经发生的事**

> Yesterday, I said hello.

**过去分词：和 have / has 一起说经历或结果**

> I have said hello.

这里的 **say** 表示“说”。

## 开口任务

模拟一次消息沟通：说了什么、对方怎么回应、现在已经完成什么。

先说短句，再把两个动词连成自己的小故事。
