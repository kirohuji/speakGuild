# 身体与意外

## 用这个话题开口

用意外发生、身体反应和后果的顺序掌握复杂变化。

先在情境中理解动作，再分别练习“要做 / 已发生 / 到现在的结果”。

## 怎么看三种形式

- **原形**：常见于 can、should、want to 等结构，也用于 I / we / you / they 的一般现在时。
- **过去式**：说已经结束、时间明确的动作。
- **过去分词**：常和 have / has 连用，表达经历或现在仍相关的结果。

## 逐个动词练习

### hurt — hurt — hurt

**原形：用在计划、能力或建议里**

> I can hurt my knee.

**过去式：讲一件已经发生的事**

> Yesterday, I hurt my knee.

**过去分词：和 have / has 一起说经历或结果**

> I have hurt my knee.

这里的 **hurt** 表示“受伤”。

## 开口任务

按“发生什么、当时怎样、现在结果”描述一个小意外。

先说短句，再把两个动词连成自己的小故事。
