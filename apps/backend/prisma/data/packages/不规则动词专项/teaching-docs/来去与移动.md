# 来去与移动

## 用这个话题开口

用路线、方向和变化理解移动类不规则动词。

先在情境中理解动作，再分别练习“要做 / 已发生 / 到现在的结果”。

## 怎么看三种形式

- **原形**：常见于 can、should、want to 等结构，也用于 I / we / you / they 的一般现在时。
- **过去式**：说已经结束、时间明确的动作。
- **过去分词**：常和 have / has 连用，表达经历或现在仍相关的结果。

## 逐个动词练习

### go — went — gone

**原形：用在计划、能力或建议里**

> We can go to the beach.

**过去式：讲一件已经发生的事**

> Yesterday, We went to the beach.

**过去分词：和 have / has 一起说经历或结果**

> We have gone to the beach.

这里的 **go** 表示“去”。
