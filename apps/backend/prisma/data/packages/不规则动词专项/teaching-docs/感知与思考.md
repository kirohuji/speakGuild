# 感知与思考

## 用这个话题开口

把看见、理解、学习和发现连接为完整的思考过程。

先在情境中理解动作，再分别练习“要做 / 已发生 / 到现在的结果”。

## 怎么看三种形式

- **原形**：常见于 can、should、want to 等结构，也用于 I / we / you / they 的一般现在时。
- **过去式**：说已经结束、时间明确的动作。
- **过去分词**：常和 have / has 连用，表达经历或现在仍相关的结果。

## 逐个动词练习

### see — saw — seen

**原形：用在计划、能力或建议里**

> I can see the message.

**过去式：讲一件已经发生的事**

> Yesterday, I saw the message.

**过去分词：和 have / has 一起说经历或结果**

> I have seen the message.

这里的 **see** 表示“看见”。

## 开口任务

说一件最近发现的事：看见或听见什么、当时怎么想、现在明白什么。

先说短句，再把两个动词连成自己的小故事。
