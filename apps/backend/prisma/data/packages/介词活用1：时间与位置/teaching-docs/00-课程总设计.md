## 主题与场景

日程里的 `at / on / in`、房间与建筑位置、上下与附近、两者之间、`to / from / into / out of` 位置变化、`across / through / along / past` 路径、地图和日历综合任务。

每个用法先建立空间或时间图像，再进入找物品、约时间、说明集合地点和介绍房间等口语任务。

## 掌握标准

学习者能说清“什么时候、在哪里”，在日程和简单地图任务中稳定使用核心介词。

## 数据迁移

迁入旧介词包的时间、位置、方位、移动和路线材料；方式和抽象搭配留给后卷。
