# Course ⑥ · 信息理解、核实与转述（L3~L4）

> 从“听懂句子”升级为提取重点、判断来源、区分事实和观点，并向别人准确转述。

## 学习包概览

| 维度 | 设计 |
|:-----|:-----|
| CEFR | B1+ |
| 前置要求 | Course ①—⑤ |
| 核心目标 | 概括信息、核实不确定内容，并根据听者需要重新组织 |
| 结课任务 | 阅读或听取一份短材料，完成摘要、核实和口头转述 |

## 场景与 Topics

| 场景 | Topics | 交际成果 |
|:-----|:-------|:---------|
| 抓取重点 | 01 识别主题；02 提取关键信息；03 区分主次；04 一句话概括 | 不逐句翻译 |
| 事实与观点 | 05 识别事实；06 识别评价；07 识别推测；08 说明证据 | 判断信息性质 |
| 来源核实 | 09 询问来源；10 检查时间背景；11 对比两个说法；12 保留判断 | 降低误传 |
| 准确转述 | 13 转述原话；14 概括他人观点；15 调整细节量；16 说明不确定性 | 面向听者表达 |
| 媒体讨论 | 17 概括短报道；18 解释影响；19 回应不同解读；20 总结可信部分 | 完成信息讨论 |

## 逐 Topic 完整教学设计

> 下列内容是生成 CSV、Warmup 与 Ink 的权威 Topic 契约。Vocabulary、Chunk、Pattern 分开登记；每个 Topic 均复用：Course 1—5 的观点、叙事、生活事务和职场转述。

### Topic 01 · 识别主题

- **教学说明**：在“a transport notice”情境中学习识别主题，必须处理信息缺口、限制或追问。
- **核心词（Vocabulary）**：`source`, `claim`, `fact`, `opinion`。
- **扩展词（Extension）**：`apparently`, `misleading`。
- **核心句块（Chunks）**：`The main point is that the schedule has changed.`；`This is a reported claim, not a confirmed fact.`；`Both reports agree on the main change.`；`As far as we know, no final decision has been made.`。
- **句型（Patterns）**：`The main point is that ___.`；`This is a claim rather than ___.`。
- **完成标准**：能在陌生变体中完成 12—16 轮互动，使用至少 3 个核心句块和 1 个主句型，并形成结论、决定或下一步。
- **口语输出**：围绕“a transport notice”完成 3—5 分钟未准备任务，并回答至少 2 个追问。
- **微写作**：写 180—250 词信息摘要或核实说明；内容必须重新组织，不得抄写口语稿。
- **反馈与重做**：按任务完成、结构、词汇、语法及发音/拼写反馈；完成第二次重说和重写，7 天后使用新材料或新限制复测。
- **跨包复习**：Course 1—5 的观点、叙事、生活事务和职场转述；本 Topic 新表达须在本包后续至少两个 Topic 再次主动调用。
- **具体对话**：
  1. Mia: What is the main point of a transport notice?
  2. Lin: The main point is that the schedule has changed.
  3. Mia: Where did that information come from?
  4. Lin: According to the notice, the service starts later.
  5. Mia: Is every detail confirmed?
  6. Lin: This is a reported claim, not a confirmed fact.
  7. Mia: Does the source explain its evidence?
  8. Lin: The source does not explain how the result was measured.
  9. Mia: How does it compare with the other source?
  10. Lin: Both reports agree on the main change.
  11. Mia: What can we safely tell the team?
  12. Lin: As far as we know, no final decision has been made.

  6. Lin: This is a reported claim, not a confirmed fact.
  7. Mia: Does the source explain its evidence?
  8. Lin: The source does not explain how the result was measured.
  9. Mia: How does it compare with the other source?
  10. Lin: Both reports agree on the main change.
  11. Mia: What can we safely tell the team?
  12. Lin: As far as we know, no final decision has been made.

## 核心语言系统

- 概括：`The main point is that...`
- 来源：`According to...` / `The report states that...`
- 转述：`She explained that...` / `He was reported to have...`
- 限定：`It appears that...` / `As far as we know...`
- 对比：`While both sources agree on..., they differ on...`

每章围绕一份模拟通知、访谈、报道或说明材料展开；第 1 课理解，第 2 课核实并转述。

## 设计边界

- 使用原创或模拟材料，避免直接复制新闻和受版权保护文本。
- 训练信息素养，但不将课程变成事实核查专业课。
- 学习者必须显式区分“原信息”和“自己的判断”。
