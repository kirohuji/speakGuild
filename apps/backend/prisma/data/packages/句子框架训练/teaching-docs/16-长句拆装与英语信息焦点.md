# 16 长句拆装与英语信息焦点

> 所属课程：基础句子类型与连接：英语句法强化训练  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

把一段中文信息重组成英语可理解的主干和分层修饰。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 先说主干，再按逻辑添加对象、状语和从句。
2. 一个句子只保留一个清晰的信息中心。
3. 旧信息靠前，新信息和重点通常靠后。
4. 读长句时先圈谓语，再判断连接词和从句边界。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `The manager sent us the revised plan yesterday.` | 经理昨天把修改后的计划发给了我们。 | 先主干后时间 |
| `The plan that she sent needs more work.` | 她发来的计划还需要完善。 | 定语从句嵌入名词 |
| `Although we were tired, we finished the task.` | 虽然很累，我们仍完成了任务。 | 让步背景前置 |
| `We finished early because everyone helped.` | 因为大家都帮忙，我们提前完成了。 | 主句先给结果 |
| `What matters is whether the plan will work.` | 重要的是计划是否可行。 | 两个名词性从句 |
| `The issue has been fixed, so we can continue.` | 问题已修复，因此我们可以继续。 | 被动结果 + 推进 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `The manager sent us the revised plan yesterday.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `The plan that she sent needs more work.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `Although we were tired, we finished the task.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `We finished early because everyone helped.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：把一个包含 8 条信息的工作事件先拆成短句，再组合成 4 句自然英语。
