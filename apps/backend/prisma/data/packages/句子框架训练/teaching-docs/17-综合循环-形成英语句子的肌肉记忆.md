# 17 综合循环：形成英语句子的肌肉记忆

> 所属课程：基础句子类型与连接：英语句法强化训练  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

跨餐厅、出行、工作、社交四个场景完成即时描述与追问。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 先在 3 秒内选主干，再决定时态、语态和从句。
2. 每个观点至少用两种句型表达。
3. 发现错误要整句重说，不只修补一个词。
4. 速度来自高质量重复和间隔提取。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `I ordered the dish because it looked fresh.` | 我点这道菜是因为它看起来新鲜。 | 过去时 + 原因从句 |
| `The flight has been delayed, so I may arrive late.` | 航班延误了，所以我可能晚到。 | 完成时 + 情态 |
| `Could you tell me where the meeting is?` | 你能告诉我会议在哪里吗？ | 情态 + 间接问句 |
| `The file that you sent cannot be opened.` | 你发的文件打不开。 | 定语从句 + 被动 |
| `If I finish early, I will call you.` | 如果我提前完成，我会打给你。 | 真实条件句 |
| `Although I was nervous, I explained the problem clearly.` | 虽然紧张，我仍把问题解释清楚了。 | 让步 + 方式状语 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `I ordered the dish because it looked fresh.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `The flight has been delayed, so I may arrive late.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `Could you tell me where the meeting is?` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `The file that you sent cannot be opened.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：随机抽取四个场景，每个说 60 秒并接受两个追问，不准备中文稿。
