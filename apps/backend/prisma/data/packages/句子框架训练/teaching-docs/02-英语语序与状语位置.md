# 02 英语语序与状语位置

> 所属课程：基础句子类型与连接：英语句法强化训练  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

说明谁在何时、何地、以何种方式做了什么。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 普通陈述句的主干通常是主语 + 谓语 + 宾语。
2. 方式常靠近动作，地点通常在时间前。
3. 频率副词常在实义动词前、be 后。
4. 长状语可前置，但不要割裂动词和宾语。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `I finished the report at home last night.` | 我昨晚在家完成了报告。 | 主干后加地点和时间 |
| `She carefully checked the address.` | 她仔细核对了地址。 | 方式副词在动词前 |
| `He is usually on time.` | 他通常准时。 | 频率副词在 be 后 |
| `We often eat outside.` | 我们经常在外面吃饭。 | 频率副词在实义动词前 |
| `After dinner, we went for a walk.` | 晚饭后，我们去散步了。 | 长时间状语前置 |
| `She speaks English very clearly.` | 她英语说得很清楚。 | 宾语不被状语拆开 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `I finished the report at home last night.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `She carefully checked the address.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `He is usually on time.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `We often eat outside.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：用同一件事练 6 种状语位置，听出哪一种最自然。
