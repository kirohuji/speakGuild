# 08 被动句：把受影响者放在前面

> 所属课程：基础句子类型与连接：英语句法强化训练  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

说明包裹、订单、房间和设备分别被如何处理。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 被动核心是 be + 过去分词，时态落在 be 上。
2. 受事重要、施事未知或流程说明时适合被动。
3. by 只在施事值得说明时出现。
4. 不能把不及物义项机械变成被动。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `The order was canceled.` | 订单被取消了。 | 一般过去时被动 |
| `The room is cleaned every day.` | 房间每天打扫。 | 一般现在时被动 |
| `The problem has been fixed.` | 问题已经修好了。 | 现在完成时被动 |
| `Your package will be delivered tomorrow.` | 你的包裹明天送达。 | 将来被动 |
| `The road is being repaired.` | 道路正在维修。 | 进行时被动 |
| `The accident happened at noon.` | 事故中午发生。 | happen 不用被动 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `The order was canceled.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `The room is cleaned every day.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `The problem has been fixed.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `Your package will be delivered tomorrow.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：以客服身份用被动句更新订单处理进度，再用主动句说明你将做什么。
