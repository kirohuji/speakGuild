# 13 状语从句：时间、原因、条件与让步

> 所属课程：基础句子类型与连接：英语句法强化训练  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

解释迟到原因、下一步条件、时间顺序和克服的困难。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 状语从句说明主句发生的背景和逻辑关系。
2. because/if/when/although 的语义不能互换。
3. 时间与真实条件从句谈未来通常用现在时。
4. 从句前置时用逗号帮助听者抓结构。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `I stayed home because I was sick.` | 我因为生病待在家。 | 原因 |
| `If it rains, we will stay inside.` | 如果下雨，我们就待在室内。 | 真实条件 |
| `Call me when you arrive.` | 你到了给我打电话。 | 未来时间从句用现在时 |
| `Although it was late, we continued.` | 虽然很晚，我们仍继续。 | 让步 |
| `I left early so that I could catch the train.` | 我早走以便赶上火车。 | 目的 |
| `It was so noisy that I could not sleep.` | 太吵了，我睡不着。 | 结果 |

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。

- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：讲一次行程变化，完整表达原因、条件、时间、让步和结果。
