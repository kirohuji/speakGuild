# 04 一般过去时：把事件放进时间线

> 所属课程：基础句子类型与连接：英语句法强化训练  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

复述昨天发生的事、先后顺序和已结束状态。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 明确结束的过去时间通常用一般过去时。
2. 规则和不规则形式都要绑定场景反复提取。
3. did 构成疑问否定后主要动词用原形。
4. 用 then、after、before 组织事件链。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `I missed the bus yesterday.` | 我昨天错过了公交。 | 已结束事件 |
| `She left before noon.` | 她中午前离开了。 | 不规则过去式 |
| `We did not see the sign.` | 我们没看见标志。 | did not + 原形 |
| `Did you call the hotel?` | 你给酒店打电话了吗？ | Did + 主语 + 原形 |
| `I arrived, checked in, and called my family.` | 我到达、入住并给家人打了电话。 | 过去事件链 |
| `The room was cold when I entered.` | 我进去时房间很冷。 | 过去状态与事件 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `I missed the bus yesterday.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `She left before noon.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `We did not see the sign.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `Did you call the hotel?` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：用 8 个过去式动词讲一次“计划出错但解决了”的经历。
