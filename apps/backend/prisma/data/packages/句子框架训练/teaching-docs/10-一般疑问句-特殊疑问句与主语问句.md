# 10 一般疑问句、特殊疑问句与主语问句

> 所属课程：基础句子类型与连接：英语句法强化训练  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

在失物招领处问清物品、地点、时间、人物和原因。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 把已有助动词或 be 移到主语前。
2. 一般现在/过去没有助动词时借 do/does/did。
3. 疑问词作宾语时倒装；作主语时不加 do。
4. 问题要精准索取缺失信息。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `Did you leave it here?` | 你把它落在这里了吗？ | 一般过去时疑问 |
| `Where did you last see it?` | 你最后在哪里见到它？ | wh + did + 主语 + 原形 |
| `Who found the bag?` | 谁找到了包？ | who 作主语 |
| `Who did you call?` | 你给谁打了电话？ | who 作宾语 |
| `Is there a name inside?` | 里面有名字吗？ | be 提前 |
| `How long have you had it?` | 你拥有它多久了？ | 完成时疑问 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `Did you leave it here?` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `Where did you last see it?` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `Who found the bag?` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `Who did you call?` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：完成一轮失物招领问答，提出不少于 8 个不重复的问题。
