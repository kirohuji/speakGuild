# 07 完成体：过去与现在怎样相连

> 所属课程：基础句子类型与连接：英语句法强化训练  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

汇报已经完成、尚未完成、持续多久和过去某时之前的事情。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 现在完成时关注过去事件与现在的联系。
2. 明确结束时间通常用一般过去时，不与 yesterday 混用。
3. for/since 表持续；already/yet/ever 表经历或完成状态。
4. 过去完成时用于明确另一个过去参照点之前。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `I have finished the report.` | 我已经完成报告了。 | 现在可用的结果 |
| `I finished it yesterday.` | 我昨天完成了。 | 明确过去时间 |
| `She has lived here for five years.` | 她在这里住了五年。 | 持续到现在 |
| `Have you ever tried this dish?` | 你吃过这道菜吗？ | 经历 |
| `The train had left before we arrived.` | 我们到之前火车已经开了。 | 过去的过去 |
| `I have not received it yet.` | 我还没收到。 | 截至现在尚未 |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `I have finished the report.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `I finished it yesterday.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `She has lived here for five years.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `Have you ever tried this dish?` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：做工作进度汇报，区分昨天完成、目前结果、持续任务和未完成项。
