# 01 五种基本句型：先立主干

> 所属课程：基础句子类型与连接：英语句法强化训练  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

用最短完整句说明人、事、状态和给予关系。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. 英语句子先建立主语和限定谓语。
2. SV、SVC、SVO、SVOO、SVOC 是扩展长句的骨架。
3. 补语描述主语或宾语，不能和宾语混为一谈。
4. 长句先缩回主干，再逐层加信息。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `The baby smiled.` | 婴儿笑了。 | SV |
| `The room is quiet.` | 房间很安静。 | SVC |
| `Maya opened the window.` | 玛雅打开了窗户。 | SVO |
| `He sent me a link.` | 他给我发了一个链接。 | SVOO |
| `The news made us nervous.` | 这个消息让我们紧张。 | SVOC |
| `We found the door unlocked.` | 我们发现门没锁。 | SVOC |

## 第一轮：跟读与替换（每句至少 3 次）

1. 以 `The baby smiled.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `The room is quiet.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `Maya opened the window.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `He sent me a link.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：看一张房间图片，分别用五种基本句型描述。
