# 15 非谓语：压缩目的、原因和附加动作

> 所属课程：基础句子类型与连接：英语句法强化训练  ·  建议训练：35–50 分钟  ·  原则：先说出口，再看答案

## 场景任务

说明来这里的目的、做过的活动、正在发生的伴随动作和受影响的物品。

完成本课后，你要能在不先写中文草稿的情况下，连续说出 6–10 句相关英语。

## 核心规则

1. to do 常表达目的或尚未实现的动作。
2. doing 可作名词性成分或主动伴随信息。
3. done 常表达被动或完成状态。
4. 非谓语不能代替句子的限定谓语。

## 对比例句

| 英语 | 中文 | 为什么这样说 |
| --- | --- | --- |
| `I came here to ask for help.` | 我来这里寻求帮助。 | 不定式表目的 |
| `Learning a language takes time.` | 学语言需要时间。 | 动名词作主语 |
| `She enjoys meeting new people.` | 她喜欢结识新朋友。 | enjoy + doing |
| `Walking home, I called my friend.` | 走回家时，我给朋友打了电话。 | 现在分词伴随 |
| `The package delivered today is mine.` | 今天送到的包裹是我的。 | 过去分词后置修饰 |
| `I have a report to finish.` | 我有一份报告要完成。 | 不定式修饰待做事项 |

1. 以 `I came here to ask for help.` 为骨架，替换人物、时间和对象，连续说 3 句。
2. 以 `Learning a language takes time.` 为骨架，替换人物、时间和对象，连续说 3 句。
3. 以 `She enjoys meeting new people.` 为骨架，替换人物、时间和对象，连续说 3 句。
4. 以 `Walking home, I called my friend.` 为骨架，替换人物、时间和对象，连续说 3 句。

要求：第一遍慢读，第二遍正常语速，第三遍不看原句；每次只改一个信息，保持句子骨架稳定。

## 第三轮：变形操练

1. 把例句 1 改成否定句，再改成一般疑问句。
2. 把例句 2 的时间改到昨天或上周，并调整动词形式。
3. 给例句 3 增加一个地点状语和一个原因。
4. 把例句 4 换一个主语，注意主谓一致、代词和语序。
5. 将例句 5 与例句 6 用合适的连接词合成一句。
6. 不照抄原句，用同一个结构说你自己的真实情况。

## 第四轮：场景输出

- **20 秒热身**：只说 3 个短句，先保证主干正确。
- **45 秒复述**：加入时间、地点、对象和原因。
- **60 秒互动**：自己提出 2 个问题并回答，至少使用本课 3 个目标结构。
- **反向挑战**：同一内容换一种句型再说一次，不逐字翻译中文。

场景提示：用非谓语把 8 个短句压缩成 4 个自然句，再口头还原完整逻辑。
