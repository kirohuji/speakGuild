## 内容结构

1. 从一座城堡看中世纪生活
2. 一次改变王位的事件
3. 莎士比亚时代的剧院一晚
4. 伦敦大火中的普通人
5. 工业革命和一座工厂城
6. 铁路怎样改变旅行
7. 博物馆里的古怪收藏
8. 英式下午茶从哪里来
9. 足球文化与社区
10. 英国不同地区的语言和身份
11. 一位普通人的战时日记
12. 传统怎样进入今天的生活

## 内容原则

用具体人物、物品、地点和一天的经历承载历史，不堆年代和君主名单。制作时为每篇记录来源、史实核验日期和图片授权；区分英国、英格兰、苏格兰、威尔士和北爱尔兰，避免概念混用。

## 明确学习内容与输出

时间线、变化的原因与影响、过去与今天的比较，以及 `used to / was built / changed / led to` 等表达。每篇用时间卡复述一个变化，再回答“最想亲眼看到哪个场景，为什么”。
