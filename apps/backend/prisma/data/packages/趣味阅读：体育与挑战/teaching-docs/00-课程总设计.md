## 主题方向

第一次参加比赛、落后时怎样调整、团队角色、裁判的一天、训练习惯、受伤后的恢复、冷门项目、残障运动、女性体育先驱、体育与社区、一次有争议的决定、胜负之外学到了什么。

具体运动覆盖个人与团队、常见与较少被关注的项目。历史人物和赛事必须核验来源；不依赖即时比分维持文章价值。

## 明确学习内容

比赛顺序、目标与阻碍、比较、训练过程、人物选择和结果；学习 `train / compete / recover / improve / team up / give up` 等高频表达。

## 读后输出

每篇完成 60 秒赛事或人物复述，再回答一个有证据的选择题：“哪个决定最重要，为什么？”
