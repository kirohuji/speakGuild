## 主题

`may / might / could` 可能性、`must / have to / need to` 义务、建议、情态否定、现在与过去推测、正式提议、过去遗憾、礼貌距离和综合立场。

## 输出任务

讨论天气与安排、解释规则、给健康或旅行建议、区分“不必”和“禁止”、说明自己对当前情况的判断。

## 掌握标准

学习者能表达不同强度的可能、义务与建议，根据线索推测现在或过去，并避免语气过强。后半 L3 话题作为进阶章节，不再另拆第三册。
