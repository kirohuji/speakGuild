# 把相对位置说清楚

`above` 和 `below` 只说明上下关系，不一定接触。`between` 强调对象彼此可区分，`among` 强调处在一个群体之中。

| 表达 | 重点 | 例句 |
| --- | --- | --- |
| `above the desk` | 在上方 | `The lamp is above the desk.` |
| `below the window` | 在下方 | `The shelf is below the window.` |
| `between A and B` | 位于明确对象之间 | `The café is between two shops.` |
| `among the papers` | 混在群体中 | `The note is among the papers.` |

`between` 不只限于两个对象；只要对象是逐个明确区分的，也可以使用它。初学阶段先掌握“两者之间”与“群体之中”的核心对比。

## 口语任务

想象一张书桌，说明灯、书、便签和杯子的相对位置，至少使用三个本课介词。
