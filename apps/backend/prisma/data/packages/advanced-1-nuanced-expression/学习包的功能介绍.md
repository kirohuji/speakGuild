# Advanced ① · 精确立场与细腻表达（L4）

> 从明确表达观点，升级为精确控制确定程度、态度、强调和保留。

## 学习包概览

| 维度 | 设计 |
|:-----|:-----|
| CEFR | B2 |
| 前置要求 | 完成 Course 1—10 |
| 核心目标 | 根据证据、关系和场合调整表达强度 |
| 结课任务 | 围绕一个复杂选择完成立场陈述、追问、修正和总结 |

## 场景与 Topics

| 场景 | Topics | 交际成果 |
|:-----|:-------|:---------|
| 确定程度 | 01 明确判断；02 合理推测；03 保留意见；04 暂缓结论 | 不把所有观点说得同样绝对 |
| 态度与评价 | 05 赞同但有限定；06 谨慎批评；07 表达担忧；08 强调价值 | 精确传达态度 |
| 聚焦与强调 | 09 突出关键点；10 对比次要因素；11 纠正常见解读；12 重构问题 | 控制听者注意力 |
| 语域切换 | 13 朋友交流；14 专业讨论；15 正式回应；16 简洁书面转述 | 根据场合换表达 |
| 立场调整 | 17 承认新证据；18 缩小主张；19 部分改变看法；20 总结当前立场 | 展示思考过程 |

## 逐 Topic 完整教学设计

> 下列契约用于生成 Advanced CSV、Warmup 与 Ink。每个 Topic 都要求精确语域、异议处理、反馈后修订，并复用：Course 1、6、7、9 的观点、信息、协商和展示。

### Topic 01 · 明确判断

- **教学说明**：在“a firm recommendation based on clear evidence”中学习明确判断；必须处理限定、异议、隐含假设或关系风险。
- **核心词（Vocabulary）**：`stance`, `certainty`, `qualification`, `emphasis`。
- **扩展词（Extension）**：`arguably`, `comparatively`。
- **核心句块（Chunks）**：`I would argue that the evidence supports a limited trial.`；`To some extent, that interpretation is reasonable.`；`The key distinction is between access and actual use.`；`A more precise way to put it would be this.`。
- **句型（Patterns）**：`I would argue that ___.`；`To some extent, ___.`。
- **完成标准**：完成 16—24 轮复杂互动，灵活改写至少一次，回应一个有根据的异议，并形成精确结论或修订方案。
- **口语输出**：围绕“a firm recommendation based on clear evidence”完成 4—6 分钟未准备表达，并接受至少 3 个追问。
- **微写作**：写 250—350 词多段文本，控制语域、限定主张并回应一个反例；不得照抄口语稿。
- **反馈与重做**：依据任务、结构、精确度、语域、语法、发音/拼写反馈；完成第二版重说和重写，7—14 天后换立场或受众复测。
- **跨包复习**：Course 1、6、7、9 的观点、信息、协商和展示；本 Topic 新表达须在本包后续至少两个 Topic 再次调用。
- **具体对话**：
  1. Emma: How strongly can you state a position on a firm recommendation based on clear evidence?
  2. Lin: I would argue that the evidence supports a limited trial.
  3. Emma: What makes the case persuasive?
  4. Lin: There is a strong case for changing the current approach.
  5. Emma: Is there any qualification you should add?
  6. Lin: To some extent, that interpretation is reasonable.
  7. Emma: What uncertainty remains?
  8. Lin: That said, the long-term impact remains uncertain.
  9. Emma: Which distinction is most important?
  10. Lin: The key distinction is between access and actual use.
  11. Emma: Has any part of your original claim changed?
  12. Lin: I may have overstated the strength of the evidence.
  13. Emma: What would you change after this discussion?
  14. Lin: I may have overstated the strength of the evidence.
  15. Emma: Please state the revised position clearly.
  16. Lin: My current position is supportive but conditional.
