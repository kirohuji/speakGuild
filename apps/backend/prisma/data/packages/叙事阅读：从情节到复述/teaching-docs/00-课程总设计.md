## 课程定位

这套课训练学习者理解故事中的人物目标、事件顺序、因果、视角和变化，并最终用自己的话复述。它位于短篇阅读与分级小说之间，为持续阅读和剧情任务提供基础。

## 10 个训练主题

1. 识别人物、地点和初始情境
2. 按顺序排列关键事件
3. 区分背景信息和推动情节的动作
4. 找出人物目标与阻碍
5. 从行动和台词推断感受
6. 解释一个决定的原因和后果
7. 追踪代词、称呼和人物关系
8. 理解转折、伏笔和信息揭示
9. 比较两个人物的选择
10. 从事件骨架完成口头或书面复述

## 材料设计

L1 使用 120–250 词单场景故事，L2 使用 250–500 词短篇，L3 使用 500–900 词分段文本。生词不应平均撒在全文中，关键情节处要控制理解负担；目标词应能从上下文推断或不影响主线。

每篇故事先检查事实理解，再进入推断和个人回应。个人回应不能替代文本理解，例如“你喜欢谁”之后必须追问“原文中的什么行动支持你的判断”。

入门故事使用迷路、第一次见面、错过车次、计划改变、帮助朋友等日常情节，明确学习人物称呼、时间顺序、动作动词、`because / so / but` 因果转折以及简单感受表达。每篇必须用事件图片或 4–6 个关键词完成口头复述；开放讨论只是复述之后的扩展。

## 评价标准

- 能否准确重建主要事件及其顺序。
- 能否解释人物行动与结果之间的关系。
- 推断是否有具体文本证据。
- 复述是否保留主线并删去无关细节。
- 是否使用自己的表达，而非连续照抄原句。

## 毕业任务

阅读一篇约 800 词的短篇，制作“人物目标—阻碍—选择—结果”情节图，并完成 2 分钟复述或 150 词摘要。
