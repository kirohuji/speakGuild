# 英语时态活用：12 个核心主题｜课程总设计

## 课程定位

这套课不要求学习者背“十六种时态表”，而是训练说话者怎样观察一件事：把它看成事实、当前过程、已经完成的事件、与现在有关的结果，还是持续到现在的活动。

课程以生活安排、工作进度、经历分享和故事复述为主要场景。状态动词会在需要判断是否使用进行体时出现，但动词的完整分类和搭配归入“常见动词专项”。

## 12 个核心主题

1. **先建立时间线和观察视角**：区分“什么时候发生”和“怎样看待它”。
2. **一般现在时：事实、习惯与固定安排**：介绍作息、职责、常态和时刻表。
3. **现在进行体：眼前过程、临时情况与变化**：描述正在发生和近期暂时发生的事。
4. **一般过去时：已经结束的事件**：讲清昨天发生了什么，以及事件的先后顺序。
5. **过去进行体：过去的背景画面**：说明某个事件发生时，另一件事正在进行。
6. **现在完成体：过去怎样连接现在**：表达结果、经历、变化和“已经/还没有”。
7. **现在完成进行体：活动持续了多久**：突出持续过程，并与现在完成体比较。
8. **过去完成体：回到更早的过去**：在故事和复盘中说明哪件事先发生。
9. **将来表达：计划、安排、预测与临时决定**：比较 will、be going to、现在进行时和一般现在时。
10. **状态动词与进行体**：比较 know、think、have、see、taste、feel 等不同义项。
11. **时间从句与时态配合**：使用 when、before、after、until、as soon as 组织时间关系。
12. **综合输出：讲经历、报进度和说计划**：在连续表达中选择合适的时态与体。

## 训练原则

- 先比较意义，再观察形式。
- 同一场景至少用两种时间视角重新表达。
- 每课包含时间线判断、对比例句、限时提取和连续输出。
- 不把所有结构都翻译成孤立的“过去、现在、将来”。

## 与其他学习包的关系

- 动词是否表示状态或动作，由“常见动词专项”建立基础。
- 情态意义和礼貌距离由“情态动词专项”深入训练。
- 不规则变化作为本课程的短时复习线，不独立占用课程主线。
