# Course ⑦ · 决策、取舍与协商（L4）

> 从简单比较和表达偏好，升级为讨论限制、权衡影响、提出交换条件并形成共同决定。

## 学习包概览

| 维度 | 设计 |
|:-----|:-----|
| CEFR | B1+ |
| 前置要求 | Course ①—⑥ |
| 核心目标 | 比较多项方案，在限制条件下进行礼貌而清晰的协商 |
| 结课任务 | 围绕预算、时间和需求完成一次多人方案协商 |

## 场景与 Topics

| 场景 | Topics | 交际成果 |
|:-----|:-------|:---------|
| 明确目标 | 01 说明需求；02 区分必要与偏好；03 确认限制；04 排列优先级 | 建立决策标准 |
| 比较方案 | 05 优缺点；06 短期长期影响；07 风险收益；08 排除不合适方案 | 形成候选方案 |
| 提出条件 | 09 假设结果；10 设置条件；11 提出交换；12 说明底线 | 清晰表达条件 |
| 协商分歧 | 13 探索对方需求；14 调整提议；15 寻找共同点；16 暂停僵局 | 推动谈判 |
| 形成决定 | 17 检查可行性；18 达成共识；19 确认承诺；20 制定备选方案 | 形成可执行结论 |

## 核心语言系统

- 取舍：`The main advantage is..., whereas...`
- 条件：`Provided that...` / `If we were to..., we could...`
- 交换：`We could agree to... if...`
- 底线：`What we really need is...`
- 决定：`Given these constraints, the best option is...`

## 章节与剧集

5 章 × 2 课，围绕活动策划、共同采购、工作排期等低风险任务；先双人协商，再过渡到多人决策。

## 数据目标

5 Scenes / 20 Topics / 约 85 Chunks / 约 45 Patterns / 140—160 Vocabulary / 10 Episodes / 20 Ink scripts。

## 设计边界

- 不训练高压销售话术或操控性谈判技巧。
- 重点是透明说明需求、限制和交换条件。
- 通过标准必须包括共同决定及责任确认。
