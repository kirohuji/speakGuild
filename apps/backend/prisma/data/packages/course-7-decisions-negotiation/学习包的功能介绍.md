# Course ⑦ · 决策、取舍与协商（L4）

> 从简单比较和表达偏好，升级为讨论限制、权衡影响、提出交换条件并形成共同决定。

## 学习包概览

| 维度 | 设计 |
|:-----|:-----|
| CEFR | B1+ |
| 前置要求 | Course ①—⑥ |
| 核心目标 | 比较多项方案，在限制条件下进行礼貌而清晰的协商 |
| 结课任务 | 围绕预算、时间和需求完成一次多人方案协商 |
### 本包新语法

> Foundation 已封版。以下中级语法通过本包的交际场景首次系统引入。

| 语法点 | 本包中的场景应用 | 核心句式 |
|:-------|:----------------|:---------|
| **第三条件句（虚拟过去）** | 复盘"如果当时…就会…"，协商中评估不同选择 | `If we **had known** earlier, we **would have** chosen differently.` |
| **混合条件句入门** | 过去决定对现在结果的影响 | `If we **had started** last month, we **would be** done now.` |
| **I wish I had...** | 表达后悔、反思决策 | `I **wish I had** raised this concern earlier.` |

> 以上语法在本包的 Chunks 和 Patterns 中体现，并在后续 Course 8—10 中持续复用。

### Topic 01 · 说明需求

- **教学说明**：在“the purpose of a weekend event”情境中学习说明需求，必须处理信息缺口、限制或追问。
- **核心词（Vocabulary）**：`priority`, `requirement`, `preference`, `constraint`。
- **扩展词（Extension）**：`non-negotiable`, `conditional`。
- **核心句块（Chunks）**：`Our main priority is keeping the plan affordable.`；`If we changed the date, we could use the larger room.`；`What matters most to us is a clear deadline.`；`Given these constraints, the second option is best.`。
- **句型（Patterns）**：`Our main priority is ___.`；`If we ___, we could ___.`。
- **完成标准**：能在陌生变体中完成 12—16 轮互动，使用至少 3 个核心句块和 1 个主句型，并形成结论、决定或下一步。
- **口语输出**：围绕“the purpose of a weekend event”完成 3—5 分钟未准备任务，并回答至少 2 个追问。
- **微写作**：写 180—250 词方案比较与协商纪要；内容必须重新组织，不得抄写口语稿。
- **反馈与重做**：按任务完成、结构、词汇、语法及发音/拼写反馈；完成第二次重说和重写，7 天后使用新材料或新限制复测。
- **跨包复习**：Course 1、5、6 的观点、协作和信息核实；本 Topic 新表达须在本包后续至少两个 Topic 再次主动调用。
- **具体对话**：
  1. Ben: We need a decision about the purpose of a weekend event.
  2. Lin: Our main priority is keeping the plan affordable.
  3. Ben: What are the main trade-offs?
  4. Lin: The advantage is speed, whereas the drawback is cost.
  5. Ben: Could a schedule change help?
  6. Lin: If we changed the date, we could use the larger room.
  7. Ben: I could accept that under one condition.
  8. Lin: We could agree to that if transport is included.

  2. Lin: Our main priority is keeping the plan affordable.
  3. Ben: What are the main trade-offs?
  4. Lin: The advantage is speed, whereas the drawback is cost.
  5. Ben: Could a schedule change help?
  6. Lin: If we changed the date, we could use the larger room.
  7. Ben: I could accept that under one condition.
  8. Lin: We could agree to that if transport is included.
  9. Ben: It sounds as if we share one priority.
  10. Lin: There seems to be common ground on the budget.
  11. Ben: Which option should we confirm?
  12. Lin: Given these constraints, the second option is best.

## 核心语言系统

- 取舍：`The main advantage is..., whereas...`
- 条件：`Provided that...` / `If we were to..., we could...`
- 交换：`We could agree to... if...`
- 底线：`What we really need is...`
- 决定：`Given these constraints, the best option is...`
