# 态度、立场与口语惯用语

## 小提示

这一课练态度、立场与口语惯用语。强硬短句先识别，开口慎用。

## 表达、中文意思与使用见解

### 1 · How dare you.

**重点：** 优先开口

**中文意思**

你敢

**使用见解**

按场景选用；注意语气与关系距离。

**例句**

- How dare you.
  你敢

- She said, "How dare you."
  她说：「你敢」

### 4 · Shut up.

**中文意思**

强硬制止；Zip it 同功能，本课不单列。识别即可，开口慎用。

**例句**

- Hey—shut up for a second.
  喂——闭嘴一下。
