# 说明情况、补救与确认

## 小提示

这一课练说明情况、补救与确认。

## 表达、中文意思与使用见解

### 1 · Is the cut still painful?

**重点：** 优先开口

**中文意思**

伤口还在痛吗?

**使用见解**

按场景选用；注意语气与关系距离。

**例句**

- Is the cut still painful? I need to know.
  伤口还在痛吗? 我需要知道。

- Wait—Is the cut still painful?
  等等——伤口还在痛吗?
