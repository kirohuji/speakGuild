# 惊喜、吐槽与情绪接话

## 小提示

这一课练「听到就接」：惊喜、吐槽与情绪接话。

## 表达、中文意思与使用见解

### 1 · For crying out loud!

**重点：** 优先开口

**中文意思**

我的天啊

**使用见解**

惯用语/进阶说法；先听懂，再挑合适场合用。

**例句**

- For crying out loud!
  我的天啊

- She said, "For crying out loud!"
  她说：「我的天啊」
