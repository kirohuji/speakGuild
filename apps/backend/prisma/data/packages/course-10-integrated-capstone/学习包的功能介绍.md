# Course ⑩ · 独立生活综合项目（L4）

> 中级系列终点。不再投放大块新语法，而是在连续项目中整合前 9 包能力。

## 学习包概览

| 维度 | 设计 |
|:-----|:-----|
| CEFR | 稳定 B1+，接近 B2 门槛 |
| 前置要求 | Course ①—⑨ |
| 核心目标 | 面对信息变化、多人立场和真实限制，独立完成连续沟通任务 |
| 结课任务 | 策划并执行一个社区或团队项目，最后完成汇报与复盘 |

## 场景与 Topics

| 场景 | Topics | 交际成果 |
|:-----|:-------|:---------|
| 项目启动 | 01 识别需求；02 访谈相关人；03 定义目标；04 确认成功标准 | 建立真实任务 |
| 信息与方案 | 05 收集信息；06 核实来源；07 设计方案；08 说明理由 | 形成可靠提案 |
| 协作与决策 | 09 分配角色；10 协调分歧；11 作出决定；12 确认行动 | 推动多人协作 |
| 变化与修复 | 13 应对延误；14 处理投诉；15 调整计划；16 向相关人更新 | 适应非预期变化 |
| 展示与复盘 | 17 展示成果；18 回答质疑；19 评估结果；20 总结成长 | 完成项目闭环 |

## 能力整合

| 来源包 | 在 Capstone 中的使用 |
|:-------|:---------------------|
| Course ①—② | 观点、理由、故事和反思 |
| Course ③—④ | 独立办事、关系和语气 |
| Course ⑤—⑥ | 协作、汇报、信息核实和转述 |
| Course ⑦—⑧ | 决策、协商、问题解决和跟进 |
| Course ⑨ | 展示、问答和总结 |

## 章节与剧集

5 章 × 2 课构成一条连续项目线。前一 Episode 的决定必须影响后一 Episode；禁止把 10 个 Episode 写成互不相关的小对话。

## 数据目标

5 Scenes / 20 Topics / 约 80 个高迁移 Chunks / 约 40 Patterns / 100—130 Vocabulary / 10 Episodes / 20 Ink scripts。

## 终结性评价

结课评价由五项组成：

1. 任务是否完成。
2. 表达是否有清晰结构和充分展开。
3. 是否能回应、追问、澄清和修复。
4. 是否能根据关系调整语气。
5. 是否能在信息变化后调整方案。

## 设计边界

- 综合包原则上不新增核心语法系统。
- 新词只服务于项目任务，不追求数量。
- 不以一次完美输出为标准；必须包含反馈后的第二次改进输出。
