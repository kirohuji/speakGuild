# 在药店问诊：描述症状与咨询用药

## 一、如何向药师描述身体不适

在药店咨询时，通常需要说明自己哪里不舒服、出现了哪些症状，以及这些症状对日常生活有什么影响。

英语中常见的表达包括 **I've got ...、I have ...、I've been feeling ...、I've been having trouble with ...**。

### 1. 描述身体不适的常用句型

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **I've got ...** | 日常口语中表示目前有某种症状，英式英语尤其常见。 | **I've got a sore throat and a slight cough.** 我喉咙痛，还有点轻微咳嗽。 |
| **I have ...** | 直接描述症状，适用于日常交流和医疗咨询。 | **I have a headache and a runny nose.** 我头痛，还流鼻涕。 |
| **I've been feeling ...** | 描述最近持续或反复出现的身体感受。 | **I've been feeling feverish since yesterday.** 从昨天开始，我一直感觉有些发热。 |
| **I've been having ...** | 描述最近一直存在或反复出现的不适。 | **I've been having trouble sleeping because of the cough.** 因为咳嗽，我最近一直睡不好。 |
| **My ... hurts.** | 直接指出疼痛的身体部位。 | **My throat hurts when I swallow.** 我吞咽时喉咙会痛。 |
| **I'm suffering from ...** | 可以描述正在经历某种疾病或症状，语气相对正式，常强调不适或困扰。 | **I've been suffering from a persistent cough.** 我一直受到持续性咳嗽的困扰。 |

### 2. Sore、ache、pain 与 hurt

| 词汇 | 核心含义 | 例句 |
|---|---|---|
| **sore** | 形容词，表示疼痛、酸痛或因刺激而不舒服，常修饰 throat、muscles 等。 | **I've got a sore throat.** 我喉咙痛。 |
| **ache** | 作名词或动词时，通常描述持续的隐痛或酸痛。 | **My back aches after sitting all day.** 坐了一整天后，我背部酸痛。 |
| **pain** | 名词，广泛表示疼痛，可以描述部位、强度和性质。 | **I have a sharp pain in my ear.** 我耳朵里有一阵刺痛。 |
| **hurt** | 动词，表示某个部位疼痛。 | **My throat hurts when I talk.** 我说话时喉咙疼。 |

**使用见解**

英语中描述疼痛时，身体部位与疼痛性质的搭配比较重要：

- **a sore throat**：喉咙痛。
- **a headache**：头痛。
- **a stomachache**：胃痛、肚子痛。
- **a toothache**：牙痛。
- **ear pain**：耳痛。
- **sore muscles**：肌肉酸痛。

还可以描述疼痛发生的条件：

**It hurts when I swallow.**

我吞咽时会痛。

**The pain gets worse at night.**

疼痛到了晚上会加重。

**It only hurts when I cough.**

只有咳嗽的时候才会痛。

## 二、如何描述感冒和呼吸道症状

喉咙痛、咳嗽、鼻塞、发热感和声音嘶哑是药店咨询中经常出现的症状。

掌握这些表达，可以让药师更清楚地了解身体状况。

### 1. 常见症状

| 表达 | 中文含义 | 例句 |
|---|---|---|
| **a sore throat** | 喉咙痛 | **I've had a sore throat for two days.** 我喉咙痛已经两天了。 |
| **a cough** | 咳嗽 | **I've developed a cough.** 我开始咳嗽了。 |
| **a dry cough** | 干咳 | **It's mostly a dry cough.** 主要是干咳。 |
| **a chesty cough** | 有痰的咳嗽，英式英语中较常见 | **I've got a chesty cough.** 我咳嗽有痰。 |
| **a runny nose** | 流鼻涕 | **I've got a runny nose as well.** 我还有点流鼻涕。 |
| **a blocked nose** | 鼻塞，英式英语常见 | **My nose is completely blocked.** 我鼻子堵得厉害。 |
| **a stuffy nose** | 鼻塞，美式英语常见 | **I have a stuffy nose.** 我鼻塞。 |
| **a fever** | 发烧 | **I think I have a fever.** 我觉得自己发烧了。 |
| **chills** | 发冷、寒战 | **I've been having chills since last night.** 从昨晚开始我一直感觉发冷。 |
| **a hoarse voice** | 声音嘶哑 | **My voice has been hoarse all morning.** 我整个上午声音都很沙哑。 |
| **body aches** | 全身酸痛 | **I've got a fever and body aches.** 我发烧了，还全身酸痛。 |

### 2. Cough 的名词和动词用法

**cough** 既可以是名词，也可以是动词。

作名词：

**I've got a cough.**

我咳嗽了。

**It's a dry cough.**

是干咳。

作动词：

**I've been coughing all night.**

我整晚都在咳嗽。

**I cough more when I lie down.**

我躺下时咳得更厉害。

当想表达持续或反复咳嗽时，**I've been coughing ...** 特别实用。

### 3. Fever 与 feverish

**have a fever** 描述发烧这一情况。

**I had a fever last night.**

我昨晚发烧了。

**feel feverish** 描述身体发热、感觉像发烧的主观感受。

**I've been feeling a bit feverish.**

我最近感觉有些发热。

如果还没有测量体温，可以直接说明：

**I feel feverish, but I haven't checked my temperature.**

我感觉有点发烧，但还没有量体温。

如果已经量过体温：

**My temperature was 38 degrees Celsius this morning.**

我今天早上体温是 38 摄氏度。

### 4. 描述症状的严重程度

| 表达 | 使用见解 | 例句 |
|---|---|---|
| **a little** | 表示程度轻微，适合描述咳嗽等行为。 | **I've been coughing a little.** 我有点咳嗽。 |
| **slightly** | 表示稍微，语气相对中性。 | **My throat feels slightly sore.** 我喉咙有点痛。 |
| **mild** | 表示轻度症状，常用于医疗场景。 | **I've got a mild headache.** 我有点轻微头痛。 |
| **pretty bad** | 口语中表示情况比较严重。 | **My sore throat is pretty bad today.** 我今天喉咙痛得挺厉害。 |
| **severe** | 表示严重的症状。 | **I've been experiencing severe throat pain.** 我一直有严重的喉咙疼痛。 |
| **persistent** | 表示症状持续存在或反复出现。 | **I have a persistent cough.** 我一直咳嗽。 |

## 三、如何说明症状持续多久

药师通常会询问症状从什么时候开始，以及持续了多长时间。

这里需要理解 **for、since、ago、yesterday** 与不同时态之间的关系。

### 1. 询问症状持续时间

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **How long have you had ...?** | 询问某个症状从过去持续到现在有多久。 | **How long have you had the sore throat?** 你喉咙痛多久了？ |
| **When did it start?** | 询问症状最初出现的时间。 | **When did the cough start?** 咳嗽是什么时候开始的？ |
| **How long has this been going on?** | 询问某种情况已经持续多久，口语中比较自然。 | **How long has this been going on?** 这种情况持续多久了？ |
| **Has it been getting worse?** | 询问症状最近是否逐渐加重。 | **Has the pain been getting worse?** 疼痛有没有越来越严重？ |

### 2. For 与 since

| 表达 | 时间关系 | 例句 |
|---|---|---|
| **for two days** | 持续两天，强调时间长度。 | **I've had a sore throat for two days.** 我喉咙痛两天了。 |
| **since yesterday** | 从昨天开始到现在，强调起点。 | **I've been coughing since yesterday.** 我从昨天开始一直咳嗽。 |
| **since Monday** | 从星期一开始。 | **I've been feeling unwell since Monday.** 我从周一开始就不太舒服。 |
| **for the past week** | 过去这一周一直如此。 | **I've been having headaches for the past week.** 过去这一周我一直头痛。 |

### 3. Ago 与 for

**Two days ago** 表示过去的一个时间点。

**The symptoms started two days ago.**

症状两天前开始出现。

**For two days** 表示持续两天。

**I've had these symptoms for two days.**

这些症状已经持续两天了。

两个表达可以描述同一情况，但需要使用合适的时态。

### 4. 描述新出现的症状

**I started feeling feverish yesterday.**

我昨天开始感觉有点发热。

**The cough started first, and the sore throat came later.**

最先出现的是咳嗽，后来才开始喉咙痛。

**I've had a sore throat for two days, but the feverish feeling only started yesterday.**

我喉咙痛已经两天了，不过发热感是昨天才开始的。

这里的 **only started yesterday** 可以强调新症状出现得更晚。

## 四、如何描述症状变化

有时候症状虽然已经持续数天，但严重程度会发生变化。

英语中可以使用 **get better、get worse、improve、ease、go away** 等动词描述。

### 1. 症状变化表达

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **get better** | 表示症状好转。 | **My throat is starting to get better.** 我的喉咙开始好转了。 |
| **get worse** | 表示症状加重。 | **The cough has been getting worse.** 咳嗽一直在加重。 |
| **improve** | 表示状况改善，语气相对中性。 | **My symptoms haven't improved much.** 我的症状没怎么改善。 |
| **ease** | 表示疼痛或不适减轻。 | **The pain eased a little after I rested.** 我休息后疼痛稍微减轻了。 |
| **go away** | 表示症状消失。 | **The sore throat hasn't gone away.** 喉咙痛还没有消失。 |
| **come and go** | 表示症状时有时无。 | **The headache comes and goes.** 头痛时有时无。 |
| **clear up** | 表示某种症状或问题逐渐消失。 | **My cold symptoms are starting to clear up.** 我的感冒症状开始消退了。 |

### 2. Get + 比较级

**get + 形容词比较级** 可以表示状态逐渐发生变化。

**It's getting worse.**

情况越来越严重了。

**I'm getting better.**

我正在好转。

**The pain is getting stronger.**

疼痛越来越强烈。

这种结构在日常交流和医疗咨询中都很常见。

### 3. 持续没有好转

**It hasn't improved at all.**

完全没有改善。

**I'm still coughing.**

我还在咳嗽。

**The pain hasn't gone away.**

疼痛一直没消失。

**I felt better yesterday, but the symptoms came back today.**

昨天感觉好了一些，不过今天症状又出现了。

其中 **come back** 可以用于描述症状再次出现。

## 五、如何说明已经服用过什么药

在询问新的药物之前，药师通常需要了解你是否已经服用过其他药品。

英语中的 **take、have taken、already、yet** 在这里十分常见。

### 1. 描述用药经历

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **I haven't taken anything yet.** | 表示目前还没有服用任何药物。 | **I haven't taken anything for the cough yet.** 我还没有吃过止咳的药。 |
| **I've already taken ...** | 强调已经服用过某种药物。 | **I've already taken some pain relief medicine today.** 我今天已经服用过一些止痛药了。 |
| **I took ... this morning.** | 说明过去某个具体时间服用过药物。 | **I took some medicine this morning.** 我今天早上吃过药。 |
| **I'm currently taking ...** | 表示目前正在持续使用某种药物。 | **I'm currently taking medication prescribed by my doctor.** 我目前正在服用医生开的药。 |
| **I stopped taking ...** | 表示已经停止服用某种药物。 | **I stopped taking it yesterday.** 我昨天停药了。 |

### 2. Take medicine

英语中通常使用 **take** 表示服药。

**take medicine**

服药。

**take a tablet**

服用一片药片。

**take a capsule**

服用一粒胶囊。

**take cough syrup**

服用止咳糖浆。

**take medication regularly**

规律服药。

如果描述一次剂量，可以使用 **dose**：

**I've already taken one dose today.**

我今天已经服过一次药了。

### 3. Already 与 yet

**already** 强调某件事已经发生。

**I've already taken something for the pain.**

我已经吃过缓解疼痛的药了。

**yet** 常用于疑问句和否定句，表示截至目前。

**Have you taken anything yet?**

你吃过什么药了吗？

**Not yet.**

还没有。

### 4. 询问药师推荐

**Could you recommend something for a sore throat?**

你能推荐一些缓解喉咙痛的药吗？

**Is there anything over the counter that might help?**

有没有什么可能有帮助的非处方药？

**What would you recommend for these symptoms?**

针对这些症状，你会推荐什么？

**Would this be suitable for someone with a penicillin allergy?**

这种药适合对青霉素过敏的人吗？

推荐药品前，应让药师了解相关的过敏史、正在使用的药物和其他可能影响用药选择的情况。

## 六、如何说明药物过敏

药物过敏信息直接影响用药安全，因此表达应当明确。

### 1. 常见过敏表达

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **I'm allergic to ...** | 最常见的过敏表达。 | **I'm allergic to penicillin.** 我对青霉素过敏。 |
| **I have an allergy to ...** | 使用名词 allergy 描述过敏情况。 | **I have an allergy to penicillin.** 我对青霉素过敏。 |
| **I had an allergic reaction to ...** | 表示过去曾对某种物质发生过敏反应。 | **I had an allergic reaction to an antibiotic before.** 我以前对一种抗生素发生过敏反应。 |
| **I'm not aware of any other allergies.** | 表示自己不知道还有其他过敏情况。 | **I'm not aware of any other medication allergies.** 我不知道自己还有其他药物过敏。 |
| **I don't know of any other allergies.** | 较口语化地说明没有其他已知过敏。 | **I don't know of any other allergies.** 据我所知，没有其他过敏。 |

### 2. Allergic 与 allergy

**allergic** 是形容词。

**I'm allergic to penicillin.**

我对青霉素过敏。

**allergy** 是名词。

**I have a penicillin allergy.**

我有青霉素过敏史。

**allergic reaction** 表示过敏反应。

**I developed a rash after taking it.**

我服用后出现了皮疹。

如果曾发生严重过敏反应，应向药师或医生明确说明相关情况和既往反应。

### 3. That I know of

**that I know of** 表示“据我所知”。

**I don't have any other allergies that I know of.**

据我所知，我没有其他过敏。

**I've never had a reaction to this medicine, as far as I know.**

据我所知，我以前没有对这种药出现过反应。

这类表达可以避免对自己并不完全确定的情况作出绝对判断。

## 七、如何询问药物剂量与服用次数

在药店购买药物时，需要根据具体产品了解每次剂量、每日次数、服用间隔和最大剂量等信息。

这里最重要的表达包括 **dose、dosage、how often、how many times a day、how much**。

### 1. 询问服药方法

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **How should I take this?** | 笼统询问药物的正确服用方式。 | **How should I take this medicine?** 这种药我应该怎么服用？ |
| **How often should I take it?** | 询问服用频率。 | **How often should I take it?** 我应该多久服用一次？ |
| **How many times a day?** | 询问每天需要服用几次。 | **How many times a day should I take it?** 我一天需要服用几次？ |
| **How much should I take each time?** | 询问每次的剂量。 | **How much should I take each time?** 我每次应该服用多少？ |
| **How long should I take it for?** | 询问需要持续服用多久。 | **How long should I take this medicine for?** 这种药需要吃多久？ |
| **What's the maximum daily dose?** | 询问一天允许服用的最大剂量。 | **What's the maximum daily dose for this product?** 这种药一天最多能服用多少？ |

### 2. Dose 与 dosage

| 词汇 | 核心含义 | 例句 |
|---|---|---|
| **dose** | 一次服用的剂量，也可指某一具体剂量。 | **I missed a dose yesterday.** 我昨天漏服了一次药。 |
| **dosage** | 剂量规定或用药方案，也常泛指用药剂量。 | **I need to check the dosage instructions.** 我需要查看剂量说明。 |
| **daily dose** | 每日剂量。 | **Don't exceed the recommended daily dose.** 不要超过建议的每日剂量。 |
| **maximum dose** | 最大剂量。 | **Ask the pharmacist about the maximum dose.** 向药师询问最大剂量。 |

### 3. How often 与 how many times

**How often should I take it?**

我应该多久服用一次？

重点是服药频率，可以用每天几次、每隔多久等方式回答。

**How many times a day should I take it?**

我每天应该服用几次？

明确询问一天之内的服药次数。

**How many tablets should I take each time?**

我每次应该吃几片？

询问的是每次服用的片数。

这几个问题涉及不同信息，实际用药时不能仅凭服用次数推断每次剂量。

### 4. 询问忘记服药怎么办

**What should I do if I miss a dose?**

如果漏服了一次，我应该怎么办？

**Should I take it as soon as I remember?**

我想起来之后就应该马上服用吗？

**Should I skip the missed dose?**

我应该跳过漏服的那次吗？

具体处理方式取决于药物说明或专业指导，不能自行假定所有药物都适用同一种规则。

## 八、如何询问饭前饭后与饮品限制

不同药物对进食、饮品和服用方式的要求可能不同。

因此，英语中需要区分 **before meals、after meals、with food、on an empty stomach** 等表达。

### 1. 与进食有关的表达

| 常用表达 | 核心含义 | 例句 |
|---|---|---|
| **before meals** | 饭前。 | **Should I take this before meals?** 这种药要饭前吃吗？ |
| **after meals** | 饭后。 | **Should I take it after meals?** 我应该饭后吃吗？ |
| **with food** | 与食物一起服用，具体要求由药品说明确定。 | **Does this medicine need to be taken with food?** 这种药需要随餐服用吗？ |
| **on an empty stomach** | 空腹。 | **Do I need to take it on an empty stomach?** 我需要空腹服用吗？ |
| **with water** | 用水送服。 | **Should I take it with water?** 我应该用水送服吗？ |
| **with coffee** | 用咖啡送服。 | **Is it okay to take this with coffee?** 可以用咖啡送服这种药吗？ |

### 2. Take with 与 take after

**take with food** 表示用药与进食相配合。

**The label says to take it with food.**

标签上写着要随餐服用。

**take after meals** 表示饭后服用。

**The pharmacist told me to take it after meals.**

药师告诉我要饭后服用。

这两个表达不能随意互换，因为不同药物的服用时间要求可能有实际区别。

### 3. 询问咖啡与饮品

**Can I take this medicine with coffee?**

我能用咖啡送服这种药吗？

**Would water be better?**

用水会不会更合适？

**Are there any drinks I should avoid?**

有没有什么饮品需要避免？

**Does caffeine affect this medicine?**

咖啡因会影响这种药吗？

水通常是服用许多口服药的常见选择，但具体饮品限制、食物相互作用及用药要求，应以当前药品的说明和药师建议为准。

## 九、如何询问副作用与驾驶安全

购买药物时，还可以询问是否可能引起困倦、头晕或其他影响日常活动的反应。

### 1. 常见副作用词汇

| 表达 | 中文意思 | 例句 |
|---|---|---|
| **side effect** | 副作用 | **Does this medicine have any common side effects?** 这种药有什么常见副作用吗？ |
| **drowsiness** | 嗜睡、困倦 | **Could this medicine cause drowsiness?** 这种药会引起嗜睡吗？ |
| **drowsy** | 昏昏欲睡的 | **Will it make me feel drowsy?** 它会让我感到困倦吗？ |
| **dizzy** | 头晕的 | **I feel a little dizzy after taking it.** 我服药后感觉有点头晕。 |
| **nausea** | 恶心 | **Could nausea be a side effect?** 恶心可能是这种药的副作用吗？ |
| **fatigue** | 疲劳 | **I've been feeling unusually fatigued.** 我最近感觉异常疲劳。 |
| **allergic reaction** | 过敏反应 | **What should I do if I have an allergic reaction?** 如果出现过敏反应，我应该怎么办？ |

### 2. Make somebody + 形容词

**make + 宾语 + 形容词** 表示使某人处于某种状态。

**This medicine makes me sleepy.**

这种药让我犯困。

**It might make you dizzy.**

它可能让你头晕。

**Will it make me drowsy?**

它会让我昏昏欲睡吗？

这里的 **sleepy、dizzy、drowsy** 都作宾语补足语。

### 3. Cause 与 affect

**cause + 名词** 表示导致某种结果。

**Could this medicine cause drowsiness?**

这种药会导致嗜睡吗？

**affect + 宾语** 表示影响某人或某事。

**Could it affect my concentration?**

它会影响我的注意力吗？

**Does it affect your ability to drive?**

它会影响驾驶能力吗？

### 4. 询问能否驾驶

**Is it safe to drive after taking this?**

服用这种药之后开车安全吗？

**Could this medicine affect my reaction time?**

这种药可能影响我的反应速度吗？

**Should I avoid driving while taking it?**

服药期间我应该避免开车吗？

**Does the warning label say anything about driving?**

警示标签有没有关于驾驶的说明？

驾驶安全需要结合具体药物、个人反应和身体状态判断。即使某种药通常不引起嗜睡，只要出现困倦、头晕、反应变慢等影响驾驶的情况，就应避免驾驶并寻求专业建议。

## 十、如何确认自己正确理解了用药说明

药师解释药品用法时，可能涉及多项信息。通过复述关键内容，可以确认自己是否正确理解。

### 1. 确认用法的常见句型

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **So you're saying ...?** | 用自己的话复述对方说明，再请对方确认。 | **So you're saying I should take it after meals?** 所以你的意思是我应该饭后服用？ |
| **Just to make sure, ...** | 表示为了确保理解准确而再次核实。 | **Just to make sure, how often should I take it?** 我确认一下，这个药应该多久吃一次？ |
| **Do you mean ...?** | 用于确认某个具体含义。 | **Do you mean one tablet each time?** 你的意思是每次一片吗？ |
| **Is that right?** | 在复述后请对方确认。 | **I should follow the instructions on the label. Is that right?** 我应该按照标签说明服用，对吗？ |
| **Have I understood correctly?** | 较完整地核实自己是否理解正确。 | **Have I understood correctly that I should take it with water?** 我理解得对吗？这种药应该用水送服？ |
| **Could you explain that again?** | 没听清或没理解时，请对方重新说明。 | **Could you explain the dosage again?** 你能再解释一下剂量吗？ |

### 2. So you're saying 与 Do you mean

**So you're saying ...** 可以用于复述整条说明。

**So you're saying I should check how it affects me before driving?**

所以你的意思是，我应该先观察这种药对自己的影响，再考虑开车？

**Do you mean ...** 更适合确认某个具体信息。

**Do you mean I should take it with food?**

你的意思是我应该随餐服用吗？

### 3. Got it、understood 与 I see

| 表达 | 语气 | 例句 |
|---|---|---|
| **Got it.** | 日常、自然，表示已理解。 | **Got it. I'll check the label.** 明白，我会查看标签。 |
| **Understood.** | 稍正式，适合较重要的说明。 | **Understood. I'll follow those instructions.** 明白，我会按这些说明做。 |
| **I see.** | 表示理解对方解释的含义。 | **I see. So the timing matters.** 明白了，所以服用时间很重要。 |
| **That makes sense.** | 表示理解并认为解释合理。 | **That makes sense. Thanks for explaining.** 有道理，谢谢你的解释。 |

## 十一、如何询问何时应该去看医生

如果症状没有改善、变得严重，或者出现新的异常情况，需要考虑进一步医疗评估。

英语中可以使用 **What if、should I、when should I、seek medical advice** 等表达咨询。

### 1. 询问后续就医

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **What if it doesn't get better?** | 询问如果症状没有好转该怎么办。 | **What if my sore throat doesn't get better?** 如果喉咙痛一直不好怎么办？ |
| **When should I see a doctor?** | 直接询问适合就医的时机。 | **When should I see a doctor about these symptoms?** 出现这些症状，什么时候应该去看医生？ |
| **Should I get checked?** | 询问是否需要接受医疗检查。 | **Should I get checked if the fever continues?** 如果持续发烧，我应该去检查吗？ |
| **What symptoms should I watch out for?** | 询问需要特别留意的症状。 | **What symptoms should I watch out for?** 我应该特别注意哪些症状？ |
| **Should I seek medical advice sooner?** | 询问是否需要更早寻求医疗建议。 | **Should I seek medical advice sooner if things get worse?** 如果症状加重，我应该更早就医吗？ |

### 2. What if

**What if + 从句?** 用于提出一种假设情况，并询问后果或应对办法。

**What if the medicine doesn't help?**

如果这种药没效果怎么办？

**What if my cough gets worse?**

如果我的咳嗽加重怎么办？

**What if I develop a fever?**

如果我开始发烧怎么办？

### 3. In a couple of days

**in a couple of days** 表示大约两天后，也可能在日常口语中表示两三天后。

**If I'm not feeling better in a couple of days, should I see a doctor?**

如果过两天我还没好转，需要看医生吗？

**within two days** 表示在两天以内，强调期限。

**If the symptoms haven't improved within two days, what should I do?**

如果两天之内症状没有改善，我应该怎么办？

需要注意，实际就医时机应根据症状及专业评估决定。出现呼吸困难、无法吞咽、明显脱水、迅速恶化或严重过敏反应等危险信号时，应及时寻求医疗救助，不应继续等待自行好转。

## 十二、如何回应建议并表达接下来的安排

药师可能会建议休息、补充水分、观察症状或进一步就医。

回应时，可以使用 **I will、I'll make sure、I'm planning to、I'll try to** 等表达。

### 1. 回应建议

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **I will.** | 简短表示会按照对方的建议行动。 | **I will. Thanks for the advice.** 我会的，谢谢你的建议。 |
| **I'll make sure to ...** | 强调会确保完成某件事。 | **I'll make sure to follow the instructions.** 我会确保按照说明服用。 |
| **I'll try to ...** | 表示会努力做某件事，但不保证一定完成。 | **I'll try to get more rest.** 我会尽量多休息。 |
| **I'm planning to ...** | 表达已经形成的近期计划。 | **I'm planning to turn in early tonight.** 我打算今晚早点睡。 |
| **I'll keep an eye on ...** | 表示会留意某个情况的变化。 | **I'll keep an eye on my symptoms.** 我会留意症状变化。 |
| **I'll get checked if ...** | 表示在某个条件成立时接受检查。 | **I'll get checked if the symptoms get worse.** 如果症状加重，我会去检查。 |

### 2. Turn in 与 go to bed

**turn in** 是非正式口语表达，表示上床睡觉。

**I'm going to turn in early tonight.**

我今晚打算早点睡。

**go to bed** 更通用。

**I should go to bed earlier.**

我应该早点睡觉。

**get some rest** 表示休息，可以包括睡觉，也可以指减少活动、放松身体。

**I need to get some rest.**

我需要休息一下。

### 3. Rest、sleep 与 relax

| 动词 | 侧重点 | 例句 |
|---|---|---|
| **rest** | 身体或精神休息，未必进入睡眠。 | **I need to rest this afternoon.** 我今天下午需要休息。 |
| **sleep** | 睡觉，处于睡眠状态。 | **I didn't sleep well last night.** 我昨晚没睡好。 |
| **relax** | 放松，缓解紧张或压力。 | **I'm going to relax for a while.** 我打算放松一会儿。 |

## 十三、综合 场景

### 场景 1：描述喉咙痛与咳嗽

| 角色 | 对话 |
|---|---|
| A | **Hi, what can I help you with today?** 你好，今天需要什么帮助？ |
| B | **I've got a sore throat, and I've been coughing a little.** 我喉咙痛，还有点咳嗽。 |
| A | **How long have you had these symptoms?** 这些症状持续多久了？ |
| B | **About two days. I started feeling feverish yesterday as well.** 大约两天，昨天开始还感觉有点发热。 |
| A | **Have you checked your temperature?** 你量过体温吗？ |
| B | **Not yet. I was hoping you could advise me on what to do.** 还没有。我想请你建议一下接下来该怎么办。 |

**使用见解**

**I've got ...** 用于直接说明目前的症状。

**I've been coughing ...** 强调持续或反复出现的咳嗽。

**started feeling feverish** 描述出现发热感的时间，避免在未测量时直接断言体温情况。

### 场景 2：说明药物过敏与正在服用的药

| 角色 | 对话 |
|---|---|
| A | **Do you have any medication allergies?** 你有药物过敏吗？ |
| B | **Yes, I'm allergic to penicillin.** 有，我对青霉素过敏。 |
| A | **Any other allergies that you know of?** 据你所知，还有其他过敏吗？ |
| B | **Not that I know of.** 据我所知没有。 |
| A | **Are you taking any other medicines at the moment?** 你目前还在服用其他药吗？ |
| B | **No, I haven't taken anything for these symptoms yet.** 没有，我还没针对这些症状吃过药。 |

**使用见解**

**be allergic to ...** 直接说明已知过敏信息。

**Not that I know of** 表示据自己所知没有。

**at the moment** 表示目前，适合询问正在进行的用药情况。

### 场景 3：咨询药物剂量与服用方法

| 角色 | 对话 |
|---|---|
| B | **Could you explain how I should take this medicine?** 你能解释一下这种药应该怎么服用吗？ |
| A | **Of course. Let's check the directions on the label together.** 当然，我们一起看一下标签上的说明。 |
| B | **Should I take it with food or on an empty stomach?** 我应该随餐服用还是空腹服用？ |
| A | **Follow the food instructions listed here for this product.** 按照这里列出的该产品进食相关说明服用。 |
| B | **And how often should I take it?** 那我应该多久服用一次？ |
| A | **The dosing frequency is listed here too. Let me go through it with you.** 服用频率这里也有注明，我给你解释一下。 |

**使用见解**

**How should I take ...?** 用于笼统询问服药方法。

**with food / on an empty stomach** 用于询问药物与进食的关系。

**how often** 询问服用频率，与 **how much each time** 所询问的剂量信息不同。

### 场景 4：确认饮品与驾驶注意事项

| 角色 | 对话 |
|---|---|
| B | **Is it okay to take this with coffee?** 这种药可以用咖啡送服吗？ |
| A | **For this product, it's best to follow the label and take it with water.** 对于这种药，最好按照标签说明用水送服。 |
| B | **Got it. One more thing — is it safe to drive after taking it?** 明白。还有个问题，服药之后开车安全吗？ |
| A | **Check the warnings carefully and avoid driving if you feel drowsy or dizzy.** 仔细查看警示信息。如果感到困倦或头晕，就不要开车。 |
| B | **So I should pay attention to how it affects me first?** 所以我应该先留意它对我的影响，对吗？ |
| A | **Exactly. And let me know if you need help understanding the warning label.** 没错。如果需要解释警示标签，也可以告诉我。 |

**使用见解**

**Is it okay to ...?** 用于询问某种行为是否适当。

**One more thing** 可以自然引出额外问题。

**affect somebody** 表示对某人产生影响，在讨论药物副作用时非常实用。

### 场景 5：症状没有好转，咨询何时就医

| 角色 | 对话 |
|---|---|
| B | **What if my sore throat doesn't get better?** 如果喉咙痛一直不好怎么办？ |
| A | **Because you're also feeling feverish, you should consider getting medical advice rather than waiting too long.** 因为你还有发热感，建议及时寻求医疗建议，不要拖太久。 |
| B | **What symptoms should I watch out for?** 我应该特别注意哪些症状？ |
| A | **Trouble breathing or swallowing, or symptoms that get rapidly worse, need urgent attention.** 呼吸或吞咽困难，以及症状迅速恶化，都需要及时就医。 |
| B | **Understood. I'll get checked if things get worse.** 明白。如果情况加重，我会去检查。 |
| A | **And don't hesitate to seek help sooner if you're concerned.** 如果你感到担忧，也可以尽早寻求帮助。 |

**使用见解**

**What if ...?** 用于提出未来可能发生的问题。

**watch out for ...** 表示留意可能出现的异常或危险信号。

**get checked** 表示接受医疗检查，适合询问是否需要专业评估。

### 场景 6：感谢药师并结束交流

| 角色 | 对话 |
|---|---|
| A | **Anything else you'd like to ask?** 还有其他想问的吗？ |
| B | **No, I think that covers everything. Thanks for explaining it all.** 没有了，我想该问的都问到了。谢谢你解释得这么清楚。 |
| A | **You're welcome. Try to get some rest and take care.** 不客气，尽量好好休息，保重。 |
| B | **I will. I'm planning to turn in early tonight.** 我会的，我打算今晚早点睡。 |
| A | **Hope you feel better soon.** 希望你早日好起来。 |
| B | **Thanks again. Have a good day!** 再次谢谢，祝你今天愉快！ |

**使用见解**

**That covers everything** 表示所有想了解的问题基本已经得到解答。

**Thanks for explaining it all** 用于感谢对方耐心解释多项信息。

**turn in early** 表示早点睡，适合在接受休息建议后表达自己的打算。

## 十五、重要使用见解

在药店问诊时，需要特别理解以下几个语言现象。

**1. 症状与持续时间的时态**

**I've got a sore throat** 描述当前症状；**I've been coughing** 描述持续或反复发生的咳嗽；**I started feeling feverish yesterday** 指出新症状出现的具体时间。

根据想表达的内容选择时态，可以让身体情况更加清楚。

**2. 提问时区分不同的用药信息**

**How often should I take it?** 询问频率。

**How much should I take each time?** 询问每次剂量。

**How long should I take it for?** 询问持续服用的时间。

这些问题涉及不同的用药信息，需要分别确认。

**3. 用药安全信息适合复述核对**

**Just to make sure ...**、**Do you mean ...?** 和 **Is that right?** 都可以用于确认重要信息。尤其在涉及过敏、剂量、服用间隔、副作用及驾驶安全时，明确核对有实际意义。

**4. 区分主观感受与已确认的情况**

**I feel feverish** 描述发热感。

**I measured a temperature of 38°C** 则提供实际测量结果。

在还没有确认某个症状或诊断时，**I think、I feel、It seems、I'm not sure** 能帮助准确表达自己的确定程度。

**5. 明确表达何时需要寻求帮助**

**What if it gets worse?**、**When should I see a doctor?** 和 **What symptoms should I watch out for?** 适合主动向专业人员了解后续注意事项。

这些句型可以广泛迁移到医院挂号、医生问诊、远程医疗咨询、药店购买非处方药，以及其他需要描述个人身体状态和确认健康信息的场景。
