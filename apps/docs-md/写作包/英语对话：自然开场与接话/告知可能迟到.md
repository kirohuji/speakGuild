# 告知可能迟到：解释延误与协调见面

## 一、如何告知对方自己可能迟到

与朋友约好见面后，如果发现自己无法准时到达，通常需要及时说明情况，并告知预计的延误时间。

英语中，**run late、be late、be delayed、be running behind** 都可以用来描述迟到，但侧重点有所不同。

### 1. 告知迟到的常用表达

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **I'm running late.** | 表示目前的行程进度落后，预计无法准时到达。适合在赴约途中使用。 | **Sorry, I'm running late. I'll be there as soon as I can.** 抱歉，我要迟到了。我会尽快赶到。 |
| **I'm going to be late.** | 明确预测自己会迟到，适合已经知道无法按时到达的情况。 | **I'm going to be a little late. I missed my bus.** 我会稍微迟到一点，刚才错过公交了。 |
| **I'm running about fifteen minutes late.** | 在说明迟到的同时给出预计延误时长。 | **I'm running about fifteen minutes late. Sorry about that.** 我大概要迟到十五分钟，真不好意思。 |
| **I'm a bit behind schedule.** | 表示当前进度落后于原计划，适用于出行和工作场景。 | **I'm a bit behind schedule, but I'm on my way.** 我比原计划晚了一点，不过已经在路上了。 |
| **I've been delayed.** | 强调因为某种情况导致行程延误，语气相对中性。 | **I've been delayed by traffic.** 我因为堵车耽搁了。 |
| **I'm held up.** | 表示被某件事情耽搁，暂时无法按计划行动。 | **Sorry, I'm held up at work.** 抱歉，工作上的事把我耽搁住了。 |

### 2. Running late 与 being late

**I'm running late.**

我要迟到了。

通常用于出发前或赴约途中，强调行程进度落后。

**I'm late.**

我迟到了。

可以表示自己已经超过约定时间，也可以表示目前已经确定迟到。

**I was late.**

我迟到了。

用于回顾已经发生的事情。

**I ended up being late.**

结果我还是迟到了。

强调实际结果，常用于回顾计划没有顺利进行的情况。

### 3. 如何表达迟到程度

| 表达 | 中文意思 | 例句 |
|---|---|---|
| **a little late** | 稍微晚一点 | **I might be a little late.** 我可能会稍微迟到一点。 |
| **a few minutes late** | 晚几分钟 | **I'm running a few minutes late.** 我要晚几分钟。 |
| **about ten minutes late** | 大约迟到十分钟 | **I'm running about ten minutes late.** 我大约会迟到十分钟。 |
| **quite late** | 迟到比较久 | **I'm going to be quite late, I'm afraid.** 恐怕我会迟到挺久。 |
| **later than expected** | 比预期更晚 | **I'll be there later than expected.** 我会比预期晚到。 |

**使用见解**

如果能够合理估计延误时间，直接提供时间往往更方便双方协调。

**Sorry, I'm running about fifteen minutes late.**

抱歉，我大概要迟到十五分钟。

如果预计时间仍有较大不确定性，可以补充：

**I'll keep you updated.**

有新情况我会告诉你。

## 二、如何表达预计到达时间

告知迟到后，对方通常最关心的是你什么时候能到。

英语中可以通过 **be there、get there、arrive、be away** 等结构描述距离目的地还有多长时间。

### 1. 表达还有多久到

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **I'll be there in ...** | 表示从现在起经过一段时间后会抵达。 | **I'll be there in about fifteen minutes.** 我大约十五分钟后到。 |
| **I'm ... away.** | 表示距离抵达还需要多长时间。 | **I'm about ten minutes away.** 我大约还有十分钟就到了。 |
| **I should be there by ...** | 表示预计最迟在某个时间到达，但 should 保留合理的不确定性。 | **I should be there by three thirty.** 我应该最迟三点半到。 |
| **I'm almost there.** | 表示距离目的地已经很近。 | **I'm almost there. Just another couple of minutes.** 我快到了，再过两分钟左右。 |
| **I'm on my way.** | 表示已经出发，正在前往目的地。 | **I'm on my way. I just got on the bus.** 我已经在路上了，刚上公交。 |
| **I'll get there as soon as I can.** | 表示会尽快赶到，适合抵达时间不确定时使用。 | **Traffic's terrible, but I'll get there as soon as I can.** 堵车很严重，不过我会尽快到。 |

### 2. In、by、at 与 around

| 表达 | 时间关系 | 例句 |
|---|---|---|
| **in fifteen minutes** | 从现在起十五分钟后 | **I'll be there in fifteen minutes.** 我十五分钟后到。 |
| **by three** | 最迟三点 | **I'll be there by three.** 我最迟三点到。 |
| **at three** | 三点这个具体时间 | **I'll meet you at three.** 我三点和你见面。 |
| **around three** | 三点左右 | **I'll arrive around three.** 我三点左右到。 |
| **after three** | 三点之后 | **I probably won't arrive until after three.** 我可能要到三点以后才能到。 |

### 3. Late 与 away 的区别

假设你们原本约好下午三点见面，现在是三点十分，预计三点十五分到达。

**I'm running fifteen minutes late.**

我会比约定时间晚十五分钟。

**I'm five minutes away.**

我距离到达还有五分钟。

两句话的参照点不同：**late** 与原定时间比较，**away** 则说明距离抵达还需要的时间。

因此，在实际交流中需要根据自己掌握的信息选择表达。

## 三、如何解释原计划与实际发生的意外

迟到时，常需要说明自己原本打算怎样安排，以及途中出现了什么问题。

这一部分涉及 **was going to、was planning to、end up、miss** 等高频结构。

### 1. 描述原本的计划

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **I was going to ...** | 表示过去已经有的打算，后续可能发生了变化。 | **I was going to leave earlier, but I got distracted.** 我本来打算早点出门，不过后来分心了。 |
| **I was planning to ...** | 强调之前已计划采取某项行动。 | **I was planning to catch the earlier bus.** 我原本打算赶上前一班公交。 |
| **I meant to ...** | 表示本来有意做某事，实际可能没能做到。 | **I meant to leave at two, but something came up.** 我原本想两点出发，不过临时出了点事。 |
| **I had planned to ...** | 过去完成时强调在过去某个时间点之前已形成的计划。 | **I had planned to arrive early, but the train was delayed.** 我原本计划提前到，但火车晚点了。 |
| **I thought I'd ...** | 表示自己原先预想会做某件事。 | **I thought I'd have enough time, but I underestimated the journey.** 我原以为时间足够，但低估了路程所需时间。 |

### 2. 描述意外情况

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **I missed the bus.** | 表示没赶上原本想乘坐的公交。 | **I missed the bus by a minute.** 我就差一分钟没赶上公交。 |
| **The train was delayed.** | 表示火车或地铁发生延误。 | **The train was delayed by twenty minutes.** 火车晚点了二十分钟。 |
| **I got stuck in traffic.** | 表示堵在路上、遭遇交通拥堵。 | **I got stuck in traffic on the way here.** 我来的路上遇到堵车了。 |
| **Something came up.** | 表示临时出现需要处理的事情。 | **Something came up just as I was leaving.** 我正准备出门时临时出了点事。 |
| **I lost track of time.** | 表示忘了时间，没注意时间已经过去。 | **I was finishing some work and lost track of time.** 我当时在收尾一些工作，结果忘了看时间。 |
| **I took the wrong bus.** | 表示坐错公交。 | **I accidentally took the wrong bus.** 我不小心坐错了公交。 |

### 3. End up + V-ing

**end up + V-ing** 表示事情最终发展成某种结果，尤其适合描述与原先打算不同的情况。

**I ended up missing the bus.**

结果我还是错过公交了。

**I ended up taking a taxi.**

最后我还是打了车。

**We ended up meeting an hour later.**

最后我们晚了一个小时才见面。

可以将原计划和最终结果结合起来：

**I was planning to take the bus, but I ended up getting a taxi.**

我本来打算坐公交，结果最后还是打了车。

### 4. Miss、miss out on 与 be delayed

| 表达 | 核心含义 | 例句 |
|---|---|---|
| **miss the bus** | 错过某班公交，没赶上。 | **I missed the last bus.** 我错过了末班公交。 |
| **miss the meeting** | 未能参加会议，或错过会议。 | **I missed the meeting because I was sick.** 我因为生病没参加会议。 |
| **miss out on something** | 错失某种机会、经历或好处。 | **I don't want to miss out on the exhibition.** 我不想错过那个展览。 |
| **be delayed** | 行程或事情发生延误。 | **My bus was delayed.** 我的公交晚点了。 |

## 四、如何描述交通状况

在告知迟到的对话中，交通状况往往会影响预计抵达时间。

英语中的 **traffic、traffic jam、backed up、held up** 经常出现，但搭配各有特点。

### 1. 常见交通表达

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **Traffic is heavy.** | 表示车流量大、交通拥堵。 | **Traffic is pretty heavy right now.** 现在路上车挺多的。 |
| **Traffic is terrible.** | 强调交通情况非常差。 | **Traffic is terrible. I haven't moved much in ten minutes.** 堵车太严重了，十分钟都没怎么动。 |
| **The roads are backed up.** | 表示道路拥堵，车辆排队积压。 | **The roads are backed up near the station.** 车站附近的道路堵得很厉害。 |
| **I'm stuck in traffic.** | 表示自己正在遭遇堵车。 | **I'm stuck in traffic, so I might be late.** 我堵在路上了，所以可能会迟到。 |
| **Traffic is moving slowly.** | 表示车流移动缓慢。 | **Traffic is moving slowly because of the rain.** 因为下雨，车流走得很慢。 |
| **There's a traffic jam.** | 表示发生了交通堵塞。 | **There's a traffic jam near the bridge.** 桥附近堵车了。 |

### 2. Traffic 的用法

**traffic** 通常是不可数名词。

**There's a lot of traffic today.**

今天路上车很多。

**Traffic is getting worse.**

交通情况正在恶化。

**We got caught in traffic.**

我们遇上堵车了。

在描述交通拥堵时，经常使用 **heavy traffic**，而不需要将 traffic 变成复数。

### 3. Be held up 与 be stuck

**I'm held up in traffic.**

我因为堵车被耽搁了。

**I'm stuck in traffic.**

我堵在路上了。

**I'm held up at work.**

工作上的事把我耽搁住了。

**held up** 可以表示多种原因造成的延误，**stuck in traffic** 则明确指交通拥堵。

### 4. 表达新的延误

**It looks like I'll be a few minutes later than I expected.**

看来我会比预期再晚几分钟。

**Traffic's worse than I thought.**

路况比我想的还糟。

**I might need another ten minutes.**

我可能还需要十分钟。

**My ETA has changed.**

我的预计到达时间变了。

**ETA** 是 *estimated time of arrival* 的缩写，在交通、配送和出行沟通中很常见。

## 五、如何在交通不确定时调整方案

如果错过了公交，而下一班车还需要等很久，可以考虑打车、换乘地铁或者改变见面安排。

### 1. 表达交通方面的不确定性

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **I'm not sure when ...** | 不确定某件事发生的时间，后接陈述语序的间接疑问句。 | **I'm not sure when the next bus is coming.** 我不确定下一班公交什么时候来。 |
| **I don't know how long ...** | 不确定需要多长时间。 | **I don't know how long the wait will be.** 我不知道还要等多久。 |
| **It might take longer than expected.** | 说明实际耗时可能超过原先估计。 | **The journey might take longer than expected.** 这段路可能比预期花更长时间。 |
| **It's hard to tell.** | 表示目前难以判断结果。 | **It's hard to tell when I'll arrive.** 现在还不好判断我什么时候能到。 |
| **I might have to ...** | 表示可能不得不采取某种行动。 | **I might have to take a taxi.** 我可能得打车了。 |

### 2. 选择其他交通方式

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **grab a cab** | 非正式口语中表示打车。 | **I might just grab a cab instead.** 我可能直接打车算了。 |
| **take a taxi** | 常见、通用的表达。 | **I'll take a taxi if the bus doesn't come soon.** 如果公交迟迟不来，我就打车。 |
| **get a ride** | 表示搭车或乘车，具体交通方式由语境决定。 | **I might be able to get a ride with a friend.** 我可能可以搭朋友的车。 |
| **switch to the subway** | 表示改乘地铁。 | **I'll switch to the subway. It might be faster.** 我改坐地铁，可能更快。 |
| **walk the rest of the way** | 表示走完剩余路程。 | **I'll get off here and walk the rest of the way.** 我在这里下车，剩下的路走过去。 |

### 3. Might、could 与 have to

| 表达 | 侧重点 | 例句 |
|---|---|---|
| **might** | 表示有可能采取某种行动，尚未完全决定。 | **I might take a taxi.** 我可能会打车。 |
| **could** | 表示某种可行的选择或办法。 | **I could take the subway instead.** 我可以改坐地铁。 |
| **have to** | 表示情况使某项行动成为必要。 | **I'll have to take a taxi if I want to arrive on time.** 如果想准时到，我就得打车。 |
| **might have to** | 表示某项行动可能会变得必要。 | **I might have to change my route.** 我可能得换路线。 |

**使用见解**

**I might just grab a cab** 很适合在公交时间不确定时提出一个备选。

**just** 在这里可以体现说话人倾向于直接采取这个办法，省去继续等待的麻烦。

## 六、如何礼貌地请求对方帮忙

当对方已经到达咖啡馆，而你仍在路上时，可以请对方帮忙点饮料或选择座位。

### 1. 接受对方主动提供的帮助

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **That'd be great.** | That would be great 的缩写，积极接受帮助。 | **That'd be great, thanks.** 那太好了，谢谢。 |
| **That would help a lot.** | 表示对方的帮助会很有用。 | **That would help a lot. I haven't had coffee all day.** 那会帮大忙，我今天还没喝过咖啡。 |
| **I'd appreciate that.** | 委婉表达自己会感谢对方的帮助。 | **I'd appreciate that. Could you order for me?** 那真是太感谢了，你能帮我点单吗？ |
| **If you don't mind.** | 表示如果对方不介意，自己愿意接受帮助。 | **Yes, please, if you don't mind.** 好的，谢谢，如果你不介意的话。 |

### 2. 请求对方帮忙点饮料

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **Could you order ... for me?** | 礼貌请求对方替自己下单。 | **Could you order an iced Americano for me?** 你能帮我点杯冰美式吗？ |
| **Could you get me ...?** | 使用双宾语结构，请对方帮忙买或拿某样东西。 | **Could you get me an iced Americano?** 能帮我买杯冰美式吗？ |
| **Would you mind getting me ...?** | 更加委婉的请求方式，mind 后接动名词。 | **Would you mind getting me a latte?** 介意帮我买杯拿铁吗？ |
| **I'll have ...** | 点单时直接说明自己的选择。 | **I'll have an iced Americano, please.** 我要一杯冰美式，谢谢。 |
| **Just ... is fine.** | 表示某个选择就足够。 | **Just an iced Americano is fine.** 一杯冰美式就好。 |

### 3. Get somebody something

**get somebody something** 可以表示为某人取得、购买或准备某物。

**Could you get me a coffee?**

你能帮我买杯咖啡吗？

**I'll get you a drink.**

我给你买杯喝的。

**She got us a table.**

她帮我们找了张桌子。

也可以使用：

**Could you get a coffee for me?**

你能帮我买杯咖啡吗？

两个结构在这种场景中都自然。

### 4. Order、get 与 grab

| 动词 | 使用见解 | 例句 |
|---|---|---|
| **order** | 强调下单行为。 | **I'll order your coffee now.** 我现在帮你点咖啡。 |
| **get** | 表示买、拿、点等，口语中非常灵活。 | **I'll get you a coffee.** 我给你买杯咖啡。 |
| **grab** | 比较随意，常表示快速买、拿或找。 | **I'll grab us a table first.** 我先给我们找张桌子。 |

## 七、如何商量与调整座位

如果朋友已经到达咖啡馆，可以请对方先找位置，同时说明自己对座位的偏好。

### 1. 表达座位选择

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **The usual table works.** | 表示平时常坐的位置可以。 | **The usual table works for me.** 平时那张桌子我可以。 |
| **Anywhere is fine.** | 表示坐哪里都可以。 | **Anywhere is fine, as long as it's quiet.** 哪里都可以，只要安静就行。 |
| **A window seat would be nice.** | 委婉表达对靠窗位置的偏好。 | **A window seat would be nice if there's one available.** 如果有空位，靠窗坐就挺好的。 |
| **Let's sit somewhere quieter.** | 提议找一个比较安静的地方。 | **Let's sit somewhere quieter so we can talk.** 我们找个安静点的地方坐，好聊天。 |
| **If it's taken, ...** | 表示如果原来的座位被占用，就采用其他选择。 | **If it's taken, any table near the window is fine.** 如果那张桌子有人坐，窗边其他桌子也可以。 |

### 2. Seat 与 table

**seat** 通常指一个座位。

**Can you save me a seat?**

你能帮我留个位置吗？

**table** 指桌子，在咖啡馆和餐厅中可以表示一整张可供就座的桌位。

**Can you grab us a table?**

你能帮我们找张桌子吗？

**save a seat** 和 **save a table** 在日常口语中都可以使用，具体取决于想保留的是什么。

### 3. Be taken 与 be available

| 表达 | 核心含义 | 例句 |
|---|---|---|
| **be taken** | 座位已被占用。 | **Is this seat taken?** 这个位置有人坐吗？ |
| **be available** | 有空位、可供使用。 | **Are there any window seats available?** 还有靠窗的空位吗？ |
| **be free** | 目前没有被占用。 | **That table looks free.** 那张桌子看起来没人坐。 |
| **be crowded** | 场所里人很多、拥挤。 | **The café gets crowded in the afternoon.** 这家咖啡馆下午人很多。 |

### 4. Works for me

**works for me** 是协商时间、地点和方案时的高频表达。

**The window seat works for me.**

靠窗的位置我可以。

**Three thirty works for me.**

三点半我可以。

**That works for me.**

那个安排对我来说可以。

**That doesn't really work for me.**

那个安排对我来说不太方便。

## 八、如何说明到达后会做什么

朋友已经在咖啡馆等待时，可以告诉对方自己抵达后会立即找到他，或者先发消息确认位置。

这一部分涉及 **when、once、as soon as** 引导的时间从句。

### 1. 描述到达后的行动

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **I'll find you when I get there.** | 表示到达后会去找对方。 | **I'll find you when I get there.** 我到了就去找你。 |
| **I'll come find you.** | 表示自己会主动过去找对方。 | **Stay where you are. I'll come find you.** 你待在原地，我过去找你。 |
| **I'll text you once I arrive.** | 表示到达后会发消息。 | **I'll text you once I arrive at the café.** 我到咖啡馆后会给你发消息。 |
| **I'll call you when I'm outside.** | 表示到了外面后会打电话。 | **I'll call you when I'm outside.** 我到外面时给你打电话。 |
| **I'll head straight to your table.** | 表示直接前往对方的桌位。 | **I'll head straight to your table when I arrive.** 我到后直接去你那桌。 |

### 2. When、once 与 as soon as

| 连接词 | 核心含义 | 例句 |
|---|---|---|
| **when** | 当某件事发生时。 | **I'll text you when I get there.** 我到了就给你发消息。 |
| **once** | 一旦某件事发生，之后就会采取下一步行动。 | **I'll let you know once I arrive.** 我一到就告诉你。 |
| **as soon as** | 强调紧接着某件事发生，通常译为“一……就……”。 | **I'll find you as soon as I get there.** 我一到就马上找你。 |

### 3. 将来时间从句

**I'll call you when I arrive.**

我到的时候会给你打电话。

**I'll text you as soon as I get there.**

我一到就给你发消息。

主句使用将来时，时间从句通常使用一般现在时。

在这些句子中，可以直接使用 **when I arrive**、**as soon as I get there**。

### 4. Get here 与 get there

**get here** 表示到达说话人当前所在的位置。

**Text me when you get here.**

你到这里时给我发消息。

**get there** 表示到达谈话中提到的目的地。

**I'll text you when I get there.**

我到了那里就给你发消息。

当 A 已经在咖啡馆，而 B 还在路上时：

A 可以说：

**Let me know when you get here.**

你到了这里告诉我。

B 可以说：

**I'll let you know when I get there.**

我到了那里就告诉你。

## 九、如何道歉并感谢对方等待

迟到时，可以通过道歉、说明原因、更新预计到达时间，以及感谢对方等待来保持交流自然。

### 1. 道歉的常见表达

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **Sorry I'm late.** | 已经迟到时使用，简短直接。 | **Sorry I'm late. The bus took forever.** 抱歉我迟到了，公交耽搁了好久。 |
| **Sorry I'm running late.** | 仍在路上、预计迟到时使用。 | **Sorry I'm running late. I'll be there in ten minutes.** 抱歉我要迟到了，十分钟后到。 |
| **Sorry about the delay.** | 对延误表示歉意，语气中性。 | **Sorry about the delay. Traffic was terrible.** 抱歉耽搁了，路上堵得厉害。 |
| **Sorry to keep you waiting.** | 为让对方等待表示歉意。 | **Sorry to keep you waiting. I'm nearly there.** 抱歉让你久等，我快到了。 |
| **Sorry again for ...** | 再次道歉，并说明具体原因。 | **Sorry again for keeping you waiting.** 再次抱歉让你等了这么久。 |

### 2. Sorry for + V-ing

**Sorry for + V-ing** 可以说明道歉的具体原因。

**Sorry for being late.**

抱歉迟到了。

**Sorry for keeping you waiting.**

抱歉让你久等。

**Sorry for changing the plan at the last minute.**

抱歉最后一刻才改计划。

**at the last minute** 表示在最后一刻，经常用于临时变更安排。

### 3. 感谢对方等待

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **Thanks for waiting.** | 直接感谢对方等待。 | **Thanks for waiting. I know it's taken longer than expected.** 谢谢你等我，我知道花的时间比预期长。 |
| **Thanks for being patient.** | 感谢对方耐心、愿意配合。 | **Thanks for being patient with me.** 谢谢你对我这么有耐心。 |
| **I really appreciate it.** | 表达真诚感谢，可以指对方等待或帮忙。 | **I really appreciate you waiting for me.** 我真的很感谢你愿意等我。 |
| **Thanks for understanding.** | 感谢对方理解迟到或计划变化。 | **Thanks for understanding. I'll be there soon.** 谢谢你理解，我很快就到。 |
| **That means a lot.** | 表示对方的体谅和帮助对自己很重要。 | **Thanks for being so understanding. That means a lot.** 谢谢你这么理解我，这对我很重要。 |

### 4. 回应 Take your time

**Take your time.**

不用着急，慢慢来。

这通常表示对方愿意等待，希望你不用因为迟到而过度着急。

自然回应：

**Thanks, I appreciate it.**

谢谢，真的很感谢。

**Thanks for understanding. I'll see you soon.**

谢谢你理解，很快见。

**I will. Sorry again for the delay.**

我会的，再次抱歉耽搁了。

如果仍在交通途中，表达尽快赶到时，也需要根据实际路况安全出行。

## 十、如何持续更新情况

有时最初预计迟到十五分钟，但由于堵车或交通工具延误，实际到达时间可能继续变化。

可以使用 **keep you updated、let you know、give you a heads-up** 等表达。

### 1. 告知最新进展

| 常用表达 | 使用见解 | 例句 |
|---|---|---|
| **I'll keep you updated.** | 表示会继续告知新情况。 | **I'll keep you updated if the traffic gets worse.** 如果路况更差，我会及时告诉你。 |
| **I'll let you know.** | 表示会把某个情况告诉对方。 | **I'll let you know once I'm in the cab.** 我一上车就告诉你。 |
| **I'll text you if anything changes.** | 约定如果情况变化会发消息。 | **I'll text you if anything changes.** 如果有变化，我会给你发消息。 |
| **Just a heads-up, ...** | 提前告知对方一件值得注意的事情，语气口语化。 | **Just a heads-up, I might be another ten minutes.** 提前说一声，我可能还要再等十分钟。 |
| **It looks like ...** | 根据最新迹象更新判断。 | **It looks like I'll be there closer to four.** 看来我可能接近四点才能到。 |
| **My ETA is ...** | 说明当前预计到达时间。 | **My ETA is around three forty.** 我预计三点四十左右到。 |

### 2. Still、another 与 even later

| 表达 | 使用见解 | 例句 |
|---|---|---|
| **still** | 表示原有情况继续存在。 | **I'm still stuck in traffic.** 我还堵在路上。 |
| **another ten minutes** | 表示在已经过去的时间之外，还需要十分钟。 | **I might need another ten minutes.** 我可能还需要十分钟。 |
| **even later** | 表示比已经预计的时间还要晚。 | **I might arrive even later than I thought.** 我可能比之前想的到得还晚。 |
| **a little longer** | 表示还需要稍微多一些时间。 | **It's taking a little longer than expected.** 花的时间比预想的稍微长一些。 |

### 3. If、when 与 once 的区别

**I'll text you if anything changes.**

如果有变化，我就给你发消息。

这里的 **if** 表示变化是否发生尚不确定。

**I'll text you when I arrive.**

我到了就给你发消息。

这里的 **when** 表示到达这个事件发生时。

**I'll text you once I'm in the cab.**

我一上出租车就给你发消息。

这里的 **once** 强调进入出租车后就采取下一步行动。

## 十一、综合 场景

### 场景 1：错过公交，告知迟到

| 角色 | 对话 |
|---|---|
| A | **Hey, I'm already at the café. Are you close?** 嘿，我已经到咖啡馆了，你快到了吗？ |
| B | **Sorry, I'm running about fifteen minutes late.** 抱歉，我大概要迟到十五分钟。 |
| A | **What happened?** 怎么回事？ |
| B | **I was planning to leave earlier, but I ended up missing the bus.** 我本来打算早点出门，结果还是错过了公交。 |
| A | **No worries. Just let me know when you're close.** 没关系，你快到的时候告诉我就行。 |
| B | **Will do. Thanks for understanding.** 好的，谢谢你理解。 |

**使用见解**

**running about fifteen minutes late** 说明延误时长。

**was planning to ... but ended up ...** 将原计划与实际结果联系起来。

**Will do** 是简短的承诺回应，表示会按照对方刚才说的去做。

### 场景 2：朋友主动帮忙点咖啡

| 角色 | 对话 |
|---|---|
| A | **Want me to order something for you while I wait?** 我等你的时候，要不要帮你点点什么？ |
| B | **That'd be great, thanks. Could you get me an iced Americano?** 那太好了，谢谢。能帮我点杯冰美式吗？ |
| A | **Sure. Anything else?** 当然，还要别的吗？ |
| B | **No, that's all. I'll pay you back when I get there.** 不用了，就这些。我到了之后把钱还你。 |
| A | **Sounds good. I'll grab us a table too.** 好，我顺便给我们找张桌子。 |
| B | **I really appreciate it.** 真的很感谢。 |

**使用见解**

**Want me to ...?** 用于主动提供帮助。

**Could you get me ...?** 是礼貌且自然的双宾语请求句。

**pay somebody back** 表示偿还别人先垫付的钱。在朋友代为买咖啡的情境中很常见。

### 场景 3：公交还没来，考虑改打车

| 角色 | 对话 |
|---|---|
| A | **Has the bus arrived yet?** 公交车到了吗？ |
| B | **Not yet. I'm not sure when the next one is coming.** 还没。我不确定下一班什么时候来。 |
| A | **That sounds annoying.** 那挺烦人的。 |
| B | **Yeah, I might just grab a cab instead.** 是啊，我可能直接打车了。 |
| A | **Good idea. That should be quicker.** 好主意，应该会更快。 |
| B | **Hopefully. I'll let you know once I'm on my way.** 希望如此。我出发后就告诉你。 |

**使用见解**

**Has the bus arrived yet?** 使用现在完成时询问到目前为止是否已经到达。

**when the next one is coming** 使用陈述语序，**one** 指代下一班公交。

**might just grab a cab** 表示倾向改用出租车，但还没有完全确定。

### 场景 4：路况恶化，需要更新预计到达时间

| 角色 | 对话 |
|---|---|
| B | **Just a heads-up, traffic's worse than I expected.** 提前说一声，路况比我预想的更糟。 |
| A | **Oh, really? How much longer do you think it'll take?** 哦，真的吗？你觉得还要多久？ |
| B | **Maybe another ten minutes. The road near the station is completely backed up.** 可能还要十分钟，车站附近那条路完全堵住了。 |
| A | **That's alright. Take your time.** 没事，慢慢来。 |
| B | **Thanks for being patient. I'll keep you updated.** 谢谢你耐心等我，有新情况我会告诉你。 |

**使用见解**

**Just a heads-up** 适合主动提供新情况。

**another ten minutes** 表示仍需额外十分钟。

**completely backed up** 强调交通严重堵塞，帮助对方理解延误原因。

### 场景 5：调整座位安排

| 角色 | 对话 |
|---|---|
| A | **I'm at the café now. Should I get our usual table?** 我已经到咖啡馆了，要我找我们平时坐的那张桌子吗？ |
| B | **That works, but if it's taken, somewhere by the window would be nice.** 可以。不过如果那张桌子有人坐，靠窗的其他位置也不错。 |
| A | **There's a free table near the window. I'll grab it.** 窗边有张空桌子，我去坐那里。 |
| B | **Perfect. I'll come find you as soon as I get there.** 太好了，我一到就去找你。 |
| A | **No problem. I'll save you a seat.** 没问题，我给你留个位置。 |
| B | **Thanks. See you soon!** 谢谢，很快见！ |

**使用见解**

**if it's taken** 表示如果常坐的桌子已经被占用。

**somewhere by the window** 为对方提供有弹性的替代选择。

**as soon as I get there** 表示抵达后立即去找对方。

### 场景 6：抵达后道歉并表达感谢

| 角色 | 对话 |
|---|---|
| B | **Hey! Sorry again for keeping you waiting.** 嘿！再次抱歉，让你久等了。 |
| A | **No worries. I'm just glad you made it.** 没关系，你能顺利到就好。 |
| B | **Thanks for ordering my coffee. How much do I owe you?** 谢谢你帮我点咖啡，我该给你多少钱？ |
| A | **Don't worry about it. You can get the next one.** 别在意，下次你请就行。 |
| B | **Deal. I owe you one!** 一言为定，欠你个人情！ |

**使用见解**

**keep somebody waiting** 表示让某人持续等待。

**made it** 在这里表示成功抵达目的地。

**How much do I owe you?** 用于询问应向对方支付多少钱。

**You can get the next one** 表示下次由对方请客，是朋友之间非常自然的表达。

## 十二、核心表达总结

| 表达意图 | 核心表达 | 示例 |
|---|---|---|
| 告知可能迟到 | I'm running late | **Sorry, I'm running late.** |
| 说明迟到时长 | running + 时间 + late | **I'm running fifteen minutes late.** |
| 表达已经在路上 | I'm on my way | **I'm on my way now.** |
| 说明还需多久 | in + 时间段 | **I'll be there in ten minutes.** |
| 说明距离到达 | 时间 + away | **I'm five minutes away.** |
| 预计最迟到达 | should be there by ... | **I should be there by three.** |
| 描述原计划 | was planning to ... | **I was planning to leave earlier.** |
| 描述意外结果 | ended up + V-ing | **I ended up missing the bus.** |
| 错过交通工具 | miss the bus | **I missed the bus.** |
| 表达临时耽搁 | something came up | **Something came up.** |
| 遇到堵车 | get stuck in traffic | **I got stuck in traffic.** |
| 描述交通拥堵 | be backed up | **The roads are backed up.** |
| 表示车流量大 | heavy traffic | **Traffic is pretty heavy.** |
| 不确定公交时间 | not sure when ... | **I'm not sure when the next bus is coming.** |
| 考虑打车 | might grab a cab | **I might grab a cab instead.** |
| 接受帮助 | That'd be great | **That'd be great, thanks.** |
| 请求代点饮料 | Could you get me ...? | **Could you get me an iced Americano?** |
| 确认座位 | That works for me | **The usual table works for me.** |
| 提出备用位置 | somewhere by ... | **Somewhere by the window is fine.** |
| 表示座位已被占 | be taken | **That table is taken.** |
| 到达后找人 | come find somebody | **I'll come find you.** |
| 一到就行动 | as soon as ... | **I'll text you as soon as I get there.** |
| 再次告知道歉 | Sorry again for ... | **Sorry again for keeping you waiting.** |
| 感谢等待 | Thanks for waiting | **Thanks for waiting.** |
| 感谢耐心 | Thanks for being patient | **Thanks for being patient.** |
| 表示尽快赶到 | as soon as I can | **I'll get there as soon as I can.** |
| 更新新情况 | keep somebody updated | **I'll keep you updated.** |
| 提前告知 | Just a heads-up | **Just a heads-up, I might be later.** |
| 更新预计到达时间 | ETA | **My ETA is around three forty.** |
| 归还垫付款 | pay somebody back | **I'll pay you back when I arrive.** |
| 询问欠款 | How much do I owe you? | **How much do I owe you?** |
| 即将见面道别 | See you soon | **See you soon!** |

告知可能迟到涉及一组联系紧密的日常交流能力：说明延误时间、解释原计划与实际变化、描述交通状况、考虑替代交通方式，以及及时更新自己的预计到达时间。

其中尤其值得掌握的是 **I'm running ... late**、**I'm ... minutes away**、**I was planning to ... but ended up ...**、**I'm stuck in traffic**、**I'll keep you updated** 和 **Sorry for keeping you waiting**。

这些表达可以广泛用于朋友约会、工作会议、上课、餐厅预约和其他需要准时抵达的场景。
