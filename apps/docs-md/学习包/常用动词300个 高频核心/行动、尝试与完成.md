# 行动、尝试与完成

## 阅读说明

- **及物动词（transitive verb）**：可以直接接宾语。  
  `I need more time.` → `more time` 是宾语。

- **不及物动词（intransitive verb）**：不直接接宾语，可以另接介词短语等成分。  
  `Something happened.` / `Listen to me.`

- **系动词（linking verb）**：接表语，说明主语的身份、性质或状态。  
  `She seems tired.` / `The sky turned dark.`

- **使役结构（causative construction）**：表示使、促使或允许某个动作发生。  
  `make someone do` / `let someone do` / `get someone to do`

- **宾语补足语（object complement）**：在宾语后补充说明宾语的状态、身份或动作。  
  `keep the door open` → `open` 说明门的状态。

- **双宾语结构（double-object construction）**：接两个宾语，通常先说接受者，再说给予的东西。  
  `She gave me a book.` → `me` 是间接宾语，`a book` 是直接宾语。

同一个动词可以有多种用法；以上分类的角度不同，也可以同时适用。

### 结构写法

#### 1. 占位符与符号

| 标记 | 含义 |
| --- | --- |
| `someone / something` | 可替换的人／事物 |
| `noun / adjective` | 名词／形容词 |
| `place / time` | 地点／时间 |
| `clause / wh-clause` | 从句／由 what、why、how 等疑问词引导的从句 |
| `do / doing / done` | 动词原形／V-ing 形式／过去分词 |
| `+` | 连接成分，不写进实际句子 |
| `( )` | 该成分可以省略 |

#### 2. 结构示例

把占位符换成具体内容，保留固定介词和不定式标记。

| 结构 | 实际表达 |
| --- | --- |
| `start with + noun` | **start with the basics**<br>从基础开始 |
| `finish doing` | **finish reading the report**<br>读完报告 |
| `manage to do` | **manage to catch the train**<br>设法赶上火车 |
| `succeed in doing` | **succeed in solving the problem**<br>成功解决问题 |
| `check (that) + clause` | **check (that) the door is locked**<br>确认门锁好了，`that` 可以省略 |

# 1. start

## 核心感觉

> **开始一项活动，或使某个过程、设备启动。**

## 语法特点

- **及物用法**：直接接项目、机器等，也可接 `V-ing` 或 `to do`。
- **不及物用法**：活动或设备可以作主语。用 `with` 引出开头的内容，用 `from` 引出起点。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **start doing**<br>开始做某事 | **I started learning English seriously last year.**<br>我去年开始认真学英语。 |
| **start to do**<br>开始做某事 | **It started to rain.**<br>开始下雨了。 |
| **start + noun**<br>启动某事 | **They started a new project.**<br>他们启动了一个新项目。 |
| **start with + noun**<br>从……开始 | **Let's start with the basics.**<br>我们先从基础开始。 |
| **start from + point**<br>从某个点开始 | **We need to start from scratch.**<br>我们需要从零开始。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **start over**<br>重新开始 | **I made a mistake, so I had to start over.**<br>我犯了错，只能重新开始。 |
| **start again**<br>再次开始 | **Let's start again from the beginning.**<br>我们从头再来。 |
| **start small**<br>从小规模开始 | **It's better to start small.**<br>最好从小规模开始。 |
| **get started**<br>开始行动 | **Let's get started.**<br>我们开始吧。 |
| **start out**<br>起初；开始时 | **The project started out as a small experiment.**<br>这个项目最开始只是一个小实验。 |

## 用法提醒

`start raining` 和 `start to rain` 都自然。表达逐渐理解时，常用 `start to understand`。

`start a car` 是启动汽车，`The car won’t start` 是汽车发动不了。

## 输出例句

**I want to start using English more actively instead of only reading and listening.**  
我想开始更主动地使用英语，而不只是阅读和听。

**The hardest part is often just getting started.**  
最难的部分往往只是开始行动。

**We started with a simple idea and gradually turned it into a real product.**  
我们从一个简单想法开始，逐渐把它做成了真正的产品。

# 2. begin

## 核心感觉

> **开始做某事，或进入某个过程的第一阶段。**

## 语法特点

- **及物与不及物用法**：可直接接活动、`V-ing` 或 `to do`，也可单独使用。
- **开头结构**：`begin with something` 引出起始内容，`begin by doing` 引出首先采取的动作。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **begin doing**<br>开始做 | **She began working there in May.**<br>她五月开始在那里工作。 |
| **begin to do**<br>开始出现某动作 | **I began to understand what he meant.**<br>我开始理解他的意思。 |
| **begin with**<br>从……开始 | **The lesson begins with a short review.**<br>课程从简短复习开始。 |
| **begin by doing**<br>先通过做……开始 | **Begin by defining the problem.**<br>先从定义问题开始。 |
| **begin something**<br>开始某件事 | **They began the meeting at nine.**<br>他们九点开始会议。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **begin again**<br>重新开始 | **We had to begin again.**<br>我们不得不重新开始。 |
| **begin to realize**<br>开始意识到 | **I began to realize how difficult it was.**<br>我开始意识到这有多难。 |
| **begin with the basics**<br>从基础开始 | **Let's begin with the basics.**<br>我们从基础开始。 |
| **begin to take shape**<br>开始成形 | **The plan began to take shape after our second meeting.**<br>第二次开会后，计划开始成形。 |
| **begin with a question**<br>以一个问题开场 | **She began with a question for the audience.**<br>她以一个面向观众的问题开场。 |

## 用法提醒

`begin` 和 `start` 在许多场合可以互换，`begin` 常见于书面说明、课程和叙述。启动设备常用 `start`。

过去式 `began`，过去分词 `begun`。

## 输出例句

**I began to notice patterns that I hadn't seen before.**  
我开始注意到以前没有发现的规律。

**The course begins with simple examples and gradually becomes more complex.**  
课程从简单例子开始，逐渐变复杂。

**Once you begin using the language actively, many rules start to feel more natural.**  
一旦开始主动使用语言，很多规则会逐渐变得自然。

# 3. continue

## 核心感觉

> **让活动接着进行，或描述某个过程继续持续。**

## 语法特点

- **及物用法**：可直接接讨论、工作等，也可接 `V-ing` 或 `to do`。
- **不及物用法**：可单独使用，或用 `with` 引出接着做的事项，用 `for / until` 说明时长或终点。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **continue doing**<br>继续做 | **She continued working.**<br>她继续工作。 |
| **continue to do**<br>继续做 | **Prices continue to rise.**<br>价格继续上涨。 |
| **continue with + noun**<br>继续进行某事 | **Let's continue with the next topic.**<br>我们继续下一个话题。 |
| **continue something**<br>继续某个过程 | **They continued the discussion.**<br>他们继续讨论。 |
| **continue until**<br>一直持续到 | **The work continued until midnight.**<br>工作一直持续到午夜。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **continue working**<br>继续工作 | **I continued working despite being tired.**<br>虽然很累，我还是继续工作。 |
| **continue to grow**<br>持续增长 | **The company continues to grow.**<br>公司继续增长。 |
| **continue as planned**<br>按计划继续 | **The event will continue as planned.**<br>活动将按计划继续。 |
| **continue for years**<br>持续多年 | **The debate continued for years.**<br>这场争论持续了多年。 |
| **continue where we left off**<br>从上次停下的地方继续 | **Let’s continue where we left off yesterday.**<br>我们从昨天停下的地方继续吧。 |

## 用法提醒

`continue working` 和 `continue to work` 通常都表示继续工作。

`continue with the next topic` 表示接着进入下一个话题。

## 输出例句

**I want to continue improving my English through regular output.**  
我想通过规律输出继续提高英语。

**Even after you understand the rule, you still need to continue using it.**  
即使理解了规则，也还需要继续使用。

**The project continued to grow after the first release.**  
第一次发布以后，这个项目继续发展。

# 4. stop

## 核心感觉

> **停止某个动作，或使人、事物停下来。**

## 语法特点

- **及物用法**：直接接被停止的事物或 `V-ing`。
- **不及物用法**：可单独使用，`stop to do` 中的不定式说明停下来做什么。
- **阻止结构**：`stop someone / something from doing`。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **stop doing**<br>停止做某事 | **He stopped talking.**<br>他不说话了。 |
| **stop to do**<br>停下来去做另一件事 | **We stopped to rest.**<br>我们停下来休息。 |
| **stop someone from doing**<br>阻止某人做 | **Nothing could stop her from trying.**<br>没有什么能阻止她尝试。 |
| **stop + noun**<br>停止某物 | **Can you stop the machine?**<br>你能把机器停下来吗？ |
| **stop at + place**<br>在某处停下或停留 | **We stopped at a café on the way home.**<br>回家路上我们在一家咖啡馆停了一下。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **stop working**<br>停止工作／设备停止运行 | **My laptop suddenly stopped working.**<br>我的电脑突然不能用了。 |
| **stop trying**<br>停止尝试 | **Don't stop trying after one failure.**<br>不要失败一次就停止尝试。 |
| **stop immediately**<br>立即停止 | **Stop immediately if you feel pain.**<br>如果感到疼痛就立刻停止。 |
| **never stop learning**<br>永远持续学习 | **You never really stop learning.**<br>真正的学习不会完全停止。 |
| **stop halfway**<br>中途停止 | **He stopped halfway through the task.**<br>他任务做到一半停了。 |

## 用法提醒

`I stopped working` 表示我停止了工作。`I stopped to rest` 表示我停下来休息。

过去式和过去分词都是 `stopped`，`V-ing` 形式是 `stopping`。

## 输出例句

**I stopped trying to memorize every rule and started focusing more on usage.**  
我不再试图记住每条规则，而开始更多关注实际用法。

**We stopped to check the map before going any further.**  
继续走之前，我们停下来查看地图。

**Sometimes the best thing to do is stop and rethink the whole approach.**  
有时候最好的做法是停下来重新考虑整个方法。

# 5. finish

## 核心感觉

> **把事情做完，或到达活动的终点。**

## 语法特点

- **及物用法**：直接接做完的事物或 `V-ing`。
- **不及物用法**：可以单独表示结束，也可用 `with + noun` 或 `by doing` 说明如何收尾。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **finish + noun**<br>完成某事 | **I finished the report.**<br>我写完报告了。 |
| **finish doing**<br>做完某事 | **I finished reading the book.**<br>我看完这本书了。 |
| **finish with**<br>以……结束 | **Let's finish with one final example.**<br>我们最后用一个例子结束。 |
| **finish by doing**<br>最后通过做……结束 | **He finished by thanking everyone.**<br>他最后感谢了所有人。 |
| **be finished**<br>完成；结束 | **Are you finished?**<br>你完成了吗？ |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **finish work**<br>完成工作 / 下班 | **What time do you finish work?**<br>你几点下班？ |
| **finish reading**<br>读完 | **I haven't finished reading it yet.**<br>我还没读完。 |
| **finish early**<br>提前完成 | **We finished early today.**<br>我们今天提前结束了。 |
| **finish on time**<br>按时完成 | **We need to finish on time.**<br>我们需要按时完成。 |
| **finish off**<br>完成最后部分；吃完 | **Let's finish off the last section.**<br>我们把最后一部分做完。 |

## 用法提醒

“读完”说 `finish reading`。最后以一个例子收尾，可以说 `finish with an example`。

`finish work` 在询问时间时常表示下班。

## 输出例句

**I want to finish this section before taking a break.**  
我想先完成这一部分再休息。

**It took me three days to finish reading the book.**  
我花了三天读完这本书。

**Starting is important, but learning how to finish things matters just as much.**  
开始很重要，但学会把事情完成同样重要。

# 6. complete

## 核心感觉

> **做完任务、流程或作品所需的步骤。**

## 语法特点

- **及物动词**：常接任务、表格、课程或流程。
- **被动表达**：`be completed` 表示某项工作已经完成或将在指定时间完成，具体取决于时态。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **complete a task**<br>完成任务 | **I completed the task yesterday.**<br>我昨天完成了任务。 |
| **complete a project**<br>完成项目 | **The team completed the project on time.**<br>团队按时完成了项目。 |
| **complete a form**<br>填完表格 | **Please complete this form.**<br>请填写完整这张表。 |
| **complete the process**<br>完成流程 | **You need to verify your email to complete the process.**<br>你需要验证邮箱才能完成流程。 |
| **be completed**<br>被完成 | **The work was completed in June.**<br>这项工作六月完成。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **successfully complete**<br>成功完成 | **She successfully completed the course.**<br>她成功完成了课程。 |
| **complete the setup**<br>完成设置 | **Follow the instructions to complete the setup.**<br>按照说明完成设置。 |
| **complete on time**<br>按时完成 | **The work was completed on time.**<br>工作按时完成了。 |
| **complete a course**<br>完成课程 | **He completed the course last month.**<br>他上个月完成了课程。 |
| **complete the final step**<br>完成最后一步 | **Complete the final step to activate your account.**<br>完成最后一步即可激活账户。 |

## 用法提醒

`finish the course` 与 `complete the course` 都可以表示修完课程，`complete` 常用于正式说明或强调完成规定步骤。

`The form is complete` 中的 `complete` 是形容词，表示表格已填完整。

## 输出例句

**I've completed the first version, but it still needs improvement.**  
我已经完成第一版，但还需要改进。

**You need to complete all the required steps.**  
你需要完成所有必要步骤。

**We completed the registration in less than five minutes.**  
我们不到五分钟就办完了登记手续。

# 7. manage

## 核心感觉

> **设法做成某事，或管理、应付某项工作或处境。**

## 语法特点

- **动作结构**：`manage to do` 表示成功做到了。
- **及物用法**：直接接管理或应付的对象。
- **不及物用法**：可单独说 `I can manage`，也可接 `without`。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **manage to do**<br>设法成功做到 | **I managed to finish on time.**<br>我总算按时完成了。 |
| **manage something**<br>管理 / 应付 | **Can you manage everything yourself?**<br>你一个人能应付所有事情吗？ |
| **manage a team**<br>管理团队 | **She manages a team of ten people.**<br>她管理一个十人团队。 |
| **manage without**<br>没有……也能应付 | **Can you manage without a car?**<br>没有车你能应付吗？ |
| **manage on + amount**<br>靠某笔钱应付生活 | **Can you manage on that salary?**<br>你靠那份薪水能应付日常开销吗？ |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **barely manage**<br>勉强做到 | **I barely managed to catch the train.**<br>我勉强赶上了火车。 |
| **finally manage**<br>最终做到 | **I finally managed to fix it.**<br>我终于把它修好了。 |
| **manage well**<br>应付得很好 | **She's managing very well.**<br>她应付得很好。 |
| **manage your time**<br>管理时间 | **You need to manage your time better.**<br>你需要更好地管理时间。 |
| **manage expectations**<br>管理预期 | **We need to manage expectations carefully.**<br>我们需要谨慎管理预期。 |

## 用法提醒

`I managed to catch the train` 表示最终赶上了。`I tried to catch the train` 表示尝试赶车，结果需要另说。

`manage without a car` 表示没有车也能应付。

## 输出例句

**I finally managed to explain the idea clearly.**  
我终于成功把这个想法解释清楚了。

**Even with very little time, we managed to finish the project.**  
即使时间很少，我们还是设法完成了项目。

**I don't know how, but somehow I managed to make it work.**  
我也不知道怎么做到的，但最后还是把它弄好了。

# 8. attempt

## 核心感觉

> **着手尝试一项有难度或结果尚不确定的行动。**

## 语法特点

- **及物动词**：直接接要尝试的任务，或接 `to do`。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **attempt to do**<br>尝试做某事 | **He attempted to open the door.**<br>他尝试打开门。 |
| **attempt something**<br>尝试某事 | **Don't attempt the climb alone.**<br>不要独自尝试攀登。 |
| **be attempted**<br>被尝试 | **The rescue was attempted twice before the weather improved.**<br>天气好转前，救援人员尝试了两次。 |
| **first attempt to do**<br>最初尝试做某事 | **The team first attempted to reach the village by road.**<br>团队最初尝试走公路到达村子。 |
| **attempt something without doing**<br>尝试做某事，同时避开另一种做法 | **She attempted the puzzle without looking at the clues.**<br>她试着在不看提示的情况下解谜。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **attempt a difficult task**<br>尝试一项困难任务 | **We attempted a difficult repair with only basic tools.**<br>我们仅用基本工具尝试了一项困难的维修。 |
| **attempt to solve**<br>尝试解决 | **They attempted to solve the issue manually.**<br>他们尝试手动解决这个问题。 |
| **attempt to escape**<br>试图逃跑 | **He attempted to escape.**<br>他试图逃跑。 |
| **attempt the climb**<br>尝试攀登 | **They attempted the climb early in the morning.**<br>他们一大早就开始尝试攀登。 |
| **never attempt something alone**<br>千万别独自尝试某事 | **Never attempt this jump alone.**<br>千万别独自尝试这个跳跃动作。 |

## 用法提醒

`attempt to do` 比 `try to do` 更正式。它说明采取了尝试，结果可用 `but failed` 或 `and succeeded` 补充。

`make an attempt` 中的 `attempt` 是名词。

## 输出例句

**I attempted to solve the problem without looking at the answer.**  
我尝试在不看答案的情况下解决这个问题。

**I attempted to restart the server, but it shut down again.**  
我试着重启服务器，但它又关机了。

**Nobody had attempted that route in winter before.**  
以前从来没有人尝试过在冬天走那条路线。

# 9. achieve

> **经过努力达到目标、标准或预期结果。**

| **achieve balance**<br>达到平衡 | **It's difficult to achieve a perfect balance.**<br>很难达到完美平衡。 |

## 高频搭配

| 搭配 | 例句 |
