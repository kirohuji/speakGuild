# 移动、位置与变化

## 阅读说明

- **及物动词（transitive verb）**：可以直接接宾语。  
  `I need more time.` → `more time` 是宾语。

- **不及物动词（intransitive verb）**：不直接接宾语，可以另接介词短语等成分。  
  `Something happened.` / `Listen to me.`

- **系动词（linking verb）**：接表语，说明主语的身份、性质或状态。  
  `She seems tired.` / `The sky turned dark.`

- **使役结构（causative construction）**：表示使、促使或允许某个动作发生。  
  `make someone do` / `let someone do` / `get someone to do`

- **宾语补足语（object complement）**：在宾语后补充说明宾语的状态、身份或动作。  
  `keep the door open` → `open` 说明门的状态。

- **双宾语结构（double-object construction）**：接两个宾语，通常先说接受者，再说给予的东西。  
  `She gave me a book.` → `me` 是间接宾语，`a book` 是直接宾语。

同一个动词可以有多种用法；以上分类的角度不同，也可以同时适用。

### 结构写法

#### 1. 占位符与符号

| 标记 | 含义 |
| --- | --- |
| `someone / something` | 可替换的人／事物 |
| `noun / adjective` | 名词／形容词 |
| `place / time` | 地点／时间 |
| `do / doing / done` | 动词原形／V-ing 形式／过去分词 |
| `+` | 连接成分，不写进实际句子 |
| `( )` | 该成分可以省略 |

#### 2. 结构示例

固定的介词、不定式标记等需要保留，占位符换成具体内容。

| 结构 | 实际表达 |
| --- | --- |
| `stay + adjective` | **stay calm**<br>保持冷静 |
| `arrive in + place` | **arrive in London**<br>抵达伦敦 |
| `lead someone to do` | **lead him to believe**<br>使他相信 |
| `return something to someone` | **return the key to her**<br>把钥匙还给她 |
| `appear (to be) + adjective` | **appear (to be) calm**<br>显得平静；`to be` 可以省略 |

# 1. go

## 核心感觉

> **前往某地，或朝某个方向、状态发展。**

## 语法特点

- **主要用作不及物动词**：地点常用 `to` 引出；`home / here / there / abroad` 前不加 `to`。
- **变化系动词用法**：接特定形容词，如 `wrong / bad / quiet`，说明主语的状态变化。
- **活动表达**：`go + V-ing` 常表示去进行运动、休闲等活动。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **go to + place**<br>去某地 | **I usually go to work by bus.**<br>我通常坐公交去上班。 |
| **go + home / there / abroad**<br>去家里、那里、国外等；这些词前通常不加 `to` | **I'm going home now.**<br>我现在要回家了。 |
| **go back**<br>回去 | **We should go back and check.**<br>我们应该回去检查一下。 |
| **go + adjective**<br>进入某种状态 | **Something must have gone wrong.**<br>肯定是哪里出问题了。 |
| **go + V-ing**<br>去进行某项活动 | **We went swimming after work.**<br>下班后我们去游泳了。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **go ahead**<br>继续；开始做 | **Go ahead. I'll catch up with you later.**<br>你先走，我之后跟上。 |
| **go through**<br>经历；检查；通过 | **I went through the report again.**<br>我又把报告检查了一遍。 |
| **go with**<br>与……搭配；和……一起去 | **This jacket goes well with those shoes.**<br>这件夹克和那双鞋很搭。 |
| **go on**<br>继续；发生 | **What's going on here?**<br>这里发生什么事了？ |
| **go without**<br>没有……也能过；缺少…… | **I can go without coffee for a few days.**<br>我几天不喝咖啡也没问题。 |

## 用法提醒

`go + adjective` 有搭配限制：常说 `go wrong / go bad`，表达“变累”通常用 `get tired`。

`go` 表示前往某处，本身不保证已经到达。过去式 `went`，过去分词 `gone`。

## 输出例句

**I'm going to the supermarket after work.**  
我下班后要去超市。

**The plan didn't go as expected.**  
计划没有像预期那样进行。

**I think we'd better go back.**  
我觉得我们最好回去。

# 2. come

## 核心感觉

> **朝说话者、听话者，或谈话中的参照点移动。**

## 语法特点

- **主要用作不及物动词**：地点常用 `to` 引出，来源用 `from` 引出。
- **方向表达**：`come here / home / back / in` 中，方向由地点副词或小品词补充。
- **状态变化表达**：可接特定形容词，如 `come true / come loose`。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **come here**<br>来到这里 | **Come here for a second.**<br>过来一下。 |
| **come to + place**<br>来到某地 | **Are you coming to the office tomorrow?**<br>你明天来办公室吗？ |
| **come from + place**<br>来自某地；从某地来 | **Where did you come from?**<br>你从哪里来的？ |
| **come over**<br>过来一趟 | **Come over when you have time.**<br>你有空过来一趟。 |
| **come with someone**<br>和某人一起过来 | **Do you want to come with us?**<br>你想和我们一起去吗？ |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **come up**<br>出现；被提出；向上来 | **A new problem came up this morning.**<br>今天早上出现了一个新问题。 |
| **come out**<br>出来；出版；结果呈现 | **The results came out yesterday.**<br>结果昨天出来了。 |
| **come across**<br>偶然遇到；给人某种印象 | **I came across an interesting article.**<br>我偶然看到了一篇有意思的文章。 |
| **come along**<br>一起过来；进展 | **How's the project coming along?**<br>项目进展得怎么样？ |
| **come to mind**<br>想到 | **Nothing came to mind at first.**<br>一开始我什么也没想到。 |

## 用法提醒

对方叫你过去时，可以回答 **I’m coming.**（我这就来。）这里以对方的位置为参照点。

`come with us` 常译为“和我们一起去”。过去式 `came`，过去分词 `come`。

## 输出例句

**Come in and have a seat.**  
进来坐吧。

**I'll come over after dinner.**  
我吃完饭后过去找你。

**The answer finally came to me.**  
我最后终于想到了答案。

# 3. move

## 核心感觉

> **移动、挪动，或从一个位置、阶段转到另一个。**

## 语法特点

- **不及物用法**：主语自己移动，也可表示搬家。
- **及物用法**：直接接被移动的东西，如 `move the chair`。
- **地点与阶段**：`to / into / from` 等说明去向或起点；`move on to` 表示继续下一项。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **move to + place**<br>搬到、移动到某地 | **She moved to Hangzhou last year.**<br>她去年搬到了杭州。 |
| **move + object**<br>移动某物 | **Can you move the chair a little?**<br>你能把椅子挪一下吗？ |
| **move from A to B**<br>从一个位置移动到另一个位置 | **We moved from the city to the suburbs.**<br>我们从市区搬到了郊区。 |
| **move on**<br>继续往下；进入下一阶段 | **Let's move on to the next question.**<br>我们继续下一个问题吧。 |
| **move forward**<br>向前推进；取得进展 | **We need to move forward with the plan.**<br>我们需要继续推进这个计划。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **move house**<br>搬家 | **We're moving house next month.**<br>我们下个月搬家。 |
| **move away**<br>搬走；离开 | **He moved away after graduation.**<br>他毕业后搬走了。 |
| **move in / out**<br>搬进来 / 搬出去 | **They moved in last weekend.**<br>他们上周末搬进来了。 |
| **move toward(s)**<br>向……移动；趋向 | **The discussion is moving towards a decision.**<br>讨论正逐渐走向一个决定。 |
| **move something up to + time**<br>把某事提前到某个时间 | **The meeting has been moved up to Monday.**<br>会议被提前到周一了。 |

## 用法提醒

“把椅子挪一下”说 `move the chair`；“搬到某地”说 `move to + place`。

`move house` 常见于英式英语；美式英语常直接用 `move` 表示搬家。

## 输出例句

**Could you move your bag?**  
你能把你的包挪一下吗？

**We're moving to a new office next month.**  
我们下个月要搬到新办公室。

**Let's move on. We don't have much time.**  
我们继续吧，时间不多了。

# 4. arrive

## 核心感觉

> **抵达目的地，或经过过程后得出结果。**

## 语法特点

- **不及物动词**：地点通过介词短语补充，不直接作宾语。
- **地点介词**：具体到达点通常用 `at`；城市、国家通常用 `in`。
- **抽象结果**：`arrive at + decision / conclusion` 表示经过考虑得出结果。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **arrive at + place**<br>到达较具体的地点 | **We arrived at the station just in time.**<br>我们刚好及时赶到车站。 |
| **arrive in + city / country**<br>到达城市、国家等较大范围 | **She arrived in London yesterday.**<br>她昨天抵达伦敦。 |
| **arrive home**<br>到家；回到家 | **What time did you arrive home?**<br>你几点到家的？ |
| **arrive from + place**<br>从某地抵达；来自某地 | **The train has just arrived from Beijing.**<br>这趟火车刚从北京开来。 |
| **arrive early / late / safely**<br>早到、迟到、安全抵达 | **Let me know when you arrive safely.**<br>你安全到了告诉我一声。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **arrive at a decision**<br>作出决定；达成决定 | **We finally arrived at a decision.**<br>我们最终作出了决定。 |
| **arrive at an agreement**<br>达成协议 | **They arrived at an agreement after hours of discussion.**<br>他们讨论了几个小时后达成了协议。 |
| **arrive on time**<br>准时到达 | **I hope we arrive on time.**<br>希望我们能准时到。 |
| **arrive late**<br>迟到；晚到 | **Sorry I arrived late.**<br>抱歉我来晚了。 |
| **arrive at a conclusion**<br>得出结论 | **How did you arrive at that conclusion?**<br>你是怎么得出那个结论的？ |

## 用法提醒

说 `arrive at the station / arrive in London`，不用 `arrive to` 表示抵达。`arrive home / here / there` 不加介词。

表达“抱歉来晚了”可以说 **Sorry I’m late.** 或 **Sorry I arrived late.**

## 输出例句

**We arrived at the hotel around midnight.**  
我们大约半夜到达酒店。

**What time did you arrive home?**  
你几点到家的？

**We haven't arrived at a final decision yet.**  
我们还没有作出最终决定。

# 5. reach

## 核心感觉

> **触及、到达某个地点、水平或目标。**

## 语法特点

- **及物用法**：直接接地点、目标、水平或要联系的人。
- **不及物用法**：`reach for something` 表示伸手去拿；`reach out to someone` 表示主动联系或提供帮助。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **reach + place**<br>到达某地 | **We reached the station just before six.**<br>我们六点前刚好到了车站。 |
| **reach + person**<br>联系到某人；找到某人 | **You can reach me by email.**<br>你可以通过邮件联系到我。 |
| **reach + level / age**<br>达到某个水平、年龄 | **The temperature reached 35 degrees.**<br>气温达到了35度。 |
| **reach + goal**<br>达到目标 | **We finally reached our goal.**<br>我们终于达成了目标。 |
| **reach an agreement**<br>达成协议 | **The two sides reached an agreement.**<br>双方达成了协议。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **reach out to**<br>主动联系；向……伸出援手 | **I'll reach out to him tomorrow.**<br>我明天会联系他。 |
| **reach for**<br>伸手去拿；努力争取 | **She reached for the book on the shelf.**<br>她伸手去拿架子上的书。 |
| **reach a conclusion**<br>得出结论 | **We reached the same conclusion.**<br>我们得出了相同的结论。 |
| **reach a point**<br>达到某个阶段或程度 | **I've reached the point where I need a break.**<br>我已经到了需要休息一下的程度。 |
| **reach a target**<br>达到目标 | **We reached our sales target ahead of schedule.**<br>我们提前完成了销售目标。 |

## 用法提醒

到达车站说 `reach the station`，不加 `to / at`。

`reach for the cup` 只说明伸手去拿，不保证已经拿到。`within reach` 中的 `reach` 是名词。

## 输出例句

**We reached the village just before dark.**  
我们天黑前刚好到达了村子。

**The temperature reached 40 degrees.**  
气温达到了40度。

**I couldn't reach him all day.**  
我一整天都联系不上他。

# 6. enter

## 核心感觉

> **进入某个空间、活动、阶段，或把信息输入其中。**

## 语法特点

- **主要用作及物动词**：直接接进入的地点、参加的比赛或输入的信息。
- **也可不带宾语**：如 `Please knock before you enter`，表示进入。
- **固定介词结构**：`enter into` 常用于协议、谈判等正式语境。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **enter + place**<br>进入某地 | **She entered the room without saying a word.**<br>她一言不发地走进了房间。 |
| **enter + building / area**<br>进入建筑或区域 | **Visitors must show their tickets before entering the building.**<br>访客进入大楼前必须出示票。 |
| **enter + competition**<br>参加比赛 | **He entered the competition last year.**<br>他去年参加了这项比赛。 |
| **enter + stage / period**<br>进入阶段、时期 | **The project has entered a new stage.**<br>项目进入了一个新阶段。 |
| **enter into + agreement / discussion**<br>进入某种抽象关系或正式活动 | **The companies entered into an agreement.**<br>两家公司签订了协议。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **enter the market**<br>进入市场 | **Several new companies have entered the market.**<br>几家新公司进入了市场。 |
| **enter a room**<br>进入房间 | **He entered the room quietly.**<br>他安静地走进了房间。 |
| **enter your name**<br>填写、输入姓名 | **Please enter your name below.**<br>请在下面输入你的姓名。 |
| **enter a phase**<br>进入某个阶段 | **The economy is entering a difficult phase.**<br>经济正进入一个困难阶段。 |
| **enter into**<br>正式开始某种关系、协议、讨论等 | **They entered into negotiations.**<br>他们开始了谈判。 |

## 用法提醒

进入房间说 `enter the room` 或 `go into the room`。

`enter into an agreement` 表示订立协议；普通地点表达优先掌握 `enter + place`。

## 输出例句

**Please knock before you enter the room.**  
进房间前请先敲门。

**The company is entering a new stage of growth.**  
这家公司正进入新的增长阶段。

**She entered the competition without much preparation.**  
她没怎么准备就参加了比赛。

# 7. exit

## 核心感觉

> **从某个空间、道路或系统中离开、退出。**

## 语法特点

- **及物用法**：直接接离开的建筑、道路或退出的程序。
- **不及物用法**：可单独表示离开、退出，也可接 `through / via` 等说明出口或路径。
- **语体特点**：常见于指示、说明和技术语境。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **exit + place**<br>离开某地 | **Please exit the building through the rear door.**<br>请从后门离开大楼。 |
| **exit + highway**<br>驶离高速公路 | **We exited the highway at the next junction.**<br>我们在下一个路口驶离了高速公路。 |
| **exit + application / program**<br>退出应用、程序 | **Save your work before you exit the program.**<br>退出程序前保存好你的工作。 |
| **exit through / via + place**<br>经由某处离开 | **Everyone exited through the side door.**<br>所有人都从侧门离开了。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **exit the building**<br>离开大楼 | **Visitors must exit the building by six.**<br>访客必须在六点前离开大楼。 |
| **exit the app**<br>退出应用 | **Tap here to exit the app.**<br>点这里退出应用。 |
| **exit the market**<br>退出市场 | **The company decided to exit the market.**<br>公司决定退出市场。 |
| **exit safely**<br>安全撤离 | **Everyone managed to exit safely.**<br>所有人都成功安全撤离了。 |

## 用法提醒

日常说“我得走了”常用 `I need to leave`。

`an emergency exit`（紧急出口）中的 `exit` 是名词；`exit the building` 中才是动词。

## 输出例句

**There's an emergency exit at the end of the hall.**  
走廊尽头有一个紧急出口。

**Click the button to exit the program.**  
点击按钮退出程序。

**We exited the highway at the next junction.**  
我们在下一个路口驶离了高速公路。

# 8. return

## 核心感觉

> **回到原来的地点、状态或活动，或把东西归还。**

## 语法特点

- **不及物用法**：`return to` 表示回到地点、话题或活动；`return home` 不加 `to`。
- **及物用法**：直接接归还的东西，接收者可用 `to` 引出。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **return to + place**<br>返回某地 | **She returned to the office after lunch.**<br>她午饭后回到了办公室。 |
| **return home**<br>回家 | **He returned home late that night.**<br>那天晚上他很晚才回家。 |
| **return to + state**<br>恢复到某种状态 | **The system returned to normal.**<br>系统恢复正常了。 |
| **return + object**<br>归还某物 | **I need to return these books.**<br>我需要归还这些书。 |
| **return to + topic**<br>回到某个话题 | **Let's return to the main question.**<br>我们回到主要问题上来。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **return the favor**<br>回报某人的帮助 | **I'll return the favor someday.**<br>以后我会回报你的。 |
| **return a call**<br>回电话 | **I'll return your call later.**<br>我晚点给你回电话。 |
| **return an item**<br>退货；归还物品 | **You can return the item within thirty days.**<br>你可以在三十天内退货。 |
| **return to normal**<br>恢复正常 | **Things slowly returned to normal.**<br>事情慢慢恢复了正常。 |
| **return to work**<br>恢复工作；回去上班 | **She returned to work on Monday.**<br>她周一回去上班了。 |

## 用法提醒

`return the book to her` 是把书还给她；`return to the library` 是回到图书馆。

`return` 已含“回”的意思，通常不用再加 `back`。`in return` 是介词短语。

## 输出例句

**I'll return to the office after lunch.**  
我午饭后会回办公室。

**Things have finally returned to normal.**  
事情终于恢复正常了。

**Could you return the key when you're done?**  
你用完后能把钥匙还回来吗？

# 9. follow

## 核心感觉

> **跟随某人、路线，或按照已有的信息、规则行动。**

## 语法特点

- **主要用作及物动词**：直接接跟随的人、路线，或遵循的说明和规则。
- **理解用法**：接解释、故事等，表示跟得上内容或逻辑。
- **不及物用法**：可以不带宾语，如 `You go first. I’ll follow`。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **follow someone**<br>跟着某人 | **Follow me. I'll show you the way.**<br>跟我来，我给你带路。 |
| **follow a road / route**<br>沿着道路、路线走 | **Follow this road for about two kilometers.**<br>沿这条路走大约两公里。 |
| **follow instructions**<br>按照说明、指示做 | **Please follow the instructions carefully.**<br>请仔细按照说明操作。 |
