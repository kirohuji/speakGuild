# 变化、趋势与结果

## 阅读说明

- **及物动词（transitive verb）**：可以直接接宾语。  
  `I need more time.` → `more time` 是宾语。

- **不及物动词（intransitive verb）**：不直接接宾语，可以另接介词短语等成分。  
  `Something happened.` / `Listen to me.`

- **系动词（linking verb）**：接表语，说明主语的身份、性质或状态。  
  `She seems tired.` / `The sky turned dark.`

- **使役结构（causative construction）**：表示使、促使或允许某个动作发生。  
  `make someone do` / `let someone do` / `get someone to do`

- **宾语补足语（object complement）**：在宾语后补充说明宾语的状态、身份或动作。  
  `keep the door open` → `open` 说明门的状态。

- **双宾语结构（double-object construction）**：接两个宾语，通常先说接受者，再说给予的东西。  
  `She gave me a book.` → `me` 是间接宾语，`a book` 是直接宾语。

同一个动词可以有多种用法；以上分类的角度不同，也可以同时适用。

### 结构写法

#### 1. 占位符与符号

| 标记 | 含义 |
| --- | --- |
| `someone / something` | 可替换的人／事物 |
| `noun / adjective` | 名词／形容词 |
| `place / time` | 地点／时间 |
| `clause / wh-clause` | 从句／由 what、why、how 等疑问词引导的从句 |
| `do / doing / done` | 动词原形／V-ing 形式／过去分词 |
| `+` | 连接成分，不写进实际句子 |
| `( )` | 该成分可以省略 |

#### 2. 结构示例

把占位符换成具体内容，保留固定介词和不定式标记。

| 结构 | 实际表达 |
| --- | --- |
| `increase by + amount` | **increase by 20%**<br>增加了 20% |
| `reduce something to + level` | **reduce the number to five**<br>把数量减少到五个 |
| `adapt to doing` | **adapt to working remotely**<br>适应远程工作 |
| `result from + cause` | **result from a wiring fault**<br>源于线路故障 |
| `indicate (that) + clause` | **indicate (that) demand is rising**<br>表明需求在增长，`that` 可以省略 |

# 1. increase

## 核心感觉

> **数量或程度上升，也可表示使某项数值上升。**

## 语法特点

- **及物用法**：接需要提高的量，如 `increase capacity`。
- **不及物用法**：变化的量作主语，`by` 说明增量，`to` 说明终点。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **something increases**<br>某物增加 | **Demand increased rapidly.**<br>需求迅速增加。 |
| **increase something**<br>提高某物 | **We need to increase capacity.**<br>我们需要提高容量。 |
| **increase from A to B**<br>从A增加到B | **Sales increased from 100 to 150.**<br>销量从100增加到150。 |
| **increase by + amount**<br>增加了多少 | **Costs increased by 20%.**<br>成本增加了20%。 |
| **increase to + level**<br>增加到某水平 | **The number increased to 500.**<br>数量增加到了500。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **increase significantly**<br>显著增加 | **Usage increased significantly after the update.**<br>更新后使用量显著增加。 |
| **gradually increase**<br>逐渐增加 | **The difficulty gradually increases.**<br>难度逐渐增加。 |
| **increase efficiency**<br>提高效率 | **Automation can increase efficiency.**<br>自动化可以提高效率。 |
| **increase the risk of**<br>增加……风险 | **Poor maintenance increases the risk of failure.**<br>维护不当会增加故障风险。 |
| **increase production**<br>提高产量 | **The factory increased production to meet demand.**<br>工厂提高了产量来满足需求。 |

## 用法提醒

从 100 增到 120，可以说 `increase by 20`、`increase by 20%` 或 `increase to 120`，分别说增量、增幅和最终值。

## 输出例句

**My confidence increased as I used English more often.**  
随着我更频繁地使用英语，我的信心提高了。

**We need to increase capacity without adding another server.**  
我们需要在不增加服务器的情况下提高容量。

**The number of users increased steadily over several months.**  
几个月里，用户数量持续稳定增长。

# 2. decrease

## 核心感觉

> **数量或程度下降，也可表示使某项数值下降。**

## 语法特点

- **不及物用法**：下降的量作主语，可接 `by / to / from...to...`。
- **及物用法**：可直接接被降低的量，如 `decrease the temperature`。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **something decreases**<br>某物减少 | **Demand decreased slightly.**<br>需求略有下降。 |
| **decrease something**<br>降低某物 | **The change decreased processing time.**<br>这个改变降低了处理时间。 |
| **decrease from A to B**<br>从A下降到B | **Errors decreased from 50 to 20.**<br>错误数量从50下降到20。 |
| **decrease by + amount**<br>下降了多少 | **Costs decreased by 10%.**<br>成本下降了10%。 |
| **decrease to + level**<br>降低到 | **The rate decreased to 5%.**<br>比率下降到5%。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **significantly decrease**<br>显著下降 | **Response time decreased significantly.**<br>响应时间显著下降。 |
| **gradually decrease**<br>逐步降低 | **The noise gradually decreased.**<br>噪音逐渐减弱。 |
| **decrease the pressure**<br>降低压力 | **The valve decreases the pressure in the pipe.**<br>这个阀门可以降低管道内的压力。 |
| **decrease over time**<br>随时间下降 | **The effect decreases over time.**<br>效果会随时间逐渐减弱。 |
| **decrease slightly**<br>略有减少 | **The number of complaints decreased slightly.**<br>投诉数量略有减少。 |

## 用法提醒

**The temperature decreased.** 描述温度下降。**We decreased the temperature.** 说明是我们降低了温度。

## 输出例句

**The number of errors decreased after we simplified the process.**  
简化流程以后，错误数量下降了。

**Regular practice can decrease the amount of time you need to form a sentence.**  
规律练习可以减少你组织句子所需要的时间。

**Performance usually decreases when the system runs out of memory.**  
系统内存不足时，性能通常会下降。

# 3. reduce

## 核心感觉

> **使数量、程度、风险或负担变小。**

## 语法特点

- **常用及物结构**：接被减少的事物，如 `reduce costs`。
- **幅度和终点**：`reduce something by...` 说明减少了多少，`reduce something to...` 说明减到多少。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **reduce something**<br>减少某物 | **We need to reduce costs.**<br>我们需要降低成本。 |
| **reduce something by**<br>减少多少 | **The change reduced processing time by 30%.**<br>这个改变把处理时间降低了30%。 |
| **reduce something to**<br>降低到 | **We reduced the number to five.**<br>我们把数量减少到了五个。 |
| **reduce the risk of**<br>降低……风险 | **Backups reduce the risk of data loss.**<br>备份会降低数据丢失风险。 |
| **be reduced**<br>被减少 | **The workload has been reduced.**<br>工作量已经减少。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **significantly reduce**<br>显著降低 | **This significantly reduces memory usage.**<br>这会显著降低内存使用量。 |
| **reduce costs**<br>降低成本 | **We need to reduce costs without reducing quality.**<br>我们需要在不降低质量的情况下削减成本。 |
| **reduce complexity**<br>降低复杂度 | **The new design reduces complexity.**<br>新设计降低了复杂度。 |
| **reduce stress**<br>减轻压力 | **Exercise may help reduce stress.**<br>运动可能有助于减轻压力。 |
| **reduce dependence on**<br>减少对……的依赖 | **The system reduces dependence on manual work.**<br>这个系统减少了对人工操作的依赖。 |

## 用法提醒

**Costs decreased.** 描述成本下降。**We reduced costs.** 说明我们采取了行动来降低成本。

## 输出例句

**The goal is to reduce unnecessary steps without removing useful information.**  
目标是减少不必要的步骤，同时保留有用信息。

**Practicing common structures can reduce hesitation when speaking.**  
练习常用结构可以减少说话时的犹豫。

**We reduced the processing time from ten seconds to three.**  
我们把处理时间从十秒降低到了三秒。

# 4. expand

## 核心感觉

> **扩大空间、规模或覆盖范围，也可进一步展开说明。**

## 语法特点

- **及物用法**：接业务、服务、范围等。
- **不及物用法**：可用 `into` 引出新领域，用 `on` 引出要详谈的内容。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **something expands**<br>某物扩大 | **The market is expanding rapidly.**<br>市场正在快速扩大。 |
| **expand something**<br>扩大某物 | **The company plans to expand its services.**<br>公司计划扩大服务范围。 |
| **expand into**<br>扩展到 | **The business expanded into Asia.**<br>业务扩展到了亚洲。 |
| **expand from A to B**<br>从A扩大到B | **The team expanded from five people to twenty.**<br>团队从五人扩大到二十人。 |
| **expand on something**<br>进一步展开说明 | **Could you expand on that point?**<br>你能进一步展开说明那个观点吗？ |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **rapidly expand**<br>快速扩张 | **The company expanded rapidly.**<br>公司快速扩张。 |
| **expand capacity**<br>扩大容量 | **We need to expand storage capacity.**<br>我们需要扩大存储容量。 |
| **expand knowledge**<br>扩展知识 | **Reading helps expand your knowledge.**<br>阅读有助于扩展知识。 |
| **expand the range of**<br>扩大……范围 | **The update expands the range of supported formats.**<br>更新扩大了支持格式的范围。 |
| **expand further**<br>进一步扩大 | **We may expand further next year.**<br>明年我们可能进一步扩张。 |

## 用法提醒

**expand into a new market** 是进入新市场。**expand on that point** 是进一步说明那个观点。

## 输出例句

**Once the basic structure works, we can expand it gradually.**  
基础结构可行以后，我们可以逐步扩展。

**Reading widely helps expand the range of ideas you can express.**  
广泛阅读可以扩展你能够表达的想法范围。

**The project expanded far beyond what we had originally planned.**  
这个项目最终扩展得远远超过了最初规划。

# 5. shrink

## 核心感觉

> **尺寸、体积或规模变小，也可使某物缩小。**

## 语法特点

- **及物与不及物用法**：缩小的东西可作宾语或主语。
- **变化结构**：可用 `by / from...to...` 说明变化幅度或范围。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **something shrinks**<br>某物缩小 | **The market is shrinking.**<br>市场正在萎缩。 |
| **shrink something**<br>使某物缩小或缩水 | **The wash shrank my sweater.**<br>这次洗涤把我的毛衣洗缩水了。 |
| **shrink from A to B**<br>从A缩小到B | **The team shrank from twenty people to twelve.**<br>团队从二十人缩减到十二人。 |
| **shrink by + amount**<br>缩小了多少 | **The economy shrank by 2%.**<br>经济萎缩了2%。 |
| **shrink in the wash**<br>洗后缩水 | **These jeans may shrink in the wash.**<br>这条牛仔裤洗后可能会缩水。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **gradually shrink**<br>逐渐缩小 | **The gap gradually shrank.**<br>差距逐渐缩小。 |
| **shrink as demand falls**<br>随需求下降而萎缩 | **The market shrank as demand fell.**<br>随着需求下降，市场萎缩了。 |
| **shrink the gap**<br>缩小差距 | **The change helped shrink the gap.**<br>这个改变帮助缩小了差距。 |
| **shrink dramatically**<br>大幅缩小 | **The available space shrank dramatically.**<br>可用空间大幅减少。 |
| **shrink back**<br>畏缩后退 | **He shrank back when the dog approached.**<br>狗靠近时，他畏缩地向后退。 |

## 用法提醒

**The sweater shrank.** 是毛衣缩水了。**The wash shrank the sweater.** 是这次洗涤让毛衣缩水了。过去式常用 `shrank`，过去分词常用 `shrunk`。

## 输出例句

**The difference between the two versions gradually shrank.**  
两个版本之间的差距逐渐缩小。

**As the project grew, my free time seemed to shrink.**  
随着项目扩大，我的空闲时间似乎越来越少。

**We managed to shrink the file without noticeably reducing image quality.**  
我们成功缩小了文件，同时没有明显降低图像质量。

# 6. decline

> **数量、质量或状况下降，也可表示婉拒。**

## 语法特点

- **不及物用法**：下降义常用 `by / to / in` 说明幅度、终点或方面。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **something declines**<br>某物下降 | **Sales declined last year.**<br>去年销量下降。 |
| **decline by**<br>下降多少 | **Revenue declined by 8%.**<br>收入下降了8%。 |
| **decline from A to B**<br>从A下降到B | **The rate declined from 12% to 7%.**<br>比率从12%下降到7%。 |
| **decline over time**<br>随时间衰退 | **Performance declined over time.**<br>性能随时间下降。 |
| **begin to decline**<br>开始下降 | **Demand began to decline.**<br>需求开始下降。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **steadily decline**<br>稳步下降 | **The number steadily declined.**<br>数量持续下降。 |
| **decline sharply**<br>急剧下降 | **Demand declined sharply in June.**<br>六月份的需求急剧下降。 |
| **gradually decline**<br>逐步下降 | **Attendance gradually declined after the first week.**<br>第一周过后，出席人数逐步减少。 |
| **decline an invitation**<br>谢绝邀请 | **She politely declined the invitation.**<br>她礼貌地谢绝了邀请。 |
| **decline in value**<br>价值下降 | **The asset declined in value.**<br>这个资产价值下降了。 |

## 用法提醒

**Sales declined.** 是销量下降。**She declined the invitation.** 是她谢绝了邀请。

## 输出例句

**My concentration starts to decline late in the afternoon.**  
下午比较晚的时候，我的专注力会开始下降。

**User engagement declined after the initial launch.**  
首次发布以后，用户参与度下降了。

**If a skill isn't used for a long time, performance may gradually decline.**  
一项技能如果长期不用，表现可能会逐渐下降。

# 7. vary

## 核心感觉

> **因对象、条件或时间而不同，也可主动改变做法。**

## 语法特点

- **不及物用法**：可用 `by / in / depending on` 说明差异。
- **及物用法**：接主动改变的内容，如 `vary your routine`。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **vary from A to B**<br>从A到B不等 | **Prices vary from $10 to $50.**<br>价格从10美元到50美元不等。 |
| **vary between A and B**<br>在A和B之间变化 | **Temperatures vary between 20 and 30 degrees.**<br>温度在20到30度之间变化。 |
| **vary depending on**<br>根据……而不同 | **Results vary depending on the data.**<br>结果会根据数据不同而变化。 |
| **vary by + category**<br>因类别而不同 | **Usage varies by age group.**<br>使用情况因年龄组而异。 |
| **vary something**<br>改变某种做法或内容 | **I vary my routine to keep it interesting.**<br>我会变换日常安排，让它更有意思。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **vary considerably**<br>差异相当大 | **Costs vary considerably.**<br>成本差异很大。 |
| **vary widely**<br>差异广泛 | **Opinions vary widely.**<br>观点差异很大。 |
| **vary over time**<br>随时间变化 | **Performance varies over time.**<br>性能会随时间变化。 |
| **vary according to**<br>根据……而变化 | **The price varies according to demand.**<br>价格随需求而变化。 |
| **vary in size**<br>大小不同 | **The files vary in size.**<br>文件大小不一。 |

## 用法提醒

**Prices vary by location.** 表示各地价格不同。**Prices fluctuate throughout the day.** 表示价格在一天内上下波动。

## 输出例句

**The amount of time people need to learn a skill varies greatly.**  
人们学会一项技能所需要的时间差异很大。

**Results may vary depending on how often you practice.**  
结果可能会根据练习频率而有所不同。

**The meaning of the expression can vary slightly by context.**  
这个表达的意思会根据语境有轻微变化。

# 9. transform

> **使外观、性质或用途发生明显转变。**

## 语法特点

- **及物用法**：`transform something into something` 说明把某物变成什么。

| **transform the way...**<br>改变……方式 | **AI is transforming the way people work.**<br>AI 正在改变人们工作的方式。 |
| **completely transform**<br>完全改变 | **The experience completely transformed him.**<br>这段经历彻底改变了他。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **radically transform**<br>彻底改变 | **The technology radically transformed the process.**<br>这项技术彻底改变了流程。 |
| **transform an industry**<br>彻底改变一个行业 | **Online booking transformed the travel industry.**<br>在线预订彻底改变了旅游业。 |

# 几组容易混淆的结构

| 结构 | 侧重点 | 例句 |
| --- | --- | --- |
| **increase / decrease / reduce** | 上升／下降／使某项数值下降。**decrease** 也可以直接接宾语 | **Demand increased, stock levels decreased, and we reduced the number of items each customer could buy.**<br>需求上升了，库存下降了，我们也减少了每位顾客可购买的件数。 |
| **increase by / increase to / increase from A to B** | 分别说增加多少／增加到多少／从多少增加到多少。**decrease** 也可以用这三种结构 | **Attendance increased by 20, from 100 to 120.**<br>到场人数增加了 20 人，从 100 人增至 120 人。 |
| **expand / shrink / decline** | **expand** 和 **shrink** 常描述规模或范围扩大、缩小。**decline** 常描述销量、参与度或质量下降 | **The company expanded its delivery area even as demand declined and its customer base shrank.**<br>虽然需求下降、客户群缩小，公司还是扩大了配送范围。 |
| **vary / fluctuate** | **vary** 可以描述不同对象之间的差异，也可以描述随时间变化。**fluctuate** 强调同一数值随时间上下波动 | **Prices vary by store, and they fluctuate throughout the year.**<br>各家店的价格不同，价格一年中也会上下波动。 |
| **alter / transform** | **alter** 指改动原有的细节、形状或安排。**transform** 常指明显改变事物的形态、用途或运行方式 | **We altered the layout and transformed the old office into a classroom.**<br>我们调整了布局，把旧办公室改成了教室。 |
| **adapt to / adapt something for** | **adapt to** 表示适应变化。**adapt something for** 表示为特定用途改造某物 | **We adapted to remote work and adapted our training materials for online use.**<br>我们适应了远程工作，也改编了培训材料，方便在线使用。 |
| **recover / improve / worsen** | **recover** 强调受挫后回升或恢复。**improve** 和 **worsen** 分别表示变好和变差 | **Sales recovered after a slow month, delivery times improved, and customer service worsened.**<br>经历了一个销售淡月后，销量回升了，配送变快了，客服质量却变差了。 |
| **strengthen / weaken** | 可以说事物自身变强或变弱，也可以说某个因素使它变强或变弱 | **The first test strengthened our case, but the second weakened it.**<br>第一次测试让我们的论点更有说服力，第二次却削弱了它。 |
| **stabilize at / fluctuate between** | 在某个水平稳定下来／在两个数值之间来回波动 | **Attendance fluctuated between 30 and 50 before stabilizing at 45.**<br>到场人数曾在 30 到 50 人之间波动，后来稳定在 45 人。 |
| **double / triple** | 增至原来的两倍／三倍。从 100 到 200 是增加 100%，从 100 到 300 是增加 200% | **Sign-ups doubled from 100 to 200 in May and tripled from 200 to 600 in June.**<br>报名人数在 5 月从 100 人增至 200 人，6 月又从 200 人增至 600 人。 |
| **contribute to / cause / result in** | **contribute to** 表示是促成因素之一。**cause** 和 **result in** 把主语说成导致结果的原因 | **Heavy traffic contributed to the delay, and a flat tire caused the driver to stop. The stop resulted in a second delay.**<br>交通拥堵是延误的原因之一，轮胎漏气又迫使司机停车，造成了第二次延误。 |

| **depend on / determine** | **depend on** 把依赖的条件放在后面。**determine** 可以让决定结果的条件作主语 | **The route depends on the weather. The weather determines which route we take.**<br>路线取决于天气。天气决定我们走哪条路线。 |
| **reflect / indicate** | **reflect** 强调某物体现了什么。**indicate** 强调证据、数据或信号指向什么 | **The new schedule reflects students’ preferences, and the attendance figures indicate that more people can now make it.**<br>新课表体现了学生的偏好，到场人数也显示现在有更多人能来上课。 |

# 综合对话

**A:** How did attendance change after we added an evening class?

我们加开晚间课以后，到场人数有什么变化？

**B:** It doubled from 30 to 60 in the first week, then fluctuated for a few weeks.

第一周从 30 人增加到 60 人，翻了一倍，之后又波动了几周。

**A:** What happened after we moved the class to a later time?

把上课时间往后推以后呢？

**B:** Attendance declined and eventually stabilized at around 45.

到场人数下降了，最后稳定在 45 人左右。

**A:** Do we know what caused the decline?

我们知道人数下降的原因吗？

**B:** The survey indicates that the later start may have contributed to it. Some students said they couldn’t get home easily after class.

问卷显示，开课时间推迟可能是其中一个原因。有些学员说，下课后回家不太方便。

**A:** Could we move the class back an hour?

我们能把课调回去，提前一个小时开始吗？

**B:** That depends on when the room is free. An earlier start could reduce the number of people who miss class because of the last bus.

这取决于教室什么时候空出来。早点开始的话，可能会少一些人因为要赶末班车而缺课。

**A:** Let’s check the room schedule and see whether attendance recovers after the change.

我们先查查教室的使用时间，再看看改完以后到场人数会不会回升。
