# 选择和意图

## 阅读说明

- **及物动词（transitive verb）**：可以直接接宾语。  
  `I need more time.` → `more time` 是宾语。

- **不及物动词（intransitive verb）**：不直接接宾语，可以另接介词短语等成分。  
  `Something happened.` / `Listen to me.`

- **系动词（linking verb）**：接表语，说明主语的身份、性质或状态。  
  `She seems tired.` / `The sky turned dark.`

- **使役结构（causative construction）**：表示使、促使或允许某个动作发生。  
  `make someone do` / `let someone do` / `get someone to do`

- **宾语补足语（object complement）**：在宾语后补充说明宾语的状态、身份或动作。  
  `keep the door open` → `open` 说明门的状态。

- **双宾语结构（double-object construction）**：接两个宾语，通常先说接受者，再说给予的东西。  
  `She gave me a book.` → `me` 是间接宾语，`a book` 是直接宾语。

同一个动词可以有多种用法；以上分类的角度不同，也可以同时适用。

### 结构写法

#### 1. 占位符与符号

| 标记 | 含义 |
| --- | --- |
| `someone / something` | 可替换的人／事物 |
| `noun / adjective` | 名词／形容词 |
| `place / time` | 地点／时间 |
| `clause / wh-clause` | 从句／由 what、why、how 等疑问词引导的从句 |
| `do / doing / done` | 动词原形／V-ing 形式／过去分词 |
| `+` | 连接成分，不写进实际句子 |
| `( )` | 该成分可以省略 |

#### 2. 结构示例

把占位符换成具体内容，保留固定介词和不定式标记。

| 结构 | 实际表达 |
| --- | --- |
| `choose between A and B` | **choose between two offers**<br>在两个邀约之间作选择 |
| `prefer doing` | **prefer working alone**<br>更喜欢独自工作 |
| `allow someone to do` | **allow us to leave early**<br>允许我们提前离开 |
| `prevent someone from doing` | **prevent users from deleting the file**<br>阻止用户删除该文件 |
| `hope (that) + clause` | **hope (that) it works**<br>希望它能奏效，`that` 可以省略 |

# 1. choose

## 核心感觉

> **从选项中作选择，或决定采取某个行动。**

## 语法特点

- **及物用法**：直接接选中的人、事物或疑问词结构，也可用 `choose to do` 说出选择采取的行动。
- **不及物用法**：可单独用，也可用 `between / from` 说明选择范围。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **choose + noun**<br>选择某物 | **You can choose any seat.**<br>你可以选任何座位。 |
| **choose between A and B**<br>在A和B之间选择 | **I had to choose between the two offers.**<br>我必须在两个工作机会之间选择。 |
| **choose from + range**<br>从一系列选项中选择 | **You can choose from several options.**<br>你可以从几个选项中选择。 |
| **choose to do**<br>选择做某事 | **She chose to stay silent.**<br>她选择保持沉默。 |
| **choose someone as...**<br>选某人担任某个角色 | **They chose her as team leader.**<br>他们选她担任团队负责人。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **carefully choose**<br>谨慎选择 | **Choose your words carefully.**<br>措辞要谨慎。 |
| **be free to choose**<br>可以自由选择 | **Everyone should be free to choose.**<br>每个人都应该可以自由选择。 |
| **choose wisely**<br>明智选择 | **You only get one chance, so choose wisely.**<br>你只有一次机会，所以要慎重选择。 |
| **choose not to do**<br>选择不做 | **He chose not to respond.**<br>他选择不回应。 |
| **choose what to do**<br>选择做什么 | **You can choose what to do next.**<br>你可以选择接下来做什么。 |

## 用法提醒

`choose between` 常用于几个明确摆在面前的选项，`choose from` 常用于从一组候选项中挑选。

过去式 `chose`，过去分词 `chosen`。

## 输出例句

**I chose to focus on one project instead of doing everything at once.**  
我选择专注于一个项目，而不是同时做所有事情。

**You don't have to choose right now.**  
你不用现在就作选择。

**Sometimes choosing what not to do is just as important as choosing what to do.**  
有时候，选择不做什么和选择做什么同样重要。

# 2. prefer

## 核心感觉

> **在几个选项中更喜欢某个事物、做法或安排。**

## 语法特点

- **及物动词**：接名词、`V-ing` 或 `to do` 表达偏好。
- **比较结构**：`prefer A to B` 中的 `to` 是介词，可接名词或 `V-ing`。
- **具体场合的偏好**：`would prefer to do` 或 `would prefer someone to do`。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **prefer A to B**<br>比起B更喜欢A | **I prefer tea to coffee.**<br>比起咖啡，我更喜欢茶。 |
| **prefer doing**<br>更喜欢做某事 | **I prefer working alone.**<br>我更喜欢独自工作。 |
| **prefer to do**<br>更愿意做某事 | **I prefer to keep things simple.**<br>我更愿意把事情保持简单。 |
| **would prefer to do**<br>这次更希望做 | **I'd prefer to wait a little longer.**<br>我更想再等一会儿。 |
| **would prefer someone to do**<br>希望某人做某事 | **I'd prefer you to tell me directly.**<br>我希望你直接告诉我。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **personally prefer**<br>个人更喜欢 | **I personally prefer the first version.**<br>我个人更喜欢第一版。 |
| **strongly prefer**<br>明显更偏好 | **Most users strongly prefer the simpler layout.**<br>大多数用户明显更喜欢简单的布局。 |
| **prefer not to do**<br>更愿意不做 | **I'd prefer not to discuss it now.**<br>我现在不太想讨论这件事。 |
| **prefer doing something to doing something**<br>比起做一件事更喜欢做另一件事 | **I prefer walking to driving.**<br>比起开车，我更喜欢走路。 |
| **prefer to do something rather than do something**<br>相比另一种做法更愿意这样做 | **I prefer to call rather than send a long message.**<br>比起发一长串消息，我更愿意打电话。 |

## 用法提醒

比较两种活动可以说 `prefer walking to driving`，也可以说 `prefer to walk rather than drive`。

`prefer to do` 也能表达一般偏好。`would prefer` 常用于眼下的选择或委婉表达。

## 输出例句

**I prefer working in the morning when my mind is clearer.**  
我更喜欢早上工作，因为那时候头脑更清楚。

**I'd prefer not to make a decision until we have more information.**  
在获得更多信息之前，我不太想作决定。

**I prefer simple tools that do one thing well.**  
我更喜欢功能单一但做得好的工具。

# 3. select

## 核心感觉

> **按条件筛选，或从列表、界面中选中。**

## 语法特点

- **及物动词**：直接接选中的项目、文件或人。
- **来源与用途**：`select someone / something from...` 说明从哪组选出，`select someone for / to do...` 说明入选的项目或任务。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **select + noun**<br>选择、选中 | **Select the file you want to open.**<br>选择你要打开的文件。 |
| **select someone / something from...**<br>从某个范围中选出人或事物 | **Five candidates were selected from over a hundred applicants.**<br>从一百多名申请者中选出了五人。 |
| **select someone for**<br>选某人参加 / 担任 | **She was selected for the program.**<br>她被选中参加这个项目。 |
| **select someone to do**<br>选某人做某事 | **They selected him to lead the team.**<br>他们选他领导团队。 |
| **be selected as**<br>被选为 | **She was selected as the winner.**<br>她被选为获胜者。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **carefully selected**<br>精心挑选 | **The examples were carefully selected.**<br>这些例子经过精心挑选。 |
| **select an option**<br>选择选项 | **Select an option from the menu.**<br>从菜单中选择一个选项。 |
| **select a candidate**<br>挑选候选人 | **The company selected three candidates.**<br>公司选出了三名候选人。 |
| **select at random**<br>随机选取 | **We selected ten entries at random.**<br>我们随机选取了十条记录。 |
| **select multiple items**<br>选中多个项目 | **Hold down Shift to select multiple items.**<br>按住 Shift 键可以选中多个项目。 |

## 用法提醒

`choose` 适用范围广。`select` 在正式选拔、按条件筛选和操作界面时常见。

`be selected for the programme` 是入选项目，`be selected as team leader` 是被选为负责人。

## 输出例句

**You can select multiple files at once.**  
你可以一次选择多个文件。

**The team selected the simplest solution.**  
团队选择了最简单的解决方案。

**Candidates are selected based on experience and skills.**  
候选人会根据经验和技能进行筛选。

# 4. accept

## 核心感觉

> **接受提议、事物或事实，也可表示接纳某人。**

## 语法特点

- **及物动词**：直接接提议、邀请、道歉等，也可接 `that` 从句。
- **接纳结构**：`accept someone as...` 表示以某身份接纳，`accept someone into...` 表示接纳进入组织或项目。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **accept + noun**<br>接受某物 | **She accepted the offer.**<br>她接受了这个提议。 |
| **accept that...**<br>接受某个事实 | **You have to accept that things have changed.**<br>你必须接受事情已经改变。 |
| **accept responsibility**<br>承担责任 | **He accepted responsibility for the mistake.**<br>他承担了这个错误的责任。 |
| **accept someone as...**<br>以某种身份接纳某人 | **They accepted him as part of the team.**<br>他们接纳他成为团队的一员。 |
| **be accepted into**<br>被接纳进入 | **She was accepted into the program.**<br>她被这个项目录取了。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **gladly accept**<br>欣然接受 | **I gladly accepted the invitation.**<br>我欣然接受了邀请。 |
| **fully accept**<br>完全接受 | **I fully accept that I was wrong.**<br>我完全承认自己错了。 |
| **accept an apology**<br>接受道歉 | **She accepted his apology.**<br>她接受了他的道歉。 |
| **accept reality**<br>接受现实 | **Eventually, he had to accept reality.**<br>最终他不得不接受现实。 |
| **widely accepted**<br>被广泛接受 | **The idea is now widely accepted.**<br>这个观点现在被广泛接受。 |

## 用法提醒

`accept the invitation` 表示接受邀请。表达同意参加，可以说 `agree to attend`。

`accept that things have changed` 表示承认并接受事态的变化。

## 输出例句

**I accepted the offer after thinking about it for a few days.**  
我考虑了几天后接受了这个提议。

**It took me a while to accept that the plan wasn't working.**  
我花了一段时间才接受这个计划行不通。

**You don't have to accept every opportunity that comes your way.**  
你不需要接受每一个来到面前的机会。

# 5. refuse

## 核心感觉

> **拒绝接受某物、拒绝做某事，或拒绝给予某人某物。**

## 语法特点

- **及物用法**：接被拒绝的提议、请求等，也可接 `to do`。
- **双宾语结构**：`refuse someone something` 表示拒绝给予某人某物。
- **省略对象**：语境明确时可单独说 `He refused`。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **refuse + noun**<br>拒绝某物 | **He refused the offer.**<br>他拒绝了这个提议。 |
| **refuse to do**<br>拒绝做某事 | **She refused to answer.**<br>她拒绝回答。 |
| **refuse someone something**<br>拒绝给某人某物 | **They refused him entry.**<br>他们拒绝让他进入。 |
| **refuse permission**<br>拒绝给予许可 | **The building owner refused permission to film.**<br>大楼业主拒绝了拍摄申请。 |
| **flatly refuse**<br>断然拒绝 | **He flatly refused to cooperate.**<br>他断然拒绝合作。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **politely refuse**<br>礼貌拒绝 | **She politely refused the invitation.**<br>她礼貌地拒绝了邀请。 |
| **simply refuse**<br>就是不肯 | **He simply refused to listen.**<br>他就是不肯听。 |
| **refuse access**<br>拒绝访问 | **They refused access to the building.**<br>他们拒绝让人进入大楼。 |
| **refuse treatment**<br>拒绝治疗 | **The patient refused treatment.**<br>病人拒绝治疗。 |
| **refuse a request**<br>拒绝请求 | **I had to refuse her request for more time.**<br>我不得不拒绝她延长时间的请求。 |

## 用法提醒

`She refused to answer` 中，拒绝和回答的主语都是 `she`。

`They refused him entry` 是他们拒绝让他进入。名词 `refusal` 可接 `to do`。

## 输出例句

**He refused to explain why he had changed his mind.**  
他拒绝解释为什么改变了主意。

**I politely refused the offer because the timing wasn't right.**  
因为时机不合适，我礼貌地拒绝了这个提议。

**She refused to let fear make the decision for her.**  
她拒绝让恐惧替自己作决定。

# 6. reject

## 核心感觉

> **明确拒绝、否决某个提议、申请、观点或人。**

## 语法特点

- **及物动词**：直接接被拒绝的方案、申请、说法等。
- **被动表达**：`be rejected` 常用于申请、投稿或提案被驳回。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **reject + noun**<br>拒绝、否决 | **They rejected the proposal.**<br>他们否决了这个提案。 |
| **reject an offer**<br>拒绝提议 | **She rejected the job offer.**<br>她拒绝了工作机会。 |
| **reject an idea**<br>否定观点 | **Don't reject the idea too quickly.**<br>不要太快否定这个想法。 |
| **reject a claim**<br>驳回某种说法 | **The court rejected the claim.**<br>法院驳回了这项主张。 |
| **be rejected**<br>被拒绝 | **His application was rejected.**<br>他的申请被拒绝了。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **completely reject**<br>完全否定 | **I completely reject that argument.**<br>我完全不接受那个论点。 |
| **firmly reject**<br>坚决拒绝 | **They firmly rejected the proposal.**<br>他们坚决否决了提案。 |
| **reject an application**<br>驳回申请 | **Her application was rejected.**<br>她的申请被拒绝了。 |
| **reject the possibility**<br>排除可能性 | **We can't reject that possibility yet.**<br>我们还不能排除这种可能性。 |
| **reject a hypothesis**<br>否定一个假设 | **The findings gave us enough reason to reject the hypothesis.**<br>研究结果为否定这一假设提供了充分理由。 |

## 用法提醒

拒绝做某事通常用 `refuse to do`。两者都可以接 `an offer`，`reject` 常强调经过判断后明确否决。

`rejection` 是名词，`fear of rejection` 表示害怕被拒绝。

## 输出例句

**The idea was rejected because it was too expensive.**  
这个想法因为成本太高被否决了。

**I don't want to reject the option before we've looked at the data.**  
在查看数据之前，我不想先排除这个选项。

**His application was rejected twice before he finally succeeded.**  
他的申请被拒绝了两次，最后才成功。

# 7. allow

## 核心感觉

> **给予许可、提供条件，或为某事留出余地。**

## 语法特点

- **及物用法**：接被允许的活动，也可接“人或事物 + to do”。
- **双宾语结构**：`allow someone time` 表示给某人留时间。
- **介词结构**：`allow for...` 表示把可能的情况考虑进去或留出余地。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **allow someone to do**<br>允许某人做 | **They allowed us to leave early.**<br>他们允许我们提前离开。 |
| **allow something / doing**<br>允许某事或某项活动 | **The hotel doesn’t allow smoking.**<br>这家酒店禁止吸烟。 |
| **be allowed to do**<br>被允许做 | **Are we allowed to park here?**<br>这里允许停车吗？ |
| **allow for something**<br>把……考虑进去 | **We need to allow for delays.**<br>我们需要把延误考虑进去。 |
| **allow time for**<br>留出时间 | **Allow enough time for testing.**<br>要给测试留足时间。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **not allow**<br>不允许 | **The system doesn't allow that.**<br>系统不允许这样做。 |
| **allow access**<br>允许访问 | **This setting allows access to the folder.**<br>这个设置允许访问该文件夹。 |
| **allow flexibility**<br>提供灵活性 | **The schedule allows some flexibility.**<br>这个时间安排有一定灵活性。 |
| **allow someone enough time**<br>给足时间 | **Allow yourself enough time to recover.**<br>给自己足够的恢复时间。 |
| **allow room for**<br>为……留出余地 | **The schedule allows room for changes.**<br>时间表留出了调整余地。 |

## 用法提醒

说 `allow people to smoke` 或 `allow smoking`。前者指出获准的人，后者说允许的活动。

`allow for delays` 是提前考虑延误，`allow enough time for testing` 是为测试留足时间。

## 输出例句

**The system allows users to change the settings themselves.**  
这个系统允许用户自行修改设置。

**I try to allow myself enough time to think before making important decisions.**  
作重要决定之前，我会尽量给自己足够的思考时间。

**The current schedule doesn't allow for much flexibility.**  
现在的时间安排没有留下多少灵活空间。

# 8. permit

## 核心感觉

> **正式允许某人做某事，或说明条件允许某事发生。**

## 语法特点

- **及物用法**：接获准的活动，或接“人或事物 + to do”。
- **条件表达**：`if time permits` 和 `weather permitting` 可表示时间或天气允许。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **permit someone to do**<br>允许某人做 | **The rules permit users to make one change.**<br>规则允许用户修改一次。 |
| **permit something**<br>允许某事 | **Photography is not permitted.**<br>这里不允许拍照。 |
| **be permitted to do**<br>获准做某事 | **Visitors are not permitted to enter this area.**<br>访客不得进入该区域。 |
| **if circumstances permit**<br>如果条件允许 | **We'll leave early if circumstances permit.**<br>如果条件允许，我们会早点走。 |
| **weather permitting**<br>天气允许的话 | **We'll go hiking tomorrow, weather permitting.**<br>天气允许的话，我们明天去徒步。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **legally permitted**<br>法律允许 | **The activity is legally permitted.**<br>这项活动在法律上是允许的。 |
| **not permitted**<br>不被允许 | **Outside food is not permitted.**<br>禁止携带外食。 |
| **permit access**<br>允许进入 | **The badge permits access to the building.**<br>这张卡允许进入大楼。 |
| **permit entry**<br>允许进入 | **Only staff are permitted entry.**<br>只有员工获准进入。 |
| **permit use**<br>允许使用 | **The license permits commercial use.**<br>该许可证允许商业使用。 |

## 用法提醒

`permit` 常见于规定、告示和正式说明，日常交流也可用 `allow`。

过去式和过去分词都是 `permitted`。`a permit` 是名词，表示许可证。

## 输出例句

**Visitors are not permitted to enter this area without permission.**  
访客未经许可不得进入这个区域。

**The software permits multiple users to work on the same file.**  
这个软件允许多个用户处理同一个文件。

**We'll continue tomorrow if time permits.**  
如果时间允许，我们明天继续。

# 9. avoid

## 核心感觉

> **避开某人某物，或设法避免某种行为、结果。**

## 语法特点

- **及物动词**：直接接避开的对象或结果。
- **动作结构**：`avoid doing` 表示避免做某事，后接 `V-ing`。

## 高频结构

| 结构 | 例句 |

## 用法提醒

`aim for a higher score` 强调目标结果。`aim to improve` 强调想达到的行动目标。

# 24. wish

## 高频结构

| **wish + subject + past perfect**<br>对过去表示遗憾 | **I wish I had started earlier.**<br>我要是早点开始就好了。 |
| **wish someone something**<br>祝愿某人 | **I wish you good luck.**<br>祝你好运。 |
| **wish to do**<br>希望做某事，较正式 | **I wish to speak to the manager.**<br>我希望和经理谈话。 |
| **wish + subject + would do**<br>盼望某种情况改变 | **I wish the neighbours would turn the music down.**<br>真希望邻居能把音乐调小一点。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |

| **wish you luck**<br>祝好运 | **I wish you luck with the interview.**<br>祝你面试顺利。 |
| **wish I could**<br>真希望我能 | **I wish I could help.**<br>真希望我能帮忙。 |
| **wish I'd done**<br>后悔没做 | **I wish I'd listened to you.**<br>我要是听你的就好了。 |
| **wish someone well**<br>祝某人顺利 | **I genuinely wish him well.**<br>我真心祝他一切顺利。 |

## 用法提醒

`I wish I had more time` 里的 `had` 表达当下的假想。`I wish I had started earlier` 里的 `had started` 表达过去的遗憾。

# 几组容易混淆的结构

| 结构 | 侧重点 | 例句 |
| --- | --- | --- |
| **choose / select / prefer** | 作选择／按条件选取／表达偏好 | **I prefer window seats, so I selected one when I booked.**<br>我比较喜欢靠窗的座位，所以订票时选了一个。 |
| **choose to do / decide to do** | 从可能的做法中选一项／作出决定 | **We decided to travel by train and chose to leave early.**<br>我们决定坐火车出行，并选择早点出发。 |
| **accept / refuse / reject an offer** | 接受／谢绝／明确拒绝，常用于评估后的决定 | **Mia accepted the offer, Tom politely refused it, and Lee rejected it because the terms were too restrictive.**<br>米娅接受了邀约，汤姆礼貌地谢绝了，李则因为条款限制太多而拒绝了。 |
| **refuse to do / reject + noun** | 拒绝做某事／否决某项事物 | **He refused to comment after the committee rejected his proposal.**<br>委员会否决他的提案后，他拒绝置评。 |
| **allow / permit someone to do** | 都可表示允许。正式规定和告示中常见 **permit** | **The hotel allows guests to bring pets. / Guests are permitted to bring pets.**<br>酒店允许客人携带宠物。／客人可携带宠物。 |
| **allow / enable someone to do** | 给予许可或提供条件／提供所需能力或条件 | **The manager allowed me to work remotely. The new software enabled me to do it.**<br>经理允许我远程工作。新软件让我具备了远程工作的条件。 |
| **avoid doing / prevent someone from doing** | 自己避免某个动作／阻止另一个行动者做某事 | **I avoid checking my phone at night. / The app prevents me from opening it after ten.**<br>我尽量避免晚上看手机。／这个应用限制我十点后打开它。 |
| **encourage / force someone to do** | 鼓励行动／施加压力或受客观条件所迫 | **She encouraged me to speak, but she didn’t force me to.**<br>她鼓励我开口，但没有逼我。 |
| **require / demand / request** | 需要或规定必须做／强烈要求／正式提出请求 | **The rules require ID. I requested an exception, and he demanded an explanation.**<br>规则要求出示身份证明。我请求破例，他则坚持要一个解释。 |
| **offer to do / ask someone to do** | 主动提出自己做／请求某人做 | **She offered to drive. I asked her to wait.**<br>她主动提出开车。我请她等一等。 |
| **seek / pursue an opportunity** | 寻找机会／采取行动争取机会 | **I spent months seeking an opportunity and pursued it as soon as it came up.**<br>我找了几个月的机会。机会一出现，我就着手争取。 |
| **aim to do / plan to do / intend to do** | 把某事作为目标／有行动计划或打算／表达意图 | **I aim to speak more confidently, plan to practise twice a week, and intend to keep it up.**<br>我的目标是说得更自信，计划每周练两次，也打算坚持下去。 |
| **hope + clause / wish + subject + past simple** | 希望一个结果发生／希望当前情况有所不同 | **I hope we have enough time. / I wish we had more time.**<br>希望我们时间够用。／要是我们有更多时间就好了。 |
| **wish + subject + had done / wish + subject + would do** | 对过去的遗憾／盼望情况改变 | **I wish I had called earlier. / I wish he would call back.**<br>我要是早点打电话就好了。／真希望他能回电话。 |
| **hesitate to do / hesitate before doing** | 对做某事有顾虑／在做某事之前迟疑 | **I hesitated to ask. / I hesitated before asking.**<br>我有些不敢开口问。／我开口问之前犹豫了一下。 |

# 综合对话

| 角色 | 对话内容 |
|:---:|---|
| **A** | **Have you chosen an English course yet?**<br>你选好英语课程了吗？ |
| **B** | **I’ve selected two to look at more closely. I’d prefer to take the smaller class.**<br>我挑了两门准备仔细看看。我更想上人数少的那门。 |
| **A** | **What are you aiming for?**<br>你的目标是什么？ |
| **B** | **I hope to speak more naturally. I can read quite a lot, but I still hesitate before answering simple questions.**<br>我希望说得更自然。我能读懂不少内容，但回答简单的问题前还是会犹豫。 |
| **A** | **Does the smaller class offer a trial lesson?**<br>人数少的那门课提供试听吗？ |
| **B** | **Yes. I requested a place yesterday. They also allow students to practise in pairs between classes.**<br>提供。我昨天申请了一个名额。他们也允许学员在课间两人一组练习。 |
| **A** | **That sounds promising. Do they require you to speak in front of everyone?**<br>听起来不错。他们要求你在所有人面前发言吗？ |
| **B** | **They encourage it. The teacher said I could start with a partner if I felt nervous.**<br>他们鼓励大家发言。老师说，如果我紧张，可以先和搭档练。 |
| **A** | **Are you planning to accept the place if they offer you one?**<br>如果他们给你名额，你打算接受吗？ |
| **B** | **Yes. I intend to go every week. I just need to plan around my work schedule.**<br>打算接受。我想每周都去，只需要配合工作时间安排一下。 |
| **A** | **I can practise with you before the first class, if you like.**<br>如果你愿意，第一节课前我可以陪你练。 |
| **B** | **Thanks. I wish I’d asked you sooner. Let’s try it on Saturday.**<br>谢谢。我要是早点问你就好了。我们周六试试吧。 |
