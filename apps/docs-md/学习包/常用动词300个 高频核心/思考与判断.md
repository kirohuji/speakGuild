# 思考、认知与判断

## 阅读说明

- **及物动词（transitive verb）**：可以直接接宾语。  
  `I need more time.` → `more time` 是宾语。

- **不及物动词（intransitive verb）**：不直接接宾语，可以另接介词短语等成分。  
  `Something happened.` / `Listen to me.`

- **系动词（linking verb）**：接表语，说明主语的身份、性质或状态。  
  `She seems tired.` / `The sky turned dark.`

- **使役结构（causative construction）**：表示使、促使或允许某个动作发生。  
  `make someone do` / `let someone do` / `get someone to do`

- **宾语补足语（object complement）**：在宾语后补充说明宾语的状态、身份或动作。  
  `keep the door open` → `open` 说明门的状态。

- **双宾语结构（double-object construction）**：接两个宾语，通常先说接受者，再说给予的东西。  
  `She gave me a book.` → `me` 是间接宾语，`a book` 是直接宾语。

同一个动词可以有多种用法；以上分类的角度不同，也可以同时适用。

### 结构写法

#### 1. 占位符与符号

| 标记 | 含义 |
| --- | --- |
| `someone / something` | 可替换的人／事物 |
| `noun / adjective` | 名词／形容词 |
| `place / time` | 地点／时间 |
| `clause / wh-clause` | 从句／由 what、why、how 等疑问词引导的从句 |
| `do / doing / done` | 动词原形／V-ing 形式／过去分词 |
| `+` | 连接成分，不写进实际句子 |
| `( )` | 该成分可以省略 |

#### 2. 结构示例

固定的介词、不定式标记等需要保留，占位符换成具体内容。

| 结构 | 实际表达 |
| --- | --- |
| `consider something + adjective` | **consider it useful**<br>认为它有用 |
| `learn from + noun` | **learn from mistakes**<br>从错误中学习 |
| `expect someone to do` | **expect him to reply**<br>预计他会回复 |
| `imagine someone doing` | **imagine her living abroad**<br>想象她在国外生活 |
| `believe (that) + clause` | **believe (that) he is right**<br>相信他是对的；`that` 可以省略 |

# 1. think

## 核心感觉

> **思考某事，或形成、表达一个看法。**

## 语法特点

- **及物用法**：常接 `that` 从句表达判断，口语中 `that` 可省略。
- **不及物用法**：可单独表示思考；`about / of` 引出思考或想到的对象。
- **时态区别**：表达看法时通常用一般时；表示正在考虑的过程时可用进行时。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **think about + noun / doing**<br>思考、考虑 | **I've been thinking about changing jobs.**<br>我一直在考虑换工作。 |
| **think of + noun**<br>想到；想起；认为 | **What do you think of the idea?**<br>你觉得这个想法怎么样？ |
| **think + clause**<br>认为…… | **I think we need more time.**<br>我觉得我们需要更多时间。 |
| **think of doing**<br>考虑做某事 | **Have you ever thought of moving abroad?**<br>你有没有想过搬到国外？ |
| **think twice**<br>三思 | **You should think twice before making that decision.**<br>做那个决定之前你应该三思。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **think it over**<br>仔细考虑 | **Let me think it over and get back to you.**<br>让我仔细想想再回复你。 |
| **think ahead**<br>提前考虑 | **We need to think ahead and plan for next year.**<br>我们需要提前考虑并规划明年。 |
| **think clearly**<br>清楚思考 | **I can't think clearly when I'm tired.**<br>我累的时候脑子不太清楚。 |
| **think highly of**<br>高度评价 | **They think highly of her work.**<br>他们很认可她的工作。 |
| **think for yourself**<br>独立思考 | **You need to learn to think for yourself.**<br>你需要学会独立思考。 |

## 用法提醒

`I think he’s right` 表达看法；`I’m thinking about it` 表示正在考虑。

表达“我觉得他不对”常说 `I don’t think he’s right`。过去式和过去分词都是 `thought`。

## 输出例句

**I think we should wait a little longer.**  
我觉得我们应该再等一会儿。

**I've been thinking about what you said yesterday.**  
我一直在想你昨天说的话。

**I couldn't think of anything to say.**  
我当时什么都想不出来。

# 2. know

## 核心感觉

> **知道事实、认识某人，或掌握怎样做某事。**

## 语法特点

- **主要用作及物动词**：接人、事物、`that` 从句或疑问词从句。
- **技能结构**：`know how to do` 表示知道如何做某事。
- **状态动词**：通常不用进行时；可省略已知的内容，如 `I know`。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **know + noun**<br>知道；认识 | **Do you know her?**<br>你认识她吗？ |
| **know that + clause**<br>知道…… | **I know that you're busy.**<br>我知道你很忙。 |
| **know + wh-clause**<br>知道具体信息 | **Do you know where he went?**<br>你知道他去哪儿了吗？ |
| **know how to do**<br>知道怎么做 | **She knows how to fix it.**<br>她知道怎么修。 |
| **get to know**<br>逐渐了解 | **It takes time to get to know someone.**<br>真正了解一个人需要时间。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **know for sure**<br>确定知道 | **I don't know for sure yet.**<br>我现在还不能确定。 |
| **know from experience**<br>从经验中知道 | **I know from experience that this takes time.**<br>我根据经验知道这需要时间。 |
| **know about**<br>了解有关……的信息 | **How much do you know about the project?**<br>你对这个项目了解多少？ |
| **know of**<br>知道……的存在 | **I know of a few good places nearby.**<br>我知道附近有几家不错的店。 |
| **you never know**<br>很难说；谁知道呢 | **You never know what might happen.**<br>谁也不知道会发生什么。 |

## 用法提醒

`know someone` 是认识某人；`know of someone` 是知道有这个人；`know about something` 是了解某事的信息。

从句用陈述语序：`Do you know where he is?`。过去式 `knew`，过去分词 `known`。

## 输出例句

**I know what you mean.**  
我明白你的意思。

**I don't know enough about it to make a decision yet.**  
我对这件事了解得还不够，还不能做决定。

**Once you get to know him, he's actually very easy to talk to.**  
你真正了解他以后，会发现他其实很好相处。

# 3. believe

## 核心感觉

> **相信某人的话，或认为某件事真实、可信。**

## 语法特点

- **及物用法**：直接接相信的人、说法或 `that` 从句。
- **介词结构**：`believe in` 表示相信存在、认可价值或信任能力。
- **宾语补足语结构**：`believe someone to be...` 较正式，也常见于被动表达。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **believe someone**<br>相信某人的话 | **I believe you.**<br>我相信你。 |
| **believe that + clause**<br>相信、认为…… | **I believe that things will improve.**<br>我相信情况会改善。 |
| **believe in + noun**<br>相信……的价值或存在 | **She really believes in what she's doing.**<br>她真的相信自己正在做的事情。 |
| **can't believe + clause**<br>难以相信 | **I can't believe you remembered.**<br>真没想到你还记得。 |
| **be believed to do**<br>被认为…… | **The building is believed to be over 200 years old.**<br>这栋建筑被认为已有两百多年历史。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **believe in yourself**<br>相信自己 | **You need to believe in yourself a little more.**<br>你需要更相信自己一点。 |
| **firmly believe**<br>坚信 | **I firmly believe this is the right decision.**<br>我坚信这是正确的决定。 |
| **believe every word**<br>相信每一句话 | **I believed every word she said.**<br>我相信她说的每一句话。 |
| **believe it or not**<br>信不信由你 | **Believe it or not, I've never been there.**<br>信不信由你，我从没去过那里。 |
| **hard to believe**<br>难以置信 | **It's hard to believe how quickly time passed.**<br>很难相信时间过得这么快。 |

## 用法提醒

`I believe you` 是相信你说的话；`I believe in you` 是相信你的能力或支持你。

`I believe...` 的语气取决于上下文，并不总比 `I think...` 更确定。通常不用进行时。

## 输出例句

**I believe we made the right choice.**  
我相信我们做了正确的选择。

**I don't believe everything I read online.**  
我不会相信网上看到的所有东西。

**She believed in the project even when everyone else had doubts.**  
即使其他人都有怀疑，她仍然相信这个项目。

# 4. understand

## 核心感觉

> **明白信息的意思、运作方式，或理解某人的处境。**

## 语法特点

- **主要用作及物动词**：接名词、`that` 从句或疑问词从句，也可省略已知内容。
- **状态用法**：表示理解时通常不用进行时。
- **过去分词结构**：`make yourself understood` 表示让别人听懂自己的意思。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **understand + noun**<br>理解某事 | **I understand the problem now.**<br>我现在明白这个问题了。 |
| **understand that + clause**<br>明白…… | **I understand that you're under a lot of pressure.**<br>我知道你压力很大。 |
| **understand why/how...**<br>理解原因或方式 | **I don't understand why he left.**<br>我不明白他为什么离开。 |
| **understand someone**<br>理解某人 | **I understand him better now.**<br>我现在更理解他了。 |
| **make yourself understood**<br>让别人明白自己 | **I could make myself understood, even with limited English.**<br>即使英语有限，我也能让别人听懂我的意思。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **fully understand**<br>完全理解 | **I don't fully understand how it works.**<br>我还没有完全明白它是怎么运作的。 |
| **clearly understand**<br>清楚理解 | **Make sure everyone clearly understands the plan.**<br>确保每个人都清楚理解计划。 |
| **understand the point**<br>明白重点 | **I understand your point, but I still disagree.**<br>我明白你的意思，但我还是不同意。 |
| **come to understand**<br>逐渐理解 | **I've come to understand why he made that choice.**<br>我逐渐理解了他为什么做那个选择。 |
| **easy to understand**<br>容易理解 | **The explanation was simple and easy to understand.**<br>这个解释简单易懂。 |

## 用法提醒

`know the rule` 侧重知道规则；`understand the rule` 侧重理解规则的意思或原理。

直接说 `understand the problem`，不用 `understand about` 连接这个宾语。过去式和过去分词都是 `understood`。

## 输出例句

**I understand the rule, but I still need more practice using it.**  
我理解这个规则，但还需要更多练习来真正使用它。

**I didn't understand what he meant at first.**  
一开始我没明白他的意思。

**The more I learn about it, the better I understand the whole system.**  
我了解得越多，就越能理解整个系统。

# 5. remember

## 核心感觉

> **记得、想起某人某事，或记住要做某事。**

## 语法特点

- **主要用作及物动词**：可接名词、从句、`V-ing` 或 `to do`。
- **回忆已经发生的动作**：用 `remember doing`。
- **记住要执行的动作**：用 `remember to do`。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **remember + noun**<br>记得某事 | **I remember that day clearly.**<br>我清楚记得那一天。 |
| **remember doing**<br>记得做过某事 | **I remember meeting her once.**<br>我记得见过她一次。 |
| **remember to do**<br>记得去做某事 | **Remember to lock the door.**<br>记得锁门。 |
| **remember that + clause**<br>记得…… | **I suddenly remembered that I had a meeting.**<br>我突然想起自己还有个会。 |
| **if I remember correctly**<br>如果我没记错 | **If I remember correctly, we met in 2024.**<br>如果我没记错，我们是2024年认识的。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **remember clearly**<br>清楚记得 | **I still remember it clearly.**<br>我到现在还记得很清楚。 |
| **remember correctly**<br>记得没错 | **Do I remember correctly that you're from Shanghai?**<br>如果我没记错，你是上海人，对吗？ |
| **remember someone's name**<br>记住某人的名字 | **I'm terrible at remembering names.**<br>我很不擅长记人名。 |
| **remember vividly**<br>清楚、鲜明地记得 | **I vividly remember my first day at work.**<br>我清楚地记得上班第一天。 |
| **always remember**<br>永远记得 | **I'll always remember what you said.**<br>我会一直记得你说的话。 |

## 用法提醒

`I remember locking the door` 是记得锁过门；`I remembered to lock the door` 是当时记得去锁门，并执行了。

`Remember to lock the door` 是提醒对方去做，动作还未必发生。

## 输出例句

**I remember seeing this place when I was a child.**  
我记得小时候见过这个地方。

**Please remember to send me the file later.**  
等下记得把文件发给我。

**I can't remember exactly what he said.**  
我记不清他具体说了什么。

# 6. forget

## 核心感觉

> **忘记信息、经历，或忘了执行某个动作。**

## 语法特点

- **主要用作及物动词**：可接名词、从句、`V-ing` 或 `to do`。
- **遗忘经历**：`forget doing` 表示不再记得做过的事，常见于 `never forget doing`。
- **遗漏动作**：`forget to do` 表示忘了去做，通常因此没做。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **forget + noun**<br>忘记某事 | **I forgot his name.**<br>我忘了他的名字。 |
| **forget doing**<br>忘记做过 | **I'll never forget meeting her for the first time.**<br>我永远不会忘记第一次见她。 |
| **forget to do**<br>忘记去做 | **I forgot to reply to his message.**<br>我忘记回复他的消息了。 |
| **forget about + noun**<br>忘掉；不再考虑 | **Forget about work for a while.**<br>暂时别想工作的事。 |
| **forget that + clause**<br>忘记一个事实 | **I forgot that the store closes early today.**<br>我忘了今天商店关门早。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **completely forget**<br>完全忘记 | **I completely forgot about the appointment.**<br>我把那个预约完全忘了。 |
| **never forget**<br>永远不会忘记 | **I'll never forget that moment.**<br>我永远不会忘记那一刻。 |
| **forget someone's name**<br>忘记名字 | **Sorry, I forgot your name.**<br>抱歉，我忘了你的名字。 |
| **forget all about**<br>把……忘得一干二净 | **I forgot all about it.**<br>我把这件事忘得一干二净。 |
| **easy to forget**<br>容易忘记 | **It's easy to forget small details when you're busy.**<br>忙的时候很容易忘记小细节。 |

## 用法提醒

`I forgot to call her` 是忘了打电话；`I’ll never forget meeting her` 是永远忘不了见她的经历。

说明东西落在哪里，常用 `leave`：`I left my keys at home`。过去式 `forgot`，过去分词 `forgotten`。

## 输出例句

**I forgot to bring my charger this morning.**  
我今天早上忘了带充电器。

**I'll never forget hearing that news for the first time.**  
我永远不会忘记第一次听到那个消息时的感觉。

**Don't forget that we still have another option.**  
别忘了我们还有另一个选择。

# 7. realize

## 核心感觉

> **意识到、明白某个事实，或使目标成为现实。**

## 语法特点

- **及物动词**：接事实、重要性等名词，或 `that / wh-` 从句。
- **认识变化**：可表示突然意识到，也可表示逐渐认识到。
- **实现用法**：可接梦想、抱负、潜力等，如 `realize a dream`。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **realize that + clause**<br>意识到…… | **I realized that I'd made a mistake.**<br>我意识到自己犯了错。 |
| **realize how + adjective + clause**<br>意识到程度 | **I didn't realize how late it was.**<br>我没意识到已经这么晚了。 |
| **realize the importance of**<br>意识到……的重要性 | **He finally realized the importance of sleep.**<br>他终于意识到睡眠的重要性。 |
| **realize a dream**<br>实现梦想 | **She finally realized her dream of becoming a doctor.**<br>她终于实现了成为医生的梦想。 |
| **come to realize**<br>逐渐意识到 | **I've come to realize that I need more time.**<br>我逐渐意识到自己需要更多时间。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **suddenly realize**<br>突然意识到 | **I suddenly realized I'd left my phone at home.**<br>我突然意识到手机落在家里了。 |
| **fully realize**<br>充分意识到 | **I don't think he fully realizes the risk.**<br>我觉得他还没有充分意识到风险。 |
| **fail to realize**<br>没有意识到 | **They failed to realize how serious the problem was.**<br>他们没有意识到问题有多严重。 |
| **make someone realize**<br>让某人意识到 | **The experience made me realize what really matters.**<br>那段经历让我意识到什么才真正重要。 |
| **realize the difference**<br>意识到差别 | **Once you hear both, you'll realize the difference.**<br>两个都听过以后，你就会意识到差别。 |

## 用法提醒

`realize` 表示“实现”并不限于美式英语；英式英语也常拼作 `realise`。

`I didn’t realize you were busy` 是此前没意识到你在忙；`I don’t know` 是现在不知道。

## 输出例句

**I didn't realize you were waiting for me.**  
我没意识到你一直在等我。

**I suddenly realized why the plan had failed.**  
我突然明白了这个计划为什么会失败。

**The more I practiced, the more I realized how much I still had to learn.**  
我练得越多，就越意识到自己还有多少东西要学。

# 8. notice

## 核心感觉

> **看见、听见或察觉到某人某事。**

## 语法特点

- **主要用作及物动词**：直接接注意到的事物或从句。
- **宾语补足语结构**：`notice someone do` 把动作作为整体观察；`notice someone doing` 侧重动作正在发生。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **notice + noun**<br>注意到某物 | **Did you notice the difference?**<br>你注意到差别了吗？ |
| **notice that + clause**<br>注意到…… | **I noticed that he looked tired.**<br>我注意到他看起来很累。 |
| **notice someone do**<br>注意到动作整体 | **I noticed him leave the room.**<br>我注意到他离开了房间。 |
| **notice someone doing**<br>注意到正在发生的动作 | **I noticed her looking at me.**<br>我注意到她正在看我。 |
| **be noticed**<br>被注意到 | **The change was immediately noticed.**<br>这个变化立刻就被注意到了。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **hardly notice**<br>几乎没注意到 | **I hardly noticed the noise.**<br>我几乎没注意到那个声音。 |
| **immediately notice**<br>立刻注意到 | **You'll immediately notice the difference.**<br>你会立刻注意到区别。 |
| **notice a change**<br>注意到变化 | **Have you noticed any change in his behavior?**<br>你有没有注意到他的行为有什么变化？ |
| **notice something unusual**<br>注意到异常 | **She noticed something unusual about the room.**<br>她注意到房间里有些不寻常。 |
| **go unnoticed**<br>未被注意 | **The mistake went unnoticed for weeks.**<br>这个错误好几个星期都没人注意到。 |

## 用法提醒

`notice him leave` 中的 `leave` 用不带 `to` 的原形；`notice him leaving` 中的 `leaving` 是 `V-ing`。

`go unnoticed` 表示未被察觉，其中 `unnoticed` 说明主语的状态。

## 输出例句

**I noticed a small mistake in the report.**  
我注意到报告里有个小错误。

**Did you notice him leave early?**  
你有没有注意到他提前走了？

**I didn't notice how tired I was until I sat down.**  
直到坐下来，我才注意到自己有多累。

# 9. recognize

## 核心感觉

> **认出、识别，或承认某个事实、身份或价值。**

## 语法特点

- **及物动词**：直接接认出的人、声音、模式等。
- **认定结构**：`recognize someone / something as...` 表示认定某种身份或性质。
- **事实表达**：`recognize that...` 表示承认、认识到事实。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **recognize someone**<br>认出某人 | **I didn't recognize him at first.**<br>我一开始没认出他。 |
| **recognize something**<br>识别某物 | **The software can recognize faces.**<br>这个软件可以识别人脸。 |
| **recognize someone / something as...**<br>认出、认定为…… | **I recognized him as the man I’d met on the train.**<br>我认出他就是我在火车上见过的那个人。 |
| **recognize that + clause**<br>承认、认识到…… | **We need to recognize that the situation has changed.**<br>我们需要承认情况已经变了。 |
| **be widely recognized**<br>被广泛认可 | **She is widely recognized as an expert in the field.**<br>她被广泛认为是这个领域的专家。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **instantly recognize**<br>立刻认出 | **I instantly recognized his voice.**<br>我立刻认出了他的声音。 |
| **barely recognize**<br>几乎认不出 | **I barely recognized the place.**<br>我几乎认不出这个地方了。 |
| **recognize the importance of**<br>认识到……的重要性 | **More people now recognize the importance of sleep.**<br>现在越来越多人认识到睡眠的重要性。 |
| **recognize a pattern**<br>识别模式 | **Children quickly learn to recognize patterns.**<br>孩子很快就会学会识别模式。 |
| **recognize someone's contribution**<br>认可某人的贡献 | **The award recognizes her contribution to the project.**<br>这个奖项肯定了她对项目的贡献。 |

## 用法提醒

`recognize her` 是认出她；`know her` 是认识她。认得一个公众人物，并不表示与对方相识。

英式英语也常拼作 `recognise`。

## 输出例句

**I recognized her voice immediately.**  
我立刻认出了她的声音。

**It took me a moment to recognize the building after the renovation.**  
装修后我过了一会儿才认出那栋楼。

**We need to recognize the limits of what we currently know.**  
我们需要认识到当前认知的局限。

# 10. consider

## 核心感觉

> **认真考虑某事，或把某人某物看作怎样。**

## 语法特点

- **及物用法**：接名词、`V-ing` 或疑问词从句。
- **宾语补足语结构**：宾语后可接形容词、名词或 `to be...`，说明对宾语的判断。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **consider + noun**<br>考虑某事 | **We need to consider every option.**<br>我们需要考虑每个选项。 |
| **consider doing**<br>考虑做某事 | **I'm considering moving closer to work.**<br>我在考虑搬到离公司近一点的地方。 |
| **consider someone / something + adjective**<br>认为A具有某性质 | **I consider this important.**<br>我认为这很重要。 |
| **consider someone / something + noun**<br>认为A是…… | **They consider him a good leader.**<br>他们认为他是个好领导。 |
| **consider whether / how**<br>考虑是否、如何 | **We should consider whether the plan is realistic.**<br>我们应该考虑这个计划是否现实。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **carefully consider**<br>认真考虑 | **Please carefully consider the consequences.**<br>请认真考虑后果。 |
| **consider the possibility**<br>考虑可能性 | **We should consider the possibility that he was wrong.**<br>我们应该考虑他可能错了这种情况。 |
| **all things considered**<br>综合考虑 | **All things considered, it was a good decision.**<br>综合来看，这是个不错的决定。 |
| **be considered to be**<br>被认为是 | **The area is considered to be very safe.**<br>这个地区被认为很安全。 |
| **worth considering**<br>值得考虑 | **That's an option worth considering.**<br>这是一个值得考虑的选项。 |

## 用法提醒

“考虑做某事”用 `consider doing`，不用 `consider to do`。

`consider him a friend` 和 `consider him to be a friend` 都可以。常见结构无需加 `as`。

## 输出例句

**I'm seriously considering taking a few days off.**  
我在认真考虑休几天假。

**We need to consider how this decision will affect the team.**  
我们需要考虑这个决定会怎样影响团队。

**I consider communication one of the most important parts of a relationship.**  
我认为沟通是关系中最重要的部分之一。

# 11. suppose

## 核心感觉

> **猜想、认为，或提出一个假设。**

## 语法特点

- **主要用作及物动词**：常接从句，`I suppose...` 可表达保留、推测或勉强接受。
- **假设表达**：句首 `Suppose (that)...` 可引出假设情境。
- **固定结构**：`be supposed to do` 表示按规定、安排或预期应该做。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **I suppose + clause**<br>我想、大概 | **I suppose he's already left.**<br>我想他大概已经走了。 |
| **suppose that...**<br>假设…… | **Suppose that the plan fails. What do we do next?**<br>假设计划失败了，我们下一步怎么办？ |
| **be supposed to do**<br>应该；按安排要做 | **You're supposed to be here at nine.**<br>你按规定应该九点到这里。 |
| **not supposed to do**<br>不应该；不允许 | **We're not supposed to use our phones here.**<br>这里按规定不能用手机。 |
| **what do you suppose...?**<br>你觉得…… | **What do you suppose happened?**<br>你觉得发生了什么？ |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **I suppose so**<br>我想是吧 | **“Will he come?” “I suppose so.”**<br>“他会来吗？”“我想会吧。” |
| **I suppose not**<br>我想不会 | **“Can we change it now?” “I suppose not.”**<br>“我们现在还能改吗？”“我想不行了。” |
| **suppose for a moment**<br>暂且假设 | **Suppose for a moment that you're right.**<br>暂且假设你是对的。 |
| **be supposed to mean**<br>按理说表示 | **What is this supposed to mean?**<br>这到底是什么意思？ |
| **be supposed to happen**<br>按预期应该发生 | **What was supposed to happen next?**<br>接下来按原计划应该发生什么？ |

## 用法提醒

`I suppose so` 是“我想是吧”；`I suppose not` 是“我想不是／不行吧”。

`You’re supposed to be here at nine` 表示你按安排应九点到场；`You’re not supposed to...` 常表示按规定不应或不允许。

## 输出例句

**I suppose we could try again tomorrow.**  
我想我们明天可以再试一次。

**You're supposed to tell me before you change the plan.**  
你按理应该在改变计划之前告诉我。

**Suppose we had twice as much time—what would you change?**  
假设我们有两倍的时间，你会改什么？

# 12. assume

## 核心感觉

> **未经充分确认就认为某事成立，或承担职责。**

## 语法特点

- **及物动词**：接名词、`that` 从句，也可接“宾语 + to be”。
- **承担用法**：可直接接责任、职务或控制权。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **assume that + clause**<br>假定…… | **Let's assume that the data is correct.**<br>我们先假定这些数据是正确的。 |
| **assume + noun**<br>把……作为假设 | **Don't assume the worst.**<br>不要直接往最坏的情况想。 |
| **assume someone / something to be...**<br>假定A为B | **We assumed the task to be simple.**<br>我们原以为这个任务很简单。 |
| **assume responsibility**<br>承担责任 | **He assumed responsibility for the mistake.**<br>他承担了这个错误的责任。 |
| **it is reasonable to assume**<br>可以合理假定 | **It's reasonable to assume that demand will increase.**<br>合理地说，可以假定需求会增加。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **wrongly assume**<br>错误地假定 | **I wrongly assumed he already knew.**<br>我错误地以为他已经知道了。 |
| **automatically assume**<br>下意识认定 | **Don't automatically assume they're against you.**<br>不要下意识就认定他们反对你。 |
| **assume control**<br>接管控制 | **She assumed control of the project.**<br>她接管了这个项目。 |
| **assume the worst**<br>往最坏的情况想 | **Don’t assume the worst before you know the facts.**<br>弄清事实之前，别先往最坏的情况想。 |
| **assume a role**<br>担任某种角色、职务 | **She assumed a leading role in the project.**<br>她在这个项目中担任了领导角色。 |

## 用法提醒

`assume that...` 可能是有意建立假设，也可能是未经核实的想当然。

`assume responsibility for something` 表示承担某事的责任。`assumption` 是对应名词。

## 输出例句

**I assumed the meeting had been cancelled.**  
我原以为会议已经取消了。

**Let's assume for now that the information is reliable.**  
我们暂时先假定这些信息是可靠的。

**The biggest mistake was assuming everyone understood the plan.**  
最大的错误是假定所有人都理解了计划。

# 13. guess

## 核心感觉

> **在信息不足时猜测，或随口表达一个判断。**

## 语法特点

- **及物用法**：接所猜的答案、数字或从句。
- **不及物用法**：可单独表示猜测，如 `I’m only guessing`。
- **口语判断**：`I guess...` 常表示“我想、我估计”，也可表达勉强接受。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **guess + noun**<br>猜某事 | **Can you guess the answer?**<br>你能猜到答案吗？ |
| **guess that + clause**<br>猜测…… | **I guessed that something was wrong.**<br>我猜到有些不对劲。 |
| **I guess + clause**<br>我想；我估计 | **I guess we'll have to wait.**<br>我想我们只能等了。 |
| **guess what**<br>你猜怎么着 | **Guess what—I got the job.**<br>你猜怎么着——我拿到那份工作了。 |
| **take a guess**<br>猜一下 | **Take a guess how much it cost.**<br>猜猜它多少钱。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **guess wildly**<br>毫无根据地猜 | **I was guessing wildly, but I got the answer right.**<br>我完全是瞎猜，却答对了。 |
| **guess someone’s age**<br>猜某人的年龄 | **Can you guess his age?**<br>你能猜出他的年龄吗？ |
| **your guess is as good as mine**<br>我也不知道 | **When will it be fixed? Your guess is as good as mine.**<br>什么时候能修好？我也不知道。 |
| **guess correctly**<br>猜对 | **You guessed correctly.**<br>你猜对了。 |
| **keep someone guessing**<br>让某人一直猜 | **The story keeps you guessing until the end.**<br>这个故事会让你一直猜到最后。 |

## 用法提醒

`I guess we’ll have to wait` 可带有“看来只能等了”的接受意味，不一定是在猜事实。

`a wild guess / an educated guess` 中的 `guess` 是名词，分别表示瞎猜／有依据的估计。

## 输出例句

**I guess he's probably busy right now.**  
我猜他现在可能在忙。

**If I had to guess, I'd say it will take about two weeks.**  
如果非要我猜，我会说大概需要两周。

**I guessed the answer, but somehow I got it right.**  
我是猜的答案，但居然猜对了。

# 14. imagine

## 核心感觉

> **想象某个画面、经历或可能性，也可表示推想。**

## 语法特点

- **主要用作及物动词**：接名词、`V-ing` 或从句。
- **宾语补足语结构**：`imagine someone doing` 表示想象某人做某事。
- **推想表达**：`I imagine (that)...` 有时接近“我想、大概”。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **imagine + noun**<br>想象某物 | **Imagine a world without the internet.**<br>想象一个没有互联网的世界。 |
| **imagine doing**<br>想象做某事 | **Can you imagine living there?**<br>你能想象住在那里吗？ |
| **imagine that + clause**<br>设想…… | **Imagine that you had no deadline.**<br>设想一下，如果你没有截止日期。 |
| **imagine someone doing**<br>想象某人做某事 | **I can't imagine him saying that.**<br>我很难想象他会说那种话。 |
| **as you can imagine**<br>正如你能想象的 | **As you can imagine, everyone was shocked.**<br>正如你能想象的，所有人都很震惊。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **hard to imagine**<br>很难想象 | **It's hard to imagine life without smartphones now.**<br>现在很难想象没有智能手机的生活。 |
| **just imagine**<br>想象一下 | **Just imagine what we could do with more time.**<br>想象一下，如果时间更多我们能做什么。 |
| **imagine yourself**<br>想象自己 | **Imagine yourself five years from now.**<br>想象五年后的自己。 |
| **imagine the worst**<br>设想最坏的情况 | **I tend to imagine the worst when I don’t hear from him.**<br>收不到他的消息时，我往往会往最坏的情况想。 |
| **imagine for a moment**<br>暂且想象一下 | **Imagine for a moment that you could live anywhere.**<br>暂且想象一下，你可以住在任何地方。 |

## 用法提醒

想象做某事用 `imagine doing`，不用 `imagine to do`。

`I imagine he’s busy` 通常是推想他在忙；`I imagine him working late` 是想象他工作到很晚的画面。

## 输出例句

**I can't imagine doing the same job for the next thirty years.**  
我很难想象未来三十年一直做同一份工作。

**Imagine how different things would be if we had started earlier.**  
想象一下，如果我们更早开始，事情会有多不一样。

**I had imagined the place would be much bigger.**  
我原本想象那个地方会大得多。

# 15. expect

## 核心感觉

> **预计某事会发生，或要求某人达到某种标准。**

## 语法特点

- **及物动词**：接名词、从句或不定式。
- **不定式结构**：`expect to do` 说明主语预计做什么；`expect someone to do` 说明预计或要求谁做什么。
- **被动结构**：`be expected to do` 可表示预计或按要求应当做。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **expect + noun**<br>预期某事 | **We expect some delays.**<br>我们预计会有一些延误。 |
| **expect to do**<br>预计会做 | **I expect to finish by Friday.**<br>我预计周五前完成。 |
| **expect someone to do**<br>预期/要求某人做 | **I expected him to call.**<br>我原以为他会打电话。 |
| **expect that + clause**<br>预计…… | **We expect that demand will increase.**<br>我们预计需求会增加。 |
| **be expected to do**<br>预计/应该做 | **Prices are expected to rise.**<br>预计价格会上涨。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **as expected**<br>正如预期 | **Everything went as expected.**<br>一切都按预期进行。 |
| **than expected**<br>比预期…… | **It took longer than expected.**<br>花的时间比预期更久。 |
| **fully expect**<br>完全预期 | **I fully expect him to succeed.**<br>我完全相信他会成功。 |
| **what did you expect?**<br>你还指望什么？ | **It was cheap—what did you expect?**<br>它本来就便宜，你还指望什么？ |
| **expect too much**<br>期待过高 | **Maybe we're expecting too much from the system.**<br>也许我们对这个系统期待太高了。 |

## 用法提醒

`I expect him to come` 是预计他会来；`I hope he’ll come` 是希望他来。预期的事也可以是不希望发生的，如 `expect delays`。

`I expect you to be on time` 常带要求意味。

## 输出例句

**I expected the task to be easier than this.**  
我原以为这个任务会比现在简单。

**We expect to hear back from them next week.**  
我们预计下周会收到他们的回复。

**Things didn't go quite as I expected.**  
事情的发展和我预想的不太一样。

# 16. doubt

## 核心感觉

> **不太相信，或对真实性、能力、可能性存疑。**

## 语法特点

- **及物动词**：直接接存疑的事物，也可接 `that / whether / if` 从句。
- **否定表达**：`not doubt that...` 表示相信、没有怀疑。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **doubt + noun**<br>怀疑某事 | **I never doubted his ability.**<br>我从没怀疑过他的能力。 |
| **doubt that + clause**<br>怀疑……会成立 | **I doubt that he'll agree.**<br>我觉得他多半不会同意。 |
| **doubt whether/if**<br>不确定是否 | **I doubt whether this will work.**<br>我不确定这个方法是否有效。 |
| **don't doubt that**<br>不怀疑 | **I don't doubt that she tried her best.**<br>我不怀疑她已经尽力了。 |
| **doubt what someone says**<br>怀疑某人说的话 | **I had no reason to doubt what she said.**<br>我没有理由怀疑她说的话。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **seriously doubt**<br>很怀疑 | **I seriously doubt he’ll change his mind.**<br>我很怀疑他会改变主意。 |
| **doubt someone’s ability**<br>怀疑某人的能力 | **I never doubted her ability to lead the team.**<br>我从未怀疑她带领团队的能力。 |
| **doubt yourself**<br>怀疑自己 | **One mistake doesn’t mean you should doubt yourself.**<br>一次失误不代表你就该怀疑自己。 |
| **begin to doubt**<br>开始怀疑 | **I’m beginning to doubt whether this is worth the effort.**<br>我开始怀疑这是否值得投入精力。 |
| **have no reason to doubt**<br>没有理由怀疑 | **We have no reason to doubt his account.**<br>我们没有理由怀疑他的叙述。 |

## 用法提醒

`I doubt he’ll come` 通常表示“我觉得他多半不会来”；`I don’t doubt he’ll come` 表示相信他会来。

`have doubts about / without a doubt / no doubt` 中的 `doubt` 是名词，不要与动词句型混用。

## 输出例句

**I doubt we'll finish everything today.**  
我觉得我们今天多半做不完所有事情。

**I never doubted that she was capable of doing it.**  
我从没怀疑过她有能力做到。

**The result made me doubt my original assumption.**  
这个结果让我开始怀疑自己原先的假设。

# 17. wonder

## 核心感觉

> **想知道答案，或对某事产生疑问、好奇。**

## 语法特点

- **及物用法**：可接 `if / whether` 或疑问词从句，表达想知道的内容。
- **不及物用法**：可单独使用，也可用 `about` 引出思考、好奇的对象。
- **委婉询问**：`I was wondering if...` 常用于礼貌请求。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **wonder if/whether**<br>想知道是否 | **I wonder if he's still awake.**<br>我想知道他是不是还醒着。 |
| **wonder why/how/what**<br>想知道为什么/如何/什么 | **I wonder why she changed her mind.**<br>我想知道她为什么改变主意。 |
| **I was wondering if...**<br>委婉询问 | **I was wondering if you could help me.**<br>我想问一下你能不能帮我。 |
| **wonder about + noun**<br>对……感到好奇 | **I've often wondered about that.**<br>我经常会想这件事。 |
| **wonder what to do**<br>不知道该做什么；想知道该怎么办 | **I was wondering what to do next.**<br>我当时在想接下来该怎么办。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **can't help wondering**<br>忍不住想 | **I can't help wondering what happened.**<br>我忍不住想到底发生了什么。 |
| **begin to wonder**<br>开始怀疑/开始想 | **I'm beginning to wonder if we chose the wrong approach.**<br>我开始怀疑我们是不是选错方法了。 |
| **make someone wonder**<br>让某人产生疑问 | **His reaction made me wonder what he knew.**<br>他的反应让我想知道他到底知道什么。 |
| **wonder to yourself**<br>心里琢磨 | **I wondered to myself whether I’d made the right choice.**<br>我在心里琢磨自己是否作出了正确选择。 |
| **wonder aloud**<br>把疑问说出口 | **She wondered aloud whether they should leave.**<br>她把“他们是不是该走了”这个疑问说了出来。 |

## 用法提醒

从句用陈述语序：`I wonder where he is`，不用 `where is he`。

`wonder if he’ll come` 本身是在提出疑问；`doubt he’ll come` 通常更倾向于认为不会。`no wonder` 中的 `wonder` 是名词。

## 输出例句

# 几组容易混淆的结构

| 结构 | 侧重点 | 例句 |

| **think / believe + clause** | 表达看法／相信某事为真；确定程度需结合语境 | **I think it will work. / I believe it will work.**<br>我觉得它会有效。／我相信它会有效。 |

| **know / understand / realize** | 知道信息／理解意义或原因／意识到某个事实 | **I knew the rule, but only later understood why it mattered.**<br>我知道这条规则，但后来才理解它为什么重要。 |
| **notice / recognize / realize** | 察觉到／识别、认出／形成明确认识 | **I noticed someone at the door, recognized her, and realized why she’d come.**<br>我注意到门口有人，认出了她，也明白了她为何而来。 |
| **remember doing** | 记得已经做过的事 | **I remember sending the email.**<br>我记得发过那封邮件。 |
| **remember to do** | 记得要执行某个动作 | **Remember to send the email.**<br>记得发那封邮件。 |
| **forget doing** | 忘记做过的经历，常用于否定表达 | **I’ll never forget meeting her.**<br>我永远忘不了见她的经历。 |
| **forget to do** | 忘了去执行某个动作 | **I forgot to send the email.**<br>我忘了发那封邮件。 |
| **consider / imagine doing** | 考虑做／想象做 | **I’m considering moving, but I can’t imagine leaving my friends.**<br>我在考虑搬家，但很难想象离开朋友们。 |
| **expect someone to do** | 预计或要求某人做 | **I expect him to reply today.**<br>我预计他今天会回复。 |
| **be supposed to do** | 按安排、规定或预期应该做 | **He’s supposed to reply today.**<br>按安排，他应该今天回复。 |
| **doubt / wonder if** | 不太相信会发生／想知道会不会发生 | **I doubt he’ll agree. / I wonder if he’ll agree.**<br>我觉得他多半不会同意。／我想知道他会不会同意。 |
| **consider / judge / evaluate** | 纳入考虑或认定怎样／作判断／按标准评估 | **We considered both options and evaluated their costs.**<br>我们考虑了两个选项，并评估了它们的成本。 |
| **decide to do / conclude that...** | 决定采取行动／得出关于事实的结论 | **We concluded that the plan was too risky and decided to change it.**<br>我们得出结论：计划风险太高，于是决定修改它。 |
| **study / learn / review** | 学习或研究的活动／获得知识、能力或信息／复习、审阅 | **I study English, learn through practice, and review what I’ve learned.**<br>我学习英语，通过实践掌握它，并复习学过的内容。 |

# 综合对话

| 角色 | 对话内容 |
|:---:|---|
| **A** | **Have you decided which course to take?**<br>你决定选哪门课了吗？ |
| **B** | **Not yet. I’ve compared a few, but I don’t know which one would help me most.**<br>还没。我比较了几门，但不知道哪门对我帮助最大。 |
| **A** | **What do you expect to get out of it?**<br>你希望从课程里获得什么？ |
| **B** | **I want to express myself more naturally. I understand a lot of grammar, but I often forget how to use it when I speak.**<br>我想表达得更自然。我理解不少语法，但说话时经常忘记怎么用。 |
| **A** | **Have you considered taking a conversation class?**<br>你考虑过上会话课吗？ |
| **B** | **Yes, but I assumed the other students would be much better than me.**<br>考虑过，但我之前想当然地觉得其他学生会比我强很多。 |
| **A** | **Do you know that, or are you guessing?**<br>你知道确实如此，还是在猜？ |
| **B** | **I’m guessing, I suppose. I noticed that one course offers a trial lesson.**<br>我想，应该是在猜吧。我注意到有门课提供试听。 |
| **A** | **Then try it. You can judge whether it suits you after you’ve taken a lesson.**<br>那就试试。上过一节后，你就能判断它适不适合你了。 |
| **B** | **I was wondering if you could come with me. I can’t imagine walking into the room alone.**<br>我想问问你能不能陪我去。我很难想象自己一个人走进教室。 |
| **A** | **Of course. And remember to check whether we need to book first.**<br>当然。记得先确认一下需不需要预约。 |
| **B** | **I will. I’m beginning to realize that I’ve spent more time worrying about speaking than actually speaking.**<br>我会的。我开始意识到，我担心开口的时间比实际开口的时间还多。 |
| **A** | **You don’t have to know everything before you start. You’ll learn as you go.**<br>不用等什么都懂了才开始。你会边做边学的。 |
| **B** | **That’s true. I’ll book the trial lesson tonight and review a few useful expressions beforehand.**<br>也是。我今晚就预约试听，再提前复习几个实用表达。 |
