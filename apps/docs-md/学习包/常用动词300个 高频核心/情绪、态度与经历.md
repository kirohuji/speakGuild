# 情绪、态度与经历

## 阅读说明

- **及物动词（transitive verb）**：可以直接接宾语。  
  `I need more time.` → `more time` 是宾语。

- **不及物动词（intransitive verb）**：不直接接宾语，可以另接介词短语等成分。  
  `Something happened.` / `Listen to me.`

- **系动词（linking verb）**：接表语，说明主语的身份、性质或状态。  
  `She seems tired.` / `The sky turned dark.`

- **使役结构（causative construction）**：表示使、促使或允许某个动作发生。  
  `make someone do` / `let someone do` / `get someone to do`

- **宾语补足语（object complement）**：在宾语后补充说明宾语的状态、身份或动作。  
  `keep the door open` → `open` 说明门的状态。

- **双宾语结构（double-object construction）**：接两个宾语，通常先说接受者，再说给予的东西。  
  `She gave me a book.` → `me` 是间接宾语，`a book` 是直接宾语。

同一个动词可以有多种用法；以上分类的角度不同，也可以同时适用。

### 结构写法

#### 1. 占位符与符号

| 标记 | 含义 |
| --- | --- |
| `someone / something` | 可替换的人／事物 |
| `noun / adjective` | 名词／形容词 |
| `place / time` | 地点／时间 |
| `clause / wh-clause` | 从句／由 what、why、how 等疑问词引导的从句 |
| `do / doing / done` | 动词原形／V-ing 形式／过去分词 |
| `+` | 连接成分，不写进实际句子 |
| `( )` | 该成分可以省略 |

#### 2. 结构示例

把占位符换成具体内容，保留固定介词和不定式标记。

| 结构 | 实际表达 |
| --- | --- |
| `enjoy doing` | **enjoy walking alone**<br>喜欢独自散步 |
| `regret to do` | **regret to inform you**<br>很遗憾地通知你 |
| `struggle with + noun` | **struggle with long sentences**<br>处理长句有困难 |
| `be interested in doing` | **be interested in learning jazz guitar**<br>对学爵士吉他感兴趣 |
| `worry (that) + clause` | **worry (that) we might be late**<br>担心我们可能迟到，`that` 可以省略 |

# 1. enjoy

## 核心感觉

> **从活动、经历或处境中感到愉快。**

## 语法特点

- **及物动词**：接活动、经历等名词，也可接 `V-ing`。
- **反身结构**：`enjoy yourself` 表示玩得开心。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **enjoy + noun**<br>喜欢、享受某事物 | **I really enjoyed the movie.**<br>我真的很喜欢这部电影。 |
| **enjoy doing**<br>喜欢做某事 | **I enjoy reading at night.**<br>我喜欢晚上看书。 |
| **enjoy yourself**<br>玩得开心 | **Did you enjoy yourself?**<br>你玩得开心吗？ |
| **enjoy being...**<br>享受处于某状态 | **I enjoy being alone sometimes.**<br>有时候我很享受独处。 |
| **enjoy the experience**<br>享受经历 | **Try to enjoy the experience.**<br>尽量享受这个过程。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **really enjoy**<br>很喜欢 | **I really enjoy this kind of work.**<br>我真的很喜欢这种工作。 |
| **thoroughly enjoy**<br>非常享受 | **I thoroughly enjoyed the book.**<br>这本书我读得非常享受。 |
| **enjoy your time**<br>享受时光 | **I hope you enjoy your time here.**<br>希望你在这里过得愉快。 |
| **enjoy doing something alone**<br>喜欢独自做某事 | **I enjoy walking alone.**<br>我喜欢一个人散步。 |
| **enjoy every moment**<br>享受每一刻 | **Try to enjoy every moment.**<br>尽量享受每一刻。 |

## 用法提醒

说“喜欢做某事”用 `enjoy doing`。在告别或把东西递给别人时，也可以单独说 **Enjoy!**，祝对方好好享用。

## 输出例句

**I enjoy learning things when I can actually use them.**  
当学到的东西能够真正使用时，我会很享受学习过程。

**I didn't expect to enjoy the trip as much as I did.**  
我没想到自己会这么享受这次旅行。

**Sometimes I enjoy doing nothing for an entire afternoon.**  
有时候我很享受整个下午什么都不做。

# 2. love

## 核心感觉

> **深爱某人，或非常喜欢某物、某项活动。**

## 语法特点

- **及物动词**：可接人、事物、`V-ing` 或 `to do`。
- **意愿结构**：`would love to do` 表达很想做某事。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **love someone**<br>爱某人 | **I love my family.**<br>我爱我的家人。 |
| **love something**<br>非常喜欢某物 | **I love this song.**<br>我太喜欢这首歌了。 |
| **love doing**<br>很喜欢做某事 | **I love reading late at night.**<br>我很喜欢深夜阅读。 |
| **love to do**<br>很喜欢做某事 | **I love to walk here in the morning.**<br>我喜欢早上来这里散步。 |
| **would love to do**<br>非常想做 | **I'd love to go with you.**<br>我很想和你一起去。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **absolutely love**<br>特别喜欢 | **I absolutely love this place.**<br>我特别喜欢这里。 |
| **love having someone around**<br>喜欢有某人在身边 | **I love having you around.**<br>我喜欢你在身边。 |
| **love the idea of**<br>很喜欢……这个想法 | **I love the idea of working remotely.**<br>我很喜欢远程工作的想法。 |
| **love every minute of**<br>全程都很享受 | **I loved every minute of the trip.**<br>这次旅行我全程都很享受。 |
| **love someone deeply**<br>深爱某人 | **He loved her deeply.**<br>他深爱着她。 |

## 用法提醒

日常口语里，`I love this song` 只是说非常喜欢这首歌。`I’d love to` 还可以单独回答邀请。

## 输出例句

**I love stories that leave me thinking for days afterward.**  
我很喜欢那种看完以后还能让我思考好几天的故事。

**I'd love to hear what you think about it.**  
我很想听听你对这件事的看法。

**She loves working on projects where she can create something from scratch.**  
她很喜欢做那种可以从零创造东西的项目。

# 3. like

## 核心感觉

> **喜欢某人某物，或习惯选择某种做法。**

## 语法特点

- **及物动词**：接名词、`V-ing` 或 `to do`。
- **请求或意愿**：`would like to do` 表示自己想做，`would like someone to do` 表示希望某人做。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **like + noun**<br>喜欢某物 | **I like this version better.**<br>我更喜欢这个版本。 |
| **like doing**<br>喜欢做某事 | **I like working alone.**<br>我喜欢独自工作。 |
| **like to do**<br>喜欢 / 习惯做 | **I like to plan my day in advance.**<br>我喜欢提前规划一天。 |
| **would like to do**<br>想要做 | **I'd like to ask you something.**<br>我想问你一件事。 |
| **would like someone to do**<br>希望某人做 | **I'd like you to check this.**<br>我希望你检查一下这个。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **really like**<br>很喜欢 | **I really like the way this is organized.**<br>我很喜欢这个组织方式。 |
| **like better**<br>更喜欢 | **Which one do you like better?**<br>你更喜欢哪个？ |
| **like the idea of**<br>喜欢……这个想法 | **I like the idea of keeping things simple.**<br>我喜欢把事情保持简单这个想法。 |
| **if you like**<br>如果你愿意 | **You can stay here if you like.**<br>如果你愿意，可以留在这里。 |
| **would you like something?**<br>你想要某物吗 | **Would you like some tea?**<br>你想喝点茶吗？ |

## 用法提醒

一般偏好里，`like doing` 和 `like to do` 常可互换。`I like to check my schedule first` 更容易理解成我习惯先查看日程。

## 输出例句

**I like explanations that show the logic behind the grammar.**  
我喜欢能够解释语法背后逻辑的说明。

**I'd like to spend more time practicing speaking.**  
我想花更多时间练口语。

**I like him, but I don't always agree with him.**  
我喜欢他，但并不总是同意他的观点。

# 4. dislike

## 核心感觉

> **对某人、某物或某项活动持不喜欢的态度。**

## 语法特点

- **及物动词**：直接接人、事物或 `V-ing`，如 `dislike being interrupted`。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **dislike + noun**<br>不喜欢某物 | **I dislike crowded places.**<br>我不喜欢拥挤的地方。 |
| **dislike someone**<br>不喜欢某人 | **He clearly dislikes me.**<br>他显然不喜欢我。 |
| **dislike doing**<br>不喜欢做某事 | **I dislike waiting for people.**<br>我不喜欢等人。 |
| **dislike being + past participle**<br>不喜欢被…… | **He dislikes being watched while he works.**<br>他工作时不喜欢被人盯着看。 |
| **dislike the idea of**<br>不喜欢……的想法 | **I dislike the idea of rushing the decision.**<br>我不喜欢匆忙作决定这个想法。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **dislike being rushed**<br>不喜欢被催 | **I dislike being rushed when I’m making a decision.**<br>我作决定时不喜欢被催。 |
| **strongly dislike**<br>很不喜欢 | **She strongly dislikes being interrupted.**<br>她很不喜欢别人打断她。 |
| **openly dislike**<br>明显表现出不喜欢 | **They openly disliked each other.**<br>他们公开表现出彼此不喜欢。 |
| **dislike the way...**<br>不喜欢……的方式 | **I dislike the way he talks to new staff.**<br>我不喜欢他和新员工说话的方式。 |
| **come to dislike**<br>渐渐不喜欢 | **Over time, I came to dislike the long commute.**<br>时间久了，我渐渐厌烦了漫长的通勤。 |

## 用法提醒

口语中 `don’t like` 很常见。`dislike` 更直接，`hate` 往往表达更强烈的情绪。

## 输出例句

**I dislike being rushed when I'm trying to think carefully.**  
我认真思考时很不喜欢被催。

**She dislikes conflict, so she often avoids difficult conversations.**  
她不喜欢冲突，所以经常回避困难的谈话。

**I came to dislike the long commute.**  
我渐渐厌烦了漫长的通勤。

# 5. hate

## 核心感觉

> **非常讨厌某事，或很不情愿面对某个情况。**

## 语法特点

- **及物动词**：可接名词、`V-ing` 或 `to do`。
- **原因结构**：`hate someone for doing` 表示因对方的行为而怨恨对方。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **hate + noun**<br>非常讨厌 | **I hate loud noises.**<br>我很讨厌巨大的噪音。 |
| **hate doing**<br>很讨厌做某事 | **I hate waiting.**<br>我很讨厌等。 |
| **hate to do**<br>不愿做某事 | **I hate to say this, but you're wrong.**<br>我不想这么说，但你错了。 |
| **would hate to do**<br>很不希望发生 | **I'd hate to lose all this work.**<br>我可不希望这些工作全丢了。 |
| **hate someone for doing**<br>因某事怨恨某人 | **She hated him for lying to her.**<br>她因为他撒谎而怨恨他。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **absolutely hate**<br>极其讨厌 | **I absolutely hate being late.**<br>我特别讨厌迟到。 |
| **hate the idea of**<br>很讨厌……这个想法 | **I hate the idea of wasting time.**<br>我很讨厌浪费时间这件事。 |
| **hate to admit**<br>不愿承认 | **I hate to admit it, but you were right.**<br>我不愿承认，但你是对的。 |
| **hate it when...**<br>很讨厌……的时候 | **I hate it when plans change at the last minute.**<br>我很讨厌计划在最后一刻改变。 |
| **hate to see**<br>不忍看到 | **I hate to see you so upset.**<br>看到你这么难过，我心里也不好受。 |

## 用法提醒

**I hate waiting.** 表达对等待的厌恶。**I hate to say this.** 常在说出难开口的话之前使用。

## 输出例句

**I hate feeling like I'm wasting time on something that doesn't matter.**  
我很讨厌把时间浪费在没意义的事情上的感觉。

**I'd hate to make the same mistake again.**  
我很不希望再犯同样的错误。

**She hated being treated as if her opinion didn't matter.**  
她很讨厌别人把她当成意见无关紧要的人。

# 6. fear

## 核心感觉

> **害怕某事，或担忧较严重的后果。**

## 语法特点

- **及物用法**：接所害怕的事物、`V-ing` 或 `that` 从句。
- **介词结构**：`fear for someone’s safety` 表示担心某人的安全。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **fear + noun**<br>害怕某物 | **Many people fear failure.**<br>很多人害怕失败。 |
| **fear doing**<br>害怕做某事会带来后果 | **He feared losing his job.**<br>他害怕失去工作。 |
| **fear that...**<br>担心…… | **I fear that we may be too late.**<br>我担心我们可能太晚了。 |
| **be feared by**<br>被……害怕 | **The animal is feared by local villagers.**<br>当地村民很害怕这种动物。 |
| **fear the worst**<br>担心最坏情况 | **When he didn't call, we feared the worst.**<br>他没有打电话，我们担心出了最坏的情况。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **fear something more than anything else**<br>最害怕某事 | **He feared losing control more than anything else.**<br>他最害怕失去控制。 |
| **fear losing something**<br>害怕失去某物 | **She feared losing her independence.**<br>她害怕失去独立生活的能力。 |
| **fear for someone's safety**<br>担心某人安全 | **We feared for his safety.**<br>我们担心他的安全。 |
| **fear the consequences**<br>担心后果 | **They feared the consequences of speaking out.**<br>他们担心公开发声的后果。 |
| **have nothing to fear**<br>没什么可害怕的 | **You have nothing to fear from a little feedback.**<br>听一点反馈没什么可怕的。 |

## 用法提醒

日常担心一般问题时常用 `worry about`。`I fear we may be too late` 语气较正式，也常暗示说话人认为坏结果可能已经发生。

## 输出例句

**People often fear change even when the current situation isn't good.**  
即使现状并不好，人们也经常害怕改变。

**He feared making the wrong decision.**  
他害怕作出错误决定。

**We feared for her safety when she didn’t come home.**  
她没回家，我们担心她的安全。

# 7. worry

## 核心感觉

> **自己感到担心，或使别人担心。**

## 语法特点

- **不及物用法**：`worry about something` 说明担心什么，也可接 `that` 从句。
- **及物用法**：担忧的原因作主语，担忧的人作宾语。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **worry about**<br>担心某事 | **Don't worry about it.**<br>别担心这件事。 |
| **worry that...**<br>担心…… | **I worry that we're moving too fast.**<br>我担心我们推进得太快。 |
| **worry someone**<br>让某人担心 | **His silence worried me.**<br>他的沉默让我担心。 |
| **be worried about**<br>对……感到担心 | **I'm worried about the deadline.**<br>我担心截止日期。 |
| **nothing to worry about**<br>没什么可担心 | **There's nothing to worry about.**<br>没什么可担心的。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **constantly worry**<br>一直担心 | **He constantly worries about money.**<br>他总是担心钱。 |
| **worry too much**<br>过度担心 | **You worry too much.**<br>你担心得太多了。 |
| **start to worry**<br>开始担心 | **I started to worry when she didn't reply.**<br>她一直没回复，我开始担心。 |
| **worried sick**<br>担心得不得了 | **Her parents were worried sick.**<br>她父母担心得不得了。 |
| **worry yourself sick**<br>担心得不得了 | **He worried himself sick waiting for the call.**<br>等电话时，他担心得不得了。 |

## 用法提醒

**I worry about the delay.** 是我担心延误。**The delay worries me.** 是延误让我担心。

## 输出例句

**I tend to worry about things that haven't happened yet.**  
我很容易担心那些还没发生的事情。

**The delay worried me more than I expected.**  
这次延误让我比预想中更担心。

**Worrying about every possible outcome doesn't make the decision easier.**  
担心每一种可能结果，并不会让决定变得更容易。

# 8. mind

## 核心感觉

> **介意某个行为，也可提醒别人留心。**

## 语法特点

- **及物用法**：接名词、`V-ing` 或“人 + V-ing”。
- **请求与许可**：`Would you mind doing...?` 请对方做，`Do you mind if I...?` 问对方是否介意我做。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **mind + noun**<br>介意某事 | **I don't mind the noise.**<br>我不介意噪音。 |
| **mind doing**<br>介意做某事 | **I don't mind waiting.**<br>我不介意等。 |
| **mind someone doing**<br>介意某人做某事 | **Do you mind me sitting here?**<br>你介意我坐这里吗？ |
| **would you mind doing**<br>你介意做……吗 | **Would you mind closing the door?**<br>你介意把门关上吗？ |
| **do you mind if...**<br>你介意我……吗 | **Do you mind if I sit here?**<br>你介意我坐这里吗？ |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **don't mind**<br>不介意 | **I don't mind at all.**<br>我完全不介意。 |
| **wouldn't mind**<br>挺想；不介意 | **I wouldn't mind a cup of coffee.**<br>我倒挺想喝杯咖啡。 |
| **never mind**<br>算了；没关系 | **Never mind. It's not important.**<br>算了，不重要。 |
| **mind your own business**<br>管好自己的事 | **Just mind your own business.**<br>管好你自己的事。 |
| **mind the gap**<br>小心间隙 | **Mind the gap.**<br>小心站台间隙。 |

## 用法提醒

别人问 **Do you mind if I sit here?**，同意时可答 **No, go ahead.**。`wouldn’t mind` 还可表示“倒也想要”。

## 输出例句

**I don't mind working alone as long as I know what I need to do.**  
只要知道自己该做什么，我并不介意独自工作。

**Would you mind explaining that again?**  
你介意再解释一遍吗？

**I wouldn't mind taking a few days off.**  
我倒挺想休几天。

# 9. regret

## 核心感觉

> **对已经发生的事感到后悔，或遗憾地告知某事。**

## 语法特点

- **及物用法**：接名词、`V-ing` 或 `that` 从句。
- **正式告知**：`regret to say / inform / tell` 用来引出坏消息。

## 高频结构

| 结构 | 例句 |
| --- | --- |
| **regret + noun**<br>后悔某事 | **I regret my decision.**<br>我后悔自己的决定。 |
| **regret doing**<br>后悔做过 | **I regret saying that.**<br>我后悔说了那句话。 |
| **regret that...**<br>遗憾…… | **I regret that things ended this way.**<br>我很遗憾事情这样结束。 |
| **regret to say**<br>遗憾地说 | **I regret to say that we can't accept the proposal.**<br>很遗憾，我们无法接受这个提案。 |
| **live to regret**<br>将来会后悔 | **You may live to regret that decision.**<br>你以后可能会后悔这个决定。 |

## 高频搭配

| 搭配 | 例句 |
| --- | --- |
| **deeply regret**<br>深感后悔 | **I deeply regret what happened.**<br>我对发生的事深感后悔。 |
| **immediately regret**<br>立刻后悔 | **I immediately regretted saying it.**<br>我一说完就后悔了。 |

# 综合对话

**A:** Did you enjoy the workshop yesterday?

你喜欢昨天的工作坊吗？

**B:** Yes. I was surprised by how much I enjoyed it. I still struggled to speak in front of everyone, though.

喜欢。我没想到自己会这么喜欢。不过当着大家的面说话，我还是觉得有点吃力。

**A:** What interested you most?

你最感兴趣的是什么？

**B:** The part about telling stories. I loved hearing how everyone described the same picture differently.

讲故事那部分。我很喜欢听大家用不同的方式描述同一张图。

**A:** I missed that part. Do you mind if I look at your notes?

我错过了那部分。你介意我看看你的笔记吗？

**B:** No, go ahead. I regret not writing down the last example, though.

不介意，你看吧。不过我有点后悔没把最后一个例子记下来。

**A:** Are you worried about the next session?

你担心下次活动吗？

**B:** A little. It frustrates me when I know what I want to say but can’t find the words.

有一点。明明知道自己想说什么，却找不到合适的词，这让我挺挫败的。

**A:** You looked more relaxed by the end. I admired the way you kept going after you lost your place.

到最后你看起来放松多了。你说到一半忘了说到哪儿，还能继续讲下去，我挺佩服的。

**B:** Thanks. I was disappointed with my first answer, but I’m satisfied with how I finished. I’m excited to go back next week.

谢谢。我对第一个回答有点失望，不过对最后的表现挺满意。我很期待下周再去。
