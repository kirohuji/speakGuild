# 动作与对象｜常见动词 + 介词

## 概念说明

英语动词的意义通常不能只用一个中文词对应。

一个高频动词往往同时包含：

- 基本动作意义
- 常见宾语类型
- 介词搭配
- 固定句型
- 词块
- 短语动词
- 不同语境中的意义延伸

例如 **look**：

| 表达 | 常见意思 |
| --- | --- |
| **look at something** | 看某物 |
| **look for something** | 寻找某物 |
| **look after someone** | 照顾某人 |
| **look into something** | 调查某事 |
| **look through something** | 浏览、检查 |
| **look around** | 四处看看 |

这些表达共享 **look** 这个动作核心，但不同的小词改变了动作与后续内容之间的关系。

因此，一个动词更适合按照“用法网络”来理解，而不是只记一个中文释义。

---

# 一、为什么有些动词需要介词？

英语动词和后续成分之间的连接方式，首先受到动词本身句法性质的影响。

## 1. 及物动词：可以直接连接宾语

有些动词可以直接带宾语。

例如：

> I **need help**.  
> 我需要帮助。

> She **opened the door**.  
> 她打开了门。

> We **discussed the problem**.  
> 我们讨论了这个问题。

结构是：

> **verb + object**

这里动词可以直接建立和宾语之间的关系。

---

## 2. 不及物动词：不能直接带宾语

有些动词不能直接把名词作为宾语。

例如：

> listen  
> wait  
> look

如果要继续说明对象，通常需要介词：

> listen **to** music

> wait **for** the bus

> look **at** the screen

结构变成：

> **verb + preposition + object**

这里的介词负责连接动作和后面的对象。

---

## 3. 直接宾语与介词宾语

| 结构 | 例子 | 中文 |
| --- | --- | --- |
| **verb + object** | discuss the problem | 讨论这个问题 |
| **verb + preposition + object** | talk about the problem | 谈论这个问题 |
| **verb + object** | enter the room | 进入房间 |
| **verb + preposition + object** | go into the room | 走进房间 |
| **verb + object** | answer the question | 回答问题 |
| **verb + preposition + object** | respond to the question | 回应这个问题 |

中文意思可能接近，但英语内部采用的结构不同。

---

## 4. 及物性不是唯一因素

“后面有介词”不能简单理解成“这个动词一定是不及物动词”。

很多英语动词会随着意义和结构变化。

例如 **look**：

> You **look tired**.

这里 **look** 是系动词。

> Look **at me**.

这里 **look** 通过 **at** 连接对象。

再比如 **agree**：

> I agree.

句子可以直接结束。

> I agree **with you**.

表示同意某个人。

> We agreed **on a date**.

表示就某件事情达成一致。

所以学习动词时，需要把：

> **意义 + 结构 + 搭配**

一起掌握。

---

# 二、动词 + 介词有没有规律？

有规律，但不能完全靠规则推导。

介词本身通常带有关系意义：

| 介词 | 常见关系 |
| --- | --- |
| **to** | 朝向、目标 |
| **at** | 指向某个点 |
| **for** | 目标、期待 |
| **about** | 围绕某个话题 |
| **on** | 依托、注意对象 |
| **from** | 来源、起点 |
| **with** | 互动、联系 |
| **in** | 范围、领域 |

这些关系会继续进入动词搭配。

例如：

> look **at** the screen

视线指向屏幕。

> wait **for** the bus

等待的目标是公交。

> talk **about** work

谈话围绕工作展开。

> depend **on** the weather

结果依赖天气。

---

## 规律的三个层次

### 1. 关系比较透明

| 表达 | 关系 |
| --- | --- |
| look **at** | 动作指向对象 |
| talk **to** | 动作朝向交流对象 |
| wait **for** | 等待目标 |
| learn **from** | 来源 |
| focus **on** | 注意力对象 |

这些搭配可以比较容易地从介词本身的关系理解。

---

### 2. 有逻辑，但已经形成固定搭配

例如：

- **depend on**
- **deal with**
- **succeed in**
- **belong to**

它们仍然可以借助介词的基本意义理解，但实际使用时要把整体结构记住。

---

### 3. 整体意义已经固定

例如：

- **look after**
- **give up**
- **find out**
- **put up with**
- **get away with**

这类表达已经具有较强的整体性，单独分析每个小词不足以推出完整意思。

---

# 三、动词的用法网络

高频动词更适合按照“用法网络”来理解。

例如 **look**：

| 类型 | 表达 |
| --- | --- |
| 基本动作 | look |
| 指向对象 | look at something |
| 寻找目标 | look for something |
| 照顾对象 | look after someone |
| 调查事情 | look into something |
| 浏览内容 | look through something |
| 四处观察 | look around |

因此，一个动词的学习内容通常包括：

> **核心意义 + 结构 + 搭配 + 对象类型 + 常见词块**

# 十二、同一动词与不同介词

同一个动词可以通过不同介词形成不同关系。

## look

| 表达 | 常见意思 |
| --- | --- |
| **look at** | 看 |
| **look for** | 寻找 |
| **look after** | 照顾 |
| **look into** | 调查 |
| **look through** | 浏览、检查 |
| **look around** | 四处看看 |

### 对比

> I'm **looking at** my phone.  
> 我正在看手机。

> I'm **looking for** my phone.  
> 我正在找手机。

---

## think

| 表达 | 常见意思 |
| --- | --- |
| **think about** | 考虑、思考 |
| **think of** | 想到、想出、评价 |

> I'm thinking **about** changing jobs.  
> 我正在考虑换工作。

> I can't think **of** a better idea.  
> 我想不出更好的主意。

> What do you think **of** the movie?  
> 你觉得这部电影怎么样？

---

## agree

| 表达 | 常见意思 |
| --- | --- |
| **agree with someone** | 同意某人 |
| **agree with an idea** | 同意某个观点 |
| **agree on something** | 就某事达成一致 |

> I agree **with** you.

> We agreed **on** a date.

---

## ask

| 表达 | 常见意思 |
| --- | --- |
| **ask for something** | 请求得到某物 |
| **ask about something** | 询问某事 |
| **ask someone for something** | 向某人要某物 |
| **ask someone about something** | 向某人询问某事 |

> I asked Daniel **for help**.

> I asked Daniel **about the meeting**.

# 十三、一个动作可以连接多个对象

英语里，一个动词可以同时连接人、事情、原因等不同关系。

| 结构 | 例子 |
| --- | --- |
| **talk to someone about something** | talk to Daniel about the project |
| **apologize to someone for something** | apologize to her for being late |
| **complain to someone about something** | complain to the manager about the service |
| **ask someone for something** | ask Daniel for help |
| **ask someone about something** | ask Daniel about the meeting |

### 例句

> I talked **to Daniel about the project**.

其中：

- **to Daniel**：交流对象
- **about the project**：交流内容

---

> I apologized **to her for being late**.

其中：

- **to her**：接受道歉的人
- **for being late**：道歉原因

# 十四、为什么英语里有大量动词短语？

英语里有很多意义较宽、使用频率很高的基础动词：

- get
- go
- come
- take
- put
- give
- bring
- keep
- turn
- look

这些动词本身承担动作核心，再通过：

- in
- out
- on
- off
- up
- down
- over
- through
- back
- away

等高频小词补充方向、状态、结果和关系。

例如：

| 基础动词 | 组合 | 常见意思 |
| --- | --- | --- |
| **go** | go out | 出去 |
|  | go back | 回去 |
|  | go through | 经历 / 穿过 |
| **take** | take out | 拿出去 |
|  | take off | 脱掉 / 起飞 |
|  | take over | 接管 |
| **put** | put on | 穿上 / 放上 |
|  | put down | 放下 |
|  | put away | 收起来 |
|  | put off | 推迟 |
| **get** | get in | 进去 |
|  | get out | 出去 |
|  | get back | 回来 |
|  | get over | 克服 / 恢复 |

这种“基础动词 + 高频小词”的组合，是英语日常表达里非常重要的一部分。

# 十五、空间意义向抽象意义延伸

很多介词和小词最初描述空间关系，后来继续扩展到抽象关系。

| 空间表达 | 抽象表达 |
| --- | --- |
| go **into** the room | go **into** detail |
| go **through** the tunnel | go **through** a difficult period |
| something **on** the table | focus **on** the problem |
| come **from** London | recover **from** an illness |
| look **at** the door | look **at** the problem |

例如：

> go **through** a tunnel  
> 穿过隧道

进一步可以说：

> go **through** a difficult time  
> 经历一段困难时期

**through** 的“从一个过程内部经过”的关系被延伸到了抽象经历。

# 十六、动词 + 介词与短语动词

## 动词 + 介词

介词负责连接后面的对象。

例如：

> listen **to music**

> wait **for the bus**

> talk **about work**

> depend **on the weather**

后面的名词是介词所连接的对象。

---

## 动词 + 小品词

小词直接参与构成整个动作意义。

例如：

> wake **up**

> sit **down**

> go **out**

> come **back**

> give **up**

> find **out**

这里的小词已经成为动作意义的一部分。

---

## 三词结构

英语里还有很多：

> verb + particle + preposition

例如：

> **look forward to** something

> **put up with** something

> **get away with** something

这些表达整体性更强。

例如：

> I'm looking forward to seeing you.

这里需要掌握：

> **look forward to something**

> **look forward to doing something**

---

# 十七、介词逻辑和固定搭配的关系

理解介词的基本关系有助于记忆：

> at → 指向  
> for → 目标  
> about → 话题  
> on → 依托  
> from → 来源

但自然英语还受到长期习惯用法影响。

因此，比较合适的学习方式是：

> **用介词关系理解 + 用完整搭配记忆**

例如：

> depend on something

可以理解 **on** 的“依托关系”，同时把：

> **depend on**

作为完整搭配熟悉。
