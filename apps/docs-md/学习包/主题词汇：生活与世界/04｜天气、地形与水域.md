# 一、天气与气候

## 1. sunny

### 核心感觉

**晴朗的**。强调有阳光的天气；可描述某天、某地的气候。

### 词性与用法

sunny 是形容词；天气句常用 It is sunny，而不是 It has sunny。

### 高频结构与搭配

| 表达 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **a sunny day** | 晴朗的一天 | **We picked a sunny day for the picnic.**<br>我们选了个晴天去野餐。 |
| **sunny spells** | 间歇的晴朗时段 | **There will be a few sunny spells in the afternoon.**<br>下午会有几段晴朗天气。 |

### 英语思维

记忆 **sunny** 时，把“晴朗的”与具体场景连接起来：强调有阳光的天气；可描述某天、某地的气候。 特别留意它与邻近词的类别差别，再决定如何选用搭配。

### 输出例句

**We picked a sunny day for the picnic.**  
我们选了个晴天去野餐。

**There will be a few sunny spells in the afternoon.**  
下午会有几段晴朗天气。

| 组合 | 核心区别 | 例句 |
| --- | --- | --- |
| **sunny / cloudy / rainy / snowy** | 描述天气特征；rainy 可指多雨的时段，snowy 也可形容覆雪的景观。 | **It was cloudy in the morning but sunny by noon.**<br>早晨多云，但到中午就晴了。 |
| **storm / thunder / lightning** | storm 是风暴天气；thunder 是雷声；lightning 是闪电。 | **We saw lightning before we heard thunder.**<br>我们先看到闪电，随后听到雷声。 |
| **humid / wet / damp** | humid 强调空气湿度；wet 指明显潮湿；damp 指微湿。 | **The air is humid, and my shirt feels damp.**<br>空气很潮湿，我的衬衫摸起来也有点湿。 |
| **mountain / hill** | 都表示高起的地形，hill 通常较小或缓；没有通用高度界限。 | **The village sits on a hill below the mountains.**<br>村庄位于群山下方的一座山丘上。 |
| **valley / canyon** | valley 是较广义的谷地；canyon 更强调深而陡的峡谷。 | **The river carved a deep canyon through the plateau.**<br>河流在高原中切割出一条深峡谷。 |
| **plain / plateau** | plain 偏平坦地形；plateau 强调海拔较高且相对平坦。 | **The plateau rises above the surrounding plains.**<br>高原高出周围的平原。 |
| **ocean / sea** | ocean 通常规模更大；sea 常用于较具体、靠近陆地的海域及专名。 | **The ship left the sea and crossed the open ocean.**<br>船只离开近海，驶过开阔的大洋。 |
| **river / stream / lake / pond** | river、stream 流动；lake、pond 通常指相对静止的水体。 | **A stream flows from the hills into the lake.**<br>一条小溪从山丘流入湖中。 |
| **bay / coast / beach** | bay 是海湾水域；coast 是海岸地带；beach 是具体的滩地。 | **There is a quiet beach inside the bay.**<br>海湾里有一处安静的海滩。 |
| **tide / wave / current** | tide 是周期性涨退潮；wave 是波浪；current 是水流。 | **The tide is coming in, and the waves are getting stronger.**<br>正在涨潮，海浪也越来越大。 |

| **There is / are + noun** | 引入自然现象或地貌。 | **There is a waterfall beyond the forest.**<br>森林那边有一处瀑布。 |
| **be located in / on / near** | 描述地理位置，根据具体地点选择介词。 | **The village is located in a valley.**<br>村庄位于山谷中。 |
| **flow into / through** | 描述水流方向或经过的地点。 | **The river flows through the canyon into the sea.**<br>河流穿过峡谷流入大海。 |
| **be covered with / in** | 描述被某种物质覆盖。 | **The mountains were covered in snow.**<br>群山被积雪覆盖。 |
| **at high tide / at low tide** | 表示涨潮、落潮期间的状态。 | **The rocks disappear underwater at high tide.**<br>涨潮时岩石没入水下。 |

# 综合情境案例

## 案例一：描述天气并调整出行

**It was sunny when we left home, but the sky soon turned cloudy. By the afternoon, strong winds brought a storm, so we changed our plans.**  
我们出门时天气晴朗，但天空很快转阴。到了下午，强风带来了一场风暴，于是我们改变了计划。

## 案例二：介绍山地风景

**The village lies in a narrow valley between two mountains. A clear stream runs past it, and a waterfall is hidden deep in the forest.**  
村庄位于两座山之间的狭窄山谷里。一条清澈的小溪流经村庄，森林深处还藏着一处瀑布。

## 案例三：介绍海岸与潮汐

**There is a sheltered bay along the coast. At low tide, you can walk across the beach to the rocks, but you need to return before the tide comes in.**  
沿海岸有一处避风海湾。退潮时，你可以穿过沙滩走到岩石区，但必须在涨潮前返回。

# 情境改写

1. 把 **It was windy.** 扩展成一句包含结果的英文，解释为什么取消活动。
2. 使用 **mountain / valley / stream** 三个词，用两句话介绍一个村庄的地理环境。
3. 使用 **bay / coast / beach** 三个词描述一次海边旅行，体现三者的不同。

# 复习清单

- **天气形容词**：sunny、cloudy、rainy、snowy、windy、humid、foggy；练习 It is... 和 a ... day。
- **自然现象**：storm、thunder、lightning、drought；区分天气事件、声音、电光和长期气候异常。
- **地形区别**：mountain / hill、valley / canyon、plain / plateau、cliff / cave。
- **水域区别**：ocean / sea、river / stream、lake / pond、coast / bay / beach。
- **动作搭配**：a storm approaches、thunder rumbles、lightning strikes、a volcano erupts、a river flows into...。
- **介词搭配**：in a valley、on an island、along the coast、on the beach、at high tide。
