# 主题词汇：生活与世界

# 10｜家庭、房屋与家居

## 综合目标

掌握家庭成员、房屋房间、家具和家居用品词汇，并能够在介绍家人、描述居住环境与整理家居等场景中准确运用。

> 本话题保留「家庭成员与亲属」「房屋与房间」「家具与家居用品」三个子主题。核心词汇为主要记忆对象；易混淆词、数量及介词搭配在各节和文末集中讲解。

### 词汇用法与例句

#### 1. parent

**核心感觉**

**parent**：父亲或母亲；家长。

**高频结构与搭配**

| 结构 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **single parent / parents** | 单亲家长／父母；可结合具体场景记忆。 | **Both of my parents work full-time.**<br>我的父母都做全职工作。 |

**用法提醒**

parent 是单数；parents 常指父母双方，也可能泛指多位家长。

**英语思维**

描述亲属关系时先确认以谁为中心，再确定家庭树上的人物；同一个英语词往往覆盖多个中文亲属称呼。

**输出例句**

**Both of my parents work full-time.**  
我的父母都做全职工作。

**A parent must sign this form.**  
这张表必须由一位家长签名。

## 2. 房屋与房间

## 情境改写

1. **I live in an apartment.** → 补充卧室数量和阳台。  
   **I live in a two-bedroom apartment with a small balcony.**  
   我住在一套带小阳台的两居室公寓里。

2. **The books are there.** → 用 shelf 说明位置。  
   **The books are on the shelf above my desk.**  
   书在我桌子上方的搁板上。

3. **She is family.** → 明确亲属关系。  
   **She is my cousin on my mother’s side.**  
   她是我母亲那边的表姐妹。

4. **The room is small.** → 说明收纳特点。  
   **The bedroom is small, but it has a built-in wardrobe.**  
   卧室不大，但有嵌入式衣柜。

## 知识点复习清单

- **亲属**：parent / sibling / cousin / nephew / niece；注意亲属关系的参照人物。
- **房屋**：house / apartment / home；room 名称与 hallway、basement、attic 等位置。
- **家具**：wardrobe / cupboard / drawer / shelf；pillow / cushion；carpet / rug。
- **词形**：shelf → shelves；two-bedroom apartment；a pair of curtains。
- **空间表达**：on the balcony、in the hallway、in the wardrobe、on the sofa、in the drawer、on the shelf。
- **主动输出**：介绍家庭关系、描述户型、说明物品位置与用途。
