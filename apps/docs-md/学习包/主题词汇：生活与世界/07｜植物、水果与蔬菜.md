# 主题词汇：生活与世界

# 07｜植物、水果与蔬菜

## 综合目标

认识常见树木、花卉与植物结构，掌握水果、蔬菜和菌菇的名称、词形变化、常用搭配，以及购买、烹饪、描述植物时的自然表达。

> 本话题按原四个主题整理，共 45 个核心词汇。每个词汇配中文释义、使用见解和两组双语例句；容易混淆的内容统一放在文末辨析。

## 五、核心混淆与使用难点

| 对比 | 使用见解 | 例句 |
| --- | --- | --- |
| **tree / shrub / vine** | tree 通常有明显主干；shrub 多为较矮的多枝木本植物；vine 常攀缘或蔓生。 | **The vine climbed up a tree beside the shrubs.**<br>藤蔓爬上了灌木旁的一棵树。 |
| **root / stem / branch / petal** | root 吸收和固定；stem 是茎；branch 是树枝；petal 是花瓣。 | **The stem supports the flower and its petals.**<br>茎支撑着花朵和花瓣。 |
| **leaf / leaves** | leaf 的复数为 leaves，容易误写成 leafs。 | **The leaves are falling.**<br>树叶正在飘落。 |
| **cactus / cacti / cactuses** | cacti 与 cactuses 都是可接受的复数。 | **These cacti need less water.**<br>这些仙人掌需要更少的水。 |
| **pear / pair** | 发音相同，pear 是梨，pair 是一对。 | **I bought a pair of gloves and a pear.**<br>我买了一副手套和一个梨。 |
| **grape / a bunch of grapes** | 一颗葡萄是 a grape；一串葡萄是 a bunch of grapes。 | **She washed a bunch of grapes.**<br>她洗了一串葡萄。 |
| **garlic / a clove of garlic** | garlic 作为食材一般不可数；量化一瓣用 clove。 | **Add one clove of garlic.**<br>加一瓣蒜。 |
| **broccoli / a broccoli floret** | broccoli 作食材通常不可数；数小朵用 floret。 | **Cut the broccoli into florets.**<br>把西兰花切成小朵。 |
| **spinach / cabbage** | spinach 作食材常不可数；cabbage 可表示一整棵或作为食材。 | **We need some spinach and a head of cabbage.**<br>我们需要一些菠菜和一颗卷心菜。 |
| **fruit / vegetable / berry** | 日常分类与植物学分类可能不同；tomato 在烹饪中通常被当作蔬菜。 | **Tomatoes are commonly treated as vegetables in cooking.**<br>在烹饪中，番茄通常被当作蔬菜。 |

## 九、SpeakGuild 知识点拆分建议

每个词汇建立一个主记忆知识点；单复数变化、特殊量词及容易混淆的表达作为关联练习，不重复创建相同词义卡。图片识别优先用于树木、花卉、水果、蔬菜；口头或书面输出优先用于购物、烹饪与植物描述。
