# 01｜判断、可能与确定

## 练习目标

本节学习 15 个用于**判断可能性、表达确定性、描述证据是否明显、区分信息是否直接表达**的形容词。完成学习后，应能根据语境选择恰当的词，并正确使用 `be likely to do`、`It is possible that...`、`be certain of/about`、`It is obvious that...` 等句型。

## 核心概念

判断一件事时，可以从四个角度选择形容词：

| 判断角度 | 需要回答的问题 | 代表词汇 |
| --- | --- | --- |
| 可能性 | 事情发生的机会有多大？ | likely, unlikely, possible, probable |
| 确定性 | 我们有多大把握？结论是否明确？ | certain, sure, definite, bound |
| 明显性 | 证据、迹象或事实有多容易看出来？ | obvious, apparent, evident |
| 表达方式 | 信息是明说的、暗示的，还是细微到难以察觉？ | explicit, implicit, subtle, noticeable |

**学习提醒：**这些形容词的区别既涉及含义，也涉及句法。即使中文都可译作“可能”，英语中也未必能够代入同一个句型。

# 一、可能性判断

## 1. likely

### 核心感觉

`likely` 表示**根据目前掌握的信息，某件事有较大可能发生**。它关注预测或预期，常见于日常判断、新闻及工作交流。

### 词性与句型

`likely` 是 **adjective（形容词）**，常作表语，也能作定语。

| 结构 | 用法见解 | 例句 |
| --- | --- | --- |
| **someone / something + be likely to do** | 直接以预计发生动作的人或事物为主语，口语和书面语都常见。 | **He's likely to arrive late.**<br>他很可能会迟到。 |
| **It is likely that + 从句** | 以整件事作为判断对象，适合完整描述某个可能发生的情况。 | **It's likely that the meeting will be postponed.**<br>会议很可能会推迟。 |
| **more / less / most likely** | 比较不同情况发生的概率。 | **She's more likely to agree if we explain the reason.**<br>如果我们说明原因，她就更有可能同意。 |
| **a likely outcome / explanation** | 用于名词前，表示可能出现的结果或合理的解释。 | **That's the most likely explanation.**<br>那是最有可能的解释。 |

### 英语思维

使用 `likely` 时，可以把它理解为：**已有迹象 → 推测某个结果出现的概率较高**。

**He's likely to leave.** 关注“他离开的可能性”。

**It's likely that he'll leave.** 把“他会离开”整件事作为判断对象。

### 输出例句

**I'm likely to stay home this weekend because I have a lot of work to finish.**  
这个周末我很可能待在家里，因为我还有很多工作要完成。

**The problem is more likely to occur when the network is unstable.**  
网络不稳定时，这个问题更容易出现。

## 2. unlikely

### 核心感觉

`unlikely` 表示**某件事发生的可能性较低**，比单纯的 `not likely` 更凝练。它并不自动表示事情绝不可能发生。

### 高频结构

| 结构 | 用法见解 | 例句 |
| --- | --- | --- |
| **be unlikely to do** | 判断某人或某事不太可能发生某个动作或变化。 | **She's unlikely to change her mind.**<br>她不太可能改变主意。 |
| **It is unlikely that...** | 对整件事发生的可能性作否定判断。 | **It's unlikely that we'll finish everything today.**<br>我们不太可能今天把所有事情都做完。 |
| **highly / very unlikely** | 进一步降低预期发生的可能性。 | **It's highly unlikely that he forgot the appointment.**<br>他忘记预约的可能性非常低。 |

### 英语思维与输出

`unlikely` 适合表达**理性预期偏低**，尤其用于礼貌地提出不同判断。

**It's unlikely that we'll get a reply before Friday, so we should prepare another option.**  
我们周五之前收到回复的可能性不大，所以应该准备另一个方案。

## 3. possible

### 核心感觉

`possible` 关注的是**有没有发生或实现的可能**。它可以表示事情可能发生，也可以表示某件事在客观条件下做得到。

### 高频结构

| 结构 | 用法见解 | 例句 |
| --- | --- | --- |
| **It is possible that + 从句** | 判断某种情况有发生的可能。 | **It's possible that I misunderstood what she meant.**<br>有可能是我误解了她的意思。 |
| **It is possible for someone to do** | 说明某人做某事在条件上可行。 | **Is it possible for us to finish this by Friday?**<br>我们有可能在周五之前完成这件事吗？ |
| **as soon as possible** | 高频固定表达，表示尽快。 | **Please reply as soon as possible.**<br>请尽快回复。 |
| **if possible / whenever possible** | 补充“如果条件允许”。 | **I'd prefer to work from home, if possible.**<br>如果可以，我更希望在家办公。 |

**结构注意：**普通的可能性判断一般使用 `It is possible that he will come`，或 `He may come`。不要直接照搬 `likely` 的形式说 `He is possible to come`。

### 英语思维与输出

`possible` 可以同时考虑两件事：**是否存在这种可能**、**客观上能否做到**。需要靠句型和上下文区分。

**It's possible that the issue is related to the latest update, but we need more evidence.**  
这个问题可能与最近的更新有关，但我们需要更多证据。

## 4. probable

### 核心感觉

`probable` 表示**根据证据或推理，某件事很可能属实或发生**。它与 `likely` 意思接近，但语体通常略偏正式。

### 高频结构

| 结构 | 用法见解 | 例句 |
| --- | --- | --- |
| **It is probable that...** | 正式地陈述某事很可能发生。 | **It's probable that demand will increase next year.**<br>明年的需求很可能增加。 |
| **a probable cause / reason** | 表示某个原因或解释是较有根据的推测。 | **The report identifies a probable cause of the failure.**<br>报告指出了故障的一个可能原因。 |
| **the probable outcome** | 讨论分析、研究或预测结果。 | **We need to consider the probable outcome of this decision.**<br>我们需要考虑这个决定可能带来的结果。 |

**结构注意：**日常使用中通常说 `He is likely to win`；`It is probable that he will win` 也自然。`He is probable to win` 不是惯常表达。

### 英语思维与输出

`probable` 常给人一种**经过分析后做出的可能性判断**的感觉。

**Based on the available information, a delay seems probable.**  
根据现有信息，延期似乎很有可能。

# 二、确定性判断

## 5. certain

### 核心感觉

`certain` 一方面可以表达**说话者确信某件事**，另一方面可以表示**某个结果肯定会出现**；放在名词前还常表示“某些、特定的”。

### 高频结构

| 结构 | 用法见解 | 例句 |
| --- | --- | --- |
| **be certain that...** | 对事实或判断有把握。 | **I'm certain that I saved the file.**<br>我确信自己保存了文件。 |
| **be certain of / about something** | 对某事有把握；常与事实、细节、结果搭配。 | **Are you certain about the date?**<br>你确定日期没错吗？ |
| **be certain to do** | 预测某事必然或几乎必然发生。 | **The changes are certain to affect the schedule.**<br>这些变化肯定会影响日程。 |
| **a certain person / certain conditions** | 特定的某人、某些条件；不表示“确信”。 | **This feature is available only under certain conditions.**<br>这个功能只在特定条件下可用。 |

### 英语思维与输出

`I'm certain that...` 强调**我的把握**；`X is certain to...` 强调**事情本身的必然趋势**。

**I'm not certain whether she received the message, so I'll check with her first.**  
我不确定她是否收到了消息，所以我会先向她确认。

## 6. sure

### 核心感觉

`sure` 在日常口语中十分常见，表达**确信、有把握**，也可用于“务必、确保”之类的提醒。

### 高频结构

| 结构 | 用法见解 | 例句 |
| --- | --- | --- |
| **be sure that...** | 表达对某件事的确信。 | **I'm sure she knows the answer.**<br>我相信她知道答案。 |
| **be sure of / about something** | 对事实、决定或细节有把握。 | **I'm not sure about the exact time.**<br>我不确定具体时间。 |
| **be sure to do** | 可表示某事必然发生，也常用于要求或提醒。 | **Be sure to back up your files.**<br>务必备份你的文件。 |
| **make sure (that)...** | 核实或确保某件事成立。 | **Make sure the door is locked.**<br>确认门已经锁好了。 |

### 英语思维与输出

`certain` 和 `sure` 都可表达强烈确信。实际口语里 `I'm sure...` 往往更日常；`I'm certain...` 语气相对正式、郑重。

**I'm pretty sure I've seen him before, but I can't remember where.**  
我相当确定以前见过他，但想不起来是在哪里。

## 7. definite

### 核心感觉

`definite` 强调**明确、确定、没有模糊空间**，常用于计划、时间、答案、结论、证据等。它通常描述一件事是否已经被明确界定。

### 高频结构

| 结构 | 用法见解 | 例句 |
| --- | --- | --- |
| **a definite answer / decision** | 明确的答复或决定。 | **I can't give you a definite answer yet.**<br>我还不能给你明确答复。 |
| **a definite date / plan** | 已确定的日期、计划。 | **We haven't set a definite date for the launch.**<br>我们还没有确定发布日期。 |
| **definite evidence / proof** | 足够明确、有力的证据。 | **There's no definite proof that the data was leaked.**<br>目前没有确凿证据表明数据遭到了泄露。 |

### 英语思维与输出

`I'm sure` 说明**人的主观确信**；`a definite answer` 说明**答案本身明确**。两者不能在所有情况下互换。

**We need a definite decision before we can move forward with the project.**  
我们需要一个明确的决定，才能继续推进项目。

## 8. bound

### 核心感觉

`bound` 在 `be bound to do` 中表达**根据趋势、经验或情境，某件事几乎肯定会发生**，语气通常很强。

### 高频结构

| 结构 | 用法见解 | 例句 |
| --- | --- | --- |
| **be bound to do** | 强烈预期某件事会发生。 | **You're bound to make mistakes when learning something new.**<br>学习新东西时，你难免会犯错。 |
| **be bound to happen** | 表示事情迟早或必然发生。 | **Some disagreements are bound to happen.**<br>出现一些分歧是难免的。 |
| **be bound by + rule / agreement** | 另一种含义：受到规则、协议约束。 | **We're bound by the terms of the contract.**<br>我们受到合同条款的约束。 |

**结构注意：**`be bound to do` 里的 `to` 后面接动词原形；`be bound by` 属于不同的搭配。

### 英语思维与输出

`bound to` 往往暗含“按这个趋势发展，结果很难避免”。它可以用于好事，也可以用于坏事。

**If you keep practicing regularly, you're bound to improve over time.**  
如果你坚持规律练习，随着时间推移肯定会进步。

# 三、明显性判断

## 9. obvious

### 核心感觉

`obvious` 表示**事情非常明显，通常不需要复杂分析就能看出来**。它常见于事实、错误、意图及答案。

### 高频结构

| 结构 | 用法见解 | 例句 |
| --- | --- | --- |
| **It is obvious that...** | 直接指出一个明显的事实或判断。 | **It's obvious that something went wrong.**<br>很明显，某个环节出了问题。 |
| **be obvious to someone** | 说明对谁而言是明显的。 | **The mistake was obvious to everyone.**<br>每个人都看出了那个错误。 |
| **an obvious reason / mistake** | 作定语，强调原因或错误一眼可见。 | **We missed an obvious detail.**<br>我们漏掉了一个很明显的细节。 |

### 英语思维与输出

`obvious` 有时会暗含“这很容易看出来”的态度。对人说 `It's obvious!` 可能显得不耐烦，正式交流中可根据语气改用 `It seems clear that...`。

**It became obvious that we needed a different approach.**  
后来情况变得很明显：我们需要换一种方法。

## 10. apparent

### 核心感觉

`apparent` 有两个需要根据上下文区分的方向：**明显可见的**，以及**表面看起来如此、实际未必如此的**。

### 高频结构

| 结构 | 用法见解 | 例句 |
| --- | --- | --- |
| **It became apparent that...** | 某件事逐渐变得清楚。 | **It soon became apparent that the plan wouldn't work.**<br>很快大家就看清了这个计划行不通。 |
| **be apparent to someone** | 对某人而言清楚可见。 | **The difference is apparent to experienced users.**<br>有经验的用户能明显看出这种差别。 |
| **an apparent improvement / success** | 表面上看到的改善或成功，具体语境可能保留真实性疑问。 | **The apparent improvement didn't last long.**<br>表面上的改善并没有持续多久。 |
| **for no apparent reason** | 看不出明显原因。 | **The app crashed for no apparent reason.**<br>应用不知为何突然崩溃了。 |

### 英语思维与输出

`apparent` 需要观察语境：

- **It became apparent that...**：往往侧重“逐渐明白”。
- **His apparent confidence...**：可能侧重“看上去很自信”，不保证内心真的自信。

**She seemed calm, but her apparent confidence disappeared when the questions began.**  
她看起来很镇定，但一开始提问，她表面上的自信就消失了。

## 11. evident

### 核心感觉

`evident` 强调**有可观察的迹象或证据，让事实清楚地显现出来**，常用于分析、报告和较正式的表达。

### 高频结构

| 结构 | 用法见解 | 例句 |
| --- | --- | --- |
| **It is evident that...** | 根据情况或迹象，某个结论已相当清楚。 | **It's evident that the team has made progress.**<br>很明显，团队已经取得了进展。 |
| **be evident in something** | 某个特征在结果、行为、数据中表现明显。 | **The improvement is evident in her writing.**<br>她的写作明显有所进步。 |
| **be evident from something** | 从某项证据、结果或数据中看出来。 | **The problem is evident from the test results.**<br>从测试结果可以明显看出这个问题。 |

### 英语思维与输出

`obvious` 常突出“容易看出”；`evident` 常突出“证据能够说明”。这只是常见语感侧重，两者有大量重叠。

**The impact of the changes is already evident in the latest figures.**  
这些变化带来的影响已经在最新数据中体现出来了。

# 四、信息表达方式

## 12. explicit

### 核心感觉

`explicit` 表示**信息被清楚、直接地说出或写出**，没有依赖猜测或暗示。它常修饰 instructions、permission、warning、statement、reference 等。

### 高频结构与搭配

| 结构 | 用法见解 | 例句 |
| --- | --- | --- |
| **explicit instructions / rules** | 指令或规则直接、明确。 | **The instructions are explicit about what to do next.**<br>说明清楚写明了接下来该做什么。 |
| **be explicit about something** | 对某个事项讲得具体且清楚。 | **Please be explicit about your requirements.**<br>请把你的要求说清楚。 |
| **explicit permission / consent** | 明确给予的许可或同意。 | **You need explicit permission to share the document.**<br>分享这份文档需要获得明确许可。 |

### 英语思维与输出

`explicit` 重在**有没有直接表达出来**，常用于避免误解的场合。

**The agreement should be explicit about who is responsible for maintenance.**  
协议应该明确写明谁负责维护。

## 13. implicit

### 核心感觉

`implicit` 表示**某种意思、判断或约定包含在话语或行为之中，但没有直接说明**。

### 高频结构与搭配

| 结构 | 用法见解 | 例句 |
| --- | --- | --- |
| **implicit meaning / message** | 言外之意、隐含信息。 | **There was an implicit warning in his words.**<br>他的话里隐含着警告。 |
| **be implicit in something** | 某种意思或原则隐含于某事之中。 | **The assumption is implicit in the proposal.**<br>这个假设隐含在提案之中。 |
| **implicit trust / agreement** | 根据习惯或关系形成的默契；`implicit trust` 也可指毫无保留的信任。 | **They have implicit trust in each other.**<br>他们彼此完全信任。 |

### 英语思维与输出

`explicit` 是把意思**明确写出或说出**；`implicit` 则需要从语境中**推断隐藏的意思**。`implicit` 在 `implicit trust` 中还有“无保留的”固定含义，值得单独记忆。

**Her reply contained an implicit refusal, even though she never said no.**  
尽管她没有直接说不，她的回复已经隐含了拒绝的意思。

## 14. subtle

### 核心感觉

`subtle` 表示**细微、不容易察觉或辨认**，也可形容某种表达、处理方式委婉而巧妙。

### 高频结构与搭配

| 结构 | 用法见解 | 例句 |
| --- | --- | --- |
| **a subtle difference / distinction** | 两者差异细微，需要仔细辨别。 | **There's a subtle difference between the two expressions.**<br>这两个表达之间有细微区别。 |
| **a subtle hint / message** | 含蓄的暗示，不直接说破。 | **She gave me a subtle hint that she wanted to leave.**<br>她含蓄地暗示我，她想离开。 |
| **a subtle change / shift** | 不容易立即察觉的变化。 | **I noticed a subtle change in his attitude.**<br>我注意到他的态度发生了微妙变化。 |

### 英语思维与输出

`subtle` 的关键是**程度细微、表现含蓄**。它可以描述区别、颜色、气味、语气、情绪变化等。

**The difference is subtle, but it can completely change the tone of the sentence.**  
这种区别虽然细微，却可能完全改变一句话的语气。

## 15. noticeable

### 核心感觉

`noticeable` 表示**某种变化、特点或现象明显到足以被注意到**。相比 `obvious`，它更常和看得见、听得出、感受得到的变化或差别搭配。

### 高频结构与搭配

| 结构 | 用法见解 | 例句 |
| --- | --- | --- |
| **a noticeable difference / improvement** | 变化明显到人能够察觉。 | **There's been a noticeable improvement in her pronunciation.**<br>她的发音有了明显进步。 |
| **be noticeable in something** | 某种变化在特定方面表现出来。 | **The delay is most noticeable in the mobile version.**<br>延迟在移动端最明显。 |
| **be noticeable to someone** | 对某些人而言可以明显察觉。 | **The difference may not be noticeable to beginners.**<br>初学者可能注意不到这个区别。 |

### 英语思维与输出

`noticeable` 常表示变化**足够明显，可以被感知**；它未必意味着原因已经清楚。`obvious` 更容易用于不言自明的事实或结论。

**After a month of practice, I could hear a noticeable difference in my pronunciation.**  
练习了一个月后，我能听出自己的发音有了明显变化。

# 五、核心混淆与综合辨析

## 1. likely / possible / probable

| 形容词 | 关键差异 | 最常用的句型 | 例句 |
| --- | --- | --- | --- |
| **likely** | 根据已知信息，预计较有可能。 | **someone is likely to do** | **He's likely to accept the offer.**<br>他很可能接受这个提议。 |
| **possible** | 存在这种可能；也可以指客观上可行。 | **It is possible that...** | **It's possible that he'll accept the offer.**<br>他有可能接受这个提议。 |
| **probable** | 根据证据推断较有可能，语体偏正式。 | **It is probable that...** | **It's probable that he'll accept the offer.**<br>他很可能接受这个提议。 |

**理解重点：**`possible` 没有必然表示“很有可能”；`likely / probable` 一般暗示相对更高的可能性。它们并无适用于所有语境的严格数值界限。

**句型重点：**`He is likely to come` 很自然；表达同一意思时，可说 `It is possible / probable that he will come`。避免把三者机械套进完全相同的句式。

## 2. certain / sure / definite / bound

| 词汇 | 最值得记住的使用场景 | 例句 |
| --- | --- | --- |
| **certain** | 确信事实；判断某事必然发生。 | **I'm certain that she's right.**<br>我确信她是对的。 |
| **sure** | 日常口语中表达确定；提醒确认。 | **Are you sure about that?**<br>你确定吗？ |
| **definite** | 计划、日期、决定、答复已经明确。 | **We need a definite answer.**<br>我们需要一个明确答复。 |
| **bound** | 根据趋势、规律等强烈预期事情会发生。 | **Mistakes are bound to happen.**<br>犯错是难免的。 |

**额外辨析：**`Be sure to call her.` 是提醒“务必给她打电话”；`She's sure to call.` 是判断“她肯定会打电话”。同一个结构要结合主语和语境理解。

## 3. obvious / apparent / evident

| 词汇 | 核心侧重 | 例句 |
| --- | --- | --- |
| **obvious** | 容易看出，几乎不需解释。 | **The answer is obvious.**<br>答案很明显。 |
| **apparent** | 明显可见；或表面看起来如此。 | **His apparent calm hid his anxiety.**<br>他表面上的平静掩盖了焦虑。 |
| **evident** | 有迹象、表现或证据支持。 | **Her progress is evident in her work.**<br>她的进步在工作表现中清晰可见。 |

**注意：**三者不是截然分开的等级。真正的使用区别取决于语境和搭配，尤其要掌握 `apparent` 的“表面上的”含义。

## 4. explicit / implicit / subtle / noticeable

| 词汇 | 判断依据 | 例句 |
| --- | --- | --- |
| **explicit** | 是否直接说清楚。 | **The rule was explicit.**<br>规定写得很明确。 |
| **implicit** | 是否需要从言行中推断。 | **The criticism was implicit.**<br>批评是含蓄表达出来的。 |
| **subtle** | 差别或暗示是否细微。 | **The hint was subtle.**<br>那个暗示很含蓄。 |
| **noticeable** | 变化或特点能否被察觉。 | **The change was noticeable.**<br>这种变化很明显。 |

**不要混淆：**`implicit` 描述没有明说的信息，`subtle` 描述细微或含蓄的程度；某个暗示可以同时是 implicit 和 subtle。

# 六、知识点记忆与输出重点

以下结构适合独立建立复习知识点，同一形容词的相关用法应尽量关联复习。

| 记忆对象 | 核心结构 | 中文提示 |
| --- | --- | --- |
| 可能性预测 | **be likely / unlikely to do** | 很可能 / 不太可能做某事 |
| 事件可能发生 | **It is possible / probable that...** | 有可能 / 很可能发生某事 |
| 确信某件事 | **be certain / sure that...** | 确信…… |
| 明确答复 | **a definite answer / decision** | 明确的答复 / 决定 |
| 强烈预期 | **be bound to do** | 肯定会；难免会…… |
| 显而易见 | **It is obvious / evident that...** | 很明显…… |
| 从证据看出 | **be evident from / in...** | 从……明显看出 / 在……体现 |
| 逐渐明朗 | **It becomes apparent that...** | 逐渐清楚…… |
| 直接说明 | **be explicit about...** | 把……说清楚 |
| 隐含信息 | **be implicit in...** | 隐含在……之中 |
| 微妙差异 | **a subtle difference between...** | ……之间的微妙区别 |
| 明显改善 | **a noticeable improvement in...** | 在……方面的明显进步 |

## 综合输出例句

**It's possible that the new feature will cause problems, but it's too early to say how likely that is.**  
新功能有可能引发问题，但现在还太早，无法判断这种情况有多大可能发生。

**I'm fairly sure the information is correct, although I can't give you a definite answer until I've checked the source.**  
我相当确定这些信息是正确的，但在核实来源之前，我还不能给你明确答复。

**It soon became apparent that the two plans were based on different assumptions.**  
很快大家就发现，这两个方案建立在不同的假设之上。

**There was an implicit warning in her message, but it was too subtle for me to notice at first.**  
她的信息里隐含着警告，但表达得太含蓄，我起初没有察觉。

**The improvement is noticeable, and the test results provide evident support for that conclusion.**  
进步是明显的，而且测试结果也为这个结论提供了清楚的证据。

## 本节总结

学习这组形容词时，优先记住四条思路：

1. **先判断概率**：`possible` 表示存在可能，`likely / probable` 常暗示更高的可能性。
2. **再判断把握**：`sure / certain` 常涉及确信，`definite` 强调明确，`bound` 常表达强烈预期。
3. **区分明显性的来源**：`obvious` 强调容易看出，`evident` 常结合证据，`apparent` 还可能描述表面印象。
4. **区分信息呈现方式**：`explicit` 是明说，`implicit` 是隐含，`subtle` 是细微含蓄，`noticeable` 是可以察觉。

复习时优先要求学习者**根据中文独立造句、选择介词和句型、辨析近义词**，再通过具体场景运用这些表达。
