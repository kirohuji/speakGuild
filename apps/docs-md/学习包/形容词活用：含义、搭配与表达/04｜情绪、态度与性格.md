# 04｜情绪、态度与性格

## 练习目标

掌握 29 个用于描述**情绪状态、态度倾向与性格特征**的形容词，特别关注情绪强度、判断依据、固定介词与后接结构；能够通过具体语境主动选择并输出。

## 核心概念

| 类别 | 判断问题 | 主要词汇 |
| --- | --- | --- |
| 情绪 | 是担心、挫败、失望、释然，还是内疚？ | anxious, uneasy, distressed, frustrated, overwhelmed, relieved, satisfied, content, disappointed, grateful |
| 态度 | 对行动、观点或他人持有什么倾向？ | enthusiastic, indifferent, reluctant, eager, confident, doubtful, skeptical, suspicious, ashamed, embarrassed, guilty, annoyed, irritated, resentful |
| 性格 | 评价一个人处理事务或对待他人的稳定特点？ | considerate, sensible, sensitive, stubborn, responsible |

**学习方法：** 先看这个形容词表达的心理或判断，再看它后面自然跟随的介词、动作或从句。中译英时先确定要表达的含义，避免机械套用一个中文释义。

# 一、情绪状态

## anxious

### 核心感觉

担忧未来的不确定结果；也可表示迫切想做某事。

### 词性与句型

`anxious` 是 **adjective（形容词）**。常用结构：**anxious about + 名词；anxious to do；anxious that + 从句**。实际使用时注意后面连接的是人、事情、动作还是完整从句。

### 高频结构与搭配

| 结构 / 搭配 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **be anxious about** | 对未来结果感到焦虑，担心尚未发生的事 | **I’m anxious about the interview tomorrow.**<br>我很担心明天的面试。 |
| **be anxious to do** | 急于做某事；根据语境可能是期待或焦急 | **She is anxious to hear the results.**<br>她急切地想知道结果。 |
| **be anxious that** | 表达对某种可能情况的担忧 | **I was anxious that I might miss the last train.**<br>我担心自己可能赶不上末班车。 |

### 英语思维

anxious about 把注意力放在不确定的事情上；anxious to do 则把注意力放在自己急切想采取的行动上。

### 输出例句

**I’m anxious about the interview tomorrow.**  
我很担心明天的面试。

**She is anxious to hear the results.**  
她急切地想知道结果。

## uneasy

### 核心感觉

隐约不安，感觉不对劲，但未必能指出明确原因。

### 词性与句型

`uneasy` 是 **adjective（形容词）**。常用结构：**uneasy about + 名词；feel uneasy；uneasy with + 情境**。实际使用时注意后面连接的是人、事情、动作还是完整从句。

### 高频结构与搭配

| 结构 / 搭配 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **feel uneasy** | 因气氛、迹象或直觉而不安 | **I felt uneasy when he avoided the question.**<br>他回避问题时，我感到有些不安。 |
| **uneasy about** | 对具体安排、决定心里没底 | **She is uneasy about sharing her personal data.**<br>她对分享个人数据感到不安。 |
| **uneasy with** | 对某种做法或处境不自在 | **I’m uneasy with the way this was handled.**<br>我对这件事的处理方式感到不安。 |

### 英语思维

uneasy 很适合表达“心里有点不对劲”，情绪通常低于 distressed 的强烈痛苦。

### 输出例句

**I felt uneasy when he avoided the question.**  
他回避问题时，我感到有些不安。

**She is uneasy about sharing her personal data.**  
她对分享个人数据感到不安。

## distressed

### 核心感觉

明显痛苦或忧虑，情绪受到严重扰动。

### 词性与句型

`distressed` 是 **adjective（形容词）**。常用结构：**be distressed by / at / about；deeply distressed**。实际使用时注意后面连接的是人、事情、动作还是完整从句。

### 高频结构与搭配

| 结构 / 搭配 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **be distressed by** | 事件对情绪造成强烈冲击 | **The family was deeply distressed by the news.**<br>这一消息让那家人十分痛苦。 |
| **be distressed about** | 因某种处境或问题深感苦恼 | **He was distressed about his mother’s condition.**<br>他十分担忧母亲的状况。 |

### 英语思维

distressed 强于 worried，常见于坏消息、危机、悲伤等语境，不适合轻描淡写的小烦恼。

### 输出例句

**The family was deeply distressed by the news.**  
这一消息让那家人十分痛苦。

**He was distressed about his mother’s condition.**  
他十分担忧母亲的状况。

## frustrated

### 高频结构与搭配

| 结构 / 搭配 | 含义与使用见解 | 例句 |

### 英语思维

frustrated 的核心是“目标受阻”；比 disappointed 更强调过程中的阻碍。

## relieved

### 核心感觉

原有担忧或压力解除后的轻松。

### 词性与句型

`relieved` 是 **adjective（形容词）**。常用结构：**relieved to do；relieved that；relieved at / by**。实际使用时注意后面连接的是人、事情、动作还是完整从句。

### 高频结构与搭配

| 结构 / 搭配 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **be relieved to hear / know** | 得知消息后松了一口气 | **I was relieved to hear that everyone was safe.**<br>听说所有人都安全，我松了一口气。 |
| **be relieved that** | 指出担忧解除的事实 | **She was relieved that the test came back negative.**<br>检查结果呈阴性，她松了一口气。 |
| **be relieved at** | 因结果而安心 | **We were relieved at the outcome.**<br>这个结果让我们如释重负。 |

### 英语思维

relieved 隐含“先有担忧，后被解除”；单纯开心用 pleased 或 happy 更自然。

### 输出例句

听说所有人都安全，我松了一口气。

**She was relieved that the test came back negative.**

# 二、态度与判断

## enthusiastic

### 核心感觉

积极投入、有明显热情；常形容对活动或计划的态度。

### 词性与句型

`enthusiastic` 是 **adjective（形容词）**。常用结构：**enthusiastic about；enthusiastic supporter**。实际使用时注意后面连接的是人、事情、动作还是完整从句。

| --- | --- | --- |
| **be enthusiastic about** | 对主题、活动、计划热情高 | **She is enthusiastic about the new project.**<br>她对新项目很有热情。 |
| **enthusiastic response** | 积极热烈的反应 | **The proposal received an enthusiastic response.**<br>这项提议获得了热烈反响。 |

### 英语思维

enthusiastic 强调主动投入的热情；interested 可以只是感兴趣。

**She is enthusiastic about the new project.**  
她对新项目很有热情。

这项提议获得了热烈反响。

# 四、核心混淆与辨析

## anxious / uneasy / distressed / overwhelmed

| 词 | 选择依据 |
| --- | --- |
| anxious | 对不确定结果担忧，或迫切想做某事 |
| uneasy | 隐约觉得不对劲、不自在 |
| distressed | 强烈痛苦或忧虑 |
| overwhelmed | 任务、压力或情绪强到难以应付 |

**I was anxious about the exam, but what really overwhelmed me was the amount of preparation.**  
我担心考试，但真正让我招架不住的是准备工作量。

## frustrated / disappointed / relieved / satisfied / content

| 词 | 关注点 |
| --- | --- |
| frustrated | 过程受阻，努力难有进展 |
| disappointed | 结果低于预期 |
| relieved | 原先的担忧解除 |
| satisfied | 结果达到标准 |
| content | 对现状感到满足 |

**I was frustrated by the delays, disappointed with the outcome, and finally relieved when the issue was resolved.**  
延期让我受挫，结果让我失望，而问题解决后我终于松了口气。

## eager / anxious / reluctant / enthusiastic / indifferent

| 词 | 关注点 |
| --- | --- |
| eager | 渴望获得机会或开始行动 |
| anxious | 急切之中可能带焦虑 |
| reluctant | 不情愿、迟疑 |
| enthusiastic | 积极投入、热情明显 |
| indifferent | 不关心、无明显兴趣 |

**She was eager to join, while he was reluctant to commit.**  
她渴望加入，而他不太愿意作出承诺。

## doubtful / skeptical / suspicious / confident

| 词 | 关注点 |
| --- | --- |
| doubtful | 对是否成立或成功信心不足 |
| skeptical | 要求更充分的证据，持审慎怀疑 |
| suspicious | 怀疑背后有不正常、不诚实或危险之处 |
| confident | 相信能力、判断或结果 |

**I’m skeptical about the claims, but I’m not suspicious of the people making them.**  
我对那些说法持怀疑态度，但没有怀疑提出这些说法的人有什么不正当动机。

## ashamed / embarrassed / guilty

| 词 | 关注点 |
| --- | --- |
| ashamed | 羞愧，可能涉及对自我或行为的负面评价 |
| embarrassed | 尴尬、社交窘迫 |
| guilty | 由于做错事而内疚；也可表示有罪 |

**I felt embarrassed when I forgot his name, but guilty when I realized I had hurt his feelings.**  
忘记他的名字让我尴尬；意识到伤害了他的感情后，我感到内疚。

## annoyed / irritated / resentful

| 词 | 关注点 |
| --- | --- |
| annoyed | 一件事让人恼火 |
| irritated | 反复刺激使人烦躁，或身体受刺激 |
| resentful | 因认为遭到不公平对待而积累怨气 |

**I was annoyed by the comment, but she remained resentful about the unfair decision for months.**  
那句话让我恼火；而她对那个不公平的决定记恨了好几个月。

## sensible / sensitive / considerate / stubborn / responsible

| 词 | 关注点 |
| --- | --- |
| sensible | 判断务实理性 |
| sensitive | 反应敏锐，或容易受到影响 |
| considerate | 能体谅他人需求 |
| stubborn | 不愿改变想法或做法 |
| responsible | 能承担责任、行事可靠 |

**She is sensitive to other people’s feelings and considerate of their needs.**  
她对他人的感受很敏锐，也很体谅他们的需要。

# 六、综合输出案例

## 场景：项目发布前的团队沟通

**A: You seem uneasy about the release. What’s worrying you?**  
你似乎对这次发布感到不安。你在担心什么？

**B: I’m anxious about the deadline and frustrated with the repeated changes.**  
我担心截止时间，而且反复修改也让我很挫败。

**A: I understand. Are you skeptical about the test results?**  
我理解。你对测试结果有疑虑吗？

**B: A little. I’m not suspicious of anyone, but I’d like more evidence before we go live.**  
有一点。我没有怀疑任何人，只是希望上线前能有更多证据。

**A: That sounds sensible. I’m grateful for your careful review.**  
这听起来很稳妥。谢谢你这么仔细地审查。

**B: Thanks. I’ll feel relieved once the final checks are complete.**  
谢谢。等最终检查完成，我就能松一口气了。

## 输出练习建议

1. 用 **anxious / uneasy / overwhelmed** 描述三种不同程度的不安。
2. 用 **frustrated / disappointed / relieved** 讲述一次项目延期到最终解决的经历。
3. 用 **eager / reluctant / enthusiastic / indifferent** 描述团队成员面对新任务的不同态度。
4. 用 **skeptical / suspicious** 区分对信息的质疑与对不当动机的怀疑。
5. 用 **ashamed / embarrassed / guilty** 描述三种不同的负面感受。
6. 用 **considerate / sensible / sensitive / stubborn / responsible** 评价一个人的行为。

| --- | --- |
| 情绪簇 | 根据原因与强度主动选择 anxious、uneasy、distressed、overwhelmed 等 |
| 态度簇 | 区分 eager、reluctant、enthusiastic、indifferent 与 confident 等 |
| 性格簇 | 区分 sensible、sensitive、considerate、stubborn、responsible |
| 介词搭配 | 掌握 grateful to/for、responsible for/to、sensitive to/about 等 |
| 句型 | 能使用 anxious to、reluctant to、relieved that、confident that 等 |
| 主动输出 | 结合原因、行为、结果说明情绪和态度，而不只使用单个形容词 |

**复习建议：** 一个形容词的不同介词搭配可以归入同一个核心知识点，分多次复现不同语境；容易混淆的词组成对比题。
