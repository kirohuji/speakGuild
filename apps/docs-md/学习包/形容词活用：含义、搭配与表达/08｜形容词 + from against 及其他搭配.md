# 形容词活用：含义、搭配与表达

# 08｜形容词 + from / against 及其他搭配

## 练习目标

掌握 12 组高频形容词搭配，理解 `from` 指向分离、来源或隔绝对象，`against` 指向需要防御的风险，`to` 指向影响或免疫对象，`on` 指向依赖、兴趣、目标与依据。重点练习搭配选择、结构变化和独立输出。

## 词性与句型

这一节多数表达为 **be + adjective / participial adjective + prepositional phrase**。介词后通常使用名词、代词或动名词，不能直接把动词原形接在介词后。

- **be different from / distinct from / separate from + noun**：比较差异或强调分离。
- **be protected against / safe from / immune to + noun**：描述风险、保护与抵抗。
- **be dependent on / keen on / intent on + noun / V-ing**：依赖、热衷或决意。
- **be based on + noun**：说明依据。

**The new policy is different from the old one.**  
新政策与旧政策不同。

**She is intent on improving her English.**  
她决心提高自己的英语水平。

**The decision is based on the available evidence.**  
这一决定基于现有证据。

**结构提醒：** `protected` 和 `based` 在许多句子中也具有明显的被动分词性质。教学中以其固定搭配和使用语境为重点。介词并无放之四海而皆准的一词一义规则，仍要结合具体搭配记忆。

# 一、差异、分离与缺席：from

## 1. different from
### 核心感觉

**差异来自比较。** 把两者放在一起比较，指出性质、做法或结果不同。最常用的是 `different from`；`different to` 在英式英语中也可见，正式学习优先掌握 `from`。
### 高频结构

| 结构 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **be different from + noun** | A 与 B 不同，强调差异 | **My approach is different from yours.**<br>我的处理方式和你的不同。 |
| **be different in + respect** | 指出具体不同的方面 | **The two plans are different in several important respects.**<br>这两个方案在几个重要方面存在差异。 |
| **different from what + clause** | 与原先认识、预期的情况不同 | **The result was different from what we expected.**<br>结果和我们预期的不一样。 |

### 英语思维

比较双方都可以是人、物、方式或结果。`different in` 说明差异出现在哪个维度；`different from` 指明比较对象。

### 输出例句

**This version is quite different from the one we tested last month.**  
这个版本与我们上个月测试的版本有很大不同。

**People can be very different in how they respond to criticism.**  
人们对批评的反应方式可能差别很大。


## 2. distinct from
### 核心感觉

**清楚可分的界线。** 强调能把 A 与 B 明确区分，常用于概念、类别、责任或身份。语气通常比 `different` 更强调独立性或界限。
### 高频结构

| 结构 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **be distinct from + noun** | 与……有清晰区分 | **Privacy is distinct from security.**<br>隐私和安全是两个不同的概念。 |
| **distinct in + feature** | 在某特征上明显不同 | **The two designs are distinct in style.**<br>这两种设计在风格上区别明显。 |
| **a distinct + noun** | 明显、清楚的；注意这种用法无需 from | **There is a distinct difference between the two proposals.**<br>两份提案之间有明显区别。 |

### 英语思维

`distinct from` 适用于需要区分概念边界的场景；`distinct` 也能作定语，表示清晰可辨。

### 输出例句

**A personal preference is distinct from an objective requirement.**  
个人偏好与客观要求应当加以区分。

**These two roles are distinct from each other, even if some tasks overlap.**  
即使部分任务重叠，这两个岗位仍然不同。


## 3. separate from
### 核心感觉

**彼此分开、独立存在。** 强调位置、组织或管理上的分离，也能表示概念上的单独处理。它既能描述已分开状态，也能描述有意保持距离。
### 高频结构

| 结构 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **be separate from + noun** | 与……分离、独立 | **The testing environment is separate from production.**<br>测试环境与生产环境是分开的。 |
| **keep A separate from B** | 把 A 与 B 分开 | **Keep personal expenses separate from business expenses.**<br>将个人支出和公司支出分开。 |
| **separate A from B** | 动词结构：把 A 与 B 分开 | **We need to separate facts from assumptions.**<br>我们需要区分事实和假设。 |

### 英语思维

`different` 看差异，`distinct` 看边界，`separate` 看是否被分开或独立处理。`separate` 也可以作动词。

### 输出例句

**The payment system must remain separate from the experimental features.**  
支付系统必须与实验性功能保持分离。

**I try to keep work separate from my personal life.**  
我尽量把工作与私人生活分开。


## 4. absent from
### 核心感觉

**在某场合或名单中缺席。** 描述人没有出现在预期地点，也可描述某特征、元素在文本或系统里缺失。常与 `school / work / meeting / report` 等搭配。
### 高频结构

| 结构 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **be absent from + place/event** | 缺席某地或某活动 | **She was absent from the meeting yesterday.**<br>她昨天没有参加会议。 |
| **be absent from + text/system** | 某项内容未出现 | **The main conclusion is absent from the summary.**<br>摘要中缺少主要结论。 |
| **absent for + duration** | 缺席持续多长时间 | **He has been absent from work for three days.**<br>他已经三天没来上班了。 |

### 英语思维

`absent from` 回答“缺席哪里”；`for` 回答“持续多久”。`absent` 还可表示心不在焉，如 `absent-minded`，但这是另一个词。

### 输出例句

**Several key details were absent from the final report.**  
最终报告遗漏了几个关键细节。

**I was absent from class because I had a medical appointment.**  
我因为预约了看医生而缺课。


# 二、免受影响与风险防护：from / against / to

## 5. free from
### 核心感觉

**没有某种负担或有害影响。** 表示免于困扰、限制、错误或不良成分，常用于偏正式的说明。`free of` 在若干名词后也很自然，例如 `free of charge / free of errors`。
### 高频结构

| 结构 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **be free from + burden/harm** | 免受问题或负担困扰 | **The new system is free from major security flaws.**<br>新系统没有重大安全漏洞。 |
| **free from + restriction** | 不受某种限制约束 | **Everyone should be free from discrimination.**<br>每个人都应免受歧视。 |
| **be free of + noun** | 另一常见结构：没有或不含 | **The service is free of charge.**<br>这项服务免费。 |

### 英语思维

`free from` 常把问题看作要摆脱的来源；`free of` 常表示没有某物。两者部分场景可互换，但固定搭配应按习惯记忆。`free to do` 则是“可以自由做”。

### 输出例句

**I want a workspace that is free from unnecessary distractions.**  
我想要一个没有不必要干扰的工作环境。

**You are free to disagree, but please explain your reasoning.**  
你可以提出不同意见，但请说明理由。


## 6. safe from
### 核心感觉

**远离某一具体危险。** 强调某人或某物处于不受特定危险侵害的状态，常以危险来源作介词宾语。`safe to do` 和 `safe for someone` 用来表达另外的判断。
### 高频结构

| 结构 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **be safe from + danger** | 不受某种危险威胁 | **The documents are safe from accidental deletion.**<br>这些文档不会被意外删除。 |
| **be safe to + verb** | 做某事是安全的 | **Is this water safe to drink?**<br>这水可以安全饮用吗？ |
| **be safe for + person** | 对某类人来说安全 | **This product is safe for children.**<br>这款产品对儿童是安全的。 |

### 英语思维

`safe from` 强调避开外部威胁；`safe to do` 判断某个行为的安全性；`safe for` 指明适用对象。

### 输出例句

**The backup files should be safe from hardware failure if they are stored separately.**  
如果备份文件单独存放，就应当能够避免因硬件故障而丢失。

**We cannot assume the information is safe to share.**  
我们不能想当然地认为这些信息可以安全分享。


## 7. protected against
### 核心感觉

**采取措施抵御某种风险。** 常出现在医学、网络安全、法律及产品说明中。`protected against` 强调抵御攻击或风险；`protected from` 同样常用，更一般地说明免受伤害。
### 高频结构

| 结构 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **be protected against + risk** | 得到针对某风险的保护 | **The system is protected against common attacks.**<br>该系统针对常见攻击采取了防护措施。 |
| **protect A against B** | 主动采取保护措施 | **Regular updates help protect devices against malware.**<br>定期更新有助于防止恶意软件侵害设备。 |
| **be protected from + harm** | 免受某种伤害或影响 | **The equipment must be protected from moisture.**<br>设备必须防潮。 |

### 英语思维

`protected` 是过去分词形容词，也可理解为被动结构。`against` 常突出“防御的对象”，`from` 常突出“隔绝的伤害来源”。保护措施的存在不等于风险被百分百消除。

### 输出例句

**Our accounts are protected against unauthorized access by two-factor authentication.**  
我们的账户通过双因素认证来防范未经授权的访问。

**Keep the samples protected from direct sunlight.**  
让样本避免阳光直射。


## 8. immune to
### 核心感觉

**具有免疫力或基本不受某种影响。** 既可以谈生物学免疫，也能比喻对批评、压力或经济变化不受影响。`immune to` 不保证绝对不受影响；语境中常有夸张意味。
### 高频结构

| 结构 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **be immune to + disease** | 对某种疾病有免疫力 | **Some people are immune to the disease after vaccination.**<br>部分人在接种疫苗后对这种疾病具有免疫力。 |
| **be immune to + criticism** | 比喻对批评不受影响 | **No manager is immune to criticism.**<br>没有哪个管理者能完全免于批评。 |
| **not immune to + change** | 也会受到变化影响 | **Small businesses are not immune to economic downturns.**<br>小企业也无法免受经济衰退的影响。 |

### 英语思维

`immune to` 可理解为“某种影响难以作用于该对象”。与 `protected against` 相比，前者更强调自身抵抗状态，后者强调存在防护措施。

### 输出例句

**Even experienced developers are not immune to making mistakes.**  
即使经验丰富的开发者也难免犯错。

**This industry is not immune to changes in consumer behavior.**  
这个行业同样会受到消费者行为变化的影响。


# 三、依赖、兴趣与依据：on

## 9. dependent on
### 核心感觉

**是否能成立要看某个条件。** 表示依赖资源、某人的支持或某种条件。`depend on` 是对应动词搭配；`independent of` 则表示不依赖。
### 高频结构

| 结构 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **be dependent on + resource** | 依赖特定资源 | **The project is dependent on external funding.**<br>该项目依赖外部资金。 |
| **be dependent on + person** | 依赖某人提供支持 | **Young children are dependent on adults for care.**<br>年幼的孩子需要成年人照料。 |
| **be dependent on whether + clause** | 取决于某种条件是否成立 | **The launch date is dependent on whether testing is completed.**<br>上线日期取决于测试能否完成。 |

### 英语思维

`dependent on` 强调条件关系：A 能否运行，取决于 B。`independent of` 表示摆脱这种依赖。记忆时与 `depend on` 关联，但练习归在形容词搭配。

### 输出例句

**Our release schedule is dependent on the approval process.**  
我们的发布日程取决于审批流程。

**I would like to become less dependent on translation when speaking English.**  
我希望说英语时减少对翻译的依赖。


## 10. keen on
### 核心感觉

**对事物有浓厚兴趣或热情。** 在英式英语中尤其常见，指爱好、喜好、热衷。`keen to do` 表示很想做某事；`not keen on` 可以委婉表示不太想。
### 高频结构

| 结构 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **be keen on + noun** | 喜欢、热衷于某事 | **She is keen on classical music.**<br>她很喜欢古典音乐。 |
| **be keen on + V-ing** | 热衷于某种活动 | **I am keen on exploring new places.**<br>我很喜欢探索新地方。 |
| **be keen to + verb** | 很想去做某事 | **We are keen to hear your feedback.**<br>我们很想听听你的反馈。 |

### 英语思维

`keen on` 侧重喜好或热情的对象；`keen to do` 侧重想采取的行动。`not keen on` 常用于日常委婉拒绝。

### 输出例句

**I am not particularly keen on working overtime every weekend.**  
我并不特别愿意每个周末都加班。

**She is keen to take on more responsibility.**  
她很愿意承担更多责任。


## 11. intent on
### 核心感觉

**下定决心要实现某事。** 强调注意力和意志集中于某个目标，往往比 `keen on` 更坚决。后接名词或动名词。`intent` 作定语也有“专注的”含义。
### 高频结构

| 结构 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **be intent on + V-ing** | 一心想要完成某事 | **He is intent on proving his point.**<br>他一心想证明自己的观点。 |
| **be intent on + noun** | 把全部注意力放在某目标上 | **She seems intent on success at any cost.**<br>她似乎一心只想不惜代价取得成功。 |
| **intent on doing + despite...** | 突出即使有阻碍仍坚持 | **They were intent on finishing despite the setbacks.**<br>尽管遇到挫折，他们仍决心完成。 |

### 英语思维

`intent on` 比 `keen on` 更强调目标导向和坚定程度。`be intent on doing` 中的 `on` 是介词，后面用 V-ing。

### 输出例句

**The team is intent on fixing the root cause rather than applying another temporary patch.**  
团队决心解决根本原因，而不再打临时补丁。

**He was so intent on winning that he ignored all advice.**  
他一心想赢，以至于忽视了所有人的建议。


## 12. based on
### 核心感觉

**以事实、数据、原则作为依据。** 用于说明判断、决定、作品或系统的基础。可以作表语，也经常作为后置或前置修饰结构。`base A on B` 是相应动词结构。
### 高频结构

| 结构 | 含义与使用见解 | 例句 |
| --- | --- | --- |
| **be based on + evidence** | 以证据、事实为依据 | **The recommendation is based on recent data.**<br>这项建议依据近期数据提出。 |
| **based on + noun, clause** | 句首说明依据，需保证修饰关系清楚 | **Based on the feedback, we revised the design.**<br>根据反馈，我们修改了设计。 |
| **base A on B** | 动词结构：把 A 建立在 B 上 | **We should base our decisions on evidence.**<br>我们应该依据证据作决定。 |

### 英语思维

`based on` 引出“依据”。注意 `The report is based on...` 与 `We based the report on...` 两种结构；句首 `Based on...` 在现代英语中广泛使用，但正式写作最好确保所说明的对象明确。

### 输出例句

**The estimate is based on the information currently available.**  
这个估算以目前掌握的信息为依据。

**Our assumptions should be based on evidence rather than guesswork.**  
我们的假设应当建立在证据而非猜测之上。

# 四、核心混淆与介词活用

## 1. different / distinct / separate

| 表达 | 核心区别 | 例句 |
| --- | --- | --- |
| **different from** | A 与 B 存在差异，范围最广 | **My opinion is different from yours.**<br>我的看法与你不同。 |
| **distinct from** | 界限清晰，能够区分为不同概念或事物 | **A legal requirement is distinct from a recommendation.**<br>法律要求与建议是两回事。 |
| **separate from** | 保持独立、分开或不混在一起 | **Keep these records separate from personal files.**<br>将这些记录与个人文件分开。 |

## 2. free from / safe from / protected against / immune to

| 表达 | 主要判断角度 | 例句 |
| --- | --- | --- |
| **free from** | 没有某种负担、问题或不良成分 | **The document is free from obvious errors.**<br>文档没有明显错误。 |
| **safe from** | 处于远离某种危险的状态 | **The files are safe from accidental deletion.**<br>文件不会遭到意外删除。 |
| **protected against** | 具有防御某种威胁的措施 | **The server is protected against common threats.**<br>服务器针对常见威胁设有防护措施。 |
| **immune to** | 自身对某种影响具有免疫或抵抗能力；也可比喻 | **No industry is immune to change.**<br>没有哪个行业能完全不受变化影响。 |

这些表达都能涉及“避免不利影响”，但关注点不同。尤其注意 `immune to` 的介词是 **to**，并且在比喻语境里常见否定形式 `not immune to`。

## 3. keen on / intent on / dependent on / based on

| 表达 | 语义焦点 | 后接示例 |
| --- | --- | --- |
| **keen on** | 喜欢、热衷 | **keen on learning languages** 喜欢学语言 |
| **intent on** | 决心、目标 | **intent on completing the project** 决心完成项目 |
| **dependent on** | 条件依赖 | **dependent on funding** 依赖资金 |
| **based on** | 判断依据 | **based on evidence** 基于证据 |

## 4. 同一形容词或分词的结构变化

| 表达 | 差异及适用情境 | 例句 |
| --- | --- | --- |
| **different from / different in** | `from` 引出比较对象；`in` 引出差异所在方面 | **The products differ in price and are different from last year models.**<br>这些产品在价格上有差异，也不同于去年的型号。 |
| **free from / free of / free to** | `from / of` 表示免于或没有；`to do` 表示有自由做 | **You are free to leave whenever you like.**<br>你想什么时候离开都可以。 |
| **safe from / safe for / safe to** | 危险来源、适用对象、行为安全性 | **Is it safe for children to use?**<br>儿童使用它安全吗？ |
| **protected against / protected from** | `against` 强调针对威胁设防；`from` 强调隔绝损害 | **The device is protected from dust and against minor impacts.**<br>设备有防尘及抵御轻微撞击的保护。 |
| **keen on / keen to** | 喜好某事或热衷活动；急于采取某行动 | **I am keen to join the workshop.**<br>我很想参加这次工作坊。 |
| **dependent on / independent of** | 依赖；不依赖 | **The outcome is independent of the order.**<br>结果不受顺序影响。 |
| **based on / base A on B** | 描述现有依据；主动说明将 A 建立在 B 上 | **We based the decision on feedback.**<br>我们根据反馈作出了决定。 |

## 5. 介词后的动词形式

**She is keen on improving her pronunciation.**  
她热衷于改善自己的发音。

**They are intent on expanding the business.**  
他们决心扩大业务。

**We are dependent on receiving approval first.**  
我们需要先获得批准，后续工作才能开展。

当 `on` 后直接接动词时，通常使用 **V-ing**。但 `keen to improve` 中的 `to` 是不定式标记，后面接动词原形。两者不能混淆。

# 五、综合 Case：真实情境中选择搭配

| 场景 | 英语表达 | 中文与使用见解 |
| --- | --- | --- |
| 软件部署 | **Our staging environment is separate from production, and the servers are protected against common attacks.** | 预发布环境与生产环境分离，服务器也设有针对常见攻击的防护。`separate from` 说环境隔离，`protected against` 说安全防护。 |
| 工作协作 | **My responsibilities are distinct from hers, although we are dependent on one another's progress.** | 我的职责和她的职责不同，但我们的进度又相互依赖。区别“角色边界”和“进度依赖”。 |
| 个人学习 | **I am keen on learning new expressions, but I am more intent on using them in conversation.** | 我喜欢学习新表达，但更决心在对话里用出来。`keen` 是兴趣，`intent` 是目标。 |
| 方案评估 | **The updated proposal is different from the original one and is based on customer feedback.** | 更新后的方案不同于原方案，它依据客户反馈进行了调整。比较方案、说明修改依据。 |
| 意外风险 | **No plan is immune to unexpected problems, but we can keep essential data safe from accidental loss.** | 没有计划能完全免受意外问题影响，但我们可以保护关键数据，避免意外丢失。 |
| 报告质量 | **The conclusion was absent from the summary, even though the full report was free from major factual errors.** | 摘要遗漏了结论，尽管完整报告没有重大事实错误。`absent from` 说内容缺失，`free from` 说没有错误。 |

# 六、主动输出练习

先尝试独立翻译，注意选择形容词与介词；参考答案只是自然表达之一。

| 中文提示 | 参考答案与见解 |
| --- | --- |
| 我们的测试环境与正式环境是分开的。 | **Our testing environment is separate from production.**<br>强调实际隔离，用 `separate from`。 |
| 隐私与安全是两个不同的概念。 | **Privacy is distinct from security.**<br>强调概念界限，用 `distinct from`。 |
| 这个结果与我之前的预期不同。 | **This result is different from what I expected.**<br>`from what I expected` 指出对比基准。 |
| 会议纪要中遗漏了这个重要决定。 | **This important decision was absent from the meeting minutes.**<br>`absent from` 也可描述信息缺失。 |
| 这份报告没有重大错误。 | **This report is free from major errors.**<br>表达“没有某种问题”。 |
| 这些文件应该不会被意外删除。 | **These files should be safe from accidental deletion.**<br>`safe from` 突出远离危险。 |
| 系统针对未经授权的访问设有防护。 | **The system is protected against unauthorized access.**<br>`against` 引出防御的威胁。 |
| 即使是专家也难免犯错。 | **Even experts are not immune to making mistakes.**<br>`to + V-ing`；比喻用法常见于否定句。 |
| 新版本的发布时间取决于测试进度。 | **The release date of the new version is dependent on testing progress.**<br>`dependent on` 说明条件依赖。 |
| 我并不太喜欢每周末都加班。 | **I am not keen on working overtime every weekend.**<br>`keen on + V-ing` 可用于委婉表达不喜欢。 |
| 她下定决心解决这个问题。 | **She is intent on solving this problem.**<br>`intent on + V-ing` 强调决心。 |
| 我们应该根据事实作出判断。 | **Our judgments should be based on facts.**<br>`based on` 说明判断依据。 |

# 七、知识点复习清单

| 复习主题 | 必须能主动调用的知识点 |
| --- | --- |
| 差异与独立 | different from、distinct from、separate from 的语义重点；different in 的补充用法 |
| 缺席与缺失 | absent from + 场所 / 活动 / 文本；absent for + 时长 |
| 无负担与安全 | free from / of、safe from / for / to 的选择 |
| 防护与免疫 | protected against / from、immune to；分清防护措施与抵抗状态 |
| 依赖关系 | dependent on + 资源 / 条件，independent of 的对照 |
| 兴趣与决心 | keen on / keen to、intent on + V-ing |
| 事实依据 | be based on 与 base A on B 的转换 |
| 结构共性 | 介词 + 名词 / 代词 / V-ing；`keen to do` 的不同结构 |

> **复习建议**：每组形容词搭配作为一个主知识点，安排“选介词 → 选近义词 → 中译英造句 → 跨场景复现”。重点复习 `different / distinct / separate`、`safe / protected / immune` 和 `keen / intent` 的语义差异，避免只背介词而不会选词。
