# 吃饭、购物与消费

## 小提示

点餐、买东西、问价格、选尺寸、付款、退换货，这些都是日常生活里很常见的消费场景。

很多表达会反复出现，也很适合直接替换食物、商品、尺寸、颜色、数量和付款方式来练习。

## 句型占位符

本章继续使用统一的句型标记：

* `[someone]`：某个人
* `[something]`：某件东西或某个内容
* `[noun]`：名词或名词短语
* `[plural noun]`：复数名词或复数名词短语
* `[adjective]`：形容词
* `[number]`：数字或数量
* `[size]`：尺寸或尺码
* `[color]`：颜色
* `[price]`：价格
* `[verb phrase]`：以动词原形开始的完整动作表达，比如 `try this on`、`pay by card`、`get the check`
* `[place]`：地点

## 表达、中文意思与使用见解

### 1. I'd like / Can I get / I'll have [something].

**中文意思**

我想要…… / 我要……

**使用见解**

这三个都是点餐时非常常见的表达。

* **I'd like...**：自然、礼貌，适用范围很广。
* **Can I get...?**：日常口语里非常常见，尤其是美式英语。
* **I'll have...**：常用于已经决定好要点什么的时候。

**句型**

`I'd like [something].`

`Can I get [something]?`

`I'll have [something].`

**例句**

| English | 中文 |
| --- | --- |
| I'd like a latte, please. | 我想要一杯拿铁。 |
| Can I get a large coffee? | 我要一杯大杯咖啡。 |
| I'll have the steak. | 我要牛排。 |
| **A:** Are you ready to order?<br>**B:** Yeah, I'll have the chicken sandwich. | **A:** 可以点餐了吗？<br>**B:** 可以，我要鸡肉三明治。 |

---

### 2. Can I get [something] with / without [something]?

**中文意思**

我可以要……加 / 不加……吗？

**使用见解**

点餐时用来调整食物或饮料。

常见表达：

* **without onions**
* **with no ice**
* **extra cheese**
* **the sauce on the side**

**句型**

`Can I get [something] without [something]?`

`Can I get [something] with [something]?`

`Can I get extra [something]?`

**例句**

| English | 中文 |
| --- | --- |
| Can I get this without onions? | 这个可以不要洋葱吗？ |
| Can I get a coffee with no sugar? | 我可以要一杯不加糖的咖啡吗？ |
| Could I have the sauce on the side? | 酱汁可以另外放吗？ |
| **A:** Anything else?<br>**B:** Yeah, can I get extra cheese? | **A:** 还需要别的吗？<br>**B:** 要，可以多加点芝士吗？ |

---

### 3. Do you have [something]?

**中文意思**

你们有……吗？

**使用见解**

可以用来询问餐厅有没有某种食物、商店有没有某样商品，或者是否提供某种选择。

**句型**

`Do you have [something]?`

**例句**

| English | 中文 |
| --- | --- |
| Do you have oat milk? | 你们有燕麦奶吗？ |
| Do you have this in black? | 这个有黑色的吗？ |
| **A:** Do you have any vegetarian options?<br>**B:** Yes, we do. | **A:** 你们有素食选择吗？<br>**B:** 有的。 |

---

### 4. What do you recommend?

**中文意思**

你推荐什么？/ 有什么推荐的吗？

**使用见解**

不知道吃什么或买什么时很实用。

也可以问某一类东西：

**What do you recommend for [something]?**

**句型**

`What do you recommend?`

`What do you recommend for [something]?`

**例句**

| English | 中文 |
| --- | --- |
| What do you recommend? | 你推荐什么？ |
| What do you recommend for dessert? | 甜点你推荐什么？ |
| **A:** I've never been here before. What do you recommend?<br>**B:** The pasta is really good. | **A:** 我以前没来过，你推荐什么？<br>**B:** 这里的意大利面很好吃。 |

### 5. Does this come with [something]?

**中文意思**

这个带……吗？/ 这个包含……吗？

**使用见解**

用来确认套餐、商品或服务里是否包含某样东西。

在餐厅和购物场景都很实用。

**句型**

`Does this come with [something]?`

**例句**

| English | 中文 |
| --- | --- |
| Does this come with fries? | 这个配薯条吗？ |
| Does this come with a drink? | 这个包含饮料吗？ |
| Does this come with a warranty? | 这个带保修吗？ |
| **A:** Does this come with rice?<br>**B:** Yes, it does. | **A:** 这个配米饭吗？<br>**B:** 配的。 |

### 6. How much is / are...?

**中文意思**

……多少钱？

**使用见解**

用来询问价格。

单数或不可数内容用 **is**：

* **How much is this shirt?**
* **How much is the coffee?**

复数内容用 **are**：

* **How much are these shoes?**
* **How much are those headphones?**

如果已经拿着商品，也可以直接说：

* **How much is this?**
* **How much are these?**

**句型**

`How much is [something]?`

`How much are [plural noun]?`

**例句**

| English | 中文 |
| --- | --- |
| How much is this? | 这个多少钱？ |
| How much is the large one? | 大号的多少钱？ |
| How much are these shoes? | 这双鞋多少钱？ |
| **A:** How much are these headphones?<br>**B:** They're ninety dollars. | **A:** 这副耳机多少钱？<br>**B:** 九十美元。 |

---

### 7. Is this on sale?

**中文意思**

这个在打折吗？/ 这个有优惠吗？

**使用见解**

购物时询问折扣和促销。

常见表达：

* **on sale**：正在打折
* **20% off**：打八折 / 减 20%
* **a discount**：折扣
* **a promotion**：促销

**句型**

`Is this on sale?`

`Is there a discount?`

`Do you have any promotions?`

**例句**

| English | 中文 |
| --- | --- |
| Is this on sale? | 这个在打折吗？ |
| Is there a discount if I buy two? | 买两个有折扣吗？ |
| **A:** Is this on sale?<br>**B:** Yes, it's 20% off today. | **A:** 这个在打折吗？<br>**B:** 是的，今天打八折。 |

---

### 8. I'm looking for [something].

**中文意思**

我在找…… / 我想买……

**使用见解**

进入商店后，店员问你需要什么时，这是非常自然的回答。

可以用来说明自己想找什么类型的商品。

**句型**

`I'm looking for [something].`

**例句**

| English | 中文 |
| --- | --- |
| I'm looking for a jacket. | 我想买一件夹克。 |
| I'm looking for something cheaper. | 我想找便宜一点的。 |
| **A:** Can I help you?<br>**B:** Yeah, I'm looking for a pair of running shoes. | **A:** 需要帮忙吗？<br>**B:** 好的，我想买一双跑鞋。 |

### 10. Can I try [something] on?

**中文意思**

我可以试穿……吗？

**使用见解**

衣服、鞋子等购物场景的高频表达。

**Try on** 表示“试穿”。

代词放在中间：

* **try it on**
* **try them on**

**句型**

`Can I try [something] on?`

**例句**

| English | 中文 |
| --- | --- |
| Can I try this on? | 我可以试穿这个吗？ |
| Can I try these shoes on? | 我可以试穿这双鞋吗？ |

### 11. It's too [adjective]. / It fits [adverb].

**中文意思**

这个太……了。/ 这个穿起来……

**使用见解**

试穿以后，可以用来描述尺寸、松紧和合身程度。

常见表达：

* **too big**
* **too small**
* **too tight**
* **too loose**
* **fits well**
* **fits perfectly**

**句型**

`It's too [adjective].`

`It's a little too [adjective].`

`It fits [adverb].`

**例句**

| English | 中文 |
| --- | --- |
| It's too tight. | 这个太紧了。 |
| It's a little too big. | 这个有点太大了。 |
| It fits really well. | 这个穿起来很合身。 |
| **A:** How does it fit?<br>**B:** Pretty well, actually. | **A:** 穿起来怎么样？<br>**B:** 其实挺合身的。 |

### 12. I'll take it / them.

**中文意思**

我要这个。/ 这些我要了。

**使用见解**

购物时表示已经决定购买。

常见说法：

* **I'll take it.**
* **I'll take them.**
* **I'll take two.**
* **I'll take both.**

如果还没决定，也可以说：

**I'll think about it.**

**句型**

`I'll take it.`

`I'll take them.`

`I'll take [number].`

`I'll think about it.`

**例句**

| English | 中文 |
| --- | --- |
| I'll take it. | 这个我要了。 |
| I'll take both. | 两个我都要。 |
| I'll think about it. | 我再考虑一下。 |
| **A:** This one's on sale today.<br>**B:** Great. I'll take it. | **A:** 这个今天打折。<br>**B:** 太好了，这个我要了。 |

### 13. For here or to go?

**中文意思**

堂食还是外带？

**使用见解**

餐厅、咖啡店里非常常见。

常见回答：

* **For here, please.**
* **To go, please.**

自己点单时也可以说：

* **I'd like a coffee to go.**
* **Can I get this to go?**

如果已经吃了一部分，想把剩下的食物打包带走，可以说：

* **Could I get a box?**
* **Could you box this up for me?**

**句型**

`For here or to go?`

`I'd like [something] to go.`

`Can I get [something] to go?`

**例句**

| English | 中文 |
| --- | --- |
| For here, please. | 堂食，谢谢。 |
| To go, please. | 外带，谢谢。 |
| I'd like a coffee to go. | 我要一杯外带咖啡。 |
| **A:** For here or to go?<br>**B:** To go, please. | **A:** 堂食还是外带？<br>**B:** 外带，谢谢。 |

**句型**

`Can I pay in cash?`

| Can I pay in cash? | 我可以付现金吗？ |
| **A:** Can I pay with my phone?<br>**B:** Of course. | **A:** 可以用手机支付吗？<br>**B:** 当然。 |

### 15. Can we pay separately?

**中文意思**

我们可以分开付款吗？

**使用见解**

和朋友一起吃饭、购物时很常用。

常见表达：

* **pay separately**：分开付款
* **split the bill**：分账
* **pay together**：一起付款
* **It's on me.**：我请客

**句型**

`Can we pay separately?`

`Can we split the bill?`

`We'll pay together.`

`It's on me.`

**例句**

| English | 中文 |
| --- | --- |
| Can we pay separately? | 我们可以分开付款吗？ |
| Can we split the bill? | 我们可以分账吗？ |
| It's on me. | 我请客。 |
| **A:** Should we split the bill?<br>**B:** No, it's on me. | **A:** 我们分账吗？<br>**B:** 不用了，我请客。 |

### 16. Could we get the bill / check, please?

**中文意思**

麻烦买单。/ 可以结账吗？

**使用见解**

餐厅吃完后请求结账。

美式英语常说：

**the check**

英式英语更常说：

**the bill**

**Can we get...?** 和 **Could we get...?** 都很常见。

**句型**

`Could we get the bill / check, please?`

`Can we get the bill / check?`

**例句**

| English | 中文 |
| --- | --- |
| Could we get the bill, please? | 麻烦买单。 |
| Can we get the check? | 我们可以买单了吗？ |
| **A:** Anything else?<br>**B:** No, thanks. Could we get the check, please? | **A:** 还需要别的吗？<br>**B:** 不用了，谢谢。麻烦买单。 |

### 17. Can I get a receipt?

**中文意思**

可以给我一张收据吗？

**使用见解**

付款后索要收据时很常用。

店员也可能会问：

**Do you need a receipt?**

**句型**

`Can I get a receipt?`

`Could I have the receipt, please?`

**例句**

| English | 中文 |
| --- | --- |
| Can I get a receipt? | 可以给我一张收据吗？ |
| Could I have the receipt, please? | 麻烦给我收据。 |
| **A:** Do you need a receipt?<br>**B:** Yes, please. | **A:** 需要收据吗？<br>**B:** 要的，谢谢。 |

---

### 18. Can I return / exchange this?

**中文意思**

这个可以退 / 换吗？

**使用见解**

买完东西以后，如果商品不合适，可以用这些表达询问退货、换货或退款。

常见表达：

* **return this**：退掉这个
* **exchange this**：换这个
* **exchange this for a different size**：换成其他尺码
* **get a refund**：退款

**句型**

`Can I return this?`

`Can I exchange this?`

`I'd like to return [something].`

`I'd like to exchange [something] for [something].`

`Can I get a refund?`

**例句**

| English | 中文 |
| --- | --- |
| Can I return this? | 这个可以退吗？ |
| Can I exchange this for a larger size? | 这个可以换成大一码吗？ |
| Can I get a refund? | 可以退款吗？ |
| **A:** What's wrong with it?<br>**B:** It's too small. I'd like to exchange it for a larger size. | **A:** 有什么问题吗？<br>**B:** 太小了，我想换成大一码。 |

# 综合对话

**场景：** Emma 和 Daniel 先逛商店，之后去餐厅吃饭。

| English | 中文 |
| --- | --- |
| **Clerk:** Hi, can I help you? | **店员:** 你好，需要帮忙吗？ |
| **Emma:** Yeah, I'm looking for a jacket. | **Emma:** 好的，我想买一件夹克。 |
| **Clerk:** What kind are you looking for? | **店员:** 你想找什么样的？ |
| **Emma:** Something simple. Do you have this in black? | **Emma:** 简单一点的。这个有黑色的吗？ |
| **Clerk:** Yes. What size do you need? | **店员:** 有。你需要什么尺码？ |
| **Emma:** Medium. Can I try it on? | **Emma:** M 码。我可以试穿吗？ |
| **Clerk:** Of course. | **店员:** 当然。 |
| **Daniel:** How does it fit? | **Daniel:** 穿起来怎么样？ |
| **Emma:** It's a little too big. Do you have this in a smaller size? | **Emma:** 有点太大了。这个有小一点的尺码吗？ |
| **Clerk:** Yes, here's a small. | **店员:** 有，这是 S 码。 |
| **Emma:** This fits much better. How much is it? | **Emma:** 这个合适多了。多少钱？ |
| **Clerk:** It's sixty dollars. | **店员:** 六十美元。 |
| **Emma:** Is this on sale? | **Emma:** 这个在打折吗？ |
| **Clerk:** Yes, it's 20% off today. | **店员:** 是的，今天打八折。 |
| **Emma:** Great. I'll take it. | **Emma:** 好，这个我要了。 |
| **Clerk:** Would you like to pay by card or in cash? | **店员:** 你想刷卡还是付现金？ |
| **Emma:** By card, please. Can I get a receipt too? | **Emma:** 刷卡，谢谢。也可以给我一张收据吗？ |
| **Clerk:** Of course. | **店员:** 当然。 |
| **Daniel:** I'm hungry. Want to get something to eat? | **Daniel:** 我饿了。要不要去吃点东西？ |
| **Emma:** Sure. | **Emma:** 好啊。 |
| **Server:** Hi. What can I get for you? | **服务员:** 你好，想点什么？ |
| **Daniel:** What do you recommend? | **Daniel:** 你推荐什么？ |
| **Server:** The chicken sandwich is very popular. | **服务员:** 鸡肉三明治很受欢迎。 |
| **Daniel:** Does it come with fries? | **Daniel:** 配薯条吗？ |
| **Server:** Yes, it does. | **服务员:** 配的。 |
| **Daniel:** Sounds good. I'll have that. | **Daniel:** 听起来不错，我要那个。 |
