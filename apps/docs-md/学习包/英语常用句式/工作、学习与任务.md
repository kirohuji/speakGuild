# 工作、学习与任务

## 小提示

说明自己在做什么、做到哪一步、什么时候完成、哪里卡住了、需不需要帮助，这些都是工作和学习里很常见的交流内容。

很多表达会围绕“当前任务、进度、截止时间、问题、反馈和下一步”反复出现。熟悉这些句型以后，可以直接替换任务、项目、作业和时间来练习。

## 句型占位符

本章继续使用统一的句型标记：

* `[someone]`：某个人
* `[something]`：某件事、任务或内容
* `[noun]`：名词或名词短语
* `[adjective]`：形容词
* `[verb phrase]`：以动词原形开始的完整动作表达，比如 `finish the report`、`check the numbers`、`send the file`
* `[V-ing phrase]`：以 V-ing 开始的完整动作表达，比如 `reading the report`、`checking the data`
* `[clause]`：完整从句
* `[time]`：时间
* `[duration]`：持续时间，比如 `an hour`、`two more days`

## 表达、中文意思与使用见解

### 1. I'm working on [something].

**中文意思**

我正在做…… / 我正在处理……

**使用见解**

用于说明自己目前正在处理的任务、项目或问题。

**Work on** 很适合表示“正在着手处理某件事情”。

**句型**

`I'm working on [something].`

**例句**

| English | 中文 |
| --- | --- |
| I'm working on a new project. | 我正在做一个新项目。 |
| I'm working on the report right now. | 我现在正在处理这份报告。 |
| **A:** What are you doing?<br>**B:** I'm working on tomorrow's presentation. | **A:** 你在做什么？<br>**B:** 我正在准备明天的演示。 |

---

### 2. I'm almost done with [something].

**中文意思**

我快做完……了。

**使用见解**

用于说明某项任务已经接近完成。

也可以直接说：

**I'm almost done.**

**句型**

`I'm almost done with [something].`

**例句**

| English | 中文 |
| --- | --- |
| I'm almost done with the report. | 这份报告我快写完了。 |
| I'm almost done with my homework. | 我的作业快做完了。 |
| **A:** Are you still working?<br>**B:** Yeah, but I'm almost done. | **A:** 你还在工作吗？<br>**B:** 是，不过快做完了。 |

---

### 3. I'm halfway through [something].

**中文意思**

我做到……一半了。

**使用见解**

用于说明任务已经完成了大约一半。

**Halfway through** 很适合描述阅读、项目、作业、课程等进度。

**句型**

`I'm halfway through [something].`

**例句**

| English | 中文 |
| --- | --- |
| I'm halfway through the report. | 报告我做到一半了。 |
| I'm halfway through the book. | 这本书我看到一半了。 |
| **A:** How much have you finished?<br>**B:** I'm about halfway through it. | **A:** 你做完多少了？<br>**B:** 大概做到一半了。 |

### 4. I haven't finished [something] yet.

**中文意思**

我还没完成……

**使用见解**

用于说明某项任务到现在仍然没有完成。

**Yet** 经常放在否定句句尾，表示“到现在为止还没有”。

**句型**

`I haven't finished [something] yet.`

**例句**

| English | 中文 |
| --- | --- |
| I haven't finished the report yet. | 我还没写完报告。 |
| I haven't finished reading it yet. | 我还没看完。 |
| **A:** Did you finish the assignment?<br>**B:** Not yet. I haven't finished the last part. | **A:** 作业做完了吗？<br>**B:** 还没有，最后一部分还没做完。 |

### 5. I need to [verb phrase].

**中文意思**

我需要…… / 我得……

**使用见解**

用于说明接下来需要完成的事情。

* **check the numbers again**
* **send one more email**
* **review the file**

**句型**

`I need to [verb phrase].`

**例句**

| English | 中文 |
| --- | --- |
| I need to finish this today. | 我今天得把这个做完。 |
