# 动词与介词搭配：表达情绪、评价、回应与人际互动

在日常交流中，我们经常需要道歉、感谢、抱怨、批评、回应他人的行为，或者描述人与人之间的态度。

这些表达通常涉及三个要素：行为的发出者、行为针对的对象，以及引发行为的原因。

例如：

- apologize to someone for something：因为某件事向某人道歉。
- blame someone for something：因为某件事责怪某人。
- complain to someone about something：向某人抱怨某件事。
- thank someone for something：因为某件事感谢某人。

掌握这些搭配时，需要理解动词所表达的行为，以及不同介词分别连接什么信息。

## 一、道歉、请求与感谢

### 1. apologize for：因某事道歉

核心含义： 说明道歉的原因，可以是自己的行为、错误，也可以是造成的不便。

常见结构： apologize for + 名词 / 动名词

| 常见搭配                            | 含义与使用见解       |
| ------------------------------- | ------------- |
| apologize for the delay         | 为延误道歉，常见于工作沟通 |
| apologize for the mistake       | 为错误道歉         |
| apologize for the inconvenience | 为造成的不便道歉，比较正式 |
| apologize for being late        | 为迟到道歉         |
| apologize for what someone said | 为某人说过的话道歉     |

| 英文例句                                                               | 中文释义                  |
| ------------------------------------------------------------------ | --------------------- |
| I apologize for the delay.                                         | 很抱歉耽误了时间。             |
| She apologized for being late to the meeting.                      | 她为开会迟到道了歉。            |
| I want to apologize for what I said yesterday.                     | 我想为昨天说的话道歉。           |
| We sincerely apologize for any inconvenience this may have caused. | 对于此事可能造成的任何不便，我们深表歉意。 |
| There's no need to apologize for asking questions.                 | 没必要因为提问而道歉。           |

使用见解：

apologize for 关注引发道歉的事情。

其中 for 是介词，后面接动名词：

I apologize for interrupting you.

抱歉打断了你。

日常口语中，I'm sorry for... 或 Sorry about... 往往更加自然。apologize 则稍显正式，适合认真承认错误、工作沟通或者需要郑重表达歉意的场景。

### 2. apologize to：向某人道歉

核心含义： 指出接受道歉的人，强调道歉行为所针对的对象。

常见结构： apologize to + 人

| 常见搭配                               | 含义与使用见解  |
| ---------------------------------- | -------- |
| apologize to someone               | 向某人道歉    |
| apologize to a customer            | 向客户道歉    |
| apologize to the public            | 向公众道歉    |
| apologize to someone in person     | 当面向某人道歉  |
| apologize to someone for something | 因某事向某人道歉 |

| 英文例句                                                                 | 中文释义                 |
| -------------------------------------------------------------------- | -------------------- |
| You should apologize to her.                                         | 你应该向她道歉。             |
| He refused to apologize to his colleague.                            | 他拒绝向同事道歉。            |
| I think you owe your parents an apology.                             | 我觉得你应该向父母道歉。         |
| She apologized to everyone for the misunderstanding.                 | 她为这场误会向所有人道了歉。       |
| I apologized to him in person because I wanted to make things right. | 我亲自向他道歉，因为我想弥补自己的过错。 |

使用见解：

apologize to 和 apologize for 可以出现在同一句话中，分别说明道歉对象和原因。

I apologized to my friend for forgetting his birthday.

我因为忘记朋友的生日而向他道歉。

注意不要把两个介词混淆：

- apologize to someone
- apologize for something

### 3. ask for：请求、索取；要求得到

核心含义： 主动提出请求，希望得到某种东西、帮助、信息或机会。

常见结构： ask for + 名词

| 常见搭配               | 含义与使用见解 |
| ------------------ | ------- |
| ask for help       | 寻求帮助    |
| ask for advice     | 征求建议    |
| ask for permission | 请求许可    |
| ask for a favour   | 请求帮忙    |
| ask for a refund   | 要求退款    |
| ask for more time  | 请求更多时间  |

| 英文例句                                              | 中文释义            |
| ------------------------------------------------- | --------------- |
| Don't be afraid to ask for help.                  | 不要害怕寻求帮助。       |
| I asked for more time to finish the project.      | 我请求多给一些时间完成项目。  |
| She asked for my advice before making a decision. | 她在作决定之前征求了我的意见。 |
| I'd like to ask for a refund.                     | 我想申请退款。         |
| He never asks for anything in return.             | 他从不要求任何回报。      |

使用见解：

ask for 强调希望得到某样东西。如果希望别人采取某个行动，通常使用 ask someone to do something。

| 结构                          | 例句与含义                                    |
| --------------------------- | ---------------------------------------- |
| ask for something           | I asked for some help. 我请求了一些帮助。         |
| ask someone for something   | I asked my colleague for help. 我向同事寻求帮助。 |
| ask someone to do something | I asked him to help me. 我请他帮忙。           |

另外，ask for it 在口语中有一种特殊含义，表示某人自找麻烦或招致不好的结果，语气可能带有责备。

He kept provoking them. He was asking for trouble.

他一直在挑衅他们，简直是在自找麻烦。

### 4. thank for：因某事感谢

核心含义： 表达感谢，同时说明感谢的具体原因。

常见结构： thank someone for + 名词 / 动名词

| 常见搭配                              | 含义与使用见解  |
| --------------------------------- | -------- |
| thank someone for their help      | 感谢某人的帮助  |
| thank someone for their support   | 感谢某人的支持  |
| thank someone for their patience  | 感谢某人的耐心  |
| thank someone for coming          | 感谢某人到场   |
| thank someone for doing something | 感谢某人做了某事 |

| 英文例句                                                   | 中文释义         |
| ------------------------------------------------------ | ------------ |
| Thank you for your help.                               | 谢谢你的帮助。      |
| I want to thank you for everything you've done for me. | 我想感谢你为我做的一切。 |
| She thanked him for being so understanding.            | 她感谢他的理解与体谅。  |
| Thank you for taking the time to explain everything.   | 谢谢你花时间解释这一切。 |
| I'd like to thank everyone for coming today.           | 感谢今天到场的每一位。  |

使用见解：

thank 是及物动词，通常直接连接感谢对象，再用 for 引出原因。

I thanked her for helping me.

我感谢她帮助了我。

还需要区分：

- Thank you for helping me. 谢谢你帮助我。
- Thanks for helping me. 谢谢你的帮助。

Thanks for... 更简洁，特别适合日常交流。

## 二、责怪、批评与原谅

### 5. blame for：因某事责怪某人

核心含义： 认为某人应该对某个错误、问题或不良结果承担责任。

常见结构： blame someone for + 名词 / 动名词

| 常见搭配                                    | 含义与使用见解      |
| --------------------------------------- | ------------ |
| blame someone for a mistake             | 因错误责怪某人      |
| blame someone for the failure           | 将失败归咎于某人     |
| blame someone for causing trouble       | 责怪某人制造麻烦     |
| blame yourself for something            | 因某事责怪自己      |
| can't blame someone for doing something | 可以理解某人为什么这样做 |

| 英文例句                                                               | 中文释义                 |
| ------------------------------------------------------------------ | -------------------- |
| Don't blame me for your mistakes.                                  | 不要因为你自己的错误责怪我。       |
| She blamed herself for what happened.                              | 她为发生的事情责怪自己。         |
| He blamed his colleague for missing the deadline.                  | 他把错过截止日期的责任归咎于同事。    |
| You can't blame her for being upset.                               | 她会生气也是可以理解的。         |
| I don't think it's fair to blame one person for the whole problem. | 我认为把整个问题都归咎于一个人并不公平。 |

使用见解：

blame someone for something 明确指出了被责怪的人以及责怪的原因。

尤其值得掌握：

You can't blame someone for...

这一结构往往用于表示理解或同情。

You can't blame him for wanting a better life.

他想过上更好的生活，这完全可以理解。

### 6. blame on：把责任归咎于……

核心含义： 把某个问题、错误或不良结果归因于某人或某种因素。

常见结构： blame something on + 人 / 原因

| 常见搭配                           | 含义与使用见解    |
| ------------------------------ | ---------- |
| blame a mistake on someone     | 把错误归咎于某人   |
| blame the failure on something | 把失败归因于某个因素 |
| blame the delay on traffic     | 将延误归咎于交通   |
| blame everything on someone    | 把所有问题都推给某人 |
| blame it on bad luck           | 归咎于运气不好    |

| 英文例句                                                  | 中文释义              |
| ----------------------------------------------------- | ----------------- |
| He blamed the delay on heavy traffic.                 | 他把延误归咎于严重的交通拥堵。   |
| Don't blame everything on me.                         | 不要把所有事情都怪到我头上。    |
| The company blamed the failure on technical problems. | 公司将失败归因于技术问题。     |
| She tried to blame her mistake on someone else.       | 她试图把自己的错误推给别人。    |
| You can't blame every problem on bad luck.            | 你不能把所有问题都归咎于运气不好。 |

使用见解：

blame for 与 blame on 的核心区别在于句子组织方式。

| 结构                          | 关注点      | 例句                                             |
| --------------------------- | -------- | ---------------------------------------------- |
| blame someone for something | 因某事责怪某人  | They blamed him for the accident. 他们因为这起事故责怪他。 |
| blame something on someone  | 把某事归咎于某人 | They blamed the accident on him. 他们把事故归咎于他。    |
| be to blame for something   | 对某事负有责任  | He was to blame for the accident. 他应该为这起事故负责。  |

注意：不能把 blame someone for... 直接改成 blame someone on...。

### 7. criticize for：因某事批评某人

核心含义： 针对某人的行为、决定、表现或做法提出批评。

常见结构： criticize someone for + 名词 / 动名词

| 常见搭配                                  | 含义与使用见解   |
| ------------------------------------- | --------- |
| criticize someone for a mistake       | 因错误批评某人   |
| criticize someone for being careless  | 批评某人粗心    |
| criticize a company for its policies  | 批评公司的政策   |
| criticize someone for doing something | 因某种行为批评某人 |
| be criticized for something           | 因某事受到批评   |

| 英文例句                                                                     | 中文释义                 |
| ------------------------------------------------------------------------ | -------------------- |
| He was criticized for his poor performance.                              | 他因为表现不佳而受到批评。        |
| She criticized the company for ignoring customer complaints.             | 她批评公司无视客户投诉。         |
| It's easy to criticize someone for making mistakes.                      | 批评别人犯错很容易。           |
| The government was heavily criticized for its response to the crisis.    | 政府因应对危机的方式受到严厉批评。    |
| I don't mind being criticized, as long as the criticism is constructive. | 只要批评具有建设性，我并不介意受到批评。 |

使用见解：

criticize for 通常针对行为或表现作出评价。与 blame for 相比，它不一定涉及责任归属，也可以是对方法、质量或判断提出意见。

He criticized my writing for being too repetitive.

他批评我的文章过于重复。

这里的重点在于评价文章的问题，而不涉及追究责任。

### 8. forgive for：原谅某人的某种行为

核心含义： 对某人的错误、冒犯或伤害选择宽恕，不再持续责怪对方。

常见结构： forgive someone for + 名词 / 动名词

| 常见搭配                                | 含义与使用见解     |
| ----------------------------------- | ----------- |
| forgive someone for a mistake       | 原谅某人的错误     |
| forgive someone for lying           | 原谅某人撒谎      |
| forgive someone for what they did   | 原谅某人的所作所为   |
| forgive yourself for something      | 原谅自己        |
| never forgive someone for something | 永远无法原谅某人的行为 |

| 英文例句                                                     | 中文释义              |
| -------------------------------------------------------- | ----------------- |
| Can you forgive me for what I said?                      | 你能原谅我说过的话吗？       |
| She eventually forgave him for lying to her.             | 她最终原谅了他对自己撒谎的行为。  |
| I don't think I can forgive him for what he did.         | 我觉得自己无法原谅他的所作所为。  |
| You need to learn to forgive yourself for past mistakes. | 你需要学会原谅自己过去犯下的错误。 |
| He apologized, but she wasn't ready to forgive him.      | 他道歉了，但她还没有准备好原谅他。 |

使用见解：

forgive someone for something 和 apologize to someone for something 经常出现在同一类情境中。

He apologized to her for lying, but she couldn't forgive him for it.

他因为撒谎向她道歉，但她无法原谅他。

注意 forgive 可以直接接人：

I forgive you.

我原谅你。

而 apologize 需要通过 to 连接道歉对象。

## 三、抱怨、评论与表达态度

### 9. comment on：评论、发表意见

核心含义： 对某件事情、观点、行为或情况进行评价、说明或发表看法。

常见结构： comment on + 话题 / 事件 / 行为

| 常见搭配                            | 含义与使用见解   |
| ------------------------------- | --------- |
| comment on a situation          | 评论某种情况    |
| comment on someone's appearance | 评论某人的外貌   |
| comment on a proposal           | 对提议发表意见   |
| comment on the results          | 评论结果      |
| refuse to comment on            | 拒绝就某事发表评论 |

| 英文例句                                                  | 中文释义              |
| ----------------------------------------------------- | ----------------- |
| I'd rather not comment on that.                       | 我不太想对此发表评论。       |
| She commented on how much he had changed.             | 她谈到了他发生了多大的变化。    |
| The manager refused to comment on the decision.       | 经理拒绝对这项决定发表评论。    |
| Several experts have commented on the possible risks. | 几位专家已经对潜在风险发表了意见。 |
| He always comments on other people's appearance.      | 他总是对别人的外貌评头论足。    |

使用见解：

comment on 可以表达积极、消极或中立的意见。

它通常强调针对某个对象发表看法，尤其适用于讨论、评价和正式沟通。

I don't feel qualified to comment on this issue.

我觉得自己没有足够的专业知识来评论这个问题。

另外，comment that... 可以直接引出评论的内容：

She commented that the room seemed unusually quiet.

她说这个房间似乎安静得有些反常。

### 10. complain about：抱怨某事

核心含义： 对某种不满意的情况、行为或经历表达抱怨。

常见结构： complain about + 名词 / 动名词

| 常见搭配                             | 含义与使用见解 |
| -------------------------------- | ------- |
| complain about the weather       | 抱怨天气    |
| complain about work              | 抱怨工作    |
| complain about the noise         | 抱怨噪音    |
| complain about being ignored     | 抱怨自己被忽视 |
| keep complaining about something | 不停地抱怨某事 |

| 英文例句                                                                 | 中文释义            |
| -------------------------------------------------------------------- | --------------- |
| He complains about everything.                                       | 他什么事情都要抱怨。      |
| I'm tired of hearing you complain about work.                        | 我已经听腻了你抱怨工作。    |
| She complained about being treated unfairly.                         | 她抱怨自己受到了不公平的对待。 |
| There's no point complaining about something you can't change.       | 抱怨无法改变的事情没有意义。  |
| The neighbours complained about the noise coming from our apartment. | 邻居抱怨我们公寓传出的噪音。  |

使用见解：

complain about 的重点是引发不满的事情，语气可以从轻微抱怨到正式投诉。

I'm not complaining, but I think things could be better.

我没有要抱怨的意思，但我觉得情况可以更好一些。

I'm not complaining 经常用于缓和后面的负面评价。

### 11. complain to：向某人投诉、抱怨

核心含义： 指明接受投诉或抱怨的对象，通常是能够听取意见或处理问题的人。

常见结构： complain to + 人 / 机构

| 常见搭配                                | 含义与使用见解 |
| ----------------------------------- | ------- |
| complain to a manager               | 向经理投诉   |
| complain to customer service        | 向客服投诉   |
| complain to the landlord            | 向房东投诉   |
| complain to a friend                | 向朋友抱怨   |
| complain to someone about something | 向某人抱怨某事 |

| 英文例句                                                                         | 中文释义               |
| ---------------------------------------------------------------------------- | ------------------ |
| I complained to the manager about the service.                               | 我向经理投诉了服务问题。       |
| Several residents complained to the council about the noise.                 | 几位居民向地方议会投诉噪音问题。   |
| She keeps complaining to me about her boyfriend.                             | 她总是向我抱怨她的男朋友。      |
| If you're unhappy with the product, you should complain to customer service. | 如果你对产品不满意，应该向客服投诉。 |

使用见解：

complain to 与 complain about 可以结合使用：

complain to someone about something

介词 to 连接接受抱怨的人，about 连接抱怨的事情。

比较：

She complained about her boss.

她抱怨自己的老板。

She complained to her boss.

她向老板抱怨。

She complained to her boss about the workload.

她向老板抱怨工作量太大。

## 四、表情、玩笑与嘲笑

### 12. frown at：对……皱眉

核心含义： 通过皱眉表达不满、困惑、担忧或不赞成。

常见结构： frown at + 人 / 事物

| 常见搭配                          | 含义与使用见解   |
| ----------------------------- | --------- |
| frown at someone              | 对某人皱眉     |
| frown at a question           | 看到问题时皱眉   |
| frown at a screen             | 对着屏幕皱眉    |
| frown at the suggestion       | 对建议表现出不赞同 |
| frown at someone in confusion | 困惑地看着某人皱眉 |

| 英文例句                                                            | 中文释义                  |
| --------------------------------------------------------------- | --------------------- |
| She frowned at me but said nothing.                             | 她皱着眉看了我一眼，却什么都没说。     |
| He frowned at the question, trying to understand what it meant. | 他看着这个问题皱起眉头，试图理解它的意思。 |
| My father frowned at the suggestion.                            | 父亲听到这个建议后皱起了眉头。       |
| She frowned at her phone when she read the message.             | 她读到那条消息时，皱着眉看着手机。     |

使用见解：

frown at 描述可见的面部反应，适合叙事、小说和描述人物情绪。

另外：

frown on / frown upon something

表示“不赞成某种行为”，常用于社会习俗或群体态度。

Smoking is frowned upon in many workplaces.

在许多工作场所，吸烟是不被认可的行为。

### 13. joke about：拿某事开玩笑

核心含义： 把某件事当作玩笑话题，以幽默、调侃或轻松的方式谈论。

常见结构： joke about + 事情 / 话题

| 常见搭配                         | 含义与使用见解   |
| ---------------------------- | --------- |
| joke about work              | 拿工作开玩笑    |
| joke about something serious | 拿严肃的事情开玩笑 |
| joke about getting old       | 调侃自己变老    |
| joke about someone's habits  | 拿某人的习惯开玩笑 |
| keep joking about something  | 不停拿某件事开玩笑 |

| 英文例句                                                                  | 中文释义                  |
| --------------------------------------------------------------------- | --------------------- |
| We often joke about how bad we were at school.                        | 我们经常拿当年在学校表现不好这件事开玩笑。 |
| I don't think you should joke about something like that.              | 我觉得你不应该拿那种事情开玩笑。      |
| He likes joking about his own mistakes.                               | 他喜欢拿自己的错误开玩笑。         |
| She was only joking about quitting her job.                           | 她刚才说辞职只是开玩笑。          |
| Some people joke about their problems to make themselves feel better. | 有些人会通过调侃自己的问题让心情好一些。  |

使用见解：

joke about 可以是善意的幽默，也可能因为话题敏感而让人不舒服。

如果想表达“我开玩笑的”，日常口语更常使用：

I'm just joking.

我只是开个玩笑。

I was only joking.

我刚才只是开玩笑。

### 14. laugh about：谈起某事时觉得好笑

核心含义： 因某段经历或某件事情而发笑，尤其常见于回忆过去的趣事。

常见结构： laugh about + 事情 / 经历

| 常见搭配                      | 含义与使用见解     |
| ------------------------- | ----------- |
| laugh about the past      | 笑谈过去        |
| laugh about a mistake     | 拿某次错误当趣事    |
| laugh about an experience | 笑谈某段经历      |
| laugh about it later      | 以后回想起来会觉得好笑 |
| something to laugh about  | 值得一笑的事情     |

| 英文例句                                                            | 中文释义                          |
| --------------------------------------------------------------- | ----------------------------- |
| We still laugh about that day.                                  | 我们现在想起那一天还是会笑。                |
| One day, you'll be able to laugh about this.                    | 总有一天，你会觉得这件事也没什么大不了，甚至可以一笑置之。 |
| They spent the evening laughing about their school days.        | 他们整个晚上都在笑谈学生时代的趣事。            |
| It was embarrassing at the time, but we can laugh about it now. | 当时确实很尴尬，但现在我们已经可以把它当作笑话来看了。   |

使用见解：

laugh about 经常带有回忆、轻松和共同经历的意味。

We'll laugh about this someday.

总有一天，我们会笑着谈起这件事。

这句话可以用来缓和当下的尴尬或困难。

### 15. laugh at：因……而笑；嘲笑

核心含义： 因某个人、行为或事情发笑，根据语境可以表示觉得好笑，也可能带有嘲讽、轻视或不尊重。

常见结构： laugh at + 人 / 事情

| 常见搭配               | 含义与使用见解    |
| ------------------ | ---------- |
| laugh at someone   | 笑某人，可能带有嘲讽 |
| laugh at a joke    | 听到笑话而笑     |
| laugh at a mistake | 因错误而发笑     |
| laugh at yourself  | 自嘲         |
| be laughed at      | 被人嘲笑       |

| 英文例句                                                           | 中文释义               |
| -------------------------------------------------------------- | ------------------ |
| Why are you laughing at me?                                    | 你为什么笑我？            |
| Everyone laughed at his joke.                                  | 大家听了他的笑话都笑了。       |
| I hate being laughed at when I make mistakes.                  | 我讨厌犯错时被别人嘲笑。       |
| It's important to be able to laugh at yourself sometimes.      | 有时候能够自嘲也很重要。       |
| She laughed at the idea because she thought it was ridiculous. | 她觉得那个想法很荒谬，所以笑了出来。 |

使用见解：

laugh at someone 很容易被理解为嘲笑，因此描述善意的共同欢笑时，可以使用 laugh with someone。

比较：

They laughed at me.

他们嘲笑我。

They laughed with me.

他们和我一起笑。

laugh at a joke 则通常没有负面的意思。

### 16. laugh off：一笑置之；用笑掩饰

核心含义： 面对尴尬、批评、错误或不愉快的事情时，通过笑来淡化其严重性或掩饰真实感受。

常见结构： laugh something off

| 常见搭配                             | 含义与使用见解   |
| -------------------------------- | --------- |
| laugh off criticism              | 对批评一笑置之   |
| laugh off a mistake              | 笑着淡化自己的错误 |
| laugh off an embarrassing moment | 用笑化解尴尬    |
| laugh off an insult              | 对侮辱一笑置之   |
| try to laugh something off       | 试图用笑掩饰某事  |

| 英文例句                                                      | 中文释义                     |
| --------------------------------------------------------- | ------------------------ |
| He tried to laugh off the embarrassing situation.         | 他试图用笑来化解尴尬的局面。           |
| She laughed off the criticism and continued working.      | 她对批评一笑置之，继续工作。           |
| I made a stupid mistake, so I just laughed it off.        | 我犯了个愚蠢的错误，于是干脆一笑置之。      |
| He laughed off the insult, although it clearly upset him. | 虽然那句侮辱显然让他很难受，但他还是笑着带过了。 |

使用见解：

laugh off 的重点在于面对某件事的处理方式，尤其适合描述人物如何应对难堪或负面评价。

注意它属于可分离短语动词：

- laugh the mistake off
- laugh off the mistake
- laugh it off

当宾语是 it、them 等人称代词时，必须放在 laugh 和 off 之间。

### 17. make fun of：取笑、嘲弄

核心含义： 因某人的外貌、行为、习惯、错误或其他特点而取笑对方。

常见结构： make fun of + 人 / 事情

| 常见搭配                             | 含义与使用见解 |
| -------------------------------- | ------- |
| make fun of someone              | 取笑某人    |
| make fun of someone's accent     | 嘲笑某人的口音 |
| make fun of someone's appearance | 嘲笑某人的外貌 |
| make fun of yourself             | 自嘲      |
| be made fun of                   | 被取笑     |

| 英文例句                                                           | 中文释义              |
| -------------------------------------------------------------- | ----------------- |
| Stop making fun of me.                                         | 别再取笑我了。           |
| It's cruel to make fun of someone because of their appearance. | 因为外貌而取笑别人是很刻薄的行为。 |
| He used to make fun of my accent.                              | 他以前经常取笑我的口音。      |
| I don't mind making fun of myself.                             | 我不介意拿自己开玩笑。       |
| She was afraid of being made fun of in front of everyone.      | 她害怕在所有人面前被取笑。     |

使用见解：

make fun of 往往比 joke about 更具有明确的取笑对象。

在朋友之间，它也可以表示轻松调侃：

I'm just making fun of you.

我只是逗你玩。

但是否善意仍然取决于双方关系、语气和具体内容。

### joke about / laugh about / laugh at / laugh off / make fun of 辨析

| 表达          | 核心区别             | 例句                                                |
| ----------- | ---------------- | ------------------------------------------------- |
| joke about  | 以某事作为开玩笑的话题      | We joked about getting older. 我们拿年纪变大这件事开玩笑。      |
| laugh about | 回想或谈论某事时觉得好笑     | We laughed about the whole experience. 我们笑谈了整段经历。 |
| laugh at    | 因某人或某事而笑，也可能表示嘲笑 | They laughed at my mistake. 他们因为我的错误笑了起来。         |
| laugh off   | 用笑淡化负面事情         | I laughed off the criticism. 我对批评一笑置之。            |
| make fun of | 以某人为对象进行取笑       | They made fun of his clothes. 他们取笑他的衣服。           |

## 五、忍受、回应与劝说

### 18. put up with：忍受、容忍

核心含义： 在不满意或不舒服的情况下，继续接受某个人的行为或某种难以改变的状况。

常见结构： put up with + 人 / 事情 / 动名词

| 常见搭配                                | 含义与使用见解  |
| ----------------------------------- | -------- |
| put up with noise                   | 忍受噪音     |
| put up with someone's behaviour     | 容忍某人的行为  |
| put up with the situation           | 忍受当前处境   |
| put up with being treated badly     | 忍受受到恶劣对待 |
| can't put up with something anymore | 再也无法忍受某事 |

| 英文例句                                                                  | 中文释义                   |
| --------------------------------------------------------------------- | ---------------------- |
| I can't put up with this noise anymore.                               | 我再也受不了这种噪音了。           |
| I don't know how she puts up with him.                                | 我真不知道她是怎么忍受他的。         |
| You shouldn't have to put up with being treated like that.            | 你不应该一直忍受别人那样对待你。       |
| We've put up with these problems for far too long.                    | 我们已经忍受这些问题太久了。         |
| I'm willing to put up with a few inconveniences if the job pays well. | 如果这份工作的薪水不错，我愿意忍受一些不便。 |

使用见解：

put up with 在日常口语中非常高频，经常用于表达对某种状况的不满。

它与 tolerate 意思接近，但 put up with 更口语化。

尤其值得掌握：

I can't put up with this anymore.

我真的再也受不了了。

How do you put up with it?

你是怎么忍受得了的？

### 19. react to：对……作出反应

核心含义： 在受到某种刺激、信息、行为或事件影响之后，表现出相应的情绪、态度或行动。

常见结构： react to + 人 / 事件 / 情况

| 常见搭配                          | 含义与使用见解    |
| ----------------------------- | ---------- |
| react to the news             | 对消息作出反应    |
| react to criticism            | 对批评作出反应    |
| react to a situation          | 应对某种情况     |
| react to someone's behaviour  | 对某人的行为作出反应 |
| react badly to something      | 对某事反应不好    |
| react positively to something | 对某事作出积极回应  |

| 英文例句                                               | 中文释义              |
| -------------------------------------------------- | ----------------- |
| How did she react to the news?                     | 她听到这个消息后是什么反应？    |
| He reacted badly to the criticism.                 | 他对批评的反应很不好。       |
| I wasn't sure how to react to what he said.        | 我不知道该如何回应他说的话。    |
| People react differently to stressful situations.  | 人们面对压力情境时会有不同的反应。 |
| The market reacted positively to the announcement. | 市场对这项公告作出了积极反应。   |

使用见解：

react to 强调受到外部因素影响后产生的反应。

可以结合副词表达不同态度：

| 搭配               | 例句                                                               |
| ---------------- | ---------------------------------------------------------------- |
| react calmly     | She reacted calmly to the accusation. 她冷静地回应了指控。                 |
| react angrily    | He reacted angrily to the decision. 他对这个决定反应愤怒。                  |
| react positively | Customers reacted positively to the change. 客户对变化作出了积极回应。        |
| overreact to     | I think you're overreacting to a small mistake. 我觉得你对一个小错误反应过度了。 |

### 20. reason with：劝说某人讲道理

核心含义： 通过讲事实、分析原因或进行理性沟通，试图让某人改变想法或行为。

常见结构： reason with + 人

| 常见搭配                                | 含义与使用见解    |
| ----------------------------------- | ---------- |
| reason with someone                 | 试图说服某人讲道理  |
| try to reason with someone          | 尝试与某人理性沟通  |
| impossible to reason with           | 完全无法讲道理    |
| difficult to reason with            | 很难通过讲道理说服  |
| reason with someone about something | 就某件事与某人讲道理 |

| 英文例句                                                                          | 中文释义                       |
| ----------------------------------------------------------------------------- | -------------------------- |
| I tried to reason with him, but he wouldn't listen.                           | 我试图和他讲道理，但他根本不听。           |
| There's no reasoning with her when she's angry.                               | 她生气的时候根本听不进道理。             |
| Instead of shouting, try reasoning with him.                                  | 与其大喊大叫，不如试着和他讲道理。          |
| She managed to reason with the child and calm him down.                       | 她成功地和孩子讲清楚了道理，让他平静下来。      |
| It's difficult to reason with someone who refuses to consider other opinions. | 如果一个人拒绝考虑其他观点，就很难通过讲道理说服他。 |

使用见解：

reason with 强调使用理性的方式影响对方的判断。

非常常见的搭配是：

There's no reasoning with someone.

和某人根本讲不通道理。

另外，reason 作名词时表示“原因、理由”，作动词时可以表示“推理、理性思考”。

We need to reason through the problem carefully.

我们需要仔细分析这个问题。

reason through 强调分析问题的过程，与 reason with someone 的人际劝说含义不同。

## 六、喊叫、攻击与炫耀

### 21. shout at：冲某人大喊

核心含义： 对某人提高音量喊叫，通常带有愤怒、责备或不满的情绪。

常见结构： shout at + 人

| 常见搭配                     | 含义与使用见解 |
| ------------------------ | ------- |
| shout at someone         | 冲某人大喊   |
| shout at a child         | 对孩子大喊   |
| shout at someone angrily | 愤怒地冲某人喊 |
| stop shouting at me      | 别再冲我喊了  |
| be shouted at            | 被人吼叫    |

| 英文例句                                                                  | 中文释义                     |
| --------------------------------------------------------------------- | ------------------------ |
| Please don't shout at me.                                             | 请不要冲我大喊。                 |
| He shouted at his colleague in front of everyone.                     | 他当着所有人的面冲同事大喊。           |
| She was upset because her boss had shouted at her.                    | 她很难过，因为老板刚才冲她发了火。        |
| There's no need to shout at someone just because they made a mistake. | 没必要因为别人犯了错就冲他们大喊。        |
| I'm trying to explain what happened, so please stop shouting at me.   | 我正在试着解释发生了什么，所以请不要再冲我喊了。 |

使用见解：

shout at 与 shout to 的区别十分重要。

| 表达               | 核心区别           | 例句                                                   |
| ---------------- | -------------- | ---------------------------------------------------- |
| shout at someone | 通常带有愤怒、责备或攻击意味 | He shouted at me. 他冲我大喊。                             |
| shout to someone | 为了让远处的人听见而大声喊话 | She shouted to me from across the street. 她在街对面大声喊我。 |
| shout for help   | 大声呼救           | He shouted for help. 他大声呼救。                          |

shout at 通常容易让人联想到冲突，但具体情绪仍需要结合语境判断。

### 22. show off to：向某人炫耀、卖弄

核心含义： 为了获得注意、赞美或认可，刻意向某人展示自己的能力、财富、成就或其他优势。

常见结构： show off to + 人

| 常见搭配                          | 含义与使用见解    |
| ----------------------------- | ---------- |
| show off to friends           | 向朋友炫耀      |
| show off to classmates        | 在同学面前卖弄    |
| show off to colleagues        | 向同事炫耀      |
| show off your skills          | 炫耀自己的技能    |
| show something off to someone | 向某人展示并炫耀某物 |

| 英文例句                                                                     | 中文释义                 |
| ------------------------------------------------------------------------ | -------------------- |
| He was just showing off to his friends.                                  | 他只是在朋友面前炫耀。          |
| She bought an expensive watch to show off to her colleagues.             | 她买了一块昂贵的手表，想在同事面前炫耀。 |
| Stop showing off to everyone.                                            | 别再到处炫耀了。             |
| He likes showing off his knowledge to people who know less than he does. | 他喜欢在懂得比自己少的人面前卖弄知识。  |
| The child was showing off his new tricks to his parents.                 | 那个孩子正在向父母炫耀自己学会的新把戏。 |

使用见解：

show off 经常带有轻微批评意味，表示一个人刻意引起别人注意。

但在某些场合，也可以表示兴奋地展示自己的本领。

注意两种不同结构：

He's showing off to his friends.

他正在朋友面前炫耀。

He's showing off his new car to his friends.

他正在向朋友炫耀自己的新车。

如果宾语是代词，需要放在 show 和 off 之间：

He showed it off to everyone.

他把那东西向所有人炫耀了一遍。

### 23. strike out at：突然攻击；愤怒地抨击

核心含义： 对某人或某种事物突然发起攻击，可以是实际的身体攻击，也可以是言语上的激烈抨击。

常见结构： strike out at + 人 / 对象

| 常见搭配                           | 含义与使用见解    |
| ------------------------------ | ---------- |
| strike out at someone          | 突然攻击某人     |
| strike out at an attacker      | 出手攻击袭击者    |
| strike out at critics          | 愤怒地抨击批评者   |
| strike out at the media        | 猛烈抨击媒体     |
| strike out at someone in anger | 愤怒地向某人发起攻击 |

| 英文例句                                                           | 中文释义                  |
| -------------------------------------------------------------- | --------------------- |
| He suddenly struck out at the man standing beside him.         | 他突然出手攻击站在身旁的男人。       |
| The politician struck out at his critics during the interview. | 这位政治人物在采访中猛烈抨击了批评他的人。 |
| She struck out at anyone who questioned her decision.          | 她愤怒地抨击任何质疑她决定的人。      |
| The frightened animal struck out at the person approaching it. | 那只受惊的动物突然攻击了正在靠近它的人。  |

使用见解：

strike out at 带有突然、强烈和具有攻击性的意味。

在身体动作中，strike out at someone 通常表示突然向某人挥拳或出手。

在抽象语境中，它可以表示愤怒地抨击某个人或团体。

需要注意另一种结构：

strike out on your own

表示开始独立生活、工作或创业。

After years of working for others, he decided to strike out on his own.

为别人工作多年后，他决定独立创业。

这与 strike out at 的攻击含义不同。

## 七、等待、服务与警告

### 24. wait on：服侍、招待；等待

核心含义： 在餐饮和服务场景中表示为某人提供服务，也可以表示照顾、伺候某人。在美式英语中还经常表示等待某人或某个结果。

常见结构： wait on + 人 / 事情

| 常见搭配                          | 含义与使用见解       |
| ----------------------------- | ------------- |
| wait on customers             | 招待顾客          |
| wait on tables                | 在餐厅做服务员       |
| wait on someone hand and foot | 无微不至地伺候某人     |
| wait on a decision            | 等待决定，主要见于美式英语 |
| wait on the results           | 等待结果，主要见于美式英语 |

| 英文例句                                                    | 中文释义                       |
| ------------------------------------------------------- | -------------------------- |
| She waited on customers at a small restaurant.          | 她在一家小餐馆招待顾客。               |
| He worked his way through college by waiting on tables. | 他靠在餐厅当服务员赚取学费和生活费，完成了大学学业。 |
| I'm not going to wait on you hand and foot.             | 我可不会对你百般伺候。                |
| We're still waiting on a response from the client.      | 我们还在等待客户的回复。               |
| The team is waiting on the final test results.          | 团队正在等待最终测试结果。              |

使用见解：

wait on 具有两种需要区分的主要用法。

1\. 提供服务

The waiter was waiting on several tables at once.

那位服务员当时正在同时招待好几桌客人。

2\. 等待某件事

We're waiting on approval before moving forward.

我们正在等待审批通过，然后才能继续推进。

第二种用法在美式工作英语中比较常见；在英式英语中，wait for 通常更自然。

另外：

wait on someone hand and foot

表示对某人照顾得无微不至，有时也带有过度伺候的批评意味。

### 25. warn about：警告、提醒注意某种危险

核心含义： 提醒某人注意可能出现的危险、风险或不良后果。

常见结构： warn someone about + 风险 / 情况

| 常见搭配                               | 含义与使用见解          |
| ---------------------------------- | ---------------- |
| warn someone about a danger        | 提醒某人注意危险         |
| warn someone about the risks       | 警告某人注意风险         |
| warn someone about a problem       | 事先提醒某人注意问题       |
| warn someone about bad weather     | 提醒某人注意恶劣天气       |
| warn someone about doing something | 提醒某人注意做某事可能带来的问题 |

| 英文例句                                                               | 中文释义                  |
| ------------------------------------------------------------------ | --------------------- |
| I warned you about the risks.                                      | 我早就提醒过你这些风险。          |
| The doctor warned him about the dangers of smoking.                | 医生提醒他注意吸烟的危害。         |
| She warned me about the traffic before I left.                     | 我出发之前，她提醒我注意交通状况。     |
| We should warn everyone about the possible consequences.           | 我们应该提醒所有人注意可能产生的后果。   |
| I wish someone had warned me about how difficult the job would be. | 我真希望之前有人提醒过我这份工作会有多难。 |

使用见解：

warn about 强调提醒某人注意某种风险或情况。

还需要掌握 warn against 和 warn someone not to do something。

| 表达                               | 核心区别          | 例句                                                                              |
| -------------------------------- | ------------- | ------------------------------------------------------------------------------- |
| warn someone about something     | 告知或提醒可能存在的危险  | She warned me about the icy roads. 她提醒我注意道路结冰。                                  |
| warn someone against something   | 告诫某人避免某种行为或选择 | He warned me against investing all my money in one company. 他告诫我不要把全部资金投入同一家公司。 |
| warn someone not to do something | 明确警告某人不要做某事   | I warned him not to touch the machine. 我警告他不要碰那台机器。                             |
| warn someone that...             | 通过从句说明警告内容    | They warned us that the road was dangerous. 他们警告我们那条路很危险。                       |

## 八、核心易混表达总结

### 1. 道歉、责怪、原谅与感谢

| 表达            | 关注点         | 例句                                         |
| ------------- | ----------- | ------------------------------------------ |
| apologize for | 道歉的原因       | I apologized for being late. 我为迟到道歉。       |
| apologize to  | 道歉的对象       | I apologized to my teacher. 我向老师道歉。        |

## 十、介词与句子结构总结

这一组表达中，最需要注意的是介词分别连接什么成分，以及动词本身是否需要直接宾语。

### 1. 人与原因的双重结构

很多表达同时包含“人”和“事情”，但它们在句子中的位置并不相同。

| 结构                                  | 使用见解                    | 例句                                                      |
| ----------------------------------- | ----------------------- | ------------------------------------------------------- |
| apologize to someone for something  | to 连接道歉对象，for 连接原因      | I apologized to her for my mistake. 我因为自己的错误向她道歉。       |
| blame someone for something         | 直接宾语是被责怪的人              | He blamed me for the delay. 他因为延误责怪我。                   |
| blame something on someone          | 直接宾语是被归咎的事情             | He blamed the delay on me. 他把延误归咎于我。                    |
| complain to someone about something | to 连接倾诉或投诉对象，about 连接问题 | I complained to the landlord about the noise. 我向房东投诉噪音。 |
| criticize someone for something     | 直接指出受到批评的人以及原因          | She criticized him for his attitude. 她批评了他的态度。          |
| forgive someone for something       | 直接指出被原谅的人               | I forgave her for the mistake. 我原谅了她的错误。                |
| thank someone for something         | 直接指出感谢对象                | I thanked him for his advice. 我感谢他的建议。                  |
| warn someone about something        | 直接指出接受警告的人              | She warned us about the risks. 她提醒我们注意风险。               |

### 2. 介词后接动名词

下列结构都可以用来描述具体的行为。

| 表达                          | 例句                                                           |
| --------------------------- | ------------------------------------------------------------ |
| apologize for doing         | I apologized for interrupting her. 我为打断她而道歉。                 |
| complain about doing        | He complained about working overtime. 他抱怨加班。                 |
| criticize someone for doing | She criticized me for leaving early. 她批评我提前离开。               |
| forgive someone for doing   | I forgave him for forgetting my birthday. 我原谅他忘记了我的生日。       |
| thank someone for doing     | I thanked her for listening to me. 我感谢她愿意听我倾诉。               |
| put up with doing           | I can't put up with waiting for hours. 我受不了等上几个小时。           |
| warn someone about doing    | He warned me about driving in bad weather. 他提醒我注意恶劣天气下开车的风险。 |

## 十一、综合语境中的实际使用

这些动词搭配经常共同出现在完整的交流和叙事中。通过观察它们在同一段话中的关系，可以更清楚地理解词语之间的区别。

### 情境一：工作中的争执与道歉

My manager criticized me for missing the deadline, but I felt that he was blaming everything on me. I tried to reason with him, but he started shouting at me. Later, he apologized to me for losing his temper.

经理因为我错过截止日期而批评我，但我觉得他把所有责任都推给了我。我试着和他讲道理，可他却开始冲我大喊。后来，他为自己发脾气向我道了歉。

这段话包含以下关系：

- criticize someone for：针对具体错误提出批评。
- blame something on someone：将问题的责任归咎于某人。
- reason with someone：尝试通过讲道理解决争执。
- shout at someone：情绪激动时向某人喊叫。
- apologize to someone for：向对方承认行为不妥并道歉。

### 情境二：朋友之间的误会

He made fun of my accent in front of everyone. I tried to laugh it off, but I was actually quite upset. When I told him how I felt, he apologized for what he'd said. I eventually forgave him.

他当着大家的面取笑我的口音。我试着一笑置之，但其实心里很难受。后来我告诉了他自己的感受，他为说过的话道歉了。我最终原谅了他。

这里体现出几种不同的情绪表达：

- make fun of：取笑某人。
- laugh off：用笑掩饰真实的不适。
- apologize for：为行为道歉。
- forgive：选择原谅。

### 情境三：面对投诉与客户反馈

Several customers complained about the service, so the manager asked for more information. After reviewing the complaints, she thanked the customers for their feedback and warned the staff about making the same mistakes again.

几位客户投诉了服务问题，因此经理要求提供更多信息。查看投诉内容后，她感谢客户提出反馈，并提醒员工注意避免再次犯下同样的错误。

这里的几个表达具有明确的工作沟通价值：

- complain about：说明投诉的内容。
- ask for：提出信息请求。
- thank someone for：感谢他人的反馈或帮助。
- warn someone about：提醒某人注意潜在问题。

### 情境四：面对外界评价

She was constantly criticized for her decisions, but she refused to react angrily. Instead, she listened carefully to the feedback and tried to improve. When people made fun of her mistakes, she simply laughed them off.

她不断因为自己的决定受到批评，但她拒绝以愤怒回应。相反，她认真听取反馈，并努力改进。当别人取笑她的错误时，她只是笑着带过。

这里体现的是不同动词在“外界行为—个人反应”关系中的作用。

其中 react to criticism、be criticized for something 和 laugh something off 都很适合用于描述个人经历、职场沟通及人物性格。

这 25 个搭配中，apologize to/for、blame for/on、complain to/about、criticize for、forgive for 和 thank for 尤其值得结合完整句子掌握，因为它们涉及 谁对谁做了什么，以及为什么这样做。

而 laugh at、laugh about、laugh off、make fun of 及 joke about 需要重点体会语气和语境，这些表达在实际交流中经常涉及微妙的人际态度。
