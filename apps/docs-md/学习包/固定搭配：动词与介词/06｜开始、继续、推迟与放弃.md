# 动词与介词搭配：行动、参与、坚持与放弃

英语中有大量动词与介词、副词小品词组合，用来描述一个行动从准备、开始、执行到结束的不同阶段。

例如，embark on 表示开始一项新的事业或经历，get down to 强调真正开始认真处理某件事，carry on with 表示继续已经开始的事情，而 stick to 则表示坚持原有的计划、决定或原则。

当事情遇到困难时，还可以通过 keep at、give in to、give up on、hold out for 等表达区分继续努力、向压力屈服、放弃希望以及坚持等待更好条件之间的差异。

这些搭配也涉及英语中非常重要的结构特点：有些组合包含介词，有些包含副词小品词，还有一些属于可以分离的短语动词。理解这一点，有助于判断宾语的位置，以及后面应该使用名词、动名词还是不定式。

## 一、开始行动与着手处理

### 1. embark on：开始、着手从事

核心含义： 开始一项重要、长期或具有挑战性的活动，通常涉及新的计划、事业、学习或人生阶段。

常见结构： embark on + 名词 / 动名词

| 常见搭配                      | 含义与使用见解          |
| ------------------------- | ---------------- |
| embark on a journey       | 开始一段旅程，也可以表示人生旅程 |
| embark on a career        | 开始职业生涯           |
| embark on a new project   | 启动新项目            |
| embark on an adventure    | 开始冒险             |
| embark on doing something | 开始着手某项较大的行动      |

| 英文例句                                                           | 中文释义                 |
| -------------------------------------------------------------- | -------------------- |
| She embarked on a new career in software development.          | 她开始了软件开发领域的新职业生涯。    |
| We're about to embark on a challenging project.                | 我们即将启动一个具有挑战性的项目。    |
| He embarked on a journey that would change his life.           | 他踏上了一段将改变自己人生的旅程。    |
| The company embarked on an ambitious expansion programme.      | 公司启动了一项雄心勃勃的扩张计划。    |
| She embarked on writing her first novel after leaving her job. | 离职后，她开始着手创作自己的第一部小说。 |

使用见解：

embark on 通常比 start 或 begin 更正式，也更强调一项行动的重要性和长期性。

I'm starting a new project.

我准备开始一个新项目。

I'm embarking on a new project.

我即将投入一项新的重要项目。

embark on 常用于职业发展、个人成长、重大研究和长期计划。

### 2. set about：开始着手；着手处理

核心含义： 开始采取具体行动，以完成某项任务、解决问题或实现目标。

常见结构： set about + 名词 / 动名词

| 常见搭配                           | 含义与使用见解 |
| ------------------------------ | ------- |
| set about a task               | 开始处理任务  |
| set about solving a problem    | 着手解决问题  |
| set about doing something      | 开始着手做某事 |
| set about organising something | 着手组织某事  |
| set about repairing something  | 开始修理某物  |

| 英文例句                                              | 中文释义             |
| ------------------------------------------------- | ---------------- |
| How should we set about solving this problem?     | 我们应该怎样着手解决这个问题？  |
| She immediately set about cleaning the house.     | 她立刻开始打扫房子。       |
| He set about gathering the information he needed. | 他开始收集自己需要的信息。    |
| We need to set about improving the system.        | 我们需要开始着手改进系统。    |
| They set about the task with great enthusiasm.    | 他们满怀热情地开始执行这项任务。 |

使用见解：

set about 强调着手采取实际行动，常常包含“准备怎么做、开始做起来”的意味。

How do I set about doing this?

我该怎么着手做这件事？

这是非常实用的句型。

注意 set about 中的 about 是介词，后面使用动名词：

set about fixing the problem

着手修复问题。

### 3. get down to：开始认真处理

核心含义： 结束闲聊、准备或拖延，开始集中精力处理真正需要完成的事情。

常见结构： get down to + 名词 / 动名词

| 常见搭配                        | 含义与使用见解   |
| --------------------------- | --------- |
| get down to work            | 开始认真工作    |
| get down to business        | 开始谈正事     |
| get down to studying        | 开始认真学习    |
| get down to the details     | 开始讨论具体细节  |
| get down to doing something | 真正开始着手做某事 |

| 英文例句                                                                           | 中文释义                  |
| ------------------------------------------------------------------------------ | --------------------- |
| Let's get down to business.                                                    | 我们开始谈正事吧。             |
| I need to get down to work.                                                    | 我得开始认真工作了。            |
| After chatting for a while, we finally got down to discussing the problem.     | 聊了一会儿之后，我们终于开始认真讨论问题。 |
| I've been putting it off, but I really need to get down to writing the report. | 我一直拖着没做，但现在真的得开始写报告了。 |
| Once everyone arrived, we got down to planning the event.                      | 所有人到齐后，我们开始认真筹划活动。    |

使用见解：

get down to 通常暗示之前已经花了一些时间在其他事情上，现在终于进入主要任务。

I really need to get down to it.

我真的得开始认真干了。

其中 to 是介词：

get down to writing

开始认真写作。

### 4. enter into：开始参与；达成某种关系或协议

核心含义： 开始参与某项活动、讨论或法律关系，尤其常见于协议、谈判和正式安排。

常见结构： enter into + 协议 / 讨论 / 关系

| 常见搭配                     | 含义与使用见解 |
| ------------------------ | ------- |
| enter into an agreement  | 达成协议    |
| enter into a contract    | 签订合同    |
| enter into negotiations  | 开始谈判    |
| enter into a discussion  | 开始参与讨论  |
| enter into a partnership | 建立合作关系  |

| 英文例句                                                            | 中文释义               |
| --------------------------------------------------------------- | ------------------ |
| The two companies entered into a partnership.                   | 两家公司建立了合作关系。       |
| We shouldn't enter into an agreement without reading the terms. | 在阅读条款之前，我们不应该签订协议。 |
| They entered into negotiations with the supplier.               | 他们开始与供应商进行谈判。      |
| I'm not willing to enter into an argument about this.           | 我不愿意就这件事展开争论。      |
| The parties entered into a legally binding contract.            | 双方签订了一份具有法律约束力的合同。 |

使用见解：

enter into 具有较强的正式语感。

在表示加入某种讨论或关系时，enter into 强调参与或建立的过程。

注意 enter 可以直接接地点：

She entered the room.

她走进了房间。

这里不需要 into。

### 5. engage in：参与、从事

核心含义： 积极参与某种活动、工作、讨论或行为，常见于正式表达和书面语。

常见结构： engage in + 名词 / 动名词

| 常见搭配                         | 含义与使用见解 |
| ---------------------------- | ------- |
| engage in discussion         | 参与讨论    |
| engage in research           | 从事研究    |
| engage in physical activity  | 进行体育活动  |
| engage in illegal activities | 从事非法活动  |
| engage in doing something    | 参与某种行为  |

| 英文例句                                                             | 中文释义             |
| ---------------------------------------------------------------- | ---------------- |
| Students are encouraged to engage in classroom discussions.      | 学生受到鼓励积极参与课堂讨论。  |
| The company is engaged in medical research.                      | 这家公司从事医学研究。      |
| He refused to engage in the argument.                            | 他拒绝参与争论。         |
| Regularly engaging in physical activity can improve your health. | 经常参加体育活动有助于改善健康。 |
| She enjoys engaging in conversations about philosophy.           | 她喜欢参与有关哲学的讨论。    |

使用见解：

engage in 经常用于描述正式活动、专业工作或行为。

与 participate in 相比，engage in 往往强调实际投入和参与程度。

engage in research

从事研究。

participate in a research project

参与某个研究项目。

## 二、参与活动与加入群体

### 6. participate in：参与、参加

核心含义： 作为参与者加入某项活动、会议、比赛或计划。

常见结构： participate in + 活动 / 事件

| 常见搭配                         | 含义与使用见解 |
| ---------------------------- | ------- |
| participate in a meeting     | 参加会议    |
| participate in a competition | 参加比赛    |
| participate in a discussion  | 参与讨论    |
| participate in an event      | 参加活动    |
| participate in a project     | 参与项目    |

| 英文例句                                                     | 中文释义         |
| -------------------------------------------------------- | ------------ |
| Everyone is encouraged to participate in the discussion. | 鼓励每个人参与讨论。   |
| She participated in an international competition.        | 她参加了一场国际比赛。  |
| I'd like to participate in the project.                  | 我想参与这个项目。    |
| Over a hundred students participated in the survey.      | 一百多名学生参与了调查。 |
| He rarely participates in group activities.              | 他很少参加集体活动。   |

使用见解：

participate in 语气比较正式，适用于学校、工作、活动和研究。

I participated in the meeting.

我参加了会议。

它比 join in 更适合正式文档。

### 7. take part in：参加、参与

核心含义： 加入某项活动并实际参与其中，日常英语和书面语都很常见。

常见结构： take part in + 活动

| 常见搭配                            | 含义与使用见解 |
| ------------------------------- | ------- |
| take part in a competition      | 参加比赛    |
| take part in an event           | 参加活动    |
| take part in a discussion       | 参与讨论    |
| take part in a survey           | 参加调查    |
| take part in a training session | 参加培训    |

| 英文例句                                                                 | 中文释义           |
| -------------------------------------------------------------------- | -------------- |
| I took part in a local writing competition.                          | 我参加了一场当地的写作比赛。 |
| Everyone should have the opportunity to take part in the discussion. | 每个人都应该有机会参与讨论。 |
| She took part in several volunteer activities.                       | 她参加了几次志愿活动。    |
| More than fifty people took part in the experiment.                  | 五十多人参与了这项实验。   |

使用见解：

take part in 与 participate in 基本可以互换，但 take part in 更适合自然、简洁的日常表达。

I'd love to take part.

我很乐意参加。

take part 可以在活动对象已经明确时独立使用。

### 8. join in on：加入某项正在进行的活动

核心含义： 加入别人已经开始的活动、对话或共同经历，常带有临时参与的意味。

常见结构： join in on + 活动 / 对话

| 常见搭配                       | 含义与使用见解   |
| -------------------------- | --------- |
| join in on a conversation  | 加入谈话      |
| join in on the fun         | 一起参与有趣的活动 |
| join in on a game          | 加入游戏      |
| join in on the discussion  | 加入讨论      |
| join in on the celebration | 加入庆祝活动    |

| 英文例句                                                       | 中文释义             |
| ---------------------------------------------------------- | ---------------- |
| Can I join in on the conversation?                         | 我能加入你们的谈话吗？      |
| Everyone was laughing, so I decided to join in on the fun. | 大家都在笑，于是我决定一起加入。 |
| She joined in on the discussion halfway through.           | 她在讨论进行到一半时加入了进来。 |
| Feel free to join in on the game.                          | 想玩的话随时加入。        |

使用见解：

join in on 带有口语色彩，尤其常见于美式英语。

更简洁且广泛使用的结构是：

join in

加入正在进行的活动。

Can I join in?

我可以一起参加吗？

### participate in / take part in / join in on / engage in 辨析

| 表达             | 主要语感        | 例句                                              |
| -------------- | ----------- | ----------------------------------------------- |
| participate in | 正式参与某项活动    | She participated in the study. 她参与了研究。          |
| take part in   | 自然地表达参加活动   | He took part in the race. 他参加了比赛。               |
| join in on     | 加入正在进行的活动   | Can I join in on the discussion? 我能加入讨论吗？       |
| engage in      | 强调投入某种活动或行为 | They engaged in a long discussion. 他们进行了长时间的讨论。 |

### 9. sign up for：报名、注册参加

核心含义： 正式登记参加某项课程、活动、服务或计划。

常见结构： sign up for + 课程 / 活动 / 服务

| 常见搭配                      | 含义与使用见解 |
| ------------------------- | ------- |
| sign up for a course      | 报名课程    |
| sign up for a competition | 报名比赛    |
| sign up for a newsletter  | 订阅电子简报  |
| sign up for a membership  | 注册会员    |
| sign up for a free trial  | 注册免费试用  |

| 英文例句                                                     | 中文释义               |
| -------------------------------------------------------- | ------------------ |
| I signed up for an English course.                       | 我报名了一门英语课程。        |
| Have you signed up for the event yet?                    | 你报名参加活动了吗？         |
| She signed up for a free trial of the service.           | 她注册了这项服务的免费试用。     |
| You need to sign up for an account before using the app. | 使用这个应用之前，你需要先注册账号。 |
| I wasn't sure whether to sign up for the workshop.       | 我不确定要不要报名参加这个工作坊。  |

使用见解：

sign up for 强调登记参加某项活动或服务。

相关结构：

sign up to do something

报名或同意去做某事。

I signed up to help organise the event.

我报名帮忙组织活动。

## 三、继续行动与保持进展

### 10. carry on with：继续做某事

核心含义： 在中断、干扰或发生某种情况之后，继续原来正在进行的事情。

常见结构： carry on with + 名词 / 动名词

| 常见搭配                          | 含义与使用见解 |
| ----------------------------- | ------- |
| carry on with work            | 继续工作    |
| carry on with a project       | 继续项目    |
| carry on with a task          | 继续任务    |
| carry on with life            | 继续生活    |
| carry on with doing something | 继续做某事   |

| 英文例句                                                        | 中文释义                |
| ----------------------------------------------------------- | ------------------- |
| Let's carry on with the meeting.                            | 我们继续开会吧。            |
| She decided to carry on with her studies.                   | 她决定继续学业。            |
| Despite the difficulties, they carried on with the project. | 尽管遇到了困难，他们仍然继续推进项目。 |
| I need to carry on with what I was doing.                   | 我得继续做刚才的事情。         |
| Life goes on, and we have to carry on with it.              | 生活还在继续，我们也得继续走下去。   |

使用见解：

carry on 在英式英语中非常常见。

Carry on.

继续吧。

Carry on with your work.

继续你的工作。

另外还可以使用：

carry on doing something

继续做某事。

He carried on talking as if nothing had happened.

他继续说着话，仿佛什么都没发生过。

### 11. get on with：继续做；与某人相处

核心含义： 可以表示继续处理某项任务，也可以表示与某人相处融洽。

常见结构： get on with + 任务 / 人

| 常见搭配                     | 含义与使用见解 |
| ------------------------ | ------- |
| get on with work         | 继续工作    |
| get on with a task       | 继续处理任务  |
| get on with your life    | 继续自己的生活 |
| get on with someone      | 与某人相处   |
| get on well with someone | 与某人相处融洽 |

| 英文例句                                     | 中文释义         |
| ---------------------------------------- | ------------ |
| I need to get on with my work.           | 我得继续工作了。     |
| Stop talking and get on with it.         | 别聊了，赶紧继续做吧。  |
| She gets on well with her colleagues.    | 她和同事相处得很好。   |
| It's time to get on with your life.      | 是时候继续自己的生活了。 |
| How are you getting on with the project? | 你的项目进展得怎么样？  |

使用见解：

get on with 在英式英语中非常高频。

Get on with it!

赶紧继续做吧！

这句话在某些语境下可能显得不耐烦，需要注意语气。

### 12. go on with：继续进行某事

核心含义： 在某件事情正在进行或曾经中断的情况下，继续原来的活动。

常见结构： go on with + 名词 / 动名词

| 常见搭配                   | 含义与使用见解 |
| ---------------------- | ------- |
| go on with a task      | 继续任务    |
| go on with the meeting | 继续会议    |
| go on with the story   | 继续讲故事   |
| go on with the work    | 继续工作    |
| go on with life        | 继续生活    |

| 英文例句                                                    | 中文释义              |
| ------------------------------------------------------- | ----------------- |
| Please go on with your story.                           | 请继续讲你的故事。         |
| They went on with the meeting despite the interruption. | 尽管受到打断，他们仍继续开会。   |
| She tried to go on with her life after the accident.    | 事故发生后，她努力继续自己的生活。 |
| We decided to go on with the plan.                      | 我们决定继续执行计划。       |

使用见解：

go on with 与 carry on with 接近，都可以表示继续已经开始的事情。

但 go on with 在部分日常语境中不如 carry on with 或 get on with 常见。

### 13. keep at：坚持不懈地做

核心含义： 即使某项任务困难、枯燥或需要很长时间，也继续努力。

常见结构： keep at + 名词 / it

| 常见搭配                 | 含义与使用见解      |
| -------------------- | ------------ |
| keep at it           | 坚持下去         |
| keep at a task       | 坚持完成任务       |
| keep at your studies | 持续努力学习       |
| keep at something    | 坚持做某事        |
| keep at someone      | 不断催促某人，另一种用法 |

| 英文例句                                                       | 中文释义                |
| ---------------------------------------------------------- | ------------------- |
| Keep at it. You're making progress.                        | 坚持下去，你正在取得进步。       |
| If you keep at it, you'll eventually get better.           | 如果你坚持下去，最终会有所进步。    |
| She kept at the problem until she found a solution.        | 她一直努力解决这个问题，直到找到办法。 |
| Learning a language takes time, so you have to keep at it. | 学习语言需要时间，因此你必须持续努力。 |
| He kept at his studies despite working full-time.          | 尽管全职工作，他仍坚持学习。      |

使用见解：

keep at it 是非常值得掌握的高频表达。

Just keep at it.

继续坚持就好。

它通常强调持续努力和面对困难时的坚持。

### 14. stick to：坚持、遵守

核心含义： 坚持某项计划、原则、决定或方法，不轻易改变。

常见结构： stick to + 名词 / 动名词

| 常见搭配                     | 含义与使用见解  |
| ------------------------ | -------- |
| stick to a plan          | 坚持计划     |
| stick to a schedule      | 遵守日程     |
| stick to the rules       | 遵守规则     |
| stick to your principles | 坚持原则     |
| stick to doing something | 继续采用某种做法 |

| 英文例句                                                      | 中文释义              |
| --------------------------------------------------------- | ----------------- |
| We should stick to the original plan.                     | 我们应该坚持原来的计划。      |
| I find it difficult to stick to a strict schedule.        | 我发现自己很难坚持严格的日程安排。 |
| She always sticks to her principles.                      | 她始终坚持自己的原则。       |
| Let's stick to the topic.                                 | 我们还是围绕这个话题讨论吧。    |
| I've decided to stick to learning one language at a time. | 我决定坚持一次只学习一门语言。   |

使用见解：

stick to 强调保持既定方向、标准或选择。

注意：

stick to doing something

坚持采用某种做法。

其中 to 是介词，后接动名词。

### 15. keep up with：跟上；保持同步

核心含义： 跟上某个人、事物或变化的速度，不落后于当前进度。

常见结构： keep up with + 人 / 变化 / 进度

| 常见搭配                      | 含义与使用见解 |
| ------------------------- | ------- |
| keep up with someone      | 跟上某人    |
| keep up with the pace     | 跟上节奏    |
| keep up with technology   | 跟上技术发展  |
| keep up with the news     | 持续关注新闻  |
| keep up with the workload | 跟上工作量   |

| 英文例句                                                   | 中文释义              |
| ------------------------------------------------------ | ----------------- |
| It's difficult to keep up with new technology.         | 很难跟上新技术的发展。       |
| I can't keep up with the workload.                     | 我已经跟不上工作量了。       |
| She walks so fast that I can barely keep up with her.  | 她走得太快了，我几乎跟不上。    |
| I try to keep up with the latest developments in AI.   | 我努力关注人工智能领域的最新进展。 |
| He's struggling to keep up with the rest of the class. | 他正在努力跟上班里其他同学的进度。 |

使用见解：

keep up with 强调外部进度，而 keep at 强调自己持续努力。

比较：

Keep at it.

坚持努力。

Keep up with the class.

跟上班级进度。

### 16. catch up on：补做、补看、补充了解

核心含义： 处理之前没有完成、没有关注或错过的事情，使自己重新跟上应有的进度。

常见结构： catch up on + 事情

| 常见搭配                 | 含义与使用见解 |
| -------------------- | ------- |
| catch up on work     | 补做工作    |
| catch up on sleep    | 补觉      |
| catch up on reading  | 补阅读进度   |
| catch up on the news | 补看新闻    |
| catch up on emails   | 处理积压邮件  |

| 英文例句                                               | 中文释义           |
| -------------------------------------------------- | -------------- |
| I need to catch up on some work this weekend.      | 这个周末我需要补做一些工作。 |
| I'm trying to catch up on sleep.                   | 我正在努力补觉。       |
| I spent the evening catching up on emails.         | 我花了一晚上处理积压的邮件。 |
| I haven't had time to catch up on the latest news. | 我一直没时间补看最近的新闻。 |
| She stayed home to catch up on her reading.        | 她待在家里补阅读进度。    |

使用见解：

catch up on 强调弥补之前落下的事情。

I have a lot to catch up on.

我有很多事情需要补上。

这是非常自然的日常表达。

### 17. catch up with：赶上；了解近况

核心含义： 赶上某人或某个进度，也可以表示与一段时间没见的人联系，了解彼此近况。

常见结构： catch up with + 人 / 进度

| 常见搭配                          | 含义与使用见解    |
| ----------------------------- | ---------- |
| catch up with someone         | 赶上某人；与某人叙旧 |
| catch up with classmates      | 赶上同学的进度    |
| catch up with a friend        | 与朋友聊近况     |
| catch up with the competition | 赶上竞争对手     |
| catch up with someone later   | 稍后再联系或见面   |

| 英文例句                                                        | 中文释义          |
| ----------------------------------------------------------- | ------------- |
| I need to catch up with my classmates.                      | 我需要赶上同学们的进度。  |
| It was great catching up with you.                          | 和你聊近况真开心。     |
| Let's catch up sometime next week.                          | 我们下周找个时间聊聊吧。  |
| The company is struggling to catch up with its competitors. | 公司正在努力追赶竞争对手。 |
| I'll catch up with you later.                               | 我稍后再找你聊。      |

使用见解：

catch up on 与 catch up with 的区别：

| 表达            | 核心区别       | 例句                                            |
| ------------- | ---------- | --------------------------------------------- |
| catch up on   | 补做落下的事情    | I need to catch up on work. 我得补做工作。           |
| catch up with | 赶上某人；与某人叙旧 | I caught up with an old friend. 我和一位老朋友聊了聊近况。 |
| keep up with  | 持续跟上进度     | I can't keep up with the pace. 我跟不上节奏。        |

## 四、推迟、取消与暂缓行动

### 18. call off：取消

核心含义： 决定不再举行原本已经安排的活动、会议、比赛或行动。

常见结构： call off + 活动 / 计划

| 常见搭配                  | 含义与使用见解 |
| --------------------- | ------- |
| call off a meeting    | 取消会议    |
| call off a trip       | 取消旅行    |
| call off a wedding    | 取消婚礼    |
| call off negotiations | 终止谈判    |
| call something off    | 取消某事    |

| 英文例句                                             | 中文释义          |
| ------------------------------------------------ | ------------- |
| They called off the meeting at the last minute.  | 他们在最后一刻取消了会议。 |
| The match was called off because of the weather. | 比赛因为天气原因被取消了。 |
| We may have to call off the trip.                | 我们可能不得不取消旅行。  |
| She decided to call off the wedding.             | 她决定取消婚礼。      |
| Let's call it off.                               | 我们取消吧。        |

使用见解：

call off 强调取消已经安排好的事情。

它是可分离短语动词：

call it off

取消它。

注意与 put off 的区别：

- call off：取消。
- put off：推迟。

### 19. put off for：推迟一段时间

核心含义： 将原本计划进行的事情推迟，for 后用于说明延迟的时间长度。

常见结构： put something off for + 时间段

| 常见搭配                             | 含义与使用见解 |
| -------------------------------- | ------- |
| put something off for a week     | 推迟一周    |
| put something off for a few days | 推迟几天    |
| put off a meeting                | 推迟会议    |
| put off making a decision        | 推迟作决定   |
| put something off until Monday   | 推迟到星期一  |

| 英文例句                                                          | 中文释义              |
| ------------------------------------------------------------- | ----------------- |
| We decided to put the meeting off for another week.           | 我们决定把会议再推迟一周。     |
| I've been putting off this task for days.                     | 我已经拖了好几天没做这个任务。   |
| She put off making a decision until she had more information. | 她推迟作决定，直到获得更多信息。  |
| Can we put it off until tomorrow?                             | 我们能把它推迟到明天吗？      |
| I kept putting it off because I didn't know where to start.   | 我一直拖着，因为不知道从哪里开始。 |

使用见解：

put off 是一个完整的短语动词，for 通常进一步说明推迟的时长。

更常见的表达包括：

put something off until...

将某件事推迟到某个时间。

put off doing something

拖延做某事。

### 20. hold off on：暂缓、先不做

核心含义： 暂时推迟某个决定或行动，通常是为了等待更多信息、合适的时机或条件变化。

常见结构： hold off on + 名词 / 动名词

| 常见搭配                             | 含义与使用见解 |
| -------------------------------- | ------- |
| hold off on a decision           | 暂缓决定    |
| hold off on buying something     | 暂时不购买   |
| hold off on making changes       | 暂缓修改    |
| hold off on announcing something | 推迟宣布    |
| hold off on starting a project   | 暂缓启动项目  |

| 英文例句                                                                  | 中文释义                |
| --------------------------------------------------------------------- | ------------------- |
| Let's hold off on making a decision.                                  | 我们先别急着作决定。          |
| I'm going to hold off on buying a new laptop.                         | 我打算暂时不买新笔记本电脑。      |
| We should hold off on the announcement until everything is confirmed. | 在一切确认之前，我们应该暂缓发布公告。 |
| The company decided to hold off on hiring new employees.              | 公司决定暂缓招聘新员工。        |
| I'd hold off on making any major changes for now.                     | 我建议目前先不要作出重大调整。     |

使用见解：

hold off on 常见于美式英语，特别适合讨论计划、消费和工作决策。

Let's hold off on that for now.

这件事我们先缓一缓。

和 put off 相比，hold off on 往往强调有意识地暂时等待。

### 21. slow down on：减少、放慢某项活动

核心含义： 减少某种行为的频率、数量或投入。这个组合可以理解，但在许多日常语境中，cut down on 更常用于表示减少消耗，slow down with 或 slow down on 则更偏向放缓活动。

常见结构： slow down on + 活动 / 行为

| 常见搭配                      | 含义与使用见解       |
| ------------------------- | ------------- |
| slow down on spending     | 放慢消费节奏        |
| slow down on new projects | 减缓新项目的推进      |
| slow down on hiring       | 放慢招聘速度        |
| cut down on sugar         | 减少糖的摄入，更常见的表达 |
| slow down                 | 放慢速度，可独立使用    |

| 英文例句                                                       | 中文释义                |
| ---------------------------------------------------------- | ------------------- |
| We need to slow down on new projects for a while.          | 我们需要暂时放缓新项目的推进。     |
| The company is slowing down on hiring.                     | 公司正在放慢招聘速度。         |
| You should slow down and take a break.                     | 你应该放慢节奏，休息一下。       |
| I'm trying to cut down on unnecessary spending.            | 我正在努力减少不必要的开支。      |
| He decided to slow down at work after years of long hours. | 长期高强度工作后，他决定放慢工作节奏。 |

使用见解：

slow down on 作为整体搭配的固定程度较低。

如果表达减少某种消耗，优先使用：

cut down on something

减少某物的使用或摄入。

I'm trying to cut down on coffee.

我正在努力少喝咖啡。

## 五、坚持、等待与保留

### 22. hold on to：抓住；保留；坚持

核心含义： 紧紧抓住某物，或继续保留某个物品、机会、信念或感情。

常见结构： hold on to + 名词

| 常见搭配                          | 含义与使用见解  |

Hold on to it.

抓紧它；把它留着。

### 23. hold out for：坚持等待更好的条件

核心含义： 拒绝接受当前条件，坚持等待更好的报价、机会或结果。

常见结构： hold out for + 目标 / 条件

| 常见搭配                              | 含义与使用见解   |
| --------------------------------- | --------- |
| hold out for a better offer       | 坚持等待更好的报价 |

hold out for 强调在当前条件不理想时保持立场、继续等待。

与 settle for 形成对比：

settle for less

接受较低条件。

hold out for more

坚持争取更好的条件。

### 24. keep back from：阻止靠近；使远离

核心含义： 让某个人或某个群体与危险、地点或对象保持距离。

常见结构： keep someone back from + 地点 / 对象

使用见解：

keep back from 作为连续结构，通常涉及空间距离和阻止靠近。

更常见的是：

Keep back!

退后！

Keep away from the edge.

远离边缘。

| keep yourself from doing something | 克制自己不做某事 |

| I couldn't keep from thinking about what had happened. | 我忍不住一直想着发生过的事情。 |

使用见解：

keep from 非常适合描述阻止行为或克制冲动。

还可以表示隐瞒：

keep something from someone

对某人隐瞒某事。

He kept the truth from his family.

他向家人隐瞒了真相。

## 六、放弃、屈服与退出

### 26. give in to：屈服于、让步于

核心含义： 在压力、诱惑、要求或情绪影响下放弃原来的抵抗或坚持。

常见结构： give in to + 压力 / 诱惑 / 要求

| 常见搭配                        | 含义与使用见解 |
| --------------------------- | ------- |
| give in to pressure         | 向压力屈服   |
| give in to temptation       | 经不住诱惑   |
| give in to demands          | 对要求作出让步 |
| give in to fear             | 向恐惧屈服   |
| give in to someone's wishes | 顺从某人的意愿 |

| 英文例句                                                 | 中文释义              |
| ---------------------------------------------------- | ----------------- |
| He refused to give in to pressure.                   | 他拒绝向压力屈服。         |
| I finally gave in to temptation and bought the book. | 我最终没抵挡住诱惑，买下了那本书。 |
| She wouldn't give in to their demands.               | 她不愿向他们的要求让步。      |
| Don't give in to fear.                               | 不要向恐惧屈服。          |
| After hours of arguing, he eventually gave in.       | 争论了几个小时后，他最终让步了。  |

使用见解：

give in 可以独立使用：

I give in.

我认输了；我让步了。

give in to 则明确指出屈服的对象。

### 27. give up on：对……放弃希望

核心含义： 因为长期失败、困难或失望，而不再相信某个人、目标或事情能够成功。

常见结构： give up on + 人 / 目标 / 事情

| 常见搭配                      | 含义与使用见解  |
| ------------------------- | -------- |
| give up on someone        | 对某人失去希望  |
| give up on a dream        | 放弃梦想     |
| give up on a project      | 放弃项目     |
| give up on a relationship | 放弃一段关系   |
| never give up on yourself | 永远不要放弃自己 |

| 英文例句                                                   | 中文释义               |
| ------------------------------------------------------ | ------------------ |
| Don't give up on yourself.                             | 不要放弃自己。            |
| She never gave up on her dream of becoming a writer.   | 她从未放弃成为作家的梦想。      |
| I'm not ready to give up on this project.              | 我还没有准备好放弃这个项目。     |
| He eventually gave up on trying to change her mind.    | 他最终放弃了说服她改变主意的努力。  |
| Sometimes people give up on relationships too quickly. | 有时候，人们过于轻易地放弃一段关系。 |

使用见解：

give up on 往往带有失去信心或希望的意味。

比较：

I gave up smoking.

我戒烟了。

I gave up on becoming a musician.

我放弃了成为音乐家的梦想。

give up doing 表示停止某种行为，give up on 则常表示不再继续追求某个目标。

### 28. bow out of：退出；主动让位

核心含义： 礼貌、主动或有意识地退出某项活动、竞争或职责。

常见结构： bow out of + 活动 / 竞争 / 职位

| 常见搭配                     | 含义与使用见解 |
| ------------------------ | ------- |
| bow out of a competition | 退出比赛    |
| bow out of a race        | 退出竞选或竞争 |
| bow out of a project     | 退出项目    |
| bow out of a discussion  | 退出讨论    |
| bow out gracefully       | 体面退出    |

| 英文例句                                                         | 中文释义             |
| ------------------------------------------------------------ | ---------------- |
| He decided to bow out of the competition.                    | 他决定退出比赛。         |
| She bowed out of the race for personal reasons.              | 她因为个人原因退出了竞选。    |
| I think it's time for me to bow out of the project.          | 我觉得是时候退出这个项目了。   |
| He chose to bow out gracefully rather than continue arguing. | 他选择体面退出，而不是继续争论。 |

使用见解：

bow out of 比 quit 更委婉，常带有有意识地退出或让位的意味。

I'll bow out of this one.

这次我就不参加了。

这种说法可以用于轻松、礼貌地拒绝参与。

### 29. let go of：松开；放下

核心含义： 松开实际抓住的东西，或者放下过去的情绪、执念和无法改变的事情。

常见结构： let go of + 人 / 物品 / 情绪

| 常见搭配                     | 含义与使用见解      |
| ------------------------ | ------------ |
| let go of someone's hand | 松开某人的手       |
| let go of the past       | 放下过去         |
| let go of anger          | 放下愤怒         |
| let go of expectations   | 放下期待         |
| let go of something      | 放开某物；不再执着于某事 |

| 英文例句                                                          | 中文释义                  |
| ------------------------------------------------------------- | --------------------- |
| Don't let go of my hand.                                      | 别松开我的手。               |
| It's time to let go of the past.                              | 是时候放下过去了。             |
| She struggled to let go of her anger.                         | 她很难放下心中的愤怒。           |
| Sometimes you have to let go of things you can't control.     | 有时候，你必须放下那些自己无法控制的事情。 |
| He finally learned to let go of his unrealistic expectations. | 他最终学会了放下不切实际的期待。      |

使用见解：

let go of 是非常常见的具象与抽象双重表达。

Let it go.

放手吧；别再纠结了。

Let go of it.

把它松开；放下它。

这两种结构都可以使用，具体取决于语境。

### give in to / give up on / bow out of / let go of 辨析

| 表达         | 核心区别        | 例句                                    |
| ---------- | ----------- | ------------------------------------- |
| give in to | 向压力、诱惑或要求屈服 | He gave in to pressure. 他向压力屈服了。      |
| give up on | 对人或目标放弃希望   | She gave up on the project. 她放弃了这个项目。 |
| bow out of | 有意识地退出活动或竞争 | He bowed out of the race. 他退出了竞选。     |
| let go of  | 松开；在心理上放下   | She let go of her anger. 她放下了愤怒。      |

## 七、行动选择与机会

核心含义： 即使存在顾虑、困难或不同意见，仍然决定执行某个计划。

常见结构： go ahead with + 计划 / 行动

| 常见搭配                       | 含义与使用见解 |
| -------------------------- | ------- |
| go ahead with a plan       | 按计划进行   |
| go ahead with a project    | 推进项目    |
| go ahead with a decision   | 执行决定    |
| go ahead with the meeting  | 照常举行会议  |
| go ahead with the purchase | 继续购买    |

| 英文例句                                                       | 中文释义                |
| ---------------------------------------------------------- | ------------------- |
| We decided to go ahead with the project.                   | 我们决定继续推进项目。         |
| Despite the risks, they went ahead with the plan.          | 尽管存在风险，他们仍然执行了计划。   |
| Are we still going ahead with the meeting?                 | 我们还会照常开会吗？          |
| She decided to go ahead with the surgery.                  | 她决定接受手术。            |
| I'm not sure whether we should go ahead with the purchase. | 我不确定我们是否应该继续这项购买计划。 |

使用见解：

go ahead with 常强调在考虑之后，决定仍然继续执行。

Go ahead.

继续吧；请便。

但 go ahead with 后必须接具体的计划或行动对象。

### 31. pass up on：放弃、错过机会

核心含义： 决定不接受某个机会、建议或选择。

常见结构： pass up + 机会 / pass up on + 机会

| 常见搭配                      | 含义与使用见解    |
| ------------------------- | ---------- |
| pass up an opportunity    | 放弃机会，更常见   |
| pass up a chance          | 错过机会       |
| pass up an offer          | 拒绝报价或提议    |
| pass up on an opportunity | 放弃机会，口语中可见 |
| too good to pass up       | 好得让人不愿错过   |

| 英文例句                                                           | 中文释义                    |
| -------------------------------------------------------------- | ----------------------- |
| I couldn't pass up the opportunity.                            | 我不能错过这个机会。              |
| She passed up a better-paying job to stay close to her family. | 她为了留在家人身边，放弃了一份薪水更高的工作。 |
| It's an offer that's hard to pass up.                          | 这是一个很难拒绝的提议。            |
| He decided to pass up on the chance to move abroad.            | 他决定放弃出国发展的机会。           |
| You might regret passing up such a good opportunity.           | 你可能会后悔错过这么好的机会。         |

使用见解：

在标准书面英语中，pass up something 通常更简洁、更常见。

pass up on 也可以在非正式使用中见到，但建议优先掌握 pass up an opportunity。

### 32. stop short of：没有做到某种程度；避免采取某项行动

核心含义： 已经接近某种行为、判断或结果，但最终没有达到或采取那一步。

常见结构： stop short of + 名词 / 动名词

| 常见搭配                              | 含义与使用见解     |
| --------------------------------- | ----------- |
| stop short of doing something     | 没有真正做某事     |
| stop short of admitting something | 没有明确承认      |
| stop short of making a decision   | 没有最终作决定     |
| stop short of accusing someone    | 没有直接指控某人    |
| stop short of a complete ban      | 没有达到全面禁止的程度 |

| 英文例句                                                                           | 中文释义                    |
| ------------------------------------------------------------------------------ | ----------------------- |
| He stopped short of admitting that he was wrong.                               | 他始终没有明确承认自己错了。          |
| The report criticised the company but stopped short of accusing it of fraud.   | 报告批评了公司，但没有直接指控其欺诈。     |
| She stopped short of saying that the plan had failed.                          | 她没有明确说这个计划已经失败。         |
| The government stopped short of introducing a complete ban.                    | 政府最终没有实施全面禁令。           |
| I agree with some of his points, but I stop short of accepting his conclusion. | 我同意他的部分观点，但还无法完全接受他的结论。 |

使用见解：

stop short of 在新闻报道、正式评论和分析文章中比较常见。

它适合表达立场上的界限：

I wouldn't go so far as to say that.

我还不至于这么说。

这是日常英语中表达相近意思的一种方式。

## 八、不同语境中的特殊表达

### 33. burst into：突然进入；突然爆发

核心含义： 突然进入某个地方，或突然开始某种强烈的情绪表达或动作。

常见结构： burst into + 名词

| 常见搭配                | 含义与使用见解 |
| ------------------- | ------- |
| burst into tears    | 突然哭起来   |
| burst into laughter | 突然大笑    |
| burst into a room   | 突然冲进房间  |
| burst into flames   | 突然燃烧起来  |
| burst into song     | 突然唱起歌来  |

| 英文例句                                          | 中文释义             |
| --------------------------------------------- | ---------------- |
| She burst into tears when she heard the news. | 听到这个消息时，她突然哭了起来。 |
| Everyone burst into laughter.                 | 所有人突然大笑起来。       |
| He burst into the room without knocking.      | 他没有敲门就突然冲进了房间。   |
| The car burst into flames after the crash.    | 汽车在撞击后突然起火。      |
| The children suddenly burst into song.        | 孩子们突然唱起歌来。       |

使用见解：

burst into 非常适合叙事，因为它能够表达动作或情绪的突然发生。

burst into tears

突然哭起来。

burst out laughing

突然大笑起来。

注意 burst into 后通常接名词，而 burst out 后可以接动名词：

She burst out crying.

她突然哭了起来。

### 34. dabble in：浅尝、涉猎

核心含义： 对某个领域或活动有一定兴趣并尝试参与，但投入程度通常有限。

常见结构： dabble in + 领域 / 活动

| 常见搭配                        | 含义与使用见解  |
| --------------------------- | -------- |
| dabble in painting          | 涉猎绘画     |
| dabble in programming       | 略微接触编程   |
| dabble in writing           | 尝试写作     |
| dabble in investing         | 小规模尝试投资  |
| dabble in different hobbies | 广泛尝试不同爱好 |

| 英文例句                                                      | 中文释义                   |
| --------------------------------------------------------- | ---------------------- |
| I used to dabble in photography.                          | 我以前稍微玩过摄影。             |
| She's dabbled in writing fiction.                         | 她曾经尝试写过小说。             |
| He dabbles in several programming languages.              | 他接触过几种编程语言，但没有特别深入。    |
| I've been dabbling in digital art recently.               | 我最近在尝试数字绘画。            |
| She dabbled in investing before taking it more seriously. | 在认真研究投资之前，她只是浅尝辄止地接触过。 |

使用见解：

dabble in 强调涉猎、尝试，往往暗示没有长期深入投入。

I've dabbled in it a little.

我稍微接触过一点。

适合表达自己对某个兴趣或领域有初步经验。

### 35. play at：假装做；不认真对待

核心含义： 表示假装从事某种活动，或者对本应认真对待的事情采取不够认真的态度。

常见结构： play at + 名词 / 动名词

| 常见搭配                     | 含义与使用见解      |
| ------------------------ | ------------ |
| play at being someone    | 假装扮演某种身份     |
| play at working          | 假装工作         |
| play at being a teacher  | 假装当老师        |
| play at a profession     | 对某个职业抱着玩玩的心态 |
| what are you playing at? | 你到底在搞什么，英式口语 |

| 英文例句                                                 | 中文释义            |
| ---------------------------------------------------- | --------------- |
| The children were playing at being doctors.          | 孩子们正在玩扮演医生的游戏。  |
| He's just playing at being a businessman.            | 他只是在装模作样地当商人。   |
| What are you playing at?                             | 你到底在搞什么？        |
| You can't just play at running a business.           | 经营企业不能只抱着玩玩的心态。 |
| She was tired of people who played at being experts. | 她厌倦了那些装作专家的人。   |

使用见解：

play at 常见于英式英语，尤其是带有批评意味的表达。

What are you playing at?

你到底想干什么？

这句话经常用于表达不满或困惑，语气需要谨慎。

### 36. hold in：抑制、忍住

核心含义： 努力控制情绪、眼泪、笑声或身体反应，不让其表现出来。

常见结构： hold in + 情绪 / 反应

| 常见搭配                  | 含义与使用见解    |
| --------------------- | ---------- |
| hold in tears         | 忍住眼泪       |
| hold in anger         | 压抑愤怒       |
| hold in laughter      | 忍住笑声       |
| hold in your emotions | 压抑情绪       |
| hold something in     | 把某种情绪或反应压住 |

| 英文例句                                                   | 中文释义               |
| ------------------------------------------------------ | ------------------ |
| She tried to hold in her tears.                        | 她努力忍住眼泪。           |
| He struggled to hold in his anger.                     | 他努力压抑自己的愤怒。        |
| I couldn't hold in my laughter.                        | 我忍不住笑了出来。          |
| It's exhausting to hold in your emotions all the time. | 一直压抑自己的情绪会让人筋疲力尽。  |
| He held it in until he was alone.                      | 他一直忍着，直到独自一人才释放出来。 |

使用见解：

hold in 可以理解为把情绪控制在内部，不让它表达出来。

Don't hold it all in.

别把所有情绪都憋在心里。

另外，hold back 也可以表示抑制情绪：

She held back her tears.

她忍住了眼泪。

### 37. knock off from：下班、停止工作

核心含义： 在部分英式及地区性口语中，knock off 可以表示结束工作；from 后可以进一步说明离开的工作岗位或场所。不过 knock off from 作为固定组合的普遍性较低。

常见结构： knock off / knock off work

| 常见搭配                  | 含义与使用见解                      |
| --------------------- | ---------------------------- |
| knock off work        | 下班                           |
| knock off early       | 提前结束工作                       |
| knock off at five     | 五点下班                         |
| knock off for the day | 结束当天的工作                      |
| knock off from work   | 某些地区使用，建议优先使用 knock off work |

| 英文例句                                                             | 中文释义                  |
| ---------------------------------------------------------------- | --------------------- |
| What time do you knock off work?                                 | 你几点下班？                |
| Let's knock off early today.                                     | 今天我们早点下班吧。            |
| We usually knock off at six.                                     | 我们通常六点下班。             |
| I've finished everything, so I'm going to knock off for the day. | 我已经完成所有工作，准备结束今天的工作了。 |
| He knocked off work and went straight home.                      | 他下班后直接回家了。            |

使用见解：

knock off 在英式口语中可以表示下班，但不同地区的使用习惯有所差异。

更普遍的表达包括：

finish work

结束工作。

get off work

下班，尤其常见于美式英语。

I'm getting off work at six.

我六点下班。

另外，knock off 也可以表示快速完成、停止某事或仿制商品，需要结合语境判断。

### 38. phase out of：逐渐退出；逐步淘汰

核心含义： 逐渐停止使用某种产品、制度或技术，或者逐步退出某个领域或业务。

常见结构： phase something out / phase out of something

| 常见搭配                          | 含义与使用见解   |
| ----------------------------- | --------- |
| phase out an old system       | 逐步淘汰旧系统   |
| phase out a product           | 逐步停止生产某产品 |
| phase out outdated technology | 淘汰过时技术    |
| phase out of a market         | 逐渐退出某个市场  |
| phase out of an industry      | 逐渐退出某个行业  |

| 英文例句                                                      | 中文释义                 |
| --------------------------------------------------------- | -------------------- |
| The company is phasing out its old software.              | 公司正在逐步淘汰旧软件。         |
| We're planning to phase out the outdated system.          | 我们计划逐步停用过时系统。        |
| The manufacturer is phasing out this model.               | 制造商正在逐步停产这款型号。       |
| The company is gradually phasing out of the market.       | 这家公司正在逐渐退出该市场。       |
| They plan to phase out the use of fossil fuels over time. | 他们计划逐步减少并最终停止使用化石燃料。 |

使用见解：

最常见、最值得掌握的是：

phase something out

逐步淘汰某物。

phase out of something 主要用于强调逐渐退出某个领域，实际使用时也可以考虑 withdraw from、exit 等表达。

### 39. set down：放下；写下；制定

核心含义： 把某物放到表面上，或者将信息、规则、想法正式记录下来。

常见结构： set something down

| 常见搭配                          | 含义与使用见解    |
| ----------------------------- | ---------- |
| set down a bag                | 放下包        |
| set down your thoughts        | 写下想法       |
| set down rules                | 制定规则       |
| set down instructions         | 写下说明       |
| set something down in writing | 将某事以书面形式记录 |

| 英文例句                                                       | 中文释义                |
| ---------------------------------------------------------- | ------------------- |
| He set down his bag and sat on the sofa.                   | 他放下包，坐在沙发上。         |
| She set down her thoughts in a notebook.                   | 她把自己的想法写在笔记本上。      |
| The rules are clearly set down in the contract.            | 这些规则在合同中有明确规定。      |
| I wanted to set everything down before I forgot it.        | 我想趁还没忘记，把所有事情都记录下来。 |
| The author set down his experiences in a series of essays. | 作者通过一系列文章记录了自己的经历。  |

使用见解：

set down 在书面英语和文学叙事中尤其自然。

它是可分离短语动词：

set it down

把它放下；把它记录下来。

### 40. set out for：动身前往

核心含义： 从某个地方出发，前往指定目的地，通常带有正式旅行、远行或叙事色彩。

常见结构： set out for + 地点

| 常见搭配                      | 含义与使用见解                      |
| ------------------------- | ---------------------------- |
| set out for home          | 动身回家                         |
| set out for the city      | 动身前往城市                       |
| set out for a destination | 出发前往目的地                      |
| set out for the mountains | 动身前往山区                       |
| set out for a journey     | 通常更自然地说 set out on a journey |

| 英文例句                                                 | 中文释义             |
| ---------------------------------------------------- | ---------------- |
| We set out for home before sunrise.                  | 我们在日出之前动身回家。     |
| They set out for the mountains early in the morning. | 他们一大早就动身前往山区。    |
| She set out for London the following day.            | 第二天，她动身前往伦敦。     |
| The travellers set out for the coast at dawn.        | 旅行者们在黎明时分出发前往海岸。 |

使用见解：

set out for 强调前往的目的地。

而：

set out to do something

表示开始行动，决心实现某个目标。

He set out to write a novel.

他开始着手写一部小说。

两者的区别非常重要。

### 41. set up：建立、安装；安排；设局

核心含义： 创建、安装或安排某个系统、组织或活动，也可以表示设计某种圈套。

常见结构： set something up

| 常见搭配              | 含义与使用见解        |

| Can you help me set up the server?                | 你能帮我配置服务器吗？   |
| She set up a meeting with the client.             | 她安排了与客户的会议。   |
| It only takes a few minutes to set up an account. | 创建一个账号只需要几分钟。 |
| He claimed that someone had set him up.           | 他声称有人设计陷害了他。  |

使用见解：

set up 是非常高频的短语动词，其意义跨度很大，但都可以与“建立某种安排或结构”联系起来。

注意：

set it up

把它设置好。

set up a business

创办企业。

set someone up with someone

为某人介绍对象。

| phase out | phase something out | They're phasing it out. 他们正在逐步淘汰它。 |
| hold in   | hold something in   | Don't hold it in. 别憋在心里。           |

其中 call off、put off、set up、set down、phase out、hold in 都属于可以分离的短语动词。宾语是人称代词时，通常必须放在动词与副词小品词之间。

## 十一、综合语境中的实际使用

### 情境一：开始一个新项目

After months of preparation, we finally embarked on a new project. At first, we struggled to decide how to set about solving the technical problems. Eventually, we got down to work and began building the system step by step.

经过几个月的准备，我们终于启动了一个新项目。一开始，我们很难确定应该如何着手解决技术问题。最终，我们开始认真工作，一步一步地搭建系统。

### 情境二：学习中的坚持与进步

I've been trying to improve my English for years. Sometimes I struggle to keep up with everything I need to learn, and I often have to catch up on things I've forgotten. But I've decided to stick to my plan and keep at it, even when progress feels slow.

多年来，我一直在努力提高英语水平。有时候我很难跟上所有需要学习的内容，也经常需要补上已经遗忘的知识。但我已经决定坚持自己的计划，即使进步缓慢，也会继续努力。

### 情境三：面对现实与个人选择

I was offered a new job, but the salary was lower than I expected. Instead of accepting it immediately, I decided to hold out for a better offer. I didn't want to give up on my long-term goals simply because I was under pressure.

有人向我提供了一份新工作，但薪水比我预期的低。我决定暂时不接受，继续等待更好的机会。我不想仅仅因为承受压力就放弃长期目标。

### 情境四：推迟与取消

We originally planned to go ahead with the event, but several unexpected problems came up. We decided to hold off on making a final decision and put the event off for another week. Unfortunately, the situation didn't improve, so we eventually called it off.

我们原本计划照常举行活动，但出现了几个意外问题。我们决定暂缓作出最终决定，并把活动再推迟一周。遗憾的是，情况没有改善，因此最终取消了活动。

### 情境五：放下过去，继续生活

After leaving his previous job, he struggled to let go of the past. He had spent years holding on to the hope that things would improve. Eventually, he decided to bow out of the industry and embark on a completely different career.

离开上一份工作后，他很难放下过去。多年来，他一直抱着情况会好转的希望。最终，他决定退出这个行业，开始一段完全不同的职业生涯。

这些表达中，get down to、carry on with、catch up on、catch up with、give up on、go ahead with、hold off on、keep at、keep up with、let go of、set up、stick to 在日常交流和职场表达中尤其值得优先掌握。

部分组合，例如 knock off from、pass up on、phase out of 和 slow down on，固定程度或通用性相对较低。学习时应优先掌握更加自然且广泛使用的核心形式：knock off work、pass up、phase something out、slow down 和 cut down on。
