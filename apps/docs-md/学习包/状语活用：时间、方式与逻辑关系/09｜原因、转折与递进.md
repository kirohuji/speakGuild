# 状语活用：时间、方式与逻辑关系

# 09｜原因、转折与递进

## 综合目标

用原因与结果、转折与对比、补充与递进三类衔接表达组织句子和段落。学习重点包括词义、语气、句子结构、标点和实际输出。

## 使用前先掌握：衔接表达的三种结构

| 类型 | 结构特点 | 示例 |
| --- | --- | --- |
| 连接副词或状语短语 | 常用句号或分号分隔两个独立句 | **The test failed. Therefore, we ran it again.**<br>测试失败了，因此我们又运行了一遍。 |
| 介词短语 | 后接名词、代词或动名词 | **We stayed home because of the storm.**<br>因为暴风雨，我们待在家里。 |
| 句内副词 | 放在实义动词前、助动词后等合适的位置 | **She also checked the logs.**<br>她还检查了日志。 |

**常见错误：** `The test failed, therefore we ran it again.` 在正式写作中属于逗号拼接。可改为 `The test failed. Therefore, we ran it again.` 或 `The test failed; therefore, we ran it again.`

## 一、原因与结果

### 1. therefore

**核心感觉**

> 因此；据此。从已经交代的事实推出合乎逻辑的结论；书面和正式说明中很常见。

**词性与句型**

- 高频结构：`S1. Therefore, S2. / S1; therefore, S2.`
- 用作连接句子的成分时，要根据句法判断是否需要句号、分号或逗号。

**高频结构与例句**

| 结构 / 语境 | 使用见解与例句 |
| --- | --- |
| 基础表达 | 从已经交代的事实推出合乎逻辑的结论；书面和正式说明中很常见。<br><br>**The payment failed. Therefore, the order was not processed.**<br>付款失败，因此订单没有得到处理。 |
| 进阶表达 | 注意结构与表达重点。<br><br>**We have no reliable evidence; therefore, we cannot draw a conclusion.**<br>我们没有可靠证据，因此无法得出结论。 |

**英语思维与易错点**

therefore 通常是连接副词，不能照搬 because 的语法把两个独立分句直接用逗号硬连。

> 况且；另外；除……之外。句首补充理由常带“而且还有一点”的口语语气；besides + 名词是另一种结构。

**词性与句型**

- 高频结构：`Besides, + clause / besides + noun/-ing`
- 用作连接句子的成分时，要根据句法判断是否需要句号、分号或逗号。

**高频结构与例句**

| 结构 / 语境 | 使用见解与例句 |
| --- | --- |
| 基础表达 | 句首补充理由常带“而且还有一点”的口语语气；besides + 名词是另一种结构。<br><br>**I don't want to go out. Besides, it's already late.**<br>我不想出门，况且现在已经很晚了。 |
| 进阶表达 | 注意结构与表达重点。<br><br>**Besides English, she speaks Spanish.**<br>除了英语，她还会说西班牙语。 |

**英语思维与易错点**

besides 表示包括在内的额外补充；beside（没有 s）通常表示“在……旁边”。

**输出提示**

尝试用 **besides** 解释一次工作、学习或生活中的真实经历，注意句子之间的逻辑关系。

### 19. in addition

**核心感觉**

> 此外；另外。中性、整齐地增加新信息；in addition to 后接名词或动名词。

**词性与句型**

- 高频结构：`In addition, + clause / in addition to + noun/-ing`
- 用作连接句子的成分时，要根据句法判断是否需要句号、分号或逗号。

**高频结构与例句**

| 结构 / 语境 | 使用见解与例句 |
| --- | --- |
| 基础表达 | 中性、整齐地增加新信息；in addition to 后接名词或动名词。<br><br>**The course includes videos. In addition, it offers practice exercises.**<br>课程包含视频，另外还有练习题。 |
| 进阶表达 | 注意结构与表达重点。<br><br>**In addition to teaching, he writes textbooks.**<br>除了教学，他还编写教材。 |

**英语思维与易错点**

in addition 与 in addition to 结构不同，别漏写 to。

**输出提示**

尝试用 **in addition** 解释一次工作、学习或生活中的真实经历，注意句子之间的逻辑关系。

### 20. what's more

**核心感觉**

> 而且；更重要的是。较口语化地继续加码，突出后一条理由。

**词性与句型**

- 高频结构：`What's more, + clause`
- 用作连接句子的成分时，要根据句法判断是否需要句号、分号或逗号。

**高频结构与例句**

| 结构 / 语境 | 使用见解与例句 |
| --- | --- |
| 基础表达 | 较口语化地继续加码，突出后一条理由。<br><br>**The restaurant is nearby. What’s more, it’s affordable.**<br>餐厅就在附近，而且价格也实惠。 |
| 进阶表达 | 注意结构与表达重点。<br><br>**The method saves time. What's more, it reduces mistakes.**<br>这个方法节省时间，更重要的是还能减少错误。 |

**英语思维与易错点**

适合口语与较轻松的写作；正式报告可改用 moreover 或 furthermore。

**输出提示**

尝试用 **what's more** 解释一次工作、学习或生活中的真实经历，注意句子之间的逻辑关系。

## 四、核心混淆对比

| 组合 | 区别与选择提示 |
| --- | --- |
| therefore / consequently / as a result | therefore 强调逻辑推论；consequently 强调随之产生的后果；as a result 中性、口语和书面皆可。 |
| thus / hence | 都偏正式；thus 可用于 `thus doing`；hence 常见于 `hence the need for...`。 |
| because of / due to | 都能引出原因名词短语；due to 更常见于正式说明；不要把二者直接当作接完整从句的连词。 |
| however / nevertheless / nonetheless | however 适用范围广；后两者常强调“即使如此，仍然……”，二者高度重叠。 |
| instead / in contrast / on the other hand | instead 表示改选替代方案；in contrast 是对比差异；on the other hand 是转换论述角度。 |
| also / additionally / in addition | also 常在句中补充；后两者常在句首连接信息，偏书面。 |
| furthermore / moreover / what's more | 都可递进增强论证；前两者偏书面，what's more 较口语化。 |
| besides / beside | besides 可表“此外、况且、除……之外”；beside 通常指“在旁边”。 |

## 五、综合情境案例

### 案例 1：解释项目延期

**The original estimate was too optimistic. As a result, we missed the deadline. However, we have identified the main causes. In addition, we have introduced a new review process.**
原来的估算过于乐观，结果我们错过了截止日期。不过，我们已经找出了主要原因。此外，我们引入了新的审核流程。

**见解：** `as a result` 连接原因与后果，`however` 转向补救信息，`in addition` 补充另一个行动。

### 案例 2：比较两个方案

**The first option is cheaper. On the other hand, it requires more maintenance. In contrast, the second option costs more initially but is easier to manage.**
第一个方案更便宜；另一方面，它需要更多维护。相比之下，第二个方案初期成本更高，但更容易管理。

**见解：** `on the other hand` 提出同一方案的另一面，`in contrast` 才开始对照另一方案。

### 案例 3：给出多个理由

**I don't think we should launch today. The final tests are incomplete. Moreover, several major bugs remain unresolved. Besides, we haven't prepared the support team.**
我认为今天不该上线。最终测试还没完成，而且几个重大漏洞仍未解决。况且，我们也还没有让支持团队做好准备。

**见解：** `moreover` 递进补强论据，`besides` 加入额外的实际顾虑。

## 八、知识点复习清单

| 复习组 | 知识点 | 易错关注点 |
| --- | --- | --- |
| 原因与结果 | therefore, consequently, thus, hence, as a result, because of, due to | 原因还是结果；后接完整句还是名词短语；标点 |
| 转折与对比 | however, nevertheless, nonetheless, instead, in contrast, on the other hand | 让步、替代、客观对比与多角度权衡 |
| 补充与递进 | also, additionally, furthermore, moreover, besides, in addition, what's more | 正式程度、句中位置、`in addition to` 和 `besides` 的用法 |

**建议复习方式：** 每次抽取一个短场景，只要求学习者选择 1–2 个恰当的衔接表达并造句；同义表达允许多解，根据语境判断自然程度。
