# 不规则动词的基本结构

## 小提示

英语动词会根据句子中的时间、语法结构和句法功能发生形式变化。

不规则动词主要涉及三个基本形式：

| 形式 | 英文 | 主要作用 |
| --- | --- | --- |
| 原形 | **Base Form** | 动词的基础形式 |
| 过去式 | **Past Simple** | 构成一般过去时等结构 |
| 过去分词 | **Past Participle** | 用于完成式、被动式等结构 |

例如：

| 原形 | 过去式 | 过去分词 |
| --- | --- | --- |
| go | went | gone |
| take | took | taken |
| see | saw | seen |
| write | wrote | written |
| begin | began | begun |
| keep | kept | kept |
| come | came | come |

不规则动词的核心并不只在于“形式特殊”，还在于这些不同形式分别承担不同的语法功能。

---

# 一、为什么英语会有不规则动词？

现代英语中，大多数普通动词的过去式和过去分词可以通过 **-ed** 构成：

> work → worked → worked  
> open → opened → opened  
> change → changed → changed

但英语历史上并不存在从一开始就统一使用 `-ed` 的动词系统。

一些古老动词通过：

- 元音变化
- 辅音变化
- 词尾变化
- 不同词形

来表示过去和分词形式。

例如：

> sing → sang → sung

> write → wrote → written

> bind → bound → bound

> keep → kept → kept

随着英语的发展，`-ed` 逐渐成为主要的规则变化方式，但许多高频、古老的动词保留了较早的变化形式。

因此，今天所谓的“不规则动词”，实际上包含了英语历史中遗留下来的多种变化模式。

---

## 高频动词中为什么有很多不规则形式？

语言中使用频率很高的词往往更容易保留传统形式。

例如：

> be  
> have  
> do  
> go  
> come  
> get  
> take  
> make  
> give  
> see  
> know  
> think

这些词长期高频出现，其特殊形式也一直被反复使用。

因此，不规则动词虽然数量远少于规则动词，却大量集中在英语最常见的核心动词中。

---

# 二、“不规则”并不等于没有规律

“不规则”主要表示：

> 不能统一使用一条 `-ed` 规则得到过去式和过去分词。

所以他是相对于那些规则动词来说没有规律,但不同不规则动词之间仍然存在许多重复模式。

例如：

### 三种形式相同

> cut – cut – cut  
> put – put – put  
> hit – hit – hit

### 过去式与过去分词相同

> keep – kept – kept  
> feel – felt – felt  
> build – built – built

### 元音发生系列变化

> sing – sang – sung  
> ring – rang – rung  
> drink – drank – drunk

### 过去式与过去分词形成类似变化

> speak – spoke – spoken  
> break – broke – broken  
> wake – woke – woken

### 原形与过去分词相同

> come – came – come  
> become – became – become  
> run – ran – run

因此，不规则动词内部仍然可以按照变化形式进行分类。

---

# 三、原形：Base Form

原形是动词最基本的形式。

例如：

> go  
> take  
> see  
> write  
> come

原形除了出现在一般现在时中，也会进入很多其他结构。

## 常见结构

| 结构 | 例子 |
| --- | --- |
| 一般现在时 | I **take** the subway every day. |
| 情态动词 + 原形 | You should **take** a break. |
| do / does / did + 原形 | Did you **see** him? |
| to + 原形 | I want to **go** home. |
| 祈使句 | **Take** your time. |

### 例句

| English | 中文 |
| --- | --- |
| I usually **take** the subway to work. | 我通常坐地铁上班。 |
| We **go** there every weekend. | 我们每个周末都去那里。 |
| You should **take** a break. | 你应该休息一下。 |
| Did you **see** him yesterday? | 你昨天见到他了吗？ |
| I want to **write** something. | 我想写点东西。 |

---

## did 后为什么使用原形？

比较：

> I **went** there yesterday.

> Did you **go** there yesterday?

在第一句中，过去时间由 **went** 表达。

在疑问句中，过去时已经由 **did** 承担，因此主要动词恢复原形：

> did + go

同样：

> She **knew** the answer.

变成：

> Did she **know** the answer?

所以：

> ❌ Did you went there?

不符合英语的结构。

对于初学者来说,希望你不要死记硬背,因为这是一个适应的过程,需要通过大量的练习慢慢掌握这个思维模式。

---

# 四、过去式：Past Simple

过去式最典型的功能是构成一般过去时。

例如：

> go → went  
> take → took  
> see → saw  
> write → wrote

### 例句

| English | 中文 |
| --- | --- |
| I **went** home early yesterday. | 我昨天很早就回家了。 |
| She **took** a taxi last night. | 她昨晚坐了出租车。 |
| We **saw** him at the station. | 我们在车站见到了他。 |
| He **wrote** three pages yesterday. | 他昨天写了三页。 |
| They **came** home late. | 他们很晚才回家。 |

过去式可以直接承担一般过去时的形式标记。

例如：

> I **wrote** the email yesterday.

这里不需要再加入另一个表示过去的助动词。

---

# 五、过去分词：Past Participle

过去分词是动词的一种**非限定形式**。

> 各位同学,请一定要理解什么是**非限定形式**,这有助你理解英语的动词系统的核心思路

例如：

> go → gone  
> take → taken  
> see → seen  
> write → written  
> break → broken

过去分词和过去式在很多不规则动词中形式不同。

比较：

| 原形 | 过去式 | 过去分词 |
| --- | --- | --- |
| go | went | gone |
| see | saw | seen |
| take | took | taken |
| break | broke | broken |
| write | wrote | written |

过去分词通常进入更大的语法结构。所以一定不要想当然地以为是另一种过去式而已。

---

## 1. 完成式

结构：

> **have + 过去分词**

例如：

> I've **seen** this movie before.

我以前看过这部电影。

> She's **gone** home.

她已经回家了。

> I've **written** the email.

我已经把邮件写好了。

---

## 2. 被动式

结构：

> **be + 过去分词**

例如：

> The window was **broken**.

窗户被打破了。

> The letter was **written** yesterday.

这封信是昨天写的。

> He was **taken** to hospital.

他被送到了医院。

---

## 3. 情态完成结构

结构：

> **modal + have + 过去分词**

例如：

> You should have **told** me.

你本应该告诉我。

> He might have **forgotten**.

他可能已经忘了。

> I could have **taken** a taxi.

我本来可以坐出租车。

---

## 4. 过去分词的形容词性质

过去分词还可以进入具有形容词性质的结构。

例如：

> a **broken** window  
> 一扇破掉的窗户

> **written** instructions  
> 书面说明

> **frozen** food  
> 冷冻食品

这也是“过去分词”不能简单理解为“过去时间”的原因。

---

# 六、过去式与过去分词的区别

以 **write** 为例：

> write – wrote – written

### 过去式

> I **wrote** the email yesterday.

我昨天写了这封邮件。

### 完成式中的过去分词

> I've **written** the email.

我已经把邮件写好了。

### 被动式中的过去分词

> The email was **written** yesterday.

这封邮件是昨天写的。

---

## 对比

| 形式 | 例句 | 功能 |
| --- | --- | --- |
| wrote | I **wrote** it yesterday. | 一般过去时 |
| written | I've **written** it. | 完成式 |
| written | It was **written** yesterday. | 被动式 |

过去式本身可以构成一般过去时。

过去分词则通常依赖**其他结构**来确定它在句子中的作用。

---

# 七、过去分词为什么叫“过去分词”？

名称中的 **past** 容易让人产生一种误解：

> 过去分词 = 更早的过去

实际上，过去分词本身并不确定句子的时间。

例如：

> It **is broken**.

现在处于损坏状态。

> It **was broken** yesterday.

过去被损坏。

> It **has been broken** for weeks.

这种状态已经持续了几周。

三个句子中都有 **broken**，但时间关系并不相同。

真正决定时间的是整个谓语结构：

> is broken  
> was broken  
> has been broken

因此，过去分词首先是一种**动词形式**，而不是一种独立的时态。

---

# 八、形式相同与语法功能相同是两回事

很多不规则动词会出现形式重合。

例如：

> cut – cut – cut

比较：

> I usually **cut** the vegetables first.

这里的 **cut** 是原形形式。

> I **cut** my finger yesterday.

这里的 **cut** 是过去式。

> I've already **cut** the paper.

这里的 **cut** 是过去分词。

在这里他们的拼写虽然完全一样，但语法身份不同。所以在你输出这句话的时候请还是按照对应的语法思维来,而不是以为cut 的过去式和过去分词都是相同的,就不考虑时态了等

---

## 过去式和过去分词同形

例如：

> think – thought – thought

> I **thought** about it yesterday.

这里是过去式。

> I've **thought** about it a lot.

这里是过去分词。

再例如：

> keep – kept – kept

> I **kept** the receipt.

> I've **kept** all the receipts.

因此：

> **词形是否相同，不能决定它的语法功能。**

判断时需要看它在整个句子中的位置和结构。

---

# 九、不规则动词的主要变化类型

## 1. 三种形式相同

| 原形 | 过去式 | 过去分词 |
| --- | --- | --- |
| cut | cut | cut |
| put | put | put |
| hit | hit | hit |
| hurt | hurt | hurt |
| let | let | let |
| set | set | set |
| shut | shut | shut |
| spread | spread | spread |

### 例句

| 形式 | English | 中文 |
| --- | --- | --- |
| 原形 | I usually **cut** the fruit first. | 我通常先切水果。 |
| 过去式 | I **cut** my hand yesterday. | 我昨天割伤了手。 |
| 过去分词 | I've already **cut** the fruit. | 我已经把水果切好了。 |

---

## 2. 过去式与过去分词相同

| 原形 | 过去式 | 过去分词 |
| --- | --- | --- |
| build | built | built |
| bring | brought | brought |
| buy | bought | bought |
| feel | felt | felt |
| keep | kept | kept |
| leave | left | left |
| make | made | made |
| think | thought | thought |

### 例句

| 形式 | English | 中文 |
| --- | --- | --- |
| 原形 | I usually **keep** the receipt. | 我通常会保留收据。 |
| 过去式 | I **kept** the receipt yesterday. | 我昨天把收据留了下来。 |
| 过去分词 | I've **kept** all the receipts. | 我把所有收据都保留着。 |

这一类的主要特点是：

> V2 = V3

所以必须通过句子结构区分过去式和过去分词。

---

## 3. 三种形式不同

| 原形 | 过去式 | 过去分词 |
| --- | --- | --- |
| begin | began | begun |
| drink | drank | drunk |
| drive | drove | driven |
| eat | ate | eaten |
| give | gave | given |
| see | saw | seen |
| speak | spoke | spoken |
| take | took | taken |
| write | wrote | written |

### 例句

| 形式 | English | 中文 |
| --- | --- | --- |
| 原形 | We usually **begin** at nine. | 我们通常九点开始。 |
| 过去式 | The meeting **began** at nine. | 会议九点开始了。 |
| 过去分词 | The meeting has already **begun**. | 会议已经开始了。 |

这一类最能直接看到 V1、V2、V3 的形式区别。

---

## 4. 原形与过去分词相同

| 原形 | 过去式 | 过去分词 |
| --- | --- | --- |
| come | came | come |
| become | became | become |
| run | ran | run |

### 例句

| 形式 | English | 中文 |
| --- | --- | --- |
| 原形 | I usually **come** home before seven. | 我通常七点前回家。 |
| 过去式 | I **came** home late yesterday. | 我昨天很晚才回家。 |
| 过去分词 | I've just **come** home. | 我刚刚到家。 |

这种类型可以写成：

> A – B – A

形式相同的是原形和过去分词。

# 十、不规则变化中的局部规律

不规则动词不存在统一规律，但一些词形成了比较明显的变化组。

## i – a – u

> sing – sang – sung  
> ring – rang – rung  
> swim – swam – swum  
> drink – drank – drunk

这些动词通过内部元音变化区分不同形式。

---

## -oke / -oken

> speak – spoke – spoken  
> break – broke – broken  
> wake – woke – woken

过去式和过去分词之间具有明显的形式联系。

---

## -ew / -own

> blow – blew – blown  
> fly – flew – flown  
> grow – grew – grown

---

## -ought / -aught

> think – thought – thought  
> buy – bought – bought  
> bring – brought – brought  
> fight – fought – fought  
> teach – taught – taught  
> catch – caught – caught

这些形式并非完全相同的规则，但在拼写和发音上具有明显的家族特征。

整理这些形式和规则，是希望你能够在理解的基础上逐渐掌握它们，而不必强迫自己死记硬背。

学习一门外语时，我们可以尝试从更丰富的角度去认识它。除了理解语法规则和词汇用法，还可以通过探索词源、语言的历史演变以及背后的文化背景，加深对语言的认识与印象，让学习变得更加有趣，也更有意义。

与此同时，语言学习离不开一个重要的原则：**Repetition（重复）**。

即使你已经理解了某个知识点，也很难仅凭一次学习就将它牢牢记住。随着不断接触、使用和重复，那些原本陌生的表达会逐渐变得熟悉，最终成为能够自然运用的语言能力。

**理解让学习更有深度，重复让记忆更加牢固，而长期的坚持，才能让这些积累真正转化为自己的能力。**

# 十一、同一个动词的三种形式要放在同一意义中比较

例如：

## take — took — taken

### 原形

> I usually **take** the subway to work.

我通常坐地铁上班。

### 过去式

> I **took** the subway yesterday.

我昨天坐了地铁。

### 过去分词

> I've **taken** this train before.

我以前坐过这班火车。

这里三种形式使用的是相近的“乘坐交通工具”意义，因此可以清楚看到形式变化本身带来的语法区别。

---

## write — wrote — written

### 原形

> I usually **write** in the evening.

我通常晚上写东西。

### 过去式

> I **wrote** three pages last night.

我昨晚写了三页。

### 过去分词

> I've **written** three pages so far.

到目前为止我已经写了三页。

---

## see — saw — seen

### 原形

> I often **see** him at work.

我经常在公司见到他。

### 过去式

> I **saw** him yesterday.

我昨天见到他了。

### 过去分词

> I've **seen** him before.

我以前见过他。

---

# 十二、动词形式和动词意义是两个层面

动词发生变形时，变化的是语法形式。

动词本身还可能拥有多个不同意义和搭配。

例如 **take**：

| 常见搭配 | 中文 |
| --- | --- |
| take the bus | 坐公交 |
| take a break | 休息一下 |
| take a photo | 拍照 |
| take your time | 慢慢来 |
| take someone home | 带某人回家 |
| take something seriously | 认真对待某事 |

这些表达都可以继续发生时态变化：

> I **took** the bus.

> We **took** a break.

> She **took** a photo.

> I've **taken** this bus before.

因此：

> **词义和搭配决定“表达什么”，动词变形决定“它以什么语法形式出现”。**

这两个层面需要区分。

---

# 十三、规则动词与不规则动词的差别主要在形式变化

从句法功能上看，规则动词和不规则动词并不存在两套完全不同的语法。

例如：

### 规则动词

> work – worked – worked

> I **worked** yesterday.

> I've **worked** here before.

### 不规则动词

> write – wrote – written

> I **wrote** yesterday.

> I've **written** about this before.

两者都会区分：

- 原形
- 过去式
- 过去分词

区别主要在于过去式和过去分词的构成方式。

规则动词主要通过：

> **-ed**

不规则动词则保留不同的历史变化形式。

# 十五、常见错误

| 错误 | 正确 | 原因 |
| --- | --- | --- |
| Did you **went** there? | Did you **go** there? | did 后使用原形 |
| I've **went** there. | I've **gone** there. | have 后使用过去分词 |
| I **seen** him yesterday. | I **saw** him yesterday. | 一般过去时使用过去式 |
| He has **came** home. | He has **come** home. | come 的过去分词为 come |
| The window was **broke**. | The window was **broken**. | 被动式使用过去分词 |
| She should have **went**. | She should have **gone**. | have 后使用过去分词 |

# 快速复习

| 知识点 | 核心关系 |
| --- | --- |
| **Base Form / V1** | 动词基础形式 |
| **Past Simple / V2** | 主要用于一般过去时 |
| **Past Participle / V3** | 用于完成式、被动式等 |
| **did + V1** | 过去标记由 did 承担 |
| **have + V3** | 完成结构 |
| **be + V3** | 被动结构 |
| **modal + have + V3** | 情态完成结构 |
| A-A-A | 三种形式相同 |
| A-B-B | 过去式和过去分词相同 |
| A-B-C | 三种形式不同 |
| A-B-A | 原形和过去分词相同 |
| 不规则 | 没有统一的 -ed 变化方式 |
| 局部规律 | 部分动词形成相似的音变和拼写组 |
| 形式相同 | 不代表语法功能相同 |

# 综合 Case｜一个忙碌的早晨

**场景：** Daniel 早上起晚了，赶到公司后和 Emma 谈起发生的事情。

| English | 中文 |
| --- | --- |
| **Emma:** You look tired. What happened? | **Emma:** 你看起来很累。怎么了？ |
| **Daniel:** I usually **wake** up at seven, but I **woke** up late today. | **Daniel:** 我通常七点起床，但今天起晚了。 |
| **Emma:** What time did you **get** up? | **Emma:** 你几点起来的？ |
| **Daniel:** Almost eight. I quickly **took** a shower and **ate** some breakfast. | **Daniel:** 快八点了。我赶紧洗了澡，吃了点早餐。 |
| **Emma:** Did you **take** the subway? | **Emma:** 你坐地铁来的吗？ |
| **Daniel:** I tried, but the train had already **left** when I got there. | **Daniel:** 我本来想坐，但到那里的时候火车已经开走了。 |
| **Emma:** So what did you **do**? | **Emma:** 那你怎么办的？ |
| **Daniel:** I **took** a taxi instead. | **Daniel:** 我改坐了出租车。 |
| **Emma:** Have you **told** the manager? | **Emma:** 你告诉经理了吗？ |
| **Daniel:** Yeah, I've already **sent** him a message. | **Daniel:** 嗯，我已经给他发消息了。 |
