
# 不规则动词的基本结构

## 阅读说明

英语动词会根据时态和语法结构发生形式变化。

学习不规则动词，首先需要认识三个基本形式：

| 形式 | 英文名称 | 主要作用 |
| :--- | :--- | :--- |
| **原形（V1）** | Base Form | 动词的基础形式 |
| **过去式（V2）** | Past Simple Form | 主要用于一般过去时 |
| **过去分词（V3）** | Past Participle | 用于完成式、被动式等结构 |

### 基本变化示例

| 原形 V1 | 过去式 V2 | 过去分词 V3 |
| :--- | :--- | :--- |
| go | went | gone |
| take | took | taken |
| see | saw | seen |
| write | wrote | written |
| begin | began | begun |
| keep | kept | kept |
| come | came | come |

学习时需要区分两个问题：

| 学习重点 | 示例 | 核心问题 |
| :--- | :--- | :--- |
| **形式如何变化？** | `write → wrote → written` | 动词有哪些不同形式？ |
| **什么时候使用？** | `I wrote` / `I've written` | 不同语法结构需要哪种形式？ |

前者属于**动词形态**，后者属于**语法结构**。两者需要结合起来理解。

---

# 1. 为什么英语有不规则动词？

现代英语中，大多数动词通过添加 `-ed` 构成过去式和过去分词。

### 规则动词示例

| 原形 | 过去式 | 过去分词 |
| :--- | :--- | :--- |
| work | worked | worked |
| open | opened | opened |
| change | changed | changed |

但英语并非从一开始就统一使用 `-ed`。

在古英语及更早的日耳曼语发展过程中，一部分动词通过内部元音变化区分不同形式，另一部分动词则通过词尾或辅音变化形成过去式。

### 不规则变化的历史特点

| 原形 | 过去式 | 过去分词 | 变化特点 |
| :--- | :--- | :--- | :--- |
| sing | sang | sung | 内部元音变化 |
| write | wrote | written | 元音及词尾变化 |
| keep | kept | kept | 元音及辅音变化 |
| go | went | gone | 不同历史词形的融合 |

随着英语的发展，`-ed` 逐渐成为常规的过去式和过去分词构成方式，但一些古老的动词保留了早期形式。

因此，**不规则动词并不是毫无规律，而是无法全部套用同一条 `-ed` 规则。**

## 1.1 为什么常用动词中有很多不规则动词？

使用频率较高的动词，往往更容易保留传统形式。

例如：

`be`、`have`、`do`、`go`、`come`、`get`、`take`、`make`、`give`、`see`、`know`、`think`

这些动词长期频繁出现在日常语言中，其特殊变化形式也不断被使用。

这解释了一个看似矛盾的现象：不规则动词的数量并不多，却在日常英语中十分常见。

# 2. 三种形式的语法功能

理解 V1、V2、V3 的区别，比单纯记住变化表更重要。

## 2.1 原形（Base Form / V1）

原形是动词的基础形式。

它不仅用于一般现在时中的部分情况，也出现在情态动词、助动词和不定式等结构中。

### 常见语法结构

| 结构 | English Example | 中文释义 |
| :--- | :--- | :--- |
| 一般现在时 | I usually **take** the subway to work. | 我通常坐地铁上班。 |
| 情态动词 + V1 | You should **take** a break. | 你应该休息一下。 |
| do / does / did + V1 | Did you **see** him yesterday? | 你昨天见到他了吗？ |
| to + V1（不定式） | I want to **write** something. | 我想写点东西。 |
| 祈使句 | **Take** your time. | 慢慢来。 |

注意：一般现在时并非总是直接使用原形。第三人称单数通常需要添加 `-s` 或 `-es`，例如 `She takes the subway.`

### 为什么 did 后面要使用原形？

比较：

| 句型 | English Example | 中文释义 |
| :--- | :--- | :--- |
| 肯定陈述句 | I **went** there yesterday. | 我昨天去了那里。 |
| 一般疑问句 | Did you **go** there yesterday? | 你昨天去那里了吗？ |
| 肯定陈述句 | She **knew** the answer. | 她知道答案。 |
| 一般疑问句 | Did she **know** the answer? | 她知道答案吗？ |

第一句使用 `went` 表示一般过去时。

第二句中，过去时的语法标记已经体现在 `did` 上，因此后面的主要动词使用原形 `go`。

同样，`knew` 在一般疑问句中变为 `did + know`。

### 常见错误

| 错误表达 | 正确表达 | 原因 |
| :--- | :--- | :--- |
| ~~Did you went there?~~ | Did you **go** there? | did 后面使用 V1 |

**语法要点：** 当助动词已经承担时态标记时，主要动词通常不再重复承担相同的变化。

---

## 2.2 过去式（Past Simple Form / V2）

过去式最常见的作用是构成一般过去时，描述过去发生的动作、事件或状态。

### 一般过去时例句

| English Example | 中文释义 |
| :--- | :--- |
| I **went** home early yesterday. | 我昨天很早就回家了。 |
| She **took** a taxi last night. | 她昨晚坐了出租车。 |
| We **saw** him at the station. | 我们在车站见到了他。 |
| He **wrote** three pages yesterday. | 他昨天写了三页。 |
| They **came** home late. | 他们很晚才回家。 |

在肯定陈述句中，主要动词的过去式通常可以直接承担一般过去时的标记。

### 肯定句与疑问句对比

| 句型 | English Example | 中文释义 |
| :--- | :--- | :--- |
| 肯定陈述句（V2） | I **wrote** the email yesterday. | 我昨天写了那封邮件。 |
| 一般疑问句（did + V1） | Did you **write** the email yesterday? | 你昨天写了那封邮件吗？ |

这里再次出现了 V2 与 `did + V1` 的转换。

---

## 2.3 过去分词（Past Participle / V3）

过去分词属于动词的**非限定形式（non-finite form）**。

所谓非限定形式，是指它本身不独立承担句子的时态、人称等限定性语法功能。

### 常见过去分词

| 原形 V1 | 过去分词 V3 |
| :--- | :--- |
| go | gone |
| take | taken |
| see | seen |
| write | written |
| break | broken |

过去分词可以出现在多种语法结构中。

### 2.3.1 完成式：have + V3

| English Example | 中文释义 |
| :--- | :--- |
| I've **seen** this movie before. | 我以前看过这部电影。 |
| She's **gone** home. | 她已经回家了。 |
| I've **written** the email. | 我已经把邮件写好了。 |

完成式中的 `have` 会根据时态和主语发生变化，而过去分词保持相应形式。

| 完成结构 | 语法功能 |
| :--- | :--- |
| `have written` | 现在完成式 |
| `had written` | 过去完成式 |
| `will have written` | 将来完成式 |

### 2.3.2 被动式：be + V3

| English Example | 中文释义 |
| :--- | :--- |
| The window was **broken**. | 窗户被打破了。 |
| The letter was **written** yesterday. | 这封信是昨天写的。 |
| He was **taken** to hospital. | 他被送到了医院。 |

被动式中的 `be` 可以根据时态变化，而过去分词用于构成被动结构。

### 2.3.3 情态完成结构：modal + have + V3

| English Example | 中文释义 |
| :--- | :--- |
| You should have **told** me. | 你本应该告诉我。 |
| He might have **forgotten**. | 他可能已经忘了。 |
| I could have **taken** a taxi. | 我本来可以坐出租车。 |

情态动词与完成结构结合后，可以表达对过去情况的推测、评价或未实现的可能性。

### 2.3.4 形容词性质

过去分词还可以修饰名词，或用于描述状态。

| English Expression | 中文释义 |
| :--- | :--- |
| a **broken** window | 一扇破损的窗户 |
| **written** instructions | 书面说明 |
| **frozen** food | 冷冻食品 |

这些用法说明，过去分词不能简单理解成另一种过去式。

# 3. 过去式与过去分词有什么区别？

以 `write — wrote — written` 为例：

| 形式 | English Example | 中文释义 | 语法功能 |
| :--- | :--- | :--- | :--- |
| V2：wrote | I **wrote** the email yesterday. | 我昨天写了那封邮件。 | 一般过去时 |
| V3：written | I've **written** the email. | 我已经写好了那封邮件。 | 现在完成式 |
| V3：written | The email was **written** yesterday. | 那封邮件是昨天写的。 | 被动式 |

它们之间的区别在于：

- `wrote` 可以直接作为一般过去时的谓语动词。
- `written` 通常需要与其他成分结合，或作为修饰成分使用。

## 3.1 过去分词为什么带有 past？

名称中的 *past* 容易让人误以为过去分词表示“更早的过去”。

实际上，过去分词本身并不能决定句子的时间。

### 不同结构中的 broken

| 语法结构 | English Example | 中文释义 |
| :--- | :--- | :--- |
| 现在状态 | The window is **broken**. | 窗户现在是破损的。 |
| 过去被动事件 | The window was **broken** yesterday. | 窗户昨天被打破了。 |
| 延续至今的状态 | The window has been **broken** for weeks. | 窗户已经坏了好几个星期了。 |

三个句子都使用 `broken`，但整体结构表达的时间关系不同。

- `is broken` 主要描述状态。
- `was broken yesterday` 可以理解为过去发生的被动事件。
- `has been broken for weeks` 强调状态从过去持续到现在。

因此，判断句子的时间与意义，需要观察整个谓语结构，而不能只看过去分词。

# 4. 不规则动词的四种主要类型

虽然不规则动词没有统一的变化方式，但可以按照 V1、V2、V3 之间的关系进行分类。

| 类型 | 形式特点 | 典型示例 |
| :--- | :--- | :--- |
| **A–A–A** | 三种形式相同 | cut — cut — cut |
| **A–B–B** | 过去式与过去分词相同 | keep — kept — kept |
| **A–B–C** | 三种形式不同 | begin — began — begun |
| **A–B–A** | 原形与过去分词相同 | come — came — come |

## 4.1 A–A–A：三种形式相同

| V1 | V2 | V3 | 核心释义 |
| :--- | :--- | :--- | :--- |
| cut | cut | cut | 切、割 |
| put | put | put | 放置 |
| hit | hit | hit | 击打 |
| hurt | hurt | hurt | 使受伤、疼痛 |
| let | let | let | 允许、让 |
| set | set | set | 设置、确定 |
| shut | shut | shut | 关闭 |
| spread | spread | spread | 传播、展开 |

这种类型最容易在拼写上混淆语法身份。

### 示例：cut — cut — cut

| 语法形式 | English Example | 中文释义 |
| :--- | :--- | :--- |
| V1 · 一般现在时 | I usually **cut** the fruit first. | 我通常先切水果。 |
| V2 · 一般过去时 | I **cut** my hand yesterday. | 我昨天割伤了手。 |
| V3 · 现在完成式 | I've already **cut** the fruit. | 我已经把水果切好了。 |

三个 `cut` 拼写相同，但并不意味着句子没有时态区别。

动词形式的语法身份仍然需要通过句子结构判断。

---

## 4.2 A–B–B：过去式与过去分词相同

| V1 | V2 | V3 | 核心释义 |
| :--- | :--- | :--- | :--- |
| build | built | built | 建造 |
| bring | brought | brought | 带来 |
| buy | bought | bought | 购买 |
| feel | felt | felt | 感觉 |
| keep | kept | kept | 保持、保留 |
| leave | left | left | 离开、留下 |
| make | made | made | 制作、使得 |
| think | thought | thought | 思考、认为 |

### 示例：keep — kept — kept

| 语法形式 | English Example | 中文释义 |
| :--- | :--- | :--- |
| V1 · 一般现在时 | I usually **keep** the receipt. | 我通常会保留收据。 |
| V2 · 一般过去时 | I **kept** the receipt yesterday. | 我昨天把收据留了下来。 |
| V3 · 现在完成式 | I've **kept** all the receipts. | 我把所有收据都保留着。 |

`kept` 既可以是过去式，也可以是过去分词。具体身份由结构决定。

---

## 4.3 A–B–C：三种形式不同

| V1 | V2 | V3 | 核心释义 |
| :--- | :--- | :--- | :--- |
| begin | began | begun | 开始 |
| drink | drank | drunk | 喝 |
| drive | drove | driven | 驾驶 |
| eat | ate | eaten | 吃 |
| give | gave | given | 给 |
| see | saw | seen | 看见 |
| speak | spoke | spoken | 说、讲话 |
| take | took | taken | 拿、带、乘坐 |
| write | wrote | written | 写 |

### 示例：begin — began — begun

| 语法形式 | English Example | 中文释义 |
| :--- | :--- | :--- |
| 一般现在时（第三人称单数） | The meeting usually **begins** at nine. | 会议通常九点开始。 |
| V2 · 一般过去时 | The meeting **began** at nine. | 会议九点开始了。 |
| V3 · 现在完成式 | The meeting has already **begun**. | 会议已经开始了。 |

这一类动词的过去式和过去分词具有不同词形，因此在学习中需要特别注意区分。

---

## 4.4 A–B–A：原形与过去分词相同

| V1 | V2 | V3 | 核心释义 |
| :--- | :--- | :--- | :--- |
| come | came | come | 来 |
| become | became | become | 变成 |
| run | ran | run | 跑、运行 |

### 示例：come — came — come

| 语法形式 | English Example | 中文释义 |
| :--- | :--- | :--- |
| V1 · 一般现在时 | I usually **come** home before seven. | 我通常七点前回家。 |
| V2 · 一般过去时 | I **came** home late yesterday. | 我昨天很晚才回家。 |
| V3 · 现在完成式 | I've just **come** home. | 我刚刚到家。 |

这类动词容易让学习者误以为过去分词应当和过去式相同。

### 常见错误

| 错误表达 | 正确表达 | 原因 |
| :--- | :--- | :--- |
| ~~He has came home.~~ | He has **come** home. | come 的 V3 仍然是 come |

# 5. 不规则变化中的局部规律

分类可以帮助我们识别词形之间的关系，而一些重复出现的拼写和发音模式，还可以帮助记忆。

## 5.1 i – a – u

| V1 | V2 | V3 |
| :--- | :--- | :--- |
| sing | sang | sung |
| ring | rang | rung |
| drink | drank | drunk |
| swim | swam | swum |

这一组动词主要通过内部元音变化区分三种形式。

**记忆线索：** `sing → sang → sung`

## 5.2 -oke / -oken

| V1 | V2 | V3 |
| :--- | :--- | :--- |
| speak | spoke | spoken |
| break | broke | broken |
| wake | woke | woken |

过去式与过去分词之间保留了明显的拼写联系。

**记忆线索：** `speak → spoke → spoken`

## 5.3 -ew / -own

| V1 | V2 | V3 |
| :--- | :--- | :--- |
| blow | blew | blown |
| fly | flew | flown |
| grow | grew | grown |

**记忆线索：** `grow → grew → grown`

## 5.4 -ought / -aught

| V1 | V2 | V3 |
| :--- | :--- | :--- |
| think | thought | thought |
| buy | bought | bought |
| bring | brought | brought |
| fight | fought | fought |
| teach | taught | taught |
| catch | caught | caught |

**记忆线索：** `think → thought → thought`

这些变化组并不是适用于所有动词的语法规则，而是部分动词之间保留下来的形态联系。

学习时可以将相似的词放在一起比较，但不应根据这些模式随意推导陌生动词的过去式。

# 6. 如何将三种形式用于真实表达？

记忆 `take — took — taken` 这样的变化表，是学习的第一步。

实际使用时，还需要根据句子的语法结构选择形式。

## 6.1 在相近意义下比较三种形式

### take — took — taken

| 语法形式 | English Example | 中文释义 |
| :--- | :--- | :--- |
| V1 · 一般现在时 | I usually **take** the subway to work. | 我通常坐地铁上班。 |
| V2 · 一般过去时 | I **took** the subway yesterday. | 我昨天坐了地铁。 |
| V3 · 现在完成式 | I've **taken** the subway before. | 我以前坐过地铁。 |

### write — wrote — written

| 语法形式 | English Example | 中文释义 |
| :--- | :--- | :--- |
| V1 · 一般现在时 | I usually **write** in the evening. | 我通常晚上写东西。 |
| V2 · 一般过去时 | I **wrote** three pages last night. | 我昨晚写了三页。 |
| V3 · 现在完成式 | I've **written** three pages so far. | 到目前为止，我已经写了三页。 |

### see — saw — seen

| 语法形式 | English Example | 中文释义 |
| :--- | :--- | :--- |
| V1 · 一般现在时 | I often **see** him at work. | 我经常在公司见到他。 |
| V2 · 一般过去时 | I **saw** him yesterday. | 我昨天见到他了。 |
| V3 · 现在完成式 | I've **seen** him before. | 我以前见过他。 |

这里有意使用相近的动词意义，避免搭配变化干扰对语法形式的观察。

## 6.2 动词意义与动词形式是两个层面

以 `take` 为例：

### 常见搭配

| English Expression | 中文释义 |
| :--- | :--- |
| take the bus | 坐公交 |
| take a break | 休息一下 |
| take a photo | 拍照 |
| take your time | 慢慢来 |
| take someone home | 带某人回家 |
| take something seriously | 认真对待某事 |

这些搭配可以根据语法需要发生形式变化。

### 搭配在句子中的应用

| 语法形式 | English Example | 中文释义 |
| :--- | :--- | :--- |
| V2 · 一般过去时 | I **took** the bus yesterday. | 我昨天坐了公交。 |
| V2 · 一般过去时 | We **took** a break after lunch. | 午饭后我们休息了一会儿。 |
| V3 · 现在完成式 | She's **taken** several photos. | 她已经拍了好几张照片。 |
| V3 · 情态完成结构 | You should have **taken** it seriously. | 你本应该认真对待这件事。 |

同一个动词可以进入不同的搭配，但它的形态变化仍然遵循 `take — took — taken`。

学习不规则动词时，主要任务是熟悉形式变化及其语法功能。词义、搭配和其他句型可以辅助理解，但不必同时掌握这个动词的全部用法。

# 7. 常见结构与易错形式

## 7.1 结构总表

| 语法结构 | 动词形式 | English Example | 中文释义 |
| :--- | :--- | :--- | :--- |
| 一般现在时 | V1（注意第三人称单数变化） | I **take** the subway. | 我坐地铁。 |
| 情态动词后 | V1 | I can **take** the subway. | 我可以坐地铁。 |
| did 后 | V1 | Did you **take** the subway? | 你坐地铁了吗？ |
| 不定式 | to + V1 | I want to **take** the subway. | 我想坐地铁。 |
| 一般过去时 | V2 | I **took** the subway. | 我坐了地铁。 |
| 现在完成式 | have / has + V3 | I've **taken** the subway before. | 我以前坐过地铁。 |
| 过去完成式 | had + V3 | I had **taken** the wrong train. | 我之前坐错了车。 |
| 被动式 | be + V3 | The photo was **taken** yesterday. | 这张照片是昨天拍的。 |
| 情态完成结构 | modal + have + V3 | I should have **taken** a taxi. | 我本应该坐出租车。 |

这里的 V1、V2、V3 表示动词的基本形态类别，而不是句子的全部语法规则。

## 7.2 常见错误

| 错误表达 | 正确表达 | 原因 |
| :--- | :--- | :--- |
| ~~Did you went there?~~ | Did you **go** there? | did 后使用原形 |
| ~~I've went there.~~ | I've **gone** there. | 完成式使用 V3 |
| ~~I seen him yesterday.~~ | I **saw** him yesterday. | 一般过去时使用 V2 |
| ~~He has came home.~~ | He has **come** home. | come 的 V3 是 come |
| ~~The window was broke.~~ | The window was **broken**. | 被动式使用 V3 |
| ~~She should have went.~~ | She should have **gone**. | 情态完成结构使用 V3 |

这些错误可以分成两类：

### 第一类：语法结构选择错误

| 错误表达 | 正确表达 |
| :--- | :--- |
| ~~Did you went?~~ | Did you **go**? |

问题不在于是否记住了 `went`，而在于没有正确处理 `did + V1`。

### 第二类：动词形态选择错误

| 错误表达 | 正确表达 |
| :--- | :--- |
| ~~I've went.~~ | I've **gone**. |

句子已经使用完成式，但没有选择 `go` 的过去分词 `gone`。

区分错误来源，有助于后续练习。

# 8. 综合对话：一个忙碌的早晨

**场景：** Daniel 早上起晚了，赶到公司后向 Emma 解释发生了什么。

| 角色 | 对话内容 |
|:---:|---|
| **Emma** | **You look tired. What happened?**<br>你看起来很累。怎么了？ |
| **Daniel** | **I usually wake up at seven, but I woke up late today.**<br>我通常七点醒来，但今天起晚了。 |
| **Emma** | **What time did you get up?**<br>你几点起来的？ |

| **Emma** | **Has he seen it?**<br>他看到了吗？ |
| **Daniel** | **Yeah, he's already replied.**<br>看到了，他已经回复了。 |
| **Emma** | **At least you made it here.**<br>至少你还是赶到了。 |
