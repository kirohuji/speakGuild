# 07｜易混形式与特殊变化

学完前面的几种主要变化以后，大部分不规则动词已经有了基本框架。

真正容易出错的，往往是少数特殊动词。

有些动词三种形式拼写一样，读音却发生变化。

有些动词长得非常接近，却属于两套完全不同的变化。

还有一些动词存在两个过去式或两个过去分词，英式英语和美式英语的习惯也可能不同。

这一篇集中整理这些容易混淆的地方，并通过实际语境理解它们的意义和用法。


# read

这是最典型的特殊动词之一。

| 形式 | 拼写 | 发音 |
|---|---|---|
| 原形 | read | /riːd/ |
| 过去式 | read | /red/ |
| 过去分词 | read | /red/ |

三个形式的拼写完全相同。

真正区分它们的是：

**读音 + 句子结构**


### 原形 read /riːd/

**I read before bed every night.**  
我每天晚上睡前都会看书。

**I want to read this book.**  
我想读这本书。

这里读：

`/riːd/`


### 过去式 read /red/

**I read the whole book yesterday.**  
我昨天把整本书读完了。

虽然拼写还是 read，但这里必须读：

`/red/`

时间表达：

`yesterday`

也已经告诉你这是过去事件。


### 过去分词 read /red/

**I've read this book before.**  
这本书我以前读过。

这里前面有：

`have`

所以 read 是过去分词，同样读：

`/red/`


### 一个很实用的判断

看到：

`I read...`

单独这一小段并不能立刻知道读 /riːd/ 还是 /red/。

要继续看上下文：

`I read before bed every night.`

现在习惯：

`/riːd/`

`I read it last night.`

过去事件：

`/red/`

英语里偶尔会出现这种拼写无法完整表达语法信息的情况。

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **read aloud**<br>大声朗读 | 强调发出声音 |
| **例句** | **Please read the instructions aloud.**<br>请把说明大声读出来。<br><br>**She read the poem aloud to the class yesterday.**<br>她昨天在课堂上朗读了这首诗。 |
| **read through**<br>从头到尾认真读一遍 | 常用于检查草稿、报告或说明，强调完整通读。 |

| **read up on**<br>查阅资料 | 深入了解某个话题 |
| **例句** | **I need to read up on the new rules.**<br>我需要查阅资料了解新规定。<br><br>**He read up on the city before travelling.**<br>出发前他查了不少这座城市的资料。 |

# lie 与 lay

这一组需要把两个独立动词分开。

### lie：躺

`lie — lay — lain`

### lay：放置

`lay — laid — laid`

两套形式刚好互相交叉，所以特别容易混淆。


# lie（躺）

这里的 lie 表示：

躺、平放、处于某个位置

它通常不直接接宾语。


### lie

**I usually lie on the sofa after dinner.**  
我吃完晚饭通常会躺在沙发上。

**Just lie down for a while.**  
躺一会儿吧。

常见表达：

**lie down**  
躺下

**lie on the bed**  
躺在床上


### lay

lie 的过去式是：

`lay`

**I lay awake for hours last night.**  
我昨晚躺着几个小时都没睡着。

**He lay on the floor without moving.**  
他躺在地上一动不动。

这个 lay 很容易让人误以为是另一个动词 lay。

只能通过句子结构判断。


### lain

过去分词是：

`lain`

**He had lain there for hours before anyone found him.**  
在有人发现他以前，他已经在那里躺了几个小时。

**The book had lain untouched for years.**  
那本书多年无人翻动。

lain 在现代日常口语中的频率不算特别高，但仍然属于标准形式。


## 高频搭配

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **lie down**<br>躺下 | 描述主体自己的动作 |
| **例句** | **You should lie down for a while.**<br>你应该躺一会儿。<br><br>**I lay down as soon as I got home.**<br>我一到家就躺下了。 |
| **lie awake**<br>躺着睡不着 | 躺着睡不着 |
| **例句** | **I often lie awake when I’m worried.**<br>我有心事时常常躺着睡不着。<br><br>**She lay awake thinking about the interview.**<br>她躺着没睡，一直想着面试的事。 |
| **lie untouched**<br>长期放着没人碰 | 长期放着没人碰 |
| **例句** | **The papers have lain untouched for months.**<br>那些文件已经好几个月没人动过了。<br><br>**The old piano lay untouched in the corner.**<br>那架旧钢琴一直搁在角落里没人碰。 |

# lay

lay 表示：

把某样东西放下、摆放

它通常需要宾语。


### lay

**Lay the book on the table.**  
把书放在桌上。

这里必须有：

`the book`

因为是“把某样东西放到某处”。


### laid

**She laid the baby on the bed.**  
她把婴儿放到了床上。

**I laid the papers on his desk.**  
我把文件放在了他的桌上。


### laid

**The table had already been laid for dinner.**  
晚餐的餐桌已经摆好了。

常见表达：

`lay the table`

表示摆餐具、准备餐桌。


## 高频搭配

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **lay something down**<br>把某物放下 | 也可表示提出规则 |
| **例句** | **Lay your bags down by the door.**<br>把包放在门边吧。<br><br>**She laid the box down carefully.**<br>她小心地放下箱子。 |
| **lay the table**<br>摆餐具 | 英式英语常见 |
| **例句** | **Could you lay the table for dinner?**<br>你能摆一下晚餐的餐具吗？<br><br>**The table had already been laid.**<br>餐桌已经摆好了。 |
| **lay the foundations for**<br>为后续发展奠定基础 | 为后续发展奠定基础 |
| **例句** | **This course will lay the foundations for further study.**<br>这门课程会为进一步学习打下基础。<br><br>**Their early work laid the foundations for the project.**<br>他们早期的工作为这个项目奠定了基础。 |

# lie 与 lay 的区别

看动作有没有直接作用到一个东西上。

### lie

`He **lay** on the bed.`

是他自己躺在那里。

### lay

`He **laid** the book on the bed.`

是他把书放到了那里。

可以用两个核心句子记：

`I **lay** down.`

`I **laid** it down.`

第二句多了一个：

`it`

这个宾语很关键。


# lie（说谎）

英语里还有一个完全不同的 lie：

`lie — lied — lied`

表示：

说谎

例如：

**He lied to me.**  
他骗了我。

**He's lied about this before.**  
这件事他以前就撒过谎。

所以英语实际上有：

**lie — lay — lain**  
躺

和：

**lie — lied — lied**  
说谎

两个不同的动词。


## 高频搭配

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **lie to someone**<br>对某人说谎 | 对某人说谎 |
| **例句** | **Don’t lie to me about what happened.**<br>不要对我隐瞒真相、编造经过。<br><br>**He admitted he had lied to his parents.**<br>他承认自己对父母撒过谎。 |
| **lie about something**<br>就某件事情说谎 | 就某件事情说谎 |
| **例句** | **She lied about her age.**<br>她谎报了年龄。<br><br>**He’s never lied about his experience.**<br>他从来没有在经历上撒过谎。 |

# hang 的两种变化

hang 是一个很典型的“意义影响词形”的动词。

通常：

`hang — hung — hung`

表示悬挂。

但涉及：

绞死某人

传统标准形式通常是：

`hang — hanged — hanged`


# hang（悬挂）

表示普通的悬挂。

**I hung my coat by the door.**  
我把外套挂在了门边。

**The picture was hung above the fireplace.**  
那幅画挂在壁炉上方。

**I've hung the washing outside.**  
我已经把衣服晾到外面了。

日常生活里绝大多数 hang 都使用：

`hung`


# hang（绞刑）

涉及司法处决或绞死时，经常使用：

`hanged`

**The prisoner was hanged for murder.**  
那名囚犯因谋杀被处以绞刑。

这里保留下来的是一个非常特殊的历史用法。

所以：

`The picture was hung.`

而：

`The man was hanged.`

这种区别在现代英语中仍然存在。

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **hang up**<br>挂起来 | 挂断电话 |
| **例句** | **Hang up your coat when you come in.**<br>进门后把外套挂起来。<br><br>**She hung up before I could reply.**<br>我还没来得及回答，她就挂了电话。 |
| **hang on**<br>等一下 | 坚持住 |
| **例句** | **Hang on, I’ll check the address.**<br>等一下，我查查地址。<br><br>**We hung on until help arrived.**<br>我们一直坚持到救援到来。 |
| **hang around**<br>在附近闲待、徘徊 | 在附近闲待、徘徊 |
| **例句** | **We hung around after the concert.**<br>演唱会结束后我们还在附近待了一会儿。<br><br>**Don’t hang around outside in the cold.**<br>天冷，别一直在外面待着。 |

# bear 的两种分词

bear 的变化是：

`bear — bore — borne / born`

过去分词有：

`borne`

和：

`born`

两个常见形式。


# bear

bear 可以表示：

承受、承担、携带、产生

例如：

**I can't bear the noise.**  
我受不了这个声音。

过去式：

**He bore the pain without complaining.**  
他忍受着疼痛，没有抱怨。

过去分词：

**The cost has been borne by the company.**  
费用由公司承担。

常见搭配：

`bear responsibility`

`bear the cost`

`bear the burden`


# born

born 主要用于：

出生

最常见结构：

`be born`

**I was born in Shanghai.**  
我出生在上海。

**She was born in 2001.**  
她出生于2001年。

这里的 born 已经形成了高度固定的用法。

如果 bear 表示其他意义，通常使用：

`borne`

例如：

`The expense was borne by the government.`

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **bear the cost**<br>承担费用 | 承担费用 |
| **例句** | **The company will bear the cost of repairs.**<br>公司会承担维修费用。<br><br>**The costs were borne by the organiser.**<br>这些费用由组织方承担。 |
| **bear in mind**<br>牢记、考虑到 | 牢记、考虑到 |
| **例句** | **Bear in mind that prices may change.**<br>请记住价格可能会变化。<br><br>**I bore that warning in mind when deciding.**<br>做决定时我记着那项提醒。 |
| **can’t bear doing / to do**<br>无法忍受某事 | 无法忍受某事 |
| **例句** | **I can’t bear waiting in long queues.**<br>我受不了排很长的队。<br><br>**She couldn’t bear to watch.**<br>她不忍心继续看下去。 |

# beat

这一组也很特殊：

`beat — beat — beaten`

过去式和原形一样。

过去分词多了：

`-en`


### beat

**They often beat us.**  
他们经常赢我们。


### beat

**They beat us yesterday.**  
他们昨天赢了我们。

这个 beat 是过去式。

拼写和原形完全一样，读音也一样。


### beaten

**We've never beaten them before.**  
我们以前从来没赢过他们。

**He was badly beaten.**  
他遭到了严重殴打。

过去分词通常使用：

`beaten`

| **例句** | **She beat me at chess again.**<br>她下棋又赢了我。<br><br>**I’ve never beaten him at tennis.**<br>我打网球从来没赢过他。 |
| **beat a record**<br>打破纪录 | 打破纪录 |

# get

get 是高频动词里很重要的一个特殊情况。

### 英式英语

通常：

`get — got — got`

### 美式英语

经常：

`get — got — gotten`

但 got 和 gotten 在美式英语里也有一定意义分工。


# got 与 gotten

#### I've got...

经常表达当前拥有：

**I've got a car.**  
我有一辆车。

**I've got a problem.**  
我有个问题。

这种 have got 已经非常接近：

`have`


#### I've gotten...

更容易表达获得、变化、发展过程：

**I've gotten much better at English.**  
我的英语已经进步了很多。

**Things have gotten worse.**  
情况变得更糟了。

**He's gotten a new job.**  
他找到了一份新工作。

美式英语里这种 gotten 非常自然。

证明

`proved`

**proved**

`The method has been **proven** effective.`

`proven method`

`proven ability`

`proven record`

**It's a proven method.**

# dream

dream 的过去式和过去分词都有两种常见形式：

**dreamed**  
dreamt

所以可以写：

`dream — dreamed — dreamed`

也可以：

`dream — dreamt — dreamt`


## dreamed

美式英语尤其常见：

**I dreamed about you last night.**  
我昨晚梦到你了。


## dreamt

英式英语里很常见：

`I **dreamt** about you last night.`

两者都正确。

这里属于语言变体。

不需要为了追求“唯一正确形式”强行淘汰其中一个。

`learn — learned — learned`

和：

`learn — learnt — learnt`

美式英语更倾向：

`learned`

英式英语两种都能见到，learnt 很常见。

例如：

`I **learned** a lot from him.`

`I **learnt** a lot from him.`

都可以表示：

我从他那里学到了很多。


## 高频搭配

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **learn from**<br>从经验或他人那里学习 | 从经验或他人那里学习 |
| **例句** | **We learn from our mistakes.**<br>我们从错误中学习。<br><br>**I learnt a lot from her feedback.**<br>我从她的反馈中学到了很多。 |
| **learn to do something**<br>学会做某事 | 学会做某事 |
| **例句** | **She’s learning to drive.**<br>她正在学开车。<br><br>**He learned to cook during college.**<br>他上大学时学会了做饭。 |

# burn

`burn — burned — burned`

或者：

`burn — burnt — burnt`

例如：

`The house **burned** down.`

`The house **burnt** down.`

两种都存在。

但 burnt 还经常作为形容词：

**burnt toast**  
烤焦的吐司

**burnt wood**  
烧焦的木头


## 高频搭配

| 搭配与释义 | 使用见解与例句 |

| **burn out**<br>耗尽精力 | 烧坏 |

# spell、smell、spill

英式英语里经常能看到：

`spell — spelt — spelt`

`smell — smelt — smelt`

`spill — spilt — spilt`

同时：

`spelled`

`smelled`

`spilled`

也都很常见。

美式英语通常更偏向：

**spelled**  
smelled
`spilled`

这种差异很适合理解成：

同一个动词存在两套历史上都保留下来的形式。

`a well-lighted street`

# fit

fit 的变化存在明显的地域和意义差异。

美式英语里：

`fit — fit — fit`

很常见。

**The key fit the lock perfectly.**  
那把钥匙正好适合这把锁。

英式英语里也常见：

`fitted`

尤其涉及安装时：

**They fitted a new kitchen.**  
他们安装了一套新厨房。

所以 fitted 在“安装设备、配装”这样的意义下尤其重要。

| --- | --- |

| **be fitted with**<br>安装有某种设备 | 安装有某种设备 |

# find 与 found

这个地方非常容易因为拼写产生误会。

#### find

`find — found — found`

表示：

找到、发现

`I **found** my keys.`


但英语还有一个独立动词：

#### found

表示：

创立、建立

它的变化是：

`found — founded — founded`

例如：

**The company was founded in 1998.**  
这家公司成立于1998年。

所以：

`found`

既可能是 find 的过去式：

`I found it.`

也可能是另一个动词的原形：

`They want to found a company.`


## 高频搭配

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **found a company**<br>创办公司 | 创办公司 |
| **例句** | **They plan to found a small company.**<br>他们计划创办一家小公司。<br><br>**She founded the company in 2015.**<br>她在2015年创办了这家公司。 |
| **be founded on**<br>建立在某种原则或依据之上 | 建立在某种原则或依据之上 |
| **例句** | **Trust must be founded on honesty.**<br>信任必须建立在诚实的基础上。<br><br>**The theory was founded on limited evidence.**<br>这一理论建立在有限的证据之上。 |

# 特殊形式的规律

### 拼写一样，语法身份仍然可能不同

例如：

`read — read — read`

`beat — beat — beaten`

`cut — cut — cut`

英语的动词形式不能永远只靠拼写判断。


### 意义变化有时会带来不同形式

最典型的是：

`hang — hung — hung`

普通悬挂。

`hang — hanged — hanged`

绞死。

还有：

`bear — bore — borne`

承受、承担。

`be born`

出生。

这种区别数量不多，但都很稳定。


### 英式和美式英语会保留不同形式

例如：

`learned / learnt`

`dreamed / dreamt`

`burned / burnt`

`spilled / spilt`

两种形式同时存在时，不需要把其中一种当成错误。

如果长期以美式英语为主，可以更稳定地使用：

**learned**  
dreamed
**burned**  
spilled

阅读英式英语时，也需要认识：

**learnt**  
dreamt
**burnt**  
spilt


### 派生词不一定和眼前看到的词属于同一个动词

例如：

`find → found → found`

但：

`found → founded → founded`

又如：

`fall → fell → fallen`

而：

`fell → felled → felled`

英语里有一些形式碰巧重合。

理解句子的意义以后，通常很容易分开。


# 综合 Case｜山间旅馆

| 情节 | 英文表达 |
| --- | --- |
| 那天晚上，我很早就上床了，却一直没有睡着。 | I **lay** awake for nearly two hours. |
| 窗外的风越来越大。 | The wind outside was growing stronger. |
| 我拿起一本书读了几页。 | I **read** a few pages of a book. |
| 大概十一点，我听见楼下传来一声巨响。 | At around eleven, I heard a loud crash downstairs. |
| 我从床上起来，走到走廊。 | I got out of bed and stepped into the corridor. |
| 墙上的一幅画掉了下来。 | **A picture that had been hung on the wall was lying on the floor.** |
| 旅馆老板也醒了。 | The noise had **woken** him up. |
| 我们一起下楼。 | We went downstairs together. |
| 他把画重新放到桌上。 | He **laid** the picture on the table. |
| 然后我注意到画后面有一扇很小的门。 | Then I noticed a small door behind where the picture had been. |
| 老板的脸色立刻变了。 | The owner’s expression changed immediately. |
| 他说那扇门已经很多年没人打开过。 | He said the door hadn’t been opened for years. |
| 钥匙早就丢了。 | The key had been lost long ago. |
| 可门现在开着。 | Yet the door was open now. |
| 我们站在那里看了几秒。 | We stood there staring at it for a few seconds. |
| 老板拿起手电筒。 | He **lit** the passage with a flashlight. |
| 门后是一条很窄的楼梯。 | Behind the door was a narrow staircase. |
| 我们往下走。 | We went down the stairs. |
| 地下室里放着几个旧箱子。 | Several old boxes stood in the basement. |
| 其中一个已经被打开。 | One of them had already been opened. |
| 老板说那些箱子从他父亲去世以后就一直放在那里。 | **They had lain there untouched for more than twenty years.** |
| 我问他里面装着什么。 | I asked him what was inside. |
| 他没有回答。 | He didn’t answer. |
| 过了一会儿，他说： | After a moment, he said: |
| “我父亲生前从来不允许我打开它们。” | “My father never allowed me to open them.” |
| 他曾经问过原因。 | He had **asked** his father about them once. |
| 但父亲撒了谎。 | His father had **lied** to him. |
| 他说里面只是旧衣服。 | He said they contained only old clothes. |
| 我们打开最大的那个箱子。 | We opened the largest box. |
| 里面没有衣服。 | There were no clothes inside. |
| 只有一叠文件。 | There was only a stack of documents. |
| 第一页写着一家公司的名字。 | The first page bore the name of a company. |
| 那家公司成立于四十年前。 | **The company had been founded forty years earlier.** |
| 而创办人的名字，正是旅馆老板的父亲。 | The founder was the owner’s father. |
| 老板读完第一页以后，站在那里很久没动。 | He **read** the first page twice. |
| 这一次的 read 读作： | /red/ |
| 因为它描述的是刚刚完成的过去动作。 | It describes an action completed in the past. |
| 他最后抬起头说： | At last, he looked up and said: |
| “我想我知道我父亲为什么一直把这里锁着了。” | “I think I know why my father always kept this place locked.” |

## Case 动词与特殊形式回顾

这一段里出现了很多容易混淆的形式：

**lay awake**  
**read** /red/
**had been hung**  
had **woken**
**laid the picture**  
**lit** the passage
**had lain there**  
had **lied**
`had been **founded**`

尤其值得放在一起看的是：

`lie — lay — lain`

`lay — laid — laid`

`lie — lied — lied`

这三组外形非常接近，但各自承担完全不同的意义。

同样：

**read /riːd/**  
read /red/

需要依靠时态和上下文判断。

这些特殊变化数量有限。

真正值得做的是在实际句子里反复遇见它们，直到看到：

`has lain`

`laid it down`

`has proven`

`was born`

`was hanged`

时能够直接识别，而不需要先在脑中重新背一次变化表。
