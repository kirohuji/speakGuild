
# 07｜易混形式与特殊变化

## 1. 认识特殊变化的不规则动词

学完前面几种主要变化类型以后，大部分不规则动词已经有了基本框架。真正容易出错的，往往是少数**拼写相近、读音不同、意义不同或存在多种变化形式**的动词。

这些特殊情况主要可以分为四类：

| 类型 | 典型动词 | 需要注意的地方 |
| --- | --- | --- |
| 拼写相同，读音不同 | read – read – read | 过去式、过去分词的读音与原形不同 |
| 形式相近，实际是不同动词 | lie / lay、find / found、fall / fell | 不能只凭拼写判断词义和语法身份 |
| 意义不同，变化形式不同 | hang、bear | 词义会影响过去式或过去分词的选择 |
| 存在两套常见变化 | get、dream、learn、burn、spell 等 | 英式英语、美式英语或使用习惯有所不同 |

下面按动词逐一整理，重点比较**三种形式、实际例句和容易混淆的用法**。

---

## 2. read – read – read

**基本意义**：阅读、朗读。

| 形式 | 拼写 | 发音 |
| --- | --- | --- |
| V1 原形 | read | /riːd/ |
| V2 过去式 | read | /red/ |
| V3 过去分词 | read | /red/ |

| 例句 | 形式与结构 |
| --- | --- |
| **I read before bed every night.**<br>我每天晚上睡前都会看书。 | 原形：/riːd/ |
| **I want to read this book.**<br>我想读这本书。 | 原形：/riːd/ |
| **I read the whole book yesterday.**<br>我昨天把整本书读完了。 | 过去式：/red/ |
| **I've read this book before.**<br>这本书我以前读过。 | 过去分词：/red/ |

**使用注意**：**read** 的三种形式拼写完全相同，但读音不同。看到 `I read...` 时，不能只凭拼写判断时态，需要结合时间状语和句子结构。`every night` 通常表示现在的习惯，`yesterday` 表示过去事件，`have + read` 则使用过去分词。

---

## 3. lie – lay – lain（躺）

**基本意义**：躺、平放、处于某个位置。

| 形式 | 动词 | 主要意义 |
| --- | --- | --- |
| V1 原形 | lie | 躺 |
| V2 过去式 | lay | 躺了 |
| V3 过去分词 | lain | 已经躺着、一直处于某位置 |

| 例句 | 形式与结构 |
| --- | --- |
| **I usually lie on the sofa after dinner.**<br>我吃完晚饭通常会躺在沙发上。 | 原形 |
| **The cat lies under the table.**<br>猫躺在桌子下面。 | 原形 |
| **I lay on the bed for hours last night.**<br>我昨晚在床上躺了几个小时。 | 过去式 |
| **He lay on the floor without moving.**<br>他躺在地上一动不动。 | 过去式 |
| **He had lain there for hours before anyone found him.**<br>在有人发现他以前，他已经在那里躺了几个小时。 | 过去分词 |
| **The book had lain on the table for years.**<br>那本书在桌上放了好几年。 | 过去分词 |

**使用注意**：表示“躺”的 **lie** 通常不直接接宾语。它的过去式是 `lay`，容易与另一个表示“放置”的动词 `lay` 混淆。`lain` 在现代日常口语中不算特别高频，但仍然是标准过去分词。

---

## 4. lay – laid – laid（放置）

**基本意义**：把某样东西放下、摆放。

| 例句 | 形式与结构 |
| --- | --- |
| **Lay the book on the table.**<br>把书放在桌上。 | 原形 |
| **She laid the baby on the bed.**<br>她把婴儿放到了床上。 | 过去式 |
| **I laid the papers on his desk.**<br>我把文件放在了他的桌上。 | 过去式 |
| **The table had already been laid for dinner.**<br>晚餐的餐桌已经摆好了。 | 过去分词（被动） |

**使用注意**：**lay** 表示“把某物放到某处”，通常需要直接宾语，例如 `lay the book on the table`。它的过去式和过去分词都是 `laid`，而不是 `lay`。

---

## 5. lie – lied – lied（说谎）

**基本意义**：说谎、撒谎。

| 例句 | 形式与结构 |
| --- | --- |
| **Don't lie to me.**<br>不要对我撒谎。 | 原形 |
| **He lied to me.**<br>他骗了我。 | 过去式 |
| **He's lied about this before.**<br>这件事他以前就撒过谎。 | 过去分词 |

**使用注意**：表示“说谎”的 **lie** 是另一个独立动词，采用规则变化 `lie – lied – lied`，不能与表示“躺”的 `lie – lay – lain` 混为一谈。

---

## 6. hang – hung – hung / hanged – hanged

**基本意义**：悬挂；在特定语境中也表示绞死。

| 变化形式 | 主要意义 | 使用场景 |
| --- | --- | --- |
| hang – hung – hung | 悬挂、挂起 | 日常生活中的普通悬挂 |
| hang – hanged – hanged | 绞死、处以绞刑 | 传统司法处决等语境 |

| 例句 | 形式与结构 |
| --- | --- |
| **I hung my coat by the door.**<br>我把外套挂在了门边。 | 过去式：hung |
| **The picture was hung above the fireplace.**<br>那幅画挂在壁炉上方。 | 过去分词：hung |
| **I've hung the washing outside.**<br>我已经把衣服晾到外面了。 | 过去分词：hung |
| **The prisoner was hanged for murder.**<br>那名囚犯因谋杀被处以绞刑。 | 过去分词：hanged |

**使用注意**：日常生活里绝大多数 **hang** 都使用 `hung`。涉及绞刑时，传统标准形式通常是 `hanged`。因此，`The picture was hung.` 与 `The man was hanged.` 使用不同形式。

---

## 7. bear – bore – borne / born

**基本意义**：承受、承担、携带、产生；`born` 主要用于出生相关表达。

| 形式 | 主要意义 | 使用场景 |
| --- | --- | --- |
| bear | 承受、承担等 | 原形 |
| bore | 承受了、承担了等 | 过去式 |
| borne | 已承受、已承担等 | 一般意义的过去分词 |
| born | 出生 | 常用于 `be born` |

| 例句 | 形式与结构 |
| --- | --- |
| **I can't bear the noise.**<br>我受不了这个声音。 | 原形 |
| **He bore the pain without complaining.**<br>他忍受着疼痛，没有抱怨。 | 过去式 |
| **The cost has been borne by the company.**<br>费用由公司承担。 | 过去分词：borne |
| **I was born in Shanghai.**<br>我出生在上海。 | 固定结构：be born |
| **She was born in 2001.**<br>她出生于2001年。 | 固定结构：be born |

**使用注意**：**borne** 常用于承担费用、责任、负担等意义。**born** 则主要用于出生相关表达，最常见的是 `be born`。

---

## 8. beat – beat – beaten

**基本意义**：击败、打败；也可以表示殴打、打破纪录。

| 例句 | 形式与结构 |
| --- | --- |
| **They often beat us.**<br>他们经常赢我们。 | 原形 |
| **They beat us yesterday.**<br>他们昨天赢了我们。 | 过去式 |
| **We've never beaten them before.**<br>我们以前从来没赢过他们。 | 过去分词 |
| **He was badly beaten.**<br>他遭到了严重殴打。 | 过去分词（被动） |

**使用注意**：**beat** 的原形和过去式拼写、读音相同，过去分词则为 `beaten`。因此，`They beat us yesterday.` 使用过去式，而 `We've never beaten them.` 使用过去分词。

## 9. get – got – got / gotten

**基本意义**：得到、获得、变得；也可用于表达拥有。

| 变化形式 | 主要使用习惯 |
| --- | --- |
| get – got – got | 英式英语常见 |
| get – got – gotten | 美式英语常见 |

| 例句 | 形式与结构 |
| --- | --- |
| **I've got a car.**<br>我有一辆车。 | have got：表示拥有 |
| **I've got a problem.**<br>我有个问题。 | have got：表示当前状态 |
| **I've gotten much better at English.**<br>我的英语已经进步了很多。 | gotten：表示变化 |
| **Things have gotten worse.**<br>情况变得更糟了。 | gotten：表示变化 |
| **He's gotten a new job.**<br>他找到了一份新工作。 | gotten：表示获得 |

**使用注意**：英式英语通常使用 `got` 作为过去分词，美式英语经常使用 `gotten`。在美式英语中，`I've got...` 常表示当前拥有，而 `I've gotten...` 更容易强调获得或变化的过程。

## 10. prove – proved – proved / proven

**基本意义**：证明、证实。

| 形式 | 动词 |
| --- | --- |
| V1 原形 | prove |
| V2 过去式 | proved |
| V3 过去分词 | proved / proven |

| 例句 | 形式与结构 |
| --- | --- |
| **They proved that the theory was wrong.**<br>他们证明了这个理论是错误的。 | 过去式：proved |
| **The method has been proved effective.**<br>这种方法已经被证明有效。 | 过去分词：proved |
| **The method has been proven effective.**<br>这种方法已经被证明有效。 | 过去分词：proven |
| **It's a proven method.**<br>这是一个经过验证的方法。 | proven 作形容词 |

**使用注意**：**proved** 和 **proven** 都可以作为过去分词。`proven` 在现代英语中很常见。

## 11. show – showed – shown

**基本意义**：展示、出示、表明。

| 例句 | 形式与结构 |
| --- | --- |
| **I've shown you this before.**<br>我以前给你看过这个。 | 过去分词 |
| **The results are shown below.**<br>结果如下所示。 | 过去分词（被动） |

**使用注意**：**show** 的常见形式是 `show – showed – shown`。部分用法和方言中也能见到 `showed` 作为过去分词，但学习和输出时优先掌握 `shown` 更稳妥。

## 14. dream – dreamed / dreamt – dreamed / dreamt

**基本意义**：做梦、梦见；也可表示梦想。

| 变化形式 | 主要使用习惯 |
| --- | --- |
| dream – dreamed – dreamed | 美式英语尤其常见 |

| 例句 | 形式与结构 |
| --- | --- |
| **I dreamed about you last night.**<br>我昨晚梦到你了。 | 过去式：dreamed |
| **I dreamt about you last night.**<br>我昨晚梦到你了。 | 过去式：dreamt |

**使用注意**：**dreamed** 和 **dreamt** 都是正确形式，属于语言变体。不需要为了追求唯一形式而排除其中一种。

## 15. learn – learned / learnt – learned / learnt

**基本意义**：学习、学会、得知。

| 变化形式 | 主要使用习惯 |

**使用注意**：两种变化都可以使用。美式英语更倾向 `learned`，英式英语中 `learned` 和 `learnt` 都能见到，`learnt` 很常见。

## 24. find 与 found

**核心区别**：`found` 既可以是 **find** 的过去式和过去分词，也可以是另一个表示“创立”的动词原形。

| 动词三态 | 主要意义 | 例句 |
| --- | --- | --- |
| find – found – found | 找到、发现 | **I found my keys.**<br>我找到了钥匙。 |
| found – founded – founded | 创立、建立 | **The company was founded in 1998.**<br>这家公司成立于1998年。 |

**使用注意**：`I found it.` 中的 `found` 是 **find** 的过去式；`They want to found a company.` 中的 `found` 则是另一个动词的原形。两者虽然拼写相同，但意义和变化形式完全不同。

## 25. fall 与 fell

**核心区别**：`fell` 既可以是 **fall** 的过去式，也可以是另一个表示“砍倒”的动词原形。

| 动词三态 | 主要意义 | 例句 |
| --- | --- | --- |
| fall – fell – fallen | 掉落、倒下 | **The tree fell during the storm.**<br>那棵树在暴风雨中倒下了。 |
| fell – felled – felled | 砍倒 | **They felled several trees.**<br>他们砍倒了几棵树。 |

**使用注意**：`The tree fell.` 表示树自己倒下；`They felled the tree.` 表示有人把树砍倒。需要根据主语、宾语和句意区分。

## 28. 特殊形式的规律总结

### 拼写相同，不代表语法身份相同

| 动词三态 | 特殊之处 |
| --- | --- |
| read – read – read | 拼写相同，过去式和过去分词读音不同 |
| beat – beat – beaten | 原形和过去式相同，过去分词增加 `-en` |
| cut – cut – cut | 三种形式拼写和读音都相同 |

**使用注意**：不能永远只靠拼写判断动词形式。需要结合助动词、时间状语和句子结构。

### 意义不同，可能使用不同形式

| 动词形式 | 主要意义 |
| --- | --- |
| hang – hung – hung | 普通悬挂 |
| hang – hanged – hanged | 绞死、处以绞刑 |
| bear – bore – borne | 承受、承担 |
| be born | 出生 |

**使用注意**：这类区别数量不多，但具有相对稳定的使用习惯，适合结合具体语义记忆。

### 英式英语与美式英语的差异

| 动词 | 美式英语常见 | 英式英语也常见 |
| --- | --- | --- |
| learn | learned | learnt |
| dream | dreamed | dreamt |
| burn | burned | burnt |
| spell | spelled | spelt |
| smell | smelled | smelt |
| spill | spilled | spilt |

**使用注意**：两种形式同时存在时，不需要把其中一种当成错误。如果长期以美式英语为主，可以优先稳定使用 `learned`、`dreamed`、`burned`、`spelled`、`smelled`、`spilled`，同时认识英式英语中常见的其他形式。

### 拼写重合，不一定属于同一个动词

| 第一组动词 | 第二组动词 | 区别 |
| --- | --- | --- |
| find – found – found | found – founded – founded | 找到 / 创立 |
| fall – fell – fallen | fell – felled – felled | 掉落 / 砍倒 |
| lie – lay – lain | lay – laid – laid | 躺 / 放置 |
| lie – lay – lain | lie – lied – lied | 躺 / 说谎 |

**使用注意**：这些词虽然在拼写上出现交叉，但实际属于不同的动词或不同的意义。理解句子的动作关系以后，通常就能区分。

## 29. 综合场景｜山间旅馆

一个刮着大风的夜晚，Daniel 住进了一家山间旅馆。半夜发生的一件事，让他发现了旅馆主人一直不知道的秘密。

| 故事内容 |
| --- |
| **I lay in bed for nearly two hours that night.**<br>那天晚上，我在床上躺了将近两个小时。 |
| **The wind outside was growing stronger, so I read a few pages of a book.**<br>窗外的风越来越大，于是我拿起一本书读了几页。 |
| **At around eleven, I heard a loud crash downstairs.**<br>大概十一点，我听见楼下传来一声巨响。 |
| **I got out of bed and stepped into the corridor. A picture that had been hung on the wall was lying on the floor.**<br>我从床上起来，走到走廊，发现原本挂在墙上的一幅画掉在了地上。 |
| **The noise had woken the hotel owner. We went downstairs together.**<br>那阵响声也把旅馆老板吵醒了。我们一起下楼查看。 |
| **He laid the picture on the table. Then I noticed a small door behind where the picture had been.**<br>他把画放到桌上。然后我注意到，原本挂画的地方后面有一扇很小的门。 |
| **The owner's expression changed immediately. He said the door hadn't been opened for years.**<br>老板的脸色立刻变了。他说那扇门已经很多年没人打开过。 |
| **The key had been lost long ago, yet the door was open now.**<br>钥匙早就丢了，可门现在却开着。 |
| **We stood there staring at it for a few seconds. Then the owner picked up a flashlight and lit the passage.**<br>我们站在那里看了几秒。随后老板拿起手电筒，照亮了门后的通道。 |
| **Behind the door was a narrow staircase. We went down the stairs and found several old boxes in the basement.**<br>门后是一条很窄的楼梯。我们沿着楼梯走下去，在地下室发现了几个旧箱子。 |
| **One of the boxes had already been opened. The owner said they had lain there untouched for more than twenty years.**<br>其中一个箱子已经被打开。老板说那些箱子已经放在那里二十多年没人碰过了。 |
| **I asked him what was inside, but he didn't answer.**<br>我问他里面装着什么，但他没有回答。 |
| **After a moment, he said, "My father never allowed me to open them."**<br>过了一会儿，他说：“我父亲生前从来不允许我打开它们。” |
| **He had asked his father about the boxes once, but his father had lied to him.**<br>他曾经问过父亲那些箱子的事，但父亲对他撒了谎。 |
| **His father had said they contained only old clothes.**<br>父亲当时说，里面只是一些旧衣服。 |
| **We opened the largest box. There were no clothes inside, only a stack of documents.**<br>我们打开最大的那个箱子。里面没有衣服，只有一叠文件。 |
| **The first page bore the name of a company. The company had been founded forty years earlier.**<br>第一页写着一家公司的名字。那家公司成立于四十年前。 |
| **The founder was the owner's father.**<br>而公司的创办人，正是旅馆老板的父亲。 |
| **He read the first page twice and stood there without moving.**<br>老板把第一页读了两遍，然后站在那里很久没动。 |
| **At last, he looked up and said, "I think I know why my father always kept this place locked."**<br>最后，他抬起头说：“我想我知道我父亲为什么一直把这里锁着了。” |

### Case 动词与特殊形式回顾

| 故事中的表达 | 动词三态 | 形式与意义 |
| --- | --- | --- |
| **lay in bed** | lie – lay – lain | 过去式：躺 |
| **read a few pages** | read – read – read | 过去式：读作 /red/ |
| **had been hung** | hang – hung – hung | 过去分词：悬挂 |
| **had woken** | wake – woke – woken | 过去分词：叫醒 |
| **laid the picture** | lay – laid – laid | 过去式：放置 |
| **lit the passage** | light – lit – lit | 过去式：照亮 |
| **had lain there** | lie – lay – lain | 过去分词：一直处于某位置 |
| **had lied to him** | lie – lied – lied | 过去分词：说谎 |
| **bore the name** | bear – bore – borne | 过去式：带有、载有 |
| **had been founded** | found – founded – founded | 过去分词：创立 |
| **read the first page twice** | read – read – read | 过去式：读作 /red/ |

**重点回顾**：`lie – lay – lain`、`lay – laid – laid` 和 `lie – lied – lied` 外形非常接近，但意义完全不同；`read /riːd/` 与 `read /red/` 则需要根据时态判断读音。

这些特殊变化数量有限。真正值得做的是在实际句子里反复遇见它们，直到看到 `has lain`、`laid it down`、`has proven`、`was born`、`was hanged` 等表达时，能够直接识别其意义和结构，而不需要重新背诵变化表。
