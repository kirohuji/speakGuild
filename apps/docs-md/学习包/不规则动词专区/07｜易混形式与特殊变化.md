
# 07｜易混形式与特殊变化

## 1. 认识特殊变化的不规则动词

学完前面几种主要变化类型以后，大部分不规则动词已经有了基本框架。真正容易出错的，往往是少数**拼写相近、读音不同、意义不同或存在多种变化形式**的动词。

这些特殊情况主要可以分为四类：

| 类型 | 典型动词 | 需要注意的地方 |
| --- | --- | --- |
| 拼写相同，读音不同 | read – read – read | 过去式、过去分词的读音与原形不同 |
| 形式相近，实际是不同动词 | lie / lay、find / found、fall / fell | 不能只凭拼写判断词义和语法身份 |
| 意义不同，变化形式不同 | hang、bear | 词义会影响过去式或过去分词的选择 |
| 存在两套常见变化 | get、dream、learn、burn、spell 等 | 英式英语、美式英语或使用习惯有所不同 |

下面按动词逐一整理，重点比较**三种形式、实际例句和容易混淆的用法**。

## 2. read – read – read

**基本意义**：阅读、朗读。

| 形式 | 拼写 | 发音 |
| --- | --- | --- |
| V1 原形 | read | /riːd/ |
| V2 过去式 | read | /red/ |
| V3 过去分词 | read | /red/ |

| 例句 | 形式与结构 |
| --- | --- |
| **I read before bed every night.**<br>我每天晚上睡前都会看书。 | 原形：/riːd/ |
| **I want to read this book.**<br>我想读这本书。 | 原形：/riːd/ |
| **I read the whole book yesterday.**<br>我昨天把整本书读完了。 | 过去式：/red/ |
| **I've read this book before.**<br>这本书我以前读过。 | 过去分词：/red/ |

**使用注意**：**read** 的三种形式拼写完全相同，但读音不同。看到 `I read...` 时，不能只凭拼写判断时态，需要结合时间状语和句子结构。`every night` 通常表示现在的习惯，`yesterday` 表示过去事件，`have + read` 则使用过去分词。

### 高频搭配

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **read aloud**<br>大声朗读 | 强调把文字读出声音。<br><br>**Please read the instructions aloud.**<br>请把说明大声读出来。<br><br>**She read the poem aloud to the class yesterday.**<br>她昨天在课堂上朗读了这首诗。 |
| **read through**<br>从头到尾认真读一遍 | 常用于检查草稿、报告或说明。<br><br>**Could you read through my draft?**<br>你能通读一下我的草稿吗？<br><br>**I've read through the report twice.**<br>我已经把报告通读了两遍。 |
| **read up on**<br>查阅资料、深入了解 | 强调为了解某个话题而阅读资料。<br><br>**I need to read up on the new rules.**<br>我需要查阅资料了解新规定。<br><br>**He read up on the city before travelling.**<br>出发前他查了不少这座城市的资料。 |

## 3. lie – lay – lain（躺）

**基本意义**：躺、平放、处于某个位置。

| 形式 | 动词 | 主要意义 |
| --- | --- | --- |
| V1 原形 | lie | 躺 |
| V2 过去式 | lay | 躺了 |
| V3 过去分词 | lain | 已经躺着、一直处于某位置 |

| 例句 | 形式与结构 |
| --- | --- |
| **I usually lie on the sofa after dinner.**<br>我吃完晚饭通常会躺在沙发上。 | 原形 |
| **Just lie down for a while.**<br>躺一会儿吧。 | 原形 |
| **I lay awake for hours last night.**<br>我昨晚躺着几个小时都没睡着。 | 过去式 |
| **He lay on the floor without moving.**<br>他躺在地上一动不动。 | 过去式 |
| **He had lain there for hours before anyone found him.**<br>在有人发现他以前，他已经在那里躺了几个小时。 | 过去分词 |
| **The book had lain untouched for years.**<br>那本书多年无人翻动。 | 过去分词 |

**使用注意**：表示“躺”的 **lie** 通常不直接接宾语。它的过去式是 `lay`，容易与另一个表示“放置”的动词 `lay` 混淆。`lain` 在现代日常口语中不算特别高频，但仍然是标准过去分词。

### 高频搭配

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **lie down**<br>躺下 | 描述主体自己的动作。<br><br>**You should lie down for a while.**<br>你应该躺一会儿。<br><br>**I lay down as soon as I got home.**<br>我一到家就躺下了。 |
| **lie awake**<br>躺着睡不着 | 强调虽然躺着，但没有入睡。<br><br>**I often lie awake when I'm worried.**<br>我有心事时常常躺着睡不着。<br><br>**She lay awake thinking about the interview.**<br>她躺着没睡，一直想着面试的事。 |
| **lie untouched**<br>长期放着没人碰 | 常用于物品长期没有被使用或处理。<br><br>**The papers have lain untouched for months.**<br>那些文件已经好几个月没人动过了。<br><br>**The old piano lay untouched in the corner.**<br>那架旧钢琴一直搁在角落里没人碰。 |

## 4. lay – laid – laid（放置）

**基本意义**：把某样东西放下、摆放。

| 例句 | 形式与结构 |
| --- | --- |
| **Lay the book on the table.**<br>把书放在桌上。 | 原形 |
| **She laid the baby on the bed.**<br>她把婴儿放到了床上。 | 过去式 |
| **I laid the papers on his desk.**<br>我把文件放在了他的桌上。 | 过去式 |
| **The table had already been laid for dinner.**<br>晚餐的餐桌已经摆好了。 | 过去分词（被动） |

**使用注意**：**lay** 表示“把某物放到某处”，通常需要直接宾语，例如 `lay the book on the table`。它的过去式和过去分词都是 `laid`，而不是 `lay`。

### 高频搭配

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **lay something down**<br>把某物放下 | 也可以表示制定或提出规则。<br><br>**Lay your bags down by the door.**<br>把包放在门边吧。<br><br>**She laid the box down carefully.**<br>她小心地放下箱子。 |
| **lay the table**<br>摆餐具 | 英式英语常见表达。<br><br>**Could you lay the table for dinner?**<br>你能摆一下晚餐的餐具吗？<br><br>**The table had already been laid.**<br>餐桌已经摆好了。 |
| **lay the foundations for**<br>为后续发展奠定基础 | 常用于学习、项目或长期发展。<br><br>**This course will lay the foundations for further study.**<br>这门课程会为进一步学习打下基础。<br><br>**Their early work laid the foundations for the project.**<br>他们早期的工作为这个项目奠定了基础。 |

## 5. lie – lied – lied（说谎）

**基本意义**：说谎、撒谎。

| 例句 | 形式与结构 |
| --- | --- |
| **Don't lie to me.**<br>不要对我撒谎。 | 原形 |
| **He lied to me.**<br>他骗了我。 | 过去式 |
| **He's lied about this before.**<br>这件事他以前就撒过谎。 | 过去分词 |

**使用注意**：表示“说谎”的 **lie** 是另一个独立动词，采用规则变化 `lie – lied – lied`，不能与表示“躺”的 `lie – lay – lain` 混为一谈。

### 高频搭配

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **lie to someone**<br>对某人说谎 | 后面接被欺骗的人。<br><br>**Don't lie to me about what happened.**<br>不要对我隐瞒真相、编造经过。<br><br>**He admitted he had lied to his parents.**<br>他承认自己对父母撒过谎。 |
| **lie about something**<br>就某件事情说谎 | 后面接说谎涉及的事情。<br><br>**She lied about her age.**<br>她谎报了年龄。<br><br>**He's never lied about his experience.**<br>他从来没有在经历上撒过谎。 |

### lie 与 lay 的区别

| 动词三态 | 意义 | 典型例句 |
| --- | --- | --- |
| lie – lay – lain | 躺 | **I lay down.**<br>我躺下了。 |
| lay – laid – laid | 放置 | **I laid it down.**<br>我把它放下了。 |
| lie – lied – lied | 说谎 | **He lied to me.**<br>他对我撒了谎。 |

**判断关键**：`I lay down.` 表示“我自己躺下”，而 `I laid it down.` 表示“我把它放下”。第二句多了直接宾语 `it`，这是区分两种动词的重要线索。

## 6. hang – hung – hung / hanged – hanged

**基本意义**：悬挂；在特定语境中也表示绞死。

| 变化形式 | 主要意义 | 使用场景 |
| --- | --- | --- |
| hang – hung – hung | 悬挂、挂起 | 日常生活中的普通悬挂 |
| hang – hanged – hanged | 绞死、处以绞刑 | 传统司法处决等语境 |

| 例句 | 形式与结构 |
| --- | --- |
| **I hung my coat by the door.**<br>我把外套挂在了门边。 | 过去式：hung |
| **The picture was hung above the fireplace.**<br>那幅画挂在壁炉上方。 | 过去分词：hung |
| **I've hung the washing outside.**<br>我已经把衣服晾到外面了。 | 过去分词：hung |
| **The prisoner was hanged for murder.**<br>那名囚犯因谋杀被处以绞刑。 | 过去分词：hanged |

**使用注意**：日常生活里绝大多数 **hang** 都使用 `hung`。涉及绞刑时，传统标准形式通常是 `hanged`。因此，`The picture was hung.` 与 `The man was hanged.` 使用不同形式。

### 高频搭配

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **hang up**<br>挂起来；挂断电话 | 根据宾语和语境判断具体意义。<br><br>**Hang up your coat when you come in.**<br>进门后把外套挂起来。<br><br>**She hung up before I could reply.**<br>我还没来得及回答，她就挂了电话。 |
| **hang on**<br>等一下；坚持住 | 常见口语表达。<br><br>**Hang on, I'll check the address.**<br>等一下，我查查地址。<br><br>**We hung on until help arrived.**<br>我们一直坚持到救援到来。 |
| **hang around**<br>在附近闲待、徘徊 | 强调没有明确目的地停留。<br><br>**We hung around after the concert.**<br>演唱会结束后我们还在附近待了一会儿。<br><br>**Don't hang around outside in the cold.**<br>天冷，别一直在外面待着。 |

## 7. bear – bore – borne / born

**基本意义**：承受、承担、携带、产生；`born` 主要用于出生相关表达。

| 形式 | 主要意义 | 使用场景 |
| --- | --- | --- |
| bear | 承受、承担等 | 原形 |
| bore | 承受了、承担了等 | 过去式 |
| borne | 已承受、已承担等 | 一般意义的过去分词 |
| born | 出生 | 常用于 `be born` |

| 例句 | 形式与结构 |
| --- | --- |
| **I can't bear the noise.**<br>我受不了这个声音。 | 原形 |
| **He bore the pain without complaining.**<br>他忍受着疼痛，没有抱怨。 | 过去式 |
| **The cost has been borne by the company.**<br>费用由公司承担。 | 过去分词：borne |
| **I was born in Shanghai.**<br>我出生在上海。 | 固定结构：be born |
| **She was born in 2001.**<br>她出生于2001年。 | 固定结构：be born |

**使用注意**：**borne** 常用于承担费用、责任、负担等意义，例如 `bear responsibility`、`bear the cost`、`bear the burden`。**born** 则主要用于出生相关表达，最常见的是 `be born`。

### 高频搭配

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **bear the cost**<br>承担费用 | 常用于正式或商务语境。<br><br>**The company will bear the cost of repairs.**<br>公司会承担维修费用。<br><br>**The costs were borne by the organiser.**<br>这些费用由组织方承担。 |
| **bear in mind**<br>牢记、考虑到 | 提醒对方在判断时考虑某个因素。<br><br>**Bear in mind that prices may change.**<br>请记住价格可能会变化。<br><br>**I bore that warning in mind when deciding.**<br>做决定时我记着那项提醒。 |
| **can't bear doing / to do**<br>无法忍受某事 | 后面可以接动名词或不定式。<br><br>**I can't bear waiting in long queues.**<br>我受不了排很长的队。<br><br>**She couldn't bear to watch.**<br>她不忍心继续看下去。 |

## 8. beat – beat – beaten

**基本意义**：击败、打败；也可以表示殴打、打破纪录。

| 例句 | 形式与结构 |
| --- | --- |
| **They often beat us.**<br>他们经常赢我们。 | 原形 |
| **They beat us yesterday.**<br>他们昨天赢了我们。 | 过去式 |
| **We've never beaten them before.**<br>我们以前从来没赢过他们。 | 过去分词 |
| **He was badly beaten.**<br>他遭到了严重殴打。 | 过去分词（被动） |

**使用注意**：**beat** 的原形和过去式拼写、读音相同，过去分词则为 `beaten`。因此，`They beat us yesterday.` 使用过去式，而 `We've never beaten them.` 使用过去分词。

### 高频搭配

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **beat someone at something**<br>在比赛或活动中战胜某人 | 常用于体育、游戏和竞技活动。<br><br>**She beat me at chess again.**<br>她下棋又赢了我。<br><br>**I've never beaten him at tennis.**<br>我打网球从来没赢过他。 |
| **beat a record**<br>打破纪录 | 指超过原有成绩。<br><br>**He hopes to beat the school record.**<br>他希望打破学校纪录。<br><br>**The record was beaten last year.**<br>这项纪录去年被打破了。 |
| **beat yourself up**<br>过度自责 | 常见口语表达。<br><br>**Don't beat yourself up over one mistake.**<br>别因为一个错误就一直自责。<br><br>**I beat myself up about it for weeks.**<br>我为这件事自责了好几个星期。 |

## 9. get – got – got / gotten

**基本意义**：得到、获得、变得；也可用于表达拥有。

| 变化形式 | 主要使用习惯 |
| --- | --- |
| get – got – got | 英式英语常见 |
| get – got – gotten | 美式英语常见 |

| 例句 | 形式与结构 |
| --- | --- |
| **I've got a car.**<br>我有一辆车。 | have got：表示拥有 |
| **I've got a problem.**<br>我有个问题。 | have got：表示当前状态 |
| **I've gotten much better at English.**<br>我的英语已经进步了很多。 | gotten：表示变化 |
| **Things have gotten worse.**<br>情况变得更糟了。 | gotten：表示变化 |
| **He's gotten a new job.**<br>他找到了一份新工作。 | gotten：表示获得 |

**使用注意**：英式英语通常使用 `got` 作为过去分词，美式英语经常使用 `gotten`。在美式英语中，`I've got...` 常表示当前拥有，而 `I've gotten...` 更容易强调获得或变化的过程。

### 高频搭配

| 搭配与释义 | 使用见解与例句 |
| --- | --- |
| **get better**<br>情况或能力好转 | 可表示健康、能力或整体情况改善。<br><br>**Your pronunciation is getting better.**<br>你的发音正在进步。<br><br>**Things have gotten better recently.**<br>最近情况已经好转了。 |
| **get hold of**<br>设法联系或取得 | 可用于联系某人或拿到某物。<br><br>**I can't get hold of the manager.**<br>我联系不上经理。<br><br>**Have you got hold of the documents yet?**<br>你已经拿到文件了吗？ |
| **get used to + -ing / 名词**<br>逐渐习惯 | `to` 是介词，后面接名词或动名词。<br><br>**I'm getting used to working remotely.**<br>我正在逐渐习惯远程工作。<br><br>**She got used to the noise after a week.**<br>过了一周她就习惯了噪音。 |

## 12. wake – woke – woken

**基本意义**：醒来、叫醒。

| 例句 | 形式与结构 |
| --- | --- |
| **I woke up early.**<br>我很早醒了。 | 过去式：woke |
| **I've just woken up.**<br>我刚醒。 | 过去分词：woken |

**使用注意**：常见标准形式是 `wake – woke – woken`。尤其注意 `woke` 是过去式，`woken` 是过去分词。

### 高频搭配

| 搭配与释义 | 使用见解与例句 |
| --- | --- |

## 28. 特殊形式的规律总结

### 拼写相同，不代表语法身份相同

| 动词三态 | 特殊之处 |
| --- | --- |
| read – read – read | 拼写相同，过去式和过去分词读音不同 |
| beat – beat – beaten | 原形和过去式相同，过去分词增加 `-en` |
| cut – cut – cut | 三种形式拼写和读音都相同 |

**使用注意**：不能永远只靠拼写判断动词形式。需要结合助动词、时间状语和句子结构。

### 意义不同，可能使用不同形式

| 动词形式 | 主要意义 |
| --- | --- |
| hang – hung – hung | 普通悬挂 |
| hang – hanged – hanged | 绞死、处以绞刑 |
| bear – bore – borne | 承受、承担 |
| be born | 出生 |

**使用注意**：这类区别数量不多，但具有相对稳定的使用习惯，适合结合具体语义记忆。

### 英式英语与美式英语的差异

| 动词 | 美式英语常见 | 英式英语也常见 |
| --- | --- | --- |
| learn | learned | learnt |
| dream | dreamed | dreamt |
| burn | burned | burnt |
| spell | spelled | spelt |
| smell | smelled | smelt |
| spill | spilled | spilt |

**使用注意**：两种形式同时存在时，不需要把其中一种当成错误。如果长期以美式英语为主，可以优先稳定使用 `learned`、`dreamed`、`burned`、`spelled`、`smelled`、`spilled`，同时认识英式英语中常见的其他形式。

### 拼写重合，不一定属于同一个动词

| 第一组动词 | 第二组动词 | 区别 |
| --- | --- | --- |
| find – found – found | found – founded – founded | 找到 / 创立 |
| fall – fell – fallen | fell – felled – felled | 掉落 / 砍倒 |
| lie – lay – lain | lay – laid – laid | 躺 / 放置 |
| lie – lay – lain | lie – lied – lied | 躺 / 说谎 |

**使用注意**：这些词虽然在拼写上出现交叉，但实际属于不同的动词或不同的意义。理解句子的动作关系以后，通常就能区分。

# 三种形式相同的动词


## 1. 认识 A–A–A 型不规则动词


这一类不规则动词的原形（V1）、过去式（V2）与过去分词（V3）在拼写上相同。


| V1 原形 | V2 过去式 | V3 过去分词 | 主要意思 |
| --- | --- | --- | --- |
| cut | cut | cut | 切、割 |
| put | put | put | 放置 |
| hit | hit | hit | 击中 |
| hurt | hurt | hurt | 受伤、疼痛 |
| let | let | let | 允许、让 |
| set | set | set | 设定 |
| shut | shut | shut | 关闭 |
| split | split | split | 分割 |
| spread | spread | spread | 传播、铺开 |
| cost | cost | cost | 花费 |
| burst | burst | burst | 爆裂 |
| broadcast | broadcast | broadcast | 广播 |


**词形相同不等于语法功能相同。** 例如 `I cut`、`I cut yesterday`、`I have cut` 中的 `cut`，分别要结合句子结构理解其形式。


下面逐一比较每个动词在不同结构中的使用。


---


## 2. cut – cut – cut


**基本意义**：切、割；也可表示削减或中断。


| 例句 | 形式与结构 |
| --- | --- |
| **I usually cut the vegetables before cooking.**<br>我通常在做饭前先切好蔬菜。 | 原形 |
| **He cut his hand while opening the box.**<br>他打开盒子时割伤了手。 | 过去式 |
| **They've cut the budget by 20%.**<br>他们已经削减了20%的预算。 | 过去分词 |
| **The cable was cut during construction.**<br>电缆在施工期间被切断了。 | 过去分词（被动） |


**使用注意**：**cut** 的三种形式在拼写和发音上都相同。`cut something in half` 表示切成两半，`cut something into pieces` 表示切成若干块。


---


## 3. put – put – put


**基本意义**：把某物放到某处，或使其处于某种状态。


| 例句 | 形式与结构 |
| --- | --- |
| **I usually put my phone beside my bed.**<br>我通常把手机放在床边。 | 原形 |
| **She put the documents on my desk yesterday.**<br>她昨天把文件放在了我的桌上。 | 过去式 |
| **I've already put everything away.**<br>我已经把所有东西都收好了。 | 过去分词 |
| **The chairs were put outside.**<br>椅子被搬到了外面。 | 过去分词（被动） |


**使用注意**：**put** 通常需要宾语及位置、方向或状态信息，例如 `put the book on the table`。过去发生的放置动作仍用 `put`，而不是 `putted`。


---


## 4. hit – hit – hit


**基本意义**：击中、撞击；也可表示达到某个数值或目标。


| 例句 | 形式与结构 |
| --- | --- |
| **Don't hit the table.**<br>别敲桌子。 | 原形 |
| **The ball hit the window yesterday.**<br>昨天球击中了窗户。 | 过去式 |
| **The area has been hit by heavy rain.**<br>这一地区受到了暴雨影响。 | 过去分词 |
| **The window was hit by a stone.**<br>窗户被石头击中了。 | 过去分词（被动） |


**使用注意**：**hit** 可以直接接被击中的对象，如 `hit the window`。在一般过去时中不发生词形变化。


---


## 5. hurt – hurt – hurt


**基本意义**：使受伤、感到疼痛；也可指情感受到伤害。


| 例句 | 形式与结构 |
| --- | --- |
| **Be careful not to hurt yourself.**<br>小心别伤到自己。 | 原形 |
| **I hurt my leg while running.**<br>我跑步时伤到了腿。 | 过去式 |
| **I've hurt my shoulder again.**<br>我又弄伤了肩膀。 | 过去分词 |
| **Several people were hurt in the accident.**<br>有几个人在事故中受伤。 | 过去分词（被动） |


**使用注意**：**hurt** 既可以及物（`I hurt my arm.`），也可以不及物（`My arm hurts.`）。注意第三人称单数现在时仍是 `hurts`。


---


## 6. let – let – let


**基本意义**：允许、让某人做某事。


| 例句 | 形式与结构 |
| --- | --- |
| **Please let me know when you arrive.**<br>到达后请告诉我。 | 原形 |
| **She let me borrow her laptop yesterday.**<br>她昨天让我借用了笔记本电脑。 | 过去式 |
| **The apartment has been let to a new tenant.**<br>这套公寓已经出租给一位新租客。 | 过去分词 |


**使用注意**：常见结构为 `let someone do something`，其中第二个动词使用不带 `to` 的原形。`let` 的过去式和过去分词仍是 `let`。


---


## 7. set – set – set


**基本意义**：设定、确定、摆放。


| 例句 | 形式与结构 |
| --- | --- |
| **I usually set the alarm for seven.**<br>我通常把闹钟设在七点。 | 原形 |
| **We set a deadline last week.**<br>我们上周确定了截止日期。 | 过去式 |
| **I've already set a reminder.**<br>我已经设置了提醒。 | 过去分词 |
| **The date has been set.**<br>日期已经确定了。 | 过去分词（被动） |


**使用注意**：**set** 可以用于 `set an alarm`、`set a deadline` 等表达。其过去式不是 `setted`。


---


## 8. shut – shut – shut


**基本意义**：关闭、合上；也可表示停止营业或运行。


| 例句 | 形式与结构 |
| --- | --- |
| **Please shut the window before leaving.**<br>离开前请关上窗户。 | 原形 |
| **He shut the door quietly.**<br>他轻轻地关上了门。 | 过去式 |
| **I've shut all the windows.**<br>我已经关好了所有窗户。 | 过去分词 |
| **The shop has been shut for weeks.**<br>这家店已经关了好几个星期。 | 过去分词（被动） |


**使用注意**：**shut** 与规则动词 `close – closed – closed` 对照记忆。`The door is shut` 描述关闭状态，不能只凭 `shut` 判断句子时态。


---


## 9. split – split – split


**基本意义**：分割、分裂、分摊。


| 例句 | 形式与结构 |
| --- | --- |
| **Let's split the bill.**<br>我们分摊账单吧。 | 原形 |
| **We split the work between us yesterday.**<br>我们昨天分配了工作。 | 过去式 |
| **The group has split into two teams.**<br>这个小组已经分成了两个队。 | 过去分词 |
| **The cost was split between us.**<br>费用由我们分摊了。 | 过去分词（被动） |


**使用注意**：**split** 可以表示 `split the bill`（分摊账单）或 `split into groups`（分成小组）。V1、V2、V3 均为 `split`。


---


## 10. spread – spread – spread


**基本意义**：铺开、涂抹、传播、蔓延。


| 例句 | 形式与结构 |
| --- | --- |
| **Don't spread the news yet.**<br>先别传播这个消息。 | 原形 |
| **The fire spread quickly last night.**<br>昨晚火势迅速蔓延。 | 过去式 |
| **The news has spread everywhere.**<br>消息已经传得到处都是。 | 过去分词 |
| **The disease was spread through close contact.**<br>这种疾病通过密切接触传播。 | 过去分词（被动） |


**使用注意**：**spread** 可以及物（`spread the news`），也可以不及物（`The news spread.`）。不应写成 `spreaded`。


---


## 11. cost – cost – cost


**基本意义**：花费、使付出代价。


| 例句 | 形式与结构 |
| --- | --- |
| **These tickets cost about fifty pounds.**<br>这些票大约要50英镑。 | 原形 |
| **The repair cost me a lot of money.**<br>这次维修花了我很多钱。 | 过去式 |
| **The project has cost us millions.**<br>这个项目已经花费了我们数百万。 | 过去分词 |


**使用注意**：表示“花费金钱”时，主语往往是物品、服务或事件：`The repair cost me £50.`。本节的常见用法为 `cost – cost – cost`；另有特殊语义中使用规则形式的情况。


---


## 12. burst – burst – burst


**基本意义**：突然爆裂、爆发或闯入。


| 例句 | 形式与结构 |
| --- | --- |
| **Be careful, or the balloon might burst.**<br>小心，气球可能会爆。 | 原形 |
| **The pipe burst last night.**<br>水管昨晚爆了。 | 过去式 |
| **One of the pipes has burst.**<br>其中一根水管已经爆裂了。 | 过去分词 |


**使用注意**：**burst** 强调突然性，如 `burst into tears`。其过去式和过去分词一般都是 `burst`。


---


## 13. broadcast – broadcast – broadcast


**基本意义**：广播、播送节目或信息。


| 例句 | 形式与结构 |
| --- | --- |
| **They broadcast the news every evening.**<br>他们每天晚上播报新闻。 | 原形 |
| **The station broadcast the interview last night.**<br>电台昨晚播出了这场采访。 | 过去式 |
| **The programme has been broadcast in several countries.**<br>这个节目已经在多个国家播出。 | 过去分词 |


**使用注意**：**broadcast – broadcast – broadcast** 是常见形式；`broadcasted` 也有使用，但 `broadcast` 尤为普遍。

| 动词三态 | 例句 | 注意 |
| --- | --- | --- |

| read – read – read | **I read the letter yesterday.**<br>我昨天读了那封信。 | **拼写相同，读音不同**：原形 /riːd/，过去式和过去分词 /red/。 |

## 15. 如何判断相同词形的语法身份？


以 `put` 为例：


| 句子 | 判断依据 |
| --- | --- |
| **I put my keys here every day.**<br>我每天都把钥匙放在这里。 | 一般现在时：V1 |
| **I put my keys here yesterday.**<br>我昨天把钥匙放在这里了。 | 一般过去时：V2 |
| **Did you put your keys here?**<br>你把钥匙放这里了吗？ | `did + V1` |
| **I have put my keys here.**<br>我已经把钥匙放在这里了。 | `have + V3` |
| **The keys were put on the shelf.**<br>钥匙被放到了架子上。 | 被动式：`be + V3` |


同样的拼写可以对应不同的语法功能。判断时应先识别整个句子的结构，再确定动词的形式身份。

# 07｜易混形式与特殊变化

## 1. 认识特殊变化的不规则动词

学完前面几种主要变化类型以后，大部分不规则动词已经有了基本框架。真正容易出错的，往往是少数**拼写相近、读音不同、意义不同或存在多种变化形式**的动词。

这些特殊情况主要可以分为四类：

| 类型 | 典型动词 | 需要注意的地方 |
| --- | --- | --- |
| 拼写相同，读音不同 | read – read – read | 过去式、过去分词的读音与原形不同 |
| 形式相近，实际是不同动词 | lie / lay、find / found、fall / fell | 不能只凭拼写判断词义和语法身份 |
| 意义不同，变化形式不同 | hang、bear | 词义会影响过去式或过去分词的选择 |
| 存在两套常见变化 | get、dream、learn、burn、spell 等 | 英式英语、美式英语或使用习惯有所不同 |

下面按动词逐一整理，重点比较**三种形式、实际例句和容易混淆的用法**。

---

## 2. read – read – read

**基本意义**：阅读、朗读。

| 形式 | 拼写 | 发音 |
| --- | --- | --- |
| V1 原形 | read | /riːd/ |
| V2 过去式 | read | /red/ |
| V3 过去分词 | read | /red/ |

| 例句 | 形式与结构 |
| --- | --- |
| **I read before bed every night.**<br>我每天晚上睡前都会看书。 | 原形：/riːd/ |
| **I want to read this book.**<br>我想读这本书。 | 原形：/riːd/ |
| **I read the whole book yesterday.**<br>我昨天把整本书读完了。 | 过去式：/red/ |
| **I've read this book before.**<br>这本书我以前读过。 | 过去分词：/red/ |

**使用注意**：**read** 的三种形式拼写完全相同，但读音不同。看到 `I read...` 时，不能只凭拼写判断时态，需要结合时间状语和句子结构。`every night` 通常表示现在的习惯，`yesterday` 表示过去事件，`have + read` 则使用过去分词。

| --- | --- |
| **read aloud**<br>大声朗读 | 强调把文字读出声音。<br><br>**Please read the instructions aloud.**<br>请把说明大声读出来。<br><br>**She read the poem aloud to the class yesterday.**<br>她昨天在课堂上朗读了这首诗。 |

## 3. lie – lay – lain（躺）

**基本意义**：躺、平放、处于某个位置。

| 形式 | 动词 | 主要意义 |
| --- | --- | --- |
| V1 原形 | lie | 躺 |
| V2 过去式 | lay | 躺了 |
| V3 过去分词 | lain | 已经躺着、一直处于某位置 |

| 例句 | 形式与结构 |
| --- | --- |
| **I usually lie on the sofa after dinner.**<br>我吃完晚饭通常会躺在沙发上。 | 原形 |
| **Just lie down for a while.**<br>躺一会儿吧。 | 原形 |
| **I lay awake for hours last night.**<br>我昨晚躺着几个小时都没睡着。 | 过去式 |
| **He lay on the floor without moving.**<br>他躺在地上一动不动。 | 过去式 |
| **He had lain there for hours before anyone found him.**<br>在有人发现他以前，他已经在那里躺了几个小时。 | 过去分词 |
| **The book had lain untouched for years.**<br>那本书多年无人翻动。 | 过去分词 |

**使用注意**：表示“躺”的 **lie** 通常不直接接宾语。它的过去式是 `lay`，容易与另一个表示“放置”的动词 `lay` 混淆。`lain` 在现代日常口语中不算特别高频，但仍然是标准过去分词。

### 高频搭配

| 搭配与释义 | 使用见解与例句 |

## 28. 特殊形式的规律总结

### 拼写相同，不代表语法身份相同

| 动词三态 | 特殊之处 |
| --- | --- |
| read – read – read | 拼写相同，过去式和过去分词读音不同 |
| beat – beat – beaten | 原形和过去式相同，过去分词增加 `-en` |
| cut – cut – cut | 三种形式拼写和读音都相同 |

**使用注意**：不能永远只靠拼写判断动词形式。需要结合助动词、时间状语和句子结构。

### 意义不同，可能使用不同形式

| 动词形式 | 主要意义 |
| --- | --- |
| hang – hung – hung | 普通悬挂 |
| hang – hanged – hanged | 绞死、处以绞刑 |
| bear – bore – borne | 承受、承担 |
| be born | 出生 |

**使用注意**：这类区别数量不多，但具有相对稳定的使用习惯，适合结合具体语义记忆。

### 英式英语与美式英语的差异

| 动词 | 美式英语常见 | 英式英语也常见 |
| --- | --- | --- |
| learn | learned | learnt |
| dream | dreamed | dreamt |
| burn | burned | burnt |
| spell | spelled | spelt |
| smell | smelled | smelt |
| spill | spilled | spilt |

**使用注意**：两种形式同时存在时，不需要把其中一种当成错误。如果长期以美式英语为主，可以优先稳定使用 `learned`、`dreamed`、`burned`、`spelled`、`smelled`、`spilled`，同时认识英式英语中常见的其他形式。

### 拼写重合，不一定属于同一个动词

| 第一组动词 | 第二组动词 | 区别 |
| --- | --- | --- |
| find – found – found | found – founded – founded | 找到 / 创立 |
| fall – fell – fallen | fell – felled – felled | 掉落 / 砍倒 |
| lie – lay – lain | lay – laid – laid | 躺 / 放置 |
| lie – lay – lain | lie – lied – lied | 躺 / 说谎 |

**使用注意**：这些词虽然在拼写上出现交叉，但实际属于不同的动词或不同的意义。理解句子的动作关系以后，通常就能区分。

### Case 动词与特殊形式回顾

| 故事中的表达 | 动词三态 | 形式与意义 |
| --- | --- | --- |
| **lay awake** | lie – lay – lain | 过去式：躺着睡不着 |
| **read a few pages** | read – read – read | 过去式：读作 /red/ |
| **had been hung** | hang – hung – hung | 过去分词：悬挂 |
| **had woken ... up** | wake – woke – woken | 过去分词：叫醒 |
| **laid the picture** | lay – laid – laid | 过去式：放置 |
| **lit the passage** | light – lit – lit | 过去式：照亮 |
| **had lain there** | lie – lay – lain | 过去分词：一直处于某位置 |
| **had lied to him** | lie – lied – lied | 过去分词：说谎 |
| **bore the name** | bear – bore – borne | 过去式：带有、载有 |
| **had been founded** | found – founded – founded | 过去分词：创立 |
| **read the first page twice** | read – read – read | 过去式：读作 /red/ |

**重点回顾**：`lie – lay – lain`、`lay – laid – laid` 和 `lie – lied – lied` 外形非常接近，但意义完全不同；`read /riːd/` 与 `read /red/` 则需要根据时态判断读音。

这些特殊变化数量有限。真正值得做的是在实际句子里反复遇见它们，直到看到 `has lain`、`laid it down`、`has proven`、`was born`、`was hanged` 等表达时，能够直接识别其意义和结构，而不需要重新背诵变化表。
