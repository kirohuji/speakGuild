
# Irregular Verbs

## 使用说明

英语不规则动词的变化并不总是遵循 `-ed` 规则。

本手册分为四个学习模块：

| 模块 | 内容 | 学习目标 |
| :--- | :--- | :--- |
| 01 | 不规则动词总表 | 查阅与熟悉基本变化 |
| 02 | 特殊形式与易混淆动词 | 理解容易出错的用法 |
| 03 | 常见变化规律 | 建立规律性记忆 |
| 04 | 高频核心动词 | 优先掌握日常表达 |

**阅读约定**

| 标记 | 含义 |
| :--- | :--- |
| **Base Form** | 动词原形 |
| **Past Simple** | 一般过去式 |
| **Past Participle** | 过去分词 |
| `/` | 表示存在两种常见形式 |
| `BrE` | 英式英语 |
| `AmE` | 美式英语 |

### 2.2 易混淆动词

#### 01 / lie · lay · lie

这三个动词的拼写或变化形式非常接近，但含义不同。

| 含义 | 原形 | 过去式 | 过去分词 |
| :--- | :--- | :--- | :--- |
| 躺 | **lie** | lay | lain |
| 放置 | **lay** | laid | laid |
| 说谎 | **lie** | lied | lied |

**例句对照**

| 用法 | English Example | 中文释义 |
| :--- | :--- | :--- |
| 躺（过去式） | He **lay** on the bed yesterday. | 他昨天躺在床上。 |
| 躺（过去分词） | He has **lain** there for hours. | 他已经在那里躺了几个小时。 |
| 放置 | She **laid** the book on the table. | 她把书放在桌子上。 |
| 说谎 | He **lied** to me. | 他对我撒了谎。 |

**记忆提示**

| 变化形式 | 核心含义 |
| :--- | :--- |
| `lie — lay — lain` | 躺 |
| `lay — laid — laid` | 放置某物 |
| `lie — lied — lied` | 说谎 |

---

#### 02 / rise · raise

| 动词 | 变化形式 | 核心区别 |
| :--- | :--- | :--- |
| **rise** | rise — rose — risen | 自己上升 |
| **raise** | raise — raised — raised | 使某物上升 |

**例句对照**

| 用法 | English Example | 中文释义 |
| :--- | :--- | :--- |
| rise（过去式） | Prices **rose** last year. | 去年价格上涨了。 |
| rise（过去分词） | Prices have **risen** sharply. | 价格已经大幅上涨。 |
| raise（规则动词） | They **raised** the price. | 他们提高了价格。 |

> **注意**
>
> `raise` 是规则动词。
>
> 区分的关键在于：是事物自己上升，还是有人使某物上升。

### 2.3 英式英语与美式英语
*British English vs American English*

下面这些动词经常同时存在两套形式。

| 动词 | 常见形式 |
| :--- | :--- |
| **burn** | burned / burnt |
| **dream** | dreamed / dreamt |
| **learn** | learned / learnt |
| **smell** | smelled / smelt |
| **spell** | spelled / spelt |
| **spill** | spilled / spilt |
| **spoil** | spoiled / spoilt |
| **leap** | leaped / leapt |
| **lean** | leaned / leant |
| **kneel** | kneeled / knelt |

> **USAGE NOTE · 用法提示**
>
> 美式英语更常使用 `-ed` 形式，例如：
>
> `learned` · `dreamed` · `burned`
>
> 英式英语中也经常使用：
>
> `learnt` · `dreamt` · `burnt`
>
> 两种形式都可能是标准英语。

### 2.4 四个需要特别注意的动词

#### GET / got · gotten

`get` 是需要单独注意的高频动词。

| 变体 | 变化形式 |
| :--- | :--- |
| **BrE** | get — got — got |
| **AmE** | get — got — gotten |

**例句对照**

| 用法 | English Example | 中文释义 |
| :--- | :--- | :--- |
| got（表示拥有） | I've **got** a car. | 我有一辆车。 |
| gotten（表示变化） | Things have **gotten** better. | 情况已经好转了。 |

美式英语里的 `gotten` 经常强调：

- 获得
- 变化
- 发展

---

#### HANG / hung · hanged

根据含义不同，`hang` 可以使用不同的过去式和过去分词。

| 使用情境 | 变化形式 |
| :--- | :--- |
| 普通悬挂 | hang — hung — hung |
| 涉及绞刑 | hang — hanged — hanged |

**例句对照**

| 用法 | English Example | 中文释义 |
| :--- | :--- | :--- |
| hung（悬挂） | She **hung** the picture on the wall. | 她把画挂在了墙上。 |
| hanged（绞刑） | The prisoner was **hanged**. | 那名囚犯被处以绞刑。 |

---

#### BEAR / borne · born

| 使用情境 | 变化形式 |
| :--- | :--- |
| 承受、承担 | bear — bore — borne |
| 出生 | bear — bore — born |

**例句对照**

| 用法 | English Example | 中文释义 |
| :--- | :--- | :--- |
| borne（承担） | The cost was **borne** by the company. | 费用由公司承担。 |
| born（出生） | I was **born** in 2000. | 我出生于 2000 年。 |

> **注意**
>
> 表示“出生”时，使用 `born`。

---

#### READ / 相同拼写，不同读音

`read` 的三种形式拼写相同，但发音不同。

| 形式 | 拼写 | 发音 |
| :--- | :--- | :--- |
| 原形 | read | /riːd/ |
| 过去式 | read | /red/ |
| 过去分词 | read | /red/ |

**例句对照**

| 用法 | English Example | 中文释义 |
| :--- | :--- | :--- |
| 原形 /riːd/ | I **read** /riːd/ every day. | 我每天都阅读。 |
| 过去式 /red/ | I **read** /red/ it yesterday. | 我昨天读了它。 |
| 过去分词 /red/ | I've **read** /red/ it before. | 我以前读过它。 |
