# 过去式与过去分词相同的动词

## 1. 认识 A–B–B 型不规则动词

这类动词的原形发生变化，但过去式和过去分词采用同一个词形，也就是 **V2 = V3**。

| 原形（V1） | 过去式（V2） | 过去分词（V3） | 核心释义 |
| --- | --- | --- | --- |
| build | built | built | 建造、建立 |
| buy | bought | bought | 购买 |
| catch | caught | caught | 抓住、赶上 |
| feel | felt | felt | 感觉 |
| find | found | found | 找到、发现 |
| hear | heard | heard | 听见、听说 |
| keep | kept | kept | 保留、保持 |
| leave | left | left | 离开、留下 |
| lose | lost | lost | 失去、丢失 |
| make | made | made | 制作、使得 |
| meet | met | met | 遇见、见面、满足 |
| say | said | said | 说、表达 |
| send | sent | sent | 发送、寄送 |
| sleep | slept | slept | 睡觉 |
| spend | spent | spent | 花费（金钱、时间） |
| teach | taught | taught | 教、教授 |
| tell | told | told | 告诉、讲述、辨别 |
| think | thought | thought | 思考、认为 |

虽然 V2 和 V3 拼写相同，但它们承担的语法功能不同。

**I lost my key yesterday.**  
我昨天把钥匙弄丢了。

**I’ve lost my key.**  
我的钥匙丢了。

第一句的 `lost` 是一般过去时中的 V2；第二句的 `lost` 是与 `have` 共同组成现在完成式的 V3。区别在于整个谓语结构，而不在于 `lost` 的拼写。

## 2. 常见变化模式

| 变化特点 | 例子 |
| --- | --- |
| 元音或辅音变化，并以 -t 结尾 | keep – kept – kept；sleep – slept – slept；send – sent – sent |
| -ought / -aught 形式 | buy – bought – bought；think – thought – thought；catch – caught – caught；teach – taught – taught |
| 其他常见变化 | make – made – made；say – said – said；find – found – found；tell – told – told |

这些是便于比较与记忆的局部模式，并不是可以套用到所有动词的统一规则。

## build – built – built

**核心释义：**建造、建立

| 语法身份 | 例句 |
| --- | --- |
| **V1：build** | **The team builds small houses.**<br>团队建造小型住宅。 |
| **V2：built** | **They built the bridge in 1998.**<br>他们在 1998 年建造了这座桥。 |
| **V3：built**（完成式） | **They have built three bridges.**<br>他们已经建了三座桥。 |
| **V3：built**（其他结构） | **The bridge was built in 1998.**<br>这座桥建于 1998 年。 |

**形式与使用：**built 既是过去式，也是过去分词；被动式中的 was built 尤其常见。

**辅助表达：**build trust（建立信任）；build on something（在……基础上发展）

## buy – bought – bought

**核心释义：**购买

| 语法身份 | 例句 |
| --- | --- |
| **V1：buy** | **I usually buy coffee here.**<br>我通常在这里买咖啡。 |
| **V2：bought** | **I bought a laptop last month.**<br>我上个月买了一台笔记本电脑。 |
| **V3：bought**（完成式） | **I've bought the tickets already.**<br>我已经买好票了。 |
| **V3：bought**（其他结构） | **The painting was bought by a collector.**<br>这幅画被一位收藏家买走了。 |

**形式与使用：**注意 bought 的拼写，不是 buyed；完成式用 have bought。

**辅助表达：**buy something for someone / buy someone something（给某人买某物）

## catch – caught – caught

**核心释义：**抓住、赶上

| 语法身份 | 例句 |
| --- | --- |
| **V1：catch** | **I sometimes catch the early train.**<br>我有时赶早班火车。 |
| **V2：caught** | **I caught the last train yesterday.**<br>昨天我赶上了末班火车。 |
| **V3：caught**（完成式） | **I've caught a cold.**<br>我感冒了。 |
| **V3：caught**（其他结构） | **He was caught stealing.**<br>他偷东西时被抓住了。 |

**形式与使用：**caught 的拼写与 taught 相似；be caught doing 表示被发现正在做某事。

**辅助表达：**catch a bus（赶公交）；catch a cold（感冒）；catch someone doing（撞见某人在做某事）

## feel – felt – felt

**核心释义：**感觉

| 语法身份 | 例句 |
| --- | --- |
| **V1：feel** | **I feel tired today.**<br>我今天觉得累。 |
| **V2：felt** | **I felt nervous before the interview.**<br>面试前我很紧张。 |
| **V3：felt**（完成式） | **I've never felt this tired before.**<br>我以前从没这么累过。 |

**形式与使用：**feel → felt 同时发生元音与词尾变化；feel 作为感官系动词时常接形容词。

**辅助表达：**feel + adjective（感觉……）；feel like doing（想做某事）

## find – found – found

**核心释义：**找到、发现

| 语法身份 | 例句 |

## hear – heard – heard

## 3. 过去式与过去分词的区别

### 一般过去时：V2

**I sent the file yesterday.**  
我昨天发送了文件。

`sent` 作为过去式，直接构成一般过去时。

### 完成式：have / has / had + V3

**I’ve sent the file.**  
我已经发送文件了。

**I had sent it before the meeting began.**  
会议开始之前我就把它发出去了。

两句都使用过去分词 `sent`，但完成式的时间关系由 `have` 或 `had` 及上下文共同确定。

### 被动式：be + V3

**The file was sent yesterday.**  
文件是昨天发出的。

**The file will be sent tomorrow.**  
文件将在明天发出。

过去分词本身不表示某个固定的过去时间，因此同一个 `sent` 可以用于过去或未来的被动式。

### did 后使用原形

**She told me the truth.**  
她告诉了我真相。

**Did she tell you the truth?**  
她告诉你真相了吗？

`did` 已经带有过去时标记，后面要使用 `tell`，不能写成 `Did she told ...?`。

## 4. 综合场景｜一场临时改变的旅行

| 角色 | 对话内容 |
|:---:|---|
| **Emma** | **Hey, Daniel! How was your weekend trip?**<br>嘿，Daniel！你周末的旅行怎么样？ |
| **Daniel** | **It was quite an adventure. Nothing went as planned!**<br>简直是一场冒险。什么都没按计划进行！ |
| **Emma** | **Really? What happened?**<br>真的吗？发生什么事了？ |
| **Daniel** | **I left home early on Saturday, but when I got to the station, I realised I'd left my ticket on the kitchen table.**<br>周六我很早就出门了，但到了车站才发现把车票落在厨房桌上了。 |
| **Emma** | **Oh no! Did you miss your train?**<br>天哪！那你错过火车了吗？ |
| **Daniel** | **Almost! Luckily, I met a friend at the station. He helped me find my booking confirmation on my phone.**<br>差一点！幸好我在车站遇到了一位朋友。他帮我在手机上找到了订票确认信息。 |
| **Emma** | **That was lucky! So you made it onto the train?**<br>那真幸运！所以你赶上火车了？ |
| **Daniel** | **Yeah, but I'd spent so much time sorting things out that I hadn't bought any breakfast.**<br>是啊，但我花了太多时间处理这些事，连早饭都没买。 |
| **Emma** | **I bet you were hungry. What did you do when you arrived?**<br>我猜你肯定饿坏了。到了之后你做了什么？ |
| **Daniel** | **I found a little café near the station and had a huge breakfast. Then I went to the hotel.**<br>我在车站附近找到一家小咖啡馆，吃了一顿丰盛的早餐，然后去了酒店。 |
| **Emma** | **At least things were getting better!**<br>至少情况开始好转了！ |
| **Daniel** | **Not for long. When I reached the hotel, the receptionist told me they'd made a mistake with my booking.**<br>好景不长。我到酒店时，前台告诉我他们弄错了我的预订。 |
| **Emma** | **Seriously? Had they given your room to someone else?**<br>不会吧？他们把你的房间给别人了吗？ |
| **Daniel** | **Exactly. But the manager found another room for me, so everything worked out in the end.**<br>没错。不过经理帮我找到了另一个房间，所以最后还是解决了。 |
| **Emma** | **Good! Did you get to explore the town?**<br>那就好！你有时间逛逛小镇吗？ |
| **Daniel** | **I did. I spent the afternoon walking around and met a local artist who told me about a beautiful lake nearby.**<br>有啊。我下午四处走了走，还遇见一位当地艺术家，他告诉我附近有个很漂亮的湖。 |
| **Emma** | **That sounds lovely. Did you go there?**<br>听起来真不错。你去了吗？ |
| **Daniel** | **Yes. I went there the next morning. I'd never seen such a peaceful place before.**<br>去了。我第二天早上去了那里。以前从没见过那么宁静的地方。 |
| **Emma** | **So the trip wasn't a disaster after all!**<br>所以这趟旅行最后也不算糟糕嘛！ |
| **Daniel** | **Not at all. By the time I got home, I'd forgotten most of the problems. I just felt happy I'd gone.**<br>一点也不。等我回到家时，那些麻烦基本都忘了。我只觉得幸好自己去了。 |
| **Emma** | **Sometimes the best trips are the ones that don't go according to plan.**<br>有时候，最棒的旅行反而是那些不按计划进行的旅行。 |
