# 08｜过去分词的实际使用

## 1. 认识过去分词

学习不规则动词时，我们经常接触 `write – wrote – written`、`take – took – taken`、`see – saw – seen` 等三种形式。其中第三种形式叫作**过去分词（Past Participle）**。

过去分词能够进入多种句子结构。理解它与助动词、名词和宾语之间的关系，可以帮助我们读懂长句，也能让表达更加准确、自然。

| 例句 | 用途与结构 |
| --- | --- |
| **I've finished the report.**<br>我已经完成报告了。 | **完成时**：have / has / had + 过去分词，表示与参照时间有关的已完成动作或经历。 |
| **The report was sent yesterday.**<br>报告昨天发出去了。 | **被动语态**：be + 过去分词，强调动作承受者。 |
| **She looks worried.**<br>她看起来很担心。 | **形容词与状态**：be / feel / look + 过去分词形容词，描述情绪或状态。 |
| **The documents sent yesterday are missing.**<br>昨天寄出的文件不见了。 | **修饰名词**：名词 + 过去分词短语，限定或说明名词。 |
| **Built in 1920, the house is still standing.**<br>这栋房子建于1920年，如今仍然屹立。 | **分词短语**：在句首补充房屋的背景信息。 |
| **I found the door locked.**<br>我发现门锁着。 | **宾语补足语**：动词 + 宾语 + 过去分词，说明宾语的状态。 |

## 过去分词与过去时间的关系

### 过去分词本身不决定整句话的时间

`written` 的名称里虽然带有“过去”，但它作为一种动词形式，可以出现在过去、现在或未来的句子中。

| 例句 | 说明 |
| --- | --- |
| **The letter was written yesterday.**<br>这封信是昨天写的。 | `was` 表示过去。 |
| **The instructions are written in English.**<br>说明是用英语写的。 | `are` 表示现在的情况。 |
| **The report will be written tomorrow.**<br>报告将于明天撰写。 | `will be` 表示未来。 |

三个句子里的 `written` 始终是过去分词。时间和视角主要由前面的助动词结构以及时间状语决定。

### 过去式与过去分词怎样分工

| 动词 | 一般过去时 | 过去分词进入完成时 | 过去分词进入被动 |
| --- | --- | --- | --- |
| write | **I wrote it yesterday.**<br>我昨天写了它。 | **I've written it.**<br>我已经写好了。 | **It was written yesterday.**<br>它是昨天写的。 |
| take | **She took the photo.**<br>她拍了照片。 | **She's taken the photo.**<br>她已经拍好照片了。 | **The photo was taken outside.**<br>照片是在室外拍的。 |
| break | **He broke the glass.**<br>他打碎了玻璃杯。 | **He's broken the glass.**<br>他把玻璃杯打碎了。 | **The glass was broken.**<br>玻璃杯被打碎了。 |

`wrote / took / broke` 可以直接充当一般过去时的谓语；`written / taken / broken` 则可以结合助动词进入完成时和被动语态。部分动词的 V2 与 V3 拼写相同，判断时依然要看所在结构。

## 完成时中的过去分词

### 完成时的基本结构

- 现在完成时：`have / has + V3`
- 过去完成时：`had + V3`
- 将来完成时：`will have + V3`

**完成时的关键在于观察某个参照时间点之前的动作、经历或状态。** 现在完成时以现在为参照，过去完成时以过去的某个时间为参照。

### 现在完成时：过去事件造成的当前结果

| 例句 | 使用见解 |
| --- | --- |
| **I've broken my glasses.**<br>我把眼镜弄坏了。 | 说话者往往关心眼镜现在不能正常使用。 |
| **She's left her phone at home.**<br>她把手机落在家里了。 | 过去遗落手机，影响现在的情况。 |
| **We've finished the report.**<br>我们已经完成报告了。 | 当前可以把报告作为完成的任务看待。 |
| **I've lost my key.**<br>我的钥匙丢了。 | 通常意味着现在找不到钥匙。 |

比较过去式和完成时：

| 过去式 | 现在完成时 |
| --- | --- |
| **I lost my key yesterday.**<br>我昨天把钥匙弄丢了。 | **I've lost my key.**<br>我的钥匙丢了。 |
| **I sent the email this morning.**<br>我今天早上发了邮件。 | **I've sent the email.**<br>我已经把邮件发出去了。 |

左侧将事件放在明确的过去时间里；右侧从当前情况出发，说明事件已经发生。**现在完成时也可以表达经历、持续和到目前为止的次数，不能把所有完成时都理解成“结果仍在”。**

### 现在完成时：截至目前的经历

| 例句 | 使用见解 |
| --- | --- |
| **Have you ever seen snow?**<br>你见过雪吗？ | 询问至今是否有过这种经历。 |
| **I've never been abroad.**<br>我从来没有出过国。 | 描述截至现在的经历范围。 |
| **She's read that book three times.**<br>那本书她已经读过三遍。 | 强调截至目前的次数。 |
| **I've tried this restaurant before.**<br>这家餐厅我以前吃过。 | 具体是哪一天可以不说。 |

常与 `ever`、`never`、`before`、`once`、`twice` 等表达配合。

### 现在完成时：从过去持续到现在

| 例句 | 使用见解 |
| --- | --- |
| **I've known him for ten years.**<br>我认识他十年了。 | `know` 表示持续的认识状态。 |
| **We've lived here since 2020.**<br>我们从2020年起一直住在这里。 | `since` 引出起点。 |
| **She's had this car for years.**<br>这辆车她已经拥有很多年了。 | `have` 在这里表示拥有。 |
| **I've felt tired all week.**<br>我这一整周都觉得累。 | 状态持续到现在。 |

`for` 通常说明持续多长时间，`since` 通常说明从什么时候开始。持续意义常见于状态动词，也能结合适当的动词和语境表达。

### 过去完成时：从一个过去时间点往前看

| 例句 | 时间关系 |
| --- | --- |
| **The train had left before we arrived.**<br>我们到达之前，火车就已经开走了。 | 先开走，后到达。 |
| **I'd already eaten when she called.**<br>她打电话来时，我已经吃过了。 | 先吃饭，后接电话。 |
| **They had finished the work by midnight.**<br>到午夜时，他们已经完成了工作。 | 以午夜作为过去的参照点。 |

过去完成时的重点在于两个过去事件的先后关系。`left / eaten / finished` 都是 V3，变化的是助动词 `had`。

## 被动语态中的过去分词

### 被动语态的基本结构

**be + V3** 表示主语是动作的承受者。`be` 的形式决定时态等语法信息，过去分词表示所涉及的动作。

| 结构 | 例句 |
| --- | --- |
| 一般现在时被动 | **English is spoken here.**<br>这里有人说英语。 |
| 一般过去时被动 | **The email was sent yesterday.**<br>邮件昨天发出去了。 |
| 现在进行时被动 | **The bridge is being built now.**<br>这座桥目前正在建设中。 |
| 一般将来时被动 | **The work will be finished tomorrow.**<br>工作明天会完成。 |

### 主动与被动：句子关注的对象不同

| 主动 | 被动 |
| --- | --- |
| **Someone stole my bike.**<br>有人偷了我的自行车。 | **My bike was stolen.**<br>我的自行车被偷了。 |
| **They built the bridge in 1990.**<br>他们在1990年建造了这座桥。 | **The bridge was built in 1990.**<br>这座桥建于1990年。 |
| **Someone sent the documents yesterday.**<br>有人昨天寄出了文件。 | **The documents were sent yesterday.**<br>文件昨天寄出去了。 |

主动句通常把动作执行者放在主语位置，被动句则把动作承受者放在主语位置。执行者不重要、不知道或已经明确时，被动表达尤其常见。

### 完成时与被动语态可以组合

结构：**have / has / had + been + V3**。

| 例句 | 结构理解 |
| --- | --- |
| **The work has been finished.**<br>工作已经完成了。 | `has + been + finished`：现在完成时被动。 |
| **The documents had been sent before noon.**<br>文件中午之前就已经发出去了。 | `had + been + sent`：过去完成时被动。 |
| **The problem has been solved.**<br>问题已经解决了。 | 关注问题已经得到处理的当前结果。 |
| **The room had been cleaned before the guests arrived.**<br>客人到达之前，房间已经打扫好了。 | 清洁发生在另一个过去事件之前。 |

这里有两个层次：`have + V3` 提供完成时视角，`be + V3` 表达被动。组合后 `be` 变成 `been`，主要动词保持过去分词形式。

## 过去分词作为形容词与状态表达

### 从动作结果到当前状态

很多过去分词能够描述事物目前的状态或性质。

| 例句 | 说明 |
| --- | --- |
| **I'm tired.**<br>我累了。 | `tired` 描述人的状态。 |
| **She looks worried.**<br>她看起来很担心。 | `worried` 说明观察到的情绪。 |
| **The door is closed.**<br>门关着。 | `closed` 描述门的状态。 |
| **My phone is broken.**<br>我的手机坏了。 | `broken` 描述损坏后的状况。 |

过去分词有时可以按被动动作理解，有时已经明显具有形容词性质，两者之间存在连续的过渡。

### 动作与状态需要结合上下文

| 句子 | 较自然的理解 |
| --- | --- |
| **The door was closed by the guard at nine.**<br>保安九点把门关上了。 | 关注关门的动作，`by the guard` 明确执行者。 |
| **When I arrived, the door was closed.**<br>我到的时候门关着。 | 更容易理解为当时的状态。 |
| **The window was broken during the storm.**<br>窗户在暴风雨中被打碎了。 | 关注遭受破坏的事件。 |
| **The window is broken.**<br>窗户坏了。 | 关注当前状况。 |

### -ed 与 -ing 形容词

| -ed：感受或受到影响的状态 | -ing：引发感受的性质 |
| --- | --- |
| **I'm bored.**<br>我觉得无聊。 | **The film is boring.**<br>这部电影很无聊。 |
| **I'm interested in history.**<br>我对历史感兴趣。 | **The topic is interesting.**<br>这个话题很有趣。 |
| **We were shocked.**<br>我们震惊了。 | **The news was shocking.**<br>这个消息令人震惊。 |
| **She felt confused.**<br>她感到困惑。 | **The explanation was confusing.**<br>这个解释让人困惑。 |

常见的 -ed 形容词包括 `interested`、`bored`、`excited`、`worried`、`frightened`、`surprised` 和 `confused`。这是一种有用的理解方式，但具体词义和搭配仍需结合语境。

### very、much 与过去分词的形容词化

| 表达 | 用法 |
| --- | --- |
| **I'm very tired.**<br>我很累。 | `tired` 的形容词性质明显。 |
| **She was extremely worried.**<br>她极其担心。 | 可用程度副词修饰情绪状态。 |
| **He is greatly respected by his colleagues.**<br>他深受同事尊敬。 | `respected` 保留明显的被动意义。 |
| **The work is much admired.**<br>这项作品广受赞赏。 | `admired` 仍有较强的被动色彩。 |

这类搭配反映了过去分词从动词用法向形容词用法过渡的不同程度；`very`、`much` 的选择也受具体词汇和习惯搭配影响。

## 过去分词修饰名词

### 放在名词前：简洁地说明性质或状态

| 例句 | 中文与用法 |
| --- | --- |
| **Be careful with the broken glass.**<br>小心那些碎玻璃。 | `broken` 说明玻璃的状态。 |
| **We need a written agreement.**<br>我们需要一份书面协议。 | `written` 表示书面形式。 |
| **The police recovered the stolen money.**<br>警方追回了被偷的钱。 | `stolen` 指曾经遭受的动作。 |
| **I bought some frozen food.**<br>我买了一些冷冻食品。 | `frozen` 表示处理后的状态。 |
| **She spoke to a retired teacher.**<br>她和一位退休教师交谈了。 | `retired` 说明身份状态。 |

其他常见表达还有 `cooked rice`、`boiled water`、`prepared food`、`an injured player`。它们往往强调已经形成的结果或现有性质。

### 放在名词后：补充较长的限定信息

| 名词后的过去分词短语 | 对应的关系从句 |
| --- | --- |
| **The people invited to the meeting have arrived.**<br>受邀参加会议的人已经到了。 | **The people who were invited to the meeting have arrived.**<br>受邀参加会议的人已经到了。 |
| **The documents sent yesterday are missing.**<br>昨天寄出的文件不见了。 | **The documents that were sent yesterday are missing.**<br>昨天寄出的文件不见了。 |
| **The money stolen from the bank was recovered.**<br>从银行偷走的钱被追回了。 | **The money that was stolen from the bank was recovered.**<br>从银行偷走的钱被追回了。 |

这类名词后置修饰可以看成相关被动关系从句的简化表达。过去分词短语与前面的名词形成意义上的联系，使句子更加紧凑。

## 过去分词短语与信息压缩

### 在句首补充背景、原因或状态

| 分词短语表达 | 展开后的理解 |
| --- | --- |
| **Built in 1920, the house is still in good condition.**<br>这栋房子建于1920年，现在保存得仍然很好。 | **The house was built in 1920.**<br>这栋房子建于1920年。 |
| **Surrounded by mountains, the village is difficult to reach.**<br>这个村庄四面环山，很难到达。 | **Because the village is surrounded by mountains, it is difficult to reach.**<br>由于村庄四面环山，所以很难到达。 |
| **Damaged in the fire, the building had to be closed.**<br>建筑在火灾中受损，因此不得不关闭。 | **Because the building was damaged in the fire, it had to be closed.**<br>由于建筑在火灾中受损，所以不得不关闭。 |
| **Written in simple English, the book is easy to read.**<br>这本书用简单的英语写成，很容易读懂。 | **The book is written in simple English.**<br>这本书用简单的英语写成。 |

这些短语经常提供背景、原因、条件或状态信息。具体的逻辑关系由上下文决定。

### 分词短语的意义主体要清楚

比较：

- **Broken by the storm, the tree blocked the road.**  
  这棵树被暴风雨折断，挡住了道路。

- **Broken during the move, the table had to be replaced.**  
  桌子在搬运时损坏了，只能换掉。

`Broken ...` 分别修饰后面主句的 `the tree` 和 `the table`。使用这种句首结构时，要让读者明确究竟是谁或什么承受了该动作。

### 为什么书面语里常用

| 较完整的从句 | 压缩后的表达 |
| --- | --- |
| **The documents that were submitted yesterday will be reviewed next week.**<br>昨天提交的文件将在下周审核。 | **The documents submitted yesterday will be reviewed next week.**<br>昨天提交的文件将在下周审核。 |
| **Because the building was damaged in the fire, it had to be closed.**<br>由于建筑在火灾中受损，所以不得不关闭。 | **Damaged in the fire, the building had to be closed.**<br>建筑在火灾中受损，因此不得不关闭。 |

这种表达在新闻报道、说明文和正式写作中尤其常见，因为它能够压缩 `who was`、`that were`、`because it was` 等结构所承载的信息。

## 过去分词作为宾语补足语

### 动词 + 宾语 + V3

过去分词可以放在宾语后面，说明宾语的状态或经历的动作。

| 例句 | 结构说明 |
| --- | --- |
| **I found the door locked.**<br>我发现门锁着。 | `locked` 描述 `the door` 的状态。 |
| **We found the window broken.**<br>我们发现窗户破了。 | `broken` 描述 `the window` 的状态。 |
| **She left the door unlocked.**<br>她让门一直没锁。 | `unlocked` 是门被保持的状态。 |
| **Keep me informed.**<br>有消息随时告诉我。 | 希望 `me` 持续得到通知。 |

### have something done：安排完成某事

常用结构：**have + 宾语 + V3**。

| 例句 | 使用见解 |
| --- | --- |
| **I had my hair cut yesterday.**<br>我昨天去剪了头发。 | 通常意味着由理发师完成。 |
| **I had my phone repaired.**<br>我把手机拿去修了。 | 由维修人员处理。 |
| **We're having the kitchen painted.**<br>我们正在找人粉刷厨房。 | 强调安排他人完成某事。 |
| **She's having her eyes tested next week.**<br>她下周要去检查视力。 | 描述已经安排好的服务。 |

### get something done：常见的口语表达

结构：**get + 宾语 + V3**。

| 例句 | 使用见解 |
| --- | --- |
| **I need to get my laptop fixed.**<br>我得把笔记本电脑拿去修。 | 常见的口语表达。 |
| **Did you get your hair cut?**<br>你去剪头发了吗？ | 关注某个安排是否完成。 |
| **I finally got the documents signed.**<br>我终于让文件签好了字。 | 突出把事情办成。 |
| **We need to get the windows cleaned.**<br>我们需要找人把窗户清理干净。 | 表达对服务或处理结果的需求。 |

`get` 往往更口语化，也容易突出促成结果的过程。`have` 和 `get` 的具体差异仍需结合语境。

### have something stolen：也能描述遭遇

相同结构有时会表达某人遭遇了不希望发生的事情。

| 例句 | 使用见解 |
| --- | --- |
| **I had my bike stolen.**<br>我的自行车被偷了。 | 描述自己遭遇盗窃。 |
| **She had her bag stolen on the train.**<br>她的包在火车上被偷了。 | 强调不愉快的经历。 |
| **He had his phone damaged during the trip.**<br>他旅行时手机被弄坏了。 | 某种损失发生在他身上。 |

这里通常不表示主动安排别人偷窃或破坏。需要根据动作意义、情境以及主语的意愿判断。

### keep / leave + 宾语 + V3

| 例句 | 使用见解 |
| --- | --- |
| **Keep the door locked.**<br>让门一直锁着。 | `keep` 强调维持状态。 |
| **Leave it closed.**<br>就让它关着。 | `leave` 强调保持原状。 |
| **Keep me informed of any changes.**<br>有任何变化请随时通知我。 | `informed` 表示持续得到信息的状态。 |
| **Don't leave the windows unlocked.**<br>别让窗户一直没锁。 | 强调某种状态可能带来的后果。 |

## get + V3 与状态变化

### get 可以表示进入某种状态

`get + V3` 在日常英语里十分常见，有些是口语被动结构，有些更接近状态变化表达。

| 例句 | 表达与使用见解 |
| --- | --- |
| **They got married last year.**<br>他们去年结婚了。 | **get married**：结婚，强调进入婚姻状态。 |
| **Get dressed. We're leaving soon.**<br>穿好衣服，我们很快就要出发了。 | **get dressed**：穿好衣服，强调穿衣动作的完成。 |
| **He got hurt during the match.**<br>他比赛时受伤了。 | **get hurt**：受伤，强调受伤事件的发生。 |
| **We got lost on the way back.**<br>我们在回程路上迷路了。 | **get lost**：迷路，表示进入不知路的状况。 |
| **He got caught stealing.**<br>他偷东西时被抓到了。 | **get caught**：被抓到，常用于被发现正在做某事。 |
| **We got stuck in traffic.**<br>我们堵在路上了。 | **get stuck**：卡住或陷入困境，强调受阻的结果。 |

### be + V3 和 get + V3 的侧重点

| 状态或中性表达 | 变化或事件表达 |
| --- | --- |
| **He was injured.**<br>他受伤了。 | **He got injured during the game.**<br>他在比赛中受伤了。 |
| **They were married for twenty years.**<br>他们维持了二十年的婚姻。 | **They got married in 2010.**<br>他们在2010年结婚了。 |
| **The door was locked when I arrived.**<br>我到达时门锁着。 | **The door got locked accidentally.**<br>门意外地被锁上了。 |

`be` 可以描述状态，也可以构成被动；`get` 往往更突出变化的发生。这是语义上的常见倾向，并非所有句子都能简单互换。

## 包含过去分词的固定表达

部分过去分词在长期使用中形成了稳定的搭配，尤其要留意后面的介词和不定式。

| 搭配与释义 | 使用见解 / 例句 |
| --- | --- |
| **be supposed to**<br>按规定、安排或期待应该做某事 | to 后接动词原形；常用于规定、职责以及原先的预期。<br><br>**You're supposed to be here at nine.**<br>你应该九点到这里。<br><br>**I thought we were supposed to wait outside.**<br>我以为我们应该在外面等。 |
| **be interested in**<br>对……感兴趣 | in 后接名词或动名词，说明兴趣指向的对象。<br><br>**I'm interested in history.**<br>我对历史感兴趣。<br><br>**She's always been interested in how languages change.**<br>她一直对语言如何演变感兴趣。 |
| **be worried about**<br>担心…… | about 引出担忧的对象，也可以用 worried that 引出具体担忧。<br><br>**I'm worried about the exam.**<br>我担心考试。<br><br>**He seemed worried about his daughter's health.**<br>他似乎很担心女儿的健康。 |
| **be used to**<br>习惯于…… | 这里的 to 是介词，后接名词或动名词；与 used to do 区分。<br><br>**I'm used to working late.**<br>我习惯晚工作。<br><br>**She's not used to this weather yet.**<br>她还不习惯这种天气。 |
| **be related to**<br>与……有关 | 用于说明两件事、两个人或两种现象的联系。<br><br>**These two issues are closely related.**<br>这两个问题密切相关。<br><br>**Is this problem related to the update?**<br>这个问题和更新有关吗？ |
| **be based on**<br>基于；根据……改编 | on 引出依据、原始素材或证据。<br><br>**The film is based on a true story.**<br>这部电影根据真实故事改编。<br><br>**Our decision was based on the available evidence.**<br>我们的决定基于现有证据。 |
| **be involved in**<br>参与；卷入 | in 后接参与的活动或所牵涉的事件；语气由语境决定。<br><br>**He's involved in the project.**<br>他参与了这个项目。<br><br>**Several departments were involved in the investigation.**<br>几个部门参与了调查。 |

`be used to` 后面可以接名词或 `-ing`，表示已经习惯某种事物或行为。它与表示过去习惯的 `used to do` 属于不同结构。

## 同一个过去分词在不同结构中的作用

### broken

| 结构 | 例句 | 功能 |
| --- | --- | --- |
| 完成时 | **I've broken my phone.**<br>我把手机弄坏了。 | `have + V3` |
| 被动 | **The window was broken last night.**<br>窗户昨晚被打碎了。 | `be + V3` |
| 状态形容词 | **My phone is broken.**<br>我的手机坏了。 | 描述当前状态 |
| 名词前修饰 | **I need to replace my broken phone.**<br>我得换掉坏手机。 | 修饰名词 |
| 分词短语 | **Broken during the move, the table had to be replaced.**<br>桌子搬家时损坏了，只能换掉。 | 补充背景信息 |

### written

| 结构 | 例句 | 功能 |
| --- | --- | --- |
| 完成时 | **I've written the report.**<br>我已经写好报告了。 | `have + V3` |
| 被动 | **The report was written by Anna.**<br>报告由安娜撰写。 | `be + V3` |
| 名词前修饰 | **Please follow the written instructions.**<br>请遵照书面说明。 | 修饰名词 |
| 名词后修饰 | **The report written by Anna is very clear.**<br>安娜写的报告很清晰。 | 修饰名词的后置短语 |
| 分词短语 | **Written in simple language, the report is easy to understand.**<br>报告用简单的语言写成，很容易理解。 | 补充说明 |

同一个 V3 的拼写不变，但不同结构会赋予它不同的句法功能。辨认它前面的助动词、它修饰的名词，以及它是否描述宾语的状态，通常就能确定具体作用。

## 快速辨析：看到 V3 时关注什么

| 例句 | 判断位置与使用见解 |
| --- | --- |
| **She's gone home.**<br>她已经回家了。 | **前面是 have / has / had**：完成时；与参照时间的联系。 |
| **The door is closed.**<br>门关着。 | **前面是 be**：被动或状态；上下文在描述动作还是状态。 |
| **He got hurt.**<br>他受伤了。 | **前面是 get**：状态变化或口语被动；进入某种状态的过程。 |
| **A broken window needs replacing.**<br>坏了的窗户需要更换。 | **在名词前**：前置修饰；名词具有什么性质。 |
| **The files sent today are important.**<br>今天发出的文件很重要。 | **在名词后**：后置修饰；哪些文件受到限定。 |
| **I found the door locked.**<br>我发现门锁着。 | **在宾语后**：宾语补足语；宾语处于什么状态。 |
| **Surrounded by trees, the house is hard to see.**<br>房子被树木环绕，很难看见。 | **位于句首**：分词短语；它在修饰哪个主体。 |

### Case 动词结构拆解

| 句中表达 | 类型与使用见解 |
| --- | --- |
| **I dropped my phone.**<br>我把手机摔了。 | **一般过去时**：dropped 描述过去发生的动作。 |
| **The screen broke immediately.**<br>屏幕当场裂了。 | **一般过去时**：broke 是过去式，说明屏幕发生破裂。 |
| **I'd dropped it several times before.**<br>我以前摔过它好几次。 | **过去完成时**：had + dropped，以故事中的过去时间为参照。 |
| **I had my phone repaired.**<br>我去修了手机。 | **have + 宾语 + 过去分词**：安排维修服务。 |
| **The screen had been badly damaged.**<br>屏幕已经严重损坏。 | **过去完成时被动**：had + been + damaged。 |
| **None of the data had been lost.**<br>数据没有丢失。 | **过去完成时被动**：lost 是 lose 的过去分词。 |
| **The screen had been replaced.**<br>屏幕已经更换好了。 | **过去完成时被动**：更换在检查手机之前已经完成。 |
| **I was told to keep the phone turned on.**<br>有人让我让手机保持开机。 | **被动 + 宾语补足语**：was told 表示被告知；turned on 说明 phone 应保持的状态。 |
| **It's fixed.**<br>修好了。 | **状态表达**：fixed 描述手机当前的状态。 |

## 本章要点

过去分词的应用范围很广。学习时可以把它放进完整结构中理解：

| 结构 | 主要用途 | 示例 |
| --- | --- | --- |
| `have + V3` | 完成时 | **I've written it.**<br>我已经写好了。 |
| `be + V3` | 被动或状态 | **It was written yesterday.**<br>它是昨天写的。 |
| `get + V3` | 进入状态、口语被动 | **I got stuck.**<br>我被卡住了。 |
| `have / get + 宾语 + V3` | 安排完成或遭遇某事 | **I had my phone repaired.**<br>我去修了手机。 |
| `keep / leave + 宾语 + V3` | 维持宾语的状态 | **Keep the door locked.**<br>让门一直锁着。 |
| `名词 + V3 短语` | 后置修饰 | **The documents sent yesterday...**<br>昨天寄出的文件…… |
| `V3 短语 + 主句` | 压缩背景信息 | **Built in 1920, the house...**<br>这栋房子建于1920年…… |

对同一个词形的理解，会随着句子结构而改变。通过具体语境反复接触这些结构，才能逐渐熟悉过去分词在口语、阅读和书面表达中的不同作用。
