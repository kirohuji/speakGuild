# 05｜原形与过去分词相同的动词

## 1. 认识 A–B–A 型不规则动词

这一组动词的**原形（V1）和过去分词（V3）相同，过去式（V2）不同**，可以记作 **A–B–A**。

| 原形 V1 | 过去式 V2 | 过去分词 V3 | 核心释义 |
| --- | --- | --- | --- |
| come | came | come | 来、到达 |
| become | became | become | 变成、成为 |
| run | ran | run | 跑、运转、经营 |
| overcome | overcame | overcome | 克服、战胜 |
| outrun | outran | outrun | 跑得更快、超过 |
| overrun | overran | overrun | 超时、超支、侵占 |

其中，`come`、`become` 和 `run` 在日常英语中非常常见；`overcome`、`outrun` 和 `overrun` 则展示了带前缀的动词如何保留基础动词的不规则变化。

虽然 V1 和 V3 的拼写相同，它们的语法身份仍然不同。比较：

| 例句 | 语法形式 |
| --- | --- |
| **They come here every weekend.** 他们每周末都来这里。 | 一般现在时：V1 `come` |
| **They came here yesterday.** 他们昨天来过这里。 | 一般过去时：V2 `came` |
| **They've come here before.** 他们以前来过这里。 | 现在完成时：V3 `come` |

在完成式中，不能因为过去式是 `came`，就写成 `have came`。`have / has / had` 后需要过去分词，而 `come` 的过去分词仍然是 `come`。

# 2. come — came — come

## 核心意义

`come` 表示向说话者、听话者或谈话中选定的参照地点移动，也可以表示季节、事件或某种情况的到来。

**Could you come over this evening?**  
你今晚能过来吗？

**Winter has come early this year.**  
今年冬天来得很早。

## 三种形式与例句

| 形式 | 例句 | 使用说明 |
| --- | --- | --- |
| V1 `come` | **I usually come home around six.** 我通常六点左右到家。 | 描述日常习惯 |
| V2 `came` | **Nobody came to the meeting yesterday.** 昨天没人来开会。 | 叙述过去发生的事情 |
| V3 `come` | **A lot of people have come to see her.** 已经有很多人来看过她。 | `have + V3`，表示截至现在的经历或结果 |

## 使用要点

`come` 和 `go` 的区别通常取决于谈话中的方向参照点。

**Come to my office when you have time.**  
你有空时来我办公室。

**I have to go to the office now.**  
我现在得去办公室。

表示到家时，使用 `come home`，不需要 `to`；普通地点名词前则常需要介词，例如 `come to my house`。

比较过去式与完成式：

**He came back at five.**  
他五点回来了。

**He has come back, so you can talk to him now.**  
他已经回来了，你现在可以和他谈谈。

前一句明确过去时间；后一句着重说明现在已经回来的情况。

# 3. become — became — become

## 核心意义

`become` 是变化系动词，表示人或事物从一种状态进入另一种状态。后面通常接形容词或名词短语。

**The room became quiet.**  
房间安静了下来。

**She became a doctor.**  
她成了一名医生。

## 三种形式与例句

| 形式 | 例句 | 使用说明 |
| --- | --- | --- |
| V1 `become` | **Things can become difficult very quickly.** 事情可能很快变得困难。 | 情态动词 `can` 后使用 V1 |
| V2 `became` | **We became good friends at university.** 我们在大学时成了好朋友。 | 过去发生的关系变化 |
| V3 `become` | **He has become much more confident.** 他现在自信多了。 | `has + V3`，说明到现在形成的变化 |

## 使用要点

`be` 说明某种状态，`become` 说明状态发生变化。

**He was angry.**  
他当时很生气。

**He became angry.**  
他生气了。

`become + adjective` 表示变得如何；`become + noun phrase` 表示成为某种身份。与 `get` 相比，`become` 也常出现在较正式或抽象的变化描述中。

注意：**has become** 正确，~~has became~~ 错误。

# 4. run — ran — run

## 核心意义

`run` 可以表示跑步、程序或机器运行，也可以表示经营、管理。不同意义下，它都采用同一组变化：`run – ran – run`。

**She runs every morning.**  
她每天早上跑步。

**The script runs every hour.**  
这个脚本每小时运行一次。

**They run a small hotel.**  
他们经营一家小旅馆。

## 三种形式与例句

| 形式 | 例句 | 使用说明 |
| --- | --- | --- |
| V1 `run` | **I run before breakfast most days.** 我大多数时候早餐前跑步。 | 一般现在时，说明习惯 |
| V2 `ran` | **We ran the program again last night.** 昨晚我们又运行了一遍程序。 | 一般过去时，使用 V2 |
| V3 `run` | **The team has run the test three times.** 团队已经把测试运行了三遍。 | 现在完成时，使用 V3 |

## 使用要点

`run` 可以不带宾语，表示某物运行；也可以直接接宾语，表示执行或经营。

**The service runs in the background.**  
这个服务在后台运行。

**We ran several tests before the release.**  
发布前我们运行了几项测试。

`run out of` 表示耗尽资源，仍然遵循 `run – ran – run`：

**We ran out of time.**  
我们的时间用完了。

**We've run out of memory.**  
我们的内存已经耗尽。

尤其注意：**I've run** 正确，~~I've ran~~ 错误。

---

# 5. overcome — overcame — overcome

## 核心意义

`overcome` 表示克服困难、障碍或恐惧，通常直接接被克服的事物；也可以表示被强烈的情绪影响。

**She overcame her fear of heights.**  
她克服了恐高。

**He was overcome with grief.**  
他悲痛不已。

## 三种形式与例句

| 形式 | 例句 | 使用说明 |
| --- | --- | --- |
| V1 `overcome` | **We must overcome these technical issues.** 我们必须克服这些技术问题。 | `must` 后使用 V1 |
| V2 `overcame` | **He eventually overcame his fear of flying.** 他最终克服了对飞行的恐惧。 | 过去式 V2，描述已发生的经历 |
| V3 `overcome` | **We've finally overcome the biggest difficulty.** 我们终于克服了最大的困难。 | `have + V3`，说明目前取得的结果 |

## 使用要点

`overcome` 与 `come` 的词形变化一致：

`come → came → come`  
`overcome → overcame → overcome`

**We overcame several obstacles.**  
我们克服了几项障碍。

**We have overcome the main obstacle.**  
我们已经克服了主要障碍。

`solve` 更侧重解决具体问题，`overcome` 更侧重跨越困难或阻力。这里掌握 `overcome difficulties / obstacles / fear` 等常见宾语即可，不必扩展到大量搭配。

# 6. outrun — outran — outrun

## 核心意义

`outrun` 由 `out-` 和 `run` 构成，表示跑得比别人快、甩开追赶者，也可描述需求或增长速度超过另一方。

**She outran everyone in the race.**  
她在比赛中跑赢了所有人。

**Demand has outrun supply.**  
需求已经超过供应。

## 三种形式与例句

| 形式 | 例句 | 使用说明 |
| --- | --- | --- |
| V1 `outrun` | **Few runners can outrun her.** 很少有跑者能跑赢她。 | `can` 后使用 V1 |
| V2 `outran` | **He outran the other competitors.** 他跑赢了其他参赛者。 | 一般过去时，使用 V2 |
| V3 `outrun` | **Demand has outrun supply this year.** 今年需求已经超过了供应。 | 现在完成时，使用 V3 |

## 使用要点

`outrun` 保留了 `run` 的不规则变化：

`run → ran → run`  
`outrun → outran → outrun`

`outran` 是过去式，`outrun` 才是过去分词。

**She outran me yesterday.**  
她昨天跑赢了我。

**No one has outrun her this season.**  
本赛季还没有人跑赢过她。

---

# 7. overrun — overran — overrun

## 核心意义

`overrun` 可以表示超过预定时间、预算或范围，也可以表示某地被大量人员、植物等占据。

**The meeting overran by twenty minutes.**  
会议超时了二十分钟。

**The garden was overrun with weeds.**  
花园里杂草丛生。

## 三种形式与例句

| 形式 | 例句 | 使用说明 |
| --- | --- | --- |
| V1 `overrun` | **Meetings sometimes overrun when the agenda is too long.** 议程过长时，会议有时会超时。 | 一般现在时，描述常见情况 |
| V2 `overran` | **The meeting overran by thirty minutes.** 会议超时了三十分钟。 | 过去式 V2，描述实际超时 |
| V3 `overrun` | **The project has overrun its budget.** 这个项目已经超出了预算。 | `has + V3`，说明截至现在的情况 |

## 使用要点

`overrun` 同样保留 `run` 的变化：

`run → ran → run`  
`overrun → overran → overrun`

它既可以不及物使用，也可以直接接宾语：

**The meeting overran by half an hour.**  
会议超时了半小时。

**The project overran its budget.**  
项目超出了预算。

`be overrun with` 则常用来表示被过多的人或事物占据，例如 `be overrun with visitors / weeds`。这种结构中的 `overrun` 是过去分词，不是过去式。

# 8. A–B–A 型动词的共同特点

这组动词有两个值得一起观察的形态家族：

| 基础动词 | 派生动词 |
| --- | --- |
| come – came – come | become – became – become；overcome – overcame – overcome |
| run – ran – run | outrun – outran – outrun；overrun – overran – overrun |

在这些例子中，前缀不会改变基础动词的不规则变化方式。不过，派生动词各有自己的词义，不能只凭前缀猜测所有用法。

再比较同一词形在不同结构中的语法身份：

| 例句 | 语法身份 |
| --- | --- |
| **I run every morning.** 我每天早上跑步。 | 一般现在时，V1 |
| **I can run five kilometres.** 我能跑五公里。 | 情态动词后，V1 |
| **I ran five kilometres yesterday.** 我昨天跑了五公里。 | 一般过去时，V2 |
| **I've run five kilometres today.** 我今天已经跑了五公里。 | 现在完成时，V3 |
| **We had run the test before the release.** 发布前我们已经运行过测试。 | 过去完成时，V3 |

**形式相同并不意味着语法功能相同。** 选择 V1、V2 或 V3 时，仍应先判断句子使用的语法结构。
