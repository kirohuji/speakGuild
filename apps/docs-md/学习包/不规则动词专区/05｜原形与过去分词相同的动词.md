# 05｜原形与过去分词相同的动词

## 1. 认识 A–B–A 型不规则动词

这类动词的**原形与过去分词拼写相同，过去式另有变化**，可以记作 **A–B–A**。

| 原形      | 过去式     | 过去分词    | 核心释义    |
| -------- | -------- | -------- | -------- |
| come    | came    | come    | 来、到达    |
| become  | became  | become  | 变成、成为   |
| run     | ran     | run     | 跑、运转、经营 |
| overcome | overcame | overcome | 克服、战胜   |
| outrun  | outran  | outrun  | 跑得更快、超过 |
| overrun | overran | overrun | 超时、超支、侵占 |

这类动词数量较少，其中 come、become 和 run 尤为常见。其他几个动词虽然使用范围相对有限，但在表达困难、竞争、变化和项目管理时也很实用。

### 相同词形，不同语法身份

以 come 为例：

| 例句 | 使用见解 |
| --- | --- |
| **They come here every weekend.**<br>他们每周末都来这里。 | **一般现在时**：come 是一般现在时的谓语形式。 |
| **They came here yesterday.**<br>他们昨天来过这里。 | **一般过去时**：came 表示发生在过去的事件。 |
| **They've come here before.**<br>他们以前来过这里。 | **现在完成时**：have + come，come 在这里是过去分词。 |

原形与过去分词虽然拼写相同，但在句子中承担的语法身份不同。判断时需要结合助动词、时态和上下文。

# come

## 核心意义

come 表示向说话者、听话者或谈话中选定的参照点移动，也可以表示某件事情的到来或某种情况的发生。

| 例句 | 使用见解 |
| --- | --- |
| **Could you come over this evening?**<br>你今晚能过来吗？ | **朝参照点移动**：目的地与当前谈话存在联系。 |
| **Are you coming to the meeting?**<br>你会来参加会议吗？ | **参加或到场**：关注是否到场。 |
| **Winter has come early this year.**<br>今年冬天来得很早。 | **事情或时间到来**：时间、季节或事件也能作为主语。 |

## 使用见解

### come 与 go 的方向感

- **Come to my office when you have time.**  
  你有空时来我办公室。
- **I have to go to the office now.**  
  我现在得去办公室。

come 经常指向谈话双方所关注的地点；go 常用于表示从当前位置前往别处。

方向由交际参照点决定。例如，电话里对朋友说 **I'm coming over now.**，即使说话者当前并不在朋友家，仍然可以使用 coming，因为目的地是双方关注的位置。

### come 后的地点表达

- **She came home late.**  
  她回家很晚。
- **She came to my house late.**  
  她很晚才到我家。

home 在 come home 中作表示方向的副词，前面不需要 to；my house 是普通名词短语，前面通常使用 to。

类似的表达还有 **come here**、**come upstairs**、**come inside**。

### came 与 has come

- **He came back at five.**  
  他五点回来了。
- **He has come back, so you can talk to him now.**  
  他已经回来了，你现在可以和他谈谈。

came 将事件放在过去的时间线上；has come 可以强调到现在已经发生的变化或形成的结果。

## 三种形式与例句

| 例句 | 形式与使用见解 |
| --- | --- |
| **I usually come home around six.**<br>我通常六点左右到家。 | **原形：come**。come 表示经常发生的动作；主语是 I，动词保持原形。 |
| **Nobody came to the meeting yesterday.**<br>昨天没人来开会。 | **过去式：came**。came 是一般过去时，用于讲述昨天已经发生的事情。 |
| **A lot of people have come to see her.**<br>已经有很多人来看过她。 | **过去分词：come**。have + come 构成现在完成时；come 在这里是过去分词。 |

## 高频搭配

| 搭配 | 使用见解 / 例句 |
| --- | --- |
| **come back**<br>回来 | 强调返回之前所在的地点，可以用于返回家中、工作岗位或某个场所。<br><br>**She came back earlier than expected.**<br>她比预想的回来得早。<br><br>**Has David come back from his trip yet?**<br>戴维旅行回来了吗？ |
| **come over**<br>过来、来访 | 常用于邀请别人来自己所在的地方，尤其是家中；语气通常比较随意、亲近。<br><br>**Why don't you come over for dinner?**<br>你为什么不过来一起吃晚饭？<br><br>**Some friends came over last night.**<br>昨晚有几个朋友来家里做客。 |
| **come up with**<br>想出、提出 | 后接 idea、solution、plan、explanation 等，强调通过思考形成主意、办法或解释。<br><br>**Can you come up with a better solution?**<br>你能想出更好的解决办法吗？<br><br>**She has come up with an interesting idea.**<br>她已经想出了一个有趣的主意。 |
| **come true**<br>实现、成真 | 主语通常是 dream、wish、hope 或 prediction，表达原本期待或设想的事情成为现实。<br><br>**Her childhood dream finally came true.**<br>她儿时的梦想终于实现了。<br><br>**I still hope that one day it will come true.**<br>我仍希望有一天它会实现。 |
| **come to an end**<br>结束 | 表示一段过程、活动或时期到达终点。主语通常是会议、争端、旅程或某段经历。<br><br>**The concert came to an end at midnight.**<br>演唱会在午夜结束。<br><br>**The long dispute has finally come to an end.**<br>这场漫长的争端终于结束了。 |

# become

## 核心意义

become 表示人或事物从一种状态进入另一种状态，既能接形容词，也能接名词短语。

| 例句 | 使用见解 |
| --- | --- |
| **The room became quiet.**<br>房间安静了下来。 | **变得**：后接形容词，说明状态变化。 |
| **She became a doctor.**<br>她成了一名医生。 | **成为**：后接名词短语，说明身份变化。 |
| **Working from home has become common.**<br>居家办公已经变得普遍。 | **形成新的情况**：强调逐渐形成并延续到现在的局面。 |

## 使用见解

### become 与 be

- **He was angry.**  
  他当时很生气。
- **He became angry.**  
  他生气了。

be 用来说明某个时间点的状态；become 关注状态发生变化。

become 本身带有变化的意义，因此很适合描述人物成长、环境变化、关系发展或事情逐渐恶化。

### become 后接形容词或名词

- **The situation became complicated.**  
  情况变复杂了。
- **They became close friends.**  
  他们成了亲密的朋友。

常见结构包括：

- **become + adjective**：变得怎么样。
- **become + noun phrase**：成为某种身份或角色。

become 属于系动词，后接描述状态的形容词时，一般不使用副词形式。

### become 与 get

- **It's getting cold.**  
  天越来越冷了。
- **The situation has become increasingly complicated.**  
  情况已经变得越来越复杂。

get 在日常交流中很常见，尤其适合描述天气、心情和即时变化。

become 在正式说明、分析以及书面表达中也很自然，尤其适合描述较为抽象或持续发展的变化。

两者有不少可以互换的场景，但实际选择仍取决于搭配和语境。

### became 与 has become

- **The town became popular in the 1990s.**  
  这个小镇在20世纪90年代开始流行。
- **The town has become popular with tourists.**  
  这个小镇如今已经深受游客欢迎。

became 把变化定位在过去；has become 说明到目前为止已经形成的状态。

## 三种形式与例句

| 例句 | 形式与使用见解 |
| --- | --- |
| **Things can become difficult very quickly.**<br>事情可能很快变得困难。 | **原形：become**。can 后接动词原形 become，说明可能出现的变化。 |
| **We became good friends at university.**<br>我们在大学时成了好朋友。 | **过去式：became**。became 表示过去发生的身份或关系变化。 |
| **He has become much more confident.**<br>他现在自信多了。 | **过去分词：become**。has + become 描述到现在已经形成的状态。 |

## 高频搭配

| 搭配 | 使用见解 / 例句 |
| --- | --- |
| **become interested in**<br>开始对……感兴趣 | interested 后接 in，可以跟名词或动名词。强调兴趣从无到有，或逐渐发展。<br><br>**I became interested in photography at school.**<br>我上学时开始对摄影感兴趣。<br><br>**She has become interested in learning Japanese.**<br>她最近开始对学日语感兴趣。 |
| **become aware of**<br>意识到、察觉到 | 强调开始认识到某个事实、问题或风险。aware 后面通常使用 of，也可以直接接 that 从句。<br><br>**We became aware of the error too late.**<br>我们太晚才意识到这个错误。<br><br>**People have become more aware of the risks.**<br>人们已经更加意识到这些风险。 |
| **become familiar with**<br>逐渐熟悉 | 常用于工具、流程、工作环境、概念或某种做事方式，强调通过接触逐渐获得熟悉感。<br><br>**You'll become familiar with the interface soon.**<br>你很快就会熟悉这个界面。<br><br>**I've become familiar with their working methods.**<br>我已经逐渐熟悉了他们的工作方式。 |
| **become dependent on**<br>变得依赖 | dependent 常接 on。既可表示经济上的依赖，也可描述系统、服务或个人对某种条件的依赖。<br><br>**He became dependent on his parents for money.**<br>他在经济上变得依赖父母。<br><br>**Many services have become dependent on the internet.**<br>许多服务已经变得依赖互联网。 |
| **become increasingly + adjective**<br>变得越来越…… | increasingly 强调程度不断增加，适合描述长期趋势，在分析性和书面表达中比较常见。<br><br>**The problem became increasingly difficult to ignore.**<br>这个问题越来越难以忽视。<br><br>**Online security has become increasingly important.**<br>网络安全已经变得越来越重要。 |

# run

## 核心意义

run 的意义相当丰富，可以从“运动、持续运行”这一概念理解：人会跑，程序会运行，人也可以让企业或活动持续运转。

| 例句 | 使用见解 |
| --- | --- |
| **She runs every morning.**<br>她每天早上跑步。 | **跑步**：表示身体移动。 |
| **The script runs every hour.**<br>这个脚本每小时运行一次。 | **程序运行**：表示程序执行。 |
| **They run a small hotel.**<br>他们经营一家小旅馆。 | **经营管理**：表示维持某个组织的运营。 |
| **The road runs along the river.**<br>这条路沿着河流延伸。 | **延伸方向**：描述道路、管线等的空间走向。 |

## 使用见解

### run 的及物与不及物用法

- **The service runs in the background.**  
  这个服务在后台运行。
- **We run several tests every day.**  
  我们每天运行几项测试。

第一句中的 run 不需要宾语，表示服务自身运行。

第二句中的 run 直接接 tests，表示有人执行测试。

类似的区别还可以体现在：

- **The business runs smoothly.**  
  企业运营得很顺利。
- **She runs the business.**  
  她经营这家企业。

### run、start 与 operate

- **I started the server.**  
  我启动了服务器。
- **The server is running.**  
  服务器正在运行。
- **They operate several data centres.**  
  他们运营着几个数据中心。

start 强调启动动作；run 可以表示运行状态，也可以表示执行或管理；operate 常用于设备操作、系统运营和组织管理，语气通常较正式。

### ran 与 have run

- **I ran five kilometres yesterday.**  
  我昨天跑了五公里。
- **I have run five kilometres today.**  
  我今天已经跑了五公里。

过去式是 ran，过去分词是 run。

标准英语中，完成时应使用 **I've run**，不能使用 **I've ran**。

### run 在抽象表达中的延伸

- **The company ran into financial trouble.**  
  这家公司遇到了财务困难。
- **She has run the business for ten years.**  
  她经营这家企业已有十年。

run 可以进入很多固定表达，不同介词或宾语会影响整体意义。理解搭配时，最好把它放在完整的句子中。

## 三种形式与例句

| 例句 | 形式与使用见解 |
| --- | --- |
| **I run before breakfast most days.**<br>我大多数时候早餐前跑步。 | **原形：run**。一般现在时，说明经常性的跑步习惯。 |
| **We ran the program again last night.**<br>昨晚我们又运行了一遍程序。 | **过去式：ran**。ran 是过去式，叙述昨晚执行程序的动作。 |
| **The team has run the test three times.**<br>团队已经把测试运行了三遍。 | **过去分词：run**。has + run 构成现在完成时，强调截至目前已执行三次。 |

## 高频搭配

| 搭配 | 使用见解 / 例句 |
| --- | --- |
| **run out of**<br>用完、耗尽 | 后接具体资源，例如 money、time、milk、memory。主语一般是人、团队或某个系统，强调可用资源已经耗尽。<br><br>**We've run out of milk.**<br>我们的牛奶喝完了。<br><br>**The server ran out of memory during the test.**<br>服务器在测试期间耗尽了内存。 |
| **run into**<br>偶然遇见；遇到问题 | 宾语是人时，常表示偶遇；宾语是 problem、difficulty、trouble 时，表示遇到意料之外的障碍。<br><br>**I ran into an old friend at the station.**<br>我在车站偶遇了一位老朋友。<br><br>**We've run into a problem with the database.**<br>我们遇到了一个数据库问题。 |
| **run a business**<br>经营企业 | 强调日常运营、管理和维持企业正常运作。拥有企业和经营企业是两个不同的概念，因此 run 不一定意味着所有权。<br><br>**Her parents ran a small shop for years.**<br>她父母经营一家小店很多年。<br><br>**He has run his own business since 2020.**<br>他从2020年起一直经营自己的企业。 |
| **run a test**<br>执行测试 | 常见于软件开发、实验、研究和质量检测。run 可以直接接 test、script、program 或 command。<br><br>**Can you run the test again?**<br>你能再跑一次测试吗？<br><br>**We ran several tests before the release.**<br>发布前我们运行了几项测试。 |
| **run smoothly**<br>运行顺利、进展顺畅 | smoothly 是副词，表示运行或进行的过程顺畅。可以用于系统、机器、活动、业务或计划。<br><br>**The application has run smoothly all week.**<br>这个应用整个星期都运行顺畅。<br><br>**Everything ran smoothly during the event.**<br>活动期间一切都进行得很顺利。 |

# overcome

## 核心意义

overcome 表示成功克服某种困难、障碍或恐惧，也可以描述人受到强烈情绪的影响。

| 例句 | 使用见解 |
| --- | --- |
| **They overcame serious difficulties.**<br>他们克服了严重的困难。 | **克服困难**：强调成功应对障碍。 |
| **She overcame her fear of heights.**<br>她克服了恐高。 | **克服恐惧**：强调能够面对过去害怕的事物。 |
| **He was overcome with grief.**<br>他悲痛不已。 | **被情绪压倒**：描述情绪造成的强烈影响。 |

## 使用见解

### overcome 通常直接接宾语

- **We need to overcome this obstacle.**  
  我们需要克服这个障碍。
- **She has overcome many setbacks.**  
  她已经克服了许多挫折。

overcome 通常作为及物动词，直接接需要克服的事物。

常见宾语包括 difficulty、fear、obstacle、challenge、problem 和 setback。

### overcome 与 solve

- **We solved the technical problem.**  
  我们解决了这个技术问题。
- **We overcame several technical difficulties.**  
  我们克服了几个技术难题。

solve 常强调找出问题的答案或解决办法。

overcome 更关注面对障碍并成功跨过去的过程，尤其适合描述挑战、阻力、困难和恐惧。

### overcame 与 have overcome

- **They overcame the problem last night.**  
  他们昨晚克服了这个问题。
- **They have overcome the main obstacle.**  
  他们已经克服了主要障碍。

overcame 用于过去发生的事件；have overcome 常用于说明目前已经取得的成果。

### be overcome with / by

- **She was overcome with emotion.**  
  她激动得难以自持。
- **He was overcome by exhaustion.**  
  他累得支撑不住了。

这种用法强调强烈的情绪或身体感受让人难以控制自己。

常见表达包括 **be overcome with grief**、**be overcome with emotion** 和 **be overcome by exhaustion**。

## 三种形式与例句

| 例句 | 形式与使用见解 |
| --- | --- |
| **We must overcome these technical issues.**<br>我们必须克服这些技术问题。 | **原形：overcome**。must 后使用原形 overcome，表达必须面对并克服的问题。 |
| **He eventually overcame his fear of flying.**<br>他最终克服了对飞行的恐惧。 | **过去式：overcame**。overcame 表示过去成功克服恐惧的经历。 |
| **We've finally overcome the biggest difficulty.**<br>我们终于克服了最大的困难。 | **过去分词：overcome**。have + overcome 表示截至目前已经克服困难。 |

## 高频搭配

| 搭配 | 使用见解 / 例句 |
| --- | --- |
| **overcome difficulties**<br>克服困难 | 适合描述成长经历、工作挑战以及完成某件事情过程中遇到的困难。<br><br>**She overcame many difficulties during her studies.**<br>她在求学期间克服了很多困难。<br><br>**The team has overcome several unexpected difficulties.**<br>团队已经克服了几项意料之外的困难。 |
| **overcome fear**<br>克服恐惧 | 表示逐渐能够面对原本害怕的事物。可以使用 overcome one's fear of something 来说明具体恐惧对象。<br><br>**He wants to overcome his fear of public speaking.**<br>他想克服公开演讲的恐惧。<br><br>**She overcame her fear and entered the room.**<br>她克服了恐惧，走进房间。 |
| **overcome obstacles**<br>克服障碍 | obstacles 可以指实际存在的障碍，也可以指法律、资源、技术或制度方面的阻碍。<br><br>**We had to overcome several legal obstacles.**<br>我们不得不克服几项法律障碍。<br><br>**They have overcome the main obstacle to progress.**<br>他们已经克服了进展中的主要障碍。 |
| **overcome a setback**<br>克服挫折 | setback 指让计划或发展暂时受阻的事情。overcome a setback 强调经历挫折后成功继续前进。<br><br>**The company overcame a serious setback.**<br>公司克服了一次严重挫折。<br><br>**He has overcome setbacks throughout his career.**<br>他的职业生涯中克服过不少挫折。 |
| **be overcome with emotion**<br>情绪激动得难以自持 | 常用于描述某人受到强烈情绪影响，甚至一时无法说话或控制表情。<br><br>**She was overcome with emotion at the ceremony.**<br>她在典礼上激动得难以自持。<br><br>**He was overcome with relief when he heard the news.**<br>听到消息时，他如释重负，情绪激动。 |

# outrun

## 核心意义

outrun 由 out- 和 run 构成，其中 out- 带有超过、胜过的含义。

除了表示跑得比别人快，outrun 还可以描述需求、供应或某种发展速度超过另一方。

| 例句 | 使用见解 |
| --- | --- |
| **She outran everyone in the race.**<br>她在比赛中跑赢了所有人。 | **跑赢某人**：强调奔跑速度上的优势。 |
| **Demand has outrun supply.**<br>需求已经超过供应。 | **需求超过供应**：表示需求增长快于供应能力。 |

## 使用见解

### outrun 的及物用法

- **The cyclist outran the dogs.**  
  骑车人把那些狗甩在了后面。
- **Demand has outrun supply.**  
  需求已经超过供应。

outrun 通常直接接被超越的对象。

其宾语既可以是竞争对手，也可以是 supply、capacity 等抽象概念。

### outrun 与 overtake

- **He outran the other competitors.**  
  他跑赢了其他参赛者。
- **He overtook another runner near the finish line.**  
  他在接近终点时超过了另一名跑者。

outrun 强调跑得更快并取得速度上的优势。

overtake 更关注从后方追上并超过的动作，也可以用于车辆超车。

### outran 与 have outrun

- **He outran his rivals yesterday.**  
  他昨天跑赢了对手。
- **He has outrun them several times.**  
  他已经好几次跑赢他们。

outrun 延续 run 的不规则变化：

**run → ran → run**

**outrun → outran → outrun**

## 三种形式与例句

| 例句 | 形式与使用见解 |
| --- | --- |
| **Few runners can outrun her.**<br>很少有跑者能跑赢她。 | **原形：outrun**。can 后使用 outrun 原形，表示跑得比别人快的能力。 |
| **He outran the other competitors.**<br>他跑赢了其他参赛者。 | **过去式：outran**。outran 是过去式，说明比赛中的过去结果。 |
| **Demand has outrun supply this year.**<br>今年需求已经超过了供应。 | **过去分词：outrun**。has + outrun 构成完成时，说明今年截至目前需求已超过供应。 |

## 高频搭配

| 搭配 | 使用见解 / 例句 |
| --- | --- |
| **outrun someone**<br>跑赢某人 | 最直接的运动意义，表示速度超过某个人。也可用于描述逃跑者成功甩开追赶者。<br><br>**She easily outran me on the final stretch.**<br>最后一段路她轻松跑赢了我。<br><br>**No one has outrun him this season.**<br>本赛季还没人跑赢过他。 |
| **outrun the competition**<br>跑赢竞争对手 | 可以描述赛跑中的优势，也能引申到商业竞争中，但商业语境下也常使用 outperform the competition。<br><br>**The young runner outran the competition with ease.**<br>这名年轻跑者轻松跑赢了其他选手。<br><br>**The company hopes to outrun the competition by expanding faster.**<br>公司希望通过更快扩张来领先竞争对手。 |
| **outrun supply**<br>需求超过供应 | 主语通常是 demand、orders 等，表示需求增长速度超过供应的增长速度或供应能力。<br><br>**Demand outran supply last winter.**<br>去年冬天需求超过了供应。<br><br>**Orders have outrun supply for months.**<br>订单需求已经连续数月超过供应。 |
| **outrun demand**<br>供应或生产增长超过需求 | 主语通常是 production、supply 等。表达这一类经济关系时，还可以使用 outpace demand。<br><br>**Production outran demand during the summer.**<br>夏季的生产增长超过了需求。<br><br>**Supply has outrun demand in some regions.**<br>部分地区的供应已经超过需求。 |

# overrun

## 核心意义

overrun 描述某件事情超过预定的时间、预算或范围，也能表示人、植物、害虫等大量进入并占据某处。

| 例句 | 使用见解 |
| --- | --- |
| **The meeting overran by twenty minutes.**<br>会议超时了20分钟。 | **超出时间**：实际持续时间超过安排。 |
| **The project overran its budget.**<br>项目超出了预算。 | **超过预算**：实际支出超过预设限额。 |
| **The garden was overrun with weeds.**<br>花园里杂草丛生。 | **大量占据**：某物在一个地方大量出现。 |

## 使用见解

### overrun 的及物与不及物用法

- **The meeting overran by half an hour.**  
  会议超时了半小时。
- **The project overran its budget.**  
  项目超出了预算。

第一句中 overrun 为不及物动词，by 引出超过的时间量。

第二句中 overrun 是及物动词，直接接 budget。

在项目管理语境中，**go over budget** 和 **exceed the budget** 也很常见。

### overrun 与 run out of

- **The meeting overran by twenty minutes.**  
  会议超时了20分钟。
- **We ran out of time.**  
  我们的时间用完了。

overrun 关注活动超过原定时长。

run out of time 表示可用时间已经耗尽，常暗示任务尚未完成或时间已经不够。

### be overrun with

- **The park was overrun with tourists.**  
  公园里挤满了游客。
- **The garden has been overrun with weeds.**  
  花园里已经长满了杂草。

be overrun with 通常暗示某种人或事物的数量过多，已经影响正常环境或秩序。

与普通的 **be full of** 相比，overrun 往往带有更明显的负面意味。

### overran 与 has overrun

- **The meeting overran yesterday.**  
  昨天会议超时了。
- **The meeting has overrun again.**  
  会议又超时了。

注意过去式使用 overran，完成时使用 overrun。

## 三种形式与例句

| 例句 | 形式与使用见解 |
| --- | --- |
| **Meetings sometimes overrun when the agenda is too long.**<br>议程过长时，会议有时会超时。 | **原形：overrun**。一般现在时，描述会议在某种条件下容易超时的情况。 |
| **The meeting overran by thirty minutes.**<br>会议超时了30分钟。 | **过去式：overran**。overran 是过去式；by 表示超出的具体时长。 |
| **The project has overrun its budget.**<br>这个项目已经超出了预算。 | **过去分词：overrun**。has + overrun 构成现在完成时，说明项目已经超出预算。 |

## 高频搭配

| 搭配 | 使用见解 / 例句 |
| --- | --- |
| **overrun by + 时间**<br>超时若干时间 | by 引出实际超过的时间量，常用于会议、面试、演讲和其他有明确时间安排的活动。<br><br>**The interview overran by ten minutes.**<br>面试超时了10分钟。<br><br>**The presentation has overrun by nearly half an hour.**<br>演示已经超时将近半小时。 |
| **overrun the budget**<br>超过预算 | 表示实际花费突破事先设定的预算限额。正式商业英语中也常见 exceed the budget 和 go over budget。<br><br>**The project overran its budget last year.**<br>这个项目去年超出了预算。<br><br>**Construction costs have exceeded the budget again.**<br>建设成本又超出了预算。 |
| **be overrun with weeds**<br>长满杂草 | 常用于花园、农田或无人维护的土地，强调杂草大量生长并占据空间。<br><br>**The garden was overrun with weeds.**<br>花园里长满了杂草。<br><br>**The fields have become overrun with weeds.**<br>田地已经杂草丛生。 |
| **be overrun with visitors**<br>来访者过多、游客爆满 | 强调某个地方涌入过多的人，常常隐含拥挤、超负荷或秩序受到影响。<br><br>**The small town was overrun with visitors in summer.**<br>夏天这座小镇挤满了游客。<br><br>**The museum has been overrun with visitors since it reopened.**<br>博物馆重新开放后一直游客爆满。 |

# A–B–A 型动词的关键语法

## 原形与过去分词依靠结构区分

| 例句 | 使用见解 |
| --- | --- |
| **I run every morning.**<br>我每天早上跑步。 | **一般现在时**：run 是现在时谓语的形式。 |
| **I can run five kilometres.**<br>我能跑五公里。 | **情态动词 + 原形**：can 后使用动词原形。 |
| **I've run five kilometres today.**<br>我今天已经跑了五公里。 | **have + 过去分词**：run 在这里是过去分词。 |
| **We had run the test before the release.**<br>发布前我们已经运行过测试。 | **had + 过去分词**：had + run 构成过去完成时。 |

特别注意：

- **I've run.** ✓ / ~~I've ran.~~
- **She has come.** ✓ / ~~She has came.~~
- **He has become confident.** ✓ / ~~He has became confident.~~

过去分词要根据动词自身的变化规律选择，不能直接把过去式放在 have 或 had 后面。

## 过去式与完成式的时间视角

| 一般过去时 | 现在完成时 |
| --- | --- |
| **She came back at five.**<br>她五点回来了。 | **She's come back. She's upstairs now.**<br>她已经回来了，现在在楼上。 |
| **The situation became worse last week.**<br>情况上周恶化了。 | **The situation has become worse.**<br>情况现在已经恶化了。 |
| **We ran the program yesterday.**<br>我们昨天运行了程序。 | **We've run the program several times.**<br>程序我们已经运行过好几次了。 |

一般过去时适合将事件放在明确的过去时间中。

现在完成时可以说明直到现在的经历、变化或结果。它不一定表示结果一直持续，具体仍要结合动词意义和语境。

## 派生动词保留变化方式

| 基础动词 | 派生动词及变化 |
| --- | --- |
| **come → came → come** | become → became → become<br><br>overcome → overcame → overcome |
| **run → ran → run** | outrun → outran → outrun<br><br>overrun → overran → overrun |

这些动词虽然共享相似的变化规律，但各自已经形成了独立而稳定的意义。

例如：

- **become**：进入新的状态。
- **overcome**：克服障碍。
- **outrun**：在速度或增长方面超过。
- **overrun**：超过限额，或大量占据某个地方。

通过基础动词可以推导词形，但理解实际意义仍需结合完整的搭配。

# 综合 Case｜服务器出问题的那个晚上

## 深夜的报警

晚上十一点，我正准备下班，监控突然报警。一个重要服务停止了响应。我马上跑回办公室，同事已经回来了。

**I ran back to the office.**  
我跑回了办公室。

**Two of my colleagues had already come back.**  
两名同事已经回来了。

## 问题逐渐恶化

我们重新启动了服务。几分钟以后，它又停了。检查日志后，我们发现数据库连接已经全部耗尽。

**We restarted the service.**  
我们重新启动了服务。

**We had run out of database connections.**  
我们的数据库连接已经耗尽了。

问题比最开始看起来严重得多。凌晨一点，越来越多的请求开始失败。请求量已经超过系统能够处理的容量。

**The problem had become much more serious than we first thought.**  
问题已经变得比我们最初想象的严重得多。

**Demand had outrun the system's capacity.**  
请求需求已经超过了系统的承载能力。

## 反复尝试

我们临时增加了几台服务器。系统恢复几分钟后，再次出现相同的问题。大家已经连续工作了几个小时，同样的测试反复执行。

**We had run the same tests again and again.**  
我们已经反复运行了相同的测试。

凌晨三点，我终于注意到一个很小的配置差异。新版本发布后，一个连接池参数发生了变化。我们调整配置，重新启动服务。这一次，所有测试都通过了。

**Every test ran successfully.**  
所有测试都成功运行了。

## 故障解决

半小时后，流量恢复正常，最大的故障终于解决。

**We had finally overcome the biggest problem.**  
我们终于克服了最大的问题。

天快亮的时候，我走出办公室。其他同事也陆续出来。我们谁都没说话。一次普通报警已经演变成一次严重事故。

**Everyone had come outside.**  
大家都已经走到了外面。

**A routine alert had become a major incident.**  
一次例行警报已经演变成了一次严重事故。

## Case 中的动词回顾

| 动词 | 故事中的实际意义 |
| --- | --- |
| **ran back** | 跑回办公室，描述过去的动作。 |
| **had come back** | 在叙述的时间点之前，同事已经回来。 |
| **had run out of** | 数据库连接已经耗尽。 |
| **had become** | 问题在过去某个时间点之前已经恶化。 |
| **had outrun** | 请求需求超过系统承载能力。 |
| **had run** | 在过去某个时间点之前已经反复执行测试。 |
| **had overcome** | 到当时为止，团队已经克服主要困难。 |

这个故事将多个 A–B–A 型动词放在同一段经历中，也展示了过去式与过去完成时如何配合使用：过去式推进主要事件，过去完成时交代在某个过去时间点之前已经发生的变化或结果。

这里的过去完成时需要有明确或隐含的过去参照点。例如，**We had run out of database connections** 表示在团队检查日志、发现问题的时候，连接就已经耗尽了。叙述故事时，可以借助这种时态关系自然地交代事件发生的先后顺序。
