# 三种形式相同的动词

## 1. 认识 A–A–A 型不规则动词

英语中有一类不规则动词，它们的三种形式在拼写上完全相同：

| 原形        | 过去式       | 过去分词      | 核心释义     |
| --------- | --------- | --------- | -------- |
| cut       | cut       | cut       | 切、割、削减   |
| put       | put       | put       | 放置       |
| hit       | hit       | hit       | 击打、撞击    |
| hurt      | hurt      | hurt      | 使受伤、疼痛   |
| let       | let       | let       | 允许、让     |
| set       | set       | set       | 设置、确定、放置 |
| shut      | shut      | shut      | 关闭       |
| split     | split     | split     | 分开、分裂    |
| spread    | spread    | spread    | 展开、传播    |
| cost      | cost      | cost      | 花费       |
| burst     | burst     | burst     | 爆裂、突然爆发  |
| broadcast | broadcast | broadcast | 广播、播送    |

这一类动词通常被归为 A–A–A 型不规则动词。

虽然三个形式的拼写完全相同，但它们在句子中仍然具有不同的语法功能。

比较：

| 例句 | 语法形式 |
| --- | --- |
| **I usually cut the vegetables first.**<br>我通常先切蔬菜。 | 一般现在时 |
| **I cut my finger yesterday.**<br>我昨天割伤了手指。 | 一般过去时 |
| **I've already cut the vegetables.**<br>我已经切好蔬菜了。 | 现在完成式 |

三个 cut 的外形相同，但通过时间表达、助动词和句子结构，我们仍然能够判断它们的语法身份。


# cut

## 核心意义

cut 的基本意义是通过切割，使物体发生分离或改变形状。

这一意义还可以延伸到减少数量、中断连接和停止供应等抽象场景。

| 例句 | 使用见解 |
| --- | --- |
| **She cut the bread into slices.**<br>她把面包切成了片。 | **切割**：通过切割改变物体的形状。 |
| **I cut my finger while cooking.**<br>我做饭时割伤了手指。 | **割伤**：切割动作造成身体损伤。 |
| **He cuts the grass every weekend.**<br>他每周末修剪草坪。 | **修剪**：去除某物的一部分。 |
| **The company cut its expenses.**<br>公司削减了开支。 | **削减**：减少原有数量。 |
| **The electricity was cut off.**<br>电力供应中断了。 | **切断**：原有的供应被中断。 |

这些用法之间存在意义上的联系。理解这种联系，有助于掌握 cut 在不同场景中的使用。

## 使用见解

### cut 通常是及物动词，也可以不及物使用

及物用法中，cut 后面直接接被切割的对象。

**She cut the rope.**  
她割断了绳子。

不及物用法可以描述某种材料被切割时的特点。

**This material cuts easily.**  
这种材料很容易切割。

### cut 后面可以继续说明切割的结果

比较：

**She cut the cake.**  
她切了蛋糕。

**She cut the cake in half.**  
她把蛋糕切成了两半。

**She cut the cake into six pieces.**  
她把蛋糕切成了六块。

| 结构                        | 含义       | 使用特点        |
| ------------------------- | -------- | ----------- |
| cut something in half     | 把某物切成两半  | 强调形成两个相等的部分 |
| cut something into pieces | 把某物切成若干块 | 强调切割之后的结果   |
| cut something into slices | 把某物切成片   | 强调切割后的形状    |

其中，into 经常用于表达事物经过变化后形成的结果。

### cut 与 reduce 的区别

两个词都可以表达“减少”。

**We need to cut costs.**  
我们需要削减成本。

**We need to reduce costs.**  
我们需要降低成本。

cut 往往带有更加直接、明确的削减意味，在预算、支出和人员数量等语境中十分常见。

reduce 的适用范围更广，也经常用于描述程度、数量和水平的降低。

## 三种形式与例句

| 例句 | 语法形式与说明 |
| --- | --- |
| **I usually cut the vegetables before cooking.**<br>我通常在做饭前先切好蔬菜。 | **原形**：用于一般现在时或原形结构。 |
| **He cut his hand while opening the box.**<br>他打开盒子时割伤了手。 | **过去式**：描述过去发生的动作。 |
| **They've cut the budget by 20%.**<br>他们已经削减了20%的预算。 | **过去分词**：用于完成时或相关结构。 |
| **The cable was cut during construction.**<br>电缆在施工期间被切断了。 | **过去分词（被动）**：用于被动结构。 |

## 高频搭配

| 搭配 | 使用见解 / 例句 |
| --- | --- |
| **cut down on something**<br>减少某物的使用或消耗 | 常用于饮食、消费和生活习惯<br><br>**I'm trying to cut down on sugar.**<br>我正在努力减少糖分摄入。<br><br>**We should cut down on unnecessary screen time.**<br>我们应该减少不必要的屏幕使用时间。 |
| **cut back on something**<br>削减、缩减 | 常用于支出、资源和活动<br><br>**The team had to cut back on travel expenses.**<br>团队不得不削减差旅开支。<br><br>**I've cut back on eating out this month.**<br>这个月我减少了外出吃饭的次数。 |

# put

## 核心意义

put 是英语中最常见的动词之一，其核心含义是：

使某个人或某个事物处于特定的位置或状态。

这种含义既可以涉及实际空间，也可以涉及抽象状态。

| 例句 | 使用见解 |
| --- | --- |
| **Put the book on the shelf.**<br>把书放到架子上。 | **放置**：使物体处于某个位置。 |
| **Put the keys back.**<br>把钥匙放回去。 | **放回**：使物体回到原来的位置。 |
| **Put your clothes away.**<br>把衣服收好。 | **收好**：将物品放到适当的位置。 |
| **The news put her in a difficult position.**<br>这个消息让她陷入了困境。 | **使处于某种状态**：使某人进入特定处境。 |

## 使用见解

### put 通常需要说明放置的位置或结果

这是 put 非常重要的语法特点。

比较：

**I put the book.**  
这个句子在通常语境下信息不完整。

**I put the book on the table.**  
我把书放在桌上。

**I put the book back.**  
我把书放了回去。

put 通常采用以下结构：

put + 宾语 + 位置 / 方向 / 状态补语

因此，在描述实际的放置动作时，往往需要说明物体最终处于什么位置。

### put 与 leave 的区别

**I put my bag on the chair.**  
我把包放到了椅子上。

**I left my bag on the chair.**  
我把包留在了椅子上。

put 关注放置动作，leave 更关注物体被留下的状态。

例如：

**I left my phone at home.**  
我把手机落在家里了。

这里使用 leave 非常自然，因为说话者强调手机仍然留在家中。

### put 可以表达抽象状态的变化

**Don't put too much pressure on yourself.**  
不要给自己太大压力。

这里的 put 已经超出了实际的空间放置，但仍然保留着“使某物施加到某个对象上”的意义。

## 三种形式与例句

| 例句 | 语法形式与说明 |
| --- | --- |
| **I usually put my phone beside my bed.**<br>我通常把手机放在床边。 | **原形**：用于一般现在时或原形结构。 |
| **She put the documents on my desk yesterday.**<br>她昨天把文件放在了我的桌上。 | **过去式**：描述过去发生的动作。 |
| **I've already put everything away.**<br>我已经把所有东西都收好了。 | **过去分词**：用于完成时或相关结构。 |
| **The chairs were put outside.**<br>椅子被搬到了外面。 | **过去分词（被动）**：用于被动结构。 |

## 高频搭配

| 搭配 | 使用见解 / 例句 |
| --- | --- |
| **put off**<br>推迟 | 常用于会议、计划和任务<br><br>**They've put off the launch until next week.**<br>他们把发布推迟到了下周。<br><br>**Don't put off calling her again.**<br>别再拖着不给她打电话了。 |
| **put up with**<br>忍受 | 表达对不愉快情况的容忍<br><br>**I can't put up with the noise anymore.**<br>我再也受不了这种噪音了。<br><br>**How do you put up with such long meetings?**<br>你是怎么忍受这么长的会议的？ |
| **put together**<br>组装；整理 | 可用于实物或信息<br><br>**Can you help me put this shelf together?**<br>你能帮我组装这个架子吗？<br><br>**She put together a short report for the meeting.**<br>她为会议整理了一份简短的报告。 |
| **put forward**<br>提出 | 常用于建议、观点或方案<br><br>**He put forward an interesting suggestion.**<br>他提出了一个有意思的建议。<br><br>**Several new proposals were put forward yesterday.**<br>昨天有人提出了几项新方案。 |
| **put someone through something**<br>使某人经历某事 | 常用于困难或不愉快的经历<br><br>**I'm sorry I put you through all that trouble.**<br>抱歉让你经历了那么多麻烦。<br><br>**The experience put her through a lot of stress.**<br>那次经历让她承受了很大压力。 |

# hit

## 核心意义

hit 的核心意义是某个人或事物与另一个对象发生接触、撞击或冲击。

这一含义也可以延伸到达到特定数值、受到事件影响等情况。

| 例句 | 使用见解 |
| --- | --- |
| **He hit the ball with a bat.**<br>他用球棒击球。 | **击打**：某物与目标发生接触。 |
| **The car hit a wall.**<br>汽车撞上了一堵墙。 | **撞击**：物体发生碰撞。 |
| **Sales hit a record high.**<br>销售额创下历史新高。 | **达到数值**：某个数值达到特定水平。 |
| **The town was hit by a storm.**<br>这座小镇遭到暴风雨袭击。 | **受到冲击**：外部事件造成影响。 |

## 使用见解

### hit 通常直接接被击中的目标

**The ball hit the window.**  
球击中了窗户。

**The car hit a tree.**  
汽车撞上了一棵树。

这里的 hit 是及物动词，直接说明撞击对象。

### hit 与 beat 的区别

两个动词都可以表示“打”，但使用侧重点不同。

**He hit me on the arm.**  
他打了我的胳膊一下。

**He beat me in the game.**  
他在比赛中击败了我。

hit 强调击打或撞击动作。

beat 可以表示反复击打，也可以表示在竞争中击败某人。

### hit 也经常用于数值和程度

**The temperature hit 40 degrees.**  
气温达到了40度。

**The company hit its sales target.**  
公司达成了销售目标。

在这些表达中，hit 表示达到某个具体数值或目标。

## 三种形式与例句

| 例句 | 语法形式与说明 |
| --- | --- |
| **Don't hit the table.**<br>别敲桌子。 | **原形**：用于一般现在时或原形结构。 |
| **The ball hit the window yesterday.**<br>昨天球击中了窗户。 | **过去式**：描述过去发生的动作。 |
| **The area has been hit by heavy rain.**<br>这一地区受到了暴雨影响。 | **过去分词**：用于完成时或相关结构。 |
| **The window was hit by a stone.**<br>窗户被石头击中了。 | **过去分词（被动）**：用于被动结构。 |

## 高频搭配

| 搭配 | 使用见解 / 例句 |
| --- | --- |
| **hit a target**<br>击中目标；达到目标 | 可以用于实际或抽象目标<br><br>**We finally hit our monthly sales target.**<br>我们终于完成了月度销售目标。<br><br>**The arrow hit the target on the first try.**<br>箭第一次就射中了靶子。 |
| **hit a record high**<br>达到历史新高 | 常见于经济、天气和统计数据<br><br>**Temperatures hit a record high yesterday.**<br>昨天气温创下历史新高。<br><br>**The company's shares hit a record high in June.**<br>这家公司的股价在六月创下历史新高。 |
| **hit the road**<br>出发、上路 | 常见的口语表达<br><br>**We'd better hit the road before it gets dark.**<br>我们最好趁天黑前出发。<br><br>**It's getting late; let's hit the road.**<br>时间不早了，我们出发吧。 |
| **hit someone hard**<br>对某人造成重大打击 | 可表示身体或情感上的冲击<br><br>**Losing the match hit him hard.**<br>输掉比赛对他打击很大。<br><br>**The sudden news hit her hard.**<br>突如其来的消息给了她很大打击。 |
| **hit the brakes**<br>踩刹车 | 强调突然或迅速采取动作<br><br>**The driver hit the brakes when he saw the dog.**<br>司机看到那只狗时猛踩了刹车。<br><br>**I had to hit the brakes at the crossing.**<br>我在路口不得不急刹车。 |

# hurt

## 核心意义

hurt 表示身体受到伤害、产生疼痛，也可以描述心理和情感上的伤害。

| 例句 | 使用见解 |
| --- | --- |
| **He hurt his knee.**<br>他伤到了膝盖。 | **使某人受伤**：身体受到损伤。 |
| **My back hurts.**<br>我的背疼。 | **身体疼痛**：身体某处产生疼痛。 |
| **Her words hurt me.**<br>她的话伤害了我。 | **伤害感情**：言语造成情感伤害。 |
| **The decision hurt the company.**<br>这个决定损害了公司的利益。 | **对某事造成损害**：某种行为造成负面影响。 |

## 使用见解

### hurt 既可以是及物动词，也可以是不及物动词

及物用法：

**I hurt my shoulder.**  
我伤到了肩膀。

不及物用法：

**My shoulder hurts.**  
我的肩膀疼。

两个句子关注的内容不同。

前者说明身体受到了伤害，后者描述身体当前的疼痛状态。

### hurt、injure 和 ache 的区别

| 动词     | 核心含义       | 例句                  |
| ------ | ---------- | ------------------- |
| hurt | 受伤；疼痛；造成伤害 | **My arm hurts.** |
| injure | 使受伤 | **He injured his leg.** |
| ache | 持续隐痛、酸痛 | **My head aches.** |

hurt 的适用范围很广，既可以描述身体疼痛，也可以描述情感上的伤害。

injure 通常强调身体损伤。

ache 则经常描述持续性的疼痛。

### hurt 经常用于表达情感伤害

**I didn't mean to hurt you.**  
我并没有打算伤害你。

**What she said really hurt my feelings.**  
她说的话真的伤害了我的感情。

## 三种形式与例句

| 例句 | 语法形式与说明 |
| --- | --- |
| **Be careful not to hurt yourself.**<br>小心别伤到自己。 | **原形**：用于一般现在时或原形结构。 |
| **I hurt my leg while running.**<br>我跑步时伤到了腿。 | **过去式**：描述过去发生的动作。 |
| **I've hurt my shoulder again.**<br>我又弄伤了肩膀。 | **过去分词**：用于完成时或相关结构。 |
| **Several people were hurt in the accident.**<br>有几个人在事故中受伤。 | **过去分词（被动）**：用于被动结构。 |

## 高频搭配

| 搭配 | 使用见解 / 例句 |
| --- | --- |
| **hurt someone's feelings**<br>伤害某人的感情 | 常用于人际交流<br><br>**I didn't mean to hurt your feelings.**<br>我并不想伤害你的感情。<br><br>**His careless remark hurt her feelings.**<br>他不经意的一句话伤害了她的感情。 |
| **hurt yourself**<br>伤到自己 | 既可以描述身体伤害，也可以描述不利于自己的行为<br><br>**Be careful not to hurt yourself.**<br>小心别伤到自己。<br><br>**You could hurt yourself lifting that box alone.**<br>你一个人搬那个箱子可能会弄伤自己。 |
| **be badly hurt**<br>受重伤 | 强调受伤程度<br><br>**Two passengers were badly hurt in the accident.**<br>两名乘客在事故中受了重伤。<br><br>**He was badly hurt when he fell off his bike.**<br>他从自行车上摔下来时伤得很重。 |
| **get hurt**<br>受伤 | 常见于口语<br><br>**Did anyone get hurt in the crash?**<br>那次碰撞有人受伤吗？<br><br>**I don't want you to get hurt.**<br>我不希望你受伤。 |
| **it wouldn't hurt to do something**<br>做某事也无妨 | 用于委婉提出建议<br><br>**It wouldn't hurt to ask for another opinion.**<br>再征求一个意见也无妨。<br><br>**It wouldn't hurt to check the figures once more.**<br>再核对一遍数字也无妨。 |

# let

## 核心意义

let 的核心意义是允许某人做某事，或者使某种行为得以发生。

它经常用于请求、许可、建议和日常交流。

## 使用见解

### let 是常见的使役动词

基本结构：

let + 宾语 + 动词原形

例如：

**Let me explain.**  
让我解释一下。

**She let him leave early.**  
她允许他提前离开。

这里的宾语是动作的执行者。

### let 后面的不定式通常不带 to

正确：

**Let him go.**  
错误：

**Let him to go.**  
这是 let 作为使役动词时非常重要的结构特点。

### let 与 allow 的区别

**My parents let me stay out late.**  
我父母允许我晚点回家。

**My parents allowed me to stay out late.**  
我父母允许我晚点回家。

| 动词    | 常见结构                          | 使用特点       |
| ----- | ----------------------------- | ---------- |
| let   | let someone do something      | 日常口语中非常常见  |
| allow | allow someone to do something | 在正式表达中也很常见 |

### let 的被动表达受到限制

普通现代英语中，表示“允许某人做某事”时，通常使用 be allowed to 来表达被动意义。

主动：

**They let us leave early.**  
他们允许我们提前离开。

被动：

**We were allowed to leave early.**  
我们被允许提前离开。

## 三种形式与例句

| 例句 | 语法形式与说明 |
| --- | --- |
| **Please let me know when you arrive.**<br>到达后请告诉我。 | **原形**：用于一般现在时或原形结构。 |
| **She let me borrow her laptop yesterday.**<br>她昨天让我借用了笔记本电脑。 | **过去式**：描述过去发生的动作。 |
| **The apartment has been let to a new tenant.**<br>这套公寓已经出租给一位新租客。 | **过去分词**：用于完成时或相关结构。 |

最后一句中的 let 表示“出租”，这种用法在英式英语中尤其常见。

## 高频搭配

| 搭配 | 使用见解 / 例句 |
| --- | --- |

## 使用见解

### burst 可以是不及物动词

**The balloon burst.**  
气球爆了。

这里直接描述气球发生的变化。

### burst 经常与 into 和 out 搭配

| 结构               | 含义       | 例句                        |
| ---------------- | -------- | ------------------------- |
| burst into + 名词 | 突然进入某种状态 | **She burst into tears.** |
| burst out + -ing | 突然开始某个动作 | **He burst out laughing.** |
| burst into + 地点 | 突然闯入某处 | **They burst into the room.** |

需要注意两个表达：

- burst into tears
- burst out laughing

前者使用名词 tears，后者使用动名词 laughing。

### burst 和 break 的区别

**The balloon burst.**  
气球爆了。

**The glass broke.**  
玻璃碎了。

burst 经常带有压力突然释放、事物突然爆开的含义。

break 的适用范围更广，可以表示破裂、损坏或折断。

| 例句 | 语法形式与说明 |

| **One of the pipes has burst.**<br>其中一根水管已经爆裂了。 | **过去分词**：用于完成时或相关结构。 |

# broadcast

## 核心意义

broadcast 表示通过电视、广播或其他传播媒介向公众传递内容。

它既可以表示信息传播的行为，也可以表示节目被播出的过程。

| 例句 | 使用见解 |
| --- | --- |
| **They broadcast the news every evening.**<br>他们每晚播报新闻。 | **广播**：通过媒体传递信息。 |
| **The match was broadcast live.**<br>比赛进行了现场直播。 | **电视播出**：通过电视或网络播送。 |
| **The speech was broadcast nationwide.**<br>演讲在全国播出。 | **公开传播**：内容传播到广大受众。 |

## 使用见解

### broadcast 通常是及物动词

**The station broadcast the interview.**  
电台播出了这场采访。

宾语通常是被传播的内容，例如新闻、节目、采访和比赛。

### broadcast 经常用于被动结构

**The programme was broadcast yesterday.**  
这个节目昨天播出了。

**The event has been broadcast in several countries.**  
这场活动已经在多个国家播出。

这里的 broadcast 都是过去分词。

### broadcast、publish 和 stream 的区别

| 动词        | 核心意义     | 常见语境          |

| publish   | 出版、发表    | 文章、书籍、研究和网络内容 |
| stream    | 通过网络流式传输 | 视频、音频和直播      |

例如：

**The interview was broadcast on television.**  
这场采访在电视上播出了。

**The article was published online.**  
这篇文章在网上发表了。

**The concert was streamed live.**  
这场音乐会通过网络进行了直播。

# A–A–A 型动词的语法判断

## 如何判断原形、过去式和过去分词？

由于三种形式相同，单独看到一个动词时，通常无法仅凭拼写判断它属于哪一种语法形式。

例如：

| 句子                                    | 动词形式  | 判断依据             |
| ------------------------------------- | ----- | ---------------- |
| **They usually set the date in advance.** | 一般现在时 | usually 表示习惯性行为 |
| **They set the date yesterday.** | 过去式 | yesterday 表示过去时间 |
| **They have set the date.** | 过去分词 | have + 过去分词 |
| **The date was set yesterday.** | 过去分词 | be + 过去分词 |

判断时主要关注：

- 助动词
- 时间表达
- 主谓关系
- 整个句子的语法结构

## 形式不变，时态仍然可以变化

比较：

| 句子                             | 时态    |
| ------------------------------ | ----- |
| **I put the book here every day.** | 一般现在时 |
| **I put the book here yesterday.** | 一般过去时 |
| **I've put the book here before.** | 现在完成式 |

虽然 put 的拼写没有变化，但三个句子的语法结构不同。

尤其需要注意完成式：

have / has + 过去分词

例如：

- I've already put everything away.
- She has cut the paper.
- They have set the date.

## 与规则动词的比较

规则动词和 A–A–A 型动词遵循相同的基本语法系统。

| 语法形式 | 规则动词 open | 不规则动词 shut |
| ---- | --------- | ---------- |
| 原形   | open      | shut       |
| 过去式  | opened    | shut       |
| 过去分词 | opened    | shut       |

比较：

| 规则动词                       | A–A–A 型动词                      |
| -------------------------- | ------------------------------ |
| **I open the shop every day.** | **I shut the shop every evening.** |
| **I opened it yesterday.** | **I shut it early yesterday.** |
| **I've opened it already.** | **I've shut it already.** |

规则动词通过词尾变化表现过去式和过去分词。

A–A–A 型动词虽然没有明显的词形变化，但仍然遵循相同的时态、完成式和被动语态规则。
