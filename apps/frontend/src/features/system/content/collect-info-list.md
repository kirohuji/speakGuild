# 漫语町个人信息收集清单

| 场景/业务功能 | 个人信息种类 | 目的 |
|--------------|-------------|------|
| 注册登录 | 手机号、短信验证码 | 用于注册创建账号和登录 |
| 注册登录 | 头像、昵称 | 用于完善网络身份标识 |
| 第三方登录 | 微信账号信息、Apple ID 信息 | 用于第三方账号授权登录 |
| 学习功能 | 练习记录、学习库| 用于完成核心备考学习功能 |
| 口语练习 | 语音录音、录音文本 | 用于 AI 发音评分和口语反馈（录音分析后即删除） |
| AI 评分 | 提交的题目内容、录音文本 | 发送至 DeepSeek API 进行评分分析 |
| 支付 | 支付时间、支付金额、支付渠道等支付信息（含 Apple 内购） | 用于完成在线支付功能，包括 App Store 内购（iOS）、支付宝、微信支付 |
| 客服与售后 | 用户与客服的联系记录、账号信息、身份核验信息、订单信息等 | 用于客服与售后服务及争议处理 |
| 附加功能 | 相册、麦克风、通知、语音识别 | 相册：读取和保存图片、文件。麦克风：口语录音。语音识别：口语练习时将语音转换为文字。通知：学习提醒。上述附加功能仅在特定场景下用户使用相关功能时才会申请询问，用户拒绝不影响用户使用基本功能 |
| 使用过程中 | 设备信息、日志信息、网络信息、IP地址 | 用于安全保障和网络状态监控 |
| 系统功能 | 网络状态、存储空间、安装包信息 | 网络状态：监控网络变化。存储空间：保存应用数据、缓存、日志。安装包信息：用于应用更新 |
| 后台功能 | 本地学习提醒、音频播放 | 支持应用在后台运行时的学习提醒、音频播放等功能 |
