## 1. 范围与约束

复用题库现有字段，不新增数据库列或规则引擎。一次正常云端判题只调用一次模型。公共规则、题型规则、方向规则组合成 prompt（`prompts/warmup-judge.prompt.ts` → `buildWarmupJudgeSystem`）。返回现有 `passed、score、feedback、correction`。

题干决定意思，显式目标决定练什么，参考答案提供一种正确实现——不是唯一答案。

入口：`EnglishPracticeAiService.judgeWarmupTurn`（云端）；前端 `practiceAiApi.judgeWarmupTurn` 在离线／本地优先时走 MiniLM。

## 2. 按题型处理

| 题型 | 复用数据 | 中译英要点 | 英译中要点 |
|------|----------|------------|------------|
| 单词替换 | `chunk`、`kind=word` | 核验指定词语境义与词形 | 理解目标词意思，不要求英文 |
| 词块替换 | `chunk`、`chunkMeaning` | 核验搭配与论元；允许合理屈折 | 理解词块语境义 |
| 词汇练习 | `targetWords`、`promptZh` | 核验明确目标词 | 理解整句与目标词 |
| 一词多句 | `vocabWord`、当前 pattern | 核心词与当前搭配都要满足 | 理解该搭配中的词义 |
| 句型操练 | `pattern`、`patternMeaning` | 核验结构与槽位，不能绕开 | 理解结构关系 |
| 长句拆解 | `levels`、录音转写 | 当前主要是录音完成流程；AI 判题待转写接入 | — |
| 对话 | 意图／必要信息 | 列表入口未完全接入 | 不套翻译规则 |

翻译方向要规范化：英译中可能是 `en + answer` 或旧格式 `answer=英文、zh=中文`。

### 句型格式要点

- 方括号是带类型的槽位；斜杠可能是槽位内选择或模板分支。
- 允许省略句、合理时态变化；语言规则优先于模板字面（如 `take her home` 不加 `to`）。
- 词块写成完整句时允许嵌入。

## 3. 判题与反馈

模型检查：主要意思是否一致、训练目标是否正确使用。目标外小错宽容；目标内关键结构错误不放行。

| score | passed | 标准 |
|-------|--------|------|
| strong | true | 意思一致、目标满足、表达自然 |
| ok | true | 意思与目标满足，重点外轻微问题 |
| weak | false | 部分正确，或目标遗漏／用错 |
| miss | false | 核心意思错误、答非所问、语言错或空答 |

通过时 `correction` 为 null。技术故障不记成答题对错。前端保留 weak 与具体反馈。

## 4. 云端调用

优先 `LlmChatClient.completeJson`；DeepSeek／百炼走 `json_object` + 应用层校验，显式 `thinking: disabled`。供应商只支持 JSON 模式时不强行发不支持的 `json_schema`。正常题目约 600 tokens。

目标缺失或使用错误必须 weak/miss，绝不能 ok。

## 5. 离线 MiniLM 判题

沿用现有 MiniLM 与模型下载机制，默认 Q8。

| 模块 | 职责 |
|------|------|
| `warmup-answer-rules.ts` | 目标词形、槽位与词块匹配；否定、数量／时长、时间、情态、角色颠倒 |
| `warmup-local-judge.ts` | MiniLM 相似度 + 规则；目标不满足不能因相似度高而通过 |
| `practiceAiApi.judgeWarmupTurn` | 断网或本地优先 → 本地评分；联网且本地优先关 → 云端；网络类错误可回退本地 |

本地规则是有限语言检查，无按题目 ID 白名单。缺少模型／损坏文件是技术错误，不伪造成绩。长句拆解录音转写未在此轮完成。
