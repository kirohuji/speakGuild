# 同步与学习包更新

## 公共内容

普通个人同步不再调用全库 `/sync/content/manifest`，也不直接安装学习包。
统一复用 `learning.store.checkPackUpdates()` → `/learning/packs/check` →
`availablePackUpdates` → 既有下载队列。检查只针对已安装包；没有包时不请求。

自动检查共享进行中的请求，同一账号、同一组包版本成功检查后缓存 30 分钟。
手动检查绕过时间间隔；安装包集合变化后可以立即重新检查。
账号切换会失效进行中的检查结果；检查期间安装或卸载的包也会重新核对。

内容编辑后，生成并发布新版本才向客户端提供更新。
已有 ZIP 的版本不能覆盖生成或上传；上传 ZIP 的版本必须与发布版本一致。
新动态生成包标记 source=dynamic，避免将内容统计版本误当作发布版本。
尚无发布版本的包保持可用，不触发下载。
更新优先使用可用的直接 delta；delta 失败时由原有安装回滚机制恢复，随后尝试全量包。
取消操作不触发全量回退。

## 个人同步

每种类型每页最多 100 条。所有已启用的分页类型使用时间戳与 ID 的复合游标，
继续接受旧时间戳游标与 null。旧时间戳边界的记录会安全重放。
每页应用成功后保存游标，后续页仅查询仍有数据的类型。
30 秒批次预算耗尽后保留进度并安排下一批；离线或切换账号后停止。
自动触发共享覆盖相同范围的同步，完成后短时间内不重复拉取。
手动同步与退出登录保留等待后重新上传的保障。

新客户端使用 compact=true；未指定时保持旧响应结构，便于前后端分别部署。
compact 响应中的 expressions 是当前页按远程 ID 去重的表达集合，包含笔记关联依赖。
expressionItems 保留实际变更的 ID，笔记关联不再内嵌重复表达。
内容快照合并为一份传输，保留未安装包、自定义内容和卸载后的离线收藏能力。
局部笔记同步无需依赖之前的表达分页。

## 历史详情

compact 练习历史只恢复列表摘要，不再逐条调用练习详情接口。
保留本机已有完整复盘与待上传记录。完整复盘继续通过现有
getPracticeSessionForReview 在线获取、缓存并在断网时回退。
因此新设备首次同步后可离线查看历史列表；尚未缓存的完整复盘需要首次联网打开。

主题练习的分析结果和提交记录、今日任务 run、热身作答仍完整恢复，
因为当前离线展示和任务重建依赖这些数据；仅省略未使用的 analysisRaw。
不新增个人数据 ZIP、第二套下载队列或第二套详情缓存。

## 验证

按要求仅执行前端 typecheck 与后端 tsc --noEmit --incremental false。
未运行 build、浏览器或运行时测试，实际流量与耗时仍需部署后观察。
