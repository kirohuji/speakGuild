# 今日任务（今日复习 + 今日练习）需求与数据流设计

> 本文档是「今日任务」功能的需求设计基线（取代旧版修复清单）。
> 核心决策：**今日复习与今日练习同属「今日任务」，共用一套数据流与统计口径**，收敛进统一 store（`today-practice.store`），并与系统设置（每日打卡目标 / 跨学习包复习 / 话题内随机出题）联动。
> 涉及文件：
> - `apps/frontend/src/stores/today-practice.store.ts`（**新增**：统一数据流 store）
> - `apps/frontend/src/features/learning/pages/today-task-page.tsx`（今日任务页：复习 + 练习两模式）
> - `apps/frontend/src/stores/daily-practice.store.ts`（plan / loadToday / completeStep / submitToday）
> - `apps/frontend/src/stores/warmup-session.store.ts`（records / stepStates 逐题作答）
> - `apps/frontend/src/stores/preferences.store.ts`（系统设置）
> - `apps/frontend/src/lib/offline/daily-practice.repository.ts`（计划构建 / SM-2 / 同步）
> - `apps/frontend/src/features/practice/components/*-drill-card.tsx`（练习卡片）
> - `apps/frontend/src/features/learning/components/today-records-drawer.tsx`（今日练习记录抽屉）

## 1. 范围与目标

### 1.1 功能范围
「今日任务」= 移动端每日学习核心入口，包含**两种模式**（同一页面、同一套数据流）：

| 模式 | 内容 | 步骤来源 |
|---|---|---|
| 今日复习（review） | 逾期/到期的已学内容 | 复习清单（`reviewBacklog`：逾期优先 → 到期） |
| 今日练习（practice） | 当前学习包的新内容 | 新学池（`practicePool`：仅从未练过，同话题同阶段） |

两模式**密切相关**：共用计划构建、进度统计、作答记录、错题重练、提交、打卡。切换模式只更换 `steps` 来源，轮次/进度/提交机制完全一致（mode 无关）。

### 1.2 设计目标
1. **单一数据流**：轮次状态机、队列、进度、导航统一由 `today-practice.store` 管理，取代页面散落的多个 `useState`/`useReducer`/派生 `useMemo`。
2. **进度口径统一**：完成/待练/未练、组内三色、话题累计进度、顶部进度条全部同源派生。
3. **与系统设置联动**：计划构建与出题顺序受设置驱动，设置变更自动重建计划。
4. **边界完备**：重练中断、错题池、防重复提交、离线恢复、队列收缩等边界有明确规则（见 §9）。

## 2. 决策基线（需求对齐）

| # | 决策 | 说明 |
|---|---|---|
| D1 | **「我不会」= 回答错误** | 与答错等价：进错题池、不自动跳下一题；错题重练轮内必须答对才算通过 |
| D2 | **话题进度 = 累计已练** | `已练 X/Y`（`bestScoreRank >= 2` 的题数 / 话题总题数），口径对齐学习计划页 |
| D3 | **「重新练习」= 重做本组；「练习错题」= 只练错题** | 全完成后：「重新练习」重做本次练习全部题目；「练习错题」只收集弱/错/我不会 |
| D4 | **组内进度三色** | 完成(绿)=通过；待练(红)=已练未通过（弱/错/我不会）；未练(灰)=未作答 |
| D5 | **「练习错题」独立按钮** | 与「继续练习」flex 并排：都有时各半、只有一个时占满 |
| D6 | **错题不消耗新题池** | 只有「通过」才写 SM-2 进度；答错/我不会不减少新题池、不被持久化为完成 |
| D7 | **继续练习队列排除错题** | 「继续练习」= 未练 + 做对（不含错题）；错题只在「练习错题」练 |
| D8 | **重练中退出 = 取消重练** | 关闭抽屉即取消重练轮、回到主轮，错题池保留，「练习错题 N」按钮恢复 |
| D9 | **历史 failed 不恢复显示** | 历史错题不恢复「已加入本轮错题」展示（本轮错题池只由本轮记录派生） |
| D10 | **记录抽屉样式统一** | 今日练习记录 drawer 无 border、无阴影、记录行无卡片背景 |
| D11 | **「我不会」禁用状态持久化** | skipped 写入 stepStates，重挂载恢复输入框禁用；重练轮开始/卡片重试时清除 |

## 3. 系统设置联动（今日任务的输入）

| 设置项 | 默认 | 对今日任务的影响 |
|---|---|---|
| **每日打卡目标** `dailyGoal`（10 / 20 / 30 题） | 20 | 决定今日计划题数：`scheduled = 池.slice(0, dailyGoal)`；「今日练习」入口显示 `min(dailyGoal, 新题池) / 新题池` |
| **跨学习包复习** `dailyPracticeMixedPacks` | false | review 模式下 `scope='mixed'`，复习候选扩大到多个学习包；false 时仅当前包 |
| **话题内随机出题** `dailyPracticeRandomOrder` | true | practice 模式下同话题同训练阶段随机排序；false 时按教学顺序 |
| **上次使用模式** `dailyPracticeLastMode` | 'practice' | 进入今日任务时的默认模式 |

规则：
- **设置变更 → 计划重建**：`dailyGoal`/模式/包/日期任一变化 → `currentPlanReusable=false` → 重新 `loadToday`。
- **模式切换**：复习 ↔ 练习随时可切（`switchPlanMode`）；切换即重置当前轮次（`roundNonce+1`）、清会话、重载对应模式计划。
- **「下一组 / 重新练习」**：`resetRound(roundNonce+1)`，不 reload，保持当前 `steps`。

## 4. 今日任务 Store 设计

### 4.1 定位与职责
`today-practice.store`（zustand）负责**两种模式共用的数据流**：

- 轮次状态机（主轮 + 错题重练轮）
- 练习进度（已练 / 错题池 / 队列）
- 导航位置、会话与提交标记
- 全部派生统计（统一口径）

**持久层保持不动**：
- `daily-practice.store`：`plan` / `loadToday` / `completeStep`（SM-2）/ `submitToday`
- `warmup-session.store`：`records`（错题池/完成派生）/ `stepStates`（卡片状态）
- `preferences.store`：设置输入

### 4.2 状态模型（round 状态机）
```ts
type RoundKind = 'main' | 'review'

today-practice.store 状态：
  kind: RoundKind
  attemptedIds: Set<string>       // 主轮已练（含错题；答对/答错/我不会都算已练，保证轮次可完成）
  reviewPendingIds: Set<string>   // 重练轮待练 id 快照（kind=review 时有效）
  reviewDoneIds: Set<string>      // 重练轮已通过 id
  roundNonce: number              // 轮次序号：决定 warmupRecordId；「下一组/重新练习/模式切换」+1；「练习错题」不变
  reviewDismissed: boolean        // 错题弹窗「稍后再练」标记
  currentIdx: number              // 当前题索引（基于 activeSteps）
  sessionHydrated: boolean        // 会话是否已从本地恢复
  hasSubmittedToday: boolean      // 当前轮是否已提交
```

### 4.3 派生统计（`deriveTodayPractice(steps, records)`）
输入：store 状态 + 页面构建的 `steps` + warmup 记录。输出（全部同源，一次计算）：

| 类别 | 派生值 | 口径 |
|---|---|---|
| 展示 | `passedStepIds` | `records.passed`（通过 → 完成/绿） |
| 展示 | `weakStepIds` | `records.score ∈ {weak, miss}`（错题池/待练/红） |
| 队列 | `reviewSteps` | `kind=review` 时 = `steps ∩ reviewPendingIds` |
| 队列 | `mainQueue` | 主轮 = `steps` **排除 `weakStepIds`**（继续练习队列，D7） |
| 队列 | `activeSteps` | `review ? reviewSteps : mainQueue` |
| 定位 | `activeDoneIds` | `review ? reviewDoneIds : passedStepIds` |
| 定位 | `resumeDoneIds` | `review ? reviewDoneIds : attemptedIds`（续练定位，主轮含错题→下一个未练开始） |
| 进度 | `attemptedCount` / `hasPracticeSteps` / `allDone` | `allDone = attemptedCount ≥ steps.length` |
| 进度 | `activeDoneCount` / `activeTotal` / `reviewAllDone` | 队列维度完成统计 |
| 计数 | `passedCount` / `weakCount` / `unattemptedCount` | 完成 / 待练 / 未练 |
| 判定 | `needsReviewRound` | `allDone && 有错题 && !review && !reviewDismissed` |

### 4.4 Actions（状态转换）
| Action | 行为 |
|---|---|
| `initMain(attemptedIds)` | 计划加载后一次性初始化主轮已练（来自 `plan.completedItemIds`） |
| `completeStep(stepId, passed)` | 主轮：加入 `attemptedIds`；重练轮：仅 `passed` 加入 `reviewDoneIds` |
| `startReview(weakIds)` | 进入重练轮（快照弱题，清空 `reviewDoneIds`） |
| `finishReview()` | 重练完成/取消 → 回主轮、清空重练集合、标记 `reviewDismissed=true` |
| `dismissReview()` | 仅标记「稍后再练」（不进入重练） |
| `resetRound(roundNonce)` | 新轮：重置全部轮次字段 + `currentIdx=0` |
| `setCurrentIdx(idx \| updater)` | 支持函数式更新（导航） |
| `setSessionHydrated(v)` / `setHasSubmittedToday(v)` | 会话与提交标记 |

## 5. 数据流全链路

### 5.1 计划构建
```
设置(preferences) + 当前包 + 日期
  → buildTodayPlan(date, mode)
     review：复习清单（逾期优先 → 到期；dailyPracticeMixedPacks 时跨包候选）
     practice：新学池（仅从未练过；同话题同阶段；dailyPracticeRandomOrder 时随机）
  → 写入 daily-practice.store.plan
  → 页面构建 steps（含 render 闭包）→ initMain(plan.completedItemIds)
```

### 5.2 会话恢复（hydrate）
- 页面构建 `steps` 后，按 `warmupRecordId` 读取本地记录：
  - 恢复 `records`（`hydrateSession`）与 `stepStates`（`hydrateHistoricalStepStates`）
  - **历史 failed 不恢复 failed 显示**（D9）：`hydrateHistoricalStepStates` 只恢复 `passed` 记录
  - 本地记录 `syncStatus === 'synced'` → `setHasSubmittedToday(true)`（重访不重复提交）
- `warmupRecordId = today-warmup:{date}:{mode}:{scope}:{roundNonce}:{itemIds}`

### 5.3 练习与作答
- 卡片 `onComplete(stepId, passed, score)` 统一走 `markDone`：
  - **passed**（strong/ok/weak）→ `completeStep`（写 SM-2）+ store `completeStep`
  - **!passed**（答错/我不会）→ 只写记录（进错题池）+ store `completeStep`（主轮算已练）——**不写 SM-2、不消耗新题池**（D6）
- 「我不会」：卡片 `skipped` 写入 `stepStates`（D11），重挂载恢复输入框禁用
- 重练轮：`disableSkip`（无「我不会」按钮）、答错不推进、答对才 `done`

### 5.4 轮次完成与提交
```
主轮完成（attempted 全覆盖）
 ├─ 无错题 → 自动提交 → 完成态
 └─ 有错题 → 弹窗「练习错题 N / 稍后再练」
      ├─ 练习错题 → 重练轮全部答对 → 提交（同一 warmupRecordId，聚合两轮记录）
      └─ 稍后再练 → 保持完成态，顶部「练习错题 N」随时再进
```
- **提交守卫**：`!hasSubmittedToday && !submitting && sessionHydrated && 当前轮完成`；**成功后才**置标记，失败可重试（outbox 兜底）。
- **防重复**：重访已提交计划（synced）不再提交、不重复建 `practiceWarmupRecord`、打卡不翻倍。
- **打卡**：`completeRun`/`syncAdHocRun` 内 `markTodayActivity(完成题数或1)`，每轮一次。

## 6. 进度统计口径（统一）

| 状态 | 颜色 | 口径 |
|---|---|---|
| 完成 | 绿 | `records.passed`（通过） |
| 待练 | 红 | 已练但未通过（`weak`/`miss`，含「我不会」） |
| 未练 | 灰 | 未作答 |

- **组内序号 chip 三色**、**顶部进度条三色**（完成绿/错红/未练灰）、**图例**全部同源（§4.3）。
- **话题累计进度** `已练 X/Y` = `bestScoreRank >= 2`（累计口径，对齐学习计划页），`topicWarmupProgress` clamp ≤ 100。
- 顶部 Badge：`activeDoneCount / activeTotal`（当前队列维度）。
- 「今日练习」入口：`{随机/顺序} min(dailyGoal, 新题池) / 新题池`。


## 7. 主操作按钮与状态（practice 模式）

| 状态 | 按钮布局 |
|---|---|
| 无练习内容 | 禁用「暂无练习」占满 |
| 未完成 + 无错题 | 「继续练习」占满 |
| 未完成 + 有错题 | 「继续练习」｜「练习错题 (N)」flex 各半 |
| 全部完成 + 有错题 | 「练习错题 (N)」占满 |
| 全部完成 + 无错题 | 「重新练习」（绿）占满 + 次要「下一组」 |
| 重练进行中 | 「继续练习」占满 |

样式：**无 border、无阴影、淡色块**；「继续练习」= primary，「练习错题」= 红（对应进度条 weak 红段），「重新练习」= 绿。「练习错题 (N)」的 `N = weakStepIds.size`。

按钮点击行为：
- 「继续练习」→ 从当前队列第一个未练开始（主轮 = `mainQueue`；重练中 = `reviewSteps`）
- 「练习错题 (N)」→ 进入错题重练轮
- 「重新练习」→ 重做本组全部（`roundNonce+1`，不 reload）
- 「下一组」→ 新的一组（`roundNonce+1`）

## 8. 错题重练轮

| 阶段 | 规则 |
|---|---|
| 进入 | `startReview(当前 weakStepIds)` + `resetStepStates(weak)`（清卡片状态、保留错题池）+ 打开抽屉 + `currentIdx=0` |
| 进行中 | `activeSteps` = 错题快照；`disableSkip`（无「我不会」）；答错不推进、可重试；答对才 `done` |
| 完成 | 全部答对 → `finishReview` → 自动提交（聚合两轮记录）→ 回主轮完成态 |
| 退出（关抽屉） | 取消重练回主轮（`finishReview`），错题池保留，「练习错题 N」按钮恢复（D8） |
| 稍后再练 | `dismissReview`（不进入重练；`needsReviewRound` 受 `reviewDismissed` 抑制） |

## 9. 边界情况清单

1. **重练中直接退出** → 取消回主轮（D8），错题按钮保留；「继续练习」回到主轮剩余未练（不会只显示重练题）。
2. **错题不消耗新题池**（D6）→ 只有 `passed` 才写 SM-2；「我不会/答错」不减少 `practicePoolCount`、不被持久化为完成；刷新后仍按未练重新出现。
3. **继续练习队列排除错题**（D7）→ 打开只显示未练 + 做对（总数 = 全部 − 错题数）；错题只在「练习错题」。
4. **历史 failed 不恢复「已加入本轮错题」**（D9）→ `hydrateHistoricalStepStates` 只恢复 `passed` 记录。
5. **播放列表与队列一致** → 主轮 playlist 基于 `mainQueue`；组卡片保留三色展示，但点开映射到当前队列（按 id 映射，避免索引错位）。
6. **队列收缩索引越界** → `currentIdx` 修正到 `activeSteps` 末尾（题被标记错题移出队列时）。
7. **重访已完成计划** → 不重复提交、不重复建记录、打卡不翻倍（`synced` 标记 → `hasSubmittedToday`）。
8. **提交失败** → 不置完成标记，可重试（`completeRun` outbox 兜底）。
9. **「我不会」输入框禁用持久化**（D11）→ `skipped` 写入 `stepStates`，重挂载恢复；重练轮开始 / 卡片重试时清除。
10. **话题累计进度** clamp ≤ 100，`已练 X/Y` 不会 X > Y。
11. **新轮重置** → 「下一组 / 重新练习 / 模式切换」`resetRound`（roundNonce+1）+ 清会话 + `clearSession`。
12. **复习模式** → 错题 / 重练 / 提交 / 进度规则与练习一致（mode 无关），仅 `steps` 来源不同。
13. **计划重建** → 设置（dailyGoal / 跨包 / 随机）/ 包 / 日期 / 模式变化 → 重新 `loadToday` 并 `initMain`。

## 10. 与其它模块的关系

| 模块 | 关系 |
|---|---|
| 学习计划页 | 包级进度 `已练 X/Y` 来自 `daily_practice_items`（`mergeLocalPracticeProgress`），不经过本 store；今日任务只消费、不修改 |
| 引导式 warmup | 独立提交路径（`syncAdHocRun`）；共用卡片 `disableSkip` 默认 false，不受影响 |
| 今日记录抽屉 | 本地 + 远端合并去重展示；样式统一（D10） |
| 打卡 | `completeRun` / `syncAdHocRun` 内 `markTodayActivity`，每轮一次，重访不重复 |
| 启动预载 / 学习包切换 | `startup-warmup-provider`、`learning.store` 仅调用 `loadToday` / `reset`，不涉及本 store |

## 11. 实施顺序

1. **today-practice.store**（状态机 + 派生）——核心，先落地
2. **页面接入 store**（替换散落 useState / useReducer / 派生 useMemo）
3. **队列 / 错题 / 按钮 / 重练规则落地**（D3-D8）
4. **防重复提交 + syncStatus**（涉及后端数据，尽早）
5. **样式（按钮 / 抽屉）+ 话题进度**（D4 / D10 / D2）

## 12. 验收要点

- [ ] **统一 store**：今日复习与今日练习共用 `today-practice.store`；轮次/队列/进度/导航全部从 store 读取，页面无散落重复的轮次状态。
- [ ] **设置联动**：`dailyGoal`（10/20/30）改变今日计划题数；`跨学习包复习` 改变 review 候选范围；`话题内随机出题` 切换顺序/随机；设置变更自动重建计划。
- [ ] **队列分离（D7）**：10 题中第 1 题「我不会」→「继续练习」只显示 9 题且不含该错题；错题只在「练习错题 (N)`。
- [ ] **错题不消耗池子（D6）**：「我不会/答错」不减少新题池、不被持久化为完成；刷新后仍按未练出现，可再次遇到。
- [ ] **重练退出（D8）**：进入错题重练后直接关抽屉 → 回到主轮，「练习错题 N」按钮恢复，「继续练习」从主轮剩余未练开始（不会只显示重练题）。
