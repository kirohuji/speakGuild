## 命名约定

- **LearningPack／学习包**：内容 zip（场景、剧本、媒体）。
- **MobileBundle／OTA**：App 前端热更新包。
- **OfflineModel**：端侧 Whisper／MiniLM 权重。

三者不要混称「安装包」而不加限定。
