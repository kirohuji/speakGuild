# 离线同步与账号

> **核对日期**：2026-11-18  
> **范围**：学习本本地数据与同步、个人数据 pull/push、账号缓存归属与首页特殊广播。  
> **相关**：学习包安装与更新见 [离线学习与沉浸式播放器手册](./离线学习与沉浸式播放器手册.md)；统计与签到见 [离线学习统计与签到](./离线学习统计与签到.md)。

## 1. 公共内容 vs 个人同步

普通个人同步**不再**调用全库 `/sync/content/manifest`，也不在 sync 流程里直接安装学习包。

- 公共内容更新：`learning.store.checkPackUpdates()` → `/learning/packs/check` → `availablePackUpdates` → 既有下载队列。
- 只检查**已安装**包；没有已装包时不请求。
- 自动检查：同账号、同组包版本成功后缓存约 30 分钟；手动检查绕过间隔。
- 安装包集合变化后可立即再检查；账号切换会使进行中检查失效。
- 内容编辑后需生成并发布新版本；优先 delta，失败回滚后再试全量。

个人数据仍走 outbox + `/sync/push` / `/sync/pull`（见手册 §11 与下文学习本）。

## 2. 学习本的本地数据与同步

学习库列表、内容详情、选择学习本弹窗均从 SQLite 读取，不直接调用学习本列表接口。header 同步按钮执行学习本范围的统一同步。页面搜索、筛选、分页不触发网络请求。

发音 / 例句音频身份与学习库 hydrate、包 deferred 索引的约定见 [手册 §2.0](./离线学习与沉浸式播放器手册.md#20-可离线音频身份统一约定)。

### 本地一致性

- `notebookItemsSql` 是统计和详情分页共用的数据集：按学习本和内容去重，优先保留待同步版本，排除删除标记、已删除学习本及缺失内容的关联，再筛选学习状态。
- 本地变更和不可变的 outbox 操作在同一 SQLite 事务中提交。写入失败整体回滚。事务后发布 `learning-library-changed`。
- 本地学习本及关联 ID 保持稳定，`remoteId` 记录服务端身份，避免同步中路由和待同步引用失效。
- 移出最后一个学习本不会自动归入未分类。删除学习本不会删除其他本共享的内容。
- 本地新建的未分类学习本在服务端与该用户已有的系统本合并，通过 `remoteId` 对应，避免重复创建。
- 登录用户首次读取本地列表时，如果缺少未分类学习本，则在本地事务中补齐并登记待同步操作；空本同样显示，并发读取不会重复创建。
- 拉取服务端系统本时优先匹配本地尚未绑定的未分类本，保留稳定的本地 ID 和待同步状态。

### 同步协议

- `notebook` / `notebook_item` 使用 snapshot 操作，独立的 `clientMutationId` 和 predecessor 表达操作顺序。
- 服务端在同一事务中保存操作结果和 `notebook_sync_receipt`；响应丢失后的重试直接返回原结果。
- 服务端版本和更新时间用于冲突检测。冲突保留在待同步队列及错误详情，不覆盖本地数据。暂不自动选胜。
- 拉取不覆盖有实际待同步操作的本地学习本和关联。
- 学习本、关联、表达式及其删除流使用时间加 ID 的分页游标；每页数据与游标原子提交。
- 升级到本协议后，统一同步会重置一次相关旧游标，重新核对远端数据，保留本地待同步操作。
- 已删除学习本下尚未上传的关联操作由服务端确认为被删除操作取代，不永久阻塞队列。
- 操作包含所属账号；拉取结果也包含账号，防止切号写错空间。
- 离线不请求同步接口、不生成失败弹窗；本地操作仍正常保存。离线退出登录被阻止。

### 部署

先应用 `20261114000100_notebook_sync_receipts` 迁移，再发布支持本协议的后端和前端。旧 API 保留供已有调用方使用。

## 3. 个人同步分页与 compact

每种类型每页最多 100 条。已启用的分页类型使用时间戳与 ID 的复合游标，继续接受旧时间戳游标与 null。

- 每页应用成功后保存游标；30 秒批次预算耗尽后保留进度并安排下一批。
- 新客户端使用 `compact=true`；未指定时保持旧响应结构，便于前后端分别部署。
- compact 中 `expressions` 是当前页按远程 ID 去重的表达集合；`expressionItems` 保留实际变更的 ID。
- 内容快照合并为一份传输，保留未安装包、自定义内容和卸载后的离线收藏能力。
- compact 练习历史只恢复列表摘要；完整复盘仍通过既有 `getPracticeSessionForReview` 在线获取并缓存。

不新增个人数据 ZIP、第二套下载队列或第二套详情缓存。

## 4. 旧缓存归属确认与首页特殊广播

### 单用户缓存架构

继续使用一套活动 SQLite 数据空间，切换用户时清理用户数据，保留学习包、词典和模型等公共资源。SQLite `kv` 标记 `offline-account:owner` 优先于 localStorage 归属标记。

进入业务页面及启动同步前先确认缓存归属。冷启动网络会话检查超时可回退缓存会话，但仍必须完成本地归属检查。

### 旧版兼容

| 情况 | 处理 |
|------|------|
| 已有归属且属当前账号 | 继续使用 |
| 无归属且无用户数据 | 初始化为空的当前账号空间 |
| 无归属但有旧数据 | 用缓存会话、`ownerId`、`user_profile` 证据认领；矛盾则不认领 |
| 仍无法确认 | 先备份隔离，再初始化当前账号；首次隔离完成提示用户 |

隔离备份：`kv` 的 `offline-account-archive:{archiveId}`（`sqlite-rows-v1`）；原生录音目录移到 `Directory.Data/offline-account-archives/{archiveId}/user-recordings`。备份不参与同步；当前无自动恢复。

### 清理中断

清理前落盘 `offline-account:transition`，成功后提交新归属并移除过渡标记。失败则保留旧归属、暂停同步，重启或重新登录会重试。

### 首页特殊广播

`GET /notifications/special`：按可见性取最新一条，再判断是否已读；已读返回空列表，不回退历史未读。只影响首页自动弹出候选，不改通知列表与未读统计。

## 5. 验证要点

- 学习本：本地新建/加入/移出、跨本共享、回执去重、冲突保留、分页。
- 账号：同账号迁移、证据冲突、录音隔离、清理失败阻断、初始化完成前不公开业务会话。
- 个人同步：compact 响应形状、游标推进、未装包收藏能力。
