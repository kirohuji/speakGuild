# Q8 判题规则改进与离线接入

沿用现有 MiniLM 模型和模型下载/缓存机制，默认版本仍为 Q8，没有新增模型、数据库字段或更改模型发布状态。

## 正式代码

- `warmup-answer-rules.ts`：目标词形、槽位与词块匹配；检查明确的否定、数量/时长、时间先后、情态差异和明显的双方角色颠倒。斜杠在槽位内与模板分支中分别处理；支持词块嵌入、插入频率副词和常见时长句型的疑问形式。
- `warmup-local-judge.ts`：相似度仍由实际 MiniLM 向量计算。目标不满足或关键意思冲突不能因相似度高而通过；取消直接取中文题干与英文回答相似度作为通过依据。相似度与词汇重合度辅助判断剩余内容，英译中与中译英分别设定门槛。
- `practiceAiApi.judgeWarmupTurn`：断网时调用当前已下载的本地模型并给出明确评分，不请求云端；联网且本地优先开启时也使用该评分，只有模型调用失败才允许联网回退。联网且本地优先关闭时继续默认云端判题；若 WebView 仍显示在线但请求出现断网/网络/超时错误，使用本地模型恢复，授权或业务错误不触发该回退。缺少模型/损坏文件仍是技术错误，不伪造成绩。
- 一词多句的核心词与当前搭配一起核验，今日练习入口也传入两项要求。
- `sentenceBuildingPrompts`：兼容已存在的题组级 answer 错放。只有恰好一个小题缺答案时才使用该现有字段，保留原始数据，不修改数据库。知识点练习和今日计划候选生成共用该读取逻辑。

本地规则是有限的语言检查，没有按题目 ID 或整句答案建立放行白名单。方向副词目的地、动名词/过去分词槽位等是通用结构检查，不把某一题直接判对。规则无法代替完整语法理解，不承诺所有自由回答都能正确识别。

## 验证结果

使用此前真实浏览器推理得到的 Q8 向量，直接运行正式评分函数；新增 35 个不同措辞/内容的样例也在独立浏览器通过同一 Q8 WASM 实际推理。额外计算了错放参考答案的真实向量，未让 MiniLM 凭中文题干猜英文译文。

| 样例集 | 改进前 | 改进后 |
| --- | ---: | ---: |
| 学习包 151 个去重样例 | 131/151 | 151/151 |
| 其中 44 个非参考原句 | 24/44 | 44/44 |
| 新增 35 个样例 | 未作为旧规则评测集 | 35/35 |

学习包原有的 9 个错误放行、11 个错误拒绝在本轮均消除；其中一题的改善来自正确读取已有上层参考答案，不能计为模型自行补全答案的能力。恢复该参考答案前，原型为 150/151。

新增样例包含博物馆到达、手机修理、早起、时长单位换算、能力与义务、人物关系、中文反问式疑问、词与子串区别、被动改写等。新增集发现的疑问式否定与晚饭前后处理问题也参与了开发修订，因此这是开发回归结果，不是独立盲测准确率。

99 个自动测试通过，覆盖规则、32 个真实 Q8 向量回归、参考答案恢复、离线路由、今日练习候选与相关知识点入口。向量回归存于测试目录 fixtures，注明来源模型、提交版本和舍入精度，CI 不需要下载模型或联网。

[186 条逐项结果](evaluations/minilm-q8-improved-results.csv)保留输入、目标、预期、实际评分、旧评分、答案恢复标记及反馈。前次三档模型对比和失败记录仍保留于 `minilm-offline-evaluation.md`，不覆盖历史结果。

## 边界

本次以 Q8 为主要验证对象，未把 Q8 的结果冒充 FP16/FP32 改进后的新实测。两档继续兼容相同评分代码。

这是桌面浏览器 WASM 模型推理、真实向量评分与路由自动测试，不是手机真机端到端验证。真机内存、连续答题和原生资源加载仍需实测。长句拆解 UI 的录音转写没有在本轮新增；文本判题不等于发音评测。

对于真正缺少参考答案、没有可明确恢复的数据，不凭跨语言相似度猜测为答对。离线需先下载模型和学习包；有效题目有明确评分，技术或题目数据缺失应修复资源后再试。

最终正式评分代码再次通过全部 186 条真实向量回归，前端类型检查与差异格式检查通过。代码已接入工作区，未部署或发布手机更新。
