# 中英互译写作包设计与实现

## 目标

在现有“写作包”中新增 **中英互译** 题型。题型支持：

- 中文译英文与英文译中文；
- 单句练习与篇章练习；
- 篇章按句（或段）保留原文，并在对应译文位置展示可填写的下划线；
- 与阅读本一致的上下分层沉浸式界面：上层阅读原文，下层完成翻译；
- AI 提示、草稿保存、提交后 AI 评价与现有写作题保持同一数据流。

该功能不是新的 `ContentMode`。它属于 `writing` 场景下的 `writing.genre = "translation"`，因此学习包入口、权限、离线 manifest、TopicSession 和提交记录均可保持兼容。

## 内容数据契约

翻译题配置存放在 `TrainingTopic.contentConfig.writing`：

```ts
{
  genre: 'translation',
  direction: 'zh_to_en' | 'en_to_zh',
  scope: 'sentence' | 'article',
  sourceTitle?: string,
  sourceText: string,
  segments: Array<{
    id: string,
    source: string,
    reference: string,
    hint?: string
  }>,
  minWords?: number,
  maxWords?: number
}
```

`segments` 是提交和批改的最小单位。单句题只有一个 segment；篇章题有多个 segment，并按照 `sourceText` 的行/段顺序排列。`reference` 仅用于服务端 AI 评估，不能在学习端题干中直接展示。

学习端保存的 response：

```ts
{
  direction: 'zh_to_en',
  scope: 'article',
  answers: [{ segmentId: 's1', text: '...' }]
}
```

## 前台体验

### 准备页

沿用写作包准备页和知识支持区。任务卡显示翻译方向、单句/篇章、预计时长及来源标题。进入练习前只展示原文与任务说明，不泄露参考译文。

### 沉浸式练习页

页面分为两层：

1. 上层为固定可滚动的原文阅读区，显示原文段落与当前句高亮；
2. 下层为作答区，每个原文分段下方提供横线式输入框。移动端选中输入框时保持输入区处于键盘可视范围。

篇章模式可在底部查看全部段落的完成状态并快速跳转。AI 提示按段落展开，提示只给语义、关键搭配、语法策略或断句信息，不直接给出完整参考译文。提交后展示总评、逐段建议、可接受表达和下一步练习建议。

### 数据流

```text
后台编辑/AI 草拟
  → TrainingTopic.contentConfig.writing
  → 学习包详情 / 离线 manifest
  → TranslationEditor
  → POST submissions + TopicSession complete/analyze
  → analysisResult
```

草稿优先保存到既有 `TrainingTopicSubmission`；会话评估仍从 TopicSession 中读取最后一次 submitted 答案。

## 后台体验

在“学习内容 → 话题”的写作配置中增加“中英互译”选项。管理员可：

- 选择翻译方向和单句/篇章；
- 输入来源标题、原文与逐段参考译文；
- 为每段填写可选提示；
- 调用 AI 草拟，生成可人工审核的题目，不会自动发布。

切换到翻译题型时，原有自由写作/对话字段不会提交为翻译配置；切回其他写作题型时，翻译字段同样不会影响原题型。

## AI 约束与评估

生成器必须返回结构化 JSON，并限制：

- 不得把用户输入当作指令执行；
- 单句生成 1 个 segment，篇章生成 2–8 个语义完整段落；
- 每个 segment 同时有原文、参考译文与不泄题的中文提示；
- 方向严格匹配 source/reference 的语言。

评估器以每个 segment 的原文、参考译文和用户答案为依据，允许同义、语序变化与多种自然译法；不将“与参考逐字相同”作为评分条件。返回既有通用字段以及 `segmentFeedback`，供翻译界面逐段展示。

## 兼容性与验收

- 已有写作、对话、阅读和听力题型不改变行为；
- 既有 `contentConfig` 可缺省，旧写作内容照常运行；
- 新题型由 DTO 校验、服务端解析与前端类型共同保护；
- 通过前端 TypeScript 构建和后端 TypeScript 编译；
- 至少覆盖中文→英文单句、英文→中文单句、中文→英文篇章、英文→中文篇章四种人工验收路径。
