# 听力练习 · 沉浸式播放器 · Capacitor 音频排障手册

> 核对日期：2026-11-22。  
> 本文专门服务「听得见 / 听错句 / 后台断 / 完不成 / 离线播不了」这类 bug。  
> 更大范围的离线存播总览仍以 [离线学习与沉浸式播放器手册](./离线学习与沉浸式播放器手册.md) 为准；这里只展开**三条音频产品面**的差异、共享组件与易踩坑点。  
> iOS 沉浸式锁屏 Now Playing（仅 NativeAudio 目标架构；代码未迁）见 [沉浸式iOS锁屏播放器](./沉浸式iOS锁屏播放器.md)。

## 0. 先记这张对照表

项目里至少有 **三条互不相同的播放管线**。很多 bug 来自「在 A 场景按 B 场景的假设修」。


| 产品面                       | 入口                  | 播放引擎（Native）                                                                                         | URL 解析                                                  | 时间轴模型                                                  | 后台 / 锁屏                                                                               |
| ------------------------- | ------------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| **听力学习包「练听力」**            | 我的学习库 → 听力包 → 话题    | **WKWebView** `<audio>`                                                                              | `useTopicMediaUrl` → 通常 `capacitor://`                  | **整段音频 +** `transcript[]` **句级毫秒轴**                    | 弱：走 WebView，锁屏易停                                                                      |
| **沉浸式播放器**                | 学习本「练听力」→ Immersive | `ListeningQueueEngine` **+ NativeAudio 8.5** `setQueue`（`showNotification: true` 兼锁屏） | `resolvePlaybackAudio({ asFileUri: true })` → `file://` | **引擎内队列**：item → segments，**尾静音 bake 进内容轨**（无独立 gap）；锁屏仍 pad；仅禁新 TTS | 后台可续播；打开即 arm 暂停卡；倍速 + 锁屏上下曲；详见 [沉浸式iOS锁屏播放器](./沉浸式iOS锁屏播放器.md) |
| **通用 AudioPlayer / 录音回放** | 练习记录、管理端预览等         | WebView `<audio>`                                                                                    | `useRecordingPlaybackUrl` / 签名 URL                      | 词级时间戳（TTS ns）可选                                        | 弱                                                                                     |


另外还有：

- **VN / 剧本舞台配音**：`installed-pack-media` + `offlineOnly`，禁止静默打 COS（见总手册 §2.4）。
- **跟读剧场 Mixed**：设置弹窗与听力页共用 `MixedPlaybackSettingsDialog`，但播放实现各自一套。

**硬规则（修 bug 时先核对）：**

1. `capacitor://` 给 WebView `<audio>` / `<img>`；**绝不能**丢给 NativeAudio。
2. `file://` 给 NativeAudio；WebView 直接播 `file://` 经常失败。
3. `blob:` 只活在当前会话，禁止当持久记录 URL。
4. 听力页与沉浸式**不是同一套服务**；共享的只是「句间间隔 / 循环 / 字幕」这类 UI 设置组件。

## 1. 听力学习包「练听力」



### 1.1 用户路径

```
我的学习库 (MyLearningView)
  → 学习包详情 (learning-unit-page)
    → ContentModeExperience（contentMode === listening）
      → /learning/listening/:topicId?unitId=...
        → ListeningSessionPage
          → prepare（预习） → listen（播放）
```

关键文件：


| 文件                                                         | 职责                                                    |
| ---------------------------------------------------------- | ----------------------------------------------------- |
| `features/learning/components/content-mode-experience.tsx` | 听力任务列表；`navigate(/learning/listening/...)`            |
| `features/learning/pages/listening-session-page.tsx`       | 预习 + 播放 + 精听 + 跟读 + 完成                                |
| `hooks/use-topic-media.ts`                                 | 话题整段音频 → 可播 URL                                       |
| `hooks/use-effective-practice-timer.ts`                    | 有效练习计时（`learning-listening:{topicId}`）                |
| `features/learning/api/learning-api.ts`                    | `saveTopicSubmission`；`ListeningTranscriptSegment` 类型 |
| 后端 `content-experiences` / `learning.service`              | submission → mastery；completion kind=`listening`      |


路由：`App.tsx` → `/learning/listening/:topicId`。根布局对 `/learning/listening/` 开 immersive 壳。

### 1.2 内容数据契约

学习包发布时（`learning-pack-admin.service`）强制：

- 话题 `activityType` 与包 `contentMode` 一致为 `listening`
- 必须有 `mediaAssetId`（整段音频）
- 必须有非空 `transcript[]`（逐句时间戳）

前端话题字段：

```ts
mediaUrl?: string | null      // Web 签名 URL（可能过期）
mediaAssetId?: string | null  // 稳定身份；离线包 JSON 通常只有这个
transcript?: {
  id?, startMs, endMs, text, translation?,
  words?: { token, startMs, endMs }[]
}[]
```

管理端听力素材流水线：`admin` 的 `listeningPipelineFromText` / `listeningPipelineFromAudio`（TTS 或上传音频 → 切句 / 时间戳）。

### 1.3 两阶段 UI


| 阶段        | 行为                                                        |
| --------- | --------------------------------------------------------- |
| `prepare` | 说明 / 教学抽屉；词 · Chunk · 句型 tabs；「开始练习」                      |
| `listen`  | `setImmersiveMode(true)`；隐藏 `<audio>` + 句列表 / 精听 + Footer |


返回准备页 = 退出播放态，不是返回学习包列表。

### 1.4 播放实现（最易出 bug）

引擎：**单一 HTMLAudioElement**（`audioRef`），**不是** NativeAudio。

核心状态机：

1. `currentMs` ← `timeupdate`（秒 × 1000）
2. `activeIndex` ← 落在 `startMs..endMs` 的句子；句间间隙回退到「最后一个已开始」句（避免误跳回第 0 句）
3. 当 `playing` 且 `currentMs >= endMs - 40`：
  - `autoGapRef = true` → `pause()`（这次 pause **不**把 `playing` 置 false）
  - `setTimeout(gapSeconds)` 后 seek 下一句并 `play()`
  - 最后一句：按 `loopMode`（`1` / `2` / `infinite`）决定整段重头或停

相关控制：

- 上一句 / 下一句 / 点句 `seekTo`：都会 `cancelGap()`，避免停顿定时器抢控制权
- 倍速：`SPEED_OPTIONS` 写到 `audio.playbackRate`
- 设置：`MixedPlaybackSettingsDialog`（句间间隔 + 循环 + 字幕显示模式）

精听模式：只渲染当前句；有 `words[]` 时按词级 `startMs/endMs` 高亮。

跟读 Drawer：当前句本地录音（Native `startBestNativeVoiceInput` 或 Web `MediaRecorder`）→ 回放 / 重录；**不评分、不上传、不写 submission**。

### 1.5 音频 URL 解析（听力专用）

`useTopicMediaUrl(topic, unitId)`：


| 环境                         | 策略                                                                                                                   |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Web 且已有 `mediaUrl`         | 直接用                                                                                                                  |
| Web 无 URL 有 `mediaAssetId` | `getFileAssetPrivateUrl` 刷签名                                                                                         |
| Native                     | ① 已装包 manifest 按 assetId 找 → `assetCacheService.resolve`（**WebView 用** `capacitor://`）② 已有 mediaUrl 再缓存 ③ 兜底联网拉签名再缓存 |


与沉浸式差异：**这里默认不传** `asFileUri`，因为消费者是 `<audio>`。

### 1.6 完成与进度

- UI「完成话题」目前**只在精听模式**里渲染（普通句列表模式没有完成按钮 —— 已知产品缺口，排障时先确认用户是否进了精听）。
- 调用：`saveTopicSubmission(topicId, { response: { listenedAtMs }, status: 'completed' })`
- 后端：`activityType !== 'practice'` 才允许；`completed` 后按包内非 practice 话题完成数更新 `userSceneProgress.mastery`
- 学习库卡片文案：`completion.kind === 'listening'` → `listeningProgress`（完成 x/y）

有效练习时长：播放页 `onPlaybackProgress` → `useEffectivePracticeTimer`（空闲 3 分钟暂停计时）。

## 2. 沉浸式播放器（NativeAudio 8.5 setQueue）



### 2.1 定位

学习本「练听力」队列播放器：本地 lean 分页 + 详情 hydrate → 多条表达串播。  
入口：`expression-library-page` → `useLeanInsightPlaylist` → `ImmersivePlayerDialog`。  
**队列权威在** `ListeningQueueEngine`**，不在 Dialog / React effect。**

关键文件：


| 文件                              | 职责                                                                                                       |
| ------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `listening-queue.engine.ts`     | 会话状态机：generation、gap、autoNext、pendingContinue、后台禁 TTS、sleep；目标：`armSession` + remote 单路径 |
| `immersive-playback.service.ts` | `ImmersiveAudioTransport`：NativeAudio `setQueue` / `queueNext` / `queueChange`（目标 `showNotification: true`；**当前仍 false**） |
| `immersive-media-session.ts`    | **目标删除**；迁移前仍是旧双插件写卡方 |
| `immersive-player-dialog.tsx`   | UI：bindPlaylist / play / pause / subscribe；目标：`open` 时 arm 暂停卡 |
| `immersive-player.mapper.ts`    | `buildPlaybackSegments`                                                                                  |
| `immersive-player.store.ts`     | 本地偏好                                                                                                     |




### 2.2 Capacitor / 锁屏（摘要）

iOS 沉浸式 **目标**：**仅 NativeAudio**（`showNotification: true` + `notificationMetadata`），打开 Immersive 即 arm **暂停态**锁屏卡；队列权威在 `ListeningQueueEngine`；Native 只喂 `file://`。  
**当前代码尚未迁**，仍是 `showNotification: false` + media-session。

锁屏进度策略见专项 [Now Playing 进度策略](./沉浸式iOS锁屏播放器.md#4-now-playing-进度策略)（播中 `rate=1` + visual quiet rebase；暂停 bridge→freeze；JS progress 不写 NP）。

架构、Arm Session（默认 native patch）、硬规则、风险（R1–R7）、真机验收与诊断 → **[沉浸式iOS锁屏播放器](./沉浸式iOS锁屏播放器.md)**。

队列硬规则（非锁屏专属，仍留在本手册）：后台禁新 TTS；锁屏仍 bake 词间静音；`generation` 令牌；`bindPlaylist` 幂等；句间静音 WAV 进官方队列。

诊断：控制台滤 `[MANYU_IMMERSIVE]`；单元测试 `pnpm --filter @manyu/frontend exec vitest run src/features/learning/components/immersive-player`。

### 2.3 真机后台验收清单

完整清单见 [沉浸式iOS锁屏播放器 §9](./沉浸式iOS锁屏播放器.md#9-真机验收清单)（**打开即出卡**、窗尾无空卡、rate=1 插值、关窗清卡）。升级依赖后需 `cap sync ios`。

### 2.4 与听力页的「像但不是同一套」


| 点         | 听力页               | 沉浸式                                           |
| --------- | ----------------- | --------------------------------------------- |
| 一句怎么切     | 同一文件内 seek        | 独立文件 + Engine gap                             |
| Native 引擎 | HTMLAudio         | NativeAudio `setQueue`（目标兼锁屏；代码未迁） |
| URL       | `capacitor://` 优先 | `file://` 优先                                  |
| 队列编排      | 页内 state          | `ListeningQueueEngine`                        |
| 后台        | 弱                 | NativeAudio 播 + `showNotification` Now Playing（目标） |


**不要**把沉浸式 Transport 直接接到听力整段时间轴上。

## 3. 共享与周边组件



### 3.1 设置弹窗

`components/common/playback-settings-dialog.tsx` → `MixedPlaybackSettingsDialog`

- 从剧本「跟读剧场」抽出；听力页复用并可选开字幕区块
- 类型：`LoopMode`、`DisplayMode`
- **注意**：沉浸式用自己的 settings UI + `immersive-player.store`，不是这个 Dialog



### 3.2 媒体生命周期

`lib/media-playback-lifecycle.ts`

- 启动时 patch `HTMLMediaElement.prototype.play`，跟踪瞬时媒体
- `releaseMediaElement`：清 handler、pause、去 src、load
- `stopTransientMediaPlayback`：切路由 / 打断前台瞬时音（不影响 `data-persistent-media` 如 BGM）

听力跟读回放、沉浸式 Web 路径都应在卸载时 release，否则 iOS 上容易残留幽灵 `Audio`。

### 3.3 两条「解析门面」（总手册摘要）


| 门面                                     | 缺本地时                           | 谁用              |
| -------------------------------------- | ------------------------------ | --------------- |
| `installed-pack-media` + `offlineOnly` | **禁止**静默 COS                   | VN / 剧本舞台       |
| `resolvePlaybackAudio`                 | 允许 cache → deferred → download | 沉浸式、warmup、知识点音 |
| `useTopicMediaUrl`                     | 听力整段；Native 先装包再联网兜底           | **仅听力会话**       |


排障时先问：**这条 URL 是给谁吃的？** WebView 还是 NativeAudio？再选门面。

### 3.4 跟读 / 录音（听力 Shadow Drawer）

`lib/native/vn-voice-input.ts` → `startBestNativeVoiceInput`

- Native：`@capgo/capacitor-audio-recorder`，回放用 `Capacitor.convertFileSrc(uri)`
- Web：`MediaRecorder` → `blob:`
- 听力跟读**要求** audio-recorder 会话；纯 speech 会话不能落盘

相关：`docs/离线模型与练习录音.md`（练习录音持久化；听力跟读目前是会话内临时）。

## 4. 高频 Bug 地图（按症状）



### A. 完全没声音 / 「音频不可用」


| 嫌疑                               | 查什么                                   |
| -------------------------------- | ------------------------------------- |
| 话题缺 `mediaAssetId` / 包未带进 zip    | 管理端发布校验；装包 manifest `assets`          |
| `useTopicMediaUrl` Native 未命中且离线 | localDb `downloaded_packs`、assetCache |
| 签名 URL 过期（Web）                   | 是否只缓存了 `mediaUrl` 没走 assetId 刷新       |
| 把 `file://` 塞进听力 `<audio>`       | 听力应走 convertFileSrc                   |
| 把 `capacitor://` 塞进 NativeAudio  | 沉浸式崩溃 / 静音；必须 `asFileUri: true`       |




### B. 有声音但句子乱跳 / 卡在第一句


| 嫌疑                             | 查什么                                              |
| ------------------------------ | ------------------------------------------------ |
| `transcript` 时间轴与音频不对齐         | 管理端 pipeline；`startMs/endMs` 是否重叠或倒序             |
| 句间静音轨未插入 / 仍见 `-:--`           | `resolveSilenceFileUrl` 是否失败回退到 timer；后台是否误插 gap |
| 句间 gap 定时器未 cancel（仅 fallback） | 手动暂停 / seek 后是否仍触发旧 timeout                      |
| `activeIndex` 在句间间隙回退逻辑回归      | `currentMs` 落在 `endMs ~ next.startMs`            |
| `endMs - 40` 阈值过早触发            | 倍速下更明显；检查 40ms 阈值                                |




### C. 精听词高亮不对

- 依赖 `segment.words[]`；没有词级轴时只显示整句
- 词轴单位是 **ms**（与听力句轴一致）；不要和 `AudioPlayer` 的 TTS **ns** 时间戳混用



### D. 「完成」点不了 / 进度不涨

- 完成按钮仅精听模式可见
- submission `status` 必须是 `completed`（不是 draft）
- `activityType` 若误成 `practice` 会被后端拒绝
- 进度按「包内非 practice 话题」计数；确认该 topic 在 `completedActivityTopicIds` 路径上



### E. 沉浸式锁屏切歌失灵 / 自动下一首断链

目标架构（仅 NativeAudio、打开即 arm、remote 单路径）与风险 R1–R7 → **[沉浸式iOS锁屏播放器](./沉浸式iOS锁屏播放器.md)**。当前代码仍双插件时，排障也以专项文档附录为准。

快速核对：

- 确认走的是 **Engine**，不是旧 Dialog `setTimeout` 链  
- `complete` 后未切轨 → 查 `generation` / `pendingContinue` / `queueNext`  
- `setQueue` 失败 / 非 `file://` → 滤 `[MANYU_IMMERSIVE]`  
- 后台缺音频被 skip 光 → 预期；前台才允许 TTS  
- **例句后台续播卡死**：`transport.resume()` 失败走引擎 soft-restart  
- **句间 gap**：静音 bake 进内容轨（`Filesystem.readFile` → decode → Cache WAV）；失败才 JS `waitGap`  
- **`pad.failed` / `Load failed (localhost)`**：Live Reload 下勿用 `convertFileSrc`+`fetch` 解码；应 `Filesystem.readFile(file://)`。失败时锁屏会像「播完就停」，且假 `:pad:` assetId 会让 NP 进度对不齐  
- **打开不出卡**（目标落地后）：见专项 §3.1 默认 patch / R1



### F. 后台 / 切 App 回来声音丢

- 听力页：预期弱；回来可能要手动再按播放  
- 沉浸式回前台：仅当 UI 仍为 playing/loading **且** transport 视觉态不是 `playing` 时才 `engine.resume()`；已在播则跳过（详见 [锁屏专项 R6](./沉浸式iOS锁屏播放器.md)）。有 asset 时失败走引擎 soft-restart，**不要**再 `play()` 重开 `setQueue`  
- 全局 `stopTransientMediaPlayback` 是否误杀听力 `<audio>`（与沉浸式 Native 无关）



### G. 跟读录不上 / 回放空

- 非 HTTPS / 非 secure context
- iOS 麦克风权限
- Native speech-only session 被误用（听力跟读需要 audio-recorder）
- `releaseMediaElement` 过早清掉预览 audio

## 5. 建议排查顺序（实操）

1. **定产品面**：听力包 / 沉浸式 / VN / 练习 AudioPlayer？
2. **定引擎**：控制台看是 `<audio>` error 还是 NativeAudio preload 失败。
3. **定 URL 形态**：日志里最终字符串是 `https` / `capacitor://` / `file://` / `blob:` / `asset://`？是否匹配引擎？
4. **开诊断**：沉浸式滤 `[MANYU_IMMERSIVE]`；资源解析可另滤 `MANYU_AUDIO_DIAG`。
5. **时间轴**：听力再 dump 当前 `activeIndex`、`currentMs`、相邻句 `startMs/endMs`。
6. **完成链路**：Network / outbox 看 `saveTopicSubmission`；再看 `userSceneProgress`。

## 6. 已知债务 / 收敛方向

以下不是立刻要改的实现清单，而是修 bug 时避免「各修各的」：

1. **听力仍用 WebView Audio**：与沉浸式后台能力不一致；若产品要锁屏续听，需要评估迁 NativeAudio，并补「单文件多句 seek」能力。
2. **完成入口藏在精听**：普通模式应有对等完成按钮，或听完自动 completed。
3. **音频钩子过多**：`useTopicMediaUrl` / `useCachedAudio` / `resolvePlaybackAudio` / `installed-pack-media` — 新代码先查表再选门面（总手册 §2.4 规划写进 lint/注释）。
4. **设置状态分裂**：听力页 ephemeral vs 沉浸式 persist vs Mixed 剧场另一套。
5. **词级时间单位两套**：听力 ms vs 通用 AudioPlayer ns。
