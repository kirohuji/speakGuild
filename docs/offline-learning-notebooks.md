# 学习本的本地数据与同步

学习库列表、内容详情、选择学习本弹窗均从 SQLite 读取，不直接调用学习本列表接口。header 的同步按钮执行学习本范围的统一同步。页面搜索、筛选、分页不触发网络请求。

## 本地一致性

- `notebookItemsSql` 是统计和详情分页共用的数据集：按学习本和内容去重，优先保留待同步版本，排除删除标记、已删除学习本及缺失内容的关联，再筛选学习状态。
- 本地变更和不可变的 outbox 操作在同一 SQLite 事务中提交。写入失败整体回滚。事务后发布 `learning-library-changed`。
- 本地学习本及关联 ID 保持稳定，remoteId 记录服务端身份，避免同步中路由和待同步引用失效。
- 移出最后一个学习本不会自动归入未分类。删除学习本不会删除其他本共享的内容。
- 本地新建的未分类学习本在服务端与该用户已有的系统本合并，通过 remoteId 对应，避免重复创建。

## 同步

- `notebook` / `notebook_item` 使用 snapshot 操作，独立的 clientMutationId 和 predecessor 表达操作顺序。
- 服务端在同一事务中保存操作结果和 `notebook_sync_receipt`；响应丢失后的重试直接返回原结果。
- 服务端版本和更新时间用于冲突检测。冲突保留在待同步队列及错误详情，不覆盖本地数据。暂不自动选择哪台设备的内容胜出。
- 拉取不覆盖有实际待同步操作的本地学习本和关联；历史上没有对应队列的脏 pending 标记可以被正常核对修复。
- 学习本、关联、表达式及其删除流使用时间加 ID 的分页游标。每页学习本数据和游标原子提交，超时显示未完成，下次继续。
- 升级到本协议后，统一同步会重置一次相关旧游标，重新核对远端数据，保留本地待同步操作。
- 已删除学习本下尚未上传的关联操作由服务端确认为被删除操作取代，不永久阻塞队列。
- 操作包含所属账号；拉取结果也包含账号，防止切换账号时将响应写入错误的数据空间。
- 离线不请求同步接口、不生成失败弹窗；本地操作仍正常保存。离线退出登录被阻止。

## 部署

先应用 `20261114000100_notebook_sync_receipts` 数据库迁移，再发布支持本协议的后端和前端。该迁移增加学习本和关联的版本字段，以及操作回执表。旧 API 保留供已有调用方使用。

## 验证

针对性测试覆盖本地新建、加入、移出、重新加入、学习状态、跨本共享内容、统计与详情统一、事务回滚、旧请求完成期间的新修改、同步依赖、回执去重、账号检查、冲突保留，以及 501 条相同时间记录的分页。
