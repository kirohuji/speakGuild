# 03-背景

对话背景的主战场。**这一桶的成本占全包 60%**，优先级判断错会直接拖垮进度。

## 四个子目录怎么分

| 目录 | 放什么 | 例子 |
|---|---|---|
| `室外-地点/` | 户外场景的默认（白天）版本 | `bg_gate_street`、`bg_plaza_fountain`、`bg_flower_front` |
| `室内-房间/` | 所有室内 | `bg_cafe_counter`、`bg_library_reading`、`bg_workshop_bench` |
| `时段与天气/` | 已有背景的 `_dawn _dusk _night _rain` 差分 | `bg_street_shops_night`、`bg_plaza_fountain_rain` |
| `庆典夜/` | 星灯纪念夜专用 | `bg_plaza_fountain_festival`、`bg_plaza_lantern` |

差分命名 = 基础名 + 时段/天气后缀。**基础图放原地，差分统一放 `时段与天气`**，这样一眼能看出哪些是差分图，找图不用满目录翻。

## 硬规格

- 1920 × 1080，WebP q85，单张 ≤ 500 KB。
- 中间 60% 横向是主视觉；两侧各 20% 会被立绘压住，别放关键信息。
- 上方 12%、下方 18% 是安全边，不放重要细节。
- 统一光源方向：**左上主光**，暖色温。同一地点不同时段的阴影方向要一致。
- 有人的场景（咖啡店、花店）可以画空镜 + 少量环境物件，**不要画围观群众**——立绘只有主要角色，背景里出现别的人会穿帮。

## 优先级

| 批次 | 数量 | 内容 |
|---|---:|---|
| P0 | 10 | 序章 + E01–E04 + E16 所需 |
| P1 | 32 | 主线剩余全部房间 |
| P2 | 13 | 只出现在日常的房间 + 次要时段/天气差分 |

**别先画差分。** 差分是锦上添花；主线跑不通就没有验收机会。

## 验收

- `# bg:` 里的每个别名都能在 assetMap 找到 → 否则黑屏。
- day/night 同构图 → 否则切时段像换了地方。
- 雨天必须真的画雨（雨丝、湿地面反光），**不要用蓝色滤镜冒充**。
