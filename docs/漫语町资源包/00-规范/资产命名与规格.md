# 资产命名与规格

## 1. 文件命名

### 1.1 通用格式

```text
<前缀>_<主体>[_<子项>][_<变体>].<扩展名>
```

只允许小写字母、数字、下划线。不用空格、不用中文、不用连字符（`-`）——连字符留给文件夹名。

### 1.2 前缀表

| 前缀 | 用途 | 对应数据库字段 |
|---|---|---|
| `map_` | 全域地图 | `GameMap.backgroundUrl` |
| `icon_` | 地点图标 | `GameLocation.icon` |
| `loc_` | 地点外观大图（可选） | `GameLocation.backgroundUrl` |
| `bg_` | 房间内景 / 对话背景 | `GameRoom.backgroundUrl`、`InkScript.assetMap` |
| `chr_` | 角色立绘 | `GameCharacter.spriteBaseUrl` / `expressions[*]` |
| `avatar_` | 角色头像 | `GameCharacter.avatarUrl` |
| `prop_` | 剧情道具图 | `assetMap`（`# image:` 或道具栏） |
| `stamp_` | 印章 / 收集品 | 收集系统 |
| `ui_` | 界面元素 | 前端静态资源 |
| `cg_` | 章末大图 | 剧集结尾展示 |
| `bgm_` / `amb_` / `sfx_` | 音乐 / 环境音 / 音效 | `bgmUrl` / `ambientUrl` / `# audio:` |

### 1.3 地点键（固定，不许自创）

`gate` 町口 · `plaza` 中央广场 · `street` 主街 · `riverside` 河岸步道 · `post` 邮局 · `library` 町立图书馆 · `bookstore` 猫尾堂旧书店 · `cafe` 橡果咖啡 · `bakery` 面包店 · `flower` 花店 · `workshop` 铁哥工房 · `warehouse` 二手仓库 · `gym` 白熊铁馆 · `boutique` 服装店 · `market` 市集 · `bath` 水音汤 · `tower` 钟楼

房间键见 `01-剧本/地点房间与背景对照表.md`，用的是 `bg_<地点>_<房间>`。

### 1.4 角色键与表情键

角色键：`fox ash maya sari yoyo iris vivi nora eira sian riggs lux wooly noel basil tank rico polar`

表情键：`default happy thinking surprised sad`，可选补充 `shy serious laugh tired proud`。

```text
chr_fox_default.png
chr_fox_happy.png
chr_fox_thinking.png
chr_fox_surprised.png
chr_fox_sad.png
avatar_fox.png
```

### 1.5 变体后缀

`_dawn` 晨光 05–08 · `_day` 白天 08–16 · `_dusk` 黄昏 16–19 · `_night` 夜 19–23 · `_rain` 雨 · `_festival` 庆典夜 · `_snow` 雪（预留）

无后缀 = 该地点的默认时段。

## 2. 尺寸与格式

### 2.1 背景（`bg_` / `loc_`）

| 项目 | 规格 |
|---|---|
| 画布 | 1920 × 1080（16:9），与 `GameMap.width/height` 默认值一致 |
| 格式 | WebP（q85）交付，保留 PNG 母版 |
| 单张体积 | 目标 ≤ 500 KB，离线包友好 |
| 安全区 | 中间 60% 横向区域是主视觉；两侧各 20% 会被立绘压住 |
| 头顶留白 | 上方 12% 不放大主体（对话框不一定在底部） |
| 底部 | 下方 18% 避免关键细节（被字幕/选项遮挡） |
| 风格 | 半写实日系动画背景，柔和体积光，统一光源方向为**左上** |

### 2.2 立绘（`chr_`）

**现行标准（与已入库的 18 张一致）：半身像 512 × 768。**

| 项目 | 规格 |
|---|---|
| 画布 | 512 × 768（2:3），透明 PNG，8-bit RGBA |
| 构图 | 半身，从腰部裁切，正面朝镜头 (`half_body / cropped_at_waist / front_view`) |
| 人物占比 | 头顶留 6–10%，左右各留 ≥ 20px |
| 表情差分 | **必须同一画布、同一构图**，只换头部；禁止在差分图里改姿势或缩放 |
| 描边 | 无外描边（防白边）；导出时保留 1px 透明边距 |
| 光照 | 与背景一致：左上主光，暖色温 |
| 体积 | 单张 ≤ 800 KB |

> 引擎按整图替换，所以「只画脸」也要导成整张同尺寸图。`_模板/` 里放一张 512×768 的透明参考线，画师照着对位。

**可选进阶：全身立绘 1080 × 1920。** 只有要做「全身 + 场景站位」的镜头才值得投入，脚底对齐 y ≈ 1820，头顶留 100px。两套尺寸不要混用，同一角色只能选其中一套。

### 2.3 头像（`avatar_`）

现状：**直接复用半身像**，不做单独头像文件（数据库里 `avatarUrl` 与 `spriteBaseUrl` 指向同一张）。

若要单独出头像：512 × 512，从半身像裁头部特写，保留耳朵与发梢，顶部留 8% 给刘海，底部到锁骨。

### 2.4 地图（`map_`）

| 项目 | 规格 |
|---|---|
| 画布 | 1920 × 1080；若要做地图平移，出 2560 × 1440 |
| 内容 | 俯视/等距小镇全景，17 个地点可辨识；不带文字标签（标签由 UI 渲染） |
| 变体 | `_day`、`_night`、`_festival` 三张，构图必须完全一致 |
| 图标 | `icon_<key>.png`，256 × 256（显示尺寸约 26px，缩放后仍需可辨） |

### 2.5 图标与道具

| 类型 | 规格 |
|---|---|
| 地点图标 | 256 × 256 PNG 透明，简洁剪影 + 单色描边 |
| 印章 | 512 × 512 PNG 透明 |
| 道具（信件/照片） | 1200 × 900 PNG，需要被放大查看，字迹要清晰 |
| CG | 1920 × 1080 WebP，构图留出上下 10% 给字幕与 UI |

### 2.6 音频

| 类型 | 规格 |
|---|---|
| BGM | MP3 128–192 kbps，无缝循环，30–90 秒 |
| 环境音 | MP3 128 kbps，无缝循环，20–40 秒 |
| SFX（对白） | MP3 128 kbps，单声道即可 |
| 响度 | 统一归一化到 -16 LUFS，避免集与集之间忽大忽小 |

## 3. 交付与收录

1. 新图先放 `_待整理/`，不要直接塞进目标目录。
2. 改名后移动到目标目录，**不要留副本**——重名靠 `_v2` 只会让 assetMap 混乱。
3. 更新 `资产收集清单.csv` 的 `status`：`todo` → `got` → `named` → `uploaded`。
4. 上传后台后，在 `InkScript.assetMap` 用**同一个别名**注册。别名和文件名不一致是最常见的线上事故。

---

## 4. 快速自检清单

- [ ] 文件名全小写、无空格、无中文
- [ ] 背景 1920×1080，立绘 512×768（半身，与已入库一致）
- [ ] 立绘底部对齐一致，多人同框不跳高度
- [ ] 背景变体之间构图完全一致（切时段不跳画面）
- [ ] 别名已在 assetMap 注册，且 `# bg:` 里写的别名存在
- [ ] 单张背景 ≤ 500 KB，整包离线体积可控
