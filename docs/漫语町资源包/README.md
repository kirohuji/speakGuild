# 漫语町资源包 · 目录与收集指南

这里是「漫语町」剧情包 + 探索模式用到的**全部美术与音频资产的落位说明**。

三句话版本：

1. **剧本在 `01-剧本`**，图片按类型入桶，音频按用途入桶。
2. **文件名 = 资产别名**，代码侧 `InkScript.assetMap` 只认别名，改名等于改剧本。
3. 收集时打开 `00-规范/资产收集清单.csv`，收一张勾一行。

---

## 一、这套资源服务于什么

| 内容层 | 规模 | 说明文档 |
|---|---|---|
| 主线剧情 | 序章 + 4 章 16 集 + 尾章 1 集 | `01-剧本/主线章节设计.md` |
| 探索模式·日常 | 17 个地点 / 35 个房间 / 36 段日常短剧 | `01-剧本/日常探索与时段系统.md` |
| 地点与背景对照 | 每个地点用什么背景、常驻谁、放什么声音 | `01-剧本/地点房间与背景对照表.md` |
| 角色立绘与表情 | 18 位角色 × 表情集 | `01-剧本/角色立绘与表情表.md` |

技术上对应已有的数据结构，不新增表：

- `GameMap.backgroundUrl` → 全域地图
- `GameLocation.backgroundUrl / icon / bgmUrl / ambientUrl` → 地点外景、地图图标
- `GameRoom.backgroundUrl / roomType / isEntrance` → 房间内景、对话背景
- `GameCharacter.avatarUrl / spriteBaseUrl / expressions` → 头像、立绘、表情
- `InkScript.assetMap` → `# bg:` / `# audio:` 标签引用的别名注册表
- `GameCommitment.startMinute / endMinute` → 日常模式的时段表

## 三、命名速查

前缀决定放哪个文件夹，后缀决定变体。

| 前缀 | 含义 | 放哪 | 示例 |
|---|---|---|---|
| `map_` | 全域地图 | `02-地图/全域地图` | `map_manyu_day.webp` |
| `icon_` | 地点图标 | `02-地图/地点图标` | `icon_cafe.png` |
| `bg_` | 对话/房间背景 | `03-背景/*` | `bg_cafe_counter.webp` |
| `loc_` | 地点外观大图（可选） | `03-背景/室外-地点` | `loc_plaza.webp` |
| `chr_` | 角色立绘 | `04-立绘/<角色键>` | `chr_fox_happy.png` |
| `avatar_` | 角色头像 | `04-立绘/<角色键>` | `avatar_fox.png` |
| `prop_` | 剧情道具 | `05-道具与UI/*` | `prop_letter_piece_02.png` |
| `stamp_` | 印章/收集品 | `05-道具与UI/印章与收集品` | `stamp_ch01.png` |
| `ui_` | 界面元素 | `05-道具与UI/UI` | `ui_choice_frame.png` |
| `cg_` | 章末大图 | `06-CG` | `cg_ch03_tower.png` |
| `bgm_` / `amb_` / `sfx_` | 音乐 / 环境音 / 音效 | `07-音频/*` | `bgm_cafe.mp3` |

变体后缀：`_dawn`（晨）、`_day`、`_dusk`（黄昏）、`_night`、`_rain`、`_festival`、`_snow`。

角色键固定为：`fox ash maya sari yoyo iris vivi nora eira sian riggs lux wooly noel basil tank rico polar`。
表情固定为：`default happy thinking surprised sad`（可按角色追加 `shy serious laugh tired proud`）。

## 五、工作流

```text
① 收到图 → 先丢 _待整理/
② 按《资产命名与规格》改名 → 移进对应文件夹
③ 在 00-规范/资产收集清单.csv 里把 status 从 todo 改成 named
④ 后台作为 FileAsset 上传 → 在 InkScript.assetMap 注册同名 alias
⑤ 剧本只写 # bg:bg_cafe_counter，不写 URL
```

第 ④ 步之后，URL 签名过期、换图重传都不需要改脚本——这是别名机制的全部意义。
