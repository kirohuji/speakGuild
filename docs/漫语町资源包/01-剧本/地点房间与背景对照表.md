## 六、落库提示

1. 先建 `GameMap`（`map_manyu_day`），再批量建 17 个 `GameLocation`，`icon` 填 `icon_<key>`。
2. 每个地点建 1–3 个 `GameRoom`，第一个 `isEntrance=true`，`backgroundUrl` 填 `bg_<地点>_<房间>`。
3. 房间里有谁 = `GameCommitment`（`characterId + roomId + startMinute + endMinute`），**不要在剧本里写「谁出现了」**。
4. Ink 里只写 `# bg:bg_cafe_counter`，`bg_` 别名在 `InkScript.assetMap` 注册一次即可。
5. 同一张图被多个剧集引用时，assetMap 只需注册一次；不同剧集各自注册也没问题，但要保证 `fileAssetId` 一致。
