# 06-CG

章末大图。玩家看完一章会记住的那一张，所以**只有 6 张，但每张都要能当宣传图**。

| 文件 | 时机 | 画面 |
|---|---|---|
| `cg_prologue.webp` | 序章 | 巴士车窗外的町口，玻璃上有轻微反光 |
| `cg_ch01_postcard.webp` | E04 章末 | 明信片特写，背面露出 `Find the people who keep the town warm.`，第一枚印章刚盖上 |
| `cg_ch02_lantern.webp` | E09 章末 | 修好的灯在工坊门口亮起，Tank 与玩家一前一后 |
| `cg_ch03_tower.webp` | E13 章末 | 钟室里三人围着一封信拼页，绳梯垂在光里 |
| `cg_ch04_rain.webp` | E15 | 小雨里搬桌椅，几个人抬着同一张桌子 |
| `cg_ch04_starlight.webp` | E16 章末 | 全场星灯亮起，人群抬头。**这是主视觉** |

## 规格

- 1920 × 1080 WebP，上下各留 10% 给字幕与 UI。
- 构图要求「一眼看懂发生在哪」——背景必须能认出是广场、工坊还是钟室。
- 可以有多个角色，但**不要依赖立绘的精细度**：CG 里的人脸只需要到「看得出是谁」的程度。
- `cg_ch04_starlight` 是全包唯一允许做高完成度的一张，商店封面、加载页、结局都复用它。

## 优先级

P0 只做 `cg_ch01_postcard`（纵切片结尾要有收束感）；其余 P1；`cg_prologue` 可延后到 P2。
