# 08-参考

放**不直接进包**的参考素材：色调、光线、材质、构图。画师开工前看这里，比看文字描述有效十倍。

## 情绪板该收什么

| 类别 | 收什么 | 为什么 |
|---|---|---|
| 色调 | 小镇石板路、木头招牌、水面的照片 | 定一套共享调色板，避免每个地点各自为政 |
| 光线 | 黄昏斜光、灯笼暖光、雨天漫射光 | 全篇光源统一左上来，靠参考图对齐 |
| 材质 | 木、石、纸、布、金属 | 漫语町是「旧但被照顾得很好」的手感 |
| 构图 | 空镜、窗边、柜台前的两人构图 | 立绘会压住两侧，构图参考能少返工 |

## 建议的共享色板（可调整）

| 用途 | 色值 | 说明 |
|---|---|---|
| 石墙 / 路面 | `#C9C2B6` | 全篇中性底 |
| 木构件 | `#8B6B4A` | 招牌、柜台、地板 |
| 河水 | `#6E93A8` | 冷色对比 |
| 灯笼暖光 | `#F2C879` | 夜景的高光色 |
| 夜蓝 | `#2C3E56` | 夜景底色 |
| 花与围巾 | `#C96F6A` | 点缀色，用量控制在 5% 以内 |

原则：**白天偏灰暖，夜里偏蓝，庆典夜把暖光占比提到 30% 以上**——这是玩家感知「今天很特别」的唯一手段。

## 使用规范

1. 参考图不打包、不注册 assetMap，只作为沟通材料。
2. 收集时标注来源与授权，避免把有版权的图当内部参考到处传。
3. 一个地点一个文件夹，命名 `ref_<地点键>_<主题>.jpg`。
