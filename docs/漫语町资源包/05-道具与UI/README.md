# 05-道具与UI

剧情里被「拿起来看」的东西，和界面上的装饰件。

## 信件与明信片

全篇的核心意象，**四段信 + 一张明信片必须同一套纸、同一手字**。

| 文件 | 说明 |
|---|---|
| `prop_invitation_card.png` | 玩家收到的邀请卡，序章与 E01 各出现一次 |
| `prop_map_wet.png` | 被雨打湿的庆典地图，E02 |
| `prop_photo_old.png` | 无署名的旧照片，E03 |
| `prop_postcard.png` | 给「未来的新朋友」的明信片，E04 |
| `prop_book_star.png` | 星灯书签，E07 |
| `prop_letter_piece_01..04.png` | 信的四段，分别在 E07 / E08 / E11 / E13 得到 |
| `prop_wind_note.png` | 被风吹走的便条，E12 |
| `prop_reply_<角色键>.png` | 角色回信 ×18，完成 3 段日常后解锁 |

**验收要点**：四段信拼起来必须是一张完整的信。建议先画完整信，再切成四段导出——顺序反过来几乎一定拼不上。

规格：1200 × 900 PNG，需要被放大查看，字迹要清晰可读。
