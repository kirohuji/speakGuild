# 学习包课程地图与设计稿

> 状态：课程规划 v1  
> 目的：先统一“有哪些学习包、每个包解决什么问题、下一批该做什么”；本文件不是具体课文或数据库导入清单。

## 1. 课程体系的核心判断

现在的内容基础已经覆盖了三种不同的学习需求：

| 内容线 | 用户真正需要解决的事 | 现有代表包 |
| --- | --- | --- |
| 高频表达积累 | 面对常见互动时，知道一句自然的话怎么说。 | 常用英语500句 |
| 自主组织表达 | 不只复读现成句子，而是能换信息、说自己的事。 | 口语万能造句：50 个高频句式 |
| 表达准确性 | 讲过去、结果、经历时，动词形式不混乱。 | 不规则动词专项 |

因此，后续不应继续平行增加“更多句子”“更多单词”“更多语法”的大包，而要补齐第四条内容线：**把已有表达迁移到具体生活场景中**。之后再按真实用户画像扩展职场、留学、听力或故事，不要一次全部铺开。

## 2. 已有学习包总目录

以下为数据库中已发布、可作为正式目录基础的内容；`[测试]` 包、单篇中英互译样例和仍为草稿的《漫语町》不计入当前正式课程地图。

### 2.1 常用英语500句

| 项目 | 设计 |
| --- | --- |
| 包类型 / 难度 | `course` / L1 起步，包含少量 L2–L3 内容 |
| 课程定位 | 建立日常互动的高频回应库；重点是意图、语气与回应，而不是逐句死背。 |
| 当前结构 | 8 个话题，每个建议 15 分钟。 |
| 用户完成后 | 能在问候、感谢、请求、澄清、表达意见、安慰和日常事务中选出合适的短表达。 |
| 与其他包的关系 | 为场景包提供可复习的整句表达；和 50 句型并行学习。 |

| 顺序 | 话题 | 本课的交流动作 |
| --- | --- | --- |
| 01 | 问候与寒暄 | 开启、维持并自然结束一段短对话。 |
| 02 | 感谢、道歉与祝福 | 让感谢、修复关系和祝福落在具体事情上。 |
| 03 | 请求、指令与许可 | 提出请求，给对方选择与回应空间。 |
| 04 | 疑问、澄清与确认 | 没听懂或信息不完整时，定位并确认问题。 |
| 05 | 观点、同意与评价 | 给出观点、理由，以及温和的不同意见。 |
| 06 | 情绪与安慰 | 表达状态、承认感受并作出恰当回应。 |
| 07 | 日常陈述与事务 | 说明进度、限制、安排和下一步。 |
| 08 | 惯用语与俚语 | 判断语域和关系，理解而不滥用固定表达。 |

**待收口：** 课程名写“500句”，而当前可追踪的 `chunk:learn` 为 480 条。正式文案和实际材料数需要在发布前一致。

### 2.2 口语万能造句：50 个高频句式

这是一个单独的 `foundation` 学习包。整体是 L1、15 个话题、50 个句式；每课 1–2 分钟的句式替换练习可作为日练，也应支持串成连续学习。原来的三个子包已经合并为这一包。

| 单元 | 话题 | 用户完成后 |
| --- | --- | --- |
| 开口与社交（01–05） | 自我介绍、计划、意愿、礼貌请求、帮助 | 能自然开始互动并表达最基本的需求。 |
| 聊天与互动（06–10） | 兴趣经历、邀请、澄清、同意/保留、共情 | 能把一问一答延续成短对话。 |
| 日常与解决（11–15） | 故障、进度、过去经历、未来、建议 | 能说明问题、描述经历并讨论解决方案。 |

**待发布：** 已合并的单包包含 15 个话题和 50 个句式。旧的三份离线 ZIP 不再适用；需要从后台生成并发布新 v3，供离线下载使用。

### 2.3 不规则动词专项

| 项目 | 设计 |
| --- | --- |
| 包类型 / 难度 | `course` / L1–L2 |
| 课程定位 | 在讲真实经历、变化和结果时正确选择不规则动词形式；不做孤立的三态表背诵。 |
| 当前结构 | 8 个话题，每个建议 15 分钟。 |
| 用户完成后 | 能围绕日常、移动、沟通、交易、意外和创造讲出一段有时间线的经历。 |
| 与其他包的关系 | 建议在 50 句型的第 03 阶段后进入；也可供有明确痛点的用户直接专项学习。 |

| 顺序 | 话题 | 叙事任务 |
| --- | --- | --- |
| 01 | 日常起居 | 用日常动作讲清发生、完成与现在结果。 |
| 02 | 来去与移动 | 讲一次出行、路线和变化。 |
| 03 | 感知与思考 | 复盘一次看见、理解、学习或发现。 |
| 04 | 说话与沟通 | 转述一段对话和回应。 |
| 05 | 金钱与交易 | 描述购买、选择、得失与处理问题。 |
| 06 | 运动与比赛 | 串联连续动作和比赛结果。 |
| 07 | 身体与意外 | 向医生或他人说明意外、反应和后果。 |
| 08 | 拥有与创造 | 介绍做过的项目、过程与结果。 |

**待收口：** 8 篇教学文档已存在，但各话题目前没有绑定的词汇、句块和句型。后续应从文档中提炼每课实际使用的材料，建立可追踪的 `learn` / `review` 关联，才能支持复习调度和学习包质量校验。

## 3. 现有内容的缺口

| 用户旅程 | 现有覆盖 | 缺口 |
| --- | --- | --- |
| 第一次开口 | 50 句型的开口与社交部分很强。 | 缺少一条把多个包内容编排成“第一周每天练什么”的入门路径。 |
| 日常自由聊天 | 50 句型 + 500句覆盖较好。 | 缺少在完整真实场景中连续使用这些表达的机会。 |
| 服务场景办事 | 只有零散表达和测试样例。 | 缺少从提出需求、听取回应、处理问题到确认下一步的一整段任务。 |
| 讲经历 | 不规则动词专项有清晰方向。 | 需要材料关联和复习承接，避免它成为单独的语法岛。 |
| 职场 / 留学 / 考试 | 尚未形成正式课程。 | 应由真实目标用户和反馈决定优先级。 |
| 听力、阅读、写作、剧情 | 只有技术测试或草稿内容。 | 这是新学习模式，不能为了目录完整度仓促上线。 |

## 4. 后续学习包候选池

下列是课程地图中的候选，不表示要同时立项。建议一次只生产一个正式新包，完成试学和复盘后再开下一个。

### P1：生活服务与出行（下一包，优先级最高）

| 项目 | 初步设计 |
| --- | --- |
| 目标用户 | L1–L2，想把基础表达用于旅行、海外生活或日常服务场景的学习者。 |
| 包承诺 | 在服务场景中完成“说明需求 → 听懂回应 → 追问/解决问题 → 确认下一步”。 |
| 规格 | `course`，12 话题，4 单元，每话题 8–12 分钟。 |
| 前置 / 复习 | 推荐完成 50 句型 01；大量复习 500句的请求、澄清、感谢表达。 |
| 新材料原则 | 每话题仅新增完成该场景不可替代的 3–6 个表达；已有内容必须标记为 `review`，不重新教授。 |

| 单元 | 话题草案 | 最终输出任务 |
| --- | --- | --- |
| 餐饮与购物 | 点单；说明忌口；付款；退换 | 完成点单或退换的一段 4–6 轮对话。 |
| 出行 | 问路；公共交通；打车；行程变更 | 说清目的地、时间和问题，并确认方案。 |
| 住宿与预约 | 酒店入住；房间问题；电话预约；求助 | 描述情况、提出要求、确认处理时间。 |
| 日常事务 | 快递；药店；手机/网络故障；丢失物品 | 提供关键信息并得到下一步行动。 |

### P2：职场协作与沟通（第二批候选）

| 项目 | 初步设计 |
| --- | --- |
| 立项条件 | 有较明确的职场用户占比，或用户反馈反复出现“开会、进度、协作”需求。 |
| 目标用户 | L2–L3，已经能完成简单日常交流，想在英文工作环境中协作。 |
| 包承诺 | 能参加短会、同步进度、提出澄清、协商任务并做基本汇报。 |
| 规格 | `course`，10 话题，5 单元，每话题 10–15 分钟。 |

话题草案：自我介绍与角色、安排会议、同步进度、提出阻塞、请求帮助、给出反馈、表达不同意见、任务分工、汇报结果、会后确认。

### P3：留学生活沟通（第二批候选）

| 项目 | 初步设计 |
| --- | --- |
| 立项条件 | 留学/海外生活是明确的主要用户目标。 |
| 目标用户 | L1–L2，准备出国或刚开始海外生活的学习者。 |
| 包承诺 | 能处理校园、住宿、医疗与社交中的高频互动。 |
| 规格 | `course`，12 话题，4 单元，每话题 8–12 分钟。 |

话题草案：课堂提问、与老师沟通、图书馆、租房看房、和室友协商、银行开户、预约看病、描述症状、参加社团、认识新同学、活动邀请、处理误会。

> 与“生活服务与出行”有较高材料重叠。只有当用户群明确时才拆成独立包；否则先将其作为场景包的扩展单元。

### P4：日常叙事与时间表达（第三批候选）

| 项目 | 初步设计 |
| --- | --- |
| 目标用户 | L2，学过不规则动词但仍难以连贯讲述经历的学习者。 |
| 包承诺 | 能把“什么时候发生、过程怎样、结果如何、我怎么看”组织成 30–60 秒短叙事。 |
| 规格 | `course`，8 话题，每话题 10–12 分钟。 |
| 与现有包的关系 | 是不规则动词专项的输出延展，不是重复三态教学。 |

话题草案：一次周末、一次意外、一次选择、一次旅行、一次改变、一次难题、一次收获、一次推荐。

### P5：听懂并自然回应（模式扩展，后置）

| 项目 | 初步设计 |
| --- | --- |
| 立项条件 | 音频、逐句文本、播放与反馈体验已稳定。 |
| 目标用户 | L1–L2，认识表达但实际听到时反应慢的学习者。 |
| 包承诺 | 从短音频中抓取意图和关键信息，并作出恰当回应。 |
| 规格 | `listening`，10 个短场景；每课 45–90 秒音频 + 听后回应。 |

优先复用 500句与生活场景包的材料，避免新增一套与口语内容脱节的听力词库。

### P6：剧情任务 / 漫语町（模式扩展，后置）

剧情适合承担持续动机和沉浸练习，但不是首发核心教材。建议先将《漫语町》打磨为 **1 个完整的短章节**：3–5 个剧情任务、一个明确关系变化、可复用的表达目标，再决定是否扩写为长期世界观内容。它不应替代基础学习路径。

## 5. 推荐的课程路线

```text
新用户
  └── 7 天开口启动（由现有内容编排，不另造一套教材）
        ├── 口语万能造句：50 个高频句式
        ├── 常用英语500句
        └── 生活服务与出行（P1）
               ├── 不规则动词专项
               ├── 职场协作与沟通（P2）
               └── 留学生活沟通（P3）

进阶输出：日常叙事与时间表达（P4）
模式扩展：听懂并自然回应（P5）／剧情任务（P6）
```

这是推荐路径，而非绝对前置。学习者应始终能因具体目标直接进入场景包、职场包或专项包；系统只需提示“建议先复习哪些表达”。

## 6. 单个学习包设计模板

未来每个正式包都先填写这一页，确认后才开始写 CSV、教学 Markdown、音频或脚本。这样能避免“先收集一批材料，再想它能教什么”。

```md
# {学习包名称}

## 一句话定位
{目标用户} 在 {具体情境} 中，能够 {可观察的输出动作}。

## 课程边界
- 难度：L{n}–L{n}
- 包类型 / 模式：course | foundation | daily；practice | listening | writing | story
- 预计完成：{话题数} 课 × {每课时长}
- 推荐前置：{已有包 / 不强制}
- 不教什么：{避免与已有包重叠的内容}

## 完成标准
1. {可观察的真实任务}
2. {可观察的真实任务}
3. {可观察的真实任务}

## 单元与话题
| 单元 | 话题 | 本课交际动作 | 新学材料 | 复习材料 | 最终输出 |
| --- | --- | --- | --- | --- | --- |

## 材料策略
- 新材料上限：{每课 vocab / chunk / pattern 数量}
- 必须复用：{来自哪些前序包}
- `learn` 认领：{首次教学的材料}
- `review` 认领：{在练习中复用的材料}

## 每课固定体验
1. 看见/听见一个真实情境。
2. 理解 1–2 个能立即开口的完整表达。
3. 替换自己的信息完成有支架练习。
4. 完成 2–6 轮对话或一个短输出任务。
5. 用明确标准自检，并进入间隔复习。

## 发布验收
- [ ] 每个话题都有明确交际动作和最终输出。
- [ ] 所有教学英文都能映射到已绑定或白名单材料。
- [ ] 新旧材料都完成 `learn` / `review` 认领。
- [ ] Topic 与 Vocabulary / Chunk / Pattern 关联完整。
- [ ] 离线包包含话题、材料索引、媒体和正确版本号。
- [ ] 至少 5 名目标用户完成试学并记录卡点。
```

## 7. 接下来的内容工作顺序

1. 先把三个现有内容线的数据关联收口，尤其是 500句数量、不规则动词材料绑定、50句型三分包归属。
2. 使用现有内容编排「7 天开口启动」，验证用户是否能顺利进入课程。
3. 按本模板完成 P1《生活服务与出行》的单包设计稿；先确认 12 个话题和材料复用，再写具体教学内容。
4. 用 P1 的试学反馈判断 P2 职场还是 P3 留学优先，不提前同时开工。
5. 当核心口语包稳定后，再投入听力、剧情等新的学习模式。
