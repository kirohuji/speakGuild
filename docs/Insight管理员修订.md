# Insight 管理员修订与关联练习

## 管理员修订

重新生成是管理员修内容的工具，权限判断沿用 `session.user.role === 'admin'`，服务端再次检查管理员身份。仅讲解、例句 tab 显示图标；离线禁用，点击后仅保存当前字段。

生成校验失败保留旧数据；内容生成期间发生其他修改时拒绝覆盖。句块例句替换与主记录更新时间在同一事务完成，并同步资源引用。新例句不沿用旧句子的音频，也不自动生成 TTS。

### 内容与排版规范

insight 修订与后台仅重新生成讲解／例句共用 `AdminContentAiService.regenerateLearningFields`。只要求模型生成选定字段，并参考原讲解中正确、有价值的信息。单词优先读取已有词典缓存中的完整义项、参考例句，同时复用词汇生成的句块风格参考；不会另启动一整套词典生成任务。

完整新建、补缺和批量生成共用 `DESCRIPTION_LAYOUT_RULE`、`LEARNER_EXAMPLE_RULE` 及内容检查。固定四节为核心含义、用法提示、易错点、常见搭配，中文正文建议160–260字，复杂内容最多320字。每节一个短段，节间空行，正文避免列表、编号和重复套话。搭配优先三条、可靠搭配不足时可两条，最多四条，格式为 `英文搭配`（中文译法），同一段用顿号连接。

例句要求3–4条自然中英对照，避免重复、长段和生僻文学表达。检查不合格时最多纠正一次；仍不合格就失败，不把低质量结果写回。规范化仅调整排版与标点，不在本地编造中文翻译。

只有管理员打开 insight 时才解析旧显示 ID、读取修订小快照和订阅修订刷新。只有管理员点击重新生成并保存成功后，才更新对应内容索引、话题／学习包缓存、今日任务题目快照和学习库内容快照。收藏关系、掌握状态及历史作答不变。

普通用户打开 insight、学习库分页、学习包安装索引，不读取或合并管理员修订记录。已移除上一版全局 ZIP 修订合并、逐字段版本比较和学习库额外查询。修订小快照只服务管理员重新打开弹窗，不参与正常用户同步流程。

内容实体的更新时间进入原有公共内容更新检查。不会自动重新发布全部完整 ZIP，其他设备仍按现有学习包更新流程获取新内容。

## 关联知识点练习

所有用户的 tab 栏右侧均提供知识点练习图标。点击前不加载练习数据；点击后只读取本地当前学习包的题目，按知识点 ID、明确的目标词以及英文题目内容筛选。缺少当前包上下文且知识点属于多个包时，让用户选择包，不混合不同包的题目。

练习界面直接复用 `GuidedWarmupPhase` 及原题型组件，保留题目原始话题上下文和稳定 ID。评分、录音、SRS、练习记录与同步沿用原流程。过滤练习使用独立会话 key，避免覆盖整个话题的练习进度和提交记录。

练习弹层打开时保持 insight 挂载，并暂停其底层键盘／手势切词；返回或完成练习后继续显示原 insight。没有匹配题目时显示提示，不创建空练习。

加入学习库按钮改为纯图标，保留可访问名称及提示。

## 验证范围

验证管理员权限和普通用户零修订查询、字段局部更新、本地缓存更新、关联题筛选及题目 ID 稳定、只读取当前包、返回 insight 和空题处理。不运行 build、不打开浏览器；真实 AI 输出与 iOS 弹层、录音交互仍需真机验收。
