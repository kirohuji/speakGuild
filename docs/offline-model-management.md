# 离线模型管理

后台入口：`/admin/offline-models`，位于“大模型管理”旁。仅管理员可准备、导入、验证、发布和删除版本。App 使用登录用户的 `/offline-models/:variantId/manifest` 接口读取已发布模型。

## 模型和资源

- 覆盖现有 Whisper Tiny/Base/Small EN q8，以及 MiniLM q8/fp16/fp32。
- 每个型号和版本独立保存，版本号不可重复。仓库下载会先解析并固定实际 commit，避免 `main` 更新导致同一包混合不同版本。
- `OfflineModelVersion.files` 保存相对路径、资产 ID、大小和 SHA-256；完整 ZIP 包单独保存为资产。资源库增加 `offline_model` 分类。
- 文件上传沿用现有 COS 存储和哈希去重。通过 `offline_model_version` 文件引用关联版本，资源库详情可以反向跳转到模型版本。
- 下架保留资源引用，允许旧版本重新发布。删除版本先解除引用，文件由资源库现有清理机制处理；其他版本共享的资源仍受到引用保护。

## 准备流程

“准备新版本”支持两种来源：

1. 下载到资源库：固定白名单模型的 Hugging Face 仓库及指定来源版本，后台下载并校验所选型号需要的文件。
2. 导入模型包：选择资源库现有 ZIP，或上传新的 ZIP。最大 600 MB，需保留配置、分词器和 `onnx/` 的相对目录。ZIP 可以多包一层模型文件夹；同一必需文件不能重复出现。解压路径、声明大小及配置用途均会校验。

后台使用独立的 BullMQ `offline-models` 队列，任务类型为 `offline-model-prepare`。任务在现有任务中心可查看进度、当前文件、错误和日志，支持取消、重试及排队调整。重复准备同一版本会拒绝；重复重试活动任务返回当前任务。强制并发执行同一模型版本被拒绝。

已下载并校验的文件逐个登记资源引用，任务失败后保留，重试可以复用。服务重启后会核对排队／进行中的模型任务。模型准备失败不会修改当前发布版本。

大文件下载、COS 上传和完整 ZIP 生成使用流式磁盘处理；ZIP 导入使用已有 AdmZip，受上传大小和解压内容上限约束。临时目录在任务结束后清理。

## 发布与验证

发布前核对完整文件清单、资源是否存在、大小和校验值；同一型号仅能有一个发布版本，数据库部分唯一索引与事务共同约束。新版本发布会下架同型号先前版本。

文件校验不代表已通过 iOS 推理测试。页面独立记录“未验证／通过／失败”及备注。标记失败的版本不能发布；尚未验证的版本发布时会明确提示管理员。回滚通过重新发布旧版本完成。

## App 安装

原生 App 下载时只向应用后端获取发布清单，从资源库资产地址下载，不再直接访问 Hugging Face。配置与权重统一使用原生 FileTransfer，以保留文件原始字节。

完整版本先下载到独立临时目录，逐文件校验清单大小与 SHA-256，并检查 JSON／基本权重完整性；整套完成后切换目录，切换失败恢复原目录，重启后可以恢复中断切换的备份。不同型号／精度分别存放，兼容读取已有旧格式安装。SHA-256 使用 Filesystem 分块读取，避免大权重一次进入 WebView 内存。已有文件校验匹配时可直接复用。安装清单提交后才报告 100%；失败保留原有可用文件。

已经安装的模型继续从本地加载，不会因进入练习或后台发布新版本而自动下载。

## 部署与使用顺序

1. 应用数据库迁移 `20261114000400_offline_models`，然后部署后端和前端。代码更新不会自动执行迁移。
2. 后端使用项目已有 Redis 和 COS 配置；下载源默认使用第三方国内镜像 `https://hf-mirror.com`，通过后端环境变量 `HF_ENDPOINT` 可改为 `https://huggingface.co` 或兼容的自建镜像（HTTPS）。元数据和固定 commit 的文件均使用同一配置源，继续校验文件大小、SHA-256／Git blob 哈希；实际源地址记录在任务日志。修改配置后需重启后端任务进程，再重试失败任务；已固定的 commit 保持不变，镜像缺少该版本时会明确失败。无法连接时使用资源库导入。
3. 管理员准备模型，等待文件校验完成，记录 iOS 验证结果，手动发布。
4. 用户在 App 模型设置中选择对应型号下载。未发布型号会得到明确提示。

实现时不自动启动实际模型下载或发布任务，也不触碰生产数据库。验证使用类型检查、SQLite 回归、模型清单／安装测试、后台页面组件测试和 ZIP 互操作测试；未进行 build、浏览器或 iOS 真机验收。
